## 資料の探し方

- 印刷版の OCR は、上の抜粋の行範囲から読み始める。ページをめくって探さない。抜粋が「未記入」のときだけ自分で探し、見つけた行範囲を返す内容に書く。
- ギリシア語の OCR は崩れていることが多い。読みの判断はページ画像で確かめる。画像は 1 枚ずつ `python3 -I tools/iiif-crop.py <identifier> <IIIF番号> <領域> <出力先のディレクトリ>` で取る。領域は `full`、ピクセルの `x,y,w,h`、割合の `pct:x,y,w,h`（脚注だけなら `pct:0,60,100,40` など）。出力先は `cache/archive.org/<identifier>/pages/`。すでにあるファイルは取り直さない。
- そのほかの校訂本・注解は `research/sources.md` にあるものを使う。足りなければ、パブリックドメインの資料を `python3 -I tools/fetch.py <URL>` で `cache/` に取り（保存先と SHA-256 の先頭 16 桁が出る）、`research/sources.md` に行を足す（URL、権利、cache のパス、SHA-256 の先頭 16 桁、取得日 {{今日}}）。同じ資料を何度もウェブから引かない。
- 七十人訳・新約の本文の確認は cache にある Swete などの OCR、口語訳は `python3 -I tools/bible.py <ref> …`（例 `Gen.18.1-3 Rom.8.18`）。

## シェルの書き方

承認の確認で止まらないように、実行するまで中身が決まらないシェルは書かない：`for` ループ、`set --`、変数をつないだ URL やファイル名、`$` を含む URL を curl に渡すこと、`rm`。繰り返しは、scratchpad に Python のスクリプトを書き、引数を渡して `python3 -I` で実行する。画像は上の `tools/iiif-crop.py` を使う。画像の切り出しや縮小に Pillow、PDF のページの書き出しに PyMuPDF（`import pymupdf`）が使える。

## 著作権

著作権の残る訳文（英訳も日本語訳も）は読まない。ウェブで訳文を探さない。著作権の残る研究書からは事実（写本の読み、校訂者の採否、成立の説）だけを取り、記録は自分の言葉で書く。著作権の切れた英訳は読んでよいが、訳文を論点一覧に写さない。

## 作るもの

ページごとに一つのファイル：{{書き込み先}}

- 各ファイルの先頭は `# <節> の論点（<範囲>）`。略号と資料の所在は `books/{{本}}/research/cruxes/README.md` にまとめ、なければ作る（手本の冒頭にならう）。
- 論点ごとに `### <ラベル> <見出し>` を立て、底本の読み、ほかの読みとその支持、採る校訂者、読者への影響（大／中／小）、訳での扱い、確かめた資料と箇所（OCR の行番号、画像のファイル名）を書く。
- 記憶で書かない。資料で確かめたものだけを載せる。確かめられなかったものは、ファイルの末尾の `## 未確認` に分ける。
- 「訳での扱い」には、訳注を付けるかどうかと、付けるなら注の案を書く。注の案は 40 字以内、写本名・校訂者名を出さない、一般の読者向け。訳注は、別の読みや後代の挿入を知らないと読者の理解が変わる箇所にだけ付ける。
- 本文の読みの違いのほか、聖書や古典の引用・暗示で、原文がどの本文（七十人訳など）に近いか、引用元が分かれる場合も、訳に影響するなら論点にする。

`research/cruxes/`、`research/sources.md`、`cache/` 以外は編集しない。コミットしない。仕事を分けるためにサブエージェントを立てない。
