## 読むもの

- ルートの `AGENTS.md` の決まり（とくに「both.md の書き方」「文体」「表記」「聖書」「訳注」）。すでに文脈にあれば読み直さなくてよい。
- `books/{{本}}/AGENTS.md`（この本の決まり。ルートと食い違うときは本が優先）。
- 対象：`books/{{本}}/src/{{節}}/both.md`。原文の行の直後に、その節の訳の行がある。
- 文体と訳語の継続の確認用：{{前のページ}}
- 論点一覧：{{論点一覧}}。訳が底本の読みに従っているか、訳注が論点一覧の扱いと合っているかを見る。
- 電子化と印刷版の照合：{{照合}}。訳は印刷版の読み（意図された形）に従っているはずである。
- 著作権の切れた英訳（読み比べ用。訳の文言を英訳に寄せる必要はない）：{{英訳}}

渡したファイルは、該当部分だけを切り出したもの。元の大きなファイルを丸ごと読まない。節番号がこの訳で付けたもの（本の README に書いてある）のときは、英訳の区切りと番号が合わなくてもよい。

著作権の残る訳文（英訳も日本語訳も）は読まない。ウェブで訳文を探さない。

## 見る観点（優先順）

1. 誤訳：原文の読み違い（格・態・時制・法、否定、主語と目的語、分詞の係り方、小辞の論理）。
2. 訳抜け・訳しすぎ：節の中の句が落ちている、原文にない内容が足されている。原文の行ごとに確かめる。
3. 底本との食い違い：底本と違う読み（異読）で訳している。
4. 規則違反：ルートと本の AGENTS.md（訳語表、文型の訳し方、出典の書き方と位置、『』の使い方、ひらく語、訳注の形と 40 字以内、一文 50 字前後）。記号と出典の書式の多くは検証スクリプトで確かめ済みなので、スクリプトで拾えない誤りを見る。
5. 不統一：このページの中や前のページと、訳語・口調・表記が揺れている。
6. 読みにくさ：日本語として意味が取りにくい、係り受けが崩れている、長すぎる（60 字超）。

好みの言い換えは求めていない。

`// ` で始まるメモの行はビルドで消え、読者には見えない。メモは、事実の誤り（出典の章節、異読や底本の記述、口語訳との違いの書き漏らしで次の訳に響くもの）だけを指摘する。メモの言い回しは見ない。

## 聖句

聖句の引用と出典は、口語訳で照合する：`node tools/bible.js <ref> …`（例 `Gen.18.1-3 Rom.8.18`）、語句から探すときは `--find <語句>`。記憶で判断しない。原文がそのまま引いているところは口語訳の文言に揃っているか、言い換えているところは原文から離れていないかを見る。出典の章節が合わないときは指摘する。

## 返すもの

日本語で、節番号の順に、表で：節番号、分類（上の 1〜6）、現在の訳（短く）、問題、直した案、必須か提案か。

直した案は [旧, 新] の組の JSON 配列にして `{{pairs}}` に保存する。

- 旧は both.md の訳の行の一部をそのまま写した文字列で、その時点のファイル全体で 1 か所だけ一致すること。原文の行は変えない。
- 組は上から順に当たる。保存したら `node tools/replace.js --dry-run books/{{本}}/src/{{節}}/both.md {{pairs}}` を実行し、`OK` が出るまで直す。

最後に、次のページでも揃えるべき訳し方（語の訳し分け、文法の形ごとの訳し方）があれば 3〜5 個まで挙げる。
