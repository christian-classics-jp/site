# アタナシオス『アントニオス伝』の決まり

アレクサンドリアの監督アタナシオスが、アントニオスの死（356 年ごろ）の後まもなく、エジプトの外の修道士たちの求めに応えて書き送った伝記。ギリシア語。手紙の形をとり、序と結び（94 章）で読み手の修道士たちに語りかける。間に、アントニオスの修道の生涯、悪霊との戦い、修道士たちへの長い講話（16〜43 章）、哲学者たちとの問答（72〜80 章）、死（89〜93 章）を語る。

同じ著者の既訳『神のことばの受肉』（`books/incarnation/`）は英訳からの重訳なので、文体は引き継がない。人名と神学用語の表記（アタナシオス、神のことば、救い主、悪霊、偶像）だけを合わせる。悪霊・誘惑・修道の語彙はこの本で決め、後の『マルティヌス伝』（sulpicius-life-of-martin）に引き継ぐ。底本を PG の画像から起こす手順は『キリストと反キリストについて』（`books/hippolytus-on-antichrist/AGENTS.md`）にならう。ここには、この本に固有の決まりだけを書く。食い違うときはこのファイルを優先する。

## 節の形

- 章（1〜94）の番号は底本（PG 26）に従う。英訳（NPNF 第 2 集第 4 巻）の章の番号も同じ。底本の序（ΠΡΟΟΙΜΙΟΝ）には番号がなく、この訳で 0 章とした。
- 底本には節の区分がない。節の番号は、画像から起こした章を `tools/split-units.js` で文の切れ目（. と、その後の閉じ引用符）で分けて、この訳が付けたもの。底本にも英訳にも、この節番号はない。英訳と照らすときは章と文の内容で照らす。ギリシア語の疑問符（;）と上の点（·）では切らない。
- 底本テキストは `research/pg26.txt`。1 行 1 節で `<章>.<節> <本文>`（`2.5`、序は `0.1`）。
- 底本の 1 節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `2:5 ` のように章・節の番号で始める（序は `0:1 `）。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 5〜7 章　…` の形（章の範囲、中身）。最初のページは `# 序、1〜4 章　…`。
- 底本の表題（ΒΙΟΣ ΚΑΙ ΠΟΛΙΤΕΙΑ ΤΟΥ ΟΣΙΟΥ ΠΑΤΡΟΣ ΗΜΩΝ ΑΝΤΩΝΙΟΥ…）と序の見出し（ΠΡΟΟΙΜΙΟΝ）は底本テキストに入れていない。書名は README から出る。
- ページの割り（`research/pages.json`）は、全文を起こす前に、英訳の章ごとの語数（序を含めて計 24,000 語ほど。ギリシア語は序と 1〜4 章で英訳の 0.76 倍）と英訳の目次の切れ目で、21 ページに分けた。生い立ちと修行の始まり（序〜4 章）、悪魔との最初の戦い（5〜7 章）、墓と荒野（8〜11 章）、廃れた砦での二十年と修道の広がり（12〜15 章）、修道士たちへの講話（16〜20、21〜24、25〜28、29〜34、35〜38、39〜43 章）、迫害とアレクサンドリア、内の山へ（44〜48、49〜53 章）、内の山での教えとしるし（54〜57、58〜62、63〜66 章）、正統の信仰とアレクサンドリア訪問（67〜71 章）、哲学者たちとの問答（72〜75、76〜80 章）、皇帝の手紙と幻、癒やし（81〜84、85〜88 章）、最後の教えと死、結び（89〜94 章）。

## 底本の扱い

- 本文は、archive.org のページ画像から起こし、OCR と語ごとに突き合わせる。ページごとに、訳す範囲を起こして `research/pg26.txt` に足す。本を始めたときに起こしたのは序と 1〜4 章（最初のページ）だけ。次のページを訳すセッションは、page-context を作る前に、そのページの章を起こして足す（起こさないと page-context は空の抜粋を書き出す）。
- 画像は pages.json の `images` の番号 N（IIIF の番号と同じ）で、`node tools/fetch.js https://archive.org/download/patrologiae_cursus_completus_gr_vol_026/page/nN_w1600.jpg cache/archive.org/patrologiae_cursus_completus_gr_vol_026/page/nN_w1600.jpg` として取り（N は 0435 ではなく 435 と書く）、`node tools/image.js crop <画像> pct:x,y,w,h <出力先> [--scale 2]` で切り出して読む。2026-11-21 には IIIF のサーバー（`tools/iiif-crop.js`）が応答しなかった。
- ページの組み：上半分にギリシア語の欄とラテン語訳の欄が並ぶ。奇数番の画像（435、437…）はギリシア語が左、偶数番（436、438…）はギリシア語が右。章の終わりなどで、ギリシア語の行が二つの欄にまたがって全幅で刷られることがある（2 章の終わりの ὅσα ἦν αὐτοῖς κινητὰ… は n438 の上部の全幅の 2 行）。その下に VERSIO EVAGRII（エウァグリオスの古ラテン語訳）、聖書の箇所、校注が続く。1 ページのギリシア語は 200〜300 語ほどで、1,000 語のページに 4〜5 枚の画像を読む。
- 手順：画像のギリシア語の欄を、行の頭の字が切れないように少し広めに切り（左の欄なら `pct:6,4,46,20` ほどから）、上から順に読んで、1 章 1 行のファイル（`<章> <本文>`）に書く。`tools/split-units.js` で足したあと、`node tools/collate.js research/pg26.txt <範囲> <OCR> <print の行範囲> --ignore-accents` で OCR との違いの候補を出し、一つずつ画像で確かめる。OCR はラテン語訳の欄（ギリシア文字に化けている）を同じ行に混ぜるので、類似度は 0.3 ほどにしかならず、長い「OCR only」が出る。候補の大半は κ を χ、β を δ と読む誤りなので、それを除いてから見る。アクセントと気息はこの比べ方では確かめられないので、画像の目視で確かめる。どの画像をどう切って読んだか、OCR との違いが何だったかは `research/sources.md` の画像の行に書き足す。
- OCR は κ を χ、β を δ、θ を ϑ と読み、章の番号もよく崩す（16 章を「10.」、25 章を「45.」と読む）。OCR だけに頼らず、必ず画像で読む。
- 起こすのはギリシア語の本文だけ。ラテン語訳、エウァグリオスの訳、校注、欄外の A・B・C・D、欄の番号、ラテン語訳の欄に太字で刷られた旧版のページ番号（631 など）、本文の中の校注の番号（`(2)`）、聖書の箇所を示す上付きの番号は起こさない。章の番号は行の頭に刷られるが、本文には入れない。行末で分けられた語はつなぐ。
- 文字は通常のギリシア文字で書く。省略の印は ᾽（U+1FBD。παρ᾽、κατ᾽、δι᾽）、上の点は ·（U+00B7）。綴り、アクセント（読点の前の重アクセント、καλαὶ) など）、気息、iota subscriptum の有無、ῤῥ（ἐῤῥᾳθύμει）、大文字（Παρθενῶνα、Κυριακῷ、Εὐαγγέλιον）、句読点は底本のとおり。
- 底本は聖書の言葉の直接の引用をイタリックで刷り、上付きの番号で下の欄に箇所を記す（2.3 の Εἰ θέλεις… は Matth. xix, 21）。底本テキストでは、イタリックの部分を „ “ で囲む。訳では „ “ の部分を聖句の直接の引用として扱い（『』と出典）、下の欄の箇所を出典に使う。イタリックでない聖句（3.7 の Ὁ δὲ ἀργὸς μηδὲ ἐσθιέτω、第二テサロニケ三・一〇）は底本テキストで „ “ に入れない。訳では、聖句をそのまま引いているとみてよいときは『』と出典を付け、`// ` メモに底本がイタリックにしていないことを書く。
- 印刷の誤りは、底本テキストには刷られたとおりに書き、訳は意図された形で行って `// ` メモに書く。0.3 の κέδρος は κέρδος（利益）の誤植（校注 4 が同じ文を κέρδος で引く）。字間を空けずに刷られた点で、句読点の位置にないもの（0.5 の τι の後、2.2 の ἐλογίζετο と περιπατῶν の間）は、活字の汚れとみなして起こさない。
- 校注は、Regius（王立図書館）、Colbertinus、Jesuit.、Vatican.、Anglicanus などの写本と、Höschel・Bolland などの刊本の読み、エウァグリオスの訳の読みを記す。訳は底本の読みに従い、写本の読みが訳に関わるときだけ `// ` メモに書く。訳注は読者の理解が変わる箇所にだけ付ける（序の ἀκολουθήσας αὐτῷ … καὶ ἐπιχέων ὕδωρ「長くつき従い、手に水を注いだ」は、写本によって「つき従った人から聞いた」と読め、アタナシオスがアントニオスの弟子だったかどうかに関わる。校注 15）。
- 英訳（NPNF）は Benedictine 版（PG と同じ本文）を基にし、脚注で写本やエウァグリオスの訳の読みに触れる（序の脚注 984 など）。英訳と底本の違いは訳の誤りとは限らないので、レビューでは底本と校注に照らしてから指摘させる。

## 文体

- 地の文は敬体（「〜です」「〜ました」）。アタナシオスがエジプトの外の修道士たちに書き送った手紙で、序と 94 章で読み手に語りかける。間の長い伝記の語りも敬体で通す（『迫害者たちの死について』と同じ）。過去のことは「〜ました」で語り、原文の歴史的現在も過去で訳す。
- 書き手のアタナシオスは「わたし」。書き手と読み手を含むキリスト者は「わたしたち」。読み手の修道士たちは「あなたがた」。
- 神、キリスト、聖霊の動作は尊敬語にする。受け身や可能と紛れる「〜られる」は避ける（「お語りになりました」「おいやしになりました」「お清めになりました」）。講話の中で主・救い主の言葉や聖句を導くときも「言われた」とせず「こうお語りになった」とする（30.3）。アントニオスにも、監督たちや皇帝たちにも尊敬語は使わない。
- アントニオスの言葉は常体。修道士たちへの講話（16〜43 章）と最後の教え（89〜91 章）は、年老いた師が弟子たちに語る落ち着いた常体（「〜しよう」「〜しなさい」「〜のだ」）。一人称は「わたし」、自分と聞き手を含めて「わたしたち」。呼びかけの τέκνα は「子供たちよ」、聞き手は「あなたがた」。哲学者たちへの問答（72〜80 章）も常体で、相手を「あなたがた」と呼ぶ。神への祈りは敬体で、神を「あなた」と呼ぶ。
- 講話の中にも、原文が「彼は言っていた」（ἔλεγε）とアントニオスを三人称で語る文がある（24.1）。その文だけは地の文として敬体で訳し（「アントニオスはよく…言っていました」）、次の文から常体の講話に戻る。講話の中で悪魔を単数の αὐτός で受けるところは、「彼」が地の文のアントニオスや複数の悪霊と紛れるなら「悪魔」と書く（24.3、24.6）。
- 悪魔と悪霊の言葉は常体。一人称は「わたし」、手下に語る複数は「われわれ」、相手を「おまえ」と呼ぶ（6 章、9 章）。アントニオスも悪霊を「おまえ」、悪霊たちを「おまえたち」と呼ぶ。ほかの人物の口調は、最初に出たページで決めてここに書く。
- 修道士たちへの講話（16〜43 章）は長いので、かぎかっこで囲まない。導入の地の文（敬体）に続けて同じ段落で語り出し、地の文の敬体と講話の常体で切れ目を示す（16:1。原文の最初の文は間接話法だが、直接話法として訳す）。講話の中の台詞（「わたしたちはもう長いあいだ修行してきた」）は「」、聖句と書かれた文字は『』。
- アントニオスが訪ねて来た人々に語る言葉（13 章）は常体で、相手を「あなたがた」と呼ぶ（「安心して帰りなさい」）。
- 主の声（10 章）は常体で、アントニオスを「あなた」と呼ぶ（「わたしはここにいた」）。アントニオスが主や主の現れに語る言葉は、神への祈りと同じ敬体（「どこにおられたのですか」）。
- 台詞を地の文から切り出して置くときは、「言いました。「…」」の形にし、閉じかぎの前に句点を付けない。台詞の後ろに地の文が続くときは「「…」と言いました。」の形にする。切り出した台詞が数節にわたり、閉じかぎの後に地の文が続くときは「…」。」と句点を置いてから続ける（6:4）。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」（アントニオスの言葉では「〜だろうか」「〜ではないか」）で終え、「？」は使わない。

## 文型の訳し方

- 序の ἐνεστήσασθε ἅμιλλαν πρός … のような長い分詞の連なりは、セミコロン（·）や分詞の切れ目で文を分ける。分詞が主文の動詞に添う状況を言うときは、文の中にとどめる。
- 理由を言う γάρ と καὶ γάρ は、「〜からです」「というのも、」「じっさい、」のいずれかで受けて、前の文との因果を残す。「また」で受けたり、訳から落としたりしない。οὔτε γάρ … οὔτε γάρ のように続けて出ても、一つずつ受ける（14.2）。常体の台詞の中でも「じっさい、」「〜からだ」で受け、「〜のだ」だけで済ませない。講話のように論の運びが続くところ（20.7、20.8 の Τὸ γάρ、ἐὰν γάρ、23.3、23.4、24.6）で落としやすい。「じっさい、」は γάρ のためにとっておき、μὲν οὖν（21.3）は「さて、」などで受ける。文頭の分詞に付く γάρ（32.1 の ἑωρακότες γάρ）や、括弧の中の γάρ（32.3 の ἔξεστι γὰρ αὐτῇ「摂理にはそれができるからだ」）も落とさない。例を挙げる γοῦν は「現に、」で受ける（25.1、26.4、28.7、28.10。Ἀμέλει も「現に」）。
- ἐάν・ὅταν の後に καί で長く並ぶ条件（36.2、36.3）は、全部で一つの条件として保つ。文を割るときは「〜としよう。……そのときは、」とし、「〜ときも同じだ」と割って、どれか一つでよいように読ませない。ἵνα の後に接続法が続くとき（37.1 の καταπτήξωσι … προσπαίζωσι）は、全部を目的に入れ（「〜するためだ」）、起きている事実のように訳さない。διά に対格が付くとき（37.3 の διὰ τὸν Κύριον）は「〜のゆえに」とし、属格の「〜によって」と分ける。
- 文頭の分詞（18.1 の εἰδότες）は、主文の前に「〜のだから」と置くか、独立した文にして前に出す（「わたしたちは知っている。もし…」）。後ろに「それを知っているのだ」と付け足さない。独立属格は文法上の主語を立てて訳す（20.5 の Τῆς ψυχῆς τὸ νοερὸν κατὰ φύσιν ἐχούσης は「魂が知性を本性にかなったあり方に保っているとき」）。
- 聖句の語を論の中で繰り返すところ（19.2 の「日々死ぬ」、20 章の「振り向く」「内に」「まっすぐ」）は、引用の訳語をそのまま使って語のつながりを見せる。
- イタリックでなく、ὡς γέγραπται で導かれても大きく言い換えた聖句（19.1 のローマ八・二八）は、『』に入れず、底本の形で訳して出典だけを付ける。
- 主語の書かれない動詞で、文脈から主（神・キリスト）が主語と取れるもの（18.1 の συγχωρήσει・ἀγανακτήσει）は「主は」と補って尊敬語にする。たとえ話の κύριος は「主人」と訳し分ける。
- 出典の書名の略称は、リポジトリのほかの本に合わせる（ヨブ記は「ヨブ」、サムエル記下は「サムエル記下」）。話の要約で、底本の欄が二つの章にまたがる範囲を挙げるとき（29.1 の Job I, 15-22; II, 1-7）は、章で示す（`（ヨブ一〜二章）`）。
- 底本が聖句の地の文の部分（29.3 の Παρεκάλουν … τὸν Κύριον, λέγοντες）までイタリックで刷るときも、『』に入れるのは台詞だけにする。
- スザンナ物語は、底本の欄の節の番号で書く（31.3 の Dan. XIII, 42 は `（スザンナ四二）`。テオドティオン訳の節）。七十人訳の節（三五節の後の付加）は `// ` メモに書く（『祈りについて』と同じく、欄の節に従う）。
- 底本の聖書の欄が箇所を挙げる暗示や要約（2.2 の使徒たち、3.7 の絶えず祈ること）は、『』に入れずに出典だけを付ける。出典は底本の欄の箇所に従う。言い回しを借りただけで底本も箇所を挙げないもの（0.5 の「手に水を注ぐ」、列王紀下三・一一）は、出典を付けず `// ` メモに書く。
- 七十人訳による引用・暗示で口語訳（ヘブル語本文からの訳）と意味が合わないもの（1.1 のヤコブ、5.2 のヨブ記、6.4 の詩篇、24 章のヨブ記四〇〜四一章とイザヤ一〇・一四）は、七十人訳の形で訳し、`// ` メモに口語訳との違いを書く。
- 出典の章節は口語訳の番号で示す。底本の欄が七十人訳の番号で挙げるとき（詩篇一一七・七 → 一一八・七、ヨブ四〇・一一 → 四〇・一六）は、`// ` メモに七十人訳の番号を書く。底本の欄の箇所が引用に合わないとき（6.1 の Act. vii, 15、7.9 の Philipp. iii, 14、24 章のヨブ記の欄の範囲、35.3 の Isa. XLII, 2 はマタイ一二・一九、37.2 の Deut. XIII, 4 は外す、38.4 の答えはマタイ二五・一二）は、実際に引かれた節の口語訳の番号で合う箇所を示し、`// ` メモに底本の欄の表記と判断の理由を書く。
- 底本が引用の言葉を変えて文脈に組み込んでいるとき（7.9〜7.10 のエリヤの言葉。「きょう」を「その前に立つ」に掛ける。20 章のルカ九・六二 の「振り向く」、ルカ一七・二一 の「内に」、マタイ三・三 の「あなたがたの道筋」）は、口語訳の文言に寄せず、底本の形で訳して `// ` メモに違いを書く。
- 口語訳にない書（シラ書など）の引用は七十人訳（Swete）から訳し、出典は `（シラ書一・二五）` の形で Swete の番号に従う（オリゲネス『祈りについて』、キプリアヌスの論文集と同じ。verify の略称の WARN は認める）。底本の欄がウルガタの番号で挙げるとき（28.7 の Eccli. I, 32）は `// ` メモに書く。
- 原文が聖句をそのまま引くところは、講話の常体の中でも口語訳の文体（「〜ません」）と、文頭の「しかし」（δέ）を保つ（26.3、27.1〜27.2）。
- 口語訳の語で、いまは差別語とされるもの（三八・一三 の「耳しい」「おし」）は、「耳の聞こえない者」「口のきけない者」と言い換える（27.1）。
- なじみのない単位はメートル法に直し、元の単位と換算の前提を `// ` メモに書く（2.4 の三百アルーラは「八十ヘクタールほど」）。
