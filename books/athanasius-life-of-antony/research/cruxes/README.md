# 校訂上の論点

アタナシオス『アントニオス伝』の本文で、写本・古代訳・刊本の読みが分かれる箇所と、聖書や古典の引用と暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（PG 26、`../pg26.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。底本テキストと印刷版の食い違い（電子化の誤り）と、印刷版の誤植（0.3 の κέδρος など）は照合で扱い、ここには書かない。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は、ことわりがなければ印刷版の OCR（`cache/archive.org/patrologiae_cursus_completus_gr_vol_026/patrologiae_cursus_completus_gr_vol_026_djvu.txt`）の行番号。OCR は校注のラテン語をギリシア文字に化けさせ、写本の略号や番号もよく崩すので、校注はページ画像（`cache/archive.org/patrologiae_cursus_completus_gr_vol_026/page/nN_w1600.jpg`）で読む。画像の切り出しは `node tools/image.js crop <画像> pct:x,y,w,h <出力先>` で行い、`/tmp` に置いただけ。各項には、元の画像と切り出した領域を書く。

## 底本の印刷版の形

- 底本：J.-P. Migne 編、Patrologia Graeca 26 の欄 835〜976（本文はベネディクト会版と同じ。本の AGENTS.md による）。各ページの上半分にギリシア語の本文とラテン語訳の欄が並び、その下に VERSIO EVAGRII（エウァグリオスの古ラテン語訳）、聖書の箇所、校注が続く。
- 本文の中の `(2)` のような番号が校注の番号。ページが変わっても番号は戻らず、(1)（n434 の表題）から (99)（n446 の 10.2）まで続く。n446 の (99) の次の注は (1)（10.3）で、そこから番号を振り直す（n449 の 16 章で (32)）。n461 の 30 章で (99)（καταπατοῦντας）の次がまた (1)（ἐξουσίαν）になり、もう一度振り直す。番号はギリシア語の本文とエウァグリオスの訳の両方に振られ、一つの列の中で混じる（n435〜n446 では、7〜13、18〜23、28〜30、39〜42、48〜49、53〜55、61〜64、69〜72、78〜79、86〜88、95〜97、振り直した後の (4) がエウァグリオスの訳の写本と刊本についての注。n447〜n449 では、振り直した後の (9)〜(13)、(20)〜(24)、(29)〜(32)。n450〜n453 では (36)〜(37)、(41)〜(42)、n452 の (45)〜(47)、n453 の (52)。n452 の (47)（エウァグリオスの訳）の次に、n453 で (47) がもう一度ギリシア語の本文の注として刷られ、(52) まで続く。n454〜n456 では (57)〜(61)、(68)、(73)〜(76)。n457 の (77)〜(82) は 25 章の注。n457〜n460 では (81)〜(82)、(87)〜(88)。n460〜n463 では (98)、二度目に振り直した後の (4)〜(5)、(10)〜(13)。n463〜n466 では (18)〜(20)、(25)〜(26)、(33)〜(34)。n466〜n469 では (41)、(46)〜(47)、(51)〜(54)、(59)〜(60)。n468 の (54)（エウァグリオスの訳）の次は、n469 で「(54′)」とダッシュを付けて刷られ、42 章のギリシア語の本文にかかる。(55) から番号が続く。n470〜n473 では (63)〜(64)、(66)〜(70)、(74)〜(77)。n473 の (80)〜(81) は 49 章の注。n473〜n476 では (82)、(90)〜(92)。n475 の 52 章の注は「(88′)」とダッシュを付けて刷られる。n476〜n479 では (90)〜(92)、(97)〜(99)、三度目に振り直した後の (1)〜(2)、(5-6)〜(9)、(13)〜(14)。n477 の (99)（エウァグリオスの訳）の次は (1) で、ここで三度目に振り直す。n478 には「(5-6)」とまとめた番号の注がある。n479 の 56 章の注は「(9′)」とダッシュを付けて刷られ、n478 の (9) とは別の注。n479〜n482 では (13)〜(14)、(17)〜(18)、(22)。n480 の 58 章の終わりの注は「(15′)」とダッシュを付けて刷られる。n483〜n485 では (29)、(33)、(39)〜(40)。n485〜n488 では (40)、(45)、(49)、(52)〜(54)。n489〜n491 では (58)〜(59)、(62)〜(63)、(66)。n492〜n493 では (70)、(74)〜(75)。n494〜n497 では (79)〜(80)（エウァグリオスの訳の 80 章）、(83)〜(84)、(89)、(92)、(93)（(91) はギリシア語の本文、(93) はエウァグリオスの訳の 85 章）。n498〜n499 では (97)〜(99)、四度目に振り直した後の (5)。n498 の (99)（エウァグリオスの訳）の次は n499 の (1)（87 章の ἐλθών）で、ここで四度目に振り直す。n498 の (94) は、底本のラテン語訳の欄（86 章の終わりの moreretur）に付き、『修道士たちへのアレイオス派の歴史』14 章を挙げる（ギリシア語の本文にもエウァグリオスの訳にもかからない）。n489 の (57) は、底本のラテン語訳の欄（73 章の mentis）に付き、テルトゥリアヌスの並行を挙げる（ギリシア語の本文にもエウァグリオスの訳にもかからない）。注 78 は、エウァグリオスの訳を 8.1 のギリシア語の読みの証人として挙げる）。
- 校注が「すべての写本は（または Regius 2 と Colb. 2 は）こう読む」と書いても、本文がその読みを刷っているとは限らない。注 60（6.5 の καταπτήξας）、注 76（7.10 の τῷ Θεῷ の位置）、注 77（7.11 の ἐν ἑαυτῷ, δεῖν）、注 (83)（49.3 の ἐνδοτέραν。校注はほとんどすべての写本が ἐσωτέραν と読むと言う）では、刷られた本文は校注が刊本の読みとする形になっている。注 82、83、98（8.3、8.4、10.1）では、校注が挙げる Regius 2 と Colb. 2 の読みを本文が採らず、刊本の読みも書かれていない。底本の読みは、校注からではなく本文（画像）から取る。
- 本文は Colb. 2 だけの読みを採ることがある。注 28（37.1 の ὅτ᾽ ἂν τοίνυν）で、校注は Colb. 2 だけの読みだが従うことにしたと書く。注 32（38.2 の τοῦτο Σωτῆρος）も Colb. 2 だけの読み。
- 注 31（38.1 の二つめの ἢ）は「Vide supra num. 22」とだけ書き、語も写本も挙げない。「num. 22」が注 (22) を指すのか本書 22 章を指すのかは確かめていない（chapter-35-38 の 38.1 の項）。
- 聖書の箇所は、上付きの番号（¹² など）で示し、エウァグリオスの訳の下の行に並べる。番号はラテン語訳の欄に付いている。ギリシア語の本文では、聖書の言葉の直接の引用をイタリックで刷る。
- 校注は、写本の読みのほか、刊本の読み、古典や聖書の並行箇所、本文の解釈（序の注 3 の、執筆はアントニオスの死後だという指摘など）にも触れる。

## 写本・古代訳・刊本の略号（校注の書き方のまま）

校注に略号表はない。ここでは校注に出る名前を、校注が言うことだけで説明する。

- Regius 1、Regius 2（Reg. とも）：王立図書館の写本。注 53 は番号を付けずに「Regius codex」とだけ書く。
- Colb. 1、Colb. 2、Colb. 3（Colbertinus）：Colbertinus と呼ばれる写本。注 35 は、Colb. 3 が 3.3 の Οὔπω γὰρ ἦν から始まる「最良の」写本だと言う。ところが注 5 は、0.4 の読みに Colb. 3 を挙げる。また注 15 は、Colb. 2 を対立する二つの読みの両方に挙げる。どちらも画像で数字を拡大して確かめたが、刷られたとおりで、どれが誤植かは決められない。
- Jesuit.（Jes.）：イエズス会の写本（校注の略号のまま）。
- Vatican.：ヴァチカンの写本。注 15 は「566 番」の写本と、「二つのヴァチカンの写本」に触れる（校注の筆者が「わたしたちの兄弟たち」fratres nostri の知らせとして挙げる）。
- Anglicanus：イングランドの写本。注 15 によれば、オックスフォードの Sancti Edmundi 学寮の長 Jacobus Millius が読みを書き送った。
- editi：それまでの刊本。editi priores は古い刊本。
- エウァグリオスの訳（Evagrius）：古ラテン語訳。校注はその読みを、ギリシア語の読みの証人として挙げる（注 2、注 33、注 38）。エウァグリオスの訳の写本は Germ.、Gemmet.、Colb.、Maximin.、Desmar.（注 (53)。71 章の remeabat）などの略号で、刊本は Rosweyde と Bolland の版で挙げられる。
- Hœschelius（Höschel）：刊本の編者。注 1 は表題をその刊本の形で挙げ、注 39 はエウァグリオスの訳の読みについて名を出す。
- Edit. Paris.：パリの刊本（注 1）。注 (43)（40 章）は、パリの編者が Höschel の欄外の推測（ἐνέπτυσα）に写本の裏づけなしに従ったと言い、注 (58)（43 章）は、パリの編者が Savile の写本の読みを良いものも悪いものもしばしば採ったと言う。
- Savil.（codex Henrici Savilii）：Henricus Savilius（ヘンリー・セイヴィル）の写本。注 (38)（39 章）によれば冒頭を欠き、Höschel がその異読を『アントニオス伝』の巻末に付けた。注 (54′)、(57)、(58) では刊本（パリの刊本）と同じ読みを持つ。注 (86)（50 章）では Colb. 2 と同じ読みを持つ。三度目に振り直した後の注 (3)、(4)、(10)（55〜56 章）では Regius 2 や Colb. 2・3 と同じ側に挙がり、本文はその読みを採る。
- Vulg.：注 (88′)（52 章）に「Vulg., παρετηρῆτο. Edit.」とある。普通の刊本の読みと、編者の注の署名と読んだが、確かめていない（chapter-49-53 の「未確認」）。注 (15′)（58 章）にも「Vulg., λιπόν. Edit.」と同じ形の注がある。

## 読み比べに使う資料

- 英訳（NPNF 第 2 集第 4 巻、`cache/ccel.org/npnf204.txt`）：ベネディクト会版の本文から訳し、脚注で写本の読みや並行箇所に触れる。論点には、英訳の脚注が挙げる事実（箇所や読みの有無）だけを書く。英訳の文は写さない。
- 新約：Robinson & Pierpont の電子テキスト（`cache/raw.githubusercontent.com/byztxt/byzantine-majority-text/`。Nestle-Aland と違う箇所を `{NA … > …}` で添える）。
- 七十人訳：Swete（`cache/archive.org/oldtestamentingr01swetuoft/`、`…02swetuoft/`、`cache/archive.org/theoldtestamenti03swetuoft/`）。ダニエル書は七十人訳（古ギリシア語訳）とテオドティオン訳を並べて刷る（III の l. 49315 以下）。
- 口語訳：`node tools/bible.js`。
- 古典：Perseus Digital Library の canonical-greekLit（クセノフォン『ソクラテスの思い出』、プラトン『パイドン』、ヘロドトス）。
