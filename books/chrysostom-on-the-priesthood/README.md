# ヨアンネス・クリュソストモス『祭司職について』

ヨアンネス・クリュソストモスの『祭司職について』（Περὶ ἱερωσύνης）全 6 巻のギリシア語原文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は J.-P. Migne 編、*Patrologiae cursus completus, series Graeca* 48（Paris: J.-P. Migne）の欄 623〜692。B. de Montfaucon のベネディクト会版の本文を再録したもの。パブリックドメイン。archive.org のスキャン（[patrologiae_cursus_completus_gr_vol_048](https://archive.org/details/patrologiae_cursus_completus_gr_vol_048)）の画像からギリシア語の本文を起こし、[research/pg48.txt](research/pg48.txt) に置いた。底本のラテン語訳、各巻の頭の内容一覧、校注は本文に入れていない。起こした章は、1 章 1 行のファイル（`<巻>.<章> <本文>`）にして、次のコマンドで節に分けた。

```sh
node tools/split-units.js <起こした章のファイル> books/chrysostom-on-the-priesthood/research/pg48.txt
```

巻（1〜6）と章の番号は底本に従う。第 2 巻の頭の、章の番号のない段落は、この訳で 0 章とした。章の中の節の番号は底本にはなく、この訳が文の切れ目で付けた。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは `research/cruxes/` にある。
