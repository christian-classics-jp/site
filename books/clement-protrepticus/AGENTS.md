# クレメンス『ギリシア人への勧め』の決まり

アレクサンドリアのクレメンスが、ギリシヤ人に偶像と秘儀を捨ててロゴスに聞くよう勧める書。同じ著者の『救われる富者とは誰か』（`books/who-is-the-rich-man/AGENTS.md`）の、底本の扱い、文体の型（γάρ、μὲν οὖν、ἀλλά、命令の訳し方など）、訳語を引き継ぐ。ギリシヤ人に向けた弁証の書として、読み手の呼び方、神々と詩人の扱い、名前の表記はタティアノス（`books/tatian-address-to-the-greeks/AGENTS.md`）、アテナゴラス（`books/athenagoras-plea/AGENTS.md`）、ユスティノス（`books/justin-first-apology/AGENTS.md`）の本にならう。そこにない決まりと、この本に固有の決まりだけをここに書く。食い違うときはこのファイルを優先する。

## 節の形

- 章（1〜12）、節（1〜123）、小節の番号は底本（Stählin 1905）に従う。節は章ごとではなく、本全体の通し番号（1 章が 1〜10 節、2 章が 11〜41 節…）。小節は節ごとに 1 から数える。ANF の英訳は章の番号だけを持つ。
- 底本テキストは `research/staehlin-1905.txt`。1 行 1 小節で `<章>.<節>.<小節> <本文>`（`2.11.1`）。
- 底本の 1 小節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `2:11:1 ` のように章・節・小節の番号で始める。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは、章全体のページなら `# 3 章　…`、章の一部のページなら `# 2 章 11〜18 節　…` の形（範囲、中身）。
- 底本の表題（ΚΛΗΜΕΝΤΟΣ ΣΤΡΩΜΑΤΕΩΣ ΠΡΟΤΡΕΠΤΙΚΟΣ ΠΡΟΣ ΕΛΛΗΝΑΣ）は電子化の `<head>` にあり、底本テキストには入れていない。表題は見出しに出さない（書名はサイトの題として README から出る。『救われる富者とは誰か』も同じ）。1 章の最初のページの見出しも、ほかのページと同じ形にする。

- 電子化は、底本の欄外の番号を行の頭に置いたため、節・小節の切れ目が文の途中にずれていることがある（『救われる富者とは誰か』と同じ）。**ページを訳す前に、そのページの範囲の節と小節の始まりを印刷版で確かめる。** djvu テキストの欄外の番号（`50,1` の形。別の行に流れていることがある）で見当をつけ、決めきれないところはページ画像（leaf ＝ ページ＋90。`research/sources.md`）で見る。ずれていれば、移す語句を `research/relabel.json` に `expect` 付きで足し、README の 2 行のコマンドで `research/staehlin-1905.txt` を作り直す。本文の文字は変えない。
- ページの境にあたる 11 か所（1.6、2.19、2.25、2.31、2.36、4.50、4.54、4.58、10.95、10.100、10.105）は、始めたときに印刷版の djvu テキストで節の始まりの行を確かめ、4 か所（4.50、4.58、10.95、10.105 の頭の語句）を前の小節に移した。ほかのページの節の頭は動かしてよいが、ページの境をまたいで語句を移さない。

- 欄外の番号の行に文の始まりが一つもないとき（3.44.4。行は ἀνοικοδομοῦσα, τοὺς δή — … で、3.44.3 の εἰκότως からの文が続いている）は、その行の中の最初の節の切れ目（読点の後。3.44.4 は関係の τοὺς δή）から始める。行の頭の語が前の小節の語と一続きの句（νεὼς ἀνοικοδομοῦσα）を作っているので、語句を割らないためである。訳の行は、後ろの小節も独立した文で始める。
- 11 章の初め（Μικρὸν δέ … εὐεργεσίαν.）は、電子化では 111 節の印の前にあるが、印刷版では 111.1 の行にある。`--running-sections` が章の初めの語句を最初の小節につなぐ。

## 底本の扱い

『救われる富者とは誰か』の「底本の扱い」に従う。この本で違うところと、足すところ：

- 底本の記号は、印刷版の写本表の後の説明（leaf 0092）による：⟨ ⟩ は推定で補った語、[ ] は取り除くべき挿入、* は欠け、† は確かには癒せない本文の崩れ、{ } は出どころの疑わしい語句、( ) は著者自身の挿入、»« は文字どおりの引用。異読の欄の < は「欠く」、+ は「足す」、∾ は「語順を替える」。{ } は電子化に残っていない。出てくるところは印刷版で確かめ、扱いを決めてここに書く。
- ⟨ ⟩ は電子化で落ち、補われた語が括弧なしで入っている。補いは訳に入れ、読者の理解が変わる補いだけ、写本にないことをメモに書く。
- [ ] の語は訳さず、メモに書く（1.3.1 の [Ὀρφεὺς] など）。
- 写本の欠け（6.72.2 のクレアンテスの詩の中と、11.112.3 の `*`）は語を補わず、それとわかる形で訳し、訳注で欠けを示す（『救われる富者とは誰か』の欠けの決まり）。
- † の付いた語句（2.11.2、10.99.2）は、底本の読みのまま意味の通る範囲で訳し、本文が崩れていることを訳注で示す。編者たちの改めの案は論点一覧に残す。
- 底本の »…« は、聖書・詩人・哲学者などの書かれたものの文字どおりの引用で、『』に入れる。
- 推定した人の書き分けは『救われる富者とは誰か』と同じ（「底本の編者の推定」「ある刊本の編者の推定で、底本もこれを採る」「ある学者の推定で、底本もこれを採る」）。
- 底本の異読の欄の略号は、同じ leaf 0092 の表による。写本は P（Paris. graec. 451。P¹ は写字生バアネス、P² はアレタスの手）と M（Mut. III. D. 7）。エウセビオス『福音の準備』の写本は A・B・H・I・O。刊本と学者は Di（Dindorf）、He（Heinsius）、Kl（Klotz）、Ma（Mayor）、Po（Potter）、Schw（Schwartz）、St（Stählin）、Sy（Sylburg）、Vi（Victorius）、Wi（Wilamowitz）。

## 文体

- ギリシヤ人に向けた勧めの言葉なので、地の文は敬体（「〜です」「〜ます」）。タティアノスの演説、アテナゴラスの弁明、同じ著者の『救われる富者とは誰か』と同じ。書き手のクレメンスは「わたし」、キリスト者全体は「わたしたち」。
- 読み手（ὑμεῖς。ギリシヤ人）は「あなたがた」。2 人称単数（σοι、εἰ βούλει など）は「あなた」。複数から単数へ途中で移るところも、移ったまま「あなた」にする（タティアノスと同じ）。尊敬語は使わない。
- 呼びかけ：ὦ Ἕλληνες は「ギリシヤの人々よ」、ὦ ἄνθρωποι は「人々よ」、ὦ ἄνθρωπε は「人よ」（テオフィロスと同じ）。ὦ σοφώτατοι τῶν ἄλλων ζῴων ἄνθρωποι は「ほかの生き物のうちで最も賢い人々よ」（3.43.1）。3.43.4 の物語の人物への呼びかけは「ソロンよ」「クロスよ」「クロイソスよ」で、その人への 2 人称は「あなた」。クロイソスへの ὦ βάρβαρε は「異民族の人よ」。ὦ φίλοι は「友よ」、ὦ φωνή は「声よ」（1.9.1）。ὦ Ὅμηρε・Ὅμηρε は「ホメロスよ」、ホメロスに向けた ἄνθρωπε も「人よ」で、ホメロスへの 2 人称は「あなた」（2.33.1〜2.33.2）。ὦ Πανέλληνες は「全ギリシヤの人々よ」（2.34.1）。ὦ δείλαιοι は「哀れな人々よ」（2.39.1）。ヘシオドスへの ὦ Βοιώτιε は「ボイオティアの人ヘシオドスよ」（2.30.1 のピンダロスも「ボイオティアの人」なので名を補い、メモに書く）、Ἀσκραῖε は「アスクラの人よ」で、ヘシオドスへの 2 人称は「あなた」（2.41.1〜2.41.2）。ヒッポンへの εὖ γε, Ἵππων は「見事です、ヒッポンよ」で、2 人称は「あなた」（4.55.1）。ὦ μάταιοι καὶ κενόφρονες は「むなしく、愚かな人々よ」（4.56.4）。ほかの呼びかけは初出で決めてここに書く。
- 神、キリスト（ロゴス、主、救い主）の動作は尊敬語にする。連体修飾や従属節の中の動詞も、最後の動詞まで同じ（1.6.2「お受けになる益」、1.10.1「お解きになるため」）。受け身と紛れる「〜られる」（勧められる、語られる）は、「お〜になる」「〜ておられる」にする（1.8.1、1.8.3）。
- ギリシヤの神々・悪霊・英雄・哲学者・詩人・秘儀の祭司には尊敬語を使わない。哲学者や詩人の説として述べる神にも使わない。クレメンスが真の神を指していると受け止めて引くところ（6 章、7 章の哲学者と詩人の言葉）は、引用の中は尊敬語にせず、クレメンス自身の地の文で受けるときだけ尊敬語にする。
- 皮肉と嘲りの強いところ（2 章、4 章）は、言い切る強さを保ち、やわらげる言葉を足さない。修辞疑問は「〜でしょうか」「〜ではありませんか」「〜のですか」で終え、「？」は使わない。地の文の短い言い切りも敬体で結ぶ（4.56.5「パロスの石は美しいものです」）。
- 詩人やシビュラの引用の中の 2 人称は「おまえ（たち）」。「あなた（がた）」はクレメンスの読み手にだけ使う（テオフィロスと同じ）。クレメンスが詩人の句を借りて人に問うところ（1.9.1 のホメロスの句でヨハネに問う）も「おまえ」。ただし、ロゴスや神が人に語りかける言葉の引用（1.5.3 の『あなたはわたしにとって、竪琴であり…』）は、口語訳の神の言葉に合わせて「あなた」。
- 1 章の「わたしのエウノモス」「わたしの歌い手」はキリストなので、動作を尊敬語にする（「歌っておられる」「来られた」。受け身と紛れる「歌われる」は避ける）。「新しい歌」「天の歌」が主語の文は、たとえの言葉として尊敬語にしない（1.4.3、1.4.4、1.5.1、1.5.2）。ロゴス、主が主語に戻ったら尊敬語にする（1.5.3、1.5.4）。
- 1.1.1 の ὃ μὲν … ὃ δέ のように、指すものを取り違えやすい代名詞の対は、名を出して訳す。クレメンスが名を伏せ、引用の落ちで明かす対（2.24.3〜2.24.4 の「ある人は」「別の人は」。後者はディアゴラス）は、取り違えのおそれがないので名を出さず、メモに書く。人の集団の対 οἳ μὲν … οἳ δέ も、直前に二つの集団が出ていれば名を出し、「A は〜。一方、B は〜」で受ける（3.42.8 の悪霊たちと迷信深い者たち）。一つの集団を分けるだけなら「その一部は…別の一部は」（2.39.9）。
- γάρ、γοῦν、μὲν οὖν、否定の後の ἀλλά、命令、一文の短さは、『救われる富者とは誰か』の「文体」の型に従う。
- 禁止（μή＋命令法、μή＋アオリスト接続法）は、読み手に言うときも、詩人に呼びかけるときも「〜てはなりません」（『救われる富者とは誰か』と同じ。2.37.4「嘆いてはなりません」、2.41.1「言うのを惜しんではなりません」）。「〜ないでください」は使わない。
- 3 人称の命令は、物や抽象（真理、預言の声）が主語なら「〜てもらいましょう」、人に向けたものなら「〜しなさい」（2.29.4「やめずにいなさい」、2.30.5「進み出なさい」）。「〜ますように」は希求法の願いにだけ使う（1.2.3、1.4.2）。3 人称の禁止（μή＋3 人称命令法）は、物や抽象が主語でも主語を変えず「A が〜してはなりません」とし、「A に〜させてはなりません」と使役にしない（4.57.6）。
- 名詞を説明する分詞は、連体の形か別の文にする。「〜ていると」のような時の条件にしない（1.4.3）。分詞や ὡς＋分詞（理由づけ）には「〜からです」を付けず、連体の形か「〜として」にする（2.19.4、2.24.1）。受け身の分詞の対（2.22.6 の σιωπωμένη／λαλουμένη）は態を揃える。連体の分詞を別の文にするときは平叙で言い切り、原文にない修辞疑問にしない（2.28.4）。-τικός ＋属格の形容詞は能動の連体で訳す（2.26.6 の εἰσηγητικὸς ἀπάτης「欺きを持ち込む」）。φαίνομαι＋分詞は「〜していることが明らかだ」、φαίνομαι＋不定詞は「〜ように見える」（2.38.1）。主動詞に添う分詞は、問いの文を分けるときも新しい問いにせず、平叙で言い切る（3.44.1 の νομοθετοῦντες、4.56.4 の ἀναπλάττοντες）。理由づけの分詞を別の文にするときは「〜と考えてのことです」の形にする（4.53.1 の νομίζων）。分詞の中の場所や手段の句は、文を分けても、かかる動詞と同じ文に置く（3.42.9 の ἐπὶ βωμοῖς ἢ ἐν ὁδοῖς は「屠る」にかかる）。
- 人を神に祭り上げる言い方（θεὸν τεθείακεν τὸν ἐρώμενον）は、祭られる人を目的語にし、「〜を…神として祭り上げる」とする。「神を神に」と重ねない（4.49.1）。受け身の τεθείασται も「神として祭り上げられた」（4.51.3）。ἐπιμορφάζω＋対格は「〜を装う」（4.47.1 の「その像に向かって敬虔を装い」）。
- 冠詞の付いた ὁ αὐτός は「同じ」（2.36.2「同じパニュアッシス」）、冠詞の前の αὐτὸς ὁ は「〜その人」。τάσσω ἐπί＋属格は「〜をつかさどる者に任じる」で、場所の「上に据える」にしない（2.39.3）。καί が主語にかかるか目的語にかかるかを確かめてから「も」「まで」を置く（2.36.2「ヘラクレスまでもが」。4.54.5 の καὶ αὐτόν は「デメトリオスも」）。冠詞のない数の語が冠詞付きの名詞句の後にあるときは、副詞「〜度目に」と読めないか確かめる（4.53.2 の δεύτερον は「二度目に」で、πολλάκις「何度も」と対）。
- 理由の διά（διά＋対格）は「〜のゆえ」、目的の ἵνα は「〜ため」で分ける（1.5.3、1.9.2、1.9.5、4.52.5 の δι᾿ αἰσχροκέρδειαν「利をむさぼる心のゆえに」、4.53.5、4.55.4 の διὰ Σαρπηδόνα「サルペドンのゆえに」）。目的の χάριν＋属格は「〜のために」（4.52.6 の κέρδους χάριν）。διά＋属格は「〜によって」「〜を通して」。理由の ὅτι は「〜のですから」にし、「〜からです」は γάρ にとっておく（1.6.4、1.7.3）。κατά ＋名詞は「〜に従って」（1.5.2）。ἕπομαι τῷ λόγῳ は「ロゴスについて行く」で、κατά の「従って」と紛れさせない（1.4.3）。資料の書き手に ἕπομαι するときは「〜にならって」（3.45.3 の「ゼノンにならって」）。
- 文を分けるときに足す接続の語（「それなのに」など）は、原文の対比の向きを変えないか確かめる。δὲ ἄρα が前の文と対比するところは「一方、」（1.2.1）。禁止（μή、μηδέ）の後の δέ は「そうではなく、」（2.11.1）。τὰ μὲν … τὰ δέ の対比（τοὺς μὲν ἄθλους … τὰς δὲ θυγατέρας のように名詞が付く形も）は「〜は。一方、〜は」で受け、「も」は καί にとっておく（2.27.3〜2.27.4、2.33.4、4.50.2〜4.50.3 の τὸν μὲν … τὸν δέ）。新しい話題へ進む γάρ は「からです」で結ばず「実際、」（2.17.2）。条件文の中の γάρ（εἰ γάρ、εἰ γὰρ οὖν）は「実際、」にせず、帰結を「〜からです」で結ぶ（2.40.1）。物語を始める γάρ は「こういう話です。」（2.19.4、2.20.1）。挿入句の中の γάρ も落とさず、括弧の中を「〜から（です）」で結ぶ（2.20.3、2.24.2、4.56.4 の「もう一度繰り返して言いますから」）。
- 神話を語る歴史的現在は、一つの節の中で現在形を通す。アオリストの分詞と挿入句だけを過去にしてよい。未完了過去やアオリストの主動詞も、その節では現在形に揃える（2.16.1、2.18.2、2.34.3〜2.34.4、4.48.5〜4.48.6 のサラピスの像の造り方）。
- クレメンスが音から説く語源や言葉遊び（2.13.1 のオルギアとオルゲ、2.13.2 のミュテリア、2.14.2 のメデア、2.18.1 のパラスとパレイン、2.38.5 のケリュティスとケリュッテイン、2.39.6 のミュルメクスとミュルミドン、2.39.7 のスミントイとスミンティオス、2.41.4 のヘミテオイとヘミオノイ）は、本文の訳語の後に（　）で片仮名の音を添え、仕組みをメモに書く。メモはビルドで消えるので、仕組みが本文だけで伝わるようにする（2.41.4 は「半分ろばの騾馬」）。
- 神々の呼び名（ἐπίκλησις）は、意味の分かるものは意味で訳す（2.37.1 の「客人を守る神」、2.38.3〜2.39.2 の「首吊りのアルテミス」「蠅払いのゼウス」「はげ頭のゼウス」など）。意味を資料で確かめていないもの（Κονδυλῖτις、Περιβασώ、χοιροψάλας）は原語の音で書き（主格の形）、メモに書く。論の筋にかかわらない掛けことば（2.11.2 の占いと狂い、2.18.1 の「役に立たない」）は、日本語で響く範囲で訳し、メモに書く。

## 引用

- 聖書の文言どおりの引用は『』に入れて本文に出典を置く。口語訳の語を借りた言い換えも本文に出典を置く。語や考えを思わせるだけの暗示は `// ` メモに書く。
- 詩人・哲学者・神託・シビュラの文言の直接の引用は『』に入れ、出典は `// ` メモに書く（タティアノス、アテナゴラス、テオフィロスと同じ）。
- 詩の引用は、底本テキストの 1 行の中に流し込まれているので、行ごとに分けず、散文に組んで一続きの『』に入れる（アテナゴラス 5:18、テオフィロス 2:3:2 と同じ）。詩の形容語は落とさず、同じ語根の語は同じ訳にする（2.29.3 の κρατερός・κρατερῷ は「強い」「強い縛め」）。『』の範囲は、印刷版が詩として組む範囲に合わせ、詩句の頭の人称の語（3.45.5 の ἐμοὶ μέν「わたしには」）も『』の中に入れる。
- メモの出典は、古典作品を漢数字と中黒で書く（『イリアス』二・二〇四、『オデュッセイア』一一・三〇三）。底本の古典の欄の箇所を使い、別の数え方の番号を足すときは、どの資料の番号かを書く。確かめていない番号は書かない。
- 引用の中の引用は『』の中でも『』に入れる（『救われる富者とは誰か』と同じ）。
- 口語訳どおりに引くところは、口語訳の表記のまま（「救主」「起す」。1.4.2、1.4.4）。口語訳が訳していない γάρ も、論のつながりを担うときは「からである」を足す（1.4.2、1.4.4）。訳語を本の中で揃えるために口語訳の語を替えるときは、メモに理由を書く（1.4.4 の φιλανθρωπία「人を愛する心」）。口語訳の文言のまま 60 字を超える引用は切らない。
- 七十人訳による引用や、クレメンスがいくつかの箇所を合わせた引用で、口語訳と意味が違うところは底本の文言に従い、メモに「口語訳はヘブル語からの訳で、「…」。七十人訳（または底本）に従って〜とした。」と書く（『第一弁明』と同じ）。名の順などが口語訳と違うときも底本に従い、メモに書く。
- 聖書自身がキリストを言う λόγος（ヨハネ一・一）は、引用の中でも「ロゴス」（口語訳の「言」は借りず、メモに書く）。聖書では「言葉」の意味で、クレメンスがそれをロゴスと受けるところ（1.2.3 のイザヤ二・三「主の言葉」）は、引用の中は口語訳のまま、地の文で「ロゴス」と言い換え、メモに書く。

## 名前の表
