# 16-chapter-08 の電子化と印刷版の照合（8.77–8.81）

照合した印刷版：O. Stählin 編、*Clemens Alexandrinus* I（GCS 12、Leipzig: Hinrichs, 1905）、pp. 59–62（OCR `cache/archive.org/clemensalexandri01clemuoft/clemensalexandri01clemuoft_djvu.txt` l. 8424〜8634、画像 0149〜0152）

画像は `cache/archive.org/clemensalexandri01clemuoft/pages/` のもの。第 8 章は p. 59 の 8 行目（0149）から始まり、8.81.4 は p. 62 の 6 行目（0152）で終わる。0148（p. 58）と 0153（p. 63）には該当する本文がない。OCR の similarity は 0.82。候補 118 件を一つずつ確かめ、底本を通読した。本文はページの上下半分の画像（0149〜0151 の pct:5,4,90,46 と pct:5,48,90,50、0152_pct:5,4,90,46.jpg）で語を追い、紛らわしい箇所は帯状の画像で確かめた。印刷版の補いのしるし（⟨ ⟩）が電子化で落ちていること（8.77.1 θεῖαι ⟨, εἰ⟩、8.78.3 ⟨ὁ⟩ προφήτης、8.81.4 ⟨αἱ⟩ δυνάμεις）は底本の既知の性質なので、ここには挙げない。8.77.1 θεῖαι の後の「 ,」の空きも、この補いから来ている。

候補のうち、次のものは OCR の誤りで、印刷版は電子化と同じ。8.77.2 ᾀσάτω（OCR の ἀσάτω は誤り）、καθ᾿ ἓν（印刷版も重アクセントの ἓν）。8.78.2 αὖ（OCR の αὐ は誤り）、ὄρη（OCR の θρὴ は誤り）、λήψεται.«。8.79.2 Μωυσέως、Ὠσηέ、λέγειν »ἰδού（印刷版に句点はない）。8.79.3 θεοῖς οἳ οὐ（0150_pct:55,65.5,40,3.jpg。気息と重アクセントの関係代名詞 οἳ で、OCR の οἱ は誤り）。8.79.4 πρός με、ἄλλος·。8.79.5 εἰκόνα ἐποίησεν（OCR の点は汚れ）。8.80.2 ἄοκνος ᾖς（0151_pct:35,33,30,3.jpg。下書きのイオタのある接続法 ᾖς で、OCR の ἧς は誤り）。8.80.3 ἥ ἐστιν。8.80.5 Δαβίδ·（印刷版は中点で、OCR の ; は誤り）。8.81.1 ῥυθμόν、ψεῦδος;«。8.81.3 ὅ γε。OCR の章番号 VII. は印刷版では VIII.。OCR だけにある |、数字、ὃ・δ΄ などは節番号や行番号、丁の切れ目のしるし（66 P・67 P・68 P・23 S・24 S）のくずれ。
