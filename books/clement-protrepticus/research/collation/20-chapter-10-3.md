# 20-chapter-10-3 の電子化と印刷版の照合（10.100–10.104）

照合した印刷版：O. Stählin 編、*Clemens Alexandrinus* I（GCS 12、Leipzig: Hinrichs, 1905）、pp. 72–75（OCR `cache/archive.org/clemensalexandri01clemuoft/clemensalexandri01clemuoft_djvu.txt` l. 9330〜9570、画像 0162〜0165）

画像は `cache/archive.org/clemensalexandri01clemuoft/pages/` のもの。10.100.1 は p. 72 の 17 行目（0162）から始まり、10.104.4 は p. 75 の 11 行目（0165）で終わる。OCR の similarity は 0.82。候補 85 件を一つずつ確かめ、底本を通読した。本文はページの上下半分の画像（0162・0163・0164 の pct:5,4,90,46 と pct:5,48,90,50、0165_pct:5,4,90,46.jpg）で語を追い、紛らわしい箇所は帯状の画像で確かめた。印刷版の補いのしるし（⟨ ⟩）が電子化で落ちていること（10.101.2 ταύτας ⟨τὰς⟩ κενὰς、10.102.1 ⟨αὐτὸν⟩ τὸν Ἑρμῆν、10.102.4 ἔτι τε ⟨εἰ⟩）は底本の既知の性質なので、ここには挙げない。10.100.2 と 10.101.1 の [καὶ] の角括弧は印刷版のもの。10.102.3 οὐδε εἱμαρμένην のアクセントの欠けは印刷版のまま（0163_pct:5,48,90,50.jpg）で、別の語にはならない。

候補のうち、次のものは OCR の誤りで、印刷版は電子化と同じ。10.100.1 ἀνέλθω、»ὁδός«、»στενὴ«。10.100.3 οὖν。10.100.4 πλεῖθι ὁ（OCR の ὃ は誤り）。10.101.1 καθάπερ、αὑτοὺς は印刷版も気息が粗い（0163_pct:78,16.5,17,2.jpg）。10.101.2 ταύτας ⟨τὰς⟩（OCR の { は ⟨ のくずれ）。10.102.1 ἦ παντί τῳ（OCR の 7、τῷ は誤り）、ὡς。10.102.2 εὔθυναν。10.102.4 γεγενημένοι; ὁ δὲ（OCR の : ὃ は誤り）、διᾴσσοντες、πάθος。10.103.1 ὅτι（OCR の ὅτε は誤り）、ὁ μόνος（OCR の ὃ は誤り）、μανδραγόραν ἤ。10.103.3 ὁ κύριος と ὃ ἐγὼ（OCR は ὁ と ὃ を取り違えている）、μεταλάμβανε·。10.103.4 ἦ γὰρ οὐχ ᾗ Νιόβη（OCR の ἢ、ἡ は誤り。0164_pct:50,52,20,2.5.jpg、0164_pct:50,52.5,20,3.jpg）、Λὼτ、ἐρᾶν·。10.104.1 ξύλα、ὄρνεα、ὄφεις、μή·。10.104.4 ἣ（OCR は行番号 10 と読んでいる）。そのほかの κ/χ、ζ/ξ などの文字の読み違いも OCR の誤り。OCR だけにある |、数字、記号は節番号や行番号、丁の切れ目のしるし（80 P〜82 P・29 S）のくずれ、または apparatus と、10.100.1 の前・10.104.4 の後の行。10.100.2 βέλτιστον | οὐχ、10.102.1 Τύχωνα | Ἑρμῆν、10.102.4 ἔρις | καὶ、10.103.2 τῆς | συνηθείας のしるしは語の間にある。
