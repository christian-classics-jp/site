- 10.95.2 の終わりの βούλεσθε … σύμβουλος; を 10.95.3 の頭へ。欄外の番号の行（p. 70 の 3 行）は βούλεσθε で始まり、行の中の ἀλλ᾿ も文の始まりだが、本の決まり（6.72.2、行の頭が文の始まりなら行の頭から）に従った。問いは続く「では、あなたがたは聞きなさい」と組になる。
- 10.95.4 の終わりの πιστεύσατε ἡμῖν … σωφρονήσητε· を 10.96.1 の頭へ（9.83.2 の型）。

- 10.98.1 の頭の ἠλίθιοι … προσκυνηταί. を 10.97.3 へ（ソフォクレスの句に続く呼びかけ）。
- 10.98.3 は候補が二つ（τίς ἀθανασίαν と μόνος）なので動かさなかった。

`relabel.json` の expect は、電子化の文字（オクシア付きの母音など）に合わせて底本テキストから写した。

論点一覧がメインの判断に委ねたものは次のように決めた。
- 10.97.1 の Χῖον（推定）に訳注を付けた（「写本は『キヨスの』ではなく『神のような』と読む。」）。人物の出身が推定から生まれ、写本では皮肉の呼び名になるので、10.89.2 と同じ型にした。
- 10.99.2 の † には、本の決まりどおり訳注を付けた（「この句は本文が崩れていて、確かには読めない。」）。κατασκευασθεῖσα は底本の読みのまま「仕組まれ」とし、ほかの案はメモに書いた。
- 10.98.1 の出どころの分からない預言には訳注を付けず、メモに書いた。クレメンスが「ある預言」と名を伏せているので、読者が聖書の言葉と取り違えない（9.87.4 は使徒の言葉として引かれていたので訳注を付けた）。
- 10.97.2 のプラトン『テアイテトス』の文は、印刷版に »« がないので『』に入れず、メモに書いた。
- 10.98.3 の εἰκών の連鎖は、通して「かたち」とした（「かたちのかたち」）。訳語表の「神のかたち」と揃い、ἄγαλμα「像」と分けられる。10.98.2 の職人の作る ἔμπνουν εἰκόνα は「息の通う像」。
- τοῦ πονηροῦ は 10.92.2 と同じく「悪い者」。νόμος ἀληθείας λόγος κυρίου の λόγος は「主がその口で語られた」を受けるので「言葉」。10.96.1 の πίστις は「証し」。ὕδωρ λογικόν は訳語表どおり「理にかなった水」。ἀντικαταλλάσσομαι は 10.95.1 と 10.99.4 で「〜と引き換えに…を得る」に揃えた。
- 10.99.4 の引用は、マタイの「天国」とルカの「あなたがた」を合わせた形で『天国はあなたがたのものである』とした。
