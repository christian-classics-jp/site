- 10.107.1 の頭の σωτηρίαν·、10.108.1 の頭の ἐσχάτης … λελυτρωμένοι.、10.109.1 の頭の μεμοίχευκας.«、10.110.1 の頭の γενόμενοι ἀπέρριψαν. を前の小節へ。10.107.1 は行の中に文の始まりが二つ（εὗρες と ζητήσωμεν）あり、電子化の位置に最も近い εὗρες から始めた（10.101.1 と同じ）。
- 10.107.1 の終わりの ταύτας … χρὴ τῇ を 10.107.2 の頭へ（9.83.2 の型。τῇ ψυχῇ を割らない）。

`relabel.json` の expect は、電子化の文字（オクシア付きの母音）に合わせて底本テキストから写した。

論点一覧がメインの判断に委ねたものは次のように決めた。
- 10.105.3 の χρηστός（写本は χριστός）に訳注を付けた（「写本は『善良な人は』を『キリストは』と読む。」）。異読の欄（p. 75 の 20 行、OCR l. 9620）は自分でも確かめた。句がだれのことを言うのかが変わるので、読者の理解が変わる箇所とみた。χρηστός は 10.108.2 と揃えて「善良な」とし、ἀγαθός の「善い」「良い」と分けた。
- 10.105.2 の ἀπαιδευσία（推定。写本は「子のないこと」）は訳注にせず、メモに書いた。並びの一項が変わるだけで、論の筋は変わらない。
- 10.105.4 の θυμός は、七十人訳と底本に従って「怒り」とし、口語訳の「毒」をメモに書いた。
- 10.106.1 の λόγος は「ロゴス」とし、「言葉」とも読めることをメモに書いた（1 章のまじないの歌と同じ見方）。
- 10.106.2 の »τὴν ὁδὸν τῆς ἀληθείας« は、口語訳第二ペテロ二・二に同じ語があるので、本文に出典を置いた。
- 10.107.2 の θείας γραφάς は、前の小節の義・愛・恥じらい・柔和を指すので、訳語表の「書物」を使わず「書きつけ」とし、メモに書いた。
- 10.107.3 の τῷ πατρί は「父なる神」（「神」を補い、メモに書いた）、τὸν υἱόν は「御子」。
- 10.108.4 の ὁ μὲν οὖν … ἑπέσθω は譲歩の μὲν οὖν なので、『救われる富者とは誰か』の決まり（26:8）どおり「従うとしましょう」。
- 10.108.5 の οὐ παιδοφθορήσεις は、『十二使徒の教え』の本の訳に揃えて「少年を汚してはならない」とし、十戒にないことをメモに書いた。νόμοι は 10.108.4 の「法」「立法者」を受けるので「法」。
- 10.109.1 の αὐστηρόν・αὐστηρία は、どちらも「厳しさ」で揃えた。
- 10.109.2 の γυναικωνῖτις は、『若者を育てる』真理の比喩を家に広げたものと取り、「女たちの部屋」とした（レビューの指摘で「真理の住む」を補った）。
- 10.110.2 の »ὁ λόγος ἦν ἐν τῷ θεῷ« は、底本の文言どおり「神のうちに」とし、口語訳の「神と共に」をメモに書いた。劇場の比喩は言葉を足さずに訳した。
