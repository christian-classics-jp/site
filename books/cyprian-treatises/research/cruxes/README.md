# 校訂上の論点

『キプリアヌス小品集』（『ドナトゥスへ』『カトリック教会の一致について』『背教者について』『主の祈りについて』）の本文で、写本・刊本の読みが分かれる箇所、編者の推定や削除が訳に響く箇所、構文や語義の取り方が分かれる箇所、聖書や古典の引用・暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（Hartel 1868 の本文、`../hartel-1868-<作品>.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。節の番号はこの訳で付けたもの（本の `AGENTS.md`）で、各項の見出しのラベルは底本テキストの行頭のラベル（章.節）。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は底本の OCR テキスト（`cache/archive.org/sthascicaecilic00hartgoog/sthascicaecilic00hartgoog_djvu.txt`）の行番号。OCR は本文・聖書の箇所の行・校注を混ぜて並べ、u を a と読むなど崩れるので、校注はページ画像で読み、OCR の行番号はおよその位置として添える。

- 底本（Hartel）：W. Hartel 編、CSEL 3.1（1868）。各ページの上が本文（左に 5 行ごとの行番号、右の欄外に章番号）、その下に聖書の箇所の行、その下に校注。校注の数字はそのページの本文の行番号で、ページごとに 1 に戻る。各論点では「p. 4 の校注 10」のように、ページと行番号で挙げる。
- 画像：IIIF の番号＝印刷ページ＋10。archive.org の幅 1600 のページ画像（`cache/archive.org/sthascicaecilic00hartgoog/page/nN_w1600.jpg`。N は IIIF の番号と同じ）と、IIIF で切り出したもの（`cache/archive.org/sthascicaecilic00hartgoog/pages/`）。
- 校注の言い回し：「om.」は欠くこと、「add.」は加えること、「m. 2」は後の手（写本の訂正者）、「s. l.」は行の上に書かれていること、「ex corr.」「ex … m. 2」は訂正の結果、「eras.」「in ras.」は削った跡、「coni.」「coniecit」は推定、「scripsi」は Hartel 自身の推定（本文では斜体で刷る。『ドナトゥスへ』5.2 の de Deo）、「uocem uncis inclusi」は、その語を角括弧に入れたこと（削るべき語とみたこと。2.2 の [contione]）。P¹・P² のような肩の数字は、写本の最初の手と後の手を分けるものとみられる（序文で確かめていない）。

## 『ドナトゥスへ』の略号

『ドナトゥスへ』の略号は、作品の前のページ（p. 2、画像 `page/n12_w1600.jpg`、OCR l. 120–147）の表で確かめた。

- S：もとセギエの写本、今のパリ写本 10592（Suppl. Lat. 712）、6〜7 世紀。初めが失われ、8 章の numquam temporibus から始まる。したがって 1〜7 章の校注には出ない。
- W：ヴュルツブルクの写本（theolog. 145）、8〜9 世紀（7 世紀とする人もいる、と Hartel は言う）。
- P：パリ写本 1647 A、10 世紀。
- M：ミュンヘン写本 208、9〜10 世紀。作品の初めを二つの写しで伝えるので、Hartel は最初の写しを M₁、もう一つを M₂ と呼ぶ。M₁ は 4.2 の reparauit で終わり、M₂ の前にはドナトゥスからキプリアヌスへの偽の短い手紙が置かれている（p. 6 の校注 6）。
- B：バンベルク写本 476、11 世紀。
- V：ヴェローナの写本、7 世紀（？）。失われた写本で、Hartel は、Manutius の版の一冊に書き込まれたゲッティンゲンの照合と、刊本の編者の注からその読みを写した。
- v：刊本（全部あるいはいくつか）。r：ローマの初版（1471 年）。Oxon.：オックスフォード版（1682 年）。
- Hartel は、SWPMB の異読はすべて校注に載せたが、V は資料に記されたものしか載せられず、M と B は 1〜7 章の校訂にだけ使った、と言う（p. 2）。ただし校注は 8.4 まで M と B を挙げる（最後は p. 10 の校注 9、8.4 の iusque への legem M）。それより後は S、W、P と刊本だけで、M・B の読みが記されていないことは底本との一致を意味しない。
- 校注に名で出る推定・注釈者：Latinius、Rigaltius、Pamelius、Baluzius、Goulartius、Gronovius（『考察』4 巻）、N. Faber、Morellius、Erasmus。Augustinus の『説教』312 は 3〜4 章を引用しており、Hartel はその読みも挙げる（p. 5・6 の校注）。6〜10 章の校注には、Felix Oefelius（Krabinger の報告による推定。8.2）、Gronovius の『スタティウス「シルウァエ」についての論考』（Hand の版、7.1）、Halm の『オクタウィウス』への注（8.4）、Baluzius（10.1）が出る。10.6 に出るベネヴェントの写本（cod. Beneuentanus）は p. 2 の略号の表にない。
