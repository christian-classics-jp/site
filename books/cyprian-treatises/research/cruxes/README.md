# 校訂上の論点

『キプリアヌス小品集』（『ドナトゥスへ』『カトリック教会の一致について』『背教者について』『主の祈りについて』）の本文で、写本・刊本の読みが分かれる箇所、編者の推定や削除が訳に響く箇所、構文や語義の取り方が分かれる箇所、聖書や古典の引用・暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（Hartel 1868 の本文、`../hartel-1868-<作品>.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。節の番号はこの訳で付けたもの（本の `AGENTS.md`）で、各項の見出しのラベルは底本テキストの行頭のラベル（章.節）。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は底本の OCR テキスト（`cache/archive.org/sthascicaecilic00hartgoog/sthascicaecilic00hartgoog_djvu.txt`）の行番号。OCR は本文・聖書の箇所の行・校注を混ぜて並べ、u を a と読むなど崩れるので、校注はページ画像で読み、OCR の行番号はおよその位置として添える。

- 底本（Hartel）：W. Hartel 編、CSEL 3.1（1868）。各ページの上が本文（左に 5 行ごとの行番号、右の欄外に章番号）、その下に聖書の箇所の行、その下に校注。校注の数字はそのページの本文の行番号で、ページごとに 1 に戻る。各論点では「p. 4 の校注 10」のように、ページと行番号で挙げる。
- 画像：IIIF の番号＝印刷ページ＋10。archive.org の幅 1600 のページ画像（`cache/archive.org/sthascicaecilic00hartgoog/page/nN_w1600.jpg`。N は IIIF の番号と同じ）と、IIIF で切り出したもの（`cache/archive.org/sthascicaecilic00hartgoog/pages/`）。
- 校注の言い回し：「om.」は欠くこと、「add.」は加えること、「m. 2」は後の手（写本の訂正者）、「s. l.」は行の上に書かれていること、「ex corr.」「ex … m. 2」は訂正の結果、「eras.」「in ras.」は削った跡、「coni.」「coniecit」は推定、「scripsi」は Hartel 自身の推定（本文では斜体で刷る。『ドナトゥスへ』5.2 の de Deo）、「uocem uncis inclusi」は、その語を角括弧に入れたこと（削るべき語とみたこと。2.2 の [contione]）。「sup. scr.」は上に書き足されていること、「super … : …」は、その語の上に後の手が別の語を書いていること、「fort. recte」は Hartel が「おそらく正しい」とみる読み（本文には採らない。『一致について』9.4 の incussione）、「cf. p. …」は Hartel が比べる箇所。P¹・P² のような肩の数字は、写本の最初の手と後の手を分けるものとみられる（序文で確かめていない）。

## 『ドナトゥスへ』の略号

『ドナトゥスへ』の略号は、作品の前のページ（p. 2、画像 `page/n12_w1600.jpg`、OCR l. 120–147）の表で確かめた。

- S：もとセギエの写本、今のパリ写本 10592（Suppl. Lat. 712）、6〜7 世紀。初めが失われ、8 章の numquam temporibus から始まる。したがって 1〜7 章の校注には出ない。
- W：ヴュルツブルクの写本（theolog. 145）、8〜9 世紀（7 世紀とする人もいる、と Hartel は言う）。
- P：パリ写本 1647 A、10 世紀。
- M：ミュンヘン写本 208、9〜10 世紀。作品の初めを二つの写しで伝えるので、Hartel は最初の写しを M₁、もう一つを M₂ と呼ぶ。M₁ は 4.2 の reparauit で終わり、M₂ の前にはドナトゥスからキプリアヌスへの偽の短い手紙が置かれている（p. 6 の校注 6）。
- B：バンベルク写本 476、11 世紀。
- V：ヴェローナの写本、7 世紀（？）。失われた写本で、Hartel は、Manutius の版の一冊に書き込まれたゲッティンゲンの照合と、刊本の編者の注からその読みを写した。
- v：刊本（全部あるいはいくつか）。r：ローマの初版（1471 年）。Oxon.：オックスフォード版（1682 年）。
- Hartel は、SWPMB の異読はすべて校注に載せたが、V は資料に記されたものしか載せられず、M と B は 1〜7 章の校訂にだけ使った、と言う（p. 2）。ただし校注は 8.4 まで M と B を挙げる（最後は p. 10 の校注 9、8.4 の iusque への legem M）。それより後は S、W、P と刊本だけで、M・B の読みが記されていないことは底本との一致を意味しない。
- 校注に名で出る推定・注釈者：Latinius、Rigaltius、Pamelius、Baluzius、Goulartius、Gronovius（『考察』4 巻）、N. Faber、Morellius、Erasmus。Augustinus の『説教』312 は 3〜4 章を引用しており、Hartel はその読みも挙げる（p. 5・6 の校注）。6〜10 章の校注には、Felix Oefelius（Krabinger の報告による推定。8.2）、Gronovius の『スタティウス「シルウァエ」についての論考』（Hand の版、7.1）、Halm の『オクタウィウス』への注（8.4）、Baluzius（10.1）が出る。10.6 に出るベネヴェントの写本（cod. Beneuentanus）は p. 2 の略号の表にない。11〜16 章の校注には、Gronovius（「l. c.」で pp. 264、321、579。7.1 と同じ『スタティウス「シルウァエ」についての論考』p. 513 も 16.2 に）、Krabinger（11.4）、Erasmus（11.4）、Rigaltius（12.2）、Morellius（14.3）、N. Faber（16.1）が出る。Hartel は古典とキプリアヌス自身の並行も挙げる（12.2 のウェルギリウス『農耕詩』2.506、プリニウス『博物誌』33.5・『書簡』9.30、『背教者について』12 章。13.3 の『処女の装いについて』21 章。14.1 の『デメトリアヌスへ』1 章。14.3 のテルトゥリアヌス『ヘルモゲネス反駁』1 章など）。V は 15.4 に一度だけ出る。

## 『カトリック教会の一致について』の略号

作品の前のページ（p. 208、画像 `page/n218_w1600.jpg`、OCR l. 9900–9910）の表で確かめた。『ドナトゥスへ』と略号が違い、P と B はない。表が年代を記すのは R と G だけ。

- S：セギエの写本（codex Seguierianus）。表には「1〜5 章と 17 章の断片を持つ」とある。p. 214 の校注 12 によれば、5.3 の separatur で終わり（fol. 34 b）、損なわれた fol. 35 に 17 章の断片だけが残る。したがって 5.3 の nec unitas corporis separatur より後の校注には出ない。
- W：ヴュルツブルクの写本。
- R：レギナ写本 lat. 116、9 世紀。
- G：ザンクト・ガレン写本 89、9 世紀。
- M：ミュンヘンの写本。4 章で、首位権の本文の長い一節を、公認の本文の前に重ねて持つ（04-de-unitate-01-06 の 4.3〜4.6 の項）。
- V：ヴェローナの写本。校注は「V teste Rigaltio」（Rigaltius の報告による V）のように、刊本の編者の報告で読みを挙げることがある。
- v：刊本。この作品の表には刊本の略号がないが、校注は『ドナトゥスへ』と同じく v を使い、名を挙げるときは Manutius（4.3 の unam cathedram constituit）、Pamelius（4.6 の付加）、Baluzius（2.1 の uiuentis、3.4 の unitatis、4.6 の quem）と書く。
- 肩の数字（M¹・M²、R¹・R²、G¹・G²、W¹・W²）は、『ドナトゥスへ』の M₁・M₂（二つの写し）と違い、すべて肩に刷られている。写本の最初の手と後の手を分けるものとみられる（序文で確かめていない）。
- OCR は R を B、G を O や 0 と読むことが多い（l. 10088 の `SW0VB` は画像では SWGVR）。略号は必ず画像で読む。
