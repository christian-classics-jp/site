# エルサレムのキュリロス『秘義教話』

エルサレムのキュリロスの『秘義教話』（Κατηχήσεις μυσταγωγικαί、5 講）のギリシア語原文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は J.-P. Migne 編、*Patrologiae cursus completus, series Graeca* 33（Paris: J.-P. Migne）の欄 1065〜1126。A. A. Touttée 編の Benedictine 版（Paris, 1720）の本文を再録したもの。パブリックドメイン。archive.org のスキャン（[patrologiae_cursus_completus_gr_vol_033](https://archive.org/details/patrologiae_cursus_completus_gr_vol_033)）の画像からギリシア語の本文を起こし、[research/pg33.txt](research/pg33.txt) に置いた。底本のラテン語訳は使っていない。底本の校注によれば、写本の中には、この 5 講を後継の監督ヨアンネスの名で伝えるものがある。

講（第 1〜5 講）と節の番号は底本に従う。各講の題の下にある、主題と聖書の朗読の箇所を示す一文には番号がなく、この訳で 0 節とした。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは `research/cruxes/` にある。
