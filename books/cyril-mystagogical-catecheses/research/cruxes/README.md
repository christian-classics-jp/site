# 校訂上の論点

エルサレムのキュリロス『秘義教話』の本文で、写本・刊本の読みが分かれる箇所と、聖書の引用と暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（PG 33、`../pg33.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。底本テキストと印刷版の食い違い（電子化の誤り）と、印刷版の誤植は照合で扱い、ここには書かない。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は、ことわりがなければ印刷版の OCR（`cache/archive.org/patrologiae_cursus_completus_gr_vol_033/patrologiae_cursus_completus_gr_vol_033_djvu.txt`）の行番号。OCR は校注のラテン語をギリシア文字に化けさせ、写本の略号もよく崩すので、校注はページ画像（`cache/archive.org/patrologiae_cursus_completus_gr_vol_033/page/nN_w1600.jpg`）で読む。画像の切り出しは `node tools/image.js crop <画像> pct:x,y,w,h <出力先>` で行い、`/tmp` に置いただけ。各項には、元の画像と切り出した領域を書く。

## 底本の印刷版の形

- 底本：J.-P. Migne 編、Patrologia Graeca 33 の欄 1065〜1126（本文はベネディクト会版〔Touttée 編、1720〕と同じ。本の AGENTS.md による）。各ページの上半分にギリシア語の本文とラテン語訳の欄が並び、その下に聖書の箇所の行、校注が続く。
- 本文の中の `(2)` のような番号が校注の番号。番号はページ（画像 1 枚、欄 2 つ）ごとに (1) から振り直す。そのため、論点では校注を「n540 の注 (3)」のように画像の番号と合わせて呼ぶ。
- 校注の番号は、ギリシア語の本文だけでなく、ラテン語訳の欄や題にも付く。n539 の注 (3)（ラテン語の題 CATECHETICAE ORATIONES QUINQUE）、n540 の注 (1)（1.3 のラテン語訳 Jesu Christi sanguis）、n542 の注 (1)（1.7 のラテン語訳 Quemadmodum panis et vinum）は、写本の読みではなく本文の解釈についての注。
- 聖書の箇所は、ラテン語訳の欄に付けた上付きの番号（¹⁸ など）で示し、ギリシア語とラテン語の欄の下の 1〜2 行に並べる。番号は第 1 講で ¹⁸ から ³⁸ まで、第 2 講で ³⁹ から ⁵⁹ まで、第 3 講で ⁶⁰ から ⁹⁶ まで続く（ページで振り直さない）。第 4 講は ⁹⁷〜⁹⁹ の後、n555 の 4.2 の ¹ から振り直し、n558 の ²² まで続く。第 5 講は n561 の ²³（5.0）から続き、n571 の ⁵⁴（5.23 の第一テサロニケ五・二三）で終わる（画像では 2 と 3 の字形が紛れやすいので、前後の番号の並びで読む）。詩篇と出エジプト記は、ウルガタの節の番号で書くことがある（n556 の ⁸ Psal. cxv, 13 は七十人訳の詩篇一一五・四、口語訳の一一六・一三。n557 の ¹³ Exod. xxviii, 36 は Swete の二八・三二）。ヨハネ六章も同じとみられる（n556 の ⁶ Joan. vi, 54 はヨハネ六・五三 に当たる）。番号はふつう該当する語の後に付くが、句読点の後、次の文の頭に付くもの（n546 の ⁴⁶〜⁴⁸、⁵⁰、n547 の ⁵²、⁵³）もある。Vid. cat. … の形で、ほかの教話の箇所を示すだけのものもある。各講の題の前には、編者の前書き（MONITUM）があり、講の内容と儀式についての注釈を載せる。聖句の直接の引用と儀式の定式はイタリックで刷る（本の AGENTS.md）。
- 下の行の箇所には誤りがある。n543 の ²⁷ Gen. xiv, 15 seqq. は、ロトの話なので創世記一九・一五以下。n543 の ²⁸ Tob. iv, 13 は、Swete の節の番号ではトビト四・一二。n548 の ⁵⁹ Rom. v, 5 は、2.8 の ἐν καινότητι ζωῆς περιπατεῖν なのでローマ六・四。詩篇は七十人訳の番号（n541 の ²³ Psal. cxviii, 37 は口語訳の詩篇一一九・三七）。n551 の ⁶⁸（3.1 のイザヤ六一・一）は、画像では Isai. LXII. と読め、節の番号がない。
- 校注は、写本の読みのほか、刊本の読み、校訂者の推測（n540 の注 (4) の ὁμόσε など）、本文の解釈、教父の並行箇所にも触れる。 番号に星印の付いた「(2*)」の注（n569）は「Lege, ὁλοκλήρου. EDIT.」と、本文の読みを直すよう求める。EDIT. の付く注は、写本の異読ではなく Migne 版の編者の訂正とみられる。

## 写本・刊本の略号（校注の書き方のまま）

校注に略号表はない。ここでは校注に出る名前を、校注が言うことと、英訳の序が言うことだけで説明する。

- Coisl.（Coislin.、Coislinianus）：Coislin の写本。n540 の注 (5) は「ambobus Coisl.」（二つの Coislin の写本）と書く。ほかの注は番号を付けずに Coisl. とだけ書く。
- Ottob.（Ottobonianus）：Ottoboni の写本。2 本ある。n539 の注 (4) は「Ottob. duobus」と書き、そのうち「primo」（1 本目）に語がないと言う。Ottob. 2 と番号を付ける注もある（n539 の注 (5)、n542 の注 (5)）。
- Roe：Roe の写本（本の AGENTS.md ではボドリアン図書館の写本）。
- Casaub.（Casaubon.）：Casaubon が異読を書き留めた写本。
- Genovef.（Genov.）：サント＝ジュヌヴィエーヴ図書館の本。英訳の序（`cache/ccel.org/npnf207.txt` l. 4648〜4650）によれば、Morel の刊本の一冊で、欄外にほかの二つの写本の異読を書き込んだもの。n542 の注 (6) は「Vetus Genov.」と書く。本の AGENTS.md の写本の一覧にはない。
- Scirlet.（Scirletianus）：Scirlet. の写本。第 3 講の前書き（n549 の ADMONITIO III）によれば、第 3 講の小さな断片だけが残り、Stanislaus Hosius が堅信の秘跡を論じるところで引いている。n551 の注 (3) によれば、その断片は 3.3 の ὥσπερ γάρ から ἐνεργητικὸν γινόμενον まで。第 4 講の前書き（n554 の PRAELOQUIUM III）によれば、第 4 講は Hosius が Petrikau の教会会議の信仰告白の弁護（39 章）でこの写本から全文を載せており、第 4 講では全文の証人になる（Scirl.、Scirlet. apud Hosium とも書く）。
- Περὶ θείων μυστηρίων（De divinis mysteriis）：王立図書館写本 2428 の、刊行されていない小冊子。n554 の PRAELOQUIUM III によれば、祭壇の供え物が真実にではなく型と象徴においてキリストのからだと血だと言う人々に反対して書かれたらしく、教父の証言を集めたもので、8 世紀より後の著者を引かない。第 4 講と第 5 講の断片を引く（n557 の注 (1)、n558 の注 (3)、(4)、n568 の注 (3)、n570 の注 (6)）。編者は、引用が自由で写本も崩れていると言う。
- 第 5 講の証人：第 5 講の前の編者の前書き（n561 の上半分の VIII）によれば、Coisl. は第 5 講の題だけを最後のページに載せ、本文を欠く。第 5 講の題の下の一文（5.0）は、すべての写本になく、編者が作ったもの。編者は第 5 講を、写本のほか、次の三つの引用と比べた。
  - Nicon（Nicon monachus）：修道士ニコンの、刊行されていない『パンデクテス』（王立図書館写本 1994）。n566 の注 (5) によれば、328 葉で 5.9 の後半と 5.10 をキュリロスの名で引く。
  - Eustratius：エウストラティオスの、死者のための祈りについての書（6 世紀の半ばの後、コンスタンティノポリスの総主教エウテュキオスのもとで書かれた。アラティウスが『煉獄について』で刊行）。n566 の注 (4) によれば、5.9〜5.10 をキュリロスの名で引く。
  - Περὶ θείων μυστηρίων（上を参照）。
- Ottob. 1：Ottob. の 1 本目。第 4 講の校注（n557 の注 (4)、n558 の注 (5)、n559 の注 (1)）は Ottob. 1 と Ottob. 2 を分けて挙げる。
- Albertinus：校注が論敵として名を挙げる人。n568 の注 (3)、n570 の注 (5)、(6) によれば、5.15 のパンを聖餐と取ることを疑い、5.20 の ἀντιτύπου から異論を引き、『神の秘義について』の自由な引用を論拠に、これらの教話が改ざんされたと論じた。
- Dositheus：エルサレムの総主教ドシテオス。n570 の注 (5) によれば、『エンケイリディオン』46 頁で 5.20 を引き、ἀντιτύπων（複数）と読む。
- Grod.（Grodecius）：Grodecius のラテン語訳。校注はこれを一つの証人として写本と並べる（「quod legit vel supposuit Grod.」n540 の注 (2)）。
- Prevot（Prevotius）：Prevot のラテン語訳。n545 の注 (2) は、Morel の刊本、Ottob. と並べて証人に挙げる。
- sac. text.（sacer textus）：聖書の本文。n548 の注 (2) は、引用の読みを決める証人の一つに挙げる。
- Morel、Milles（Millesius）、editi：刊本。editi はそれまでの刊本。n539 の注 (4) によれば、Milles は Roe の写本から ἐπιστάμην を採った。
- Anastasius Sinaita：シナイのアナスタシオス（またはその名で伝わる『問答』の著者）。n543 の注 (1)、(3) は、1.8 の一部を引用する証人として挙げる。
- 英訳の脚注は、ここにない「Cod. Mon. 1」の読みを挙げる（1.8 の πειρασθήσῃ）。英訳の序（l. 4714〜4734）は、Reischl と Rupp のミュンヘン版（1848、1860）を最良の校訂版と呼ぶ。英訳の脚注の読みが PG の本文と校注にないときは、この版から来ている可能性がある（確かめていない）。第 4 講の脚注 [2448] は、ほかにも Monac. 1、2、Vindob.、Vatt.、Mesm.（Morel とする）の名を挙げ、Rupp の読みにも触れる。
