# 第 3 講　塗油

3:0 塗油について。朗読は、ヨハネの第一の公同の手紙から。『あなたがたは神から油を注がれているので、すべてのことを知っている』（第一ヨハネ二・二〇）から。『その来臨に際して、わたしたちがみまえに恥じいることがない』（第一ヨハネ二・二八）まで。
3:1 キリストにあずかる洗礼を受け、キリストを着たあなたがたは、神の御子と同じかたちになりました。神は、わたしたちを子とされることへとあらかじめ定め、キリストの栄光のからだと同じかたちにしてくださったからです。こうしてキリストにあずかる者となったのですから、あなたがたが油を注がれた者（キリスト）と呼ばれるのは当然です。神も、あなたがたについて、こうお語りになりました。『わが油そそがれた者たちにさわってはならない』（詩篇一〇五・一五）。あなたがたが油を注がれた者となったのは、聖霊の写しを受けたからです。あなたがたには、すべてのことが姿として行われました。あなたがたはキリストの姿だからです。キリストは、ヨルダン川で身を洗い、ご自分の神性の香りを水に分け与えて、水から上がられました。すると、聖霊が実体をもってキリストの上に降られました。似た方が、似た方の上にとどまられたのです。あなたがたにも同じように、聖なる水の池から上がったとき、塗油が与えられました。キリストに注がれたものの写しです。キリストに注がれたもの、それは聖霊です。幸いなイザヤも、その預言の中で、主の口を借りて、この聖霊についてこう言いました。『主の霊がわたしに臨んだ。主がわたしに油を注がれたからである。主は、貧しい者に福音を宣べ伝えるために、わたしをつかわされた』（イザヤ六一・一）。
3:2 キリストは、人の手で、からだに塗る油や香油を注がれたのではないからです。父が、キリストを全世界の救い主としてお立てになり、聖霊によって油を注がれたのです。ペテロが言うとおりです。『神が聖霊によって油を注がれた、ナザレのイエス』（使徒一〇・三八）。預言者ダビデも、声をあげて言いました。『神よ、あなたの御座は世々限りなく続き、あなたの支配のつえは公平のつえである。あなたは義を愛し、不義を憎まれた。それゆえに、神、あなたの神は、喜びの油を、あなたのともがらにまさって、あなたに注がれた』（詩篇四五・六〜七）。キリストは、本当に十字架につけられ、葬られ、よみがえられました。そしてあなたがたは、洗礼のとき、様において、キリストと共に十字架につけられ、共に葬られ、共によみがえります。そうするのにふさわしい者とされるのです。それと同じことが、塗油についても言えます。キリストは、目に見えない喜びの油を注がれました。つまり、聖霊です。聖霊は喜びの油と呼ばれます。霊的な喜びをもたらす方だからです。一方、あなたがたは、香油を塗られました。キリストと交わる者、キリストにあずかる者となったのです。
3:3 しかし、その香油を、ただの香油だと思ってはいけません。聖餐のパンは、聖霊への呼び求めの後には、もうただのパンではなく、キリストのからだです。それと同じように、この聖なる香油も、呼び求めの後には、もうただの香油ではありません。いわば、ありふれたものでもありません。キリストの賜物となり、その神性の臨在によって、聖霊を働かせるものとなるのです。この香油は、象徴として、額に、また、あなたの感覚の器官に塗られます。目に見える香油によってからだが塗られ、聖なる、いのちを与える聖霊によって、魂が聖なるものとされるのです。
3:4 まず、あなたがたは額に塗られました。最初の違反者である人が、どこへ行っても身に負っていた恥から、解き放たれるためです。また、顔おおいなしに、主の栄光を鏡に映すように見るためです。次に、耳に塗られました。神の秘義を聞く耳を受けるためです。この耳について、イザヤはこう言いました。『主はわたしに、聞く耳を加えてくださった』（イザヤ五〇・四）。主イエスも、福音書の中でこう言われました。『耳のある者は聞くがよい』（マタイ一一・一五）。次に、鼻に塗られました。神の香油を感じ取って、こう言うためです。『わたしたちは、救われる者にとって、神に対するキリストのかおりである』（第二コリント二・一五）。その後、胸に塗られました。正義の胸当を着けて、悪魔の策略に対抗して立つためです。キリストは、洗礼を受け、聖霊が降られた後で、出て行って、敵対する者を打ち負かされました。それと同じように、あなたがたも、聖なる洗礼と秘義の塗油の後で、聖霊の武具を身に着けています。そして、敵対する力に対抗して立ちます。こう言って、その力を打ち負かすのです。『わたしを強くしてくださるキリストによって、何事でもすることができる』（ピリピ四・一三）。
3:5 この聖なる塗油にふさわしい者とされたあなたがたは、キリスト者と呼ばれます。新しく生まれたことによって、その名をも真実なものとしているのです。この恵みにふさわしい者とされる前には、あなたがたは、本来、この呼び名にふさわしくありませんでした。キリスト者となることへと、道を進んでいる途中だったのです。
3:6 また、あなたがたは知っておかなければなりません。この塗油の象徴は、旧約の聖書にあるのです。モーセは、神の命令を兄弟に伝え、彼を大祭司に立てたとき、彼が水で身を洗った後で、油を注ぎました。すると、彼は油を注がれた者（キリスト）と呼ばれました。もちろん、型としての塗油によってです。同じように、大祭司も、ソロモンを王に立てるとき、ソロモンがギホンで身を洗った後で、油を注ぎました。しかし、こうしたことは、彼らには型として起こりました。あなたがたには、型としてではなく、真実に起こったのです。あなたがたは、聖霊によって、本当に油を塗られたからです。あなたがたの救いの初めはキリストです。キリストは本当に初穂であり、あなたがたはそのかたまりだからです。初穂が聖なるものであれば、その聖さがかたまりにも移ることは明らかです。
3:7 この塗油を、しみのないまま守りなさい。それがあなたがたのうちにとどまるなら、すべてのことを教えてくれるでしょう。いま聞いたとおりです。幸いなヨハネがそう言い、この塗油について多くのことを深く語っていました。この聖なるものは、からだを守る霊的な守りであり、魂を救うものなのです。幸いなイザヤは、遠い昔に、これについて預言して、こう言いました。『主は、この山で、すべての国民のために設けられる。彼らはぶどう酒を飲み、喜びを飲み、香油を塗る』^[旧約のギリシア語訳による。日本語の聖書に香油の句はない。]（イザヤ二五・六〜七）。イザヤは、ほかのところでも、教会を山と呼んでいます。たとえば、『終りの日に、主の山ははっきりと現れる』（イザヤ二・二）と言うときです。また、あなたが確信できるように、この香油を秘義のものとして語るイザヤの言葉を聞きなさい。『これらすべてを国民に渡せ。主の計画は、すべての国民に向けられているからである』^[これもギリシア語訳による。日本語の聖書にこの命令はない。]（イザヤ二五・七）。ですから、この聖なる香油を塗られたあなたがたは、それを、しみもきずもないまま、自分のうちに守りなさい。良い行いによって進歩し、あなたがたの救いの君であるキリスト・イエスに喜ばれる者となりなさい。栄光が世々限りなく、キリストにありますように。アーメン。
