# 70〜73 章　ミトラスの秘儀、削られた聖句

70.1 Ὅταν δὲ οἱ τὰ τοῦ Μίθρου μυστήρια παραδιδόντες λέγωσιν ἐκ πέτρας γεγεννῆσθαι αὐτόν, καὶ σπήλαιον καλῶσι τὸν τόπον ἔνθα μυεῖν τοὺς πειθομένους αὐτῷ παραδιδοῦσιν, ἐνταῦθα οὐχὶ τὸ εἰρημένον ὑπο Δανιήλ. ὅτι Λίθος ἄνευ χειρῶν ἐτμήθη ἐξ ὄρους μεγάλου, μεμιμῆσθαι αὐτοὺς ἐπίσταμαι, καὶ τὰ ὑπὸ Ἡσαίου ὁμοίως, οὗ καὶ τοὺς λόγους πάντας μιμήσασθαι ἐπεχείρησαν; Δικαιοπραξίας γὰρ λόγους καὶ παρ᾿ ἐκείνοις λέγεσθαι ἐτεχνάσαντο.
70:1 「また、ミトラスの秘儀を伝える者たちは、ミトラスが岩から生まれたと言います。そして、ミトラスに従う者たちを入信させると伝える場所を、洞穴と呼びます。そのとき、わたしは次のことを知らずにいられるでしょうか。彼らは、ダニエルによって言われた言葉をまねたのです。『一つの石が、人手によらずに、大きな山から切り出された』（ダニエル二・三四参照）という言葉です。また、イザヤの言葉も同じようにまねたのです（イザヤ三三・一六参照）。彼らは、そのイザヤの言葉を、すべてまねようと企てました。実際、彼らは、義を行うことについての言葉も、あの者たちのあいだで語られるように仕組んだのです」
// 「ミトラス」は『第一弁明』66:4 と同じ。ミトラスの秘儀は洞穴で行われた（『第一弁明』66:4 のメモ）。後の章で、キリストの生まれた洞穴について同じ論が出る。
// 「大きな山から」は、ダニエル二・三四の「切り出された」に、二・三五の「大きな山」を合わせた形。口語訳の二・三四には「山から」がない（二・四五にはある）。底本に従った。
// 底本は、ある刊本の編者の直した「イザヤの言葉も同じように」を採る。写本は「同じようにこれらのことを行ったと」と読み、続く「そのイザヤの」に当たる語の指す人がいなくなる。
// 「洞穴」は、70:2 で引くイザヤ三三・一六の「岩の高い洞穴」に当たる（底本の注）。「あの者たち」は、ミトラスの秘儀にあずかる者たちのこと。
70.2 Τοὺς δὲ εἰρημένους λόγους τοῦ Ἡσαΐου ἀναγκαίως ἀνιστορήσω ὑμῖν, ὅπως ἐξ αὐτῶν γνῶτε ταῦθ᾿ οὕτως ἔχειν. Εἰσὶ δὲ οὗτοι· Ἀκούσατε, οἱ πόρρωθεν, ἃ ἐποίησα· γνώσονται οἱ ἐγγίζοντες τὴν ἰσχύν μου. Ἀπέστησαν οἱ ἐν Σιὼν ἄνομοι· λήψεται τρόμος τοὺς ἀσεβεῖς. Τίς ἀναγγελεῖ ὑμῖν τὸν τόπον τὸν αἰώνιον; Πορευόμενος ἐν δικαιοσύνῃ, λαλῶν εὐθεῖαν ὁδόν, μισῶν ἀνομίαν καὶ ἀδικίαν, καὶ τὰς χεῖρας ἀφωσιωμένος ἀπὸ δώρων, βαρύνων ὦτα ἵνα μὴ ἀκούσῃ κρίσιν ἄδικον αἵματος, καμμύων τοὺς ὀφθαλμοὺς ἵνα μὴ ἴδῃ ἀδικίαν· οὗτος οἰκήσει ἐν ὑψηλῷ σπηλαίῳ πέτρας ἰσχυρᾶς.
70:2 「イザヤの語った言葉を、どうしても、あなたがたに詳しく述べておきます。そこから、これがそのとおりであることを、あなたがたが知るためです。その言葉は、次のとおりです。『遠くにいる者たちよ、わたしがおこなったことを聞け。近づく者たちは、わたしの力を知る。シオンにいる不法の者たちは離れ去った。おののきが、神を敬わない者たちを捕える。だれが、あなたがたに永遠の場所を告げるのか。義のうちに歩む者、まっすぐな道を語る者、不法と不義とを憎む者、贈り物から手を清く保つ者。耳をふさいで、血の不正な裁きを聞かない者、目を閉じて、不義を見ない者。その人は、堅い岩の高い洞穴に住む」
// 三三・一三の口語訳は「あなたがた近くにいる者よ、わが大能を知れ」（命令）。七十人訳に従って「近づく者たちは、わたしの力を知る」とした。「聞け」は底本に従った（七十人訳は「聞く」）。
// 三三・一四の口語訳は「シオンの罪びとは恐れに満たされ、おののきは神を恐れない者を捕えた。「われわれのうち、だれが焼きつくす火の中におることができよう」」と続く。七十人訳に従って「シオンにいる不法の者たちは離れ去った」「だれが、あなたがたに永遠の場所を告げるのか」とした。七十人訳はこの問いの前に「火が燃えていることを、だれがあなたがたに告げるのか」を持つが、底本に従って入れなかった（似た問いが続くので、写すときに落ちたとみられる）。
// 三三・一五の口語訳は「正しく歩む者、正直に語る者、しえたげて得た利をいやしめる者、手を振って、まいないを取らない者、耳をふさいで血を流す謀略を聞かない者、目を閉じて悪を見ない者」。七十人訳に従って「義のうちに歩む者、まっすぐな道を語る者、不法と不義とを憎む者」「血の裁き」「不義を見ない者」とした。「手を清く保つ」と「不正な（裁き）」は底本に従った（七十人訳は「手を振り払う」、「血の裁き」）。
// 三三・一六の口語訳は「このような人は高い所に住み、堅い岩はそのとりでとなり」。七十人訳に従って「堅い岩の高い洞穴に住む」とした。この「洞穴」が、70:1 のミトラスの洞穴の論の根拠。
70.3 Ἄρτος δοθήσεται αὐτῷ, καὶ τὸ ὕδωρ αὐτοῦ πιστόν. Βασιλέα μετὰ δόξης ὄψεσθε, καὶ οἱ ὀφθαλμοὶ ὑμῶν ὄψονται πόρρωθεν. Ἡ ψυχὴ ὑμῶν μελετήσει φόβον κυρίου. Ποῦ ἔστιν ὁ γραμματικός; Ποῦ εἰσιν οἱ βουλεύοντες; Ποῦ ἔστιν ὁ ἀριθμῶν τοὺς τρεφομένους, μικρὸν καὶ μέγαν λαόν; Ὧι οὐ συνεβουλεύσαντο, οὐδὲ ᾔδεισαν βάθη φωνῶν, ὥστε μὴ ἀκοῦσαι· λαὸς πεφαυλισμένος, καὶ οὐκ ἔστι τῷ ἀκούοντι σύνεσις.
70:3 「パンは彼に与えられ、その水は確かである。あなたがたは、栄光のうちにある王を見る。あなたがたの目は、遠くから見る。あなたがたの魂は、主への恐れを思い巡らす。文字に通じた者はどこにいるのか。計りごとをする者たちはどこにいるのか。養われている者たち、小さい民と大きい民とを数える者はどこにいるのか。彼らは、その民と共に計らず、声の深みを知らなかった。そのため、聞くことがなかった。それはさげすまれた民で、聞く者には悟りがない』（イザヤ三三・一三〜一九）」
// 三三・一六の後半の口語訳は「そのパンは与えられ、その水は絶えることがない」。七十人訳に従って「その水は確かである」とした。
// 三三・一七の口語訳は「あなたの目は麗しく飾った王を見、遠く広い国を見る」。七十人訳に従って「あなたがたは、栄光のうちにある王を見る」とした。七十人訳の後半は「あなたがたの目は遠くの地を見る」で、底本に従って「地」を入れなかった（底本の注は、ユスティノスが「見る」を王に掛けて読んだとみる）。
// 三三・一八の口語訳は「あなたの心はかの恐ろしかった事を思い出す。「数を調べた者はどこにいるか。みつぎを量った者はどこにいるか。やぐらを数えた者はどこにいるか」」。七十人訳に従って「恐れを思い巡らす」「計りごとをする者たち」「養われている者たち、小さい民と大きい民とを数える者」とした。「あなたがたの（魂）」「主への（恐れ）」「文字に通じた者」（一人）は底本に従った（七十人訳は「われわれの」、「恐れ」だけ、「文字に通じた者たち」）。「主への恐れ」と「文字に通じた者」は、70:5 の論の根拠。
// 三三・一九の口語訳は「あなたはもはや高慢な民を見ない。かの民の言葉はあいまいで、聞きとりがたく、その舌はどもって、悟りがたい」。七十人訳に従って訳した。「彼らは…共に計らず、声の深みを知らなかった」は底本に従った（七十人訳は「彼は…共に計らず、深い声の民を知らなかった」）。
70.4 Ὅτι μὲν οὖν καὶ λέγει ἐν ταύτῃ τῇ προφητείᾳ περὶ τοῦ ἄρτου, ὅν παρέδωκεν ἡμῖν ὁ ἡμέτερος Χριστὸς ποιεῖν εἰς ἀνάμνησιν τοῦ σεσωματοποιῆσθαι αὐτὸν διὰ τοὺς πιστεύοντας εἰς αὐτόν, δι᾿ οὓς καὶ παθητὸς γέγονε, καὶ περὶ τοῦ ποτηρίου, ὃ εἰς ἀνάμνησιν τοῦ αἵματος αὐτοῦ παρέδωκεν εὐχαριστοῦντας ποιεῖν, φαίνεται. Καὶ ὅτι βασιλέα τοῦτον αὐτὸν μετὰ δόξης ὀψόμεθα. αὕτη ἡ προφητεία δηλοῖ.
70:4 「では、この預言の中で、パンについても語っていることは、明らかです。わたしたちのキリストが、わたしたちに、行うようお伝えになったパンです。そのかたが、ご自分を信じる人々のために体をとられたことを、記念するためです。そのかたは、その人々のために、苦しみを受けるかたともなられました。また、杯についても語っています。そのかたが、ご自分の血を記念して、感謝をささげつつ行うようお伝えになった杯です。そして、まさにこのかたを、わたしたちが栄光のうちにある王として見ることも、この預言は明らかにしています」
// パンと杯を記念として行うことは、41:1 と『第一弁明』66:3 にもある。70:3 の「パン」と「水」を、聖餐のパンと杯に当てている。ミトラスの秘儀のパンと水の杯は『第一弁明』66:4 にある。
70.5 Καὶ ὅτι λαός, ὁ εἰς αὐτὸν πιστεύειν προεγνωσμένος, μελετήσειν φόβον κυρίου προέγνωστο, αὗται αἱ λέξεις τῆς προφητείας βοῶσι. Καὶ ὅτι οἱ τὰ γράμματα τῶν γραφῶν ἐπίστασθαι λογιζόμενοι, καὶ ἀκούοντες τῶν προφητειῶν, οὐκ ἔχουσι σύνεσιν, ὁμοίως αὗται αἱ γραφαὶ κεκράγασιν. Ὅταν δέ, ὦ Τρύφων, ἔφην, ἐκ παρθένου γεγεννῆσθαι τὸν Περσέα ἀκούσω, καὶ τοῦτο μιμήσασθαι τὸν πλάνον ὄφιν συνίημι.
70:5 「また、このかたを信じると前もって知られていた民が、主への恐れを思い巡らすことも、前もって知られていました。この預言の文言は、そのことを叫んでいます。また、聖書の文字に通じていると思っている者たちは、預言を聞いても悟りを持ちません。同じように、この聖書の言葉は、そのことも叫んでいます。また、トリュフォンよ、ペルセウスはおとめから生まれたと言われます。それを聞くとき、わたしは、惑わす蛇がこのこともまねたのだと悟ります」とわたしは言った。
// 「惑わす蛇」は悪魔のこと（39:6、45:4、『第一弁明』28:1）。ペルセウスの話は 67:2 でトリュフォンが持ち出した。

71.1 Ἀλλ᾿ οὐχὶ τοῖς διδασκάλοις ὑμῶν πείθομαι, μὴ συντεθειμένοις καλῶς ἐξηγεῖσθαι τὰ ὑπὸ τῶν παρὰ Πτολεμαίῳ τῷ Αἰγυπτίων γενομένῳ βασιλεῖ ἑβδομήκοντα πρεσβυτέρων, ἀλλ᾿ αὐτοὶ ἐξηγεῖσθαι πειρῶνται.
71:1 「しかし、わたしは、あなたがたの教師たちには従いません。その教師たちは、エジプト人の王プトレマイオスのもとにいた七十人の長老たちの訳したものを、正しく訳されていると認めません。そして、自分たちで訳してみようとしています」
// 「訳す」と訳した語は、68:7 の「訳」と同じ語の動詞。
71.2 Καὶ ὅτι πολλὰς γραφὰς τέλεον περιεῖλον ἀπὸ τῶν ἐξηγήσεων τῶν γεγενημένων ὑπὸ τῶν παρὰ Πτολεμαίῳ γεγενημένων, πρεσβυτέρων, ἐξ ὧν διαρρήδην οὗτος αὐτὸς ὁ σταυρωθεὶς ὅτι θεὸς καὶ ἄνθρωπος καὶ σταυρούμενος καὶ ἀποθνήσκων κεκηρυγμένος ἀποδείκνυται, εἰδέναι ὑμᾶς βούλομαι· ἅς, ἐπειδὴ ἀρνεῖσθαι πάντας τοὺς ἀπὸ τοῦ γένους ὑμῶν ἐπίσταμαι, ταῖς τοιαύταις ζητήσεσιν οὐ προσβάλλω, ἀλλ᾿ ἐπὶ τὰς ἐκ τῶν ὁμολογουμένων ἔτι παρ᾿ ὑμῖν τὰς ζητήσεις ποιεῖν ἔρχομαι.
71:2 「また、彼らは、プトレマイオスのもとにいた長老たちの行った訳から、多くの聖句をすっかり取り除きました。そのことを、あなたがたに知ってほしいのです。それらの聖句は、十字架につけられたまさにこのかたについて、はっきりと示しています。このかたが、神であり人であり、十字架につけられ、死なれるかたであると、告げ知らされていたことです。しかし、あなたがたの民族の者がみな、それらの聖句を否定することを、わたしは知っています。ですから、そのような問いには取りかかりません。そうではなく、あなたがたのもとで今も認められている聖句から問うことに進みます」
71.3 Καὶ γὰρ ὅσας ὑμῖν ἀνήνεγκα ταύτας γνωριζετε, πλὴν ὅτι περὶ τῆς λέξεως, τῆς Ἰδοὺ ἡ παρθένος ἐν γαστρὶ λήψεται, ἀντείπατε, λέγοντες εἰρῆσθαι· Ἰδοὺ ἡ νεᾶνις ἐν γαστρὶ λήψεται. Καὶ ὑπεσχόμην ἀπόδειξιν ποιήσασθαι οὐκ εἰς Ἐζεκίαν, ὡς ἐδιδάχθητε, τὴν προφητείαν εἰρῆσθαι ἀλλ᾿ εἰς τοῦτον τὸν ἐμὸν Χριστόν· καὶ δὴ τὴν ἀπόδειξιν ποιήσομαι.
71:3 「実際、わたしがあなたがたに挙げた聖句は、どれも、あなたがたが認めているものです。ただし、『見よ、おとめがみごもる』という文言については、あなたがたは反論しました。『見よ、若い女がみごもる』と言われているのだ、と言ったのです（イザヤ七・一四）。そこで、わたしは、論証をすると約束しました。その預言は、あなたがたが教えられたようにヒゼキヤについてではなく、このわたしのキリストについて言われたのだ、と。では、いよいよ、その論証をしましょう」
// 「論証をすると約束しました」は、43:8 と 68:7〜68:8 を指す。イザヤ七・一四は 67:1 と同じ文言。
71.4 Καὶ ὁ Τρύφων εἶπε· Πρῶτον ἀξιοῦμεν εἰπεῖν σε ἡμῖν καί τινας ὧν λέγεις τέλεον παραγεγράφθαι γραφῶν.
71:4 トリュフォンは言った。「まず、あなたが言う、すっかり削られたという聖句のうち、いくつかを、わたしたちに言ってほしいのです」

72.1 Κἀγὼ εἶπον· Ὡς ὑμῖν φίλον, πράξω. Ἀπὸ μὲν οὖν τῶν ἐξηγήσεων, ὧν ἐξηγήσατο Ἔσδρας εἰς τὸν νόμον τὸν περὶ τοῦ πάσχα, τὴν ἐξήγησιν ταύτην ἀφείλοντο· Καὶ εἶπεν Ἔσδρας τῷ λαῷ· Τοῦτο τὸ πάσχα ὁ σωτὴρ ἡμῶν καὶ ἡ καταφυγὴ ἡμῶν. Καὶ ἐὰν διανοηθῆτε καὶ ἀναβῇ ὑμῶν ἐπὶ τὴν καρδίαν, ὅτι μέλλομεν αὐτὸν ταπεινοῦν ἐν σημείῳ, καὶ μετὰ ταῦτα ἐλπίσωμεν ἐπ᾿ αὐτόν, οὐ μὴ ἐρημωθῇ ὁ τόπος οὗτος εἰς τὸν ἅπαντα χρόνον, λέγει ὁ θεὸς τῶν δυνάμεων· ἂν δὲ μὴ πιστεύσητε αὐτῷ μηδὲ εἰσακούσητε τοῦ κηρύγματος αὐτοῦ. ἔσεσθε ἐπίχαρμα τοῖς ἔθνεσι.
72:1 わたしは言った。「お望みのとおりにしましょう。では、エズラが過越についての律法について行った解き明かしがあります。彼らは、その中から、次の解き明かしを取り去りました^[この言葉は、今の旧約のどの写本や古代訳にも見当たらない。]。『エズラは民に言った。「この過越は、われわれの救い主であり、われわれの逃れ場である。われわれは、このかたをしるしのうちに低くしようとしており、その後、このかたに望みを置く。あなたがたがこのことを悟り、心に思い浮かべるなら、この所は、いつまでも荒れ果てることがない、と万軍の神は言われる。しかし、あなたがたがこのかたを信じず、その宣べ伝えることに聞き従わないなら、異邦人の物笑いとなる」』」
// 「解き明かし」と訳した語は、71:1〜71:2 で「訳」と訳した語と同じ。ここでは、エズラが律法を解き明かした言葉を言う。
// ユスティノスはエズラの言葉として引くが、どの聖書の本文にもない。後の時代のラクタンティウスもラテン語で引く。第一コリント五・七をもとに、キリスト教徒が付けた注解とみる説がある（底本の注）。「この所」はエルサレム。「しるし」は、後の章で十字架を言うのと同じ語。
72.2 Καὶ ἀπὸ τῶν διὰ Ἱερεμίου λεχθέντων ταῦτα περιέκοψαν· Ἐγὼ ὡς ἀρνίον ἄκακον. φερόμενον τοῦ θύεσθαι. Ἐπ᾿ ἐμὲ ἐλογίζοντο λογισμόν, λέγοντες· Δεῦτε, ἐμβάλωμεν ξύλον εἰς τὸν ἄρτον αὐτοῦ καὶ ἐκτρίψωμεν αὐτὸν ἐκ γῆς ζώντων, καὶ τὸ ὄνομα αὐτοῦ οὐ μὴ μνησθῇ οὐκέτι.
72:2 「また、エレミヤを通して語られた言葉から、彼らは次の言葉を切り取りました。『わたしは、ほふられるために連れて行かれる、おとなしい小羊のようであった。彼らは、わたしに対して計りごとをめぐらして言った。「さあ、彼のパンに木を投げ入れよう。生ける者の地から彼を絶ち滅ぼそう。彼の名は、もはや思い出されることがない」』（エレミヤ一一・一九）」
// 口語訳エレミヤ一一・一九は「しかしわたしは、ほふられに行く、おとなしい小羊のようで、彼らがわたしを害しようと、計りごとをめぐらしているのを知らなかった。彼らは言う、「さあ、木とその実を共に滅ぼそう。生ける者の地から彼を絶って、その名を人に忘れさせよう」」。七十人訳に従って「彼のパンに木を投げ入れよう」とした。「知らなかった」がないこと、「計りごと」に「悪い」がないことは、底本に従った（七十人訳は「知らなかった」「悪い計りごと」）。
// この句は、今のエレミヤ書にもある。ユスティノス自身も、72:3 で、会堂の写本のいくつかにはまだあると言う。
72.3 Καὶ ἐπειδὴ αὕτη ή περικοπή, ἡ ἐκ τῶν λόγων τοῦ Ἱερεμίου, ἔτι ἐστὶν ἐγγεγραμμένη ἔν τισιν ἀντιγράφοις τῶν ἐν συναγωγαῖς Ἰουδαίων (πρὸ γὰρ ὀλίγου χρόνου ταῦτα ἐξέκοψαν), ἐπειδὰν καὶ ἐκ τούτων τῶν λόγων ἀποδεικνύηται ὅτι ἐβουλεύσαντο Ἰουδαῖοι περὶ αὐτοῦ τοῦ Χριστοῦ, ἀναιρεῖν αὐτὸν σταυρώσαντες βουλευσάμενοι, καὶ αὐτὸς μηνύεται, ὡς καὶ διὰ τοῦ Ἡσαΐου προεφητεύθη, ὡς πρόβατον ἐπὶ σφαγὴν ἀγόμενος, καὶ ἐνθάδε ὡς ἀρνίον ἄκακον δηλοῦται· ὥστ᾿ ἀπορούμενοι ἐπὶ τὸ βλασφημεῖν χωροῦσι.
72:3 「エレミヤの言葉から取ったこの一節は、ユダヤ人の会堂にある写本のいくつかには、今も書き記されています。実際、彼らがこれを切り取ったのは、少し前のことです。そこで、この言葉からも、次のことが示されるたびに、彼らは当惑して、冒涜することに走るのです。ユダヤ人が、まさにキリストについて計りごとをめぐらし、このかたを十字架につけて殺そうと決めたことです。また、イザヤを通しても預言されたように、このかたのことが『ほふり場に引かれて行く羊のように』と示されていることです（イザヤ五三・七参照）。そして、ここでも『おとなしい小羊のように』と明らかにされていることです」
// 「ほふり場に引かれて行く羊のように」は、13:5 のイザヤ五三・七と同じ言い方。
// 底本は、ある刊本の編者の直した「そのため」を採る。写本は「それらについて」の意味の語で、文がつながらない。
72.4 Καὶ ἀπὸ τῶν λόγων τοῦ αὐτοῦ Ἱερεμίου ὁμοίως ταῦτα περιέκοψαν· Ἐμνήσθη δὲ κύριος ὁ θεὸς ἅγιος Ἰσραὴλ τῶν νεκρῶν αὐτοῦ, τῶν κεκοιμημένων εἰς γῆν χώματος, καὶ κατέβη πρὸς αὐτοὺς εὐαγγελίσασθαι αὐτοῖς τὸ σωτήριον αὐτοῦ.
72:4 「また、同じエレミヤの言葉から、同じように次の言葉を切り取りました^[この言葉は、今のエレミヤ書には見当たらない。]。『主なる神、イスラエルの聖なるかたは、ご自分の死者たち、ちりの地に眠っている者たちを思い出された。そして、ご自分の救いを彼らに宣べ伝えるために、彼らのところに下られた』（第一ペテロ三・一九、四・六参照）」
// エイレナイオスも、この言葉をエレミヤやイザヤの名で引く。キリストが死者のところに下られたことの預言として読まれた（底本の注）。
// 底本は、エイレナイオスの読みによって、ある学者の直した「聖なるかた」を採る。写本は「イスラエルから出た（主なる神）」と読む。

73.1 Καὶ ἀπὸ τοῦ ἐνενηκοστοῦ πέμπτου ψαλμοῦ τῶν διὰ Δαυῒδ λεχθέντων λόγων λέξεις βραχείας ἀφείλοντο ταύτας· ἀπὸ τοῦ ξύλου. Εἰρημένου γὰρ τοῦ λόγου· Εἴπατε ἐν τοῖς ἔθνεσιν· Ὁ κύριος ἐβασίλευσεν ἀπὸ τοῦ ξύλου, ἀφῆκαν· Εἴπατε ἐν τοῖς ἔθνεσιν· Ὁ κύριος ἐβασίλευσεν.
73:1 「また、ダビデを通して語られた言葉のうち、第九十五篇の詩から、彼らは次の短い文言を取り去りました。『木から』^[『木から』の句は、詩篇のごく一部の古い写本にしかない。]という文言です。実際、聖句は『もろもろの国民の中に言え、「主は木から王となられた」』と言っていました。ところが、彼らは『もろもろの国民の中に言え、「主は王となられた」』だけを残したのです（詩篇九六・一〇）」
// 「第九十五篇」は七十人訳の番号で、口語訳では九六篇。
// 「木から」の句は、ヘブル語本文にも七十人訳のほとんどの写本にもなく、ごく一部の写本と、後のラテン語の著述家たちに見える。ユダヤ人が削ったのではなく、キリスト教徒が加えたとみる説がある（底本の注）。『第一弁明』41:2 にもある。
73.2 Ἐν δὲ τοῖς ἔθνεσι περὶ οὐδενὸς ὡς θεοῦ καὶ κυρίου ἐλέχθη ποτὲ ἀπὸ τῶν τοῦ γένους ὑμῶν ἀνθρώπων ὅτι ἐβασίλευσεν, ἀλλ᾿ ἢ περὶ τούτου μόνου τοῦ σταυρωθέντος. ὃν καὶ σεσῶσθαι ἀναστάντα ἐν τῷ αὐτῷ ψαλμῷ τὸ πνεῦμα τὸ ἄγιον λέγει. μηνύον ὅτι οὐκ ἔστιν ὅμοιος τοῖς τῶν ἐθνῶν θεοῖς· ἐκεῖνα γὰρ εἴδωλά ἐστι δαιμονίων.
73:2 「しかし、神であり主であるとして、もろもろの国民の中で王となったと言われた人は、これまで、あなたがたの民族にはいません。ただ、十字架につけられたこのかたについてだけ、そう言われたのです。聖霊は、同じ詩の中で、このかたがよみがえって救いを受けられたことも言っています。そして、このかたが、もろもろの国民の神々のようではないことを示しています。実際、それらは悪霊の偶像です（詩篇九六・五、歴代志上一六・二六参照）」
// 「悪霊の偶像」は 55:2 と同じ形（二つの箇所を合わせたもの）。73:3 で引く詩では「悪霊」とだけある。
// 「救いを受けられた」が詩のどの句を指すかは、底本の注にもない。
73.3 Ἀλλ᾿ ὅπως τὸ λεγόμενον νοήσητε, τὸν πάντα ψαλμὸν ἀπαγγελῶ ὑμῖν. Ἔστι δὲ οὗτος· Ἄισατε τῷ κυρίῳ ᾆσμκ καινόν, ᾄσατε τῷ κυρίῳ πᾶσα ἡ γῆ. Ἄισατε τῷ κυρίῳ καὶ εὐλογῄσατε τὸ ὄνομα αὐτοῦ· εὐαγγελίζεσθε ἡμέραν ἐξ ἡμέρας τὸ σωτήριον αὐτοῦ. Ἀναγγείλατε ἐν τοῖς ἔθνεσι τὴν δόξαν αὐτοῦ, ἐν πᾶσι τοῖς λαοῖς τὰ θαυμάσια αὐτοῦ· ὅτι μέγας κύριος καὶ αἰνετὸς σφόδρα, φοβερός ἐστιν ὑπὲρ πάντας τοὺς θεούς· ὅτι πάντες οἱ θεοὶ τῶν ἐθνῶν δαιμόνια. ὁ δὲ κύριος τοὺς οὐρανοὺς ἐποίησεν. Ἐξομολόγησις καὶ ὡραιότης ἐνώπιον αὐτοῦ. ἁγιωσύνη καὶ μεγαλοπρέπεια ἐν τῷ ἁγιάσματι αὐτοῦ. Ἐνέγκατε τῷ κυρίῳ, αἱ πατριαὶ τῶν ἐθνῶν, ἐνέγκατε τῷ κυρίῳ δόξαν καὶ τιμήν, ἐνέγκατε τῷ κυρίῳ δόξαν ἐν ὀνόματι αὐτοῦ.
73:3 「しかし、言われていることを、あなたがたが理解するために、詩の全体を、あなたがたに告げましょう。それは次のとおりです。『新しい歌を主に向かって歌え。全地よ、主に向かって歌え。主に向かって歌い、その御名をほめよ。日ごとに、その救いを宣べ伝えよ。もろもろの国民の中にその栄光を告げ知らせ、もろもろの民の中にそのくすしきみわざを告げ知らせよ。主は大いなるかたで、いとほめたたうべき者、すべての神々にまさって恐るべき者だからである。もろもろの国民の神々は、みな悪霊だからである。しかし、主はもろもろの天を造られた。ほめたたえとうるわしさとはその御前にあり、聖さと威厳とはその聖所にある。もろもろの国民のやからよ、主に帰せよ。栄光と誉れとを主に帰せよ。その御名において、栄光を主に帰せよ」
// 電子化の「ᾆσμκ」は、印刷版の誤植を写したもの。意図された形は「ᾆσμα」（歌）。
// 九六・三の口語訳は「もろもろの国の中にその栄光をあらわし、もろもろの民の中にそのくすしきみわざをあらわせ」。七十人訳に従って「告げ知らせよ」とした。九六・四の口語訳には「だからである」がない。七十人訳に従った。
// 九六・五の口語訳は「もろもろの民のすべての神はむなしい」。七十人訳に従って「悪霊だからである」とした。73:2 の論の根拠。
// 九六・六の口語訳は「誉と、威厳とはそのみ前にあり、力と、うるわしさとはその聖所にある」。七十人訳に従って「ほめたたえとうるわしさとは」「聖さと威厳とは」とした。
// 九六・七〜八の口語訳は「もろもろの民のやからよ、主に帰せよ、栄光と力とを主に帰せよ。そのみ名にふさわしい栄光を主に帰せよ」。七十人訳に従って「栄光と誉れとを」とした。「その御名において」は底本に従った（七十人訳は「その御名に（ふさわしい）栄光を」）。ユスティノスは、ほかの箇所（『第一弁明』41:2）では「やからよ」の代わりに「代々の父」と読んでいて、ここは写す者が七十人訳に合わせたとみる説がある（底本の注）。
73.4 Αἴρετε θυσίας καὶ εἰσπορεύεσθε εἰς τὰς αὐλάς αὐτοῦ, προσκυνήσατε τῷ κυρίῳ ἐν αὐλῇ ἁγίᾳ αὐτοῦ. Σαλευθήτω ἀπὸ προσώπου αὐτοῦ πᾶσα ἡ γῆ. Εἴπατε ἐν τοῖς ἔθνεσιν· Ὁ κύριος ἐβασίλευσεν ἀπὸ τοῦ ξύλου. Καὶ γὰρ κατώρθωσε τὴν οἰκουμένην. ἥτις οὐ σαλευθήσεται· κρινεῖ λαοὺς ἐν εὐθύτητι. Εὐφραινέσθωσαν οἱ οὐρανοί καὶ ἀγαλλιάσθω ἡ γῆ, σαλευθήσεται ἡ θάλασσα καὶ τὸ πλήρωμα αὐτῆς. Χαρήσεται τὰ πεδία καὶ πάντα τὰ ἐν αὐτοῖς, ἀγαλλιάσονται πάντα τὰ ξύλα τοῦ δρυμοῦ ἀπὸ προσώπου κυρίου. ὅτι ἔρχεται, ὅτι ἔρχεται κρῖναι τὴν γῆν. Κρινεῖ τὴν οἰκουμένην ἐν δικαιοσύνῃ καὶ λαοὺς ἐν τῇ ἀληθείᾳ αὐτοῦ.
73:4 「いけにえを携えて、その大庭に入れ。その聖なる大庭で、主を拝め。全地は、その御前に揺り動かされよ。もろもろの国民の中に言え、「主は木から王となられた」。主は世界を堅く立てられたからである。世界は揺り動かされることがない。主は、公平をもってもろもろの民をさばかれる。天は喜び、地は楽しめ。海とその中に満ちるものとは揺り動かされる。野とその中のすべての物は喜び、林のすべての木は、主の御前で大いに喜ぶ。主が来られるからである。地をさばくために来られるからである。主は、義をもって世界をさばき、ご自分のまことをもってもろもろの民をさばかれる』（詩篇九六篇）」
// 九六・八後半〜九の口語訳は「供え物を携えてその大庭にきたれ。聖なる装いをして主を拝め、全地よ、そのみ前におののけ」。七十人訳に従って「いけにえを携えて」「その聖なる大庭で」「揺り動かされよ」とした。
// 九六・一〇の口語訳は「主は王となられた。世界は堅く立って、動かされることはない」。七十人訳に従って「主は世界を堅く立てられたからである」とした。「木から」は写本にない語で、底本は、ユスティノスの論に従ってある刊本の編者が補ったものを採る（73:1 の訳注）。
// 九六・一一〜一二の口語訳は「海とその中に満ちるものとは鳴りどよめき、田畑とその中のすべての物は大いに喜べ。そのとき、林のもろもろの木も主のみ前に喜び歌うであろう」。七十人訳に従って訳した。「揺り動かされる」（七十人訳は「揺り動かされよ」）と、「そのとき」がないことは、底本に従った。
// 九六・一三の口語訳は「主は来られる、地をさばくために来られる」。七十人訳に従って「主が来られるからである」とした。
73.5 Καὶ ὁ Τρύφων· Εἰ μέν. ὡς ἔφης. εἶπε, παρέγραψάν τι ἀπὸ τῶν γραφῶν οἱ ἄρχοντες τοῦ λαοῦ. θεὸς δύναται ἐπίστασθαι· ἀπίστῳ δὲ ἔοικε τὸ τοιοῦτον.
73:5 トリュフォンは言った。「あなたが言ったように、民の治める者たちが聖書から何かを削ったのかどうか、それは神なら知ることがおできになります。しかし、そのようなことは、信じがたいことに思えます」
// 「削った」と訳した語は、71:4 の「削られた」と同じ語。
73.6 Ναί. ἔφην, ἀπίστῳ ἔοικε· φοβερώτερον γάρ ἐστι τῆς μοσχοποιΐας, ἣν ἐποίησαν ἐπὶ γῆς μάννα πεπλησμένοι, καὶ τοῦ τὰ τέκνα θύειν τοῖς δαιμονίοις. ἢ τοῦ αὐτοὺς τοὺς προφήτας ἀνῃρηκέναι. Ἀλλὰ δή. ἔφην. μοι νομίζεσθε μηδὲ ἀκηκοέναι ἃς εἶπον περικεκοφέναι αὐτοὺς γραφάς. Ὑπὲρ αὐταρκείας γὰρ αἱ τοσαῦται προανιστορημέναι εἰσὶν εἰς ἀπόδειξιν τῶν ζητηθέντων μετὰ τῶν λεχθήσεσθαι μελλόντων παρ᾿ ὑμῖν παραπεφυλαγμένων.
73:6 わたしは言った。「そうです、信じがたいことに思えます。実際、それは、子牛を造ったことよりも恐ろしいことです。彼らは、地上でマナに満ち足りていながら、子牛を造りました（出エジプト三二章参照）。また、子供たちを悪霊にいけにえとしてささげたことや（詩篇一〇六・三七参照）、預言者たちそのものを殺したことよりも、恐ろしいことです。しかし、わたしが、彼らが切り取ったと言った聖句については、聞きもしなかったものと思ってください。実際、これまでに詳しく述べたこれほど多くの聖句で、問われたことを論証するには十分すぎるほどです。これから述べようとしている、あなたがたのもとに保たれている聖句も加わるのですから」
// 「地上で」は、底本の注が疑う読み。
// 底本は、ある刊本の編者たちの直した「あなたがたのもとに」を採る。写本は「わたしたちのもとに」と読む。
