# ディダケーの決まり

## 節の形

- 底本の 1 節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `1:1 ` のように章と節の番号で始める（『クレメンスの第一の手紙』と同じ形）。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 1〜6 章　二つの道` の形。

## 文体

- 地の文は常体。教える者が弟子に語る調子で書く。τέκνον μου は「わが子よ」。
- 命令は原文の形で訳し分ける：命令法は「〜せよ」、μή＋命令法は「〜するな」、οὐ＋未来形は「〜してはならない」。3 人称の命令法は「〜するがよい」（会衆に向けた言葉）か、日本語として自然なら「〜してはならない」（μηδεὶς φαγέτω など）。
- 神への祈りは敬体（「〜ますように」）。

## 訳語

| 原語 | 訳 |
|---|---|
| κύριος | 主 |
| ὁδὸς τῆς ζωῆς / τοῦ θανάτου | いのちの道／死の道 |
| ἐλεημοσύνη | 施し |
| ἐκκλησία | 教会 |
| εὐαγγέλιον | 福音（書物の意味の「福音書」にはしない） |
| εὐχαριστία | 聖餐。動詞 εὐχαριστέω は「感謝をささげる」 |
| παῖς（イエス、ダビデ） | しもべ（口語訳の使徒三・一三にならう） |
| δεσπότης | 主（口語訳の使徒四・二四にならう） |
| δοῦλος / παιδίσκη | しもべ／はしため |
| ἱμάτιον / χιτών | 上着／下着（口語訳と同じ） |

## 聖書の出典

原文が引用だと示しているところ（「主が言われた」「〜と書いてある」など）にだけ出典を付ける。福音書の言い回しをなぞるだけのところには付けない。出どころの知られていない言葉（1:6 など）には付けない。
