# ディオグネトスへの手紙

『ディオグネトスへの手紙』（Πρὸς Διόγνητον）のギリシア語原文からの翻訳。

底本は [Open Apostolic Fathers](https://jtauber.github.io/apostolic-fathers/)（James Tauber & Seumas Macdonald, Version 1.0, 2019, doi:10.5281/zenodo.2555673）のギリシア語本文。Kirsopp Lake の Loeb 版（1913）の本文を、印刷版と照らし合わせて校正したもの。各節の `both.md` に置いたギリシア語本文は CC BY-SA 4.0 で、そのまま引き継ぐ。章・節の番号も底本に従う。本文を伝えた写本は一つだけで、1870 年に焼失した。底本が欠落を示すところ（7.6〜7.7、10.1 の後）は、語を補わずに訳した。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
