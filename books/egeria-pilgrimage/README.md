# エゲリア『巡礼記』

4 世紀の終わりに聖地を巡った女性エゲリアの『巡礼記』（Peregrinatio ad loca sancta）のラテン語原文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は P. Geyer 編、*Itinera Hierosolymitana saeculi IIII–VIII*（Corpus Scriptorum Ecclesiasticorum Latinorum 39、Wien: F. Tempsky, 1898）の pp. 37〜101。パブリックドメイン。archive.org のスキャン（[itinerahierosoly00geye](https://archive.org/details/itinerahierosoly00geye)）の画像から本文を起こし、[research/geyer-1898.txt](research/geyer-1898.txt) に置いた。この書を伝える写本は 11 世紀の一つだけで、冒頭と結びが失われ、途中にも二か所、一葉ずつの欠けがある。底本は題を「シルウィアの作と伝えられる巡礼記」とするが、いまは著者を、7 世紀のスペインの修道院長ウァレリウスの手紙に名の見えるエゲリア（エテリアとも呼ばれ、名の正しい形には諸説ある）とみるのが一般的で、この訳もそれに従う。底本で同じ巻のすぐ後に続くペトルス・ディアコヌスの『聖地について』は訳していない。

章と節の番号は底本に従う。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは `research/cruxes/` にある。
