# 校訂上の論点

エゲリア『巡礼記』の本文で、写本と刊本の読みが分かれる箇所、底本が写本の読みを改めた箇所、編者のあいだで構文や意味の取り方が分かれて訳に響く箇所、聖書の引用・暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（Geyer 1898 の本文、`../geyer-1898.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。各項の見出しのラベルは底本テキストの行頭のラベル（章.節）。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は各資料の OCR テキスト（`_djvu.txt`）の行番号。底本の校注は OCR が崩れる（とくに斜体）ので、ページ画像（`cache/archive.org/itinerahierosoly00geye/page/`）で読み、OCR の行番号はおよその位置として添える。

- 底本（Geyer）：P. Geyer 編、CSEL 39（1898）。各ページの上が本文、その下に聖書の箇所（行番号と箇所。「cf.」が付くものは暗示や要約）、その下に校注。校注の番号はページごとの行番号（本文の欄外の 5、10 … で数える）。各論点では「p. 37 校注 4」のように、印刷ページと校注の行番号で挙げる。画像は archive.org のページ画像 `nN_w1600.jpg`（N＝印刷ページ＋55。n92＝p. 37）。
- 校注の略号（画像 n92〜n96 の校注で確かめたもの）：
  - A：アレッツォの写本（cod. Arretinus、11 世紀。OCR l. 4783）。この書を伝える唯一の写本。
  - 「ipse scripsi」「ipse addidi」は Geyer 自身が改めた・補ったもの。「scripsi cum Cholodniak」は Cholodniak の推定に従って改めたもの。「om.」は欠くこと（「et om. Bernard」は Bernard が et を除いたこと）。「transposuit」は語の位置を移したこと。「fortasse」は Geyer が本文に入れずに示す「〜かもしれない」という案。「suspicor emendandum esse」は、Geyer が改めるべきだと疑いながら本文に入れなかった案。「nihil mutandum est」は改める必要がないという判断。「sic semper A」は A がいつもその綴りで書くこと。「e. q. s.」は以下同じ。
  - 画像 n96〜n100 の校注で確かめたもの：「locum aperte corruptum」は明らかに崩れた箇所（本文には † を刷る。4.3）。「emendare conatus est」は改めを試みたこと、「ipse tentaui」は Geyer が本文に入れずに試みた改め。「emendauit」「coni.」は改めたこと・推定したこと。「probante Bernardo」は Bernard も同じ読みを採ること。「corr. ex」は A で別の字から直されていること（「filios corr. ex filiis A」）。「littera h erasa est」は A で字が削られていること。「lineola perducta (ducta) est」は A で字や語に線が引かれていること。「an erat?」は「erat ではないか」という Geyer の問い。「cf. Krit. Beitr.」は Geyer の Kritische Bemerkungen を参照させるもの。
  - 画像 n100〜n105 の校注で確かめたもの：「transposui」は Geyer が語の位置を移したこと（6.4）。「falso」は他の刊本が誤って刷ったこと（「grandis falso Pomialowsky」）。「emendaui Krit. Beitr. p. 22」は Geyer が前著で改めたこと。「uerba: … a librario omissa in infima pagina minoribus litterulis scripta exstant」は、写字生が落とした語がページの下に小さな字で書かれて残っていること（6.3）。「in margine codicis exstat」は A の欄外に書かれていること（8.4）。「quod idem … ueri simile uidetur」は、ほかの学者も同じ読みを本当らしいとしたこと。「in editione Bernardiana」「in ed. Bernard.」は Bernard の刊本に載った推定（Purser の推定はこの形で出る）。聖書の欄の「(Sept.)」は七十人訳によること（「cf. Exod. 14, 2 (Sept.)」）。
  - 画像 n105〜n110 の校注で確かめたもの：「cum signis transpositionis」は A に語順を入れ替える印が付いていること（10.7 の oratio ibi）。「ipse conieci」は Geyer が本文に入れずに出した推定（10.9 の ortati）。「non delendum esse censui」は Geyer が語を除くべきだと判断したことで、本文ではその語を角括弧に入れて残す（12.2 の [non]）。「ipse suppleui」は Geyer が補ったこと（本文は山括弧。12.2 の ⟨positus sit⟩）。「add. Gamurrini」は Gamurrini が補ったこと（12.7 の ⟨est,⟩）。「in codice scriptum esse affirmat Pomialowsky」は、Pomialowsky が写本にそう書かれていると言うこと（12.8 の safdra）。12.7 の校注 22 で A の cum の上に小さく刷った lo は、A で行の上に書き足された字（Kritische Bemerkungen l. 5617–5620 が、cum の上に lo が書かれていると言う。ほかのページの同じような小さな字は、それぞれの「未確認」に残す）。
  - 画像 n110〜n115 の校注で確かめたもの：「perperam」は他の学者の改めを誤りとすること（「tumbae perperam Bernard」）。「ipse olim conieci …, sed perperam」は Geyer が以前に出した推定を自分で退けたこと（16.6 の foderunt）。「uox euanuit」は A でその語が消えて読めないこと、「leg.」は「〜と読んだ」（16.6 の stat leg. Cholodniak et Gamurrini, fuit ipse）。「in codice supra lineam est」は A で行の上（行間）に書かれていること（13.1 の etiam）。「deletum est」は A で字が消されていること（16.3 の g）。「Gamurrini (1)」は Gamurrini の初版。校注の A の読みの上に小さく刷った字（14.2 ferebat の n、16.6 perdiscoperuisset の n、16.3 torrente の eo）は、12.7 の lo と同じく A で行の上に書き足された字とみられる（序で確かめていないので、chapter-13-16 の「未確認」に残す）。聖書の欄の「et q. s.」（et quae sequuntur）は「以下」（「III. Reg. 17, 3 et q. s.」）。
  - 画像 n115〜n119 の校注で確かめたもの：「seu uoce seu deleta A」は A でその語（seu）が消されていること（18.1。A の語の上に小さく刷った字は、ここでも行の上に書かれた字とみられる）。「sed et deleto」「sed c deleto」は A で字や語が消されていること、「tamen lineis deletum」は線を引いて消されていること（19.7、19.10）。「sed corr. A」は A でその語が直されていること（19.18）。「ipse conieceram」は Geyer が以前に出した推定（本文には入れない。19.15 の pariete）。「eandem emendationem exhibent」はほかの刊本も同じ改めを刷ること（17.1）。「codicem habere mihi confirmauit Gamurrini」は、Gamurrini が A の読みを Geyer に確かめたこと（19.19 の nos）。「(= deum)」は A の略記の読み方（19.6 の dm̄）。
  - 画像 n119〜n123 の校注で確かめたもの：「dittographia A」は A が同じ語を二度書いたこと（本文では二度目を角括弧に入れて残す。20.13 の [aliquando]）。「nihil supplendum est cum Gamurrini」は、Gamurrini と同じく語を補う必要はないという判断。「delendum censet」はその語を除くべきだとすること（20.6 の eos）。「scribendum uidetur」は Geyer が本文に入れずに「〜と書くべきもののようだ」と示す案（20.12 の syria orientalis）。「lineola deletum est」は A で語に線を引いて消してあること（20.9 の suo）。「sim. 19」「similiter p. 68, 6」は同じページの 19 行目、p. 68 の 6 行目も同じであること。
  - 画像 n123〜n126 の校注で確かめたもの：「emendaui Comm. Woelfflin. p. 94」は Geyer が Commentationes Woelfflinianae（語の索引では Comment. Woelfflin. p. 91–95）で改めたこと（21.2 の loco）。「seclusit」は他の刊本がその語を除くべき語として括弧に入れたこと（22.1 の Tharso seclusit Bernard）。「sed ordo uirgulis adscriptis restitutus est」は A に書き添えた印で語順が元に直されていること（23.4 の est ibi）。「corr. in」は A でその語が別の形に直されていること（23.5 の omnia corr. in omni）。「rasura quattuor litterarum」は A で四字分が削られていること、「in rasura」は削った跡の上に書かれていること（23.5、23.7）。「altero a lineola deleta」は二つ目の a に線を引いて消してあること（23.4 の hisaauros）。「edd.」は諸刊本（24 章の praeterea edd.）。A の略記は、校注で字の上に横線を引いた形で刷られる（23.8 の p̄rare＝praestare、23.10 の dōnae＝domnae）。p. 70 校注 7 の lecta' と p. 71 校注 16 の luce' の上付きの小さな記号の意味は確かめていない（chapter-21-23 の「未確認」）。
  - 画像 n126〜n129 の校注で確かめたもの：「an scribendum …?」は Geyer が本文に入れずに「…と書くべきではないか」と問う案（24.2 の ipse A an scribendum ipsa?）。「addidit Cholodniak」は Cholodniak が補ったことで、本文ではその語を山括弧に入れる（24.3 の ⟨intro⟩）。山括弧は Geyer 自身の補いだけでなく、Geyer が採ったほかの学者の補いにも使われる。「uide Du Cangii glossarium s. v.」はデュ・カンジュの辞書のその語の項を見よということ（24.7 の cereofala）。「signum ur euanuit, sed etiam nunc distingui potest」は A で -ur の略記の印が消えかけているが、まだ見分けられること、「euanuit, sed … legi potest」は A でその語が消えかけているが、…と読めること（24.12）。A の読みの上に小さく刷った字（24.6 inclin& の N、24.7 dicit の v、24.9 luc& の N、24.12 ana sī の sta）は、KB が 24.7 について同じ手が i の上に v を書いたと言う（KB l. 4339–4340）のと同じく、A で行の上に書かれた字とみられる（v のほかは chapter-24 の「未確認」）。
  - 画像 n129〜n132 の校注で確かめたもの：「seclusi」は Geyer がその語を除くべき語として本文で角括弧に入れたこと（25.3 の [martyrii]。理由は書かない）。「sic saepius A」「sic saepe」は A がたびたびその形で書くこと（25.7 の astase、25.8 の extimari）。「in extrema linea A」は A で行末に書かれていること（25.8 の genus を gē と略す）。「sic ipse lectionem codicis annotaui」は Geyer が自分で A を読んで記したこと（26.1 の fanuhel）。「fiunt sic, non sunt A」は、A が fiunt で sunt ではないこと（25.1。Gamurrini の sunt を退ける）。聖書の欄に cf. のないもの（p. 75 の「27 Matth. 21, 9」）は、本文が字間をあけて刷る直接の引用。
  - 画像 n133〜n136 の校注で確かめたもの：校注の見出しの語の後の「]」は、本文のその語についての注であることを示す（「24 nona] non Du Chesne」は、本文の nona の代わりに Du Chesne が non と読むこと。27.3）。「delet」は他の刊本がその語を除くこと（「alterum similiter delet Bernard」は二つ目の similiter を Bernard が除くこと。27.5）。「l. c.」は前に引いた書（loco citato。p. 78 校注 24 の Du Chesne l. c. p. 479 は Origines du culte chrétien）。「lineola per litteram s ducta deletum est」は A で s の字に線を引いて語が消してあること（27.6 の sic）。「lacunam … alii aliter suppleuerunt」は、編者が示す欠け（本文の点線）を、学者たちがそれぞれ違う語で補ったこと（28.4 の farina の後。p. 81 校注 12）。「lacunam indicaui」は Geyer が欠けを示したこと（29.1）。「emendaui」は Geyer が本文で改めたこと（27.6 の hora）。
  - 画像 n136〜n139 の校注で確かめたもの：ipse のない「scripsi」も Geyer が本文で改めたこと（30.1 の agi scripsi、30.3 の ubi scripsi）。「ipse et Pomialowsky」は Geyer と Pomialowsky がともにその読みを採ること（32.1 の lucernarium）。「item Du Chesne」は Du Chesne も同じ読みであること。A の読みの ę（下に鉤を付けた e。p. 84 校注 2 の quę）は ae を表す字で、quę は quae。A の読みの上に小さく刷った字（p. 82 校注 20 の g の上の o と eo）は、ここでも A の略記と行の上に書かれた字とみられる（chapter-29-32 の「未確認」）。
  - 底本の山括弧（底本テキストでは ⟨ ⟩）は Geyer が写本にない語を補ったもの（2.3 の ⟨quia⟩。p. 38 校注 4 の quia ipse addidi）。山括弧なしで補った語もある（4.7 の est。p. 42 校注 17 の est ipse addidi）。6.4 の ⟨denuo,⟩ は補いではなく、A にある語を Geyer が別の位置へ移した印（p. 46 校注 20 の transposui）。
- 校注に出る人名（推定を出した刊本の編者や学者。Geyer の序 OCR l. 520–545）：

  - Sittl（J. v. Müllers Jahresberichte 1889）、Woelfflin（Archiv f. lat. Lexik. IV）：本文に推定を出した学者（l. 544–546）。
  - Purser（Bernard の刊本に推定が載る。p. 45 校注 27、p. 47 校注 19）、Mommsen（Berliner Sitzungsberichte 1887, p. 361。p. 47 校注 19）、I. v. d. Vliet（Archiv f. lat. Lex. X。p. 49 校注 1）：校注に推定が引かれる学者。
