- 訳注：24.1 の Anastasis（「『復活』の意。主の墓の上に建つ円い聖堂。」）と 24.7 の ad Crucem（「主が十字架にかけられたゴルゴタの場所。」）に付けた。どちらも別の読みの注ではなく場所の名の注で、16.1 の Getha、21.4 の Fadana と同じく、音や字どおりの訳だけでは読者が場所を思い描けないため。根拠は底本の索引（OCR l. 18871–18880 の illa rotunda ecclesia, quae Anastasis, hoc est resurrectio uocitatur）と、同じ巻のエウケリウス（OCR l. 8688–8694 の Anastasis in loco est resurrectionis, Golgotha uero … locus est dominicae passionis）で、自分で確かめた。論点一覧の案の「墓の聖堂の東にある」は、エウケリウスの文から推した方角で、底本では確かめられないので入れなかった。

論点一覧から決めたこと（本の `AGENTS.md` の訳語表、文型の訳し方、底本の扱いに書いた）：

- 典礼の語の訳語表を作った。Anastasis「アナスタシス」、spelunca「ほら穴」、cancelli「仕切り」、basilica「聖堂」、ad / ante / post Crucem「十字架の所／十字架の前／十字架の後ろ」、missa「散会」（底本の索引の dimissio。80, 5 の oblatio の意味の missa はそのページで決める）、operatio「務め」、ymni「賛歌」、licinicon「リュクニコン」と lucernare「ともしびの祈り」、明かりの語の訳し分け、fideles「信徒たち」と laici「一般の人たち」、ad manum accedere「監督の手のもとに進み出る」（Bernard の「接吻するために」は原文にないので足さない）、commemoratio「祈りの中で思い起こすこと」、kyrie eleyson「キュリエ・エレエーソン」、pisinni「子供たち」など。
- monazontes は「修道士たち」とし、monachus と訳し分けない。底本の索引が monazontes = monachi, monachae とし、後の章（OCR l. 6590 の ecclesia monazontes cum ymnis と、l. 6712〜6714 の monazontes … loci ipsius monachi）で同じ人々を指すため。24.1 の ut hic dicunt は 3.4 の ascitis と同じく「ここで言う」。
- 単数の -et（benedicet、dicet など）も現在形として「〜します」。原文が唱える人・読む人を主語にした能動の文（24.9、24.10）は能動で訳す。
- 24.3 の ⟨intro⟩ はほかの学者（Cholodniak）の補いを Geyer が採ったもので、`⟨ ⟩` で起こしてメモに補いの主を書く。
- 24.1 の antiphonae: は、拡大してコロンと読んだ（OCR もコロン）。24.8 の talis est. ut は刷られたとおりピリオドを残し、一つの文として訳してメモに書いた。
