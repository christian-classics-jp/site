論点一覧から決めたこと（本の `AGENTS.md` の訳語表、名前の表、文型の訳し方に書いた）：

- 大きな教会の名 Martyrio（27.3 が初出）は、Anastasis、Eleona、Lazarium と同じく音で写して「マルテュリウム」。名の由来は 30 章の初め（p. 83, 2 の Propterea autem Martyrium appellatur, quia …）で原文が述べるので、訳注は付けない。
- 27.8 の Missa autem, quae fit sabbato …, hoc est oblatio は、底本の索引がこの missa（80, 5）だけを oblatio の意に分けるので「務め」と訳した。27.7 が oblatio と missa を別の事柄として述べ、27.8 の後半の et missa（Geyer の改め）が「散会も済む」と言うので、ほかの missa は「散会」のままで筋が通る。
- eortae は licinicon と同じ quod hic appellant … id est … の型なので、ἑορταί の音で「ヘオルタイ」とし、説明の quadragesimas を「四旬節」で受けた。「祭り」の意の訳注は、断食の季節を「祭り」と呼ぶ理由を説明できず 40 字に収まらないので付けない。
- ebdomadarii は、直後の id est qui faciunt septimanas と同語反復にならないように、呼び名を「週の人たち」、説明を「週を通して断食する人たち」と訳した。
- feria は土曜日の「土曜日」に合わせて「月曜日」〜「金曜日」。dies paschales は「復活祭の時期」、quadragesimae は「四旬節」、martyrorum dies は「殉教者の記念の日」、absoluere は底本の索引の「断食を終える」、biduanas facere は「二日ずつの断食をする」、de sera ad seram manducare は「晩から晩へと、晩に一度だけ食べる」、28.4 の qui satis fecerit は qui minus と対にして「多くした人」。
- 27.3 の dominica enim die nona fit は底本と索引に従い「主の日には第九時の務めが行われるからです」とし、Du Chesne の non はメモに書いた。27.5 の neque（写本は atque）、27.6 の hora lucernari（写本は tota）は底本どおり訳し、訳注は付けずメモに書いた。27.6 の legem は字どおり「律法」。
