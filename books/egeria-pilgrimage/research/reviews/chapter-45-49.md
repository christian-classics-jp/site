論点一覧とレビューから決めたこと（本の `AGENTS.md` の「底本の扱い」、訳語表、名前の表、文型の訳し方に書いた）：

- 結びの点線（p. 101）は冒頭の点線と同じく底本テキストに入れず、訳は「四日目には」で切って訳注を置く。
- conpetens は「洗礼を願い出た人」、neofiti は「洗礼を受けたばかりの人たち」、cathecisis は『秘義教話』の「教話」、simbolum は「信条」、lex は「教え」、carnaliter / spiritualiter は「字義どおりに」「霊的に」、lauacrum は「洗い」、patres / matres は字どおり「父」「母」、siriste は口語訳に揃えて「アラム語」、encenia は「献堂の祭り」、saeculares は「一般の人たち」。
- 文の中で主文に係る ne ＋接続法と目的の ut ＋接続法は「〜ためです」で後ろから受ける。
- appellatur で示す行事や期間の呼び名は「」に入れる。
- non solum … sed et は対比の中身を原文の並びで確かめ、「だけでなく」を一度だけ置く。
- accedere ad baptismum は「洗礼に進む」。

レビューの後、自分で見直して直したこと（本の `AGENTS.md` の id est と enim の決まり）：46.1 の Consuetudo est enim を「というのも、ここのならわしは次のとおりなのです」、46.3 の id est ab hora prima を「つまり第一時から第三時まで」、47.2 の Illa enim hora を「その時刻には、洗礼志願者はだれもアナスタシスに近づかないからです」とした。
