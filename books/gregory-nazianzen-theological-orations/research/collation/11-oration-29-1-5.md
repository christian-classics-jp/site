29.2.2 の ἢν（＝ἐάν、「もし」）は、印刷版では関係代名詞 ἣν で、二つとも μοναρχία を受ける（「一つの位格が囲い込む単一支配ではなく、本性の同等さが成り立たせる単一支配」）。29.2.4 の ὑπερερρύῃ は接続法になっているが、印刷版は直説法アオリスト ὑπερερρύη（杯があふれ出た）。29.3.1 は、アレイオス論争の言い回し「彼がいなかったときはなかった」の前半の ἦν が ἢν になっている。

語の変わらない違いとして、29.2.1 の ‘Ελλήνων（印刷版は Ἑλλή-νων）、29.2.3 の οἱδ’（印刷版は οἶδ’）、29.3.5 の πὼς（印刷版は前接語の πως）、29.5.3 の Φιλοχρόνους と 29.5.4 の προΦέρεται（印刷版は小文字の φ）は、表に入れなかった。

照合の候補のうち、29.1.3 の σφιγγόμενον（OCR は σφυγγόμενον）、29.3.3 の ἐκπεπόρευται と βιαζώμεθα、29.5.1 の υἱός と ἠργμένος は、印刷版が電子化と同じで、OCR の誤りだった。29.3.2 の πάλιν ἐρώτα με, καὶ πάλιν ἀποκρινοῦμαί σοι と 29.3.3 の二つ目の πότε は OCR で崩れたり欠けたりしていたが、印刷版にはある（0104_pdf.png）。印刷版そのものの誤植は見つからなかった。
