29.6.1 の `*` は、印刷版では上付きの点（・）で、「なんと強情で恥知らずなことか」と「欲して生んだのか」の問いとの切れ目になっている。29.6.2 の το は印刷版にない余分な文字で、訳では読まない。29.6.4 と 29.8.5 の ἃν（ἃ ἄν の縮約に見える）は、印刷版ではどちらも小辞の ἂν。29.6.10 の ἢ（「あるいは／より」）は、印刷版では冠詞 ἡ で、「出生は意志よりも上にある」となる。29.8.1 と 29.9.9 の ἢν（＝ἐάν）は、印刷版ではどちらも ἦν（「あった」）。29.8.4 の二つ目の εἰ（「もし」）は、印刷版では εἶ（「あなたは〜である」）で、「あなたがどれほど大胆でも」となる。29.9.5 の ἢ も、印刷版では冠詞 ἡ（「なんという余計な知恵か」）。29.9.1 の ’ は、印刷版では上付きの点で、文の切れ目になっている。

語の変わらない違いとして、29.9.1 の Λευὶ,（印刷版は Λευί,）と、各所の ἁλλὰ・ἁλλ’（印刷版は ἀλλὰ・ἀλλ’）は、表に入れなかった。

照合の候補のうち、29.6.5 の τῆς βίας、29.7.1 の θέλων、29.8.5 の κατάβαλέ σου τὰς ῥεύσεις, καὶ τὰς、29.9.3 の ὤν（OCR は ὦν）、29.9.7 の αἰνιγμάτων（OCR は αἰνυγμάτων）、29.9.9 の οὗτος γὰρ は、印刷版が電子化と同じで、OCR の誤りや欠けだった。印刷版そのものの誤植は見つからなかった。
