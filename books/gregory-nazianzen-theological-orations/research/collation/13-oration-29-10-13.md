29.11.4 の二つ目の εἰ（「もし」）は、印刷版では εἶ（「あなたは〜である」）で、「あなたがどれほど『生まれざるもの』を好むにしても」となる。29.13.6 の ἦ（「あった」）は、印刷版では接続法の ᾖ で、「本性によってそうであるもの」となる。同じ節の ἢ（「あるいは／より」）は、印刷版では冠詞 ἡ（「真理は名にではなく事柄にある」）。29.13.2 の γεννᾶ は、箴言八・二五の引用で、印刷版は γεννᾷ（「〔主は〕わたしを生む」）。

29.13.1〜2 と 29.13.5〜6 は、電子化が節の切れ目で文を終えている（.）が、印刷版ではどちらも上付きの点（·）で、文は続いている。29.13.1〜2 では、「やんだのなら始まりもあった」も ὡς（「〜と言って」）に導かれる相手の言い分の続きになる。29.13.5〜6 では、29.13.6 の不定詞 εἶναι・ὀνομάζεσθαι も、29.13.5 の「わたしたちの説（ὁ ἡμέτερος λόγος）」の内容の続きになる。

語の変わらない違いとして、29.11.3・29.11.4 の ἁλλὰ（印刷版は ἀλλὰ）、29.12.6 の καἲ（印刷版は καὶ）、29.13.2 の ἀίδιον（印刷版は ἀΐδιον）は、表に入れなかった。29.13.5 の ὂ μὲν ἂν μετέχῃ の ὂ は、印刷版では関係代名詞 ὃ（気息の違い。ὂ という語はないので表に入れなかった）。

照合の候補のうち、29.10.3 の οὐ γὰρ（OCR で欠け）、29.11.1 の ὃ δὲ（OCR で位置がずれた）、29.11.2 の ἆρ’（OCR は ἄρ’。印刷版は電子化と同じ ἆρ’、0117_pct:5,15.5,50,3.jpg）、29.12.3 の ὅτι δὲ οὐ ταὐτὸν ἀγέννητον καὶ θεός, ὧδε ἂν μάθοις、29.13.1 の γεννᾷν（OCR は γεννᾶν）、29.13.3 の τοῦ λόγου、29.13.5 の μετέχῃ（OCR は μετέχη）は、印刷版が電子化と同じで、OCR の誤りや欠けだった。印刷版そのものの誤植は見つからなかった。
