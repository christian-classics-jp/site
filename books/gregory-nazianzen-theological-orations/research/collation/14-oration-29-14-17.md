29.15.1 の Τὰ（中性複数の冠詞）は、印刷版では Τὸ で、引用される小前提は『原因であることは本性による（Τὸ δὲ αἴτιον φύσει）』という一つの命題になる。29.16.1 の προκατείληφες は二人称（「あなたが先に占めた」）になっているが、印刷版は三人称の προκατείληφεν で、「御父がその本質を先に占めた」となる。29.16.2 の ἢν は ἐάν（「もし」）の縮約形と読めるが、印刷版は ἦν（「〜であった」）で、「二つのうちの一つを受け入れることが必要であったなら」となる。29.17.4 の ἢν も同じで、印刷版は ἦν（黙示録一・八などの『かつておられた方』）。29.17.1 は、電子化では φωνῶν（「ことば」）が本来の位置から抜けて κηρύσσομεν の途中に入り込んでいる。印刷版では「御子についての偉大で高いことば（φωνῶν）から」となり、続く「それはどれか。神（θεός）ということば、ことば（λόγος）ということば」（τῆς θεός, τῆς λόγος は φωνῆς を補う）の前提になる。29.16.5 の ἃν は、ἃ ἄν の融合形 ἅν と読める綴りなので表に入れたが、δέξῃ … πείθειν の構文からは ἐάν の ἂν としか読めず、意味は変わらない。

語の途中の空き（θαλάτ- τιον、ἀμ- φοτέροις、ὁμολογή- σοντας、προσ- γενόμενον）は、どれも印刷版の行末のハイフンで、印刷版では一語。

語の変わらない違いとして、29.14.5 の ὂ μόνου θεοῦ（印刷版は関係代名詞 ὃ、0122_pct:5,37,90,10.jpg）、29.14.7・29.16.1・29.16.2 の ἁλλ’・ἁλλὰ（印刷版は ἀλλ’・ἀλλὰ）、29.17.2 の ἁλήθεια（二か所。印刷版は ἀλήθεια）、29.17.3 の Ὅς ὣν（印刷版は Ὃς ὢν、0127_pct:5,40,90,4.jpg）は、気息やアクセントだけの違いで、電子化の形はどれもその語として存在しないので、表に入れなかった。29.16.1・29.17.1・29.17.2 の ‘Ο と 29.17.4 の ‘O（ラテン文字）は、印刷版の Ὁ を写した文字の違い。29.17.3 の τοῦτον γὰρ は、印刷版では引用の始まりとして Τοῦτον と大文字。句読点では、29.15.3 の ὁ θεός οὐσία は印刷版では ὁ θεός, οὐσία（0125_pct:5,6,90,9.jpg）、29.17.5 の δυνάμεως ὧν は印刷版では δυνάμεως, ὧν だが、どちらも文の切れ目は変わらないので表に入れなかった。29.16.4 の ἐνεργείας,εἰ（コンマの後の空きがない）は印刷版も同じ。

照合の候補のうち、29.14.5 の χαρίζῃ（印刷版も χαρίζῃ、0122_pct:5,37,90,10.jpg）、29.15.2 の κατὰ τίνος, καὶ τίνα（OCR で τίνος の位置がずれた）、29.15.3 の πῇ（印刷版も πῇ、0125_pct:5,12.5,90,4.5.jpg）、29.16.1 の ὂν ἀξιάγαστον（OCR は ὃν。印刷版は電子化と同じ ὂν、0125_pct:5,26,90,8.jpg）、29.16.2 の ᾐδέσθην（OCR は ἠδέσθην。印刷版は電子化と同じ ᾐδέσθην、0126_pct:5,10,90,12.jpg）、29.17.2 の ὁ ὢν（OCR は ὧν。印刷版は ὢν、0127_pct:5,26.5,90,4.5.jpg）、29.17.4 の ὁ ὤν（OCR は ὦν。印刷版は ὤν、0128_pct:5,6,90,7.jpg）、29.17.6 の ὅτε ἄλογος ἦν と ἢ ζωῆς ἐνδεής（OCR で崩れた）は、印刷版が電子化と同じで、OCR の誤りや欠けだった。印刷版そのものの誤植は見つからなかった。
