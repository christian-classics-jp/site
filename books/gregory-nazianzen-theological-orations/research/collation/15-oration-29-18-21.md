29.19.3–4 は、電子化では δι’ が抜け、次の文の頭に ἐγένετο. が重なって入っている。電子化のままだと「彼がなった（ὃν ἐγένετο）ことばに」と読めてしまうが、印刷版は「そのため（δι’ ὃν）に生まれたことば（λόγος）の前で、母の胎で躍った預言者」となる。29.20.5 は、電子化では ἐγείρει の目的語 Λάζαρον が抜け、代わりに Θεὸς が重なっている。印刷版は「しかしラザロをよみがえらせる。神であったから」で、前の「ラザロはどこかと尋ねる。人であったから」と対になる。

29.18.2 の ὕπνουν は ὑπνόω の未完了過去（一人称単数・三人称複数）、πείνην は名詞 πείνη（飢え）の対格と読める綴りだが、どちらも τὸ を付けた不定詞の列（τὸ ὑπνοῦν, τὸ πεινῆν, τὸ κοπιᾷν …）の中にあり、印刷版は不定詞 ὑπνοῦν・πεινῆν。29.20.2 の δίψᾳ も名詞 δίψα（渇き）の与格と読める綴りだが、印刷版は接続法 διψᾷ（ヨハネ七・三七『もし渇く者があれば』）。どれも語の意味は同じなので、意味は変わらないとした。29.19.2 は、印刷版では括弧が ἡ δὲ ἦν の前から κατεδέξατο の後まで続く。電子化は開き括弧が落ち、閉じ括弧だけが残っているので、挿入句（「その原因とは、あなたが救われることだった…」）の始まりがわからなくなる。ἡ は印刷版も冠詞の ἡ で（気息記号だけ。0135 の ἡ γὰρ πίστις（0135_pct:69,12.5,10,3.png）と同じ形で、0130 の ὃ δὲ（0130_pct:19,27.5,10,3.png）のような重アクセントはない）、語は変わらない。29.18.5 の μάθης と 29.20.6 の τῆ は、29.15.1 の τῆ φύσει と同じ下書きのイオタの欠け。

語の途中の空き（ὑψω- θέντι、συν- ἐπαίρῃ、ἀποσπαρ- γανοῦται、δαι- μόνων、θά- πτεται）は、どれも印刷版の行末のハイフンで、印刷版では一語。

語の変わらない違いとして、29.19.5・29.20.3・29.20.5・29.20.6・29.20.8 の ἁλλ’・ἁλλὰ（印刷版は ἀλλ’・ἀλλὰ）、29.20.8 の καταλύτης（印刷版は καταλυτής、0133_pct:5,29,92,24.png。同じ語のアクセントの違い）は、表に入れなかった。29.21.1 の ἵν εἰδῶσι は、印刷版では省略符の付いた ἵν’（0134_pct:5,29,92,24.png）。29.21.1 の ταῦτα（印刷版は節の頭で Ταῦτα）、29.21.5 の χριστοῦ（印刷版は Χριστοῦ）は大文字の違い。句読点では、29.20.5 の δακρύει ἀλλὰ は印刷版では δακρύει, ἀλλὰ だが、文の切れ目は変わらない。

照合の候補のうち、29.18.4 の ὁμώνυμόν σου（OCR は ὁμώνυμον。印刷版は電子化と同じ）、29.19.5 の ὡραῖος ἦν（OCR は ἣν。印刷版は ἦν、0132_pct:5,5,92,25.png）、29.20.3 の κουφίζεται（OCR は κουφίξεται）、29.20.4 の λῃσταῖς περιπεσόντα（0132_pct:5,52,92,8.png）、29.20.8 の ἐξουσίαν ἔχει πάλιν λαβεῖν αὐτήν（0133_pct:5,52,92,8.png）、29.20.5 の Λάζαρος（OCR は Λάξαρος）、29.20.9 の ᾅδου（OCR は ὥδου。印刷版は ᾅδου、0134_pct:5,5,92,25.png）、29.21.1 の αἰνιγματισταῖς・ἀναγκαίως（OCR は αἰνυγματισταῖς・ἀνωγκαίως）は、印刷版が電子化と同じで、OCR の誤りだった。29.18.5 の ἐναπομένοις は、ほかの動詞（μάθῃς, συνεπαίρῃ, γινώσκῃς）が接続法なのに一つだけ希求法の形だが、印刷版もこの形で（0130_pct:5,5,92,25.png）、印刷版の校訂資料は写本 c の ἐναπομένης を別の読みとして挙げているので、誤植ではなく採られた読み。印刷版そのものの誤植は見つからなかった。
