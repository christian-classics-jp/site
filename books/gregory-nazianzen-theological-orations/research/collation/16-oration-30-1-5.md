関係代名詞 ἥν（印刷版は重アクセントの ἣν）を、電子化は 5 か所すべて ἢν（ἐάν の縮まった形「もし」）にしている。30.2.5 は、電子化のままだと「もし神がわたしたちのために人の性を引き受けたなら」と読めてしまうが、印刷版は「神がわたしたちのために引き受けた人の性（ἀνθρωπότητος, ἣν …）の原因は何か」。30.5.1 も、電子化では「もしあなたが子を父に従わせるなら」と読めるが、印刷版は「あなたが子を父に従わせる、その服従（τὴν ὑποταγήν, ἣν …）」。この二つは別の読みが立つので意味が変わるとした。30.4.2・30.4.6 の二つは前置詞（δι’、μεθ’）の後で、ἤν とは読めないので意味は変わらないとした。

30.4.6 は、電子化では ἀπολλύμενον· と μεθ’ ἣν ἵσταται のあいだに μένον ’ が入っている。印刷版のこの行（l. 16）は διαιρῶν τὸ σωζόμενον καὶ τὸ ἀπολλύμενον· μεθ’ ἣν ἵσταται で、間に語はない。μένον は μένω（とどまる）の分詞として読めてしまうので、意味が変わるとした（直前の ἀπολλύ-μενον の語尾が重なった残りとみられる）。

30.4.5 は、印刷版では βασιλεύεσθαι の後に句点があり、τῆς μὲν οὖν ἐκείνως νοουμένης βασιλείας οὐκ ἔσται πέρας で新しい文が始まる。電子化は句点が落ちていて、τῆς … βασιλείας が βασιλεύεσθαι（治められること）に続く属格のようにも読める。30.1.1 は、印刷版では εὐγνωμονεστέροις の後に中点（·）があり、続く分詞の句（τὰς μὲν ὑψηλοτέρας … προσνείμαντες）がそこで切れる。電子化は中点の代わりに気息記号の ῾ が入っている。

30.2.6 の δ と 30.5.4 の ὂ は、どちらも印刷版の ὃ。δ は語にならず、直前の ὃ μὲν との対で ὃ と知れるので、意味は変わらないとした。30.3.3 の εὐδοκία（主格）は、印刷版では ἐνεργείᾳ と対になる与格 εὐδοκίᾳ。30.1.1 と 30.5.3 の τῆ、30.3.1 の τούτω も下書きのイオタの欠け。30.5.6 の ἃν（ἃ ἄν の縮まった形の綴り）は印刷版では小辞の ἂν で、ここでは ἃ ἄν とは読めない。語の途中の空き（διακε- λεύεται、ἀνθρωπό- τητος）は、どちらも印刷版の行末のハイフンで、印刷版では一語。

語の変わらない違いとして、30.1.1 の καἰ（印刷版は καὶ）、30.2.6・30.2.7 の ἔκτισε・ἔκτισεν（印刷版は聖句の語として大文字の Ἔκτισε・Ἔκτισεν）、30.3.3 の χριστὸν（印刷版は Χριστὸν）は、表に入れなかった。句読点では、30.4.1 の ἄχρι τοῦδε καὶ（印刷版は τοῦδε, καὶ）、30.4.5 の καὶ θελόντων καὶ μή（印刷版は θελόντων, καὶ μή）は、文の切れ目が変わらないので入れなかった。

照合の候補のうち、30.1.1 の ἐπειγομένου（OCR は ἐπευγομένου。0137_pct:5,4,92,25_x2.png）、30.2.1 の λίαν（OCR は Mav）、30.4.6 の θεὸς（OCR は εὸς）、30.5.1 の θεὸς ὤν（OCR は ὦν。印刷版は ὤν、0142_pct:5,4,92,25_x2.png）、30.5.4 の Χριστοῦ（OCR は Νριστοῦ）、30.5.5 の εἶναί（OCR は εἷναι。0142_pct:5,50,92,10_x2.png）、30.5.7 の παρεωραμένοι（印刷版は行末で παρε-ωραμένοι と分けて一語。0143_pct:5,4,92,25_x2.png）は、印刷版が電子化と同じで、OCR の誤りだった。30.2.4〜30.2.6（τέθειται、σοφίας ὁ λόγος、τίς δὲ τῆς、πάντως ἡμᾶς）と 30.4.5〜30.4.6（ἔσται πέρας、χεῖρα καὶ σωζομένους）の削除・挿入の候補は、OCR が行頭の語を行番号や注解の行と一緒に別の位置に移したもので、印刷版の語順は電子化と同じ（0138_pct:5,4,92,25_x2.png、0138_pct:5,28,92,25_x2.png、0141_pct:5,28,92,25_x2.png）。30.5.3 の印刷版の αὐτὸς は、ο の活字が欠けて αὐτ’ς のように見える（0142_pct:5,28,92,25_x2.png）が、語は αὐτὸς で電子化と同じ。印刷版そのものの誤植は見つからなかった。
