# 17-oration-30-6-10 の電子化と印刷版の照合（30.6-30.10）

30.10.7 の Ἠὼς は「暁」（ἠώς）という別の語で、文が成り立たない。印刷版は疑問詞の Πῶς で、マタイ一二・三四 の Πῶς δύνασθε ἀγαθὰ λαλεῖν, πονηροὶ ὄντες; の引用。続く 30.10.8 の πῶς γὰρ ἀδύνατόν τι τούτων がこの Πῶς を受ける。Π が Ἠ に読み違えられたものとみて、意味が変わるとした。

30.6.9 の ὂ は、印刷版では関係代名詞の ὃ（重アクセント）。ὂ は語にならず、続く ἀλλαχοῦ σαφῶς περιορίζει の目的語として ὃ と知れるので、意味は変わらないとした。30.10.1 の βλέπη と 30.10.8 の τῆ は、下書きのイオタの欠け。30.6.7 の κατα- ληφθείημεν は印刷版の行末のハイフンで、印刷版では一語。30.7.3 の προσφιλονεικ[ῶν は、印刷版では行末で προσφιλο-νεικῶν と分けた一語で、角括弧はない。

語の変わらない違いとして、30.6.10 の Έλλην（印刷版は Ἕλλην）と ἁλλὰ（印刷版は ἀλλὰ）、30.10.7 の οἴδα（印刷版は οἶδα。0150_pct:5,24,92,22_x2.png）は、アクセントや気息だけの違いで別の語にならないので、表に入れなかった。30.8.1 の最初の οὐ τοῦ λόγου は、印刷版では大文字の Λόγου（0147_pct:5,24,92,22_x2.png）。語は変わらないので表には入れないが、Mason はここを御子の呼び名として大文字にしている（同じ節の後の τοῦ λόγου δέ は印刷版でも小文字。0148_pct:5,4,92,22_x2.png）。

照合の候補のうち、30.6.5 の διαθέσεως（OCR は διαθέτεως。印刷版の σ の活字がかすれている。0144_pdf.png）と 30.10.8 の θελήσαντος（OCR は θέλήσαντος。0150_pct:5,44,92,12_x2.png）は、印刷版が電子化と同じで、OCR の誤りだった。30.7.1 の μου καὶ θεὸν ὑμῶν、30.8.2 の ἡμῶν γὰρ κυρίως μὲν θεός, οὐ κυρίως δὲ πατήρ、30.8.4 の Χριστοῦ μὲν θεός と γνωριμώτερον、30.9.1〜9.2 の ἢ δόξαν … καὶ λόγῳ φύσεως、30.10.1 の Ἕκτον τιθέσθω … ἀφ’、30.10.7 の οἶδα の削除・挿入・置き換えの候補は、OCR が行頭の語を行番号や注解の行と一緒に別の位置に移したもの、または数字に読んだもので、印刷版の語と語順は電子化と同じ（0146_pct:5,24,92,22_x2.png、0148_pct:5,4,92,22_x2.png、0148_pct:5,24,92,22_x2.png、0149_pct:5,4,92,22_x2.png、0150_pct:5,24,92,22_x2.png）。30.7.5 の挿入 το と 30.10.2 の Kal το は、印刷版に対応する語がなく（0147_pct:5,24,92,22_x2.png、0149_pct:5,24,92,22_x2.png）、OCR の雑音だった。30.7.1 の τρίτον ἀρίθμει τό· μεῖζον· は、印刷版も μεῖζον（中性）で、電子化と同じ（0146_pct:5,24,92,22_x2.png）。印刷版そのものの誤植は見つからなかった。
