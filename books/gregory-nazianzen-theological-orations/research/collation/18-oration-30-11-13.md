30.13.3 の ἢ は「あるいは」だが、印刷版は関係代名詞の女性形 ἣ で、直前の τὴν ἀγαθότητα を受け、「善性、それはとりわけ神ただひとりのものである」となる。電子化の形では「あるいはとりわけ神ただひとりの」と、何と何を並べるのかわからない文になる。拡大すると、ここの気息記号は同じ版面の ὃ（0156_pct:26,50,5,2.5_x6.png）と同じく粗い気息の形で、滑らかな気息の ἢ（0156_pct:9,47,6,2.5_x6.png）とは向きが逆。OCR も ἣ と読んでいる。そのため意味が変わるとした。

30.11.1・30.11.3・30.13.2 の ὂ と 30.12.5 の ἂς は、どれも印刷版では関係代名詞の ὃ・ἃς（気息の違い）。ὂ・ἂς という語はなく、構文から関係代名詞と知れるので、意味は変わらないとした。30.13.9 の ἃν（ἃ ἄν の縮まった形の綴り）は、印刷版では小辞の ἂν で、τί ἂν … γένοιτο の構文からは小辞としか読めない。語の途中の空き（χειραγω- γουμένους、οἰκειό- τερον）は、どちらも印刷版の行末のハイフンで、印刷版では一語。

語の変わらない違いとして、30.11.4 の ἁληθείας（印刷版は ἀληθείας）、30.11.9・30.12.1・30.13.4 の ἁλλὰ と 30.12.5 の ἁλλ’（印刷版は ἀλλὰ・ἀλλ’）、30.13.1 の ἂγαθός（印刷版は ἀγαθός。0156_pct:5,24,92,22_x2.png）は、気息やアクセントだけの違いで別の語にならないので、表に入れなかった。30.12.4 の ἵν ᾖ は、印刷版では省略符の付いた ἵν’ ᾖ（0154_pct:5,24,92,22_x2.png）。大文字の違いとして、30.13.1・30.13.4 の χριστόν（印刷版は Χριστόν）、30.13.2 の τῷ μόνῳ σοφῷ θεῷ, ἢ τῷ μόνῳ ἔχοντι（印刷版は引用の始まりとして二か所とも Τῷ。0156_pct:5,24,92,22_x2.png）、30.13.5 の δώσω（印刷版は Δώσω。0157_pct:5,24,92,22_x2.png）がある。

照合の候補のうち、30.11.4・30.11.5 の ἆρα と 30.12.7 の ἆρ’（OCR は ρα・ἄρα・ἄρ’）は、印刷版も疑問の ἆρα・ἆρ’ で、電子化と同じ（0152_pct:5,4,92,22_x2.png、0155_pct:5,24,92,22_x2.png）。30.13.4 の ἀντιδιῄρητο（OCR は ἀντιδιήρητο）と 30.13.5 の οὓς（OCR は ods）も、印刷版は電子化と同じ（0157_pct:5,4,92,22_x2.png、0157_pct:5,24,92,22_x2.png）。30.11.2 の οὐδὲν οὖν ἴδιον, ὅτι κοινά と 30.13.9 の δι’ ὧν τοῦ υἱοῦ κατεσπουδάσαμεν の削除・挿入の候補は、OCR が行を注解の行と一緒に別の位置に移したもので、印刷版の語順は電子化と同じ（0151_pct:5,24,92,22_x2.png、0158_pct:5,4,92,22_x2.png）。30.13.2 の καὶ πάντῃ ῥᾴστην ἔχειν τὴν λύσιν μοι φαίνεται. εἰ γὰρ τὸ の置き換えの候補は OCR がこの行を読み落としたもので、印刷版にこの語句はある（0156_pct:5,24,92,22_x2.png）。そのほかの挿入（Z / Φ、ς、/ 6、ΕΝ ᾿ など）は印刷版に対応する語がなく、OCR の雑音だった。30.12.6 の εἴτουν ἀποκαταστάσεως は、印刷版では行末で ἀπο-καταστάσεως と分けた一語。印刷版そのものの誤植は見つからなかった。
