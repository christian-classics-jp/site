30.14.4 の ἢ は「あるいは」だが、印刷版は気息だけで重音のない冠詞の ἡ で、「これが、わたしには弁護（παράκλησις）の意味と思われる」となる。電子化の形では主語の冠詞が「あるいは」に変わり、文が成り立たない。30.18.2 も同じく、印刷版は冠詞の ἡ（直前の κλῆσις を受けて「『神』という呼び名は」）で、電子化の ἢ では文の主語がなくなる。30.18.3 の ἢν は ἐάν の縮まった形（「もし」）と同じ綴りになるが、印刷版は ἦν（「あった」）で、οὐ γὰρ ἦν, ἢ ἔσται で「かつてあった、あるいはこれからある、ということがないので」となる。どれも拡大して、気息とアクセントの形を確かめた。

30.15.2 の ο οὐτῶ τὰ του と 30.18.1 の ’Ο は、印刷版では冠詞の ὁ・Ὁ に粗い気息があり、οὕτω・τοῦ のアクセントもある。ο・οὐτῶ・’Ο（滑らかな気息の Ὀ）という語はなく、構文から冠詞と副詞と知れるので、意味は変わらないとした。

語の変わらない違いとして、30.14.1 の Ἐννατον（印刷版は Ἔννατον）、30.14.1 と 30.18.1 の πὼς（印刷版は πως）、30.14.1 と 30.17.3 の ἁλλὰ・ἁλλ’（印刷版は ἀλλὰ・ἀλλ’）、30.14.3 の καἲ と 30.15.4 の καἰ（印刷版は καὶ）、30.15.1 の μεταποιητης（印刷版は μεταποιητής）、30.15.4 の τῳ υἱῷ（印刷版は τῷ υἱῷ）、30.16.5 の αθεωρήτους（印刷版は ἀθεωρήτους）、30.17.1 の Ἐβραίων（印刷版は Ἑβραίων）、30.17.3 の ἁληθείας（印刷版は ἀληθείας）、30.18.1 の εὐρίσκομεν（印刷版は εὑρίσκομεν）、30.18.2 の μοχθῇρῶν（印刷版は μοχθηρῶν。0164_pdf.png）は、気息やアクセント（μοχθῇρῶν は下書きのイオタも）だけの違いで別の語にならないので、表に入れなかった。大文字の違いとして、30.14.2 の χριστός（印刷版は Χριστός。0158_pdf.png）、30.18.2 の ἡ κύριος φωνή と 30.18.3 の καί, κύριος ὄνομα αὐτῷ（印刷版はどちらも Κύριος。0164_pdf.png）がある。

照合の候補のうち、30.18.1 の ἥ τίς ποτε εἴη と 30.18.3 の ᾗ τὸ εἶναι、τὸ δὲ ὂν は、印刷版も電子化と同じ（0164_pct:5,11.5,92,5.5_x2.png、0164_pct:5,36,92,5_x2.png、0164_pct:5,39.5,92,3_x2.png。OCR の ὃν は誤り）。30.17.1 の λυομένῃ（OCR は λυομένη）、30.17.3 の ὅ τι（OCR は ὃ）、30.18.1 の ὁ μὲν ὤν（OCR は ὧν）も、印刷版は電子化と同じ（0163_pdf.png）。30.14.1 の συνήθεια, τὸ ζητεῖν ἐκδίκησιν ἔχει· τοῦτο γάρ πως καὶ、30.14.3〜4 の καὶ προσπίπτοντα δουλικῶς と οὔτε γὰρ τοῦ πατρὸς、30.16.5 の ὁ μὲν、30.18.1 の ὁ θεός、30.18.3 の αὐτῷ と ἦν, ἢ ἔσται … の削除・置き換え・挿入の候補は、OCR が語句を読み落としたか、注解の行と一緒に別の位置に移したもので、印刷版の語と語順は電子化と同じ（0158_pdf.png、0159_pdf.png、0162_pdf.png、0164_pdf.png、0165_pdf.png）。そのほかの候補（Kal・TO・yap などのラテン文字化、χε / ς 7、a Ξ / % などの挿入）は OCR の誤りと雑音で、印刷版は電子化と同じだった。印刷版そのものの誤植は見つからなかった。
