30.20.9 の ἢ（「あるいは／より」）は、印刷版では冠詞の ἡ で、「単純なものの本性（ἡ τῶν ἁπλῶν φύσις）はこのようなものである」となる。電子化の形では文の主語の冠詞が消え、直後の ἢ ἀφομοίωμα（「似姿よりも」）の比較の ἢ とも紛れる。30.20.1 の ’ は、印刷版では上付きの点で、「本質において御父と同じものだから」と「それだけでなく、そこから出たものでもある」との切れ目になっている。

30.20.3・30.20.11・30.21.8 の ἃν（ἃ ἄν の縮まった形の綴り）は、印刷版ではどれも小辞の ἂν で、εἴποι・ἀνοίξωμεν・σφαλείης の構文からは小辞としか読めない。30.21.1 の ἂ は、印刷版では関係代名詞の ἃ（気息の違い）。ἂ という語はなく、続く δὲ ἰδίως ἡμέτερα から関係代名詞と知れる。30.21.1 の λύση は下書きのイオタの欠けで、印刷版は ἵνα の下の接続法 λύσῃ（拡大して下書きのイオタを確かめた）。30.20.4 の κότος は、直前の γεγεννηκότος の語尾が重なって入ったもので、印刷版にはない（印刷版は τοῦ で行が終わり、次の行が γεγεννηκότος で始まる。ハイフンはない）。30.20.11 の ἅγ ἴον は、印刷版では行の途中にある一語の ἅγιον。30.21.2 の Ἀδάμα は余分な α の付いた形で、印刷版は Ἀδάμ。どれも語にならない形か、構文から本来の語と知れるので、意味は変わらないとした。

語の変わらない違いとして、30.20.2 の ἁλλὰ（印刷版は ἀλλὰ）、30.20.6 の ἁλήθεια（印刷版は ἀλήθεια）、30.21.1 の καἰ（印刷版は καὶ）は、気息やアクセントだけの違いで別の語にならないので、表に入れなかった。大文字の違いとして、30.21.5 の τὴν γὰρ γενεὰν（印刷版は Τὴν。0171_pdf.png）、30.21.8 の Ἰησοῦς χριστός（印刷版は Χριστός。0172_pdf.png）がある。30.19.4 の προιόντος と 30.21.7 の θεικῶς は、印刷版も分音符のない同じ綴り（0166_pdf.png、0171_pdf.png）。

照合の候補のうち、30.20.1 の ὅτι ταὐτόν（OCR は ὅτε）、30.20.5 の δύναμις（OCR は δύναμὲς。印刷版は δύνα-μις と行をまたぐ）、30.20.12 の ψυχῇ（OCR は ψυχῆ）、30.21.7 の γένῃ（OCR は γένη。印刷版にも下書きのイオタがある。0171_pct:5,42,92,6_x2.png）は、印刷版も電子化と同じ（0166_pdf.png、0167_pdf.png、0169_pdf.png）。30.19.2、30.19.5、30.20.2〜4、30.20.6〜7、30.21.4〜6、30.21.8 の削除・置き換え・挿入の候補は、OCR が語句を読み落としたか、注解の行と一緒に別の位置に移したもので、印刷版の語と語順は電子化と同じ（0165_pdf.png〜0172_pdf.png）。そのほかの候補（Kal・TO・yap などのラテン文字化、/ \ ¢€ などの挿入、上付きの点の : や ᾿ への崩れ）は OCR の誤りと雑音で、印刷版は電子化と同じだった。印刷版そのものの誤植は見つからなかった。
