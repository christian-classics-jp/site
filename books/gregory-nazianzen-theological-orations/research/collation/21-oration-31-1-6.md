31.3.4 では、電子化は聖霊について言う三つ目の句から πάντα を落としている。印刷版では πάντα が行末にあり、次の行が ἄνθρωπον で始まる（ハイフンはない）。印刷版の句は、父・子について言う前の二つと同じく、ヨハネ一・九 の「すべての人を照らす」のままである。電子化の形では、聖霊だけが「人を照らす」となり、三つを同じ言葉で言うという 31.3.2 の宣言（τὰς αὐτὰς τῇ τριάδι φωνὰς ἐφαρμόζοντες）からも外れる。31.3.5 では、電子化は動詞 ἐφαντάσθη を落としている。印刷版は「このことを、ダビデもかつて幻に見て、こう言いました」で、異読の欄にも προτερον εφαντασθη dg（語順の違い）とあって、本文に ἐφαντάσθη があることが確かめられる。電子化の形では関係節 ὃ καὶ Δαβὶδ πρότερον に動詞がなく、「幻に見た」という語が訳から消える。

31.3.4・31.4.2・31.4.5 の ἢν は、印刷版ではどれも ἦν（「あった」）。ἢν は条件の ἤν（＝ἐάν）の綴りになるが、31.3.4 は ἦν, καὶ ἦν, καὶ ἦν の繰り返しの中、31.4.2 と 31.4.5 は εἰ … ἦν の条件文の中で、どれも構文から ἦν としか読めない。31.2.2 の οἲ と 31.3.6 の ὂ は気息の違いで、印刷版は関係代名詞の οἳ と ὃ（οἲ・ὂ という語はない）。31.2.2 の γραφῆ は下書きのイオタの欠けで、印刷版は παρά に続く与格の γραφῇ。31.5.5 の οὐσία も下書きのイオタの欠けで、印刷版は与格の οὐσίᾳ。続く δυνάμει と、同じ節の δυνάμει μέν, οὐκ οὐσίᾳ δέ と同じ与格である。31.5.1 の Μαλλὸν は μαλλός（羊毛の房）の対格の綴りになるが、印刷版は副詞の Μᾶλλον で、続く δὲ からもそう読める。31.4.1 と 31.4.3 の ἅγ ἴον は、印刷版では行の途中にある一語の ἅγιον。どれも語にならない形か、構文から本来の語と知れるので、意味は変わらないとした。31.4.4 の ’ は、印刷版では上付きの点で、「聖さはこの聖霊とは別のものなのか」という問いと、挟み込んだ「それが何と考えられているのか、だれか言ってほしい」との切れ目になっている。

語の変わらない違いとして、31.4.3 の λείπει δέ πὼς と 31.5.4 の μέσως πὼς（印刷版はどちらも無アクセントの πως。0177_pct:5,21,92,6_x2.png、0178_pdf.png）は、不定の小辞のアクセントだけの違いで別の語にならないので、表に入れなかった。31.4.4 の καὶ ἥ τις（OCR は ἢ）と 31.4.5 の ἄμεινον ὂν（OCR は ὃν）は、印刷版も電子化と同じ（0177_pct:50,23.5,40,2.8_x4.png、0177_pdf.png）。

照合の候補のうち、31.1.1 の冒頭 30 語、31.2.1〜2.2、31.3.1、31.3.3、31.3.5〜3.6、31.4.1〜4.5、31.5.1、31.5.5、31.6.3〜6.6 の削除・置き換え・挿入の候補（31.4.2 の ἓν κάτω と θῇς ἄνω、31.4.5 の καὶ δίχα πνεύματος と χρόνῳ γὰρ ἀπὸ θεοῦ、31.6.3 の ἐνεργηθήσεται δῆλον ὅτι 以下、31.6.5 の τραγελάφους 以下、31.6.6 の τὸ μὲν γάρ 以下など）は、OCR が語句を読み落としたか、注解や異読の欄の行と一緒に別の位置に移したもので、印刷版の語と語順は電子化と同じ（0173_pdf.png〜0180_pdf.png）。31.3.3 の繰り返しの句の位置のずれ（OCR の πατήρ . κόσμον , ὁ）も OCR の行の崩れで、印刷版は電子化と同じ。そのほかの候補（Kal・TO・TOD・yap・Noyous などのラテン文字化、31.6.1 の “ἄλλησιν、31.5.2 の μῶνλον、31.5.5 の περυγραπτόν などの文字の崩れ、/ \ > などの挿入、上付きの点の : や ᾿ への崩れ）は OCR の誤りと雑音で、印刷版は電子化と同じだった。印刷版そのものの誤植は見つからなかった。
