31.10.6 では、電子化は φιλοτιμίᾳ を二度書き、その代わりに φύσεως と後ろの句点を落としている。印刷版は「生き物が別の生き物へ移り変わり、作り変えられる。自然の熱心さによって」で、φιλοτιμίᾳ φύσεως が一つの句である。注解の欄にも φιλοτιμίᾳ φ.] 'in nature's eagerness to excel' とあり、31.10.4 の ἡ φύσις ἐφιλοτεχνήσατο を引いている。電子化の形では「自然」という語が訳から消え、続く ἤδη δὲ の文との切れ目もなくなる。

31.10.2 の εἰς は前置詞「〜へ」の綴りになるが、印刷版は数詞の εἷς（「一つの」）で、異読の欄にも εις θεος μια φυσις とある。後ろの θεὸς は主格で、前置詞の εἰς とは結びつかないので、構文から εἷς としか読めず、意味は変わらないとした。31.7.5・31.9.1・31.10.4 の ἃν（ἃ ἄν の縮まった形の綴り）は、印刷版ではどれも小辞の ἂν で、ὑπολάβοις・ἦν・ἔχων の構文からは小辞としか読めない。31.7.3 の ἂγ ἀθ’ ἁ は、印刷版では行の途中にある一語の ἀγαθὰ。31.9.1 の ἵν は省略符の欠け。31.7.1 と 31.7.2 の ’ は、印刷版では上付きの点で、31.7.1 では「さあ、あなたの番だ」と「石投げ紐を放て」との切れ目、31.7.2 では「兄と弟だと作り上げてもよい」と「あなたはあまりに肉体にとらわれているのだから」との切れ目になっている。31.8.2 の句点は、印刷版では読点で、「どこに置くのか、言ってみよ、行き出るものを」は一つの問いである。電子化の句点では問いが ἐκπορευτόν で切れ、εἰπέ μοι 以下が離れる。

語の変わらない違いとして、31.7.1 の Ἑνταῦθα（印刷版は Ἐνταῦθα。0181_pct:5,8,92,4_x2.png）、31.10.3 の ἁλλὰ（印刷版は ἀλλὰ）、31.10.6 の πὼς（二か所。印刷版は前接語の πως。0186_pct:5,8,92,5_x2.png、0186_pdf.png）は、気息やアクセントだけの違いで別の語にならないので、表に入れなかった。31.10.2 の Φύσιν、31.10.3 の Φησιν、31.10.4 の Φύσις は、印刷版では小文字の φ で、表に入れなかった。31.10.3 の Ἠσαίας は、印刷版では固有名の気息の違いだけで、表に入れなかった。31.9.1 の διάφορον διάφορον は、印刷版も同じ繰り返しで（0183_pct:5,38,92,9_x2.png）、異読の欄に om διαφορον sec. loco e とある。31.9.4 の Σαβέλλιον ᾖ（OCR は ἢ）は、印刷版も電子化と同じ ᾖ（0184_pct:5,29,92,4.5_x2.png）。31.10.1 の δὸς οὖν μοί, φησιν の μοί も、印刷版と同じ（0184_pct:5,36,92,4_x2.png）。

照合の候補のうち、31.7.1 の καὶ εἰ μὲν ἀγέννητον, δύο τὰ ἄναρχα、31.7.5 の ἢ τάχα ἂν、31.10.1 の τί οὖν, ὁμοούσιον; εἴπερ θεός、31.10.2〜10.3 の ὀνομάτων τε καὶ πραγμάτων、31.10.7 の ἐφ’ ἕτερον μεταβήσομαι λόγον などの削除・置き換え・挿入の候補は、OCR が語句を読み落としたか、注解や異読の欄の行と一緒に別の位置に移したもので、印刷版の語と語順は電子化と同じ（0181_pdf.png〜0186_pdf.png）。そのほかの候補（Kal・TO・TOV・yap・vids などのラテン文字化、/ \ > などの挿入、上付きの点の : や ᾿ への崩れ）は OCR の誤りと雑音で、印刷版は電子化と同じだった。印刷版そのものの誤植は見つからなかった。
