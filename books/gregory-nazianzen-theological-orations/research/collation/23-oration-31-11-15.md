31.11.1 では、電子化は ἀμφοτέρων を落としている。印刷版は「セツは何か。両者から生まれたものだ」で、アダム（形づくられたもの）とエバ（その切り取られた部分）に対して、セツが二人の子であることを言う。電子化の形では「生まれたもの」とだけなり、だれから生まれたのかが消える。31.11.4 の ὁ は冠詞の欠けで、問いの意味は変わらない。31.11.6 の οἶ μαί は、印刷版では行の途中にある一語の οἶμαί。31.13.1 と 31.15.4 の τῆ は下書きのイオタの欠けで、印刷版はどちらも与格の τῇ。

語の変わらない違いとして、31.11.4 の Eὖα は頭の E がラテン文字（31.11.1 の Εὖα はギリシア文字）で、印刷版は Εὖα。31.11.5 と 31.12.3 の καἰ（印刷版は καὶ）、31.12.3 の ἁλλ’（印刷版は ἀλλ’）、31.13.2 の πὼς（印刷版は前接語の πως。0189_pdf.png）、31.13.6 の γενναιοτερον（印刷版は γενναιότερον。0190_pdf.png）、31.14.2 の ἦττον（印刷版は ἧττον と読めるが、拡大しても気息は確かめにくい。0190_pct:5,44,92,4.5_x2.png）は、気息やアクセントだけの違いで別の語にならないので、表に入れなかった。31.13.5 の διθείασ と 31.13.6 の τριθείασ は語末の σ の字形の違いで、印刷版は διθείας・τριθείας。31.14.2 の μερίζεται,, は読点の重なりで、印刷版は読点一つ（0190_pdf.png）。31.12.7 と 31.12.8 の χριστοῦ は、印刷版では大文字の Χριστοῦ（0188_pdf.png）。31.12.9 の καθῃρηκώς は、印刷版では下書きのイオタのない καθηρηκώς（0189_pdf.png）で、同じ語の綴りの違い。

印刷版そのものの誤植として、31.15.4 の καὶ πρὸς τὸ καλὸν の πρὸς が、印刷版ではアクセントのない προς になっている（0192_pct:5,25.5,92,4.5_x2.png）。語は変わらないので表に入れなかった。電子化は πρὸς で、正しい形になっている。

照合の候補のうち、31.11.2〜11.3 の ἐπὶ δὲ τούτων θεωρῶν と οὐδὲ γὰρ οἷόν τε の順序、31.12.4 の νοί τοῦτ’、31.14.2 の οὐδέ τι、31.15.2〜15.3 の πάθεσι καὶ τῇ δυνάμει μεμερισμένα、31.15.4 の τὸ ἄκρον καλὸν ἐγγύτητι などの削除・置き換え・挿入の候補は、OCR が語句を読み落としたか、注解や異読の欄の行と一緒に別の位置に移したもの、あるいは OCR の範囲の終わりで切れたもので、印刷版の語と語順は電子化と同じ（0186_pdf.png〜0192_pdf.png）。31.12.9 の θῇς（OCR は Ons）と ἔσῃ（OCR は Eon）も、印刷版は電子化と同じ。そのほかの候補（Kal・TO・TOV・yap などのラテン文字化、/ \ > などの挿入、上付きの点の " や ᾿ への崩れ）は OCR の誤りと雑音で、印刷版は電子化と同じだった。
