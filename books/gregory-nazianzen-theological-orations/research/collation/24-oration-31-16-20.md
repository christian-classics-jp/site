31.18.1 では、電子化は ὑποκειμένων の前に ὕπο κε（語の書きかけ）を、後に μέν ὢν を余分に入れている。印刷版は「数はすべて、基にある物の量を示すもので、物の本性を示すものではない」で、μέν ὢν があると分詞が一つ増えて文の組み立てが崩れる。31.19.2 では、電子化は冠詞の ἡ を接続詞の ἢ（「あるいは」）にしている。印刷版は「では、何を代わりに渡すのか」で、Mason の注もこの句を τίς γὰρ ἡ ἀντίδοσις; として引く（0196_pdf.png）。31.17.3 の ο は気息のない字で、印刷版は冠詞の ὁ。31.18.1 の δουματιστῶν は γ を υ にした綴りの誤りで、そのような語はない。31.18.2 の οὐσία は下書きのイオタが欠けて主格の形になっているが、印刷版は τῇ と合う与格の οὐσίᾳ。31.18.3 の τῆ は下書きのイオタの欠けで、印刷版は与格の τῇ。31.18.5 の ἃν は荒い気息で、ἃ ἄν の縮約と同じ形になる。印刷版は滑らかな気息の小辞 ἂν。

語の変わらない違いとして、31.17.1 の συναριθμεῖταl は語末の ι がラテン文字の l になっている（印刷版は συναριθμεῖταί。0193_pdf.png）。31.16.2 の διῃρημένους と 31.18.3 の διῃρημένας は、印刷版では下書きのイオタのない διηρημένους・διηρημένας（0193_pdf.png、0195_pdf.png）で、同じ語の綴りの違い。31.17.3 の κἄν（印刷版は κἂν。0194_pct:5,24,92,14_x2.png）、31.18.3 の ἁλεκτρυών（印刷版は ἀλεκτρυών。0195_pdf.png）、31.20.6 の ἁλλὰ（印刷版は ἀλλὰ。0198_pdf.png）は、気息やアクセントだけの違いで別の語にならないので、表に入れなかった。31.19.4 の οὐσίασ は語末の σ の字形の違いで、印刷版は οὐσίας。

印刷版そのものの誤植として、31.17.2 の ἵνα γὰρ μὴ κάμῃς の κάμῃς が、印刷版では下書きのイオタのない κάμης になっている（0194_pct:5,19,92,6_x2.png）。ἵνα に続く接続法なので κάμῃς が正しく、電子化は正しい形になっている。別の語にはならないので表に入れなかった。

照合の候補のうち、31.16.4 の εἰ μὲν οὖν οὗτος ἰσχυρὸς、31.17.2〜17.3 の τοῖς ἐχθροῖς τὸ ζητούμενον と προήσομαι τὸ προσκυνούμενον、31.19.1 の τάδε καὶ τάδε、31.19.2 の ἐπεὶ κἀμοὶ Πέτρος などの削除・置き換えの候補は、OCR が語句を注解や異読の欄の行と一緒に別の位置に移したもので、印刷版の語と語順は電子化と同じ（0193_pdf.png〜0196_pdf.png）。31.20.1 の τὸ ἓν（OCR は ὃν）、31.19.8 の ἆρα（OCR は apa。0197_pct:50,15.5,48,4.5_x2.png）、31.20.6 の ὑπολάβῃς（0198_pct:5,49.5,92,5_x2.png）も、印刷版は電子化と同じ。そのほかの候補（Kal・TO・TOV・yap などのラテン文字化、/ \ > などの挿入、上付きの点の ᾿ への崩れ）は OCR の誤りと雑音で、印刷版は電子化と同じだった。
