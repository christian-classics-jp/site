31.21.2 と 31.22.2 の τῆ は下書きのイオタの欠けで、印刷版はどちらも与格の τῇ（31.21.2 は παρά に続き、31.22.2 は続く γραφῇ と合う）。31.23.2 の εἰ μί’ は、印刷版では行の途中にある一語の εἰμι（イザヤ四四・六 の引用で、Mason の注も ἐγώ εἰμι πρῶτος と引く。0202_pdf.png）。電子化の形では条件の εἰ と語にならない μί’ に割れるが、続く πρῶτος と引用の形から εἰμι と知れる。31.24.5 の ἐπικρύψεψς は語末の ω を ψ にした綴りの誤りで、そのような語はない。どれも語にならない形か、構文から本来の語と知れるので、意味は変わらないとした。

語の変わらない違いとして、31.21.2 の καἰ（印刷版は καὶ。0199_pct:5,25,92,6_x2.png）は気息の記号の誤りで、別の語にならないので表に入れなかった。31.24.1 の Ἰουδαικῆς は、印刷版も分音記号のない ᾿Ιουδαικῆς（0203_pdf.png）で、電子化は印刷版どおり。

照合の候補のうち、31.22.3 の ὂν（OCR は ὃν）は、印刷版も分詞の ὂν で、電子化と同じ（0200_pct:5,15,92,11_x2.png）。31.24.4 の ᾐδέσθης（OCR は ἠδέσθης）も、印刷版は下書きのイオタのある ᾐδέσθης（0203_pct:5,47,92,4_x2.png）。31.24.2 の ἆρα（OCR は dpa。0203_pct:5,19,92,6_x2.png）、31.23.5 の τοσοῦτόν と συλλογισμοί（0202_pdf.png）も、印刷版は電子化と同じ。31.21.1〜21.2 の φωτισμῷ τῆς γνώσεως κατηυγάσθησαν、31.22.3 の τὸ μὲν ἠρεμεῖν の τὸ、31.22.4〜22.5 の τὸ δὲ ἀθρόως εὖ ποιεῖν ἐκ、31.22.6 の καὶ τοῦτο ἡμέτερον. οὐδενὶ、31.23.2〜23.3 の οὐκ ἔσται.、31.24.4 の οὕτω μὲν οὖν στησόμεθα と σοὶ γὰρ οὐδὲ などの削除・挿入の候補は、OCR が語句を別の行に移したか落としたもので、印刷版の語と語順は電子化と同じ（0199_pdf.png〜0203_pdf.png）。そのほかの候補（Kal・TO・TOV・yap・THY などのラテン文字化、/ \ > などの挿入、上付きの点の ᾿ や " への崩れ、異読の欄と注解の行の混入）は OCR の誤りと雑音で、印刷版は電子化と同じだった。
