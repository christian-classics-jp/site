31.25.3 は、印刷版では ἀναγκαῖον のあとに終止符があり、「なぜか。知っておかねばならない。強いられるのではなく、納得するためである」と、ἵνα 以下が問い τίνος ἕνεκεν への答えになる。電子化の形では「強いられないために知っておく必要がある」と、ἵνα 以下が εἰδέναι にかかる。31.26.1 と 31.28.3 の ἢ（「あるいは」）は、印刷版ではどちらも冠詞の ἡ で、前の ἡ μετάθεσις や ἡ ἀναγέννησις と対になる。31.27.1 の ἢν は、印刷版では τάξιν を受ける関係代名詞の ἣν（Mason の注も「τάξιν は ὁρᾷς の目的語」と説く。0208_pdf.png）。これら三つは電子化の形でも別の語として読めるので、意味が変わるとした（30.2.5・30.5.1 の ἢν、30.18.2 の ἢ と同じ扱い）。31.25.4 の ἐξουσίς は語にならない綴りで、31.26.3 の τροφῆ と 31.26.4 の τῆ は下書きのイオタの欠け（続く τῇ や τῶν δεχομένων δυνάμει と合う与格）なので、意味は変わらないとした。

語の変わらない違いとして、31.26.3 の ἵν εἴπω は、印刷版では省略の記号のある ἵν’ εἴπω（0206_pct:5,29.5,92,5_x2.png）。記号が欠けているだけで語は変わらないので、表に入れなかった。

照合の候補のうち、31.25.3〜25.4 の ὥσπερ ἃ βίᾳ κατέχεται τῶν、τὸ δὲ ἑκούσιον μονιμώτερόν τε、τοῦ βιασαμένου, τὸ δὲ、31.25.6 の λέγω δὲ τί; ἡ、31.27.1〜27.2 の ἀθρόως ἐκφαίνοντας, μήτε εἰς τέλος κρύπτοντας などの削除・挿入の候補は、OCR が語句を別の行に移したもので、印刷版の語と語順は電子化と同じ（0204_pdf.png、0205_pdf.png、0208_pdf.png）。31.28.3 の ἀξίας τοῦ ἀναπλάσαντος. は OCR の範囲の次の行（l. 21439）にあり、印刷版にもある（0210_pdf.png）。31.26.3 の Δαβίξ（印刷版は Δαβίδ）、31.27.3 の τυγχατούσης（印刷版は τυγχανούσης）、31.25.3 の πεισθώμεν、31.25.6 の ῥάστη（印刷版は ῥᾴστη）、31.25.2 の πρωτῃ（印刷版は πρώτῃ）、31.27.1 の ἣν（電子化の誤りは上の表）、31.28.3 の ἕν（印刷版は ἓν）は OCR の誤りで、印刷版は電子化と同じだった（0204_pdf.png〜0209_pdf.png）。31.28.1 の ὅς τις（2 か所）と 31.28.2 の οὐδὲ προσκυνητόν も、印刷版どおり（0209_pdf.png。Mason の注も οὐδὲ προσκ. と引く）。そのほかの候補（Kal・TO・TOV・yap・THY・TPOTKUYNTOY などのラテン文字化、/ \ > などの挿入、上付きの点の ᾿ や " への崩れ、異読の欄と注解の行の混入）は OCR の誤りと雑音で、印刷版は電子化と同じだった。
