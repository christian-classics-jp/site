31.29.1 は、電子化では主動詞の ἐπιδειχθήσεται（「示されるだろう」）が抜け、ἐξ ὧν 以下の文が動詞を欠く。印刷版では行末で ἐπιδειχθή-σεται と分けて組まれている。31.29.4 の ἀληθείας（「真理の霊」）も、電子化で一語が抜けている（Mason の注も ἀληθείας, John xiv 17 と引く。0211_pdf.png）。31.30.1 の γε は、電子化で抜けている。印刷版の πρός γε は副詞で「そのうえ」（Mason の注も「πρός γε] adv. 'besides'」と説く。0213_pdf.png）。γε がないと πρός が ἄλλον παράκλητον を受ける前置詞にも読める。31.30.2 の εἰ（「もし」）は、印刷版では εἶ（「あなたは〜である」）で、「あなたはまったく鈍い人だ」となる。31.29.3 の ἦ は、印刷版では ἵνα に続く接続法の ᾖ。31.32.2 と 31.33.4 の ἢν は、印刷版ではどちらも関係代名詞の ἣν。ἦ と ἢν は電子化の形でも別の語として読めるので、意味が変わるとした（31.26.1・31.27.1 の ἢ・ἢν と同じ扱い）。31.29.3 の τῆ と 31.31.2 の ἔχη は下書きのイオタの欠けで、31.29.4 の αυνέχον と συνεχόμενον の重複は語にならない綴りや同じ語の繰り返しなので、意味は変わらないとした。

31.29.4 の φοβοῦ θεοῦ は、印刷版も φοβοῦ と組まれていて、電子化はそれを写している。並びは πνεῦμα σοφίας, συνέσεως, ... εὐσεβείας に続く属格（イザヤ書 11 章 2 節の「主を畏れる霊」）なので、意図された形は名詞の φόβου。φοβοῦ は動詞の命令形（「恐れよ」）になる。

語の変わらない違いとして、31.33.1 の ἵν ᾖ は、印刷版では省略の記号のある ἵν’ ᾖ（0217_pdf.png）。31.32.1 の ἁλλὰ は印刷版では ἀλλὰ、31.29.4 の οἴμαι は οἶμαι、31.31.3 の πὼς は πως（0212_pdf.png、0215_pdf.png）。31.29.4 の πνεῦμα χριστοῦ は印刷版では大文字の Χριστοῦ（0211_pct:5,10.5,92,4_x2.png）。印刷版には、31.29.4 の αὐτεξούσιον, καὶ ἀναλλοίωτον と 31.32.1 の οὐσιώδεις,—καὶ ἅμα にコンマがあり、電子化にはない（0213_pdf.png、0216_pdf.png）。どれも記号、アクセント、大文字の違いや、意味の切れ目を変えないコンマで、語は変わらないので、表に入れなかった。

照合の候補のうち、31.29.2 の τί γὰρ οὐ δύναται τῶν、31.31.1 の Ὡς ἔγωγε πολλὰ διασκεψάμενος πρὸς ἐμαυτὸν、31.32.1 の ἀτοπώτερον、31.33.1 の Ἀλλ’ οὐδὲ τοῦτο θέσθαι δυνατὸν ἐμοί, δι’ ἓν μέν などの削除・挿入の候補は、OCR が語句を別の行に移したもので、印刷版の語と語順は電子化と同じ（0210_pdf.png、0214_pdf.png、0216_pdf.png、0217_pdf.png）。31.29.4 の μετεχό- τὸ μενον の τὸ と、31.32.2 の ἐγένετο. のあとの終止符は OCR の雑音で、印刷版にはない（0211_pdf.png、0217_pdf.png）。31.29.4 の「ον So」（印刷版は δυνάμεων, ὥσπερ）、31.30.3 の Kal ἕκαστον（印刷版は καθ’ ἕκαστον）、31.31.2 の ἄλλου（印刷版は ἄλλοι）、31.29.3 の ἢ Tapa（印刷版は ᾖ παρὰ。電子化の誤りは上の表）、31.29.3 の ἀγούση（印刷版は ἀγούσῃ）、31.31.3 と 31.32.3 の ἕν・EV（印刷版は ἓν）は OCR の誤りで、印刷版は電子化と同じだった（0210_pdf.png〜0217_pdf.png）。そのほかの候補（Kal・TO・TOV・yap・TH・iva・Apecavas などのラテン文字化、/ \ > などの挿入、上付きの点の ᾿ や " への崩れ、異読の欄と注解の行の混入）は OCR の誤りと雑音で、印刷版は電子化と同じだった。
