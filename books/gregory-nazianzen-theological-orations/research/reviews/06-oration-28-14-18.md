- 決めたこと（論点一覧の「メインで決めること」）：
  - λόγος：16.1 と 16.6 の、わたしたちを導く ὁ λόγος は Mason の注に従い「理性」。御子とは取らない。17.2 の νοῦν τε καὶ λόγον は「知性と理性」。宇宙に置かれた λόγος（16.4、16.5）は「理法」。訳語表に行を足した。
  - 16.6 の πρῶτος ἐν ἡμῖν νόμος は、28.6.1 の φυσικὸς νόμος に揃えて「最初の道理」。
  - 18.3 の ἐφαντάσθη は Mason の注に従い「幻を見た」。訳語表の φαντάζομαι の欄に例外として書いた。
  - 18.3 の γενητῆς は、訳語表の ἀγένητος「生じたのでない」に揃えて「生じた本性」。訳語表の ἀγέννητος の欄に書いた。
  - 15.2 の δαιμόνων は 27.10.2 と同じ「霊」。ἔφεσις／ἐφίεμαι／πόθος は 28.13.7 の「慕い求める」「慕う思い」で通した。προΐστημι は 28.1.1 の「立てる」で受けた。どちらも訳語表に足した。
  - 17.3 の第一コリント一三・一二 は人称と語を変えた言い換えなので、『』も出典も付けない。18.1 の創世記四・二六 も名指しのない言い換えなので、『』と出典を付けず、訳注に箇所を書いた。「底本の扱い」の聖書の出典の決まりに書き足した。
  - 14.2 の πλάσματα は「像」、15.2 の τῶν πλασμάτων は Mason の注に従い「作りごと」と訳し分けた。18.3 の「油を注がれた石」にキリストの名は足さなかった。
  - 名前：エノス、イスラエル（口語訳）、『神の姿』を名前の表に足した。
