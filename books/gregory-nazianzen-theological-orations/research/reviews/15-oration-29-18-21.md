- 訳注：
  - 29.20.7 の μεμαλάκισται（「イザヤ五三・五の七十人訳の語。口語訳は『砕かれた』。」）。cache の Swete III（`theoldtestamenti03swetuoft_djvu.txt` l. 19962〜19966、αὐτὸς δὲ ἐτραυματίσθη … καὶ μεμαλάκισται διὰ τὰς ἀνομίας ἡμῶν）と bible.js Isa.53.5、Matt.9.35 で確かめ直した。続く「あらゆるわずらい」（マタイ九・三五 の μαλακία）との掛け合わせが七十人訳の語にしか立たないので、28.18.1 の型で付けた。μεμαλάκισται は「わずらいを負い」とし、口語訳マタイ九・三五 の「わずらい」とつなげた。
  - 29.20.8 の γλυκασμός（「雅歌五・一六の七十人訳の語。口語訳は『彼はことごとく麗しい』。」）。cache の Swete II（`oldtestamentingr02swetuoft_djvu.txt` l. 44683、φάρυγξ αὐτοῦ γλυκασμοὶ καὶ ὅλος ἐπιθυμία）と bible.js Song.5.16 で確かめ直した。苦い味と甘さの対が七十人訳の語に拠るので、同じ型で付けた。
- 決めたこと（論点一覧の「メインで決めること」）：
  - 18.1 の ἀγνωμοσύνη：訳語表の「分別のない」の仲間で、次の講話 30.1.1 の εὐγνωμονεστέροις と対が見える「分別のなさ」。
  - 18.1〜18.2 の「低い言葉」の列：聖書の語として挙げる動詞と名詞（θεός μου、μείζων、ἔκτισε、ἐποίησε、ἡγίασεν、δοῦλον、ὑπήκοον、δέδωκε、ἔμαθε、ἐντέταλται、ἀπέσταλται）は『』に入れ、29.17 の呼び名と同じく出典は付けない。語は口語訳の該当箇所に寄せた（『わたしを造られた』『お立てになった』『聖別した』『僕』『従順』）。ἐποίησε は使徒二・三六、ヘブル三・二 の口語訳「立てた」に寄せ、29.16 の ποιέω「作る」と訳し分けた。μὴ δύνασθαι 以下の不定詞と、ἄγνοια 以下の名詞、ὑπνοῦν 以下の不定詞は、語を挙げるのでなく事柄を並べるので『』に入れない。
  - 18.5 の σύνθετος／19.1 の ἀσύνθετος：「合わさったかた」「合わさっていないかた」。κενόω の仲間（18.5、21.1、21.3）は「むなしくする」で通し、21.3 の κένωσις τοῦ σταυροῦ（名指しの言い換え）に（第一コリント一・一七）を付けた。
  - 18.5 の φύσεως λόγος／λόγος οἰκονομίας：「本性の理」「救いのわざの理」。
  - 19.2 の ἀναιτίως／δι’ αἰτίαν／τίς αἰτία θεοῦ：Mason に従い目的の意味の「わけ」とし、父を原因とする論の「原因」と訳し分けた。γέγονε は直後の γενόμενος ἄνθρωπος と同じ動詞なので「人となられました」とし、重なりを残した。
  - 19.2 の ἵνα γένωμαι τοσοῦτον θεός, ὅσον ἐκεῖνος ἄνθρωπος：文型の決まりどおり程度の構文で「あのかたが人となられたその分だけ、わたしが神となるため」。
  - 19.3 の τοῦτο／ἐκεῖνο：向きを決めつけず「前のほうは人のこと、後のほうは神のこと」（お生まれになった／前にお生まれになっていた、女から／おとめから の対をまとめて受ける）。
  - 19.5 の τὰ Αἰγυπτίων：Mason の注に従い「エジプトの偶像」。イザヤ五三・二 は名指しがないが逐語の句なので 28.12.5 の型で『』と出典を付け、口語訳の長い文言から語だけを取った（『見るべき姿』も『美しさ』も）。詩篇四五・二 は「ダビデにとっては」と名指すので『』と出典。
  - 20.1 の Ἐβαπτίσθη：口語訳の「バプテスマ」（28.20.3 のメモの「バプテスマのヨハネ」と同じ）。
  - 20.6 の羊と小羊：七十人訳の順（口語訳使徒八・三二 と同じ）。λόγος は「ことば」として、声のない小羊、荒野の声と並べた。
  - 20.8 の χολή：「胆汁」（口語訳詩篇六九・二一 の「毒」は使わない）。
  - 21.1 の λόγων ἀντίθεσις：訳語表の「反対論」で「言葉で反対論を戦わせること」。εἷς ἀντικείμενος は「敵対する者は、ひとりで足ります」。
  - 21.2、21.5 の πνεῦμα：口語訳第一テサロニケ五・一九 の「御霊」に揃え、二つを同じ語にした（28.6 の第一コリント二・一〇 の「御霊」とも同じ）。
  - 21.4 の τεχνολόγοι：29.15.3 の「術語で論じる人々」と揃えて「術語で論じる者」。ἀνθ’ ὧν νῦν ὀνομάζονται は名を補わず「今呼ばれている名の代わりに」（名前の表の決まり。`// ` メモ）。συνδέσμους／κρατούμενα は 28.11.2 の語に揃え、名指しがないので出典は付けない。
  - 21.5：第二コリント五・二〇 の δεόμεθα ὑπὲρ Χριστοῦ· καταλλάγητε τῷ θεῷ と第一テサロニケ五・一九 は逐語なので『』と出典を付け、口語訳の文言にした。
  - 21.6 の σώζοιμεν／σωζοίμεθα：掛け合わせを残して「守り」「守られ」。εἰλικρινεῖς καὶ ἀπρόσκοποι は名指しがないので出典なしで口語訳ピリピ一・一〇 の語。頌栄は「このかたに、栄光がとこしえにありますように。アーメン」（口語訳ローマ一一・三六 の「とこしえに」、表記はこの叢書の「アーメン」）。
  - どれも本の `AGENTS.md` の該当する行（訳語表、底本の扱い、文体）に書いた。

適用の後、自分で見直して、「〜かた」の連体節と 20.7 の動詞に残っていた尊敬語の抜けを、20.1・20.8 の指摘と同じ型で直した（20.5「お聞き入れになるかた」「お止めになるかた」、20.7「強盗をもお救いになり」、20.8「苦い味をお消しになるかた」、21.4「結び目をお告げになり、固く結ばれたものをお解きになるかた」）。

案のなかった指摘：19.2 の「人となられました」の重なり（γέγονε と γενόμενος ἄνθρωπος が同じ動詞なので残した）、20.5 の「よみがえらせなさいます」（文法上成り立つので残した）。
