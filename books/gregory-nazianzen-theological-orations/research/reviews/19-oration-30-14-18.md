# レビュー：第 30 講話 14〜18 章

- 日付：2026-11-22
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページの `jp.md`（18-oration-30-11-13）、論点一覧 `research/cruxes/19-oration-30-14-18.md`、照合 `research/collation/19-oration-30-14-18.md`、NPNF 2-7 の英訳 `cache/ccel.org/npnf207.txt` l. 34188〜34295（脚注は論点一覧の l. 34595〜34643）。印刷版の注解は論点一覧の行番号（OCR `cache/archive.org/thefivetheologic00greguoft/thefivetheologic00greguoft_djvu.txt` l. 15573〜16421）と画像 `pages/0158_pdf.png`〜`0165_pdf.png` からたどれる。
- 結果：19 組（15 項目。必須 5 組、提案 14 組）。19 組すべてを採り、1 組（30.14.1 の ταπεινότης）は語を変えて採った。聖句の文言と出典は妥当とされた。
- 訳注：1 つ。30.18.1 の出エジプト三・一四（論が七十人訳の名 ὁ ὤν に拠る。Swete I l. 11398〜11410 で確かめた）。
- 決めたこと（論点一覧の「メインで決めること」）：
  - 30.14.4 の πείθει καρτερεῖν の相手：Mason の注と 14 章の要約に従い「わたしたち」。直前で、子が父の前にひれ伏すという考えを退けているので、父を説き伏せると論が戻る。NPNF の取り方はメモに書いた。
  - 30.14.2 の μετὰ τοῦ σώματος：関係節 οὗ προσέλαβεν（30.12.3 の ὁ προσλαβών と同じ動詞）のとおり「お取りになった体とともに」とし、Mason の「教会」説をメモに書いた。ἕως ἄν は Mason に従い終わりの時点と読まれないよう「至るまでも」。
  - 引用の型：ヘブル七・二五 は論敵が τό で掲げる句なので、人称を変えていても 30.13.1 と同じく『』と出典を付け、底本の「わたしたちのために」に従った。第一ヨハネ二・一 は 29.19.5 の型で『助け主』だけ。出エジプト三・一四 は七十人訳の形で訳注。『焼きつくす火』は 28.31.2 の型で出典を付けた。組み合わせの句には出エジプト三・一五 を加えず、Mason の挙げる二・二〇 とイザヤ四二・八 にした。
  - 30.15.1 の τῶν αἰώνων は、時の長さの論に合わせて「世々」。30.15.4 の τὸ νοούμενον は 28.12.6 の「知性で知られるもの」。
  - 30.15.2 の ἐν χρῷ は底本どおり「すれすれ」とし、写本の多くが ἐν χρόνῳ と読むことをメモに書いた。
  - 30.16.4 の列は 29.18 の語に揃えて『』に入れず、παραδόσεως は「引き渡し」と両方に開いた。ἐλείπετο は Mason に従い反実仮想。
  - 30.16.5 の τοσοῦτον：Mason の注に従い「これだけにします。…程度のものです」と二文にし、文型の訳し方に書き足した。
  - 30.18 の訳語：ὁ ὤν は『有る者』、τὸ ὄν は『有る』ということ。οὐ γὰρ ἦν, ἢ ἔσται は Mason に従い「（前や後のものは）かつてあったこともなく、これからあることもない」。ὁ δεσμός は Mason とエリアスに従い「魂を体につなぐこの絆」。
  - 「絶対と関係」の語（15.4 の ἀπόλυτον・ἄσχετον、18.2 の ἄφετος・πρός τι）は「それだけで立つ」「関係を言う語」「関係で言われる語」の一組にした。
  - 照合の 3 件（30.14.4 の ἡ、30.18.2 の ἡ、30.18.3 の ἦν）は印刷版の読みで訳し、メモに書いた。
  - レビューの後に自分で直したこと：προσηγορία・κλῆσις を「呼び名」、ὄνομα を「名」に揃えた（16.4「こうした名」、16.5「名の奥義」、18.1「その呼び名を尋ねた」）。14.2 の πρεσβεύει を 14.1 と同じ「使者として願う」にした。pages.json の印刷版の範囲を p. 137 の注まで（l. 16421）延ばした。
  - どれも本の `AGENTS.md` の該当する行（底本の扱い、文体、訳語表、文型の訳し方、名前の表）に書いた。
