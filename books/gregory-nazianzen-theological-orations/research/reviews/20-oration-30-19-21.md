- 訳注：3 つ。30.19.1 の『愛する者の、もろもろの力の王』（詩篇六八・一二 の七十人訳。Swete II l. 26175〜26178 で確かめた）、30.20.11 の使徒一七・二八（Mason の注「子について言われた言葉ではない」。OCR l. 16831〜16832）、30.21.5 のイザヤ五三・八（七十人訳。Swete III l. 19980）。
- 決めたこと（論点一覧の「メインで決めること」）：
  - 30.19.1〜3 の οἰκονομία：ταύτης διττῆς は一つの名詞を二つに割るので、「体を超えた救いのわざ」「体における救いのわざ」と同じ語で受け、訳語表の「（受肉）」を外した。29.18.5 の「救いのわざの理」とのつながりも残る。動詞の οἰκονομεῖ は「つかさどる」、διοικούμεθα は「治められている」とし、メモに書いた。
  - 30.19.1 の σαβαώθ：すぐ後で στρατιῶν と言い直し、τῶν δυνάμεων と並ぶので、口語訳の「万軍の主」を使わず「サバオトの主」「もろもろの力の主」とした。名前の表に書いた。
  - 呼び名の列は 29.17 と同じく『』に入れ、出典は付けない。『愛する者の、もろもろの力の王』は七十人訳にしかないので、28.18.1 の型で訳注を付けた。
  - 30.20.2〜5 の λόγος：30.18.2 の型で『ことば（ロゴス）』と一度だけ音を添え、定義も「ロゴス」と呼ばれる、声に出さない定義、理法、と読み替えを追えるようにした。20.9 の λόγῳ は Mason に従い「理性」。訳語表に行を足した。
  - 30.20.3 のヨハネ一四・九：30.12.6 の型で常体の「」と出典。νοέω は「知った」とし、挿入句（『見た』ということ）は「」の外に出した。
  - 30.19.4 の προελθόντος ἢ προϊόντος：「発出」「送り出す」と別の「進み出る」とし、二つの時制を残した。
  - 30.20.7 の καὶ οὗ λέγεται は Mason の一つ目の取り方、30.20.11 の ἐκεῖθεν は Mason の言い換え（from Him）に従い「このかたから」（呼び名『いのち』の御子）、30.21.4 の ἐντεῦθεν は「ここから（天へ）」、30.21.7 の συμπαθῶς は「思いやりをもって」。どれもメモに書いた。
  - 30.21.1 と 30.21.5 の τὸ ὑπὲρ ἡμᾶς などは中性で「面」とし、30.21.3 の τὸ χρίον／τὸ χριόμενον は「もの」とした。21.1 の χωρηθῇ は受け入れる側を主語に立てた。
  - 30.21.3 の αὕτη：女性の分詞 ἁγιάζουσα が続くので神性と取り、「神性こそが、人性の油注ぎだからです」。30.2.8 の既訳（「この油注ぎは、人性が受けたものだからです」）は同じ句で、中身は矛盾しないので、このページでは直さず、メモに同じ句であることを書いた。交差の向きは本文に従った（油を注ぐものが『人』と呼ばれ、注がれるものが神とされる。Mason の注の「『神』の名を帯び」は本文と合わないので採らない）。
  - 30.21.8 のヘブル一三・八：名指しも導入の語もない言い換えなので、30.10.7 の型で「」に入れ、『』も出典も付けず、メモに箇所と Mason の組み立て（σωματικῶς までが主語）を書いた。
  - 照合の誤りのうち語の変わるもの（30.20.9 の ἢ→ἡ）と、30.20.4 の κότος の重複、30.21.1 の λύση をメモに書いた。
  - レビューで決まった訳し方（子と聖霊の状態の動詞も尊敬語、διά＋対格は「ゆえ」、ἴδιον／ἰδίως は「固有」、呼び名の意味は括弧で一度だけ添える）は、本の `AGENTS.md` の文体の節と文型の訳し方に書いた。
