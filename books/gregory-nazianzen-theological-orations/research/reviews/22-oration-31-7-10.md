- 決めたこと（論点一覧の「メインで決めること」）：
  - 31.8.2 のヨハネ一五・二六 は、28.31.2 の型で『』の文言を論に合わせ、訳注で口語訳を示した。訳語表の ἐκπόρευσις の行の決まり（逐語の引用は口語訳の「来る」）の例外として、その行に書いた。
  - 31.7.5〜7.6 の文法上の性は、訳注にせず本文に「男性の語」「女性の語」「中性」を補った。訳注は別の読みを知らないと理解が変わる箇所にだけ付ける決まりのため。
  - 話し手の割り振り：7.1 の Ἐνταῦθα … πλεκέσθωσαν はグレゴリオス、ἢ ἀγέννητον から 7.2 の ἀδελφοί までを論敵の「」、σὺ δέ μοι … φιλοσώματος はグレゴリオスの差し挟み（Mason）、7.3 の εἰ δὲ ἐκ τοῦ υἱοῦ から παραδοξότερον までを論敵の「」（φησι を受ける問いなので論敵の側に含めた。Mason に注はない）。8.3 の τίς οὖν ἡ ἐκπόρευσις は Mason の 8 章の要約に従い論敵の問い。10.1 は Mason の 10 章の要約に従い、問いを論敵、πάνυ γε と εἴπερ θεός をグレゴリオスの答えとした。
  - 31.9.1 の ἔκφανσις は Mason の注に従い「出で方」とし、「現れ」としない（サベリオス派の考えに読まれるため）。訳語表に行を立てた。
  - 31.10.4 と 10.6 の、生きものの誕生を工夫する主語の φύσις は「自然」。10.2 の神の φύσις と 10.3 の ῥευστῆς φύσεως は「本性」。訳語表の φύσις の行に書いた。
  - διαίρεσις：7.1〜8.3 の論理の二者択一は「区分」、9.4 の τῆς πονηρᾶς νῦν διαιρέσεως は Mason の注（エウノミオス派による本性の分割）に従い「分割」と訳し分けた。訳語表に行を立てた。
  - τὰ πράγματα（7.4、10.2）は「事柄」。31.5.5 の πραγμάτων ἀκολουθίαν は順序を言うので「実在の順序」としたが、ここは「名」と並んで「名が指す当のこと」を言い、「実在」は訳語表の ὑπόστασις（28.9.3）と重なるので訳し分けた。訳語表に行を立てた。
  - 8.2 の τὴν τρίτην σου διαθήκην は「旧約と新約に続く、あなたの第三の契約」と補った。
  - 9.3 の τὸ μὴ γεγεννῆσθαι／τὸ γεγεννῆσθαι／τὸ ἐκπορεύεσθαι は、グレゴリオスの地の文に普通体の「生まれた」を置かない決まりに従い「お生まれにならなかったこと」「お生まれになったこと」「発出なさること」。8.2 の聖霊の状態（「発出なさる」「おられる」）も尊敬語。
  - 31.10.3 のイザヤ八・一九 は名指しの言い換えとして出典を付け、『』に入れず、訳注も付けない（句の向きがルカ二四・五 に近いことはメモ）。31.10.6 の不死鳥は本文に名を補わず、訳注も付けずにメモに書いた（言い伝えであることは本文で分かる）。
  - 名前：マルキオン、ウァレンティノス（ほかの本と同じ）、アイオーン（『異端反駁』と同じ）。
- 文言を変えて採ったもの：31.9.3 は、案の「いま語っている聖霊」では原文にない「語っている」が入るので、「一方を父、一方を子、そしてもう一方を、聖霊というこの名で呼び表した」とした（τοῦθ’ ὅπερ λέγεται の「この」と「呼ばれる」を残す）。31.10.6 は「近いもの」でなく原文の προσέοικεν に合わせて「よく似ています」を残し、比較の「ほかの例よりも」だけを足した。
