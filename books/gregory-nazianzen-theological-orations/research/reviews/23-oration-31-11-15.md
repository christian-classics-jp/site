- 決めたこと（論点一覧の「メインで決めること」）：
  - 31.12.1〜12.4 の τῷ πνεύματι：12.1 の論敵の問いは「聖霊を礼拝したのか」、12.2 は「聖霊において」「聖霊によって」、12.4 は第一コリント一四・一五 の口語訳「霊で」を受けて「聖霊で礼拝すること」とし、与格の受け直しをメモに書いた。προσκυνέω は 12.3 のヨハネ四・二四 の口語訳に合わせて「礼拝する」で通し、訳語表に行を立てた。
  - 12.3 の二つの聖句の πνεῦμα：ヨハネ四・二四 は口語訳の「霊」のまま（Mason の注で、グレゴリオスも聖霊と言い切らない）。ローマ八・二六 は 12.4 の αὐτὸ ἑαυτῷ とつなぐため「聖霊みずから」とし、口語訳の「御霊みずから」をメモに書いた。指すかたは同じなので訳注にしない。
  - 13.1 の λόγον ἔχοντας は、Mason の注（ことば＝御子と、理の二重の意味）に従い 27.5.4 の型でひらがなの「ことば」。法廷の言葉は「欠席裁判で負ける」「聖霊の弁護に立つ」「訴える者であるあなたがたを、わたしたちの弁護人として」で揃えた。
  - τριθεῖται／διθεῖται は「三神論者」「二神論者」、διθεία／τριθεία は「二神論」「三神論」。13.3 は Mason の注に従い「自分たちが『三神論者』と呼ぶわたしたち」。訳語表に行を立てた。
  - 13.2 の εὐγνώμονας は訳語表の「分別」の仲間（「子については、いくらか分別のある人々」）。31.1.2 の人々と同じことをメモに書いた。
  - 12.9 の φαντασία と 14.3 の τὸ φανταζόμενον は、31.3.5 と同じ「かいま見る」。
  - 15.2 の ἐπινοίᾳ θεωρητόν は Mason の注に従い「考えの上でだけ見て取れる」とし、29.13.5 の「見方」と訳し分けた。
  - 14.2 の光の σύγκρασις は「光が一つに溶け合っている」とし、キリスト論の「混ぜ合わされる」と訳し分けた。
  - 話し手の割り振り：11.1〜11.4 は 29.11 の型（グレゴリオスの問いと自答は地の文、πῶς οὔ; πῶς δ’ οὔ; τίνος γὰρ ἄλλου; οὐδαμῶς. は論敵の「」）。11.3 は Mason の注に従い ἄλλο τι まで、12.1 は 12.2 の λαβών; まで、15.1 は 15.2 の ὡς δὲ καὶ ἄνθρωποι; までを論敵の「」とした。
  - 12.6 の εἴρηται は聖書を名指すとみて出典（ヨハネ一・三）を付け、『』に入れない。
  - 名前：エバ（口語訳）。
- 文言を変えて採ったもの：
  - 31.12.6 は、案の「端的にすべてのもの」では日本語として硬いので、ἁπλῶς を「無条件に」とし「無条件にすべてのもの、ということではない」とした。
  - 31.12.9 の μηδενὶ περικόψῃς は、案の「三つのどれからも切り取ってはなりません」では目的語の τὴν μίαν φύσιν が「三つ」から切り取る形に変わるので、「どんな点でも切り詰めてはなりません」とした（μηδενί を限定の与格に取る）。
  - 31.13.3 の γάρ は、案の「というのも、…共通の言葉があるからです」に続く「この人たちだけに向けた言葉もあります」とつなぐため、二つを一文にまとめた。
  - 31.15.4 の οὐκ οἶδα εἰ μή は、案の「やはりそうなのではないでしょうか」では「わたし」の判断が消えるので、「やはりそうなのではないかと、わたしは思います」とした。
- 後で直したもの：31.11.3 の論敵の言葉が、提案を当てた後で 60 字を超えたので、「同じ一つのものから、一方は生まれたものとして、もう一方は別の何かとして出たわけではないではないか」とした。
