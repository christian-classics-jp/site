- 決めたこと（論点一覧の「メインで決めること」）：
  - 25.7 の οἰκονομία：Mason の注（相手を思いやって最善から離れること）に従い「配慮」。τελειότης は「完全さ」、26.1 の τελείωσις は「完成」。
  - 27.3 の ἀποκατάστασις：救い主ご自身のことなので、「万物更新」も 30.12.6 の「回復」もとらず、「よみがえって、もとのお姿にお戻りになった」。
  - 28.1〜28.2 の σέβω／σεπτός：論の段（礼拝すべき → あがめるべき → 神）を見せるため、προσκυνέω の「礼拝する」と分け、28.7.3 に揃えて「あがめる」。前のページの「敬う」（31.5.4、31.13.5、31.16.1）は段の論がないところなので直さない。
  - 26.5〜26.6 のヨハネの四つの言葉：動詞を『つかわす』に揃えた（14.16 の口語訳「送って」を替える）。τὸ πνεῦμα τῆς ἀληθείας は、第 31 講話の決まり（聖句の τὸ πνεῦμα も「聖霊」。31.12.3、31.19.4）に従い「真理の聖霊」。26.6 の Πέμψει μέν, ἐν δὲ τῷ ὀνόματί μου は言い換えなので常体の「」、Ἐρωτήσω／Πέμψει は語として『』、Πέμψω／Ἥξει は『』に入れて Mason の挙げる箇所を出典に置いた。
  - 25.1、26.2 の διαθήκη：「二つの契約」から受けるよう、ἡ παλαιά／ἡ καινή を「古い契約」「新しい契約」とした（31.5.1 の「旧約」は書物を言う）。
  - 25.2、27.1 の ἀθρόως：どちらも「一度に」（31.22.4 の「突然」とは向きが違う）。
  - 25.7 のガラテヤ五・一一：グレゴリオスが最初の ἔτι を欠くので、口語訳の「今でも」を除いた。
  - 26.3 の ἀναβάσεσι：出典は口語訳の番号（詩篇八四・五）で書き、訳注で口語訳の文言を示した。
  - 26.4 の ἐμφυσώμενον：尊敬語と紛れる受け身を避け、「キリストの吹きかける息としておいでになりました」。26.5 の ἐκφαίνεται も「イエスも、聖霊を少しずつ明かしておられます」と主を立てた。
  - 28.1 の θεοφόρων：31.12.5 の ἐνθέων（「神に満たされた人々」）と分け、Mason の注（第二ペテロ一・二一）に寄せて「神の霊に動かされた人」。
  - 28.3 の ἀναγέννησις／ἀνάπλασις：「新たに生まれること」「形づくり直されること」（訳語表の πλάσις の仲間）。
