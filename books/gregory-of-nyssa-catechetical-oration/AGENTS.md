# ニュッサのグレゴリオス『教理大講話』の決まり

ニュッサのグレゴリオス（335 ごろ〜395 ごろ）が、383 年から間もないころに書いた、教理を教える者のための手引き。ギリシア語。題は写本で λόγος κατηχητικός。教える相手（ギリシア人、ユダヤ人、異端の人々）に合わせて論じ方を変えるべきことを説く序に続いて、Srawley の分け方では四つの部分からなる。三位一体の神（1〜4 章）、人の創造と悪の起源（5〜8 章）、受肉と贖い（9〜32 章。受肉が神にふさわしいこと、神の善・知恵・正義・力がそこに表れること、悪魔へのあざむき、十字架）、洗礼と聖餐と信仰（33〜40 章）。

次の本の決まりを、同じ語を同じ意味で使うかぎり引き継ぐ。ここには、この本で違うところと、この本に固有の決まりだけを書く。食い違うときはこのファイルを優先する。

- 三位一体と御子の論の用語、論敵の言葉の口調、背理法の文での神への尊敬語：『神学講話』（`books/gregory-nazianzen-theological-orations/AGENTS.md`）の「文体」「訳語表」「文型の訳し方」「名前の表」。同じ時代のカッパドキアの神学で、グレゴリオスはナジアンゾスのグレゴリオスの友。訳語表は、この本で使い方が違う語だけをこのファイルの訳語表に書く。
- 受肉と贖い、人の朽ちることと朽ちないことの語：『アントニオス伝』（`books/athanasius-life-of-antony/AGENTS.md`）と『神のことばの受肉』（`books/incarnation/`。英訳からの重訳なので文体は引き継がず、用語と人名の表記だけ）。9〜32 章の論じ方はアタナシオスに拠る。
- 洗礼・塗油・聖餐の語（33〜37 章）：『秘義教話』（`books/cyril-mystagogical-catecheses/AGENTS.md`）。

## 節の形

- 章（1〜40）の番号は底本（Srawley 1903）に従う。英訳（NPNF 第 2 集第 5 巻）の章の番号も同じ。底本の序（Πρόλογος）には番号がなく、この訳で 0 章とした（『アントニオス伝』と同じ）。序は、英訳の Prologue と同じく、1 章の Ἀλλ᾽ ἐπειδὴ の前まで。
- 底本には章の中の区分がない。底本の欄外の数字（5、10、15。奇数ページは右、偶数ページは左の欄外）はページごとの行番号で、節ではない。節の番号は、画像から起こした章を `tools/split-units.js` で文の切れ目（. と、その後の閉じ引用符）で分けて、この訳が付けたもの。底本にも英訳にも、この節番号はない。英訳と照らすときは章と文の内容で照らす。ギリシア語の疑問符（;）と上の点（·）では切らない。
- 底本テキストは `research/srawley-1903.txt`。1 行 1 節で `<章>.<節> <本文>`（`2.5`、序は `0.1`）。
- 底本の 1 節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `2:5 ` のように章・節の番号で始める（序は `0:1 `）。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 2〜4 章　…` の形（章の範囲、中身）。1 章だけのページは `# 5 章　…`、序のページは `# 序　…`。
- 底本の題（ΛΟΓΟΣ ΚΑΤΗΧΗΤΙΚΟΣ）と序の見出し（Πρόλογος）は底本テキストに入れていない。書名は README から出る。
- ページの割り（`research/pages.json`）は、全文を起こす前に、OCR のギリシア語の本文の行の語数を章ごとに数え（序から 40 章まで計 21,700 語ほど。注解に引かれたギリシア語も少し混じる。序は見積もり 620 語に対して、起こすと 621 語）、1 ページ 1,000 語ほどを目安に、章の途中では切らずに 20 ページに分けた。節の番号は起こすまで決まらないので、1,500 語を超える 8 章（約 1,740 語）、35 章（約 1,470 語）も 1 章 1 ページにした。Srawley の四つの部分（1〜4、5〜8、9〜32、33〜40 章）はまたがない。序（約 620 語）は 1 章（約 920 語）と合わせると長いので、序だけで 1 ページにした。
- 底本の章の初めのページの注解の頭には、章の中身の要約（イタリック）があり、見出しの中身を決めるときの手がかりになる（Srawley の文なので訳文には写さない）。

## 底本の扱い

- 本文は、archive.org のページ画像から起こし、OCR と語ごとに突き合わせる。本を始めたときに起こしたのは序（0.1〜0.10、pp. 1〜6）だけ。次のページを訳すセッションは、page-context を作る前に、そのページの章を起こして `research/srawley-1903.txt` に足す（起こさないと page-context は空の抜粋を書き出す）。
- 画像は pages.json の `images` の番号 N（archive.org のページ画像の番号で、N＝印刷ページ＋56。`_page_numbers.json` の leafNum と同じ数で、IIIF の番号も同じはずだが、IIIF では確かめていない）で、`node tools/fetch.js https://archive.org/download/TheCatecheticalOrationOf/page/nN_w1600.jpg cache/archive.org/TheCatecheticalOrationOf/page/nN_w1600.jpg` として取り（N は 0057 ではなく 57 と書く）、`node tools/image.js crop <画像> pct:5,10,90,24 <出力先>` と `pct:5,33,90,16` ほどで、本文を上下 2 回に分けて切って読む。1 ページの本文は 11〜20 行（120〜180 語ほど）とまちまちなので、異読の欄の手前まで切り出す（5 章では `pct:5,6,90,26` と `pct:5,30,90,26`。20 行のページは本文が画像の 57% ほどまで続く）。2026-11-23 には IIIF のサーバー（`tools/iiif-crop.js`）が応答しなかった。
- 手順：pages.json の `print` の範囲から、本文の行だけを拾って下書きにする。OCR の各ページは、柱（CATECHETICAL ORATION、GREGORY OF NYSSA）、本文の行（あいだにアクセントだけの崩れた行が入る）、異読の欄（`||` や vulg を含む行から）、注解の順に並ぶ。柱から異読の欄の手前までの、語のある行の番号を `node tools/ocr-lines.js <OCR> <行番号の並び> --label <章>` に渡して 1 章 1 行の下書きにし、画像を見ながら `node tools/replace.js` の短い組で直す。直した章のファイルを `tools/split-units.js` で底本テキストに足したあと、`node tools/collate.js research/srawley-1903.txt <章> <OCR> <print の行範囲> --skip 'vulg|\|\||CATECHETICAL|GREGORY'` で OCR との違いの候補を出し、残りがみな OCR の読み誤り（下に挙げる型）であることを確かめる。collate.js で確かめたあと、下書きから来た語頭の気息（ἡ／ἠ、ὁ／ὀ、οὗ／οὖ）、アクセント（ὃν／ὂν、ἕν／ἓν）、iota subscriptum（ἦ／ᾖ、τῇ）を、画像でもう一度通して見る。collate.js は OCR と同じ読みを違いとして出さないので、この通し読みを省かない。どの画像をどう切って読んだか、OCR との違いが何だったかは `research/sources.md` の画像の行に書き足す。
- OCR の崩れの型：ラテン文字への化け（τὸ を `TO`、τὸν を `Tov`、τῇ を `TH`、ὡς を `ws`、γὰρ を `yap`、δοίη を `Soin`、βλέπειν καὶ を `βλέTew Kal`）、上の点（·）を `"` や `:` と読む、気息やアクセントの取り違え（ὂν を ὃν、ἓν を ἕν）、行頭の気息の落ち（ἀιδιότης を αιδιότης）、欄外の行番号の混入（15 を `1s`、10 を `Io`）、行の順の入れ替わり（p. 5 では、ページの下の方の行が前に来ていた）。OCR が別の正しい語形に読み誤ったもの（ἠπατημένας を ἡπατημένας、ᾖ を ἦ、ὂν を ὃν）は、下書きにそのまま残り、collate.js の候補にも出ない。章の番号も崩れる（`pages.json` の行範囲は `research/sources.md` の章の書き出しの行の表から作った）。OCR だけに頼らず、必ず画像で読む。
- 起こすのはギリシア語の本文だけ。章の番号（本文の行の頭の `1.` など）、欄外の行番号、柱、異読の欄、注解は起こさない。行末で分けられた語はつなぐ。

- 字間を空けずに刷られた点で、句読点の位置になく文が続くもの（0.5 の σοφῶς の後）は、活字の汚れとして起こさない。
- 底本が聖句や引用をどう刷るか（引用符、字体）、角括弧などの版の記号は、初めて出るページで画像と序論で確かめ、ここに書く。逐語の聖句は、引用符なしで、地の文より立った字体で刷られ、書き出しが大文字（4.3 の Τῷ λόγῳ … αὐτῶν、p. 18）。底本テキストには字体の違いを写さない。
- 印刷の誤りは、底本テキストには刷られたとおりに書き、訳は意図された形で行って `// ` メモに書く。
- 異読の欄の略号（序論の § 3、OCR l. 1800〜2180）：d＝Trinity College, Cambridge B. 9. 1（12 世紀）、e＝パリの Codex Regius（12 世紀）、f＝大英博物館 Add. 22509（10〜11 世紀。冒頭を欠き、0.4 の οὐ γὰρ δι᾽ ὧν から始まる）、g＝ボドリアン図書館 Cromwell IX（12〜13 世紀。冒頭を欠き、1 章の後半から始まる。32〜33 章にも大きな欠けがある。章を 21 に分ける）、h＝ウィーン Gr. suppl. 10（15 世紀）、l＝大英博物館 Royal 16 D. ## 文体

- 地の文は敬体（「〜です」「〜ます」）。教理を教える者に向けた手引きで、講話ではないが、読み手に宛てた論考は敬体で訳してきた（『祈りについて』『反キリストについて』『ギリシア人への勧め』）。引き継ぐ『神学講話』とも揃う。命令は「〜しなさい」、一人称複数の勧めの接続法（0.6 の ἀπαιτήσωμεν）は「〜しましょう」。一人称複数の未来の直説法（5.2 の προσαξόμεθα、5.18 の διαληψόμεθα）は「〜することにします」とし、勧めと混ぜない。
- 書き手のグレゴリオスは「わたし」。書き手と読み手、正統の信仰に立つ人々は「わたしたち」。読み手の教える者に 2 人称単数で向かうところ（0.4 の θεραπεύσεις、ἀνατρέψεις）は「あなた」。問いを出す相手に 2 人称単数で向かうところ（5.21 の ἐρεῖς、5.24 の σοι）も、原文が 2 人称に切り替えているので「あなた」とし、問いの中身は常体で言い切る（「では、あなたは言うでしょう。…のか、と」）。尊敬語は使わない。
- 論じる相手（ギリシア人、ユダヤ人、異端の人々）を 3 人称単数で受けるところ（0.5〜0.8 の ὑπείληφεν、λέγοι、ἡγεῖται）は「その人」「相手」などとし、「彼」を重ねない。相手の反論（φησί、φασί で引くもの、「〜と言う人もいるだろう」と想定するもの）は、『神学講話』と同じく常体で言い切る（「〜だ」「〜ではないか」）。
- 神、キリスト、聖霊の動作は尊敬語にする。受け身や可能と紛れる「〜られる」は避け、「お〜になる」にする。相手の説を仮定して突き崩す文でも、神の動作は尊敬語にする（『神学講話』と同じ）。τὸ θεῖον（神的なもの）を主語にとる文も、神を言うので尊敬語で受ける。神のことば（御子）の動作も尊敬語にする（1.10〜1.14 の「生きておられる」「お選びになる」「おできになる」）。ただし、ことばに限らず一般のものについて言う条件（1.8 の「知性をもつ体のないものとして実在するなら、必ず生きている」）と、「実在する」「区別されている」のような状態は常体の述語でよい。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。
- 一文を短く切る。グレゴリオスの文は長く、分詞と関係節を重ねるので、論の順（前提、帰結）が見えるように文を分ける。
- 聖句は七十人訳から引かれる。口語訳の文言がグレゴリオスの論と食い違うところ（4.3 の詩篇三三・六。口語訳は「天の万軍」「主の口の息」）は、論に関わる語だけを七十人訳に従わせ、ほかの語は口語訳に揃えて（4.3 の『もろもろの天は』）、「旧約のギリシア語訳による。日本語の聖書では〜。」の型の訳注を付ける（『秘義教話』と同じ）。

## 訳語表

『神学講話』の訳語表と違う使い方をする語と、この本に固有の語。決めた理由を右の欄に書く。初めて出たページで決め、レビューで決まった訳し方もここに統合する。

## 文型の訳し方

レビューで決まった文型の訳し方をここに書く。

- 神や神のことばが主語の文では、受け身や可能と紛れる「〜られる」「〜される」（「傾けられない」「移される」）を使わず、「お〜になる」にする（1.11 の「心をお傾けにならない」「はたらきへとお移しになる」）。連体修飾も同じで、「造られたかた」でなく「お造りになったかた」（4.4、8.11、8.14）。背理法で名詞化した神の動作も同じ（8.19 の「お生み出しにならないこと」）。主語が書かれていない不定詞を名詞にしたもの（22.1 の「おふるいにならないこと」、22.3 の「お任せになること」、23.7 の「お選びになったこと」）も、神の動作なら尊敬語にする。神を指す分詞の名詞化（26.3 の τοῦ ἐνεργοῦντος「それをなさるかた」）も同じ。δύναμις（力）を主語にとる文は常体でよい（24.4、27.2、27.11）が、27.6 の ἡ θεία δύναμις … πρὸς τὸ ἑαυτῆς βλέπουσα πρέπον のように、神ご自身の判断を言う文は尊敬語にする。「あわれまれます」「救い出されました」「差し出された」のような「〜れる」は使わず、「おあわれみになります」「お救いになりました」「お差し出しになった」とする（21.3、23.2）。人や物が主語に立ち、行うのが神である受け身（29.1 の名詞 ἀναβολή、30.1 の προσαχθῆναι τὴν θεραπείαν、30.4 の仮定の説の中の ἀποκληροῦσθαι、καλουμένων）も、神を主語に立てて尊敬語にする（「先延ばしになさった」「お施しになった」「お召しになる」）。受け身の形で自動の意味の προσάγομαι（30.5 の μὴ προσαχθέντας τῇ πίστει、2.1、8.2）は、人が主語なら「身を寄せる」「〜するようになる」とし、「導かれる」と訳して導く側の落ち度に読ませない。できないことを言う否定（οὔτε χωρισθῆναι δυναμένην）は、受け身の「引き離される」にせず「離れることはありえません」（2.4）。神や父が主語に立つ受け身（「父が思い浮かべられる」）は、受け取る側の人を主語に立てる（1.13 の「聞く者は必ず、ことばの父もあわせて思い浮かべます」）。
- 「〜を受けているそのかた」のように主語を落とした連体修飾は、かかる名詞が主語に読まれやすい。関係が逆に読まれるところは「ご自分が実在を受けているそのかた」のように主語を書く（1.14）。
- 父を指す男性の関係詞の句（τὸν ὅθεν ἐστίν、τὸν οὗ ἐστὶ λόγος）は、「出どころ」のような物の語にせず「〜かた」で受ける（1.13 の「ことばがそこから出るかた」「そのことばの主であるかた」）。中性の ἐκεῖνο で受ける属格の句（3.2 の ἐκεῖνο, οὗ καὶ ὁ λόγος ἐστὶ καὶ τὸ πνεῦμα）も「ことばと霊の主であるあのかた」。
- 「A があるように B もある」という比べの文に理由（διά、γάρ）が続くときは、理由が主文にかかるよう、比べの句を先に出す（2.3 の「神のことばがあることが、先に認められました。それと同じように、神の霊があると考えることも…。…からです」）。
- 中性の抽象（τὸ δυνατόν、τὸ ἀδύνατον）は「〜こと」で揃える（1.11 の「力あること」「力のないこと」）。
- 主動詞の下の分詞（8.17 の κατονομάζοι の下の ἢ … λέγων、ἢ … εἶναι）は、主動詞と並ぶ別の文にせず、「〜と言って、そう呼ぶ」のように係りを残す。εὐλόγως のような論の運びの語（訳語表の「もっとも」）も落とさない。
- 主格で並べた語の構文が途中で変わるところ（1.14 の εἴτε γὰρ ἀγαθότης … σημεῖόν τις ποιοῖτο。Srawley の注は 9 章にも似た破れがあるとする）は、先に「〜としましょう」で枠を立て、並べた語を例として後から続ける。9.1 の γένεσις ἀνθρωπίνη … θέσις（τὰ ἐφεξῆς にゆるく同格で置かれた主格の並び）も同じで、「その事柄とは、…です」と後から続ける。
- 「θεοῦ τὸ …」の繰り返し（12.3）は、「〜ことは、神に属します」と同じ形で並べる。
- 現在形の一般論の中の不定過去（格言の不定過去。17.1 の ἐδέξαντο）は、現在形で訳す（「感謝して受けるのです」）。
- 属格独立句が主文の時や前提を言うところ（16.9 の ἐκρυείσης）は、独立した文にしても「そのときには」「もう〜しています」のような語で主文との関係を残す。
- 論の理由を言う γάρ（18.1 の τοῖς γάρ）は、「というのも」「〜からです」で訳し、落とさない。「のです」で済ませない（24.5 の οὐ γάρ、25.2 の εἰ γὰρ καί、25.3 の ἡ γάρ は「というのも、…からです」）。直前の文も「というのも」で始まるところ（25.1 の τοῦ γὰρ ὄντος、30.7 の οὐδὲ γὰρ ἦν）は、「〜からです」だけでよい。そのとき、γάρ は主文にかけ、属格独立句（30.7 の προτεθείσης τῆς χάριτος）を理由の側にしない。たとえを出す γάρ（24.4 の ὡς γάρ）は「たとえば」。前の文を説き明かす γάρ（23.7 の τὸ μὲν γάρ）は「つまり」でもよい。論の次の前提を出す ἀλλὰ μήν（23.2）は逆接にせず「さて」とし、前の文に制限を加える ἀλλὰ μήν（23.4）は「けれども」とする。冠詞付きの οἱ πολλοί（18.2 の ἐν τοῖς πολλοῖς τῶν ἐθνῶν）は「大部分の」、冠詞なしの πολλοί は「多くの」と訳し分ける。冠詞付きの抽象名詞（20.5 の τὴν φιλανθρωπίαν）に「その」を付けて人を指すように読ませない。
- 底本で一つの長い文が挿入で途切れ、何度も言い直されるところ（21.2。Srawley の注が組み立てを示す）は、注の組み立てに従って文を分け、帰結（21.2 の πάντα μοι … ἀναζήτει）は、前の事情を受ける「そうであれば」で結ぶ。
- δέδεικται に主語の並びと述語の分詞が続く形（24.8 の δέδεικται … πάντα … ἐπιδεικνύμενα）は、分詞を示されたことの中身として訳す（「…は、みな、…に表れています。そのことが示されました」）。
- 驚きを言う πῶς の文（24.4）は、πῶς が καί … καί の両方にかかるように一つの問いにまとめる（「姿を見せておられながら、高みから下りておられないのは、どうしてでしょうか」）。地の文では「〜のは、どうしてでしょうか」、見た人の思いとして引くところ（24.4 の火の文）は「〜のは、どうしてなのか、と」。
- 行う者を書かない受け身で、神のことばが主語に立つもの（24.8 の ἐλπισθῆναι δύνασθαι αὐτόν … ἐγκρατηθῆναι）は、望む側を立てて「死に支配されうると、敵に望みを抱かせた」とし、補った語は `// ` メモに書く。神のことばを言う抽象名詞（24.9 の ἡ καθαρότης、ἡ ζωή、ἡ ὁδηγία）が主語の文は、常体の述語（「触れる」）でよい。
- ἐστιν を挟む名詞の文は、冠詞の付いた側を主語にする（26.10 の ἴασις γάρ ἐστιν ἀρρωστίας ἡ τοῦ νοσήματος κάθαρσις は「病気を清め去ることは、病のいやしだからです」）。
- μέν … δέ で二人を対にしたたとえで、後の μέν・δέ が前と逆の人を指すところ（26.5 の τὸν μὲν ἐπαινοῦμεν, τῷ δὲ χαλεπαίνομεν）は、「一方／他方」にせず、名指しで書く（「いやす者をほめ、たくらむ者に腹を立てる」）。
- 論じる相手を言う不定代名詞 τις（27.5 の πῶς ἐπιζητεῖ τις）は落とさず、「〜する人」で主語を立てる。
- 条件の ἢ εἰ …（「あるいは、もし…なら」。9.4）は、予測の言い切り（「同意するでしょう」）にせず、「あるいは、…としましょう。そのときは」と条件の形を残す。
