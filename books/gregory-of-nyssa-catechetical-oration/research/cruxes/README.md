# 校訂上の論点

ニュッサのグレゴリオス『教理大講話』の本文で、写本・抜粋・刊本の読みが分かれる箇所と、聖書の引用と暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（Srawley 1903、`../srawley-1903.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。底本テキストと印刷版の食い違い（電子化の誤り）は照合で扱い、ここには書かない。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は、ことわりがなければ印刷版の OCR（`cache/archive.org/TheCatecheticalOrationOf/TheCatecheticalOrationOf_djvu.txt`）の行番号。OCR は異読の欄のギリシア語（アクセントなしで刷られている）をよくラテン文字に化けさせ、写本の略号や上付きの数字も崩す（n58 の `ιατρειας l¹` を `carpecas 11` と読む）。異読の欄は、ページ画像（`cache/archive.org/TheCatecheticalOrationOf/page/nN_w1600.jpg`、N＝印刷ページ＋56）で読む。画像の切り出しは `node tools/image.js crop <画像> pct:x,y,w,h <出力先>` で行い、`/tmp` に置いただけ。各項には、元の画像と切り出した領域を書く。

## 底本の印刷版の形

- 各ページの上にギリシア語の本文（15 行。欄外に 5 行ごとの行番号）、その下に異読の欄、その下に二段組の英語の注解。
- 異読の欄は、そのページの行番号、見出しの語（`]` で閉じる。省略形のこともある）、異読、写本の略号の順で、`||` で区切る。見出しの語を書かずに異読と略号だけを書くこともある（n59 の `1 επανορθωσοιτο dnp`。その行の語の別の形）。`om` は欠くこと、`+` は加えること。
- 注解は、語や句の意味、論の運び、並行箇所、刊本（Krabinger 1838 など）の読みと解釈に触れる。章の初めのページの注解の頭に、その章の要約がある。

## 写本・抜粋・刊本の略号（序論の § 3 による）

本の `AGENTS.md`（底本の扱い）に、序論 l. 1800〜2180 から写本の年代と所蔵を書いた。ここには、論点を量るのに要る群の分け方を足す。序論 pp. xlviii〜xlix（画像 n54、n55。OCR l. 2068〜2180 は略号が崩れている）による。

- 写本は二つの群に分かれる。1 群は a、d、g、h、n、p（と、読みを見た範囲で i、k）。2 群は c、f、l、m。e と、e に拠る b は、両方の群の特徴を交互に持つ混合の本文。
- 1 群はさらに a、g、p と h、n に分かれ、d は両方の要素を持つ。a は p から直接に出た写本で、g は p に近い。
- エウテュミオス・ジガベノスの『教義の武具』に引かれた断片（euth）は h、n に近い。1 群の独自の読みは、一つを除いて、崩れか手直しによると序論は見る。手直しの傾向は euth の独自の読みでいっそう強いという。
- 2 群のうち c、l、m はパリ版（vulg）に近く、多くの崩れた読みと同じ一連の欠落を共にする。f はその本文の古く純粋な形を示す。校訂には f か f l の読みだけが大事だという。g の訂正者の読みは f l とよく一致する。
- 第一の拠りどころは 1 群の p と n、2 群の f と l。1 群には早い段階の崩れの跡があり、2 群には手直しの跡がある。序論は、全体として f l の読みのほうが本来の形らしいとする。ただし本文は f l にいつも従うわけではない（chapter-00 の 0.5 の θεῶν、0.7 の ἐπίνοιαν、0.8 の δοθέντος など）。
- 遅い写本 a、b、c、i、k、m の読みは異読の欄に挙げない。
- g は 1.13 の καὶ τὸ μὴ διαφέρειν から始まる（n68 の異読の欄 1 行目の `incipit g`）。それより前の箇所で g の名がないのは、欠けているため。
- euth：写本が揃うときは euth とだけ書き、分かれるときは euth 1、2、3…と番号を添える（1＝ミュンヘン Monac. 55、16 世紀。2＝ミュンヘン Monac. 367、11 世紀。3＝ミュンヘン Monac. 551、15 世紀。4＝パリ Gr. 1230、13 世紀。5＝パリ Gr. 1231、13 世紀。6＝ウィーン Gr. 76、12 世紀。7＝ウィーン Gr. 40、15 世紀。l. 2030〜2049。番号の 5 の行は OCR で数字が落ちている）。序の 0.5 の οὐκοῦν ὅταν から 3 章の終わりまでが euth にある（p. 3 の注解、l. 2520〜2529。異読の欄 n59 の 9 行目）。
- `*` は写本の最初の手、上付きの `1` は訂正者の手（l¹）。上付きの `vid`（videtur）は「そう読めるらしい」で、読みが確かでないことを言う（n80 の `l*vid`、n83 の `el*vid`）。vulg は 1638 年のパリ版の読み。
- Ps-Cyr Al：偽キュリロス『聖三位一体について』の読み（n70 の異読の欄、2.4 の τὸ πνεῦμα）。注解は、2.2 からの一節がこの書とダマスコスのヨアンネス『正統信仰について』1.7 に言い換えて取り込まれていると言い、3.3 の一節については後者だけを挙げる。
- 序から続いた euth の抜粋は 3.4 の最後の λόγος で終わる（n73 の `desinit euth`）。4 章の異読の欄に euth はない。5 章では、5.18 の τὸ νῦν から章の終わりまでが euth 1、2、4、5、6 にある（n81 の `exstant seqq in euth 12456`、n84 の `desinit euth`）。注解はここを『教義の武具』第 1 部第 6 題とする（l. 4870〜4871）。6〜7 章に euth はない。8 章では、8.18 の ὅτι γάρ から 8.20 の χώραν οὐκ ἔχει まで（同じ第 6 題。n105、n106）と、8.23 の διὰ τίνος から 16 章の τό τε σῶμα τῆς ψυχῆς διακρίνεται まで（第 1 部第 7 題。n107 の `exstant seqq in euth 12456`、注解 l. 7597〜7602）が euth 1、2、4、5、6 にある。
- 写本 b と e の欄外には古注がある（8.16 の μυρμηκία の語釈。n104 の注解）。
- 8.23 の διὰ τίνος から始まる euth 1、2、4、5、6 の抜粋は、9〜12 章の全体にある（16 章まで）。ただし euth 5 は、13.4 の φύσιν の後から 15.8 の καὶ ὄνομα の手前までを欠く（n116 の `quae sequuntur desunt in euth 5`、n121 の `hic rursus incipit euth 5`）。この範囲の番号なしの euth は、euth 5 を除く写本と読める。ただしこの範囲の 13.7 に `euth 245` が刷られている（n117。chapter-13-15 の冒頭）。異読の欄は写本の番号を `euth 25`（2 と 5）、`euth 16`（1 と 6）、`euth 1456` のように数字を続けて刷る。
- この抜粋の終わり：euth 2 は 16.5 の συνάφεια から後を欠く（n125 の `desunt seqq in euth 2`）。抜粋の全体は、異読の欄では p. 70 の 7 行目の διακρίνεται（16.6 の終わり）で終わる（n126 の `desinit euth`）。ところが 8 章の注解（l. 7597〜7600）は、16.7 の τό τε σῶμα τῆς ψυχῆς διακρίνεται までとする（chapter-16-17 の「未確認」）。euth 5 は 15.8 で再び始まったあと、16.4 にも名がある（n125）。17 章に euth はない。
- 27〜30 章：27.3 の μιᾶς δέ から 27.9 の ὑπερανέστηκεν まで euth 1、4、5、6 にあり（n158、n160）、28 章では再び始まる印のないまま 28.1 に `euth 16` の名が出て、28.7 の μάχεται で終わる（n161〜n163。euth 4 は 28.4 の ζωήν の後を欠く）。29.1 の τί δέ から 30.2 の τὸν βίον までが euth 1、5、6 にある（n164 の `exstant seqq in euth 156`、n166 の `desinit euth`。注解は第 1 部第 7 題とする。l. 13504〜13508）。
- q＝ヴァティカン Vat. gr. 423（10 世紀）、r＝パリ Coislin 120（もと 209。10 世紀）。どちらも 10 章の断片だけを含む（序論 p. xlvi、画像 n52。OCR l. 2019〜2025 は q を `g=`、r を `y=` と崩す）。異読の欄は 10.1〜10.3 で q、r の読みを挙げる。
- Thdrt＝テオドレトス『対話』第 2（「混ざらない者」）に引かれた 10 章の一節の読み。刊本で分かれるときは、シルモン版を Thdrt^sirm、ローマ版を Thdrt^rom と書く（序論 p. xlix、画像 n55。OCR l. 2171〜2173 は上付きの字を崩す）。序論は、テオドレトスの引用は数行の短いもので、10、16、32 章の注を見よと言う（l. 2073、2080）。
- ビザンティオンのレオンティオス『ネストリオス派とエウテュケス派を駁す』第 3 巻に 10 章からの短い抜粋がある（序論 l. 2077〜2087、10 章の注解 l. 7874〜7878）。異読の欄にレオンティオスの読みは挙がらず、略号はない。
- 序論は、偽キュリロス『聖三位一体について』とダマスコスのヨアンネス『正統信仰について』に、序と 1〜2 章を思わせる箇所があるが、本文の校訂には役立たないと言う（画像 n54）。
