## 6.1〜6.7 二つの世界と、その混ぜ合わせとしての人

### 6.1 δέ（d、e、h、n は欠く）、βουλήν（g¹、l¹ は βούλησιν）、τὸν λόγον（l と vulg は τῶν λόγων）
- 底本：Ζητεῖς δὲ καὶ τὴν αἰτίαν τυχὸν τῆς κατὰ τὴν βουλὴν διαμαρτίας· εἰς τοῦτο γὰρ ἡ ἀκολουθία τὸν λόγον φέρει。
- ほかの読み：d、e、h、n は δέ を欠く（n84 の異読の欄、6 章の 12 行目）。g と l の訂正者は βουλήν の代わりに βούλησιν（意志、望み。同）。l と vulg は τὸν λόγον の代わりに τῶν λόγων（13 行目）。
- 採る校訂者：底本は刷られた本文の形。注解は κατὰ τὴν βουλήν が 5 章の終わりの ἡ ἀβουλία を受けると言う。6.1 の ἀρχή（οὐκοῦν πάλιν ἀρχή τις ἡμῖν … εὑρεθήσεται）は、序（p. 3）と 5 章（p. 20、5.2 の注）と同じ使い方だと言う。7.1 の ἀβουλίας の注解も、6.1 の τῆς κατὰ τὴν βουλὴν διαμαρτίας を挙げて、同じつながりを言う。
- 読者への影響：中（語の取り方）。βούλησιν と読むと「意志の誤り」になり、5.24 の ἀβουλία（思慮のなさ）とのつながりが切れる。底本の βουλήν なら、本の訳語表どおり「思慮」で結べる。

### 6.2 τῶν πατέρων と μυθώδης διήγησις（注解の取り方）
- 底本：τοιοῦτόν τινα λόγον παρὰ τῶν πατέρων διεδεξάμεθα· ἔστι δὲ ὁ λόγος οὐ μυθώδης διήγησις, ἀλλ᾽ ἐξ αὐτῆς τῆς φύσεως ἡμῶν τὸ πιστὸν ἐπαγόμενος。異読はない。
- 取り方：注解は、τῶν πατέρων について、同じ趣旨の教え（悪魔が人をねたんで堕ちたこと）が先の著者にあるとして、ユスティノス『トリュフォンとの対話』119 章（p. 205）、エイレナイオス 5.22.2、アタナシオス『異教徒駁論』3、『神のことばの受肉』4、25 を挙げ、グレゴリオスはオリゲネスの影響を受けながらも、魂が時に先立って堕ちたというオリゲネスの考え（『諸原理について』3.5）は採らないと言う。μυθώδης διήγησις は、プラトンの μῦθοι のように真理を詩的な作り話の形で示す話のことで、グレゴリオスは自分の話が人の本性そのものから信用を得るものだと言っている、と注解は言う。グレゴリオスが創世記の物語（オリゲネスと同じく、5 章、8 章で ἀναγωγή によって解く）を念頭に置いている可能性にも触れる。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：小。
- 訳での扱い：訳注なし。μυθώδης διήγησις は「作り話」「神話めいた物語」のように、事実でない話の含みが出る訳にする。τὸ πιστὸν ἐπαγόμενος は「信じるに足ることを、わたしたちの本性そのものから引き出す」の向き。

### 6.5 τῆς τοῦ κρείττονος φύσεως（f、l と vulg は τοῦ を欠く）と、その取り方
- 底本：ὡς ἂν πάντα τοῦ καλοῦ κατὰ τὸ ἴσον μετέχοι καὶ μηδὲν τῶν ὄντων ἀμοιροίη τῆς τοῦ κρείττονος φύσεως。
- ほかの読み：f、l と vulg は τοῦ を欠いて τῆς κρείττονος φύσεως（「よりすぐれた本性」。n86 の 8 行目）。

- 訳での扱い：訳注なし。注解に従い、τοῦ καλοῦ と対にして「よりすぐれたもの」の向きで訳すか、「よりすぐれた本性」とするか、メインで決める。μίξις τε καὶ ἀνάκρασις は注解で「混ぜ合わせと溶け合い」で、霊と物質が互いに入り込むことはグレゴリオスに特徴的な考えだという（『主の祈りについて』4 を挙げる）。

### 6.6 λεπτή（l は λευκή、vulg は λογική を加える）、κτίσιν（l と vulg は φύσιν）と、μέν の節の取り方
- 底本：διὰ τοῦτο τὸ μὲν κατάλληλον τῇ νοητῇ φύσει χωρίον ἡ λεπτὴ καὶ εὐκίνητός ἐστιν οὐσία, κατὰ τὴν ὑπερκόσμιον λῆξιν … προμηθείᾳ δὲ κρείττονι πρὸς τὴν αἰσθητὴν κτίσιν γίνεταί τις τοῦ νοητοῦ συνανάκρασις。
- ほかの読み：l は λεπτή（細かい）の代わりに λευκή（白い）、vulg は λογική（理性をもつ）を加える（n86 の 10 行目。刷りは `λευκη l + λογικη vulg`）。l と vulg は κτίσιν の代わりに φύσιν（13 行目）。
- 採る校訂者：底本は λεπτή、κτίσιν。注解は、μέν の節は譲歩に取るのがよく、ἡ λεπτὴ … οὐσία が主語、χωρίον が述語だと言う。意味は「知性の本性にふさわしい場は、細かく動きやすい本質の領域で、それは世界の上に住むことにより、その本性の特質のゆえに知性で捉えられるものと深い近しさをもつ。けれども…」で、神はすべてを御自分と結ぶ計画を、人のうちで知性のものと感覚のものを混ぜ合わせることで果たした、という考えだと言う。λῆξις は「割り当て」「定められた場所」（λαγχάνω から）で、Moeller の論（ある人は sors、ある人は locus と訳すが、両方の意味がある）を引く。英訳は μέν の節を譲歩に取らず、前後を二つの文に分けている。
- 読者への影響：中（構文）。譲歩に取らないと、天の領域の話と、感覚の世界への混ぜ合わせの話のつながりが見えにくい。
- 訳での扱い：訳注なし。注解に従い「…ではあるが、よりすぐれた先見によって…」と譲歩で結ぶかどうか、メインで決める。λῆξις は「割り当てられた住まい」のように、場所と分け前の両方が出る語にする。

### 6.6 ἀπόβλητον … καθώς φησιν ὁ ἀπόστολος（第一テモテ四・四）

### 6.10 悪は善の欠如であること（ἀντιδιαιρεῖσθαι、ἀντιδιαστέλλεσθαι、καθ᾽ ὑπόστασιν、ἕξις と στέρησις）

### 7.6〜7.7 σαρκώδεις καὶ πνευματικὰς … καταστάσεις（e は ψυχικάς）と ὁ γὰρ πνευματικὸς … ἀνακρίνει τὰ πάντα（第一コリント二・一四〜一五、三・一。f は ὁ δέ、διακρίνει）
- 底本：7.6 διαιρεῖ γὰρ ἐν τῷ πρὸς Κορινθίους λόγῳ τάς τε σαρκώδεις καὶ τὰς πνευματικὰς τῶν ψυχῶν καταστάσεις … αὐτὴν ἐφ᾽ ἑαυτῆς τοῦ καλοῦ τε καὶ τοῦ ἐναντίου διακρίνειν τὴν φύσιν. 7.7 ὁ γὰρ πνευματικός, φησίν, ἀνακρίνει τὰ πάντα。
- ほかの読み：e は καὶ τὰς πνευματικάς の代わりに καὶ τὰς ψυχικὰς καταστάσεις（n94 の 18〜19 行目。刷りは `και τας πν.] και τας ψυχικας καταστασεις e`）。f は 7.6 の ἐφ᾽ ἑαυτῆς の代わりに ἀφ᾽ ἑαυτ.、τοῦ ἐναντίου の τοῦ を欠く。f は 7.7 の ὁ γάρ の代わりに ὁ δέ、ἀνακρίνει の代わりに διακρίνει（n95 の 3〜5 行目）。l と vulg は 7.6 で προσήκει κρίνειν の語順、ἀποστήσαντας の代わりに ἀποστήσαντα（2〜3 行目）。
- 採る校訂者：底本は刷られた本文の形。注解は πρὸς Κορ. に第一コリント二・一四〜一五 を挙げ、καταστάσεις を「心の傾き」「状態」と取る。7.6 の注解は、善と悪は感覚で判断されるのではなく、知性が体の現れから退いて、善とその反対の本性を、それ自身の性格において見分けなければならない、と言う。英訳の脚注 [1961] は 7.7 に第一コリント二・一五 を挙げる。第一コリント二・一五 は、ビザンティン型の本文で Ὁ δὲ πνευματικὸς ἀνακρίνει μὲν πάντα（Nestle-Aland は μέν の代わりに [τὰ]）、口語訳「しかし、霊の人は、すべてのものを判断する」。二・一四 は Ψυχικὸς δὲ ἄνθρωπος …（口語訳「生れながらの人」）、三・一 は … ὡς σαρκικοῖς（Nestle-Aland は σαρκίνοις。口語訳「肉に属する者」）。グレゴリオスの σαρκώδεις は、二・一四 の ψυχικός でなく三・一 の側の語で、e の ψυχικάς は二・一四 に寄せた形に見える。f の ὁ δέ も第一コリント二・一五 の形に寄る。底本は 7.7 の引用を小文字で刷り始める（6.7 の Λαβών と違う）。
- 読者への影響：小。
- 訳での扱い：訳注なし。7.7 の引用は『』に入れて口語訳の「霊の人は、すべてのものを判断する」に揃え、出典（第一コリント二・一五）を付ける。7.6 の σαρκώδεις／πνευματικάς は、口語訳の「肉に属する」「霊の」に寄せるかどうか、メインで決める（ψυχῶν καταστάσεις の ψυχή「魂」と、二・一四 の ψυχικός「生れながらの」は別の語として訳す）。7.6 の διακρίνειν（見分ける）と 7.7 の ἀνακρίνει（判断する）は訳し分ける。

### 7.7 προφέρουσιν（g¹、l、p は προσφέρουσιν）、ἐγγεγενῆσθαι（e は γεγενῆσθαι、vulg は ἂν γεγενῆσθαι）、πως（d は欠く）、πονηροῦ θεοῦ（l* と vulg は θεοῦ を欠く）と、文の組み立て
- 底本：ταύτην οἶμαι τὴν αἰτίαν τῆς τῶν δογμάτων τούτων μυθοποιίας τοῖς τὰ τοιαῦτα προφέρουσιν ἐγγεγενῆσθαι, ὅτι πρὸς τὸ ἡδὺ τῆς σωματικῆς ἀπολαύσεως τὸ ἀγαθὸν ὁριζόμενοι διὰ τὸ πάθεσι καὶ ἀρρωστήμασιν ὑποκεῖσθαι … ἐπακολουθεῖν δέ πως τοῖς τοιούτοις παθήμασιν ἀλγεινήν τινα αἴσθησιν, πονηροῦ θεοῦ τὴν ἀνθρωποποιίαν ἔργον εἶναι νομίζουσιν。
- ほかの読み：g の訂正者、l、p は προφέρουσιν の代わりに προσφέρουσιν。e は ἐγγεγενῆσθαι の代わりに γεγενῆσθαι、vulg は ἂν γεγενῆσθαι（n95 の 7 行目）。d は πως を欠く（11 行目）。l の最初の手と vulg は πονηροῦ θεοῦ の θεοῦ を欠く（「悪しき者のわざ」。12 行目）。
- 採る校訂者：底本は刷られた本文の形。注解は、μυθοποιία に序の τὰς ἠπατημένας περὶ τῶν δογμάτων μυθοποιίας（0.4）を比べ、ἐγγίγνεσθαι は inesse、innasci の意味で、クセノフォン『ソクラテスの思い出』1.2.21 を比べる。Krabinger の句読は悪く、ὅτι は νομίζουσιν を支配し、ἐπακολουθεῖν は ὑποκεῖσθαι と結んで διὰ τό に属する、と言う。πρὸς τὸ ἡδύ は「善を体の楽しみの快さに照らして定める」で、σωματικῆς は引用の πνευματικός と対比されると言う。πάθεσι καὶ ἀρρωστήμασιν はここではどちらも体の病で、8 章の τὰ τῆς ψυχῆς ἀρρωστήματα（魂の病）と違うと言う。英訳は「悪しき神のわざ」の意味で訳しており、θεοῦ ありの読みに立っている。
- 読者への影響：小（θεοῦ を欠いても「悪しき者のわざ」で、マニ教の悪の原理を言うことは変わらない）。
- 訳での扱い：訳注なし。注解に従い、ὅτι の節の主動詞を νομίζουσιν（考える）に取り、διὰ τό の二つの不定詞（体が情念と病に服すること、苦しみに痛みの感覚が続くこと）を理由としてまとめる。μυθοποιία は 0.4 の訳と揃える。σωματικῆς と 7.7 の πνευματικός の対比が見えるように訳す。

### 7.8 ὡς εἴγε … ἀπαθῶς ἐπεσκόπουν（διάνοια と νοῦς）
- 底本：ὡς εἴγε πρὸς τὸ ὑψηλότερον ἔβλεπεν αὐτοῖς ἡ διάνοια, καὶ τῆς περὶ τὰς ἡδονὰς διαθέσεως τὸν νοῦν ἀποικίσαντες ἀπαθῶς ἐπεσκόπουν τὴν τῶν ὄντων φύσιν, οὐκ ἂν ἄλλο τι κακὸν εἶναι παρὰ τὴν πονηρίαν ᾠήθησαν。異読はない。
- 取り方：注解は「もし彼らの思いがより高い方へ目を向け、知性を快楽を求める心の傾きから引き離して、情念に左右されずにものの本性を見ていたなら」と取り、διάνοια と νοῦς について 6 章（p. 35、6.14 の注）を見よと言う。οὐκ ἂν ἄλλο については、道徳の悪だけが κακόν だという原理がこの書の全体を通す考えで、9 章（受肉は神をおとしめない）、15〜16 章（キリストが取ったのは道徳の弱さでなく体の弱さ）にも出ると言い、オリゲネスにもあり、悪の座を意志に置くことに根があると言う。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：小。
- 訳での扱い：訳注なし。διάνοια（思い）と νοῦς（知性）は訳語表どおり訳し分ける。ἀπαθῶς は ἀπάθεια（情念に動かされないこと）の系。

### 7.9 ἐφ᾽ ἑαυτοῦ（g*、p は ὑφ᾽ ἑαυτοῦ、f は ἢ ἀφ᾽ ἑ.）、τῷ μὴ εἶναι（p は τό）、τὸ ἀγαθόν（f は τό を欠く）

### 7.10 ὁ ἆθλον（f、l と vulg は ὁ を欠く）、γέρας（l*vid と vulg は πέρας）、προθείς（d、e、g、h、n、p は προσθείς）、ἄψυχον（vulg は ἔμψυχον）
- 底本：ὁ ἆθλον τῆς προαιρέσεως τὸ τῶν ἀγαθῶν γέρας τοῖς κατ᾽ ἀρετὴν πολιτευομένοις προθείς, οὐκ ἀνάγκῃ τινὶ βιαίᾳ πρὸς τὸ ἑαυτῷ δοκοῦν ὑποζεύξας τὴν ἀνθρωπίνην φύσιν, καθάπερ τι σκεῦος ἄψυχον ἀκουσίως πρὸς τὸ καλὸν ἐφελκόμενος。

- 6.2 の注解が挙げるユスティノス『トリュフォンとの対話』119 章、エイレナイオス 5.22.2、アタナシオス『異教徒駁論』3、『神のことばの受肉』4、25、オリゲネス『諸原理について』3.5 の本文は見ていない。注解がそれらを挙げることだけを確かめた。6.8 の注解のメトディオス、ルフィヌス、バシレイオス、ダマスコスのヨアンネス、7.5 のプラトン『国家』429E〜430A、6.7 の『ティマイオス』42A、6.2 の『ティマイオス』82C、7.7 のクセノフォンも同じ。
- 6.14 の αὐτὸν ἑαυτοῦ γενέσθαι πείσας φονέα（人を自分自身の殺害者にした）がヨハネ八・四四（悪魔は初めから人殺し）を響かせるかどうか。注解は挙げず、本文も照らしていない。
- 6.17 の κατάρα（のろい）と αἰσχύνη（恥）が創世記三章（三・七〜一〇、一七）を響かせることは、論点一覧の判断で、注解は 6.15 の τῆς θείας ἐμφανείας に創世記三章を挙げるだけ。
- 6.9 の ἐπὶ μηδενὶ κακῷ κτισθείς と知恵の書二・二三 の ἔκτισεν … ἐπ᾽ ἀφθαρσίᾳ の言い方の近さは、論点一覧の判断で、注解は挙げていない（本文は確かめた）。
