## 8.1〜8.11 死は、悪を取り除くための神の配慮であること

### 8.1 διάλυσιν（l*vid と vulg は ἀνάλυσιν）、καὶ τοῦτο … σβέννυσθαι（l* と vulg は欠く）と、ζωή と βίος
- 底本：Ἀλλ᾽ ἀγανακτεῖ πάντως ὁ πρὸς τὴν διάλυσιν βλέπων τοῦ σώματος, καὶ χαλεπὸν ποιεῖται τῷ θανάτῳ τὴν ζωὴν ἡμῶν διαλύεσθαι, καὶ τοῦτό φησι τῶν κακῶν ἔσχατον εἶναι, τὸ τὸν βίον ἡμῶν τῇ νεκρότητι σβέννυσθαι。
- ほかの読み：l の最初の手（らしい）と vulg は διάλυσιν の代わりに ἀνάλυσιν（n97 の異読の欄、8 章の 3 行目）。l の最初の手と vulg は καὶ τοῦτό … σβέννυσθαι を欠く（5〜6 行目）。
- 採る校訂者：底本は刷られた本文の形。注解は、ζωή の「解かれること」は、死によって人の本性を組み立てる部分が解かれることを言い、βίος の「消えること」は、生の外に表れるはたらきがやむことを言う、と二つを分ける。τοῦ σκυθρωποῦ（8.2）は「この陰鬱に見える必然」、εὐεργεσίας は、死が堕落の後に体を堕落の結果から逃れさせるための神の恵みの備えであることを言う、と注解は言う。
- 読者への影響：小。l* と vulg の欠落は、相手の反論の言い直しを落とすだけ。
- 訳での扱い：訳注なし。ζωή（組み立ての解かれる「いのち」）と βίος（外に表れる「生」「暮らし」）を、注解に従って訳し分けるか、メインで決める。8.3 の τὸ ζῇν、τοῖς τοῦ βίου μετέχουσιν、8.4 の ὁ τῆς ζωῆς χορηγός、βιῴημεν も同じ組の語。

### 8.4 βλέπει（vulg は βλέπῃ）、ἐπεσπασάμεθα（l*vid と vulg は ἐξεσπασάμεθα）、καταμίξαντες（d は παραμίξαντες）、ἐναπειλημμένης（d、g、h、n、p は ἀπειλημμένης、e は ἀπειλημένης）

### 8.4 ἀναπλασθείη の後の付加（d、e、g、h、l¹、n、p は εἴ γε τὸ κατ᾽ εἰκόνα ἐν τῇ παρούσῃ ζωῇ διεσώσατο を加える）
- 底本：ὅπως ἂν τῆς νῦν ἐναπειλημμένης αὐτῷ ῥυπαρίας ἀποκριθείσης εἰς τὸ ἐξ ἀρχῆς σχῆμα διὰ τῆς ἀναστάσεως ἀναπλασθείη. τὸ δὲ τοιοῦτον δόγμα …。
- ほかの読み：d、e、g、h、l の訂正者、n、p は ἀναπλασθείη の後に εἴ γε τὸ κατ᾽ εἰκόνα ἐν τῇ παρούσῃ ζωῇ διεσώσατο（「もしこの世のいのちのうちで、かたちにかなうものを保ったなら」）を加える（n98 の異読の欄、14 行目の項。刷りは `+ ει γε το κατ εικονα εν τη παρουση ζωη διεσωσατο deghl¹np`）。
- 採る校訂者：底本は付加なし（f と、l の最初の手）。注解は、写本の一つの群がこの句を加え、Krabinger はこれを本文に入れたが、f と l にはなく、疑わしい響きがあり、文脈にそぐわない考えを持ち込むと言う。後の付加で、この箇所が万人の救いを説くと読まれるのを防ぐためのものだろう、と言う。英訳はこの句を訳している（l. 43163〜43164）。
- 読者への影響：大。付加があると、復活による初めの形への造り直しが、この世で神のかたちを保った人に限られる。付加がなければ、人が土に返るのは、だれについても汚れを取り除いて造り直すためだ、という文になる。8.13〜8.16 の、この世で癒やされなかった魂も後の世で癒やされるという論とつながるのは底本の形。英訳など付加のある本文で読んだ読者には、違いが目立つ。
- 訳での扱い：訳注を付ける。注の案：「多くの写本は『この世で神のかたちを保っていれば』と加える。後の付加とみられる。」（39 字）。訳は底本どおり付加なしで訳す。

### 8.5 δερματίνους ἐπιβάλλει χιτῶνας τοῖς πρωτοπλάστοις ὁ κύριος（創世記三・二一）
- 底本：ἐπειδὴ γάρ, φησίν, ἐν τοῖς ἀπηγορευμένοις ἐγένοντο οἱ πρῶτοι ἄνθρωποι καὶ τῆς μακαριότητος ἐκείνης ἀπεγυμνώθησαν, δερματίνους ἐπιβάλλει χιτῶνας τοῖς πρωτοπλάστοις ὁ κύριος。異読はない。
- 取り方：七十人訳（Swete）の創世記三・二一 は καὶ ἐποίησεν Κύριος ὁ θεὸς τῷ Ἀδὰμ καὶ τῇ γυναικὶ αὐτοῦ χιτῶνας δερματίνους, καὶ ἐνέδυσεν αὐτούς。グレゴリオスの文は χιτῶνας δερματίνους の語だけを取り、動詞（ἐπιβάλλει、着せかける）、受ける者（τοῖς πρωτοπλάστοις）、主語（ὁ κύριος だけ）を自分の言葉にした言い換え。底本も地の文と同じ字体で刷る。注解は ἐν τοῖς ἀπ. を「禁じられたことに巻き込まれた」、ἀπεγυμν. について「皮の衣が ἀπάθεια（情念からの自由）に取って代わる」、πρωτοπλάστοις を、知恵の書七・一、一〇・一 で最初の人に使われる語だと言う。知恵の書七・一 は γηγενοῦς ἀπόγονος πρωτοπλάστου、一〇・一 は πρωτόπλαστον πατέρα κόσμου（Swete）。口語訳の創世記三・二一 は「主なる神は人とその妻とのために皮の着物を造って、彼らに着せられた」。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：小。
- 訳での扱い：訳注なし。言い換えなので『』に入れず、χιτῶνας δερματίνους だけを口語訳の「皮の着物」に寄せる。続く 8.5 の ὁ γὰρ χιτών（着物は外から着せかけるもの）と 8.12 の τῶν νεκρῶν δερμάτων ἐπιβολῆς は同じ喩えなので、χιτών は「着物」、δέρμα は「皮」で通す。出典（創世記三・二一）。ἀπεγυμνώθησαν は「裸にされた」で、創世記三章の裸を響かせる訳にする。

### 8.5 οὔ μοι δοκεῖ … φέρων（g と p は φέρειν）の主語、τε（e、l は欠く）、τόν（e は欠く）、εἰς ἀεί（h は εἰς を欠く）、τῷ σώματι（vulg は τοῦ σώματος）
- 底本：ὁ κύριος· οὔ μοι δοκεῖ πρὸς τὰ τοιαῦτα δέρματα τοῦ λόγου τὴν διάνοιαν φέρων· ποίων γὰρ ἀποσφαγέντων τε καὶ δαρέντων ζῴων ἐπινοεῖται αὐτοῖς ἡ περιβολή; … ἐπιβεβληκέναι τὸν τὴν κακίαν ἡμῶν ἰατρεύοντα, οὐχ ὡς εἰς ἀεὶ παραμένειν· … πρὸς καιρὸν τὴν ἑαυτοῦ χρῆσιν παρέχων τῷ σώματι。
- ほかの読み：g と p は φέρων の代わりに φέρειν（n99 の 7 行目）。e と l は ἀποσφαγέντων τε の τε を欠く（同）。e は τὸν τὴν κακίαν の τόν を欠く（12 行目）。h は εἰς ἀεί の εἰς を欠く（13 行目）。vulg は τῷ σώματι の代わりに τοῦ σώματος（15 行目）。
- 採る校訂者：底本は φέρων。注解は「（モーセは）言葉の意味を、こうした文字どおりの皮に向けているのではない、とわたしは思う」と取り、φέρων は φησίν の主語、つまりモーセにかかり、δοκεῖ は挟み込みだと言う。g と p の φέρειν なら「（モーセが）向けているとは、わたしには思えない」と、δοκεῖ が本動詞になる。英訳は「わたしの考えでは、この皮を文字どおりに取らなくてよい」の意味で、主語をモーセにせずに訳している。
- 読者への影響：中（構文）。注解の取り方なら、皮を文字どおりに取らないのはモーセ自身の意図で、グレゴリオスはそう推し量っている。英訳の取り方では、読み手への指示になる。
- 訳での扱い：訳注なし。注解に従い、「モーセは、わたしの思うに、言葉の意味をこのような皮に向けているのではありません」のように、主語をモーセにし、「わたしの思うに」を挟み込みにする。注解は εἰς ἀεὶ παραμένειν について、最初の人は不死と朽ちないことの祝福を受けていたので（5 章、『人間の創造について』4、『モーセの生涯』）、死は一時の備え、しばらく着せられる「着物」で、そのため οὐ συμπεφυκὼς τῇ φύσει（本性に生まれつきついたものではない）と言う、と言う。
- 確かめた資料：画像 `n99_w1600.jpg`（全体）。l. 6765〜6766。注解 l. 6779〜6808。英訳 l. 43170〜43179。

### 8.5 ἐκ προμηθείας … τὸν τὴν κακίαν ἡμῶν ἰατρεύοντα（死ぬ力は理性をもたない本性のもの）
- 底本：ἀλλ᾽, ἐπειδὴ πᾶν δέρμα χωρισθὲν τοῦ ζῴου νεκρόν ἐστι, πάντως οἶμαι τὴν πρὸς τὸ νεκροῦσθαι δύναμιν, ἣ τῆς ἀλόγου φύσεως ἐξαίρετος ἦν, ἐκ προμηθείας μετὰ ταῦτα τοῖς ἀνθρώποις ἐπιβεβληκέναι τὸν τὴν κακίαν ἡμῶν ἰατρεύοντα。異読は前の項のとおり。
- 取り方：注解は、グレゴリオスにとって皮は、理性をもたない本性に特有の、死ぬ力を表すと言い、『魂と復活について』で δέρμα を「理性をもたない本性の形で、情念に親しくなったわたしたちが、それを着せられた」と説くこと、『処女性について』12 で皮の衣を「肉の思い」とすること、『死者について』を比べる。

### 8.23〜8.24 ἀπολομένην（l と vulg は ἀπολλυμένην）、κατ᾽ ἀρχάς（l と vulg は ἐξ ἀρχῆς）、μανθάνοντες（e は μανθάνομεν）と、τὸ μυστήριον τῆς ἀληθείας
- 底本：τῷ γὰρ ἐξ ἀρχῆς τὴν ζωὴν δεδωκότι μόνῳ δυνατὸν ἦν καὶ πρέπον ἅμα καὶ ἀπολομένην ἀνακαλέσασθαι. ὃ παρὰ τοῦ μυστηρίου τῆς ἀληθείας ἀκούομεν, θεὸν πεποιηκέναι κατ᾽ ἀρχὰς τὸν ἄνθρωπον καὶ σεσωκέναι διαπεπτωκότα μανθάνοντες。
- ほかの読み：l と vulg は ἀπολομένην（アオリスト）の代わりに ἀπολλυμένην（現在。n108 の 3 行目）。l と vulg は κατ᾽ ἀρχάς の代わりに ἐξ ἀρχῆς（5 行目）。e は μανθάνοντες の代わりに μανθάνομεν（6 行目）。
- 採る校訂者：底本は刷られた本文の形。8.24 の τὸ μυστήριον τῆς ἀληθείας について 8 章の注解はないが、すぐ後の 9.1 の同じ句について、注解は受肉の教えのことで、それは誕生などの事柄の上に立ち、それによって確かにされる、と言う（9.1 では f が ἀληθείας の代わりに εὐσεβείας、euth 1、4、5、6 が οἰκονομίας と読む）。
- 読者への影響：小。
- 訳での扱い：訳注なし。μυστήριον は訳語表の「奥義」で、「真理の奥義」。9.1 の同じ句と同じ訳にする。
