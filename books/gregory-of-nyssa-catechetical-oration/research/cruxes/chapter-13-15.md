## 13 章　誕生と死は人の本性に固有だという反論と、その前と後は本性を越えるという答え

### 13.1〜13.11 γέννησις と γένεσις、γεγεννῆσθαι と γεγενῆσθαι の入れ替わり
- 底本：13 章には「生まれる」の語が二つの系で出る。名詞は 13.1 の γέννησις（2 回）、13.3 の ἡ γέννησις、τῆς γεννήσεως、13.9 の τὴν γέννησιν、13.10 の τὴν γέννησιν αὐτοῦ（γεννάω の系）と、13.7 の τῷ τῆς γενέσεως τρόπῳ（γίγνομαι の系）。不定詞の完了は、13.7 の γεγενῆσθαι μὲν αὐτὸν ἀκούεις と 13.11 の ἐν τοῖς ὑπὲρ τὴν φύσιν γεγενῆσθαι（γίγνομαι）、13.8 の 2 回、13.9 の 2 回、13.10 の γεγεννῆσθαι（γεννάω）。
- ほかの読み（n115〜n118 の異読の欄）：
  - 13.1 の γέννησίς τε καὶ θάνατος：g の訂正者は γένεσις（n115 の 17 行目）。13.1 の τὸ πρὸ τῆς γεννήσεως：d、g、h、n、p と euth は γενέσεως（n116 の 1 行目）。
  - 13.3 の ἡ γέννησις：d、g、h、n、p は γένεσις（n116 の 6 行目）。τῆς γεννήσεως ἡδονή：d、g、h、n、p は γενέσεως（8 行目）。
  - 13.7 の γεγενῆσθαι μέν：d、e、h、n と euth 2、4、5 は γεγεννῆσθαι（n117 の 8 行目）。τῆς γενέσεως τρόπῳ：e、f の訂正者と euth 2、4 は γεννήσεως（10 行目）。
  - 13.8：p と euth 1 は γεγενῆσθαι（n117 の 16 行目。16 行目には ὁ γὰρ γεγεννῆσθαι と、行末で分けられた τὸ ἐκ παρθένου γεγεν-｜νῆσθαι の頭があり、どちらの項かは刷りから決まらない）。
  - 13.9：l、p は γεγενῆσθαι（n117 の 18 行目の τὸ γεγεννῆσθαι αὐτόν）。f、p は γεγενῆσθαι（19 行目の οὕτως αὐτὸν γεγεννῆσθαι）。
  - 13.10：n の最初の手と p は γεγενῆσθαι（n118 の 4 行目）。τὴν γέννησιν αὐτοῦ：d、g、h、n、p は γένεσιν（5 行目）。
  - 13.11 の γεγενῆσθαι：d、e、g、h は γεγεννῆσθαι（n118 の 8 行目）。
- 採る校訂者：底本は、名詞では d、g、h、n、p の γένεσις を採らず γέννησις とし、13.7 だけは逆に γένεσις を採る（e、f¹、euth 2、4 の γεννήσεως を採らない）。注解は、グレゴリオスは γένεσις と γέννησις をほとんど入れ替えのきく語として使うらしいが、13.7 は写本の群の分かれ方から γένεσις が確かで、16 章と 27 章にも異読なしで出る、と言う。不定詞では、γεγεννῆσθαι の側（13.8〜13.10）でも γεγενῆσθαι の側（13.7、13.11）でも写本が割れる。15 章にも 15.1 の τοῦ γενέσθαι θεὸν ἐν ἀνθρώποις（vulg は γεγενῆσθαι）、15.8 の ἐν κακίᾳ γεγενῆσθαι、15.9 の ἐν ἀνθρώπου γίνεται φύσει、ἐν ᾧ οὔτε γέγονεν θεός, οὔτε γενέσθαι φύσιν ἔχει と γίγνομαι が続く（15.9 の項）。英訳は 15.1 と 15.8 の γίγνομαι の形を「生まれる」の意味で訳す。
- 読者への影響：中（語の選び方）。13 章の反論と答えは「生まれること」と「死ぬこと」をめぐるので、γέννησις は「誕生」で動かない。迷うのは γίγνομαι の系で、13.7 の τῷ τῆς γενέσεως τρόπῳ（その生まれ方）は誕生のことだが、13.11 の ἐν τοῖς ὑπὲρ τὴν φύσιν γεγενῆσθαι と 15 章の γενέσθαι、γεγενῆσθαι、γέγονεν は「（〜のうちに）来た、なった」とも「生まれた」とも取れる。chapter-09-12 の 11.2 の項は、γεγενῆσθαι θεὸν ἐν ἀνθρώπου φύσει を「来られた」の向きにするか、メインに回した。
- 訳での扱い：訳注なし。γέννησις は「誕生」、13.7 の γένεσις も誕生を言うので「生まれ方」とし、訳を分けない。γίγνομαι の完了と不定過去（13.11、15.1、15.8、15.9）を「生まれる」とするか、11.2 の決めごとに合わせて「（人のうちに）来られる」とするか、メインで決める（15.9 の項）。

### 13.2〜13.3、13.10 πάθος の二つの意味と、15.4 の ἀπάθεια、15.9 の τὸ κατὰ κακίαν πάθος
- 底本：ἐκ πάθους γὰρ ἀρξάμενος τοῦ εἶναι ὁ ἄνθρωπος πάθει συναπαρτίζεται. ἐκεῖ δὲ οὔτε ἡ γέννησις ἀπὸ πάθους ἤρξατο, οὔτε ὁ θάνατος εἰς πάθος κατέληξεν· οὔτε γὰρ τῆς γεννήσεως ἡδονὴ καθηγήσατο, οὔτε τὸν θάνατον φθορὰ διεδέξατο（13.2〜13.3）。ἐκ τῶν αὐτῶν δώσεις πάντως καὶ τὸ ἔξω πάθους εἶναι καὶ τὴν γέννησιν αὐτοῦ καὶ τὸν θάνατον（13.10）。この語には異読はない。
- 取り方：注解は、この箇所で πάθος は二つの違う意味で使われ、その語のあいまいさをグレゴリオスが解くのは 16 章になってからだ、と言う。誕生に当てはめると、πάθος は本来は親の側の πάθος で（下の ἡδονή を見よ）「情欲」を言い、死に当てはめると、φθορά に服することに表れる不完全さ、もろさ、弱さを言う、と言う。συναπαρτίζεται は「その生を閉じる」、すなわち φθορά を伴う死の πάθος によって、と取る。ἐκεῖ δέ（キリストの場合）は、人の生では πάθος を伴う両端（πέρατα）のどちらにも神の力が表れ、誕生に ἡδονή が先立たず、死に φθορά が続かなかった、と言う。16 章の要約は、πάθος という語は本来、道徳の堕落にだけ使え、本性の過程には使えない、とグレゴリオスが区別すると言う（l. 9069〜9080）。15.4 の注解は、反論者の言う受肉の仕方は πάθη に服することを含み、グレゴリオスはまず、受肉によって神が πάθη に巻き込まれたという非難を 15 章と 16 章で扱う、と言う（l. 8863〜8879）。英訳は 13 章の πάθος をどれも同じ一つの語（「弱さ」の意味）で訳し、15.9 の τὸ κατὰ κακίαν πάθος も同じ語に「悪い」を付けて訳す。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：大（語の選び方）。訳語表の πάθος の項は「情念（魂の）、苦しみ（体の）」と分け、9.3 の τὸ κατὰ κακίαν πάθος を「悪による情念」とし、15 章の終わり（15.9）も同じ訳にすると決めている。ところが 13 章では、（1）誕生の πάθος（親の情欲）と死の πάθος（朽ちることへのもろさ）が同じ語で並び、（2）13.10 の τὸ ἔξω πάθους εἶναι は、一つの句で誕生と死の両方にかかる。（3）16 章は、本当に πάθος と呼べるのは悪だけだという論で、15.9 の「悪による〜」と同じ語でつながる。（4）15.4 の反論の ἐν ἀπαθείᾳ τὸν θεὸν διαμεῖναι は、神が誕生や死という πάθη を受けずにいることで、訳語表の ἀπάθεια（5.17 の「情念に動かされないこと」）の意味とずれる。誕生には「情念」、死には「苦しみ」と訳し分けると、13.10 の句が一語で言えず、16 章の論も切れる。
- 訳での扱い：訳注なし。13〜16 章の πάθος と 15.4 の ἀπάθεια を一つの語で通すか（誕生と死の両方にかかり、15.9 の「悪による〜」にもつながる語）、意味ごとに訳し分けて `// ` メモで同じ語であることを書くか、訳す前にメインで決め、訳語表の πάθος と ἀπάθεια の項を書き直す。ἡδονή は「快楽」、φθορά は訳語表の「朽ちること」、13.6 の διαφθορά も同じ系（次の項）。

### 13.3 φθορά、13.6 διαφθορά と詩篇一五・一〇（七十人訳）、使徒二章（注解の「Acts ii 10」）
- 底本：οὔτε τὸν θάνατον φθορὰ διεδέξατο（13.3）。ἄνθρωπος μὲν γὰρ ἐκ συνδυασμοῦ τίκτεται καὶ μετὰ θάνατον ἐν διαφθορᾷ γίνεται（13.6）。τῷ ἀνεπιδέκτῳ τῆς εἰς φθορὰν ἀλλοιώσεως（13.7）。
- 注解が挙げる箇所：13.3 の φθορά に「詩篇一五・一〇、使徒二・一〇」を比べ、どちらにもある διαφθορά の語が下（13.6）に出る、と言う。詩篇一五・一〇（七十人訳の番号。口語訳の一六・一〇）は οὐδὲ δώσεις τὸν ὅσιόν σου ἰδεῖν διαφθοράν（Swete II）。使徒二・一〇 は地名の並び（フルギヤ、パンフリヤ…）で διαφθορά はなく、この詩篇を引くのは使徒二・二七（同じ句。二・三一 にも οὐδὲ ἡ σὰρξ αὐτοῦ εἶδεν διαφθοράν）。画像では「ii 10」と刷られている（`pct:52,64.5,40,5 --scale 1` で拡大）。「27」の誤植と見る（論点一覧の判断）。

### 13.4〜13.6 τὸ κήρυγμα（第一コリント二・四）と、13.5 の ὅρων（euth は πάντα を加える）、τοῦ Χριστοῦ（f は τοῦ を欠く）、τὴν φύσιν（euth は ἐν πολλοῖς を加える）、θεόν（euth は καὶ θεόν）
- 底本：τὸ μὴ διὰ τῶν κατὰ φύσιν προιέναι τὸ κήρυγμα. εἰ γὰρ ἐντὸς ἦν τῶν τῆς φύσεως ὅρων τὰ περὶ τοῦ Χριστοῦ διηγήματα, ποῦ τὸ θεῖον; εἰ δὲ ὑπερβαίνει τὴν φύσιν ὁ λόγος, ἐν οἷς ἀπιστεῖς, ἐν τούτοις ἐστὶν ἡ ἀπόδειξις τοῦ θεὸν εἶναι τὸν κηρυσσόμενον。…εἰ ταῦτα περιεῖχε τὸ κήρυγμα（13.6）。

- 底本：καθάπερ γὰρ πολλῶν ὄντων τῶν ἐν τῇ κτίσει θεωρουμένων οὐδὲν ἄλλο πρὸς τὸ φῶς ἢ τὴν ζωὴν τὴν ἀντιδιαίρεσιν ἔχει, οὐ λίθος, οὐ ξύλον, οὐχ ὕδωρ, οὐκ ἄνθρωπος, οὐκ ἄλλο τι τῶν ὄντων οὐδέν, πλὴν ἰδίως τὰ κατὰ τὸ ἐναντίον νοούμενα, οἷον σκότος καὶ θάνατος· οὕτω καὶ ἐπὶ τῆς ἀρετῆς οὐκ ἄν τις κτίσιν τινὰ κατὰ τὸ ἐναντίον αὐτῇ νοεῖσθαι λέγοι, πλὴν τὸ κατὰ κακίαν νόημα。
- ほかの読み：f は ἐν τῇ κτίσει の代わりに ἐν τῇ φύσει（n121 の 8 行目。15.9 の φύσις δέ τις と同じ語になる）。euth は ἀντιδιαίρεσιν の代わりに ἀντίθεσιν（9 行目）。euth 1 は αὐτῇ を欠く（13 行目）。euth 4 は νόημα の代わりに κίνημα（14 行目）。
- 採る校訂者：底本は κτίσει（f に従わない）。注解は ἰδίως を「ただ、その正確な反対と考えられるものだけは別として」と取る。15.9 の注解は、ἀντιδιαιρεῖσθαι に 6 章 p. 33 の注を見よと言い、「論理の上で対置される」の意味で言い換える（次の項）。
- 読者への影響：中（語の選び方）。訳語表は ἀντιδιαιρεῖσθαι を「どの箇所でも『言葉の上で』を付ける（15 章にも出る）」とする。15.7 の名詞 ἀντιδιαίρεσις と 15.9 の動詞 ἀντιδιαιρεῖται が、その 15 章の箇所。
- 訳での扱い：訳注なし。訳語表のとおり、ἀντιδιαίρεσις・ἀντιδιαιρεῖται に「言葉の上で（対置される）」を付ける。光と闇、いのちと死の例が論の要なので、並び（石、木、水、人…）は一つずつ訳す。τὸ κατὰ κακίαν νόημα は「悪という考え」。15.7 の κτίσις は「被造物」で、15.9 の φύσις τις（注解では κτίσις と同じ）と同じ訳にするか、メインで決める（次の項）。

### 15.8 καιρὸν εἶχεν（l と vulg は ἄν を加える）、φύσεως（h は πίστεως）、δογματιζόντων（f、g¹、l と vulg は δοξαζόντων）、αὐτοσοφίαν（vulg は τὴν αὐτοσοφίαν、f は τὴν αὐτοῦ σοφίαν）、εἴ τι（g¹ は ὅ τι）、ἐστι（f は欠く）と、euth 5 の再開
- 底本：οὐκοῦν εἰ μὲν ἐν κακίᾳ γεγενῆσθαι τὸ θεῖον ὁ ἡμέτερος ἐπρέσβευε λόγος, καιρὸν εἶχεν ὁ ἀντιλέγων κατατρέχειν ἡμῶν τῆς πίστεως, ὡς ἀνάρμοστά τε καὶ ἀπεμφαίνοντα περὶ τῆς θείας φύσεως δογματιζόντων· οὐ γὰρ δὴ θεμιτὸν ἦν αὐτοσοφίαν καὶ ἀγαθότητα καὶ ἀφθαρσίαν, καὶ εἴ τι ὑψηλόν ἐστι νόημά τε καὶ ὄνομα, πρὸς τὸ ἐναντίον μεταπεπτωκέναι λέγειν。
- ほかの読み：l と vulg は καιρὸν ἂν εἶχεν（n121 の 15 行目）。h は φύσεως の代わりに πίστεως（17 行目）。f、g の訂正者、l と vulg は δογματιζόντων（説く）の代わりに δοξαζόντων（考える、思いなす。同）。vulg は τὴν αὐτοσοφίαν、f は τὴν αὐτοῦ σοφίαν（「その（神の）知恵」。18 行目）。g の訂正者は εἴ τι の代わりに ὅ τι（19 行目）。f は ὑψηλόν ἐστι の ἐστι を欠く（同）。euth 5 は καὶ ὄνομα から再び始まる（同）。
- 採る校訂者：底本は δογματιζόντων、αὐτοσοφίαν で、f l と g の訂正者の一致（δοξαζόντων）に従わない。注解はこの読みに触れない。注解は ἐπρέσβευε を「説いた」と取り、ルキアノス『漁師』23 を比べ、κατατρέχειν に 5 章を、ἀπεμφαίνοντα に 1 章 p. 10 の注（chapter-01 の 1.11 の項）を見よと言う。英訳は「知恵そのもの」の意味で訳し、αὐτοσοφίαν に立つ。また ἐν κακίᾳ γεγενῆσθαι を「悪い事情のもとで生まれた」の意味で訳す。
- 読者への影響：小。f の τὴν αὐτοῦ σοφίαν では「神の知恵」となり、「知恵そのもの」という、神を抽象の名で言う言い方が消える。
- 訳での扱い：訳注なし。αὐτοσοφία は「知恵そのもの」とし、ἀγαθότης（善）、ἀφθαρσία（朽ちないこと。訳語表）と並べる。ἀπεμφαίνοντα は訳語表の ἀπεμφαίνω（1.11「ふさわしくない」、10.3「そぐわない」）のどちらに揃えるか、ἀνάρμοστα（調和しない）と組む語として決める。δογματιζόντων は訳語表の δόγμα（教会の「教え」）の動詞で、相手がわたしたちを非難する文なので「説く」。ὁ ἀντιλέγων は単数で、15.9 の ἐπαισχύνονται（複数）に移る（次の項）。ἐν κακίᾳ γεγενῆσθαι は 13.1〜13.11 の項（γίγνομαι の訳）。

### 15.9 θεός（d、e、g、h、n、p と euth は ὁ θεός）、γενέσθαι（l と vulg は τοῦ γενέσθαι）、τῇ ὁμολογίᾳ（vulg は τὴν ὁμολογίαν）と、φύσις τις、φύσιν ἔχει、ἅψασθαι、τὸ λογικόν、οὐσία の取り方
- 底本：εἰ οὖν θεὸς μὲν ἡ ἀληθὴς ἀρετή, φύσις δέ τις οὐκ ἀντιδιαιρεῖται τῇ ἀρετῇ, ἀλλὰ κακία, θεὸς δὲ οὐκ ἐν κακίᾳ, ἀλλ᾽ ἐν ἀνθρώπου γίνεται φύσει, μόνον δὲ ἀπρεπὲς καὶ αἰσχρὸν τὸ κατὰ κακίαν πάθος, ἐν ᾧ οὔτε γέγονεν θεός, οὔτε γενέσθαι φύσιν ἔχει, τί ἐπαισχύνονται τῇ ὁμολογίᾳ τοῦ θεὸν ἀνθρωπίνης ἅψασθαι φύσεως, … οὔτε γὰρ τὸ λογικόν, οὔτε τὸ διανοητικόν, οὔτε τὸ ἐπιστήμης δεκτικόν, οὔτε ἄλλο τι τοιοῦτον, ὃ τῆς ἀνθρωπίνης ἴδιον οὐσίας ἐστί, τῷ λόγῳ τῆς ἀρετῆς ἠναντίωται。
- ほかの読み：d、e、g、h、n、p と euth は γέγονεν θεός を γέγονεν ὁ θεός とする（n122 の 5 行目）。l と vulg は γενέσθαι の代わりに τοῦ γενέσθαι（同）。vulg は τῇ ὁμολογίᾳ の代わりに τὴν ὁμολογίαν（6 行目）。
- 採る校訂者：底本は冠詞なしの θεός（d e g h n p と euth に従わない）。注解は、φύσις は上の κτίσις（15.7）と同じ意味で使われ、6 章の τῆς τοῦ κρείττονος φύσεως の注を比べ、「どんな種類の存在するものも、論理の上で徳に対置されることはなく、ただ悪だけ」と言い換える。φύσιν ἔχει は πέφυκε と同じで、「（悪のうちに）生まれることは、神の本性ではない（神にはできない）」と言う。ἅψασθαι は「人の本性をつかんだ、とった」で、16 章の τίνος … ἧφθαι τὸ θεῖον; を比べる。οὐδεμιᾶς … は「人の造りには、徳の概念に反するもの、それゆえ ἀπρεπές で αἰσχρόν で、神がとることのできないものは何もないから」と取る。τὸ λογικόν は「理性による思考」、τὸ διανοητικόν は「理解の力」（6 章を比べる）、τὸ ἐπιστήμης δεκτικόν は「正確な知識を受け入れる力」、οὐσίας には 6 章 p. 32 の注を見よと言う。英訳は φύσις を「存在」の意味の語で訳し、脚注 [1980] にギリシア語の語を挙げる。
- 読者への影響：中（語の取り方）。（1）φύσις δέ τις は、訳語表の「本性」ではなく、注解では「（どんな）存在するもの」「被造物」。15.7 の κτίσις と同じものを言い、15.9 の ἐν ἀνθρώπου … φύσει（人の本性）とは別の使い方。（2）ἐν ᾧ οὔτε γέγονεν θεός, οὔτε γενέσθαι φύσιν ἔχει は、注解の言い換えでは「生まれる」だが、本文は ἐν ᾧ（悪による πάθος の中に）で、「その中に神が来たこともなく、来ることも本性にない」とも読める（γίγνομαι の訳。13.1〜13.11 の項）。（3）τί ἐπαισχύνονται は 3 人称複数で、15.8 の単数の ὁ ἀντιλέγων から、反論する人々一般に移る。（4）τὸ λογικόν は、訳語表の ἄλογος（「ことばをもたない」）の肯定の形で、注解の「理性」の意味が前に出る。（5）ἴδιον οὐσίας の οὐσία は、注解が 6 章 p. 32 の注を見よと言う使い方で、訳語表の 6.8 の τις οὐσία（「ある存在」）の系。
- 訳での扱い：訳注なし。φύσις δέ τις は「どんな存在も（被造物も）」の向きで、15.7 の κτίσιν τινά と揃える。τὸ κατὰ κακίαν πάθος は訳語表のとおり 9.3 と同じ訳（13.2〜13.3 の項の決め方による）。ἀπρεπὲς καὶ αἰσχρόν は訳語表の「ふさわしくない」「恥ずべき」、ἐπαισχύνονται は「恥じる」で同じ字にする。ἐπαισχύνονται の主語は「（反論する）人々」と言い添える。ἅψασθαι は「（人の本性に）触れる」より、注解の「とる」の向き（16 章の ἧφθαι と同じ訳）。τὸ λογικόν は「ことばをもつこと」（訳語表の ἄλογος と揃える）か「理性」か、メインで決める。τὸ διανοητικόν は訳語表の διάνοια（思い）の系、τὸ ἐπιστήμης δεκτικόν は「知識を受け入れる力」。τὸν τῆς ἀρετῆς λόγον、τῷ λόγῳ τῆς ἀρετῆς の λόγος は御子でなく「徳の概念、本質」。
