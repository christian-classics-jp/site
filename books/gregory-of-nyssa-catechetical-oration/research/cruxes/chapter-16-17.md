## 16 章　誕生と死は πάθος かという反論と、本来の πάθος は悪だけだという答え、復活による魂と体のふたたびの結合

注解の要約（l. 9069〜9100）によると、16 章の論の運びは次のとおり。

- 反論：人の誕生に伴う変化は πάθος だ。
- 答え：グレゴリオスは πάθος の正しい使い方と誤った使い方を分ける。本来この語は道徳の堕落にだけ使え、本性の過程には使えない。
- 医者のたとえ：神が人の本性に触れても本当の πάθος に服さないのは、医者が患者の病に触れても服さないのと同じ。
- 誕生と生：キリストの誕生には人の誕生に伴う情欲がなく、その生には悪への衝動がなかった。
- 死：魂と体が分かれることは、初めに結びつくことと同じく πάθος ではない。
- 復活：キリストの復活は、死で分かれた知性で知られる要素と感覚で知られる要素とが、解けない永遠の結合へと結び直されることだった。キリストはそれによって、悪の混ざりから解かれた同じ結合の、全人類のための初めとなる。

### 16.1〜16.6 πάθος の「本来の意味」と「転用」（κυρίως／ἐκ καταχρήσεως）と、ἀπαθής、παθητικὴ διάθεσις、ἔργον、κίνημα・κίνησις
- 底本：
  - 16.1：ἡ τροπὴ τοῦ ἡμετέρου σώματος πάθος ἐστίν … ἐν πάθει γίνεται· ἀπαθὲς δὲ τὸ θεῖον … τὸν ἀπαθῆ κατὰ τὴν φύσιν πρὸς κοινωνίαν πάθους ἐλθεῖν。
  - 16.2：τὸ πάθος τὸ μὲν κυρίως, τὸ δὲ ἐκ καταχρήσεως λέγεται. τὸ μὲν οὖν προαιρέσεως ἁπτόμενον … ἀληθῶς πάθος ἐστί, τὸ δ᾽ ὅσον ἐν τῇ φύσει … θεωρεῖται, τοῦτο κυριώτερον ἔργον ἂν μᾶλλον ἢ πάθος προσαγορεύοιτο。
  - 16.3：τοῦ κυρίως λεγομένου πάθους, ὅπερ κακία ἐστίν, ἢ τοῦ κατὰ τὴν φύσιν κινήματος; … μηδεμιᾶς παθητικῆς διαθέσεως … οὐδὲ γὰρ τὸν ἰατρὸν ἐν πάθει γίνεσθαι λέγομεν, ὅταν θεραπεύῃ τὸν ἐν πάθει γινόμενον … ἔξω πάθους ὁ θεραπευτὴς διαμένει。
  - 16.4：τὸ καθ᾽ ἡδονὴν πάθος … ποῖον ὑπολείπεται πάθος … τὴν … διάζευξιν πάθος προσαγορεύοι。
  - 16.5〜16.6：ὁ χωρισμὸς … πάθος ἐστί … ἡ συνάφεια … πάθος ἂν εἴη … ἣν γένεσιν ὀνομάζομεν, πάθος οὐκ ἔστιν … ἣν θάνατον ὀνομάζομεν, πάθος ἂν … λέγοιτο。
  - πάθος の語そのものには異読がない（16.2 の冠詞の異読は次の項）。
- 取り方（注解）：
  - 16.2 の πάθος の注（l. 9162〜9218）は、アリストテレス『形而上学』Δ 21 の πάθος の定義を引き、この語にはいくつもの意味がある、と言う。定義に挙がるのは、変化を受けうる性質、その性質のはたらきと変化、とくに害になる変化や動き、大きな災いの四つ。グレゴリオスは、このあいまいさをつかんで「本来の」使い方と「誤って当てた」使い方を分けた、と言う。
  - 本来の意味（道徳の堕落）では、受肉は πάθος を伴いえない。キリストは、誕生の事情でも自分の生でも、罪に触れなかったから。
  - 反論の ἡ τροπὴ … πάθος が言っているのはもう一つの意味。注解は、医者のたとえがこの意味への答えらしい、と言う。神の本性は人の本性に触れても παθητικὴ διάθεσις に服さない。患者の病に触れる医者が服さないのと同じだ、と言う。
  - 同じ論と同じ医者のたとえが『エウノミオス駁論』第 6 巻（Migne 721 B、C、724 B）にある、と言う。
  - 英語には πάθος のどの意味も表す一語がない、とも言う。英訳は「弱さ」の意味の語を使う。もう一つの候補の「パッション」は、道徳の意味にもキリストの体の苦しみにも使えるが、誕生の過程には合わない、と言う（13 章 p. 60 の注を見よ）。
  - 16.2 の注（l. 9295〜9300）は、διεξοδικῶς を「順を追って細かに」と取る。この文を「本性がその固有の順に進むとき、本性のうちで順を追って起こることはみな、『πάθος』よりも、より正確には『はたらき（ἔργον）』と呼ばれる」と言い換える。
  - 16.3 の κινήματος は、上で ἔργον と定義したもの（誕生、成長など本性の過程）と言う（l. 9325〜9328）。
  - 16.3 の μηδεμιᾶς は「神についてのわたしたちの考えには、πάθος への傾きがわたしたちの信仰とともに入ってくることはない」と取る（l. 9389〜9397）。
  - 英訳は 16 章の πάθος をすべて同じ一語（「弱さ」）で訳す。脚注 [1983] は、ここでグレゴリオスが言うのは体のもろさではなく道徳の弱さだ、と言う。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：大（語の選び方）。
  - 訳語表の πάθος の項は、13 章の誕生の側を「情念」、死の側を「苦しみ」と訳し分ける。13.10 は「情念と苦しみの外」、15.4 の ἐν ἀπαθείᾳ は「苦しみを受けないまま」、15.9 の τὸ κατὰ κακίαν πάθος は「悪による情念」と訳した。そして「16 章もこの訳し分けに合わせる」とする。
  - ところが 16 章は語そのものを論じる。（1）16.2 は「πάθος という語には本来の言い方と転用がある」と、一つの語の二つの使い方を立てる。その上で、本来の πάθος は悪であり、本性の過程（誕生、成長、栄養による存続、元素の集まりと解体）は πάθος より ἔργον と呼ぶべきだ、と言う。訳し分けると、二つの使い方が同じ語だという論の前提が訳文から消える。
  - （2）16.1 の反論の πάθος（体の変化）と ἀπαθές・τὸν ἀπαθῆ は、15.4 に合わせれば「苦しみ」「苦しみを受けない」。ところが 16.2 の答えでは、本来の πάθος は「悪」で、訳語表の「情念」の側に来る。反論と答えで別の語になる。
  - （3）16.3 の医者のたとえでは、ἐν πάθει γίνεσθαι（医者が）と τὸν ἐν πάθει γινόμενον（患者）が同じ句で並ぶ。患者の側は「病」、医者の側は「病にかかる」とも「苦しみを受ける」とも取れる。ἔξω πάθους（16.3）は 13.10 の句と同じ形。
  - （4）16.4〜16.6 は、誕生（γένεσις）も、死（魂と体の分離）も、それぞれの結合と分離も「πάθος ではない」と同じ述語で並べ、背理法で論じる。
- 訳での扱い：訳注なし。訳す前にメインで決める。訳語表の πάθος と ἀπάθεια の項を書き直すことになる。選択肢は次の二つ。
  - （a）16 章では πάθος を一つの語で通し、16.2 で「本来の意味」と「転用」を言えるようにする。たとえば「苦しみ」で通し、本来の苦しみは悪だと言う形にする。この場合、13.10 と 15.4 の訳語との関係を `// ` メモに書く。
  - （b）訳し分けを保ち、16.2 だけ「πάθος と呼ばれるもの」のように語を地の文で立てて、二つの使い方を説明する。
  - ἔργον は「はたらき」、κίνημα・κίνησις は「動き」とし、16.3 の κινήματος と 16.5〜16.7 の κίνησις を同じ字で揃える。παθητικὴ διάθεσις は、決めた πάθος の訳の形容詞形にする。ἀρρώστημα（16.3、16.4）は訳語表（8.14）の「病」。

### 16.2 τοῦ ἐπιρρύτου（写本はすべて τῆς。底本の推定）と、τῆς τροφῆς（f と euth は τῆς を欠く）

### 16.7 καταμιχθέντα（l と vulg は καταμιχθέντος）、τε（f は欠く）、συγκρίματος（h は συγκράματος）と、ἐν ἑκατέρᾳ γεγενῆσθαι、τοῦτο οἰκονομήσασθαι の組み立て

- 採る校訂者：底本は καταμιχθέντα（f と d e g h n p の側）。注解の言うことは次のとおり。
  - καταμιχθέντα は τὸν θεόν を受ける。ふつうの本文（Krabinger も）は καταμιχθέντος と読み、νοερόν の後に読点を入れる、と言う（l. 9493〜9496）。
  - τοῦ ἀ. συγκρίματος は τὸ αἰσθητὸν … καὶ τὸ νοερόν にかかり、「具体の人の本性に属する、感覚で知られる要素と知性で知られる要素」と取る（l. 9498〜9501）。
  - συνανακράσεως には 11 章 p. 57 の ἀνάκρασις の注を比べる（l. 9503〜9504）。
  - τοῦτο は τὸ … καὶ εἰς ἀεὶ διαμεῖναι τὴν ἕνωσιν を指し、「ひとたびできた結合が、また（καί）永遠でもあること」と取る。οἰκονομήσασθαι の主語は τὸν θεόν で、καταμιχθέντα ですでに受けている、と言う（l. 9506〜9511）。
  - 受肉で神と人が結合した目的は、人のうちに魂と体の永遠の結合を生じさせることにあった、と言う。その結合は死が起こったことで乱されていた（l. 9513〜9521）。
  - 英訳は、具体の人間がこの二つの混ざりによって形づくられたとき、という属格の独立句（καταμιχθέντος の側）で訳す。また ἐν ἑκατέρᾳ γεγενῆσθαι を「両方の動きに服して生まれた」の意味で訳す。
- 読者への影響：中（構文）。καταμιχθέντα では、神が魂と体の両方に混ざり、その混ざり合いによって、ひとたび結ばれた魂と体の結合が永遠に続くよう計らった、となる。καταμιχθέντος では、混ざったのは人の組み立て（または神）で、文の主語の続き方が変わる。
- 訳での扱い：訳注なし。底本と注解に従い、主語の「神」を通して一文の流れを保つ。
  - καταμίγνυμι・συνανάκρασις は訳語表の「混ざる」の系（16 章の συνανάκρασις も「混ざる」の系、と訳語表にある）。
  - τὸ αἰσθητόν・τὸ νοερόν は、訳語表の τὸ νοητόν／τὸ αἰσθητόν（「知性で知られるもの／感覚で知られるもの」）と νοερός（「知性をもつ」）の使い分けに注意する。ここは νοερός なので「知性をもつ部分」、αἰσθητόν は「感覚で知られる部分」。16.11 の τὴν νοερὰν οὐσίαν τῇ αἰσθητῇ も同じ。
  - σύγκριμα は「組み立て、合わさったもの」で、16.5 の σύγκρισις と同じ語根。
  - ἐν ἑκατέρᾳ γεγενῆσθαι τῇ … κινήσει は、訳語表の γίγνομαι ἐν（神が。「〜のうちにおいでになる」）を当て、「両方の動きのうちにおいでになった」とする。英訳のように「生まれた」とはしない。
  - ἀρρήτου … καὶ ἀνεκφράστου は 8.16 の訳（「言い表せず、語り尽くせない」）に揃えてよい。

### 16.11 ἑαυτοῦ（e、l と vulg は αὐτοῦ）、οὕτω（f と vulg は οὗτος）、γενικωτέρῳ τινὶ λόγῳ（d は λόγῳ τινί、vulg は τινὶ τρόπῳ）、τὴν νοεράν（vulg は τήν を欠く）と、γενικωτέρῳ の意味、16.11〜16.13 の ἀρχή
- 底本：ὁ γὰρ τὴν ἀναληφθεῖσαν παρ᾽ ἑαυτοῦ ψυχὴν πάλιν ἑνώσας τῷ οἰκείῳ σώματι διὰ τῆς δυνάμεως ἑαυτοῦ τῆς ἑκατέρῳ τούτων παρὰ τὴν πρώτην σύστασιν ἐμμιχθείσης οὕτω γενικωτέρῳ τινὶ λόγῳ τὴν νοερὰν οὐσίαν τῇ αἰσθητῇ συγκατέμιξεν, τῆς ἀρχῆς κατὰ τὸ ἀκόλουθον ἐπὶ τὸ πέρας εὐοδουμένης。
- ほかの読み：
  - e、l と vulg は 2 回目の ἑαυτοῦ の代わりに αὐτοῦ（n127 の 15 行目）。
  - f と vulg は οὕτω の代わりに οὗτος（「このかたが」。16 行目）。
  - d は λόγῳ τινί の語順、vulg は λόγῳ の代わりに τρόπῳ（n128 の 1 行目）。
  - vulg は τὴν νοεράν の τήν を欠く（1 行目）。
- 採る校訂者：底本は刷られた本文の形。注解の言うことは次のとおり。
  - 15. ἑκατέρῳ：神の力は、キリストの人の魂と体の両方に、その初めの組み立てのとき、すなわち宿ったときから結ばれていた。復活で体と魂を結び直したのも同じ神の力のはたらきだった（l. 9596〜9603）。
  - 16 f. γενικωτέρῳ τινὶ λόγῳ：γενικός は類（γένος）に属するもの、「類の」で、εἰδικός（種の）と対になる。キリストの神の力による魂と体の再結合の個別の例（キリスト自身の復活）と、全人類の復活に表れる知性で知られる要素と感覚で知られる要素の「より普遍的な規模」での再結合とが対比されている。Krabinger はパリ版のラテン訳に従って generaliori quadam ratione と訳した（l. 9605〜9618）。
  - 1-2. τῆς ἀρχῆς：「その初めが筋道どおりに果てまで首尾よく進んで」。ἀρχή はキリストが復活で始めた新しいいのちの初めで、人類の全体にその果てまで行きわたる。メトディオスとの関係について序論 pp. xxv〜xxviii を見よ（l. 9673〜9682）。
  - 英訳の脚注 [1984] も、Krabinger の読み（γενικωτέρῳ τινὶ λόγῳ τὴν νοερὰν οὐσίαν τῇ αἰσθητῇ συγκατέμιξεν）を最善とする。パリ版のラテン訳（Hervetus）は明らかな誤りだ、と言う。
- 読者への影響：中（語の取り方）。γενικωτέρῳ τινὶ λόγῳ を「より一般的な理によって」と字どおりに訳すと意味が通らない。注解の取り方では「（キリストひとりにとどまらず）いっそう広く、類の全体にわたる仕方で」。
- 訳での扱い：訳注なし。
  - γενικωτέρῳ τινὶ λόγῳ は「いわば人という類の全体にわたる仕方で」の向きで訳す。λόγος は御子ではない（訳語表）。

## 17 章　なぜ神はみこころだけで救わず、回り道をしたのかという反論と、病人は医者に治し方を指図しないという答え

注解の要約（l. 9780〜9792）は次のとおり。

- グレゴリオスは 15 章で述べた反論（なぜ神は命令一つで人を立て直さなかったのか）に戻る。
- 道理をわきまえた人には、こう答えれば足りる、と言う。病人は医者に治療の仕方を指図せず、治し方にけちをつけず、目的を見て感謝して手当てを受ける。それと同じく、わたしたちは受肉の恵みの目的を見て、この世で受けられるより大きな光を待つべきだ、と。

### 17.2 ἡ προφητεία（l と vulg は ὁ προφήτης）と、詩篇三〇・二〇（七十人訳。口語訳の三一・一九）
