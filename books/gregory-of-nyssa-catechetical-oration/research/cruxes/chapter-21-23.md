### 21.2 一つの長い文の組み立て（ἐν τούτῳ τοίνυν … πάντα μοι κατὰ ταὐτὸν ἀναζήτει）
- 底本：21.2 は ἐν τούτῳ τοίνυν τῆς ἑτερότητος … οὔσης から πάντα μοι κατὰ ταὐτὸν ἀναζήτει … ἐστίν まで、句点のない一つの文（split-units.js で 1 節になった）。
- 取り方（注解 l. 10764〜10782、10801〜10803、10891〜10893、10901〜10904、10986〜10992、11001〜11017）：
  - 属格独立句 τῆς ἑτερότητος … οὔσης で始まるが、主文は ἀλλοίωσις と κίνησις の意味についての長い挿入（ἡ δὲ ἀλλοίωσις から τῇ ἀνυπαρξίᾳ τὴν ὕπαρξιν まで）で途切れる。
  - ἐπειδὴ τοίνυν κατὰ τὴν τρεπτήν で文が取り上げ直され、καλὸν δὲ τὸ μέν の挿入でまた途切れる。
  - ἐπεὶ οὖν τῆς πρὸς τὸ ὄντως で新しく始め直すが、οὐ γὰρ ἂν … περιπλασθείσης の挿入が入る。
  - ἐν ταύτῃ τοίνυν γεγονότος でもう一度始め直し、帰結の文は πάντα μοι κατὰ ταὐτόν で始まる。人の堕落の事情に対して、問題のもう一方の要素、神の本性と性格を置く、と言う。
  - 続く 21.3 の οὐκοῦν ὡς ἀγαθός、σοφίας δ᾽ ἂν εἴη と 22.1 の τί οὖν ἐν τούτοις τὸ δίκαιον で、神の主な属性を順に見ていく、と言う。
- 読者への影響：中（文の組み立て）。属格独立句と ἐπειδή、ἐπεί の節が帰結を持たないまま重なる。
- 訳での扱い：訳注なし。メインで決める。本の AGENTS.md の文型の訳し方（構文が途中で変わるところは、先に枠を立て、後から続ける。属格独立句は独立した文にしても主文との関係を残す）に従って文を分ける。帰結の πάντα μοι … ἀναζήτει（命令）が、人の側の事情（ἐν ταύτῃ τοίνυν γεγονότος …）を受けていることが見えるよう、「人がこのような不幸に陥ったのですから、…を、あわせて探ってみなさい」の向きで結ぶ案がある。注解が挿入とする三つの部分は、独立した文にしてよい。

## 21 章　人は神に倣って造られたが、移り変わる本性をもつ。欺かれて自分から悪へ移った

注解の要約（l. 10644〜10666）によると、21 章の論の運びは次のとおり。

- グレゴリオスは、受肉が正義を示したことを示しにかかる。人は神に似せて造られたが、造られたものなので、神と違い、移り変わる本性をもった。
- 移り変わりは、善か悪へ向かう動きを含む。人の知性は、何がまことに善いかについて、まぼろしに迷わされやすい。そのようなまぼろしによって、サタンは人を欺き、悪へ誘った。
- あがないの問題の二つの要素は、人が自分からサタンに縛られたことと、神の本性と性格（善、知恵、正義、力、朽ちないことなど）である。神の善は堕ちた人へのあわれみをかき立て、知恵は呼び戻す方法を備えた。知恵には正義が必ず伴う。

### 21.2 τύχοι（f、g は τύχῃ）、τῇ φύσει（d は欠く）、μὴ πάντως（f、h、l* と vulg は μή を欠く）、μένειν（l* と vulg は μίμημα）、τίς ἐστιν（l と vulg は τις を欠く）、εἰς ἕτερον … ἐν ᾧ ἐστίν（f は欠く）、δύο δέ（l*vid と vulg は δύο λέγει）
- 底本：τὸ δὲ μιμούμενον, εἰ μὴ ἐν ἑτερότητι τύχοι τινί … ἐν τῷ τὸ μὲν ἄτρεπτον εἶναι τῇ φύσει, τὸ δὲ μὴ οὕτως ἔχειν, ἀλλὰ δι᾽ ἀλλοιώσεως μὲν ὑποστῆναι κατὰ τὸν ἀποδοθέντα λόγον, ἀλλοιούμενον δὲ μὴ πάντως ἐν τῷ εἶναι μένειν· ἡ δὲ ἀλλοίωσις κίνησίς τίς ἐστιν εἰς ἕτερον ἀπὸ τοῦ ἐν ᾧ ἐστὶν εἰς ἀεὶ προιοῦσα· δύο δὲ τῆς τοιαύτης εἴδη κινήσεως。

  - l の最初の手と vulg は μένειν の代わりに μίμημα（9 行目）。vulg は μή も欠くので、「変質しながら、まったく存在において写しである」の形になる。
  - l と vulg は κίνησίς τίς の τις を欠く（9 行目）。
  - f は εἰς ἕτερον … ἐν ᾧ ἐστίν を欠く（9〜10 行目）。

  - 英訳は μή のある形で、「その状態にいつもとどまるのではない」の意味に訳す。
- 採る校訂者：底本は μή のある形。底本は、ここでは f、l の読みに従わない。
- 読者への影響：中。μή の有無で文意が逆になるが、底本の形は注解の取り方と前後の論（変質は別の状態へ進む動き）に合う。

### 21.2 διεξοδευομένου（d、f は διεξοδευμένου）、καταλαμβάνεται と、善へ向かう進みに終わりがないこと
- 底本：τὸ μὲν πρὸς τὸ ἀγαθὸν ἀεὶ γιγνόμενον, ἐν ᾧ ἡ πρόοδος στάσιν οὐκ ἔχει, διότι πέρας οὐδὲν τοῦ διεξοδευομένου καταλαμβάνεται· τὸ δὲ πρὸς τὸ ἐναντίον, οὗ ἡ ὑπόστασις ἐν τῷ μὴ ὑφεστάναι ἐστίν。
- ほかの読み（n138 の異読の欄）：d、f は διεξοδευομένου（現在分詞）の代わりに διεξοδευμένου（完了分詞。12 行目）。
- 取り方（注解 l. 10805〜10824）：
  - 善の方向への進みは止められない。「たどっていくものに境がないから」で、善への進みに限りがない、ということ。
  - Διεξοδ. は受動で、「たどられるもの」。パリ版のラテン訳 ejus quod transit は意味をなさない。Krabinger は ejus quod evolvitur と訳す。Glauber は、人がはたらいているその対象そのものに終わりがない、と取り、美そのもの・善そのものが永遠だというプラトンの考えの影響を見て、『パイドン』を挙げる。
  - καταλαμβάνεσθαι は、この書でほかに θεωρεῖσθαι を使うのと同じく、εἶναι の言い換えにすぎない、と言う。
  - 英訳は受動に取り、脚注 [1995] で Glauber と Krabinger に触れる。

- 読者への影響：小。

## 22 章　神は力ずくでなく、正しい仕方で人を取り戻された

注解の要約（l. 11021〜11033）によると、神の正義は、サタンに対して暴君のように力をふるうことを控えたことに表れた。自分の自由を売り渡した者は、正当な持ち主に身代金を払って取り戻されるべきだと正義が求めるように、人の場合も、正義にかなうあがないの仕方が要った。それは、持ち主が受け取りたいと思う身代金を払うことだった。

### 22.1 τυραννικῇ … αὐθεντίᾳ、δικαιολογίας ἀφορμήν と、偽ディオニュシオスの並行
- 底本：Τί οὖν ἐν τούτοις τὸ δίκαιον; τὸ μὴ τυραννικῇ τινὶ χρήσασθαι κατὰ τοῦ κατέχοντος ἡμᾶς αὐθεντίᾳ, μηδὲ τῷ περιόντι τῆς δυνάμεως ἀποσπάσαντα τοῦ κρατοῦντος καταλιπεῖν τινὰ δικαιολογίας ἀφορμὴν τῷ δι᾽ ἡδονῆς καταδουλωσαμένῳ τὸν ἄνθρωπον。語そのものに異読はない（n140、n141 の異読の欄に項がない）。
- 取り方（注解）：
  - μὴ τυραννικῇ には、Krabinger が引く偽ディオニュシオス『教会位階論』3 章 11 節の一節（背いた群れの、わたしたちに対する力を、力によってでなく、裁きと正義によって打ち破った、という句）を挙げる。マクシモスがそこに、グレゴリオスのこの箇所に触れる注を付けている、と言う（l. 11035、11083〜11091。英訳の脚注 [1996] も同じ）。
  - δικαιολογ. は「自分を弁護する正当な言い分」（l. 11093〜11094）。
- 読者への影響：中（語の選び方）。τυραννικός は 20.2 の τυραννικὸν τῆς δυνάμεως εἶδος（訳では「暴君のもの」）と同じ語で、22.2 の τυραννικῶς、τὸν τυραννικόν（τρόπον）とともに、δίκαιος と対になる。
- 訳での扱い：訳注なし。τυραννικός・τυραννικῶς は 20.2 に揃えて「暴君のような」「暴君のように」で通し、「正しい」と対にする。αὐθεντία は「力ずくの支配」の向き（15.5 の αὐθεντικῆς τινὸς … ἐξουσίας「主としての権威」とは文脈が違う）。δικαιολογίας ἀφορμήν は「正当な言い分を立てるきっかけ」。

### 22.2 εὐπατρίδαι（l と vulg は εὐπατρίδες）と、売り渡しと買い戻しのたとえの語

- 読者への影響：中（語の選び方）。売る・買う・買い戻す・身代金の語（ἀποδίδομαι、ὠνέομαι、πρατήρ、ἀπεμπολέω、ἐξωνέομαι、λύτρον、23 章の ἀνταλλάσσω・ἀντάλλαγμα、συνάλλαγμα、συναλλαγματικός、λύτρωσις）が、22〜23 章の論の骨組みになる。訳語表にはまだない。

### 22.3 τὸ ἐπὶ τῷ κρατοῦντι（l*、n と vulg は τῷ ἐπικρατοῦντι）と、λύτρον ἀντὶ τοῦ κατεχομένου
- 底本：οὗτος δέ ἐστί τις τὸ ἐπὶ τῷ κρατοῦντι ποιήσασθαι πᾶν ὅπερ ἂν ἐθέλοι λύτρον ἀντὶ τοῦ κατεχομένου λαβεῖν。
- ほかの読み（n141 の異読の欄）：l の最初の手、n と vulg は τις τὸ ἐπὶ τῷ κρατοῦντι の代わりに τις τῷ ἐπικρατοῦντι（18 行目）。
  - 底本の形は「支配している者に、望むどんな身代金でも受け取れるように任せること」（ἐπί τινι ποιεῖσθαι「〜の手に委ねる」）。
  - 異読の形は冠詞 τό と前置詞 ἐπί がなく、「支配している者に（τῷ ἐπικρατοῦντι）、…を受け取るようにさせること」の向きになる。
- 聖書：λύτρον ἀντί の句は、マルコ一〇・四五、マタイ二〇・二八 の λύτρον ἀντὶ πολλῶν（口語訳「多くの人のあがないとして」）と同じ組み立て（論点一覧の判断。注解はこの聖句を挙げない）。
- 採る校訂者：底本は τὸ ἐπὶ τῷ κρατοῦντι。英訳は、持ち主に身代金を渡す、という意味に訳し、どちらの読みに立つかは訳からは決められない。
- 読者への影響：中（文の組み立てと語の選び方）。
- 訳での扱い：訳注なし。
  - 底本どおり「支配している者に、捕らえられている者の代わりに望むどんな身代金でも受け取ることを任せる」の向き。
  - λύτρον は、商いのたとえの中なので「身代金」とし、23.4 の αὐτὸν αἱρεῖται λύτρον … γενέσθαι も同じ字にすると、22〜23 章の論が一つにつながる。λύτρωσις（23.7）は「あがない」で、同じ語根であることが見えるよう「身代金による買い戻し」なども考えられる。メインで決める。マルコ一〇・四五 の暗示は、出典を付けない（逐語の引用でない）。
  - 英訳と比べるレビューで、この句の訳し方の違いを誤りとしない。

## 23 章　敵は奇跡に表れた力を見て、キリストを身代金に選んだ。神性は肉に覆われていた

注解の要約（l. 11116〜11125、11180〜11186）によると、サタンは高ぶりから、取り引きで得をするために、自分が持っているものより高くまさったものを求めた。キリストの奇跡に表れた力を見て、サタンはキリストを身代金に選び、神性を隠すキリストの人間性の覆いが、キリストを恐れでなく求めの対象にした。人を救おうと望んだことに神の善が、取り引きによる身代金に正義が、身代金を成しとげた仕方に知恵が表れた。

### 23.2 πρὸς μέν（f、l と vulg は μέν を欠く）、τίνος ἄν（f は ἄν を欠く）と、6 章のねたみの論とのつながり（φθόνος、φιλαρχία、ῥοπή、ὑπόθεσις、τῦφος）
- 底本：ὁ τοίνυν κατὰ τὸν ἐν ἀρχῇ τοῦ συγγράμματος προαποδοθέντα λόγον τῷ πρὸς τὸν εὐημεροῦντα φθόνῳ πρὸς μὲν τὸ ἀγαθὸν ἐπιμύσας, τὸν δὲ τῆς κακίας ζόφον ἐν ἑαυτῷ γεννήσας, ἀρχὴν δὲ τῆς πρὸς τὰ χείρω ῥοπῆς καὶ ὑπόθεσιν καὶ οἱονεὶ μητέρα τῆς λοιπῆς κακίας τὴν φιλαρχίαν νοσήσας, τίνος ἂν ἀντηλλάξατο τὸν κατεχόμενον … ὡς ἂν μᾶλλον ἑαυτοῦ τὸ κατὰ τὸν τῦφον θρέψειεν πάθος, τὰ μείζω τῶν ἐλαττόνων διαμειβόμενος;
- ほかの読み（n142 の異読の欄）：f、l と vulg は πρὸς μὲν τὸ ἀγαθόν の μέν を欠く（5 行目）。f は τίνος ἄν の ἄν を欠く（8 行目）。

### 23.2 τὸν κατὰ τῶν δαιμόνων φόβον、τῶν κατὰ τὸν ἀέρα παθῶν τὴν ἐξουσίαν（πάθος の語）

### 23.4 αὐτόν（l と vulg は欠く）、23.5 περικαλύπτεται（vulg は περικεκάλυπται）と、神性が肉に覆われたこと
- 底本：ἀλλὰ μὴν ἀμήχανον ἦν αὐτὸν γυμνῇ προσβλέψαι τῇ τοῦ θεοῦ φαντασίᾳ, μὴ σαρκός τινα μοῖραν ἐν αὐτῷ θεωρήσαντα, ἣν ἤδη διὰ τῆς ἁμαρτίας κεχείρωτο. διὰ τοῦτο περικαλύπτεται τῇ σαρκὶ ἡ θεότης, ὡς ἄν, πρὸς τὸ σύντροφόν τε καὶ συγγενὲς αὐτῷ βλέπων, μὴ πτοηθείη τὸν προσεγγισμὸν τῆς ὑπερεχούσης δυνάμεως· καὶ τὴν ἠρέμα διὰ τῶν θαυμάτων ἐπὶ τὸ μεῖζον διαλάμπουσαν δύναμιν κατανοήσας, ἐπιθυμητὸν μᾶλλον ἢ φοβερὸν τὸ φανὲν εἶναι νομίσῃ。
- ほかの読み（n145 の異読の欄）：l と vulg は ἀμήχανον ἦν αὐτόν の αὐτόν を欠く（4 行目）。vulg は περικαλύπτεται（現在）の代わりに περικεκάλυπται（完了。6 行目）。
- 取り方（注解）：
  - ἀλλὰ μήν：キリストの人間性がサタンの目から神性を覆ったという考えは、24 章（προκάλυμμα、釣り針）と 26 章（人を先に欺いた者が、人という覆いに欺かれる）でいっそう詳しく言われる。ナジアンゾスのグレゴリオス『講話』39.13 を比べ、Mason の『神学講話』p. 117 を見よ、と言う。受肉に示された控えめさによってサタンが欺かれたという考えの最も早い跡はイグナティオス『エペソ人へ』19 で、第一コリント二・八 から示されたかもしれない、と言う（l. 11541〜11563）。
  - προσβλέψαι τῇ … φ. は前の φαντασία の項（l. 11565〜11571）。
  - σύντροφον は「よく知った、なじみのものを見て」（l. 11573〜11574）。

### 23.6 παραποδισθείη（f は παρεμποδισθείη）、θεϊκῆς ἐπιφανείας（f、l と vulg は ὑψηλῆς ἐμφανείας）、πάντων（vulg は πάντως）、τοῦ σοφοῦ, τοῦ δικαίου（f は τοῦ δυνατοῦ を加える）
- 底本：τὸ γὰρ διὰ τῆς τοῦ σώματος περιβολῆς χωρητὴν τὴν θείαν δύναμιν ἐπινοῆσαι γενέσθαι, ὡς ἂν ἡ ὑπὲρ ἡμῶν οἰκονομία μὴ παραποδισθείη τῷ φόβῳ τῆς θεικῆς ἐπιφανείας, πάντων κατὰ ταὐτὸν τὴν ἀπόδειξιν ἔχει, τοῦ ἀγαθοῦ, τοῦ σοφοῦ, τοῦ δικαίου。
- ほかの読み（n146 の異読の欄）：
  - f は παραποδισθείη の代わりに παρεμποδισθείη（同じ意味の別の複合動詞。8 行目）。
  - f、l と vulg は θεικῆς ἐπιφανείας（神の現れ）の代わりに ὑψηλῆς ἐμφανείας（高い現れ。8 行目）。底本は、ここでは f、l の読みに従わない。
  - vulg は πάντων の代わりに πάντως（9 行目）。
  - f は τοῦ σοφοῦ の後に τοῦ δυνατοῦ（力）を加える（10 行目）。
- 取り方（注解）：χωρητήν には、下の χωρητὸν … τῷ ἐχθρῷ と 26 章の ἐντὸς τοῦ κρατοῦντος γενέσθαι を比べる。神の力は、敵が身代金に選んだ人間性と分かたれずに一つになり、その人間性が神性を覆ったことで、サタンにとって χωρητή（受け入れられるもの）になった、と言う（l. 11643〜11651）。
- 採る校訂者：底本は παραποδισθείη、θεϊκῆς ἐπιφανείας、πάντων、τοῦ δυνατοῦ のない形。24 章は、力（τὸ δυνατόν）がどこに表れたかを問うことから始まる（24 章の書き出し、p. 90 の 15〜16 行目）。f の付加は、24 章の問いの前に力を並べてしまう形になる（論点一覧の判断）。
- 読者への影響：小。
- 訳での扱い：訳注なし。
  - θεϊκῆς ἐπιφανείας は「神の現れ」で、23.4 の τῇ τοῦ θεοῦ φαντασίᾳ と 6.15 の τῆς θείας ἐμφανείας（訳「神の現れ」）に字を揃えられる。
  - ἡ ὑπὲρ ἡμῶν οἰκονομία は訳語表の「（神の）救いのわざ」。
  - χωρητός・ἀχώρητος は「入れられる・入れられない」の対を残す（23.7 の χωρητὸν … τῷ ἐχθρῷ τὸ ἀχώρητον）。注解に従えば、敵が受け入れられる（つかめる）ようにした、ということ。
  - 属性の三つは 23.7 の順（善、正義、知恵）と並びが違う。底本どおり、23.6 は「善、知恵、正義」の順に訳す。

### 23.6〜23.7 ἐπινοῆσαι・δι᾽ ἐπινοίας（工夫）と、τὸ μὲν … σῶσαι（e は欠く）、ποιῆσαι（e は語順が違う）
- 底本：
  - 23.6：τὸ γὰρ … χωρητὴν τὴν θείαν δύναμιν ἐπινοῆσαι γενέσθαι。
  - 23.7：τὸ μὲν γὰρ ἐλέσθαι σῶσαι τῆς ἀγαθότητός ἐστι μαρτυρία· τὸ δὲ συναλλαγματικὴν ποιήσασθαι τὴν τοῦ κρατουμένου λύτρωσιν τὸ δίκαιον δείκνυσι· τὸ δὲ χωρητὸν δι᾽ ἐπινοίας ποιῆσαι τῷ ἐχθρῷ τὸ ἀχώρητον τῆς ἀνωτάτω σοφίας τὴν ἀπόδειξιν ἔχει。
  - 22.2 にも τὸν δίκαιον τρόπον ἐπινοηθῆναι τῆς ἀνακλήσεως。
- ほかの読み（n146 の異読の欄）：e には τὸ μὲν … σῶσαι がない（10 行目。desunt in e）。e は δι᾽ ἐπινοίας ποιῆσαι の代わりに ποιῆσαι δι᾽ ἐπ. の語順（13 行目）。
- 取り方（注解）：ἐπινοῆσαι は、下の δι᾽ ἐπινοίας と同じく、「工夫、考案」の意味で使われている、と言う（l. 11653〜11655）。20.7 の注解（chapter-18-20 の 20.7 の項）は、この一節を、受肉の救いのわざの知恵と巧みさの例として挙げる。
- 採る校訂者：底本は τὸ μὲν … σῶσαι を含む形。
- 読者への影響：中（語の選び方）。訳語表は ἐπίνοια を「概念」とする（序の考えの仲間）。ここは「工夫」の意味で、6.16 の διὰ τῆς ἐπινοίας ταύτης はすでに「この工夫によって」と訳されている。
- 訳での扱い：訳注なし。メインで決める。23.6 の ἐπινοῆσαι、23.7 の δι᾽ ἐπινοίας は 6.16 に合わせて「工夫する」「工夫によって」とし、訳語表の ἐπίνοια の項に「工夫」の意味を足す。22.2 の ἐπινοηθῆναι は「考え出される」の向き。συναλλαγματικήν は 22.2 の項の案「取り引きによる」、λύτρωσις は 22.3 の項。τῆς ἀνωτάτω σοφίας は「この上ない知恵」。
