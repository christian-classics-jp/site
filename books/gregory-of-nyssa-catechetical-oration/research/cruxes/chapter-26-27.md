## 26〜27 章の全体　語の論点

### 26.8〜27.10 「混ぜる」の語（悪が本性に混ざることと、神が人の本性に混ざること）
- 底本：悪の側は、26.8 の ἀτιμοτέρας ὕλης τῷ χρυσῷ καταμιχθείσης（劣った素材が金に混ざる）、26.9 の τοῦ κακοῦ … τοῦ νῦν αὐτῇ καταμιχθέντος καὶ συμφυέντος（今、本性に混ざり、結びついている悪）、26.8 の περιφυέντων（悪の産んだものが、悪を考え出した者にまといつく）。神の側は、26.10 の δι᾽ ὧν γὰρ κατεμίχθη τῇ ἀνθρωπότητι、27.1 の τὸν πρὸς τὴν φύσιν ἡμῶν ἀνακιρνάμενον … τὴν πρὸς ἡμᾶς συνανάκρασιν、27.4 の ὁ δὲ τῷ ἀνθρώπῳ καταμιγνύμενος … ἐποιεῖτο τὴν συνανάκρασιν、27.5 の τὴν θείαν ἐπιμιξίαν、τῳ θεῷ περιπλακῆναι τὸν ἄνθρωπον、27.10 の τῆς πρὸς τὸ θεῖον … συμπλοκῆς。
- 注解：27.1 の ἀνακιρνάμενον は「ご自分を注ぎ入れる」の意味で、11 章の κατακιρνᾶται を比べる（l. 12832〜12833）。συνανάκρασιν には 16 章（p. 70）と 11 章（p. 57）の注を見よと言う（l. 12838〜12839）。27.5 の περιπλακῆναι は字義では「人が神のまわりに巻きつけられる」で、人間性は神性がまとう衣と考えられている、と言う（l. 12970〜12978。下の 27.5 の項）。
- 採る校訂者：本文の読みの違いではない（27.4 の συνανάκρασιν、27.5 の ἐπιμιξίαν の異読は各項）。
- 読者への影響：中（語のつながり）。同じ καταμίγνυμι が、悪が本性に混ざること（26.9）と、神が人間に混ざること（26.10、27.4）の両方に使われる。悪を本性から取り除くために、神が本性に混ざる、という対が語で立っている。
- 訳での扱い：訳注なし。訳語表の κατακιρνάω・ἀνάκρασις・συγκεράννυμι の項（「混ざる」の系。μίγνυμι の系も「混ざる」「混じり合う」）に従う。26.9 の悪の καταμιχθέντος と 26.10 の神の κατεμίχθη を同じ字にすると対が残る（論点一覧の判断）。ἀνακιρνάω、καταμίγνυμι、περιπλέκω、συμπλοκή は訳語表にないので、メインで決める（συμπλέκω は訳語表の「絡み合う」）。

## 26 章　悪魔へのあざむきは、正義と知恵にかなう。悪を考え出した者も清められる

### 26 章の全体　章の要約と論の参照
- 注解の要約（l. 12284〜12294、12301〜12316）：神性がサタンから覆い隠されたことは、正義と知恵にそぐわない欺きのわざを含むと思われるかもしれない。グレゴリオスは答える。欺いた者が欺き返されたことで、サタンを報いに応じて扱った神の正義が示され、正しい報いに愛の目的を合わせたことに知恵が表れた。毒を盛る者も医者も食べ物に薬を混ぜるが、目的が違う。サタンへの欺きの目的は、欺かれた者だけでなく欺いた者自身にも益を与えることだった。神の力は悪に触れて精錬の火のようにはたらく。サタン自身もそれによって清められ、受肉の正しさと救いの力を認めるようになる。清めの訓練が終わったとき、すべての造られたものが神に賛美の声を合わせる。
- 読者への影響：小。見出しを決める手がかり（訳文には写さない）。

### 26.1 ἀπάτην τινά（Krabinger は ἀπάτῃ τινί）
- 底本：ἐνάγεται πρὸς τὸ νομίσαι ἀπάτην τινὰ τὴν τοιαύτην μέθοδον ἐπινενοῆσθαι ὑπὲρ ἡμῶν τῷ θεῷ。
- ほかの読み：Krabinger 版は ἀπάτῃ τινί（「ある欺きによって」）。遅い写本 c の欄外にある読みで、Krabinger が示すとおり、その写本を書いたマクシモス・マルグニオスの推測による手直しだ、と注解は言う（l. 12318〜12328）。
- 採る校訂者：底本は ἀπάτην τινά で、すべての写本がこの読みだと注解は言う。ἀπάτην τινά は第二の述語で、「わたしたちのために神が工夫したこの方法が、一種の欺きである（と考える）」の意味だという（l. 12318〜12323）。
- 読者への影響：小〜中。底本の読みでは、方法そのものが欺きだと相手が考える。Krabinger の読みでは、方法が欺きによって工夫された、となる。英訳は欺きを手段とする向きで訳していて、Krabinger の読みに近い（英訳 l. 44347〜44348）。
- 訳での扱い：訳注なし。「この方法は一種の欺きとして工夫された」の向き（第二の述語）で訳す。ἀπάτη は訳語表の「欺き」、ἐπινοέω は訳語表の「工夫する」（23.6〜23.7）。μέθοδος は訳語表にない。訳語表は τρόπος を「方法」で通すとするので（26.4 の ἐν τῷ τρόπῳ、26.5 の ὁ τρόπος τῆς θεραπείας も τρόπος）、μέθοδος に別の語（「やり方」「手立て」など）を当てるかをメインで決める。παραλογισμός（26.1）も訳語表にない。

### 26.1 δικαιοσύνης τε καὶ σοφίας ἐξετάσει（l と vulg の語順）、τὴν τοιαύτην（vulg は τήν を欠く）、τὸ γὰρ μή（l* は μή を欠き、vulg は οὐ）、τῶν ἀπατώντων（l* は ἀπάντων）
- 底本：ἐν τῇ τῆς δικαιοσύνης τε καὶ σοφίας ἐξετάσει τῆς κατὰ τὴν οἰκονομίαν ταύτην θεωρουμένης ἐνάγεται πρὸς τὸ νομίσαι ἀπάτην τινὰ τὴν τοιαύτην μέθοδον … τὸ γὰρ μὴ γυμνῇ τῇ θεότητι … ἐπείπερ ἴδιον τῶν ἀπατώντων ἐστί。

### 26.2 τὴν ἀλήθειαν（h は τήν を欠く）と、τῇ μὲν δικαιοσύνῃ … τῇ δὲ ἀγαθότητι の二つの与格
- 底本：ἀλλ᾽ ὁ πρὸς τὴν ἀλήθειαν βλέπων … τῇ μὲν δικαιοσύνῃ τὸ κατ᾽ ἀξίαν ἀντιδιδόντα, τῇ δὲ ἀγαθότητι τοῦ σκοποῦ τῆς φιλανθρωπίας οὐκ ἐξιστάμενον。
- ほかの読み：h は τήν を欠く（n153 の 6 行目）。
- 注解：Krabinger は δικαιοσύνῃ を ἀντιδιδόντα に支配される与格（正義に、ふさわしいものを返す）と取り、ἀγαθότητι を事情・観点の与格とする。パリ版のラテン訳も同じ向き。注解は、ムーアに従い、二つの与格を同じ構文に取るほうがよいと言い、「正義においては、ふさわしい報いをし、善においては、人への愛の目的から離れない」と取る（l. 12404〜12415）。英訳の脚注 [2003] も同じことを言う（l. 44429〜44432）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中。Krabinger の取り方では、正義が報いを受ける側になり、μέν … δέ の対が崩れる。
- 訳での扱い：訳注なし。注解に従い、「正義の点では…報い、善の点では…離れない」と二つを同じ形で並べる。σκοπός（目的）は 26.3、26.5 にも出る論の要の語で、訳語表にない。26.4 の τοῦ βελτίονος は、注解で τοῦ σκοποῦ τῆς φιλανθρωπίας のこと（l. 12503〜12505）。

### 26.9 εἴπερ εἰς αἴσθησιν τῆς εὐεργεσίας ἔλθοι（注解は、推測を述べる言い方とする）と、νυνὶ γάρ の句切り（g、p、d、l¹、n、h は νῦν を前の文に付ける）

### 27.7 τὸ μὲν γὰρ ἀπρεπὲς ἐπὶ τῆς θεότητος ἴσον と、πλὴν … συσχηματισθῆναι τὸ θεῖον の取り方

### 27.10 τῆς ὑψηλῆς（g¹ は τῆς ἴσης、h は τῆς を欠く）、τὴν … ἐπιστατοῦσαν δύναμιν（e、h、n は属格）と、ὁ ἀληθὴς λόγος
- 底本：ἀλλ᾽ ὁ ἀληθὴς λόγος ἐπὶ τῆς ὑψηλῆς ἀξίας οὔτε κάτω βλέπει διὰ συγκρίσεως, οὔτε ἄνω· πάντα γὰρ κατὰ τὸ ἴσον τὴν τοῦ παντὸς ἐπιστατοῦσαν δύναμιν ὑποβέβηκεν, ὥστε, εἰ τὴν ἐπίγειον φύσιν ἀναξίαν τῆς πρὸς τὸ θεῖον οἰήσονται συμπλοκῆς, οὐδ᾽ ἂν ἄλλη τις εὑρεθείη τὸ ἄξιον ἔχουσα。
- ほかの読み（n161 の異読の欄）：g の訂正者は τῆς ἴσης、h は τῆς を欠く（1 行目）。e、h、n は τῆς … ἐπιστατούσης δυνάμεως（3〜4 行目。ὑποβέβηκεν が属格をとる形）。
- 注解：ὁ ἀληθὴς λόγος は、神の超えた尊さを扱う「まことの論」で、造られたものの「上」と「下」を比べない。本当の比べは造られたものと造り主のあいだにある。造られたものはみな等しく神の力の下にある、と言う（l. 13172〜13181）。
- 採る校訂者：底本は刷られた本文の形。
- 読者への影響：小。
- 訳での扱い：訳注なし。ὁ ἀληθὴς λόγος は御子でない λόγος なので、訳語表の λόγος の項のとおり「まことの論」の向き。οἰήσονται（3 人称複数の未来）の主語は書かれていない相手で、文体の決まりの「その人」「相手」で受ける。συμπλοκή は 27.5 の περιπλακῆναι とともにメインで決める（上の「混ぜる」の語の項）。
- 確かめた資料：画像 `n161_w1600.jpg`（異読の欄、注解の左の欄の 1.）。l. 13166、13172〜13181。訳語表の λόγος の項。

### 27.11 ἓν πρέπον（l*（vid）と vulg は ἐμπρέπον）、τῷ θεῷ（d は欠き、f と l は τῷ を欠く）
- 底本：εἰ δὲ ἐπ᾽ ἴσης πάντα τῆς ἀξίας ἀπολιμπάνεται, ἓν πρέπον ἐστὶ τῷ θεῷ τὸ εὐεργετεῖν τὸν δεόμενον. ὅπου τοίνυν ἦν ἡ νόσος, ἐκεῖ φοιτῆσαι τὴν ἰωμένην δύναμιν ὁμολογοῦντες, τί ἔξω τῆς θεοπρεποῦς ὑπολήψεως πεπιστεύκαμεν;
- ほかの読み（n161 の異読の欄）：l の最初の手（vid）と vulg は ἓν πρεπ. の代わりに ἐμπρέπον（7 行目。「神にふさわしいのは、乏しい者に善を行うことだ」）。d は τῷ θεῷ を欠き、f と l は τῷ を欠く（同）。
- 注解：ἓν πρέπον について、神が人の本性をとったことの本当の正当化は、神の道徳の性格に見いだされる。乏しい者を助けることは、神の性格にかなう、と言う（l. 13183〜13188）。
- 採る校訂者：底本は ἓν πρέπον（注解の見出しの語も同じ）。英訳も ἓν に立って訳している（l. 44520〜44522）。
- 読者への影響：中。ἓν なら「すべてが等しく尊さに届かないなら、神にふさわしいことは一つ、乏しい者に善を行うことだ」と、27.7 の「悪のほかにふさわしくないものはない」と対になる。
- 訳での扱い：訳注なし。「一つ」を訳に出す。πρέπον、θεοπρεπής は訳語表の「ふさわしい」「神にふさわしい」、ὑπόληψις は「考え」。εὐεργετέω は 26.6〜26.9 の εὐεργετῶν、εὐεργετεῖ、εὐεργεσία と同じ語で、字を揃える（論点一覧の判断）。神の動作なので尊敬語。
- 確かめた資料：画像 `n161_w1600.jpg`（異読の欄、注解の左の欄の 7.）。l. 13166〜13167、13183〜13188。英訳 l. 44520〜44522。
