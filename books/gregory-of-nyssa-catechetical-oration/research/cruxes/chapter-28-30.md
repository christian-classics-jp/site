## 28〜30 章の全体　語の論点

### 29.1〜30.7 χάρις と εὐεργεσία（訳語表ではどちらも「恵み」になる）
- 底本：εὐεργεσία は 29.1 の τί ἀνεβάλετο τὴν εὐεργεσίαν、ἡ πρὸς τὴν εὐεργεσίαν ἡμῶν ἀναβολή、30.3 の πᾶσιν ἀφθόνως τὴν εὐεργεσίαν νεῖμαι。χάρις は 30.3 の οὐκ ἐπὶ πάντας ἦλθεν ἡ χάρις、30.4 の διὰ τί … οὐκ ἐπὶ πάντας ἡ χάρις、30.7 の ἐν κοινῷ προτεθείσης τῆς χάριτος。30.3 では同じ相手の問いの中に二つが並ぶ。
- 注解：30.3 の ἡ χάρις は福音を言う語で、パウロの手紙にふつうに見られる、と言い、使徒二〇・二四、第二コリント六・一、八・九、コロサイ一・六を挙げる（l. 13724〜13728）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中。訳語表は εὐεργεσία・εὐεργετέω を「恵み・恵みを施す」とする（26.5〜26.9、27.11）。これまでの訳は χάρις も「恵み」とした（5.19 の「自由であるという恵み」、6.7 の「一つの恵み」、16.9 の「初めの恵み」、18.2 のテトス二・一一 の「神の恵み」）。30.3 では二つが同じ文に並ぶので、同じ字にすると訳し分けが消える。
- 訳での扱い：訳注なし。どちらかを訳し分けるか、メインで決める。χάρις は 18.2 で口語訳に寄せた「恵み」が先にあるので、εὐεργεσία の側を、この範囲だけ「恵みのわざ」「善いわざ」などとする道もある（論点一覧の判断）。
- 確かめた資料：画像 `n164_w1600.jpg`、`n166_w1600.jpg`（注解の右の欄の 12.）、`n167_w1600.jpg`、`n169_w1600.jpg`。l. 13724〜13728。訳語表の εὐεργεσία の項。`src/chapter-05/both.md` の 5.19、`src/chapter-06-07/both.md` の 6.7、`src/chapter-16-17/both.md` の 16.9、`src/chapter-18-20/both.md` の 18.2 の訳。

### 29.2〜29.5 医者のたとえの語（νόσημα、χυμός、πάθος、ἰατρεία、θεραπεία、θεραπευτής、νόσος、ἀρρωστία）
- 底本：29.2 の ἐπὶ τῶν σωματικῶν νοσημάτων、διεφθορὼς χυμός、τῶν τεχνικῶς μεθοδευόντων τὰ πάθη、γυμνῷ τῷ πάθει τὴν ἰατρείαν προσάγουσιν。29.3 の ἡ τῆς κακίας νόσος、ὁ τοῦ παντὸς θεραπευτής。29.4 の προσάγει τῷ ἀνθρώπῳ τὴν θεραπείαν、ἡ χαλεπὴ νόσος。29.5 の διὰ πάσης τῆς ἀρρωστίας προχωρήσειεν ἡ θεραπεία … θεραπεύει τὴν νόσον。30.1 の μετὰ τὸ προσαχθῆναι τὴν θεραπείαν。
- 注解：διεφθορώς は自動詞の意味。χυμός は体液を言う「体液（humour）」。29.2 の οὐ καταφ. は、体を閉じる薬で手当てしない、ということで、医者はこういうとき体の毛穴を開き、病を外へ出そうとする、と言う。τὸ ἐνδομυχοῦν は「内に潜むもの」。ἀναμένειν はここと下で対格と不定詞をとる（l. 13517〜13531）。
- 採る校訂者：本文の読みの違いではない（各節の異読は各項）。
- 読者への影響：中（語のつながり）。訳語表の医者の語の項は、νόσος と ἀρρωστία をどちらも「病」、νόσημα を「病気」、θεραπεία・θεραπεύω を「手当て・手当てする」とし、礼拝の θεραπευτής（18.2 の「仕える者」）とつなげないとする。29.5 では ἀρρωστία と νόσος が同じ文に並び、26.10 の ἀρρωστία・νόσημα と同じ問題が出る。29.2 の πάθος は訳語表の「苦しみ（体の）」の項にあたるが、ここでは医者が手当てする病そのもの（γυμνῷ τῷ πάθει「むき出しになった病」）。χυμός は訳語表にない。ἰατρεία は訳語表にないが、8.13〜8.14 で「治療」と訳した（8.14 は ἰατρεία καὶ θεραπεία を「癒やしであり治療」とした）。
- 訳での扱い：訳注なし。29.5 の ἀρρωστία と νόσος の分け方、29.2 の πάθος、ἰατρεία（8.13 の「治療」に揃え、θεραπεία の「手当て」と分けるか）、29.3 の θεραπευτής（16.3 の医者の θεραπευτής と同じ向き。18.2 の「仕える者」とはつなげない）を、メインで決める。
- 確かめた資料：画像 `n164_w1600.jpg`（注解の右の欄の 8.、10.、12.）、`n165_w1600.jpg`。l. 13517〜13531。訳語表の κακόν（医者のたとえ）の項、δαίμων の項。`src/chapter-08/both.md` の 8.13〜8.14 の訳。

### 30.3〜30.7 呼びかけとくじの語（κλῆσις・καλέω、ἀποκληρόω、δυσκληρία、λόγος）
- 底本：30.3 の τινῶν προσθεμένων τῷ λόγῳ。30.4 の τὸ παρὰ τοῦ θείου βουλήματος ἀποκληροῦσθαι τοῖς ἀνθρώποις τὴν πίστιν, τῶν μὲν καλουμένων, τῶν δὲ λοιπῶν ἀμοιρούντων τῆς κλήσεως、εἰ δὲ ὁμότιμος ἐπὶ πάντας ἡ κλῆσις、οἱ διακονοῦντες τὸν λόγον、τοῦ μὴ πάντων ἐπικρατῆσαι τὸν λόγον。30.5 の οὐκ ἐπὶ τὸν κεκληκότα πρὸς συγκατάθεσιν。30.6 の τὸν λόγον … κηρύξαντος。30.7 の τῆς δυσκληρίας ἐπαιτιᾶσθαι。
- 注解：30.3 の προσθεμένων は「ある人々がことばに付いた」で、λόγος は新約でふつうのように福音の宣べ伝えを言う（使徒四・四）（l. 13762〜13766）。30.4 の καλουμένων は、続く κλῆσις と同じく新約の意味で、福音を知ることへの呼びかけを言う（l. 13833〜13836）。ἀποκληροῦσθαι は下の 30.4 の項。30.7 の δυσκληρία は字義では「不運」で、λῆξις（くじで当たった分け前）と対になる語だと言う（l. 13996〜13997）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（語のつながり）。30.4 の ἀποκληροῦσθαι（くじで割り当てる）と 30.7 の δυσκληρία（くじの悪さ、不運）は、どちらも κλῆρος（くじ）の語。神がくじのように気まぐれに分けるのではない（30.4）、退いた者は自分の不運を他人のせいにできない（30.7）、と論の初めと終わりで語が響き合う。κλῆσις・καλέω（呼ぶ）は別の語根。
- 訳での扱い：訳注なし。『神学講話』の訳語表は κλῆσις を「呼び名」とする（名の論の 29.13.7、30.18）が、ここは呼びかけ・召しの意味なので引き継がない。κλῆσις・καλέω は口語訳の「召し」「召す」に寄せるか、「呼びかけ」「呼ぶ」とするか、メインで決める（30.5 の τὸν κεκληκότα も同じ字にする）。λόγος は、訳語表の λόγος の項（御子でない λόγος はそのつど訳す）に従い、宣べ伝えられる福音の意味で訳す。ἀποκληρόω と δυσκληρία に「くじ」の字を残すと、語の響き合いが残る（論点一覧の判断）。
- 確かめた資料：画像 `n167_w1600.jpg`（注解の左の欄の 1.、8.、右の欄の 9.）、`n169_w1600.jpg`（注解の左の欄の 5.）。l. 13762〜13766、13791〜13836、13996〜13997。訳語表の λόγος の項。`books/gregory-nazianzen-theological-orations/AGENTS.md` の προσηγορία・κλῆσις の項。

## 28 章　人の生まれ方は神にふさわしくないものではない

### 28 章の全体　章の要約と論の参照
- 注解の要約（l. 13190〜13203）：グレゴリオスは、神がこのような仕方で人のいのちに入るのはふさわしくない、という反論に対して、人の生まれ方を弁護する。神の性格にそぐわない唯一のものは道徳の悪である。体の成り立ちには、悪いものも尊くないものもない。生む器官は、ほかの器官より尊さが劣るどころか、まさる。それによって種族の不死が保たれるからだ。

### 28.1 γεννήσεως（l と vulg は ἡμῶν を加える）、διαθρυλλοῦσι（d、e、g、p は διαθρυλοῦσι）、ὂν（f と euth 1、6 は ὧν）、θεῷ（l と vulg は τῷ θεῷ）

- ほかの読み（n161 の異読の欄）：l と vulg は γεννήσεως の後に ἡμῶν（「わたしたちの生まれ方」。12 行目）。d、e、g、p は διαθρυλοῦσι（λ を一つにした綴り）。f と euth 1、6 は ὂν の代わりに ὧν（13 行目）。l と vulg は τῷ θεῷ（14 行目）。
- 注解：κωμῳδοῦσι は「わたしたちの本性をあざけり、生まれ方をうるさく言い立てる」。διαθρυλλεῖν は「言い続ける」（l. 13205〜13208）。διὰ τούτων は「これらの手段によって」で、本性とそのはたらきをけなして言うことによって、の意味（l. 13210〜13212。下の 28.7 の項）。ἐφάψασθαι には 16 章の τῆς φύσεως ἡμῶν αὐτὸν ἐφῆφθαι を比べる（l. 13214〜13215）。
- 採る校訂者：底本は刷られた本文の形。英訳も「わたしたちの生まれ方」と ἡμῶν のある形で訳しているが、τῆς φύσεως ἡμῶν からの補いとも取れる（l. 44540〜44541）。
- 読者への影響：小。ἡμῶν の有無は、前の τὴν φύσιν ἡμῶν から意味が変わらない。

- 読者への影響：小。
- 訳での扱い：訳注なし。ἀκολουθία は訳語表の「筋道」の項にあたるが、ここは論の運びでなく「本性の成り行き」なので、16.13 の「本性の必然の筋道に従って」と同じく「本性の筋道」とできる（論点一覧の判断）。δημιουργός はこれまでの訳（7.10、8.17 の「造り主」）に揃える。ἢ οὕτω γ᾽ ἄν は「そうでなければ」で、帰結の願望法 ἐπανίοι（ἄν つき）。

### 28.4 μόνης（euth は欠く）、φύσις δὲ κακία οὐκ ἔστι（p は ἡ φύσις、euth 1、6 は φύσει、f と l と vulg は κακίας）
- 底本：εἰ οὖν μόνης κακίας τὸ θεῖον κεχώρισται, φύσις δὲ κακία οὐκ ἔστι, …（「本性は悪ではない」）
- ほかの読み（n162 の異読の欄）：euth は μόνης を欠く（4 行目）。p は ἡ φύσις、euth 1、6 は φύσει（5 行目）。f、l、vulg は κακία の代わりに κακίας（同。「悪には本性（実体）がない」「本性は悪のものではない」）。
- 注解：この読みには触れない。εἰ οὖν の注は、帰結は τίνα κ.τ.λ. から始まり、τὸ δὲ μυστ. と ἡ δὲ τοῦ ἀνθρ. の句は条件の部分に入る、と言う（l. 13297〜13300。下の項）。
- 採る校訂者：底本は κακία（f l に従わない）。英訳は、悪のうちに本性はない、という向きで訳しており、κακίας に近い形に立っているらしい（l. 44551〜44552）。
- 読者への影響：中。底本の κακία なら、「神が離れているのは悪だけで、本性は悪ではない。だから神が本性に入っても悪に入ったのではない」と、条件が一つの筋で結論へつながる。κακίας なら「悪は本性をもたない（悪は実在するものではない）」という、5〜7 章の悪の論（悪はないもの）を思わせる命題になる。
- 訳での扱い：訳注なし。底本の読みで「本性は悪ではない」と訳す。二つ目の読みは論の筋（本性に入ることが悪に入ることではない）を変えず、一般の読者の理解は変わらない（論点一覧の判断）。

### 28.5 τὸ διαμένειν（l と vulg は τό を欠く）、τὸ ἀνθρώπινον（l と vulg は τὸν ἄνθρωπον）、τῶν ἀνθρώπων（vulg は τῷ ἀνθρώπῳ）、ἡ αἰσθητική τε καὶ ἐνεργητική（d、h、l、n、p、vulg は ἡ ἐνεργητική）、τῇ φύσει（vulg は τῇ を欠く）
- 底本：ὁ δὲ σκοπός ἐστι τὸ διαμένειν ἐν τῇ ζωῇ τὸ ἀνθρώπινον. τὰ μὲν οὖν λοιπὰ τῶν ὀργάνων τὴν παροῦσαν συνέχει τῶν ἀνθρώπων ζωήν, ἄλλα πρὸς ἄλλην ἐνέργειαν μεμερισμένα, δι᾽ ὧν ἡ αἰσθητική τε καὶ ἐνεργητικὴ δύναμις οἰκονομεῖται· τὰ δὲ γεννητικὰ τοῦ μέλλοντος ἔχει τὴν πρόνοιαν, δι᾽ ἑαυτῶν τῇ φύσει τὴν διαδοχὴν ἀντεισάγοντα.

## 29 章　なぜ受肉が遅れたのか

### 29 章の全体　章の要約と並行箇所
- 注解の要約（l. 13415〜13421）：「なぜ受肉はこれほど遅れたのか」と問われるかもしれない。グレゴリオスは、病が表に出てくるのを待ってから薬を用いる医者のたとえを出して答える。

## 30 章　救いの後にも罪が残ること。信仰がすべての人に及ばないこと

### 30 章の全体　章の要約
- 注解の要約（l. 13604〜13611、13666〜13682）：「手当てがなされたのに、なぜ罪はやまないのか」と問われるかもしれない。グレゴリオスはたとえで答える。蛇は頭に致命の一撃を受けても、すぐに体の端までいのちを失うわけではない。同じように、罪は致命傷を受けたが、死にかけていても、まだすっかり死んではいない。次の反論は、恵みがすべての人に来ていないことから起こる。それは神の意志か力が欠けていることを示す、と言われる。グレゴリオスは、すべての人が神の申し出を受ける機会をもたなかったのなら、その反論にも重みがあっただろう、と答える。けれども、キリスト教の信仰はすべての言葉で宣べ伝えられた。また、神は人の自発に何かを残した。人は受け入れるのも拒むのも自由で、差し出された恵みを拒むなら、責められるべきは神でなく人だ。
- 注解の並行箇所：蛇のたとえは偽作の『キリストの降誕の日の講話』p. 1133 に引き写されている（l. 13684〜13686）。30.3〜30.4 の全体には、バトラー『宗教の類比』2.6「啓示が普遍的でないことについて」を比べよと言う（l. 13773〜13778）。
- 読者への影響：小。見出しを決める手がかり（訳文には写さない）。

- ほかの読み（n166 の異読の欄）：d、e、g、h、n、p は τῆς κεφαλῆς（3 行目）。f は ὁ κατόπιν ὁλκός の代わりに τοῦ σώματος ὁλκός（「体のとぐろ」。5 行目）。vulg は οὐρεόν（綴り）。f は ἐμψύχωται（6 行目）。l と vulg は κινήσεως の代わりに δυνάμεως（「いのちの力」）。d は ἐστέρηται の後に τῷ ἰδίῳ θυμῷ を繰り返す（7 行目）。l と vulg は τῷ βίῳ（9 行目）。ここで euth の抜粋が終わる（`desinit euth`）。
- 注解：τὴν καιρίαν は πληγήν を補う（「致命の一撃」）（l. 13688）。ὁ κατόπιν ὁλκός は「後ろのとぐろ」で、頭に続く全体を言う。ὁλκός は蛇の這った跡に使う語で、ここでは「とぐろ」（l. 13690〜13693）。ἐψύχωται は「生かされている、いのちを与えられている」（l. 13695〜13696）。θυμῷ は「気、元気」で、ここでは動物のいのちを言う。プラトンが魂の動物の部分を θυμός と ἐπιθυμία に分けたのと同じ使い方（『国家』439E、410D）（l. 13699〜13703）。τῆς ζωτικῆς κινήσεως は「いのちの動き」（l. 13705〜13706）。λειψάνοις は「その残りによって、なお人のいのちを悩ませる」で、βίος は絶対的に「人のいのち」を言う。8 章の τὸν βίον ἡμῶν τῇ νεκρότητι σβέννυσθαι を比べよ（l. 13708〜13713）。
- 採る校訂者：底本は刷られた本文の形（f の τοῦ σώματος に従わない）。
- 読者への影響：小。
- 訳での扱い：訳注なし。θυμός は注解に従い「いのちの勢い」の向きで、怒りの意味にしない（論点一覧の判断）。『アントニオス伝』の訳語表は θυμός を「怒り」とするが、ここは動物のいのちを言うので引き継がない。βίος は「人のいのち」。κακία は訳語表の「悪」。

### 30.4 προσήκει（f は語順を変える）、φασίν（e は φησιν）、τὸ παρά（f と vulg は τό を欠く）、τῶν μέν（l は τῶνδε μέν）、εἶχεν（d、e、g、h、n、p は ἂν εἶχε）
- 底本：οὔτε γὰρ ἀβούλητον εἶναι τὸ ἀγαθὸν προσήκει τῷ θεῷ, οὔτε ἀδύνατον. εἰ οὖν ἀγαθόν τι ἡ πίστις, διὰ τί, φασίν, οὐκ ἐπὶ πάντας ἡ χάρις; εἰ μὲν οὖν ταῦτα καὶ παρ᾽ ἡμῶν ἐν τῷ λόγῳ κατεσκευάζετο, τὸ παρὰ τοῦ θείου βουλήματος ἀποκληροῦσθαι τοῖς ἀνθρώποις τὴν πίστιν, τῶν μὲν καλουμένων, τῶν δὲ λοιπῶν ἀμοιρούντων τῆς κλήσεως, καιρὸν εἶχεν τὸ τοιοῦτον ἔγκλημα κατὰ τοῦ μυστηρίου προφέρεσθαι·
- ほかの読み（n167 の異読の欄）：f は προσήκει τ. ἀ.（προσήκει を前に出す。5 行目）。e は φησιν（6 行目）。f と vulg は τὸ παρά の τό を欠く（8 行目）。l は τῶνδε μέν（9 行目）。d、e、g、h、n、p は ἂν εἶχε（10 行目）。

### 30.4 ἀποκληροῦσθαι の意味（くじで、気まぐれに割り当てる）
- 底本：τὸ παρὰ τοῦ θείου βουλήματος ἀποκληροῦσθαι τοῖς ἀνθρώποις τὴν πίστιν, τῶν μὲν καλουμένων, τῶν δὲ λοιπῶν ἀμοιρούντων τῆς κλήσεως。異読はない。
- 注解：「信仰が行き当たりばったりに分け与えられ、ある人々は呼ばれ、残りは呼びかけにあずからない」。ἀποκληροῦν は「くじで割り当てる」で、筋の通った原理によらず、でたらめに分けるという考えを含む。オリゲネスは ἀποκληρωτικῶς を τεταγμένως、ὡρισμένως と対にし、κατὰ συντυχίαν と並べる（『フィロカリア』Robinson 版 p. 210、とくに p. 242 の φρονοῦσιν ὡς ἄρα κατὰ ἀποκλήρωσιν ὁ θεὸς ὃν θέλει ἐλεεῖ, ὃν δὲ θέλει σκληρύνει）。この取り方は、ἀποκληροῦν を「相続から外す」と取って abdicaretur fides と訳したエルウェトゥス（1573 年のラテン語訳）より良い（アリストテレス『政治学』7.11.8 の ἀποκληροῦν τοὺς πλείους と、ἀπόκληρος を比べる）、と言う。グレゴリオスの考えは、特定の人々に恵みを排他的、恣意的に与えることはなく、神はすべての人に自由に差し出す、ということで、選びの教えの聖書的でない形を退け、意志の自由を説く点で、ユスティノス『第一弁明』43 の言葉を思わせる、と言う（l. 13791〜13831）。英訳の脚注 [2011] も、この一節を反カルヴァン主義的とし、ユスティノス『第一弁明』43 を挙げる（l. 44675〜44681）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中。「くじのように気まぐれに分ける」と取ると、神が恣意的に選ぶという考えを退ける論になる。「相続から外す」と取ると、信仰を奪う、取り上げる、という意味になり、続く「ある人々は呼ばれ、残りは呼びかけにあずからない」との対応が弱くなる。
- 訳での扱い：訳注なし。注解に従い「くじで割り当てるように分ける」の向きで訳す。30.7 の δυσκληρία とつなげる（上の全体の項）。
- 確かめた資料：画像 `n167_w1600.jpg`（注解の左の欄の 8. から右の欄）。l. 13791〜13831。英訳 l. 44675〜44681。

### 30.4 πρώτην（e は欠く）、τοῦ（vulg は欠く）、ἀθρόως（d は欠く）、τῆς διδαχῆς（vulg は欠く）と、ὁμόγλωσσοι（使徒二章）

### 30.4〜30.5 ὁ γὰρ τοῦ παντὸς … κύριος と προαίρεσις、ἀδούλωτον、αὐτεξούσιον
- 底本：ὁ γὰρ τοῦ παντὸς τὴν ἐξουσίαν ἔχων δι᾽ ὑπερβολὴν τῆς εἰς τὸν ἄνθρωπον τιμῆς ἀφῆκέ τι καὶ ὑπὸ τὴν ἡμετέραν ἐξουσίαν εἶναι, οὗ μόνος ἕκαστός ἐστι κύριος. τοῦτο δέ ἐστιν ἡ προαίρεσις, ἀδούλωτόν τι χρῆμα καὶ αὐτεξούσιον, ἐν τῇ ἐλευθερίᾳ τῆς διανοίας κείμενον. 異読はない。

- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（語のつながり）。5 章の自由意志の論（5.19〜5.24）と、語でつながる。
- 訳での扱い：訳注なし。προαίρεσις は訳語表の「意志」、αὐτεξούσιον は「自由」（5.19 の「主人をもたず、自由であるという恵み」）。ἀδούλωτον は訳語表にないが、5.19 の ἀδέσποτον「主人をもたない」と並ぶ語なので、「奴隷にされない」とすると対が残る（論点一覧の判断）。ἐξουσία は「権能」「支配」、τιμή は 28.4 からの「尊さ」の系で「尊ぶこと」とできる（上の 28.4 の項）。

### 30.5 μετατεθείη（e は μεταθείη）、πρὸς συγκατάθεσιν（l*（vid）と vulg は πρὸς τὴν κατάθεσιν）
- 底本：οὐκοῦν ἐπὶ τοὺς μὴ προσαχθέντας τῇ πίστει δικαιότερον ἂν τὸ τοιοῦτον ἔγκλημα μετατεθείη, οὐκ ἐπὶ τὸν κεκληκότα πρὸς συγκατάθεσιν.
- ほかの読み（n168 の異読の欄）：e は μεταθείη（15 行目。字の落ち）。l の最初の手（vid）と vulg は τὴν κατάθεσιν（同。συγ- を欠き冠詞を足す）。
- 注解：συγκατάθεσιν には、5 章の οὐκ ἔξω τῆς τῶν ἀντιλεγόντων συγκαταθέσεως を比べよ（l. 13931〜13933 の右の欄）。
- 採る校訂者：底本は συγκατάθεσιν。
- 読者への影響：小。
- 訳での扱い：訳注なし。συγκατάθεσις は 5.19 の訳（「反論する人々が同意すること」）に揃えて「同意」。τὸν κεκληκότα は上の全体の項（κλῆσις・καλέω）の字に揃える。
- 確かめた資料：画像 `n168_w1600.jpg`（異読の欄、`pct:3,54.5,90,4`、注解の右の欄の 15.）。l. 13906〜13907、13931〜13933。`src/chapter-05/both.md` の 5.19 の訳。

### 30.6 κατὰ ταὐτόν（d は κατ᾽ αὐτόν、f は κατ᾽ αὐτό）と、ペテロの説教（使徒二・四一）、ἐκκλησία
- 底本：οὐδὲ γὰρ ἐπὶ τοῦ Πέτρου κατ᾽ ἀρχὰς τὸν λόγον ἐν πολυανθρώπῳ τῶν Ἰουδαίων ἐκκλησίᾳ κηρύξαντος, τρισχιλίων κατὰ ταὐτὸν παραδεξαμένων τὴν πίστιν, πλείους ὄντες τῶν πεπιστευκότων οἱ ἀπειθήσαντες ἐμέμψαντο τὸν ἀπόστολον ἐφ᾽ οἷς οὐκ ἐπείσθησαν.
- ほかの読み（n168 の異読の欄 18 行目）：d は κατ᾽ αὐτόν、f は κατ᾽ αὐτό（どちらも「その同じ時に」の ταὐτόν の気息と字の崩れ）。
- 注解：ἐπὶ τοῦ Π. は使徒二・四一（l. 13934 の右の欄）。ἐκκλησίᾳ は、ここではまったく一般に人々の集まりを言う。使徒一九・三二 を比べよ（l. 13935〜13937 の右の欄）。
- 新約の本文（Robinson & Pierpont）：使徒二・四一 は … καὶ προσετέθησαν τῇ ἡμέρᾳ ἐκείνῃ ψυχαὶ ὡσεὶ τρισχίλιαι。口語訳は「その日、仲間に加わったものが三千人ほどあった」。使徒一九・三二 は ἦν γὰρ ἡ ἐκκλησία συγκεχυμένη（エペソの騒ぎの集まり）。
- 採る校訂者：底本は κατὰ ταὐτόν。
- 読者への影響：小。ἐκκλησία は「教会」でなく、ユダヤ人の大勢の「集まり」。
- 訳での扱い：訳注なし。ἐκκλησία は注解に従い「集まり」とし、「教会」としない（論点一覧の判断）。0.1 の ἡ ἐκκλησία は「教会」と訳し、『秘義教話』の訳語表も「教会」とするが、ここはユダヤ人の集まりなので分ける。「三千人」は使徒二・四一 の数で、引用でないので出典は付けない。Πέτρος は口語訳の「ペテロ」。
- 確かめた資料：画像 `n168_w1600.jpg`（異読の欄、`pct:3,54.5,90,4`、注解の右の欄の 16.、17.）。l. 13907、13934〜13937。`src/chapter-00/both.md` の 0.1 の訳。新約 `ACT.csv` l. 68、693。口語訳（`node tools/bible.js Acts.2.41`）。

### 30.7 ἦν（d は欠く）、προτεθείσης（vulg は προταθείσης）
- 底本：οὐδὲ γὰρ ἦν εἰκός, ἐν κοινῷ προτεθείσης τῆς χάριτος, τὸν ἑκουσίως ἀποφοιτήσαντα μὴ ἑαυτόν, ἀλλ᾽ ἕτερον τῆς δυσκληρίας ἐπαιτιᾶσθαι.
- ほかの読み（n169 の異読の欄 1 行目）：d は ἦν を欠く。vulg は προταθείσης（προτείνω。「差し出された」）。
- 注解：δυσκληρίας は上の全体の項（l. 13996〜13997）。
- 採る校訂者：底本は προτεθείσης（προτίθημι。「皆の前に置かれた」）。
- 読者への影響：小。
- 訳での扱い：訳注なし。εἰκός は訳語表の「当然、理に合う」。χάρις は上の全体の項。
- 確かめた資料：画像 `n169_w1600.jpg`（異読の欄、注解の左の欄の 5.）。l. 13989、13996〜13997。訳語表の εἰκός の項。
