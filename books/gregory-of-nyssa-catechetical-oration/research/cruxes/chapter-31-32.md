## 31〜32 章の全体　語の論点

### 32.4、32.7、32.14、32.16 μυστήριον・μυστικός と 32.12 μυσταγωγεῖ
- 底本：32.4 の δι᾽ ἀκριβείας καταμαθὼν τὸ μυστήριον、32.7 の τί οὖν ἔξω τοῦ εἰκότος ἐν τῷ μυστηρίῳ μανθάνομεν、32.14 の τοῦτο μεμαθήκαμεν περὶ τοῦ σταυροῦ τὸ μυστήριον、32.16 の μέρος τι τῶν μυστικῶν διδαγμάτων、32.12 の ὁ μέγας … Παῦλος μυσταγωγεῖ τὸν ἐν Εφέσῳ λαόν。
- 注解：32.4 の τὸ μυστήριον は、キリスト教の啓示一般を言う（l. 14247〜14249）。32.16 の μυστικός は μυστήριον の古い意味（啓示された真理）によるもので、秘跡の儀式の意味はない。秘跡はまだ論じられておらず、ἡ κατὰ τὸ λουτρόν の前の καί が、これを前の受肉と十字架の μυστήρια につなぐからだ、と言う（l. 14978〜14993）。32.12 の μυσταγωγεῖ は「手ほどきする」で、異教の秘儀の語をキリスト教に移した用例（イグナティオス『エペソ人へ』12、ピリピ四・一二、第一コリント二・七、知恵の書八・四）を挙げ、33 章の μυηθεῖσι の注を見よと言う（l. 14792〜14798）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中。訳語表は μυστήριον を「奥義」（0.1）と「秘義」（33 章以下の儀式）に分ける。32.16 は洗礼の話への橋渡しの文なので、「秘義」にすると、儀式としての洗礼を言うように読める。
- 訳での扱い：訳注なし。注解に従い、この範囲の μυστήριον・μυστικός はみな「奥義」の側（32.16 は「奥義の教え」など）。32.12 の μυσταγωγεῖ は『秘義教話』の μυσταγωγία「秘義の手ほどき」と字が重なるので、ここでは「奥義へと手ほどきする」のように「奥義」に寄せるかを、メインで決める。
- 確かめた資料：画像 `n171_w1600.jpg`、`n176_w1600.jpg`、`n178_w1600.jpg`（全体）。l. 14244〜14249、14792〜14798、14978〜14993。`books/cyril-mystagogical-catecheses/AGENTS.md` の訳語表（μυσταγωγία）。

### 32.11、32.14、32.16 λόγος の使い分け
- 底本：32.11 の εἴτε δὴ θεότητα … εἴτε λόγον εἴτε δύναμιν εἴτε σοφίαν … οὐδὲν ὁ λόγος ἡμῶν περὶ φωνῆς … διαφέρεται（同じ文に、神を呼ぶ名の λόγος と、「わたしたちの論」の λόγος が並ぶ）。32.14 の τὰ δὲ ἀπὸ τούτου τοιαῦτα κατὰ τὸ ἀκόλουθον περιέχει ὁ λόγος、32.16 の αὐτόθεν τοῦ λόγου τὸ ὑπὲρ τὴν φύσιν ἐμφαίνοντος。32.7 の λόγον βαθύτερον、32.8 の κατὰ τὸν ὑψηλότερόν τε καὶ θειότερον λόγον（意味）。
- 注解：32.14 は「（福音の）記事に含まれる、その後の出来事」の意に取る（l. 14854〜14863）。32.15 の ἡ ἱστορία（記録）と同じものを指す。32.8 の λόγον は、福音のすべての言葉と出来事が、表に見えるものより「高く、神的な意味」をもつこと（l. 14509〜14519）。
- 採る校訂者：本文の読みの違いではない（32.8 の λόγον の異読は下の項）。
- 読者への影響：中。訳語表の λόγος は、御子の「ことば」、論の「論」「教え」、福音の「みことば」（30 章）に分けている。32.14 と 32.16 の「記事、語られていること」は、まだ表にない使い方。英訳は 32.11 の λόγον を「知性」の意の語で訳していて、御子の名と取っていない。
- 訳での扱い：訳注なし。32.11 の神の名の λόγον は、δύναμις・σοφία と並ぶ呼び名なので、訳語表の御子の「ことば」に揃え、同じ文の ὁ λόγος ἡμῶν は「わたしたちの論」と分けるのが自然。32.14 と 32.16 は「記事」「語られていること」のように、32.15 の ἱστορία「記録」とつながる語にするか、メインで決める。32.7 と 32.8 は「意味」。

### 31.1 ἐριστικῆς（f は αἱρετικῆς）と ἐβούλετο（sic codd）
- 底本：Ἀλλ᾽ οὐκ ἀποροῦσιν οὐδὲ πρὸς τὰ τοιαῦτα τῆς ἐριστικῆς ἀντιλογίας. λέγουσι γὰρ δύνασθαι τὸν θεόν, εἴπερ ἐβούλετο, …
- ほかの読み：f は αἱρετικῆς（「異端の反論」。n169 の異読の欄 1 行目の `7 εριστικης] αιρετικης f`）。ἐβούλετο には `sic codd`（写本はみなこう読む）と刷られている。
- 注解：τῆς ἐριστ. ἀντ. の冠詞は英語なら不定冠詞にあたり、「言いがかりの返答」の意。ἐριστικός は、まともな論を持たず、ただ争うのが好きで言い返すことを言い、プラトン『ソフィスト』225 C 以下の定義を挙げる。ἀντιλογία にも見下す響きがある（l. 14011〜14025）。8. ἀναγκαστικῶς は συμβουλευτικῶς（勧めによって）の反対で、プラトン『法律』930 B を挙げる（l. 14027〜14030）。
- 採る校訂者：底本は ἐριστικῆς。
- 読者への影響：小。
- 訳での扱い：訳注なし。「言いがかり」「争い好きの反論」の向きで訳す。ἐβούλετο は写本どおりの未完了で、「もしお望みになったなら」と、神を主語にした尊敬語で受ける。

### 31.2 ποῦ δὲ ἡ ἀρετή（vulg は欠く）、ἢ τῶν ἀλόγων（f は καί）、κατορθούντων の意味
- 底本：ποῦ τοίνυν ἐν τούτοις τὸ αὐτεξούσιον; ποῦ δὲ ἡ ἀρετή; ποῦ δὲ τῶν κατορθούντων ὁ ἔπαινος; μόνων γὰρ τῶν ἀψύχων ἢ τῶν ἀλόγων ἐστὶ …

- 注解：κατορθούντων は自動詞で「（道徳の上で）成し遂げる人々」。ストア派が広めた意味だと言う（l. 14032〜14036）。31.3 の ἀφῄρηται τῶν κατορθούντων ὁ ἔπαινος も同じ句。
- 採る校訂者：底本は ἀρετή の問いあり、ἢ。
- 読者への影響：中（κατορθούντων の取り方）。英訳は ἀρετή の問いを訳していて底本の側に立つが、τῶν κατορθούντων ὁ ἔπαινος を「導く者からのほまれ」の向きで訳していて（脚注 [2012] に原語だけを挙げる）、注解の取り方と違う。
- 訳での扱い：訳注なし。注解に従い「正しく行う人々へのほまれ」の向きで、31.2 と 31.3 を同じ言い方にする。英訳と比べるレビューで、この違いを誤りとしない。

### 32.1 τὸ μάλιστα μὲν（f は τό を欠く、vulg は μηδέ を μή）と、反論の二段の組み立て
- 底本：τὸ μάλιστα μὲν μηδὲ ὅλως δεῖν εἰς θανάτου πεῖραν ἐλθεῖν τὴν ὑπερέχουσαν φύσιν, … εἰ δὲ καὶ πάντως ἔδει τοῦτο γενέσθαι κατά τινα λόγον ἀπόρρητον, ἀλλ᾽ οὖν τὸ μὴ τῷ ἀτίμῳ τρόπῳ τοῦ θανάτου καθυβρισθῆναι。
- ほかの読み：f は τό を欠く、vulg は μηδέ の代わりに μή（n170 の異読の欄 2〜3 行目の `32. 13 om το f || μη vulg`。見出しの語なし）。
- 注解：τὸ μάλιστα μέν に対応するのは下の εἰ δὲ καί。反論はまず「死はどんな形でも救いの計画に入れるべきでない」という強い形で出され、次に「死が要るとしても、恥ずべき死に方は避けられたはずだ」と弱めた形になる。τὸ … μηδὲ … δεῖν は τί に答え、下の τὸ μὴ … καθυβρισθῆναι と並ぶ（l. 14137〜14146、14199〜14205）。μετὰ ῥᾳστώνης は「たやすく」、つまり苦しみを受けずに（l. 14196〜14197）。
- 採る校訂者：底本は τό あり、μηδέ。
- 読者への影響：中（組み立て）。英訳は τὸ μάλιστα μέν を「よりよい見方を取れば」の向きの挿入句で訳していて（脚注 [2014] に原語だけを挙げる）、注解の取り方と違う。
- 訳での扱い：訳注なし。注解の組み立てに従い、「何よりもまず…。また、たとえ…としても、せめて…」のように、二つの τό の句を相手の言い分の二段として並べる。英訳と比べるレビューで、この違いを誤りとしない。

### 32.7 εἰ μέν（l は ἡμῖν、vulg は εἰ μή）、εἰδεῖεν（f と vulg は εἰδοῖεν）、κρυπτῶν（l と vulg は κρυπτομένων）、ἐπιίστορες（l*vid と vulg は ἐπίστορες）
- 底本：ὁ δὲ σταυρὸς εἰ μέν τινα καὶ ἕτερον περιέχει λόγον βαθύτερον, εἰδεῖεν ἂν οἱ τῶν κρυπτῶν ἐπιίστορες. ὃ δ᾽ οὖν εἰς ἡμᾶς ἐκ παραδόσεως ἥκει, τοιοῦτόν ἐστιν。
- ほかの読み（n173 の異読の欄 5〜6 行目）：l は εἰ μέν の代わりに ἡμῖν、vulg は εἰ μή（「もし…でないなら」）。f と vulg は εἰδοῖεν（綴りの違い）。l と vulg は κρυπτομένων（「隠されているもの」）。l の最初の手（らしい）と vulg は ἐπίστορες（綴りの違い）。

### 32.8 ὃ οὐχὶ … ἐμφαίνεται（d、e、f、h、l¹、n、p は ᾧ、vulg は ἐν ᾧ）、ἐμφαίνεται（e は φαίνεται）、δέ（l* は διά）

### 32.8 ἐν μὲν τῷ θανάτῳ … ἐν δὲ τῷ τρόπῳ（Thdrt^sirm は ἀθανάτῳ、vulg と Thdrt^sirm は ἀνθρώπῳ、Thdrt^rom は σκοπῷ）

### 32.9 文の組み立てと προβολάς（h は προσβολάς）、τούτου（f は τούτῳ）、τῷ（d は欠く）、ἑαυτόν（l*vid と vulg は ἑαυτῷ）、συνδέων（d、f は συνδεσμῶν）、ἐστί（vulg は欠く）

### 32.14 κεραίαν（l*vid は καιρέαν、vulg は καὶ γαῖαν）、διαλαμβάνει（l*vid と vulg は καταλαμβάνει、h は λαμβάνει）
- 底本：ἐνταῦθα τὴν μέσην κεραίαν μιᾷ προσηγορίᾳ διαλαμβάνει, πᾶν τὸ διὰ μέσου τῶν ἐπουρανίων καὶ ὑποχθονίων ὀνομάσας ἐπίγειον。

### 32.15 πρὸς τὸ εἶναι（l と vulg は ἀναστῆναι）、語順（l と vulg）、μηδέν（f、l と vulg は μηδέ）
- 底本：τὸ γὰρ μὴ ἐμμεῖναι τῷ θανάτῳ, καὶ τὰς διὰ τοῦ σιδήρου κατὰ τοῦ σώματος γενομένας πληγὰς μηδὲν ἐμπόδιον πρὸς τὸ εἶναι ποιήσασθαι, κατ᾽ ἐξουσίαν τε φαίνεσθαι μετὰ τὴν ἀνάστασιν τοῖς μαθηταῖς, … μηδὲν τῆς εἰσόδου τῆς διὰ τῶν θυρῶν προσδεόμενον, …
- ほかの読み：l と vulg は εἶναι の代わりに ἀναστῆναι（「よみがえること」）。l と vulg は τοῖς μαθηταῖς μετὰ τὴν ἀνάστασιν の語順（n177 の異読の欄 2 行目の `14 ειναι] αναστηναι l vulg || 15 τοις μαθ. μ. τ. α. l vulg`）。f、l と vulg は μηδὲν τῆς εἰσόδου の μηδέν の代わりに μηδέ（n178 の異読の欄 1 行目）。
- 注解：πρὸς τὸ εἶναι は「（キリストが）存在することに何の妨げにもならなかった」で、グレゴリオスは復活のいのちを考えている。最良の写本は εἶναι と読み、l とパリ版の ἀναστῆναι は明らかに推測による修正だ、と言う（l. 14875〜14881）。

- 読者への影響：小。底本の「存在すること（有ること）」も、注解の取り方では復活のいのちを言う。
- 訳での扱い：訳注なし。訳語表の τὸ εἶναι「有ること」に揃えるか、注解の取り方に従って「生きて有ること」のように補うかは、訳出で決める。英訳と比べるレビューで、「よみがえる」でないことを誤りとしない。κατ᾽ ἐξουσίαν は訳語表の「思いのままに」。

### 32.15 福音書と使徒の働きの暗示（ヨハネ一九・三四、二〇・一九、二〇・二二、マタイ二八・二〇、ルカ二四・三六、使徒一・九）

- 訳での扱い：訳注なし。どれも言い換えた暗示で、『』で囲まない。語は口語訳に寄せられる（「息を吹きかけて」「共にいる」「彼らの中に」）。σιδήρου は「鉄」のままにし、「槍」を補うかは訳出で決める。出典を付けるかはメインで決める。キリストの動作なので、不定詞の名詞化でも尊敬語にする（訳語表の文型の訳し方）。

- 底本：ἀλλ᾽ ἐπειδὴ μέρος τι τῶν μυστικῶν διδαγμάτων καὶ ἡ κατὰ τὸ λουτρόν ἐστιν οἰκονομία, ὃ εἴτε βάπτισμα εἴτε φώτισμα εἴτε παλιγγενεσίαν βούλοιτό τις ὀνομάζειν, οὐδὲν πρὸς τὴν ὀνομασίαν διαφερόμεθα, …
- ほかの読み（n178 の異読の欄 2〜3 行目）：ἀλλ᾽ から後が euth 4、5、7 にある（`αλλ] exstant sqq in euth 457`）。l と vulg は κατά の代わりに περί。e の最初の手は εἴτε φώτισμα を欠く。
- 注解：ἀλλ᾽ ἐπειδή から、洗礼を扱う次の部分に移る。ここから 34 章の τὸ ἐπηγγελμένον οὐκ ἀμφιβάλλοντες までの全体が、エウテュミオス・ジガベノス『教義の武具』第 25 題に引かれている（l. 14969〜14976）。μυστικῶν は上の「μυστήριον・μυστικός」の項。ἡ κατὰ τὸ λουτρὸν οἰκ. は「洗いの οἰκονομία」で、エペソ五・二六 とテトス三・五 を挙げ、後者から παλιγγενεσία の語も来る、と言う（l. 14995〜14999）。φώτισμα はヘブル六・四、一〇・三二 を参照させ、ユスティノス『第一弁明』61 の、この洗いは「照らし」と呼ばれる、学ぶ者の思いが照らされるからだ、という一節と、グレゴリオス『キリストの洗礼について』p. 592 を引き、洗礼のほかの呼び名についてアレクサンドリアのクレメンス『教育者』1・6、ナジアンゾスのグレゴリオス『講話』40 を挙げる（l. 15001〜15013）。
- 新約・口語訳との近さ：テトス三・五 の口語訳は「再生の洗い」、エペソ五・二六 は「水で洗うことにより」、ヘブル六・四 は「いったん、光を受けて」。
- 採る校訂者：底本は κατά、εἴτε φώτισμα あり。
- 読者への影響：中（訳語）。33 章以下の洗礼の論の用語がここで初めて出る。
- 訳での扱い：訳注なし。『秘義教話』の訳語表（λουτρόν「洗い」、テトス三・五 の「再生の洗い」、φωτισμός「照らし」）に合わせ、βάπτισμα「洗礼」、φώτισμα「照らし」、παλιγγενεσία「再生」とするのが自然。ἡ κατὰ τὸ λουτρὸν οἰκονομία は訳語表の οἰκονομία「救いのわざ」で受けて「洗いによる救いのわざ」の向きにするか、メインで決める。テトス三・五 などは暗示で、出典は付けない。
