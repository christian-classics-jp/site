## 33〜34 章の全体　語の論点

### 33.1、33.2、34.5 μυστήριον・μυηθεῖσι・μυστικὴ οἰκονομία
- 底本：33.1 の δι᾽ ὧν τὸ τῆς ἀναγεννήσεως πληροῦται μυστήριον、33.2 の ζωῆς ἀρχηγὸς τοῖς μυηθεῖσι γίνεται、34.5 の τοῖς διὰ τῆς μυστικῆς ταύτης οἰκονομίας ἀναγεννωμένοις。
- 注解：33.1 の μυστήριον は、ここで「秘跡」の意味に近づく。34 章の τῆς μυστικῆς ταύτης οἰκονομίας と比べよ、と言う（l. 15131〜15133）。33.2 の μυηθεῖσι は 32 章の μυσταγωγεῖ の注を見よと言い、μύειν と μυστήριον をキリスト教の秘跡に使う例について、イグナティオス『エペソ人へ』12 への Lightfoot の注を挙げる（l. 15154〜15159）。34.5 の μυστικῆς … οἰκονομίας は「この秘跡としての οἰκονομία を通して」の意味で、『エウノミオス駁論』の τῇ τῶν μυστικῶν ἐθῶν τε καὶ συμβόλων κοινωνίᾳ と『キリストの洗礼について』の τῆς μυστικῆς πράξεως を比べさせる（l. 15665〜15673）。
- 採る校訂者：本文の読みの違いではない（33.2 の μυηθεῖσι の異読は 33.2 の項）。
- 読者への影響：中（訳語）。訳語表は μυστήριον を、32 章までの啓示の意味の「奥義」と、33 章以下の儀式の「秘義」に分ける。32.16 の μυστικῶν διδαγμάτων は注解に従って「奥義の教え」にした。33.1 から儀式の意味になると注解が言うので、ここが切り替わりの箇所になる。
- 訳での扱い：訳注なし。33.1 は「再生の秘義」、33.2 の τοῖς μυηθεῖσι は『秘義教話』の μυέω に寄せて「秘義を授けられた者」の向き、34.5 の μυστικός は「秘義の」とするのが、訳語表の分け方に合う。32.12 の μυσταγωγεῖ（「奥義へと手ほどきする」）とは場面が違うので、字をつなげなくてよい。
- 確かめた資料：画像 `n179_w1600.jpg`、`n180_w1600.jpg`、`n185_w1600.jpg`（全体）。l. 15131〜15133、15154〜15159、15665〜15673。`books/cyril-mystagogical-catecheses/AGENTS.md` の訳語表（μυστήριον、μυσταγωγία）。

### 33.1、33.2、34.1〜34.5 ἐπίκλησις・ἐπικαλέω・καλέω・κλῆσις
- 底本：33.1 の χάριτος οὐρανίας ἐπίκλησις、33.2 の δυνάμεως θείας ἐπίκλησις、34.1 の τὸ θεῖον … καλούμενον、34.2 の κατὰ πάντα καιρὸν ἐπικλήσεως、34.3 の τοῖς ἐπικαλουμένοις、34.5 の τὴν διὰ τῆς εὐχῆς κλῆσιν、κἂν μὴ ἐπικληθῇ … τὸ θεῖον。
- 注解：33.1 の χάριτος οὐρ. ἐπίκλησις に、グレゴリオス『キリストの洗礼について』の、水は上からの恵みが祝福するので人を新しくする、という一節と、『洗礼について』の、受ける者の信仰と聖別する祭司の祝福があれば、どの水も洗礼に適う、という一節を引く（l. 15091〜15101）。εὐχή にはユスティノス『第一弁明』61 の、洗礼を受ける者が祈りと断食をし、教会も共に祈る、という一節を引く（l. 15084〜15089）。34 章の要約は、洗礼の儀式に祈りによる神への呼び求めが先立つことを、論の一つに数える（l. 15345〜15348）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（訳語）。同じ語根の名詞と動詞が 2 章のあいだに 7 回出て、34 章の論（呼び求めれば神はそこにおられる）の要になる。
- 訳での扱い：訳注なし。『秘義教話』の訳語表は ἐπίκλησις を「呼び求め」とし、呼び求められる者の属格は「〜への呼び求め」とする。それに合わせて 33.1 は「天の恵みへの呼び求め」、33.2 は「神の力への呼び求め」、動詞は「呼び求める」（神が主語の受け身は、訳語表の文型の決まりで呼ぶ側の人を主語に立てる）、34.5 の κλῆσις も「呼び求め」でつなぐのが自然。訳語表の κλῆσις「召し」（30 章の、神が人を召す意味）とは向きが逆なので、34.5 では「召し」にしない。
- 確かめた資料：画像 `n179_w1600.jpg`（`pct:3,33,92,10`）。l. 15084〜15101、15345〜15348。`books/cyril-mystagogical-catecheses/AGENTS.md` の訳語表（ἐπίκλησις）。

### 33.1、33.3、34.5 γένεσις・γέννησις・ἀναγέννησις
- 底本：33.1 の τῆς πρώτης γενέσεως、ἑτέραν γένεσιν、ἐκ θνητῆς γενέσεως、τῆς ἀναγεννήσεως、33.3 の τῆς κατὰ σάρκα γεννήσεως、33.5 の τῆς διὰ τοῦ ὕδατος γινομένης ἀναγεννήσεως、34.5 の ἐν τῷ πνευματικῷ τῆς γεννήσεως τρόπῳ、ἀναγεννωμένοις。
- ほかの読み：写本は γένεσις と γέννησις をよく取り替える（33.1 の 4 行目の γένεσιν を euth 7 と vulg は γέννησιν、6 行目の γενέσεως を l と vulg は γεννήσεως、34.5 の γεννήσεως を d、e、g、h、n、p は γενέσεως。各項を見よ）。
- 採る校訂者：底本は 33.1 で γένεσις、33.3 と 34.5 で γέννησις。
- 読者への影響：中（訳語）。訳語表は 13 章の γένεσις を「生まれ方」、γέννησις を「誕生」とし、綴りにかかわらず「生まれる」とする。ここは同じ「誕生」を言う語で、写本も取り替えるので、二つを訳し分ける根拠は弱い。一方、ἀναγέννησις は、32.16 で「再生」とした παλιγγενεσία と別の語。
- 訳での扱い：訳注なし。γένεσις と γέννησις はどちらも「誕生」（33.1 の「初めの誕生」「別の誕生」）でよい。ἀναγέννησις を「新しく生まれること」とするか、παλιγγενεσία と同じ「再生」にするかは、メインで決める（『秘義教話』の訳語表に ἀναγέννησις の項はない）。
- 確かめた資料：画像 `n179_w1600.jpg`（`pct:3,33,92,10`）、`n184_w1600.jpg`（`pct:10,48.5,82,8`）。本の `AGENTS.md` の訳語表（γίγνομαι ἐν … / γέννησις・γένεσις、λουτρόν / βάπτισμα / φώτισμα / παλιγγενεσία）。

### 34.1、34.2、34.4、34.5 τὰ γινόμενα（儀式）と 34.2 τὰ γινόμενα（キリストの生涯の出来事）
- 底本：34.1 の ἐπὶ ἁγιασμῷ τῶν γινομένων、34.2 の τὸ παρεῖναι τοῖς γινομένοις αὐτόν、34.4 の εἰς τὸ παρεῖναι τὸ θεῖον τοῖς γινομένοις、34.5 の θεοῦ παρέσεσθαι τοῖς γινομένοις ἐπηγγελμένου。これと別に、34.2 の τοῖς διὰ τῶν γινομένων θαύμασι。
- ほかの読み：34.1 の γινομένων を f は τελουμένων（n182 の異読の欄 2 行目の `γινομενων] τελουμενων f`）。34.5 の γινομένοις を f は βουλομένοις、l と vulg は γενομένοις（n184 の異読の欄 2 行目）。
- 注解：34.1 の ἐπὶ ἁγιασμῷ τ. γ. は「儀式を聖別するために」で、ἐπί は目的を言う（5 章の ἐπὶ τούτοις の注を見よ。l. 15372〜15375）。34.2 の τοῖς γινομένοις は、上の τῶν γινομένων と比べよと言いながら、「呼び求められるたびに、行われることのうちにおられる」の意味に取る（l. 15462〜15465）。34.2 の初めの τῶν γινομένων は、キリストの生涯の出来事のうちに表れた不思議の意味に取る（l. 15442〜15446）。
- 採る校訂者：底本は γινομένων、γινομένοις。f の τελουμένων は、儀式を言う語で、意味を明らかにする形。
- 読者への影響：中。同じ τὰ γινόμενα が、34.2 の一文の中で二つの意味（キリストの生涯の出来事と、洗礼で行われること）に使われる。英訳は脚注 [2022]、[2025] で原語を挙げ、洗礼で行われることの意味で訳す。
- 訳での扱い：訳注なし。儀式の意味の τὰ γινόμενα（34.1、34.2 の後のほう、34.4、34.5）は「（洗礼で）行われること」で揃え、34.2 の初めの τῶν γινομένων は「（キリストが）なさったこと」の向きにして、二つを訳し分ける。34.5 の τοῖς γινομένοις に「洗礼で」を補うなら `// ` メモに書く。

### 34.5 τῆς θείας οἰκονομίας と τῆς μυστικῆς ταύτης οἰκονομίας
- 底本：τὸ δὲ προηγεῖσθαι τὴν διὰ τῆς εὐχῆς κλῆσιν τῆς θείας οἰκονομίας περιουσία τίς ἐστι τῆς ἀποδείξεως、τοῖς διὰ τῆς μυστικῆς ταύτης οἰκονομίας ἀναγεννωμένοις。
- 注解：τῆς θείας οἰκονομίας は、神の「計画」のうち、秘跡の手立てを使うことにかかわる部分を言う（下の τῆς μυστικῆς ταύτης οἰκονομίας と比べよ。l. 15576〜15582）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（訳語）。訳語表の οἰκονομία は「救いのわざ（神の）」で、10.3 の ἡ θεία οἰκονομία は受肉を言うので「神の救いのわざ」とした。32.16 の ἡ κατὰ τὸ λουτρὸν οἰκονομία も洗礼のことで、訳はメインで決めることになっていた。34.5 の二つは洗礼の儀式そのものを指す。
- 訳での扱い：訳注なし。「神の救いのわざ」とすると、10.3 の受肉と区別がつかず、呼び求めが受肉に先立つように読める。32.16 の決め方に合わせ、「（洗礼という）神の救いのわざ」「この秘義による救いのわざ」のように、洗礼を指すことが分かる形にするのがよい。メインで決める。

## 33 章

### 33.1 文の組み立て（ἐπειδὰν γάρ … ἐπειδὰν οὖν … δυσπειθῶς ἔχουσι）
- 底本：Ἐπειδὰν γὰρ παρ᾽ ἡμῶν τὸ τοιοῦτον ἀκούσωσιν, ὅτι, … τῆς ἐκ τοῦ θανάτου φθορᾶς· ἐπειδὰν οὖν τούτων καὶ τῶν τοιούτων ἀκούσωσιν καὶ προδιδαχθῶσι τὸν τρόπον, … δυσπειθῶς ἔχουσι πρὸς τὸ φαινόμενον βλέποντες。
- 注解：τὸ τοιοῦτον は ὅτι 以下で説き明かされる。前提の句は ἐπειδὰν οὖν τούτων で言い直され、帰結は δυσπειθῶς ἔχουσι から始まる（l. 15074〜15079）。πρὸς τὴν ζωήν は永遠のいのちのこと（l. 15081〜15082）。33 章の要約は、生まれつきの誕生がこの死ぬべき生への入り口であるように、洗礼の新しい誕生は永遠のいのちへの入り口だ、と言う（l. 15050〜15054）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（組み立て）。一文が底本で 11 行あり、ὅτι 以下に ἵνα の目的の句と、ὥσπερ … οὕτως の比べが入れ子になっている。冒頭の γάρ は 32.16 の終わり（洗いの話に移るという予告）を受ける。
- 訳での扱い：訳注なし。注解の組み立てに従い、ὅτι 以下（新しい誕生が見いだされねばならなかったこと）を独立した文に分け、ἐπειδὰν οὖν で「そのように聞き、…と前もって教えられると」と受け直して、帰結の「信じかねる」につなぐ。πρὸς τὴν ζωήν の「いのち」は、すぐ後の εἰς ἀθάνατον ζωήν と同じものとして、補わなくても通じる。
- 確かめた資料：画像 `n179_w1600.jpg`（全体）。l. 15019〜15036、15050〜15054、15074〜15082。

### 33.1 γένεσιν（euth 7 と vulg は γέννησιν）、γεγεννημένον（d、e、h、p は γεγενημένον、l は τό）、ἵν᾽ ὥσπερ（l と vulg は ὥσπερ γάρ）、γενέσεως（l と vulg は γεννήσεως）、φθοράν（f、l と vulg は γεννήσεως を加える）、γένηται（d は γεγέννηται）
- 底本：ἑτέραν γένεσιν ἐξευρεθῆναι … ἀλλ᾽ εἰς ἀθάνατον ζωὴν τὸν γεγεννημένον παράγουσαν, ἵν᾽, ὥσπερ ἐκ θνητῆς γενέσεως θνητὸν ἐξ ἀνάγκης τὸ γεγεννημένον ὑπέστη, οὕτως ἐκ τῆς μὴ παραδεχομένης φθορὰν τὸ γεννώμενον κρεῖττον γένηται τῆς ἐκ τοῦ θανάτου φθορᾶς。
- ほかの読み（n179 の異読の欄 1〜3 行目）：
  - 4 行目の γένεσιν を euth 7 と vulg は γέννησιν（`33. 4 γεννησιν euth 7 vulg`）。
  - 6 行目の τὸν γεγεννημένον を d、e、h、p は γεγενημένον（ν が一つ）、l は τὸ γεγεννημένον（中性）（`6 γεγενημενον dehp το γ. l`）。
  - ἵν᾽ ὥσπερ を l と vulg は ὥσπερ γάρ（`ιν ωσπερ] ωσπερ γαρ l vulg`）。
  - 6 行目の γενέσεως を l と vulg は γεννήσεως（`γεννησεως l vulg`）。
  - 7 行目の τὸ γεγεννημένον を h、n、p は γεγενημ.（`7 γεγενημ. hnp`）。
  - φθοράν の後に f、l と vulg は γεννήσεως を加える（`8 φθοραν]+γεννησεως fl vulg`）。
  - γένηται を d は γεγέννηται（`9 γενηται] γεγεννηται d`）。
- 採る校訂者：底本は γένεσιν、γεγεννημένον、ἵν᾽ ὥσπερ、γενέσεως、φθοράν（加えない）、γένηται。f l の γεννήσεως の付加に従わない。

### 33.1 οὖν（l と vulg は欠く）、προδιδαχθῶσι（euth 4、5 は προσδιδαχθῶσι）、σωματικῶς（e は σωματικόν）と、τὸ φαινόμενον、τῇ ἐπαγγελίᾳ

### 33.4 συγκρινόμενος の係り（vulg は ποιότητα; συγκρινόμενος と区切り、ὁ ἄνθρωπος と読む。f は συγκρινομένην）

- ほかの読み（n181 の異読の欄 1 行目）：vulg は ποιότητα の後に疑問符を置き、συγκρινόμενος を次の文に付ける（`1 ποιοτητα; συγκρινομενος vulg`）。f は συγκρινομένην（ποιότητα にかかる、`συγκρινομενην f`）。vulg は ἄνθρωπος に冠詞を付けて ὁ ἄνθρωπος（`ο ανθρωπος vulg`）。

### 34.1 ἐπὶ ἁγιασμῷ（p は τῷ ἁγιασμῷ、vulg は ἁγιασμῶν）と、τὰ κατόπιν ἐξητασμένα、κατασκευή、τὴν διὰ σαρκός

### 34.2 文の組み立て（δειχθέντος … δείξαντα）と、τοῖς διὰ τῶν γινομένων θαύμασι（e、h、n と euth は καὶ διὰ τῶν γινομένων θαυμάτων、f は θαυμασίων）
- 底本：δειχθέντος γὰρ τοῦ θεὸν εἶναι τὸν ἐν σαρκὶ φανερωθέντα, τοῖς διὰ τῶν γινομένων θαύμασι τὴν φύσιν ἑαυτοῦ δείξαντα, συναπεδείχθη τὸ παρεῖναι τοῖς γινομένοις αὐτὸν κατὰ πάντα καιρὸν ἐπικλήσεως。
- ほかの読み（n183 の異読の欄 1 行目）：e、h、n と euth は καὶ διὰ τῶν γινομένων θαυμάτων（`1 και δια τ. γ. θαυματων ehn euth`）。f は θαυμασίων（`θαυμασιων f`）。
- 注解：δειχθέντος は名詞の働きをする τοῦ θεὸν εἶναι κτλ. と一致し、全体で属格独立句になる。δείξαντα 以下は τὸν … φανερωθέντα にかかる従属の句。e、h、n と Euth. の読みは構文を易しくしようとした形、と言う（l. 15389〜15396）。συναπεδείχθη について、秘跡を通して神がはたらくことの証明は二つの論に拠ると言う。一つは、受肉が神の力の人々のうちでのはたらきを示したこと、もう一つは、キリストの約束が神の真実のゆえに頼れることで、この文は前者、続く文が後者を扱う（l. 15448〜15460）。

- 訳での扱い：訳注なし。注解の組み立てに従い、δείξαντα は φανερωθέντα にかけて「なさった不思議によってご自分の本性をお示しになった」とし、前提（神であることが示された）と帰結（呼び求めのたびにおられることも、あわせて示された）を文に分ける。英訳と比べるレビューで、この違いを誤りとしない。

### 34.4 οὐκέτ᾽ οὖν ἄν（f、l と vulg は οὖν を欠き、l と vulg は καί を加え、d、e、g、h、n、p と euth は ἄν を欠く）、προσδεοίμεθα（d は προσδεόμεθα）、τό（vulg は τόν）、αὐτῶν（d、h、n、p は αὐτόν）、πεπιστευκότες（f は πιστεύοντες）
- 底本：οὐκέτ᾽ οὖν ἂν ἑτέρας εἰς τὸ παρεῖναι τὸ θεῖον τοῖς γινομένοις ἀποδείξεως προσδεοίμεθα, τὸ μὲν θεὸν εἶναι διὰ τῶν θαυμάτων αὐτῶν πεπιστευκότες。
- ほかの読み（n183 の異読の欄 2〜4 行目）：f、l と vulg は οὖν を欠き、l と vulg は καὶ οὐκέτ᾽ と読む（`8 om ουν fl vulg και ουκετ l vulg`）。d、e、g、h、n、p と euth は ἄν を欠く（`om αν deghnp euth`）。d は προσδεόμεθα（直説法、`9 προσδεομεθα d`）。vulg は τὸν μέν（`τον μεν vulg`）。d、h、n、p は αὐτῶν の代わりに αὐτόν（`10 αυτον dhnp`）。f は πιστεύοντες（`πιστευοντες f`）。
- 採る校訂者：底本は οὖν と ἄν を両方残す。οὖν は f l に従わず 1 群と e に、ἄν は f l に従う（ἄν を欠くのは 1 群と e、euth）。αὐτῶν は e、f、g、l に従う。
- 読者への影響：小。ἄν を欠くと「もはや必要としない」の言い切りに近くなるが、意味は変わらない。αὐτόν では「不思議によって、そのかたが神であると信じている」となり、αὐτῶν（「不思議そのものによって」）と強めるところが違うだけ。
- 訳での扱い：訳注なし。ἂν … προσδεοίμεθα は可能の希求法で「もはや必要としないでしょう」の向き。τὸ μὲν … πεπιστευκότες、ἴδιον δὲ … εἰδότες、ἐν δὲ … οὐκ ἀμφιβάλλοντες の三つの分詞は理由の並び（34.2〜34.3 の二つの論と、約束の真実）なので、文型の決まり（8.17）のとおり主動詞との係りを残す。
- 確かめた資料：画像 `n183_w1600.jpg`（`pct:10,39,82,10`）。l. 15432〜15436。

### 34.4 ἴδιον δὲ … εἰδότες（l の最初の手と vulg は欠く）、οὐκ（f は μή）、ἀμφιβάλλοντες で euth が終わる
- 底本：ἴδιον δὲ τῆς θεότητος τὸ ἀμίκτως πρὸς τὸ ψεῦδος ἔχειν εἰδότες, ἐν δὲ τῷ ἀψευδεῖ τῆς ὑποσχέσεως παρεῖναι τὸ ἐπηγγελμένον οὐκ ἀμφιβάλλοντες。
- ほかの読み（n183 の異読の欄 4〜5 行目）：l の最初の手と vulg は ἴδιον … εἰδότες を欠く（`10-11 ιδιον...ειδοτες om l* vulg`）。f は οὐκ の代わりに μή（`13 ουκ] μη f`）。ἀμφιβάλλοντες で euth が終わる（`αμφιβαλλοντες] desinit euth`）。
- 注解：ἐν δὲ τῷ ἀψ. は「約束の偽りのない真実によって、約束されたものがそこにある」の意味（l. 15482〜15484）。
- 採る校訂者：底本は ἴδιον … εἰδότες を残す（l の訂正者の手と、ほかの写本）。
- 読者への影響：小。l* と vulg の欠落は、34.3 の「真実は神の本性に固有のもの」を受ける前提を落とすが、底本では残る。同じ語の続く箇所（-ότες … -οντες）で目が飛んだ欠落に見える（論点一覧の判断）。
- 訳での扱い：訳注なし。ἀμίκτως πρὸς τὸ ψεῦδος ἔχειν は「偽りと少しも混じらない」の向き。訳語表の μίγνυμι の系（「混ざる」「混じり合う」）とつながる語だが、ここは受肉の論ではないので、「混じらない」でよい。τὸ ἀψευδές τῆς ὑποσχέσεως は「約束が偽りのないこと」。

### 34.5 τὸ δὲ προηγεῖσθαι … περιουσία τίς ἐστι τῆς ἀποδείξεως（論の位置）
- 底本：τὸ δὲ προηγεῖσθαι τὴν διὰ τῆς εὐχῆς κλῆσιν τῆς θείας οἰκονομίας περιουσία τίς ἐστι τῆς ἀποδείξεως τοῦ κατὰ θεὸν ἐπιτελεῖσθαι τὸ ἐνεργούμενον。
- 注解：「祈りによる呼び求めが神の οἰκονομία に先立つことは、いわば証明のあり余る分になる」の意味に取る。グレゴリオスが言いたいのは、すでに挙げた事実だけで神の恵みのはたらきの証明には足り、祈りによる呼び求めからの論はそれを超える分だ、ということ。人の誕生では、呼び求めがなくても神の力が人の努力と共にはたらく、というたとえでこれを示す（l. 15486〜15499）。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（論の運び）。περιουσία を「余分」と訳すと、呼び求めが要らないものに読める。注解の取り方は、証明として十分なうえに、さらに上乗せされるもの。
- 訳での扱い：訳注なし。περιουσία は訳語表（24.2〜24.4 の項）の「あふれるほどの豊かさ」の系で、「証明をあふれるほどに満たすもの」の向き。τὸ ἐνεργούμενον は 33.1 の τὸ σωματικῶς ἐνεργούμενον と同じ語で、「行われること」で揃える。κατὰ θεόν は「神によって」（神のはたらきによって成し遂げられること）。
- 確かめた資料：画像 `n183_w1600.jpg`（注解の右の欄）。l. 15486〜15499。本の `AGENTS.md` の訳語表（καταβαίνω / κάθοδος / συγκατάβασις の項の περιουσία）。

### 34.5 παρ᾽ αὐτῶν（f は παρ᾽ αὐτοῖς）、δι᾽ εὐχῆς τὸ θεῖον（e は語順が違い、f は δι᾽ εὐχῆς を欠く）、γεννήσεως（d、e、g、h、n、p は γενέσεως）、γινομένοις（f は βουλομένοις、l と vulg は γενομένοις）、καθά（vulg は καθώς）と、ἐν τοῖς ἔμπροσθεν、καθὰ πεπιστεύκαμεν
- 底本：εἰ γὰρ ἐπὶ τοῦ ἑτέρου τῆς ἀνθρωποποιίας εἴδους αἱ τῶν γεννώντων ὁρμαί, κἂν μὴ ἐπικληθῇ παρ᾽ αὐτῶν δι᾽ εὐχῆς τὸ θεῖον, τῇ τοῦ θεοῦ δυνάμει, καθὼς ἐν τοῖς ἔμπροσθεν εἴρηται, διαπλάσσουσι τὸ γεννώμενον, … πόσῳ μᾶλλον ἐν τῷ πνευματικῷ τῆς γεννήσεως τρόπῳ, καὶ θεοῦ παρέσεσθαι τοῖς γινομένοις ἐπηγγελμένου καὶ τὴν παρ᾽ ἑαυτοῦ δύναμιν ἐντεθεικότος τῷ ἔργῳ, καθὰ πεπιστεύκαμεν, … μᾶλλον ἐπιτελὲς ἔσται τὸ σπουδαζόμενον;
- ほかの読み（n184 の異読の欄 1〜2 行目）：f は παρ᾽ αὐτοῖς（`4 παρ αυτοις f`）。e は τὸ θεῖον δι᾽ εὐχῆς の語順、f は δι᾽ εὐχῆς を欠く（`5 το θ. δι ευχης e om δι ευχης f`）。d、e、g、h、n、p は γενέσεως（`8 γενεσεως deghnp`）。f は βουλομένοις、l と vulg は γενομένοις（`9 γινομενοις] βουλομενοις f γενομενοις l vulg`）。vulg は καθώς（`10 καθως vulg`）。
- 注解：ἐν τοῖς ἔμπροσθεν は 33 章のこと（l. 15584）。ἄπρακτος は「その努力は実を結ばず、益がない」（l. 15586〜15587）。καθὰ πεπιστ. は、たとえばエペソ五・二五〜二六 のような箇所に基づく（l. 15589〜15591）。εἰ συμπ. は「同時に、祈りによる助けがしかるべく招かれるなら」（l. 15593〜15595）。
- 新約：エペソ五・二六 は ἵνα αὐτὴν ἁγιάσῃ, καθαρίσας τῷ λουτρῷ τοῦ ὕδατος ἐν ῥήματι（EPH.csv l. 125）。口語訳は「水で洗うことにより、言葉によって、教会をきよめて聖なるものとするため」。
- 採る校訂者：底本は παρ᾽ αὐτῶν、δι᾽ εὐχῆς あり、γεννήσεως（f l に従う）、γινομένοις、καθά。f の βουλομένοις（「望む者たちのうちにおられる」）は意味を変えるが、f だけの読み。
- 読者への影響：小。
- 訳での扱い：訳注なし。ἡ ἀνθρωποποιία は「人を造ること」、ἐπὶ τοῦ ἑτέρου … εἴδους は「もう一つの（体の）人の造り方では」。ἐν τοῖς ἔμπροσθεν は「先に（述べたとおり）」で、章を補わない。καθὰ πεπιστεύκαμεν の背後のエペソ五・二五〜二六 は、注解が「たとえば」と挙げる箇所で、出典は付けない。神の動作（ἐπηγγελμένου、ἐντεθεικότος）は尊敬語。προαίρεσις と ὁρμή は訳語表の「意志」「（〜へ向かう）衝動」の系で、αἱ τῶν γεννώντων ὁρμαί は親の「衝動」、τῆς ἡμετέρας προαιρέσεως … τὴν ὁρμὴν ἐχούσης は「わたしたちの意志が…へと向かっている」とする。

### 34.5 日の出のたとえ：γάρ（d は欠き、l と vulg は δέ）、ἐπιφαῦσαι（vulg は ἐπιφᾶναι）、αὐτοῖς（e は ἑαυτοῖς）、τὸ πάντως γινόμενον（f と g の訂正者は ἐσόμενον）
- 底本：καθάπερ γὰρ οἱ ἐπιφαῦσαι τὸν ἥλιον αὐτοῖς εὐχόμενοι τῷ θεῷ οὐδὲν ἀμβλύνουσι τὸ πάντως γινόμενον, οὐδὲ μὴν ἄχρηστον εἶναί τις φήσει τὴν τῶν προσευχομένων σπουδήν, εἰ περὶ τοῦ πάντως ἐσομένου τὸν θεὸν ἱκετεύουσιν。
- ほかの読み（n184 の異読の欄 2〜3 行目）：d は γάρ を欠き、l と vulg は δέ（`14 γαρ] om d δε l vulg`）。vulg は ἐπιφᾶναι（`επιφαναι vulg`）。e は ἑαυτοῖς（`15 εαυτοις e`）。f と g の訂正者は τὸ πάντως γινόμενον を ἐσόμενον（`16 γινομενον] εσομενον fg¹`。上付きの ¹ は `--scale 1.2` で確かめた）。

- 新約：エペソ五・一四 は καὶ ἐπιφαύσει σοι ὁ χριστός（EPH.csv l. 113）。口語訳は「キリストがあなたを照すであろう」。語が同じなだけで、ここは日の出のたとえで、聖句の暗示ではない。
- 採る校訂者：底本は γάρ、ἐπιφαῦσαι、αὐτοῖς、γινόμενον（f g¹ に従わない）。f g¹ の ἐσόμενον は、後の τοῦ πάντως ἐσομένου と同じ語にそろえた形。
- 読者への影響：小。
- 訳での扱い：訳注なし。ἐπιφαῦσαι は「（日が）照る」「昇る」で、エペソ五・一四 の出典は付けない。αὐτοῖς は注解のとおり「自分たちに」。οὐδὲν ἀμβλύνουσι τὸ πάντως γινόμενον は「どのみち起こることを少しも鈍らせない（妨げない）」。

### 34.5 οὕτως οἱ πεπεισμένοι（f、l の最初の手らしいもの、vulg は πεπιστευμένοι）と、言い足りない文、προσθήκην
- 底本：οὕτως οἱ πεπεισμένοι κατὰ τὴν ἀψευδῆ τοῦ ἐπαγγειλαμένου ὑπόσχεσιν πάντως παρεῖναι τὴν χάριν τοῖς διὰ τῆς μυστικῆς ταύτης οἰκονομίας ἀναγεννωμένοις ἢ προσθήκην τινὰ ποιοῦνται τῆς χάριτος, ἢ τὴν οὖσαν οὐκ ἀποστρέφουσιν。
- ほかの読み：f、l の最初の手（と読めるもの）、vulg は πεπιστευμένοι（n184 の異読の欄 4 行目の `18 πεπεισμ.] πεπιστευμενοι fl*vid vulg`。`*vid` は `--scale 1.5` で確かめた）。
- 注解：οὕτως οἱ πεπεισμένοι について、グレゴリオスはこの文で考えを言い尽くしていないので、Glauber（Krabinger が引く）に従い「そして神に願う」のような語を補わなければならない、と言う（l. 15618〜15623）。προσθήκην は「彼らの祈りによって」のこと（l. 15675〜15676）。英訳の脚注 [2023] も ποιοῦνται（中動相）を祈りによるものとする（l. 44979）。
- 採る校訂者：底本は πεπεισμένοι で、f l* の読みに従わない（l の訂正者とほかの写本）。πεπιστευμένοι は受け身の形で「信頼を託された」の意味になり、文に合わない。
- 読者への影響：中（訳し方）。補いがないと、「確信している人々が、恵みに何かを加える」と、祈る行為なしに恵みを増やすように読める。たとえの側（日の出を祈る人々）と対になるのは、確信しながらも祈る人々。
- 訳での扱い：訳注なし。注解に従って「（そのうえで神に願う）」を補い、補った語は `// ` メモに書く。ἢ … ἢ は「何か恵みを加えるか、少なくとも、ある恵みを退けはしない」の向き（ἀποστρέφω は「退ける」「背を向けさせる」）。

### 34.6 συνεῖναι（f は欠き、d、g*、h、n、p は εἶναι、g¹ と l¹ は παρεῖναι）、τό（f、h は τόν）と、διὰ πάντων の取り方
- 底本：τὸ γὰρ πάντως συνεῖναι διὰ τὸ θεὸν εἶναι τὸν ἐπαγγειλάμενον πεπίστευται· ἡ δὲ τῆς θεότητος μαρτυρία διὰ τῶν θαυμάτων ἐστίν. ὥστε διὰ πάντων τὸ παρεῖναι τὸ θεῖον οὐδεμίαν ἀμφιβολίαν ἔχει。
- ほかの読み（n185 の異読の欄 1 行目）：f は συνεῖναι を欠き、d、g の最初の手、h、n、p は εἶναι、g と l の訂正者は παρεῖναι（`4 συνειναι] om f ειναι dg*hnp παρειναι g¹l¹`）。f、h は 5 行目の τό を τόν（`5 το] τον fh`。διὰ τὸ θεὸν εἶναι の τό）。
- 注解：συνεῖναι は上の ἑκάστῳ συνεῖναι（34.3）と比べよ（l. 15678〜15679）。ἡ δὲ τῆς θ. μαρτυρία は、上の論と 11〜12 章を見よ（l. 15681〜15682）。διὰ πάντων に注はない。
- 採る校訂者：底本は συνεῖναι で、どの写本の群の読みとも違う（f は欠き、1 群は εἶναι、訂正者は παρεῖναι）。異読の欄から見ると、l の最初の手と e の読みが συνεῖναι になる（論点一覧の判断）。
- 読者への影響：小（読み）。中（取り方）：διὰ πάντων は「以上すべて（の論）によって」とも、「（儀式の）すべてにわたって」とも取れる。英訳は後者で訳し、脚注 [2025] で τῶν γινομένων を補うと言う（l. 44973〜44974、44984）。ὥστε で論をまとめる文なので、前者の取り方もできる。
- 訳での扱い：訳注なし。συνεῖναι は 34.3 と同じ語で受ける（「共におられる」の向き）。διὰ πάντων をどちらに取るかはメインで決める。英訳の取り方に従うなら、補った「行われること」を `// ` メモに書く。
