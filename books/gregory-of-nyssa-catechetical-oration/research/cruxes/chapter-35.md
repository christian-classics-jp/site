### 35.1〜35.21 導く者の語（ἡγούμενος、καθηγούμενος、ἀρχηγός、ἐξηγούμενος、προάγων、προκαθηγέομαι）
- 底本：35.1 の παρὰ τοῦ ἑπομένου πρὸς τὸν ἡγούμενον、35.2 の ὁ τῆς ζωῆς ἡμῶν καθηγησάμενος と κατὰ τὸν ἀρχηγὸν τῆς σωτηρίας ἡμῶν、35.3 の τῷ πρὸς τὴν σωτηρίαν ἡμῶν ἐξηγουμένῳ、35.4 の τῷ προάγοντι、35.5 の περὶ τὸν ἀρχηγὸν τῆς σωτηρίας ἡμῶν、35.8 の τοῦ καθηγουμένου τῆς ζωῆς ἡμῶν、35.11 の τοῦ καθηγουμένου τῆς σωτηρίας ἡμῶν と τῶν ἀκολουθούντων τῷ καθηγουμένῳ、35.18 の εἰ μὴ τοῦτο προκαθηγήσαιτο、35.21 の ἡ διὰ τοῦ λουτροῦ προκαθηγήσατο κάθαρσις。
- 注解：35.1 の πρὸς τὸν ἡγ. は ὁμοιότης にかかる（l. 15906）。35.2 の ὁ τῆς ζωῆς … καθηγ. は「いのちの創始者」の意（l. 15916〜15917）。35.3 の τῷ … ἐξηγουμένῳ はイエス・キリストのことで、ἕπεσθαι が支配する。「わたしたちを救いへと導くかたに、熱心な倣いによって従う」の意に取る（l. 15913〜15922）。
- 論の形：「従う者（ὁ ἑπόμενος、οἱ ἑπόμενοι、οἱ ἀκολουθοῦντες）」と「先に立って導く者」の対で、迷宮のたとえ（35.4 の κατόπιν ἑπόμενοι、κατ᾽ ἴχνος ἑπόμενοι τῷ προάγοντι）につながる。35.18 と 35.21 の προκαθηγέομαι は、洗礼が復活に「先立つ」ことを言い、同じ語根を使う。
- 33.2 の ζωῆς ἀρχηγός は、注解に従い「いのちの源」と訳した（chapter-33-34 の 33.2 の項）。35.2 と 35.5 の ἀρχηγός はヘブル二・一〇 の引用で（次の項）、口語訳は「救の君」。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（語のつながり）。「従う者」と「導く者」の対が見えないと、倣いの論の形が崩れる。
- 訳での扱い：訳注なし。ἡγούμενος・καθηγούμενος を「導くかた」の系で揃え、ἑπόμενος・ἀκολουθέω の「従う」と対にするか、ἀρχηγός を口語訳の「救の君」に寄せるか、33.2 の「源」と揃えるかをメインで決める。

### 35.1 συναποθεωθείσης（神とされること）
- 底本：διὰ τῆς ἀναληφθείσης παρ᾽ αὐτοῦ καὶ συναποθεωθείσης σαρκὸς ἅπαν συνδιασωθῇ τὸ συγγενὲς αὐτῇ καὶ ὁμόφυλον。異読の欄に、この語の異読はない。
- 注解（l. 15804〜15849）：37 章の συναποθεωθῇ τὸ ἀνθρώπινον と比べよ。考えについては 25 章の κατεμίχθη πρὸς τὸ ἡμέτερον, ἵνα τὸ ἡμέτερον τῇ πρὸς τὸ θεῖον ἐπιμιξίᾳ γένηται θεῖον を見よ。受肉による人の本性の θέωσις の考えはエイレナイオスにすでにあり、クレメンス、オリゲネス、アタナシオスとその後の教父に多い。聖書の出発点は詩篇八一（八二）・六 と第二ペテロ一・四。アタナシオスは御子であることとキリスト者の子とされることを注意深く分ける、と言う。オリゲネス『ケルソス駁論』3.41 の一節を引く。
- 採る校訂者：本文の読みの違いではない。
- 読者への影響：中（語）。25.3 の訳は「神的なものとなる」。συν-、ἀπο- の付いた受け身で、「（ことばが取った肉が）ことばと共に神とされた」の意。「神になる」と訳すと、人が神と同じものになるように読まれうる。
- 訳での扱い：訳注なし。訳語表にない語。25.3 の「神的なものとなる」と揃えるか、「神とされた」とするかをメインで決める。37 章の συναποθεωθῇ と同じ語にしておく。

### 35.10、35.11、35.19 οἰκονομία の三つの使い方
- 底本：35.10 の κατ᾽ οἰκονομίαν ἐπῆκται τῇ ἀνθρωπίνῃ φύσει … ὁ θάνατος、35.11 の ἡ κατὰ τὸν θάνατον … οἰκονομία、35.19 の κατὰ τὴν τοῦ τάξαντος οἰκονομίαν。

### 35.10、35.16、35.21〜35.22 ἀπαθής・ἀπάθεια・πάθος
- 底本：35.10 の σῶον καὶ ἀπαθῆ καὶ ἀκέραιον、35.16 の μὴ τραπῆναι πρὸς πάθος、35.21 の τῷ δὲ καθαρῷ τὸ ἀπαθὲς προσῳκείωται, ἐν δὲ τῇ ἀπαθείᾳ τὸ μακάριον、35.22 の οἷς δὲ προσεπωρώθη τὰ πάθη。
- 注解：35.10 の ἀπαθῆ は「情念から自由な」、ἀκέραιον は「純粋な」（ローマ一六・一九 を挙げる。l. 16117〜16118）。35.16 の τραπῆναι πρὸς πάθος は「弱さを伴う変化を受ける」の意で、16 章の論を見よ（l. 16395〜16397）。35.21 の πρὸς τὸ συγγενές は、続く τὸ ἀπαθές で説明される。6 章で人は初め ἀπαθὴς τὴν φύσιν と言われ、堕落によって ἐμπαθής になった（l. 16583〜16599）。35.22 の προσεπωρώθη は、情念が心の上に覆い、殻を作ったという考え（l. 16601〜16608）。
- 訳語表：ἀπάθεια は 5.17 の「情念に動かされないこと」、ἐμπαθής は「情念に支配される」。16 章は、πάθος の本来の意味（悪）を「情念」、本性の過程と体の側を「苦しみ」と訳し分けた。
- 読者への影響：中（語）。35.16 は神の力が死のうちにあっても弱さへと変わらないことで、16 章の「苦しみ」の側。35.10、35.21〜35.22 は悪から清められた状態と、こびりついた情念で、「情念」の側。
- 訳での扱い：訳注なし。35.10 と 35.21 の ἀπαθής・ἀπάθεια は 5.17 の「情念に動かされない（こと）」、35.22 の τὰ πάθη は「情念」、35.16 の πάθος は 16 章の体の側に合わせて「苦しみ」とするのが、注解と訳語表に合う（論点一覧の判断）。
- 確かめた資料：画像 `n189_w1600.jpg`（注解）、`n192_w1600.jpg`（注解の右の欄 ib.）、`n194_w1600.jpg`（注解の 9.、12.）。l. 16117〜16118、16395〜16397、16583〜16608。

### 35.6〜35.17 倣いの語（μίμησις、ὁμοίωμα、εἰκών、διατυπόω、ὑποκρίνομαι、ἀπομιμέομαι、προμελετάω）

### 35.9、35.14 ἐπιχεάμενος・ὑποδύς・καταδυείς（注ぐことと沈むこと）
- 底本：35.9 の ἀντὶ γῆς τὸ ὕδωρ ἐπιχεάμενος καὶ ὑποδὺς τὸ στοιχεῖον ἐν τρισὶ περιόδοις、35.14 の τὸ ὕδωρ τρὶς ἐπιχεάμενοι καὶ πάλιν ἀναβάντες ἀπὸ τοῦ ὕδατος、ὡς ἡμεῖς ἐν τῷ ὕδατι, οὕτως ἐκεῖνος ἐν τῷ θανάτῳ καταδυείς。
- ほかの読み：35.9 の ἐπιχεάμενος は、d、p が ἐπιχεόμενος（現在。n189 の異読の欄 4 行目）。
- 注解：ἐπιχεάμενος は中動態で「自分の上に水を注がれて」の意。下の τὸ ὕδωρ τρὶς ἐπιχεάμενοι も同じ。この語は浸すことより注ぐことを思わせるが、続く ὑποδύς は浸すことを含む（l. 16081〜16087）。περιόδοις は、受洗者が三度別々に水に浸され、上がること（l. 16089〜16094）。
- 英訳：ἐπιχεόμενος の形を挙げ、浸すことがどうしても要るわけではなかったと読めると脚注 [2031] で言う（l. 45189〜45190）。

- 読者への影響：中（語）。注ぐことと沈むことが同じ文に並ぶ。35.1 の κάθοδος（水へ下ること）、35.14 の ἀναβάντες、ἀναδῦναι と合わせて、水に入って出ることの像。
- 訳での扱い：訳注なし。「水を注がれ」「その元素の下にくぐり」と、二つの語をどちらも残す（片方にまとめない）。περίοδος は訳語表で「回り道」（15.5、26.9）だが、ここは三度の動きなので、訳し分けをメインで決める（`// ` メモに書く）。

- 注解：τί γάρ は 33 章と比べよ。「人と〜とのあいだに、どんな等しさがあるか」の意（l. 16455〜16457）。ἐκεῖνο は τὸ … καταβαλλόμενον を、τοῦτο は ἄνθρωπος を指す（l. 16459〜16460）。τὴν μεγάλην ἀν. の μεγάλην と μεῖζον は、復活を、洗礼のうちのその象徴の始まりと対にする（l. 16462〜16465）。ἐντεῦθεν は「洗礼から」（l. 16467）。
- 既存の訳：33.3〜33.4 の τὸ εἰς ἀφορμὴν τῆς συστάσεως τοῦ ζῴου καταβαλλόμενον（名を出さない「種」）の訳（chapter-33-34 の項）。
- 読者への影響：中（指示）。前の文では ἐκεῖνο が種、τοῦτο が人。次の文では ἐκεῖνο が大いなる復活、τοῦτο が洗礼で、指すものが入れ替わる。
- 訳での扱い：訳注なし。ἐκεῖνο・τοῦτο を「あれ」「これ」で残さず、指すものを名指しで書くか、メインで決める（補った語は `// ` メモに書く）。33 章の種の言い方に揃える。

### 35.19 βλέπων（vulg は ἀναβλέποντες）、δεῖ πάντως（d、g と l の最初の手らしいものは δὴ πάντως δεῖ、h、n、p は δεῖ πάντως δεῖ）と、挿入句、συγκρίματος、ἀναστοιχείωσιν
- 底本：μὴ δύνασθαι δέ φημι δίχα τῆς κατὰ τὸ λουτρὸν ἀναγεννήσεως ἐν ἀναστάσει γενέσθαι τὸν ἄνθρωπον, οὐ πρὸς τὴν τοῦ συγκρίματος ἡμῶν ἀνάπλασίν τε καὶ ἀναστοιχείωσιν βλέπων· πρὸς τοῦτο γὰρ δεῖ πάντως πορευθῆναι τὴν φύσιν οἰκείαις ἀνάγκαις κατὰ τὴν τοῦ τάξαντος οἰκονομίαν συνωθουμένην, κἂν προσλάβῃ τὴν ἐκ τοῦ λουτροῦ χάριν, κἂν ἄμοιρος μείνῃ τῆς τοιαύτης μυήσεως· ἀλλὰ τὴν ἐπὶ τὸ μακάριόν τε καὶ θεῖον … ἀποκατάστασιν。
- ほかの読み（n193 の異読の欄）：vulg は βλέπων の代わりに ἀναβλέποντες（11 行目）。d、g と l の最初の手らしいもの（`l*vid`）は δὴ πάντως δεῖ、h、n、p は δεῖ πάντως δεῖ（12 行目）。
- 注解：κατὰ τὸ λουτρόν は 32 章の終わりの ἡ κατὰ τὸ λουτρὸν οἰκονομία と比べよ（l. 16469〜16470）。οὐ … βλέπων と ἀποκατάστασιν は全体の項（l. 16472〜16481）。συγκρίματος は 16 章の τοῦ ἀνθρωπίνου συγκρίματος と比べよ（l. 16483〜16484）。ἀναστοιχείωσις は、グレゴリオスがふつう受肉による人の更新に使う語だが（8 章の注）、ここでは、死で解かれた人の本性の要素が組み直される、より一般の意味（l. 16486〜16497）。πρὸς τοῦτο から μυήσεως までは挿入句で、すべての人の復活が何かを説く（l. 16499〜16502）。οἰκ. ἀνάγκαις は「わたしたちの本性は、それを定めたかたの計画に従い、自分の定まった法則に押されて、どのみちそこに達する」の意で、人類の復活は本性の法則のはたらきで、恵みのわざである祝福のいのちへの復活とは別、と言う。グレゴリオスは、5 章と 8 章で述べた、人は本性として死なないという考えを前提にしているとし、8 章の ἡ νεκρότης οἰκονομικῶς περιετέθη … を引く（l. 16504〜16520）。
- 既存の訳：33〜34 章の λουτρόν は「洗い」、ἀναγέννησις は「新たに生まれること」（訳語表）。16 章の συγκρίματος の訳。
- 採る校訂者：底本は βλέπων、δεῖ πάντως（e、f と l の訂正者の側。異読の欄に名がないので、そう読める）。
- 読者への影響：中（組み立て）。挿入句を見落とすと、洗礼を受けない人は復活しないと読まれる。注解の言うとおり、挿入句は「すべての人が復活する」ことを言い、本文の主張は祝福された状態への回復についてだけ。
- 訳での扱い：訳注なし。挿入句を独立した文に分け、「ただし、〜を言うのではありません」「わたしが言うのは〜です」の形で、οὐ … ἀλλά の対を残す。ἀναστοιχείωσις は 35.10 の ἀναστοιχειωθῆναι と同じ語根だが、ここは一般の意味（注解）。訳語の扱いをメインで決める。
- 確かめた資料：画像 `n193_w1600.jpg`（本文、異読の欄、`pct:40,38.5,50,4 --scale 1.2`、注解）。l. 16436〜16440、16443〜16446、16469〜16520。

### 35.23 καθαρίζονται（f は παραδίδονται）
- 底本：οἱ δὲ ταύτης ἀμύητοι τῆς καθάρσεως ἀναγκαίως τῷ πυρὶ καθαρίζονται。

- 35.19 の挿入句を注解は μυήσεως までとするが、挿入の始まりを πρὸς τοῦτο γάρ とするか、その前の οὐ … βλέπων からとするかは、注解の言い方（This clause, as far as μυήσεως）だけに拠る。
