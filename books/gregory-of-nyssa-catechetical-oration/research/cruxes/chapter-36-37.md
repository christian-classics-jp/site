### 36.1 ὁ κοινὸς λόγος、τοῦ θείου χοροῦ、36.2 ἀρχή τε καὶ ὑπόθεσις
- 底本：ὅ τε κοινὸς δείκνυσι λόγος καὶ ἡ τῶν γραφῶν διδασκαλία ἐντὸς τοῦ θείου γενέσθαι χοροῦ、36.2 の μεγάλων ἀγαθῶν ἀρχή τε καὶ ὑπόθεσις γίνεται。
- 注解：κοινὸς λόγος は人の「共通の理性」「常識」で、5 章の τῶν κοινῶν ἐννοιῶν と比べよ（n195 の 9.、l. 16720〜16722）。θείου χοροῦ は「幸いな者たちの群れ」（10-11.、l. 16724〜16725）。ἀρχή τε καὶ ὑπόθεσις は 6 章の ἡ ἀπάθεια τῆς κατ᾽ ἀρετὴν ζωῆς ἀρχὴ καὶ ὑπόθεσις γίνεται と比べよ（13.、l. 16727〜16731）。
- 読者への影響：小。κοινὸς λόγος を御子の「ことば」や「論」と読ませない。
- 訳での扱い：訳注なし。ἀρχή τε καὶ ὑπόθεσις は 6.13 の「初めであり、土台となります」と字を揃える。
- 確かめた資料：画像 `n195_w1600.jpg`（全体）。l. 16720〜16731。

### 36.2 τοῖς ἐπικαλουμένοις τὴν ζωτικὴν αὐτοῦ δύναμιν の係り
- 底本：πιστεῦσαι πανταχοῦ τὸν θεὸν εἶναι, ἐν πᾶσι δὲ ὄντα, παρεῖναι καὶ τοῖς ἐπικαλουμένοις τὴν ζωτικὴν αὐτοῦ δύναμιν, παρόντα δὲ τὸ οἰκεῖον ποιεῖν。
- 取り方：τὴν ζωτικὴν αὐτοῦ δύναμιν は、ἐπικαλουμένοις の目的語（「そのいのちを与える力を呼び求める人々」）とも取れる。注解はこの句の係りに触れない。36 章の要約は「呼び求められるときの神の特別な臨在」と言う（l. 16709〜16710）。注解は、ここで 33〜34 章の論をまとめていると言う（n196 の ib. τίς γάρ、l. 16786〜16791）。英訳は目的語の側で訳す（「呼び求める人々」と「その力のために」）。
- 訳語表：33〜34 章の ἐπικαλέω は「呼び求める」。
- 読者への影響：小。
- 訳での扱い：訳注なし。目的語に取って「呼び求める人々」とすれば、33〜34 章の「呼び求め」と揃う。
- 確かめた資料：画像 `n195_w1600.jpg`（全体）、`n196_w1600.jpg`（`pct:3,25,94,30`）。l. 16709〜16710、16786〜16791。英訳 l. 45208〜45210。

### 36.2 τὸ οἰκεῖον、36.4 τὴν οἰκειότητα
- 底本：36.2 の παρόντα δὲ τὸ οἰκεῖον ποιεῖν、36.4 の ὡς πρὸς αὐτὸ τὸ θεῖον ἔχειν τὴν οἰκειότητα。
- 注解：τὸ οἰκεῖον は「そのかたの性格にふさわしいこと」で、続く ἡ τῶν δεομένων σωτηρία で説き明かされる。27 章の ἓν πρέπον ἐστὶ τῷ θεῷ τὸ εὐεργετεῖν τὸν δεόμενον と同じ論（n196 の 4.、l. 16793〜16798）。27.11 の訳は「神にふさわしいことは一つ、必要とする者に恵みを施すことです」。36.3 の αὕτη は σωτηρία を受け、その σωτηρία は下で πρὸς αὐτὸ τὸ θεῖον ἔχειν τὴν οἰκειότητα と定められる（l. 16800〜16811）。36 章の要約は、洗礼から生じる恵みを「神との縁」と言う（l. 16716〜16718）。
- 訳語表：συγγενής・συγγένεια は「縁つづき」「縁」（35 章）。
- 読者への影響：小〜中。同じ語根の二語（「ご自分にふさわしいこと」と「神との近さ」）が救いの定めでつながる。
- 訳での扱い：訳注なし。οἰκειότης を 35 章の συγγένεια「縁」と同じ字にするか分けるか、τὸ οἰκεῖον との語のつながりを残すかをメインで決める。

### 36.3 τὸ δὲ σύντροφον τῇ ἀνθρωπίνῃ ζωῇ
- 底本：πίστις καὶ ὕδωρ, ἡ μὲν ἐντὸς τῆς προαιρέσεως ἡμῶν ἀποκειμένη, τὸ δὲ σύντροφον τῇ ἀνθρωπίνῃ ζωῇ。
- 注解：「他方（水）は人のいのちと親しく結びついている」の意。σύντροφος は 23 章の πρὸς τὸ σύντροφόν τε καὶ συγγενὲς αὐτῷ βλέπων と比べよ。考えについては『キリストの洗礼について』の、人は合成されたものなので、見える体には感覚で知られる水が、見えない魂には信仰によって呼ばれる見えない霊が、縁つづきの薬として割り当てられた、という一節を引く（n196 の 10.、l. 16817〜16830）。
- 先行の訳：23.5 の πρὸς τὸ σύντροφόν τε καὶ συγγενὲς αὐτῷ は「自分になじみ深く、同じ類のもの」。訳語表は προαίρεσις を「意志」とする。
- 読者への影響：小。
- 訳での扱い：訳注なし。σύντροφον は 23.5 の「なじみ深い」と字を揃えられる。

### 37 章の「変える」の語（μεταποιέω、μετατίθημι、μεθίστημι、μεταστοιχειόω、ἀλλοιωτικὴ δύναμις）
- 底本：37.3 の ὅλον πρὸς ἑαυτὸ μεταποιεῖ καὶ μετατίθησιν、37.4 の τὸ πᾶν μετεποίησεν、37.11 の πρὸς τὸ τοῦ σώματος εἶδος τῆς τροφῆς μεθισταμένης、37.13 の πρὸς τὴν τοῦ σώματος φύσιν μεθισταμένης と πρὸς τὴν θεικὴν ἀξίαν μετεποιήθη、37.14 の εἰς σῶμα τοῦ θεοῦ λόγου μεταποιεῖσθαι、37.15 の ὁ … μεταποιηθεὶς ἄρτος εἰς θείαν μετέστη δύναμιν と εὐθὺς πρὸς τὸ σῶμα διὰ τοῦ λόγου μεταποιούμενος、37.16 の τὴν εἰς τὸ θερμὸν μεταποίησιν、37.18 の πρὸς ἐκεῖνο μεταστοιχειώσας τῶν φαινομένων τὴν φύσιν。37.11 と 37.16 の διὰ τῆς ἀλλοιωτικῆς δυνάμεως。
- 注解（n199 の 5.、l. 17092〜17131）：μεταποιεῖν はこの章で 6 つの意味に使われる。(1) キリストの死なない体との結び合いによるわたしたちの体の変化（37.3〜37.4）、(2) ことばの内住による主の人の体の神の尊さへの変化（37.13）、(3) 主がパンを人の体に取り込むこと（37.15）、(4) 聖餐の要素の変化（37.14、37.15）、(5) わたしたちの体の中でぶどう酒が熱に変わること（37.16）、(6) 洗礼による再生の人の変化（40 章）。この用法の多さから、語そのものに変化の種類の特定の考えを読み込んではならず、文脈で決めるべきだと言う。37.3 の μετατίθησιν は μεταποιεῖν とほぼ同じ意味。μεθιστάναι も多義で、食べ物が体に変わること（37.11、37.13）と、パンが主の体の中で神の力に移ること（37.15）に使う（n203 の 1.、l. 17572〜17584）。μεταστοιχειόω は、ある要素を別の要素に取り替えるより、同じ要素を組み替えて新しい形を与えることに使われることが多いと言い、8 章の ἀναστοιχειώσει、35 章の ἀναστοιχείωσιν と比べる（n208、l. 18104〜18150）。ἀλλοιωτικὴ δύναμις は体の「同化、消化の力」で、ἀλλοίωσις はアリストテレスで性質の変化を言う（n202 の 14.、l. 17456〜17468）。
- 注解の解釈（n206 の 2-3.、l. 17851〜17921）：この章の言葉は、後の西方の化体説に考えでは似た、要素の変化の教えと広く受け取られてきた。注解は、語だけからは何も論じられず、要はパンとぶどう酒が（食べることを経ず）直ちに主の体と血になるという点にあると言う。用途の変化以上のことを言うが、たとえが示すのは「形」の変化で「実体」の変化ではない、とする（37.11 の εἶδος の注 l. 17470〜17570 も同じ）。
- 採る校訂者：本文の読みの違いではない（37.14 と 37.15 の読みの違いは下の項）。
- 読者への影響：中。どの語にどの日本語を当てるかで、後代の教理（化体説など）を読み込ませることになる。
- 訳での扱い：訳注なし。33.6 の μεταποιεῖ「造り変える」に揃えるか、μετατίθημι・μεθίστημι・μεταστοιχειόω をどう訳し分けるかをメインで決める。「化体」「実体変化」のような後代の教理の語は使わないのが注解の立場に合う。μεταστοιχειόω は字のとおり「要素を組み替える」の向きが注解の説明に合う。
- 確かめた資料：画像 `n199_w1600.jpg`、`n203_w1600.jpg`、`n206_w1600.jpg`、`n208_w1600.jpg`（`pct:3,25,94,30`）。l. 17092〜17131、17456〜17584、17851〜17921、18104〜18150。

### 37.11、37.14 δυνάμει（可能態として）
- 底本：37.11 の ὁ πρὸς ταῦτα βλέπων δυνάμει πρὸς τὸν ὄγκον τοῦ ἡμετέρου σώματος βλέπει、37.14 の ἐκεῖνο τὸ σῶμα ἄρτος τῇ δυνάμει ἦν。
- 注解：37.11 の δυνάμει は「潜在的に」で、ἐνεργείᾳ と対になるアリストテレスの意味（n202 の 12.、l. 17441〜17450）。37.14 では、パンが体に変えられたので、キリストの体が「潜在的に」パンだったと言う（37.11 ではパンが体に変えられうるので「潜在的に」体だった）（n205 の 4.、l. 17789〜17797）。
- 訳語表：δύναμις は「力」で通す（2〜4 章）。同じ章の 37.2 の ἡ τοῦ βοηθοῦντος δύναμις、37.5 の τὴν ζωοποιὸν δύναμιν、37.8 の διὰ τῆς ἐπιρρεούσης αὐτῇ δυνάμεως、37.18 の τῇ τῆς εὐλογίας δυνάμει は「力」。
- 読者への影響：中。副詞の δυνάμει を「力によって」と訳すと、論（パンは可能態としての体）が読み取れない。
- 訳での扱い：訳注なし。副詞の δυνάμει と τῇ δυνάμει を「力」と分けて「潜在的に」「可能性として」などとするかをメインで決める。英訳は 37.11 を「含意として」の向きで訳し、37.14 も同じ語で訳す。
- 確かめた資料：画像 `n202_w1600.jpg`、`n205_w1600.jpg`（`pct:3,25,94,30`、n202 は `pct:3,55,94,18` も）。l. 17441〜17450、17789〜17797。英訳 l. 45290、45318〜45319、脚注 [2039]（l. 45361）。

### 37.17 τοῦτο τὸ μέρος（l と vulg は τό を欠く）、ἐκείνη（vulg は ἐκείνου）、συναποθεωθῇ（l* と vulg は συναποθεωρηθῇ）、ἧς（vulg は οἷς）、ὁ ἄνθρωπος（vulg は ὁ を欠く）、γένοιτο（f、euth 7 は γένηται）
- 底本：ἐπεὶ οὖν καὶ τοῦτο τὸ μέρος ἡ θεοδόχος ἐκείνη σὰρξ … ἵνα τῇ τῆς θεότητος κοινωνίᾳ συναποθεωθῇ τὸ ἀνθρώπινον … διὰ τῆς σαρκός, ἧς ἡ σύστασις ἐξ οἴνου τε καὶ ἄρτου ἐστί … ὡς ἂν τῇ πρὸς τὸ ἀθάνατον ἑνώσει καὶ ὁ ἄνθρωπος τῆς ἀφθαρσίας μέτοχος γένοιτο。θεός（l* と vulg は λόγος）と ἐπικήρῳ（l と vulg は τῶν ἀνθρώπων を加える）は上の「37.17 ὁ δὲ φανερωθεὶς θεός」の項。
- ほかの読み：l と vulg は τό を欠き、vulg は ἐκείνου（n207 の 10 行目）。l の最初の手（らしい）と vulg は συναποθεωρηθῇ（n208 の 1 行目）。vulg は ἧς の代わりに οἷς（3 行目）。vulg は ὁ を欠く（5 行目）。f と euth 7 は γένηται（接続法。6 行目）。
- 注解：διὰ τῆς σαρκός は「ぶどう酒とパンからなるあの肉によって」の意。パリ版は οἷς と読み、新しい無関係な考えを持ち込む（n208 の ib.、l. 18078〜18082）。ὁ ἄνθρ. は「人」で、上の τὸ ἀνθρώπινον に応じる（5.、l. 18084〜18085）。
- 採る校訂者：底本は刷られた本文の形。συναποθεωρηθῇ は συναποθεωθῇ の崩れに見える（論点一覧の判断）。
- 読者への影響：小。
- 訳での扱い：訳注なし。ὁ ἄνθρωπος と τὸ ἀνθρώπινον の対応が見えるように訳す。
