### 40.1 μέχρι τῶν εἰρημένων、κατήχησις、δι᾽ ἀπάτης ἑαυτοὺς παράγοντες、τῷ δοκεῖν μόνον
- 底本：Ἀλλ᾽ οὔ μοι δοκεῖ μέχρι τῶν εἰρημένων αὐτάρκη τὴν διδασκαλίαν ἡ κατήχησις ἔχειν … ὃ πολλοὶ τῶν προσιόντων τῇ τοῦ βαπτίσματος χάριτι παρορῶσι, δι᾽ ἀπάτης ἑαυτοὺς παράγοντες, καὶ τῷ δοκεῖν μόνον, οὐχὶ τῷ ὄντι γεννώμενοι。
- 注解：μέχρι τ. εἰρ. は「ここまで述べたかぎりでは」（または「これらの言葉では」）、教えの点でわたしたちの教えは十分でないように思われる、の意味。μέχρι のこの含む意味には、ナジアンゾスのグレゴリオス『講話』28.9 の οὐδὲ ἐκεῖ στήσεται μέχρι τοῦ εἰπεῖν（メイソンの注）を比べよ。κατήχησις は序の ὁ τῆς κατηχήσεως λόγος（注）を見よ（n215 の 6.、l. 18925〜18936）。δι᾽ ἀπάτης は 7 章の δι᾽ ἀπάτης παρασυρέντες を比べよ（9.、l. 18938〜18939）。
- 訳語表：κατήχησις は「教理の教え」（0.1、0.2）。ἀπάτη は「欺き」（7.5。21〜26 章も同じ）。
- 読者への影響：小。τῷ δοκεῖν μόνον, οὐχὶ τῷ ὄντι は「見かけだけで、本当には」の対。
- 訳での扱い：訳注なし。κατήχησις は序と同じ「教理の教え」。δι᾽ ἀπάτης は「欺きによって」で 7 章の訳とつなぐ。

### 40.2〜40.5 γνωρίσματα、μεταποίησις・μεταβολή・μετάστασις、ἀναστοιχείωσις、ἐντελής（変化の語）
- 底本：40.2 の ἡ … τῆς ζωῆς ἡμῶν μεταποίησις οὐκ ἂν εἴη μεταποίησις … ἐφ᾽ οὗ μηδὲν τῶν γνωρισμάτων μετεποιήθη、40.3 の ἐπὶ ἀνακαινισμῷ καὶ μεταβολῇ τῆς φύσεως ἡμῶν、40.4 の εἰ οὖν ἡ ἄνωθεν γέννησις ἀναστοιχείωσίς τις τοῦ ἀνθρώπου γίνεται … σκεπτέον τίνος μεταποιηθέντος ἐντελὴς τῆς ἀναγεννήσεως ἡ χάρις ἐστί、40.5 の τῶν πονηρῶν γνωρισμάτων ἐξαλειφθέντων … ἡ πρὸς τὸ κρεῖττον μετάστασις γίνεται。
- 注解：μεταποίησις は 37 章の μεταποιεῖ の注を見よ（n215 の 12.、l. 18941〜18942）。γνωρισμάτων は「特徴となる面」、すなわち人をそれと見分ける性格の特徴。グレゴリオスはもちろん悪い性格の特徴を念頭に置いている。下の τῶν πονηρῶν γνωρισμάτων を比べよ（14.、l. 18944〜18949）。ἐπὶ ἀνακ. の ἐπί の使い方は 5 章の ἐπὶ τῇ … ἀπολαύσει を比べよ（15.、l. 18951〜18952）。ἡ ἄν. γένν. は 39 章の終わり（注）を比べよ。ἀναστοιχείωσις は 8 章の ἀναστοιχειώσει（注）を比べよ（n216 の 6.、ib.、l. 19020〜19024）。ἐντελής は 24 章 p. 93（注）を比べよ（8.、l. 19026〜19027）。μετάστασις は 37 章の μεθισταμένης の注を見よ（11.、l. 19029〜19030）。39 章の注解は、39.6 の τῆς ἐπὶ τὸ κρεῖττον μεταστάσεως に 40.3 の ἐπὶ ἀνακαινισμῷ καὶ μεταβολῇ … γέννησιν を比べさせる（chapter-38-39、l. 18813〜18816）。
- 訳語表：μεταποιέω・μεταποίησις は「造り変える・造り変えること」（37 章。「化体」のような語は使わない）、μεταβολή は「変化」、μεθίστημι は「移り変わる、移る」、μεταστοιχειόω は「組み替える」。γνώρισμα は「特徴」（0.8、1.14）。
- 既存の訳：8.11 の ἀναστοιχειώσει と 35.10 の同じ語は「組み立て直す」。24.6 の ἐντελῆ は「余すところのない」。39.6 の τῆς ἐπὶ τὸ κρεῖττον μεταστάσεως は「よりよいものへと移ること」。39.8 の ἄνωθεν γέννησις は「上からの誕生」の向き（chapter-38-39 の 39.8 の項）。
- 読者への影響：中。40.2〜40.5 は「造り変えられないなら造り変えではない」という語の重ねで論が進む。μεταποίησις・μεταβολή・μετάστασις を混ぜると論の筋が見えにくくなる。
- 訳での扱い：訳注なし。μεταποίησις・μεταποιέω は「造り変えること・造り変える」、μεταβολή は「変化」、μετάστασις は 39.6 に合わせて「（よりよいものへと）移ること」、ἀναστοιχείωσις は 8.11 に合わせて「組み立て直すこと」、ἐντελής は 24.6 に合わせて「余すところのない（完全な）」。γνωρίσματα は「特徴」で、40.5、40.14 の悪い特徴とつなぐ。40.4 の ἡ ἄνωθεν γέννησις は 39.8 に合わせて「上からの誕生」。

### 40.3 ἡ ἀνθρωπότης αὐτὴ καθ᾽ ἑαυτήν、τὸ λογικὸν … τὸ ἐπιστήμης δεκτικόν
- 底本：ἀλλὰ μὴν ἡ ἀνθρωπότης αὐτὴ καθ᾽ ἑαυτὴν μεταβολὴν ἐκ τοῦ βαπτίσματος οὐ προσίεται, οὔτε τὸ λογικὸν οὔτε τὸ διανοητικὸν οὔτε τὸ ἐπιστήμης δεκτικὸν οὐδὲ ἄλλο τι τῶν χαρακτηριζόντων ἰδίως τὴν ἀνθρωπίνην φύσιν ἐν μεταποιήσει γίνεται。
- 注解：ἡ ἀνθρωπότης は「それ自体としての人間」、すなわち人という抽象の概念。恵みは人の本性の本質的な特性のどれも変えない（n215 の 17.、l. 18954〜18956、n216 の頭 l. 19010〜19014）。οὔτε τὸ λογ. の人の能力の記述は、15 章の終わりと 33 章（注）を見よ（n216 の 2.、l. 19016〜19018）。
- 訳語表：ἀνθρωπότης は「人間」（15.4。同じ文の ἀνθρωπίνη φύσις「人の本性」と分ける）。15.9 の τὸ λογικόν「ことばをもつこと」、τὸ διανοητικόν「考えること」、τὸ ἐπιστήμης δεκτικόν「知識を受け入れること」。
- 読者への影響：小。
- 訳での扱い：訳注なし。15.9 の三つの語に揃え、ἀνθρωπότης「人間」と ἀνθρωπίνη φύσις「人の本性」を同じ文の中で分ける。40.3 の ἀλλὰ μήν は、論の次の前提を出すので、文型の訳し方（23.2、37.5）に従い「さて」。

### 40.5 καθαροὶ τὰς προαιρέσεις、μετεποιήθημεν（不定過去）
- 底本：οὐκοῦν εἰ … καθαροὶ τὰς προαιρέσεις γενοίμεθα, τὰς πονηρίας τῶν ψυχῶν ἀποκλύσαντες, κρείττους γεγόναμεν καὶ πρὸς τὸ κρεῖττον μετεποιήθημεν。
- 注解：καθαροὶ τ. π. は「意志において清い」（n216 の 13.、l. 19010、19040）。μετεποιήθημεν のこの不定過去の使い方は、37 章 p. 142 の ἔσβεσαν（注）を比べよ（15.、l. 19042〜19044）。
- 訳語表：προαίρεσις は「意志」。40.12 の διὰ τῆς προαιρέσεως（注解は生の「目的」「目指すところ」とする。n218 の 8.、l. 19262〜19263）、40.18 の ἐκ τῆς ἑκάστου προαιρέσεως、δι᾽ ἀγαθῆς προαιρέσεως も同じ語。
- 読者への影響：小。帰結の γεγόναμεν と μετεποιήθημεν は、条件が満たされればそのときにはもう成っている、という完了・不定過去で、未来に訳すと意味がずれる。
- 訳での扱い：訳注なし。προαίρεσις は 40 章の 4 か所とも「意志」で通す。μετεποιήθημεν は「もう造り変えられている」の向き（37.15 の ἔσβεσαν の訳に合わせる）。

### 40.6 ἐμπαθεῖς κηλῖδας、μύησις・ἀμύητος、συμβαίνοι、τὸ ὕδωρ ὕδωρ ἐστίν、ἡ δωρεὰ τοῦ ἁγίου πνεύματος
- 底本：ἡ δὲ ψυχὴ τὰς ἐμπαθεῖς κηλῖδας μὴ ἀπορρύψαιτο, ἀλλ᾽ ὁ μετὰ τὴν μύησιν βίος συμβαίνοι τῷ ἀμυήτῳ βίῳ … ὅτι ἐπὶ τούτων τὸ ὕδωρ ὕδωρ ἐστίν, οὐδαμοῦ τῆς δωρεᾶς τοῦ ἁγίου πνεύματος ἐπιφανείσης τῷ γιγνομένῳ。
- 注解：ἐμπαθεῖς κηλ. は「情念が引き起こしたしみ」。ἐμπαθεῖς には 5 章の ἐμπαθές を比べよ（n216 の 16.、l. 19046〜19048）。μύησιν は 35 章の τῆς τοιαύτης μυήσεως を比べよ（17.、l. 19050〜19051）。συμβαίνοι は「一致する」「同じ性格である」（ib.、l. 19053〜19054）。ἐπὶ τούτων は「その人々の場合には、水は水で、聖霊の賜物は行われることのうちにどこにも現れない」。改める必要はない。グレゴリオスの意味は、人が洗礼の条件を満たさないとき洗礼の恵みは与えられない、ということ。τῆς δωρ. τ. ἁ. π. で、グレゴリオスは、洗礼に含めていたであろう塗油を考えているらしい（n216 の 19.、l. 19056〜19060、n217 の頭 l. 19128〜19137）。
- 訳語表：ἐμπαθής は「情念に支配される」（5.17）。35.19 の μύησις は「秘義を授けられること」、35.23 の ἀμύητοι は「秘義を授けられていない」。8.13 の κηλῖδας は「しみ」。
- 新約：ἡ δωρεὰ τοῦ ἁγίου πνεύματος は、使徒二・三八 の τὴν δωρεὰν τοῦ ἁγίου πνεύματος（ACT.csv l. 65）と同じ句で、口語訳は「聖霊の賜物」（`node tools/bible.js Acts.2.38`。名指しの引用ではない）。
- 読者への影響：中。「水はただの水」は 40 章の要の言い方（要約にも引かれる）。τῷ γιγνομένῳ は 33〜34 章の「（洗礼で）行われること」。
- 訳での扱い：訳注なし。ἐμπαθεῖς κηλῖδας は「情念によるしみ」。μύησις・ἀμύητος は 35 章に合わせて「秘義を授けられた（あとの）生」「秘義を授けられていない生」。τῷ γιγνομένῳ は文型の訳し方（34.2、34.5）の「行われること」の語順にする。δωρεά は「聖霊の賜物」。塗油の語は足さない。

### 40.6 τὸ κατὰ τὸν θυμὸν αἶσχος ὑβρίζῃ τὴν θείαν μορφήν
- 底本：ὅταν μὴ μόνον τὸ κατὰ τὸν θυμὸν αἶσχος ὑβρίζῃ τὴν θείαν μορφὴν ἢ τὸ κατὰ πλεονεξίαν πάθος …。
- 注解：Τὸ κ. τ. θ. αἶσχος は「怒りの醜さ」。Αἶσχος は心や体の醜さに使う。プラトン『饗宴』201a の ἄλλο τι ὁ Ἔρως κάλλους ἂν εἴη ἔρως, αἴσχους δ᾽ οὔ; を比べよ（n217 の 2.、l. 19139〜19145）。μορφήν は、神のかたちに（κατ᾽ εἰκόνα θεοῦ）造られたことによって人がもつ、変わらない特徴について、ここで正しく使われている（5 章）（ib.、l. 19148〜19154。参照の「(c. 5).」は右の欄の頭にある。`pct:48,60,50,8` で確かめた）。英訳の脚注 [2055]：ラテン語の訳者たちが「魂の卑しさ」と訳したのはまったくの誤りで、それはすぐ下で挙がる、と言う（l. 45669〜45671）。英訳の本文は「怒りの醜さ」の意味で訳す（l. 45587）。
- 訳語表：αἰσχρόν・αἶσχος・αἰσχρότης は「恥ずべき（もの）・恥ずべきこと」（9.3〜9.5。καλόν の反対の語）。εἰκών は「かたち」（5.14 など）。μορφή は訳語表にない（8.4 の μετεμορφώθημεν は「姿を変えて」）。
- 新約：口語訳はピリピ二・六 の μορφὴ θεοῦ を「神のかたち」と訳す（`node tools/bible.js Phil.2.6`）。
- 読者への影響：中。注解の取り方では、αἶσχος（醜さ）と θεία μορφή（神の姿の美しさ）が対になっている。訳語表の「恥ずべきこと」にすると、この対が見えにくい。μορφή を「かたち」にすると εἰκών の訳と重なる。

- 底本：40.14 の ἐρεῖ πρὸς σὲ ἡ προφητεία ὅτι Υἱὸς ἀνθρώπου εἶ, οὐχὶ υἱὸς ὑψίστου· ἀγαπᾷς ματαιότητα, ζητεῖς ψεῦδος. 40.15 の οὐκ ἔγνως πῶς θαυμαστοῦται ἄνθρωπος, ὅτι οὐκ ἄλλως, εἰ μὴ ὅσιος γένηται。書き出しの Υἱός は大文字で刷られる（引用として扱われている）。

- 口語訳：詩篇四・二〜三 は「人の子らよ、いつまで…むなしい言葉を愛し、偽りを慕い求めるのか」「しかしあなたがたは知るがよい、主は神を敬う人をご自分のために聖別されたことを」。八二・六 は「あなたがたは皆いと高き者の子だ」。七十人訳の ἐθαυμάστωσεν（驚くべきものとした）は、口語訳では「聖別された」。

- 訳での扱い：言い換えなので『』で囲まない（ἀγαπᾷς ματαιότητα, ζητεῖς ψεῦδος の部分は口語訳の「むなしい言葉を愛し、偽りを慕い求める」に寄せてよい）。Υἱὸς ἀνθρώπου は、キリストの呼び名と紛れないよう「人間の子」とするかをメインで決める。υἱὸς ὑψίστου は口語訳の「いと高き者の子」。θαυμαστοῦται は七十人訳に従って「驚くべきものとされる」の向き。訳注を付けるかはメインで決める（推さない。言い換えで、出典も名指されていないので）。付けるなら、40.15 の「驚くべきものとされる」の後に、案：`^[旧約のギリシア語訳による。日本語の聖書では『聖別された』。]`（29 字）。出典を付けるなら（詩篇四・二〜三）。

- 注解：大部分の写本ではここで書は終わる。しかし m と、フロント・デュ・デュクが使った Codex Vulcobianus には、長い付加の一節が続き、ヘルウェトゥスのラテン訳とパリ版にもある。アケファロイ派の頭で、536 年のコンスタンティノポリスの教会会議で断罪されたセウェロスの異端を扱う。この一節の全体は、ライトゥのテオドロス（650 年ごろの司祭で修道士）の、マニ教徒、パウロス派、アポリナリオス派、ネストリオス派、エウテュケス派に答える受肉論の結びで、Migne の PG 91、1479 頁以下とガランディの古教父文庫 13 巻に刷られている。写字生の誤りでグレゴリオスの本文に入り込んだ（n220 の注解、l. 19418〜19447）。英訳の脚注 [2062]：この一節は、ヘルウェトゥスが使ったヴルコビウスの写本一つにあり、「明らかに、どこかの不注意な写字生の付加」。モレルはセウェロス駁論の序の一部とみる。Krabinger はこれを引くが、彼の写本はどれも認めない、と言う（l. 45693〜45704）。英訳の本文は付加の文を訳さない。
- 採る校訂者：底本は付加の文を本文に入れず、異読の欄に挙げる。
- 読者への影響：小。付加の文は、グレゴリオスの死後の 6〜7 世紀の論争を扱い、本文には属さない。訳は底本どおり 40.18 で終える。
- 訳での扱い：訳注なし。付加の文は訳さない。
