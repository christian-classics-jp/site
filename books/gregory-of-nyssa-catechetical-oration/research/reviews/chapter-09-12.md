- 論点一覧で、訳す前にメインで決めたこと：
  - 9.1 の破格の構文は、本の文型の訳し方（1.14）に従い「その事柄とは」で枠を立てる。οὐχ ὁμοίως ἕξει の主語は συνθήσεται と同じ人。τὰ ἐφεξῆς（これから述べる事柄）と τὸ ἐφεξῆς τῶν λεγομένων（その後に語られること、復活）を訳し分ける。
  - 9.3 の τὸ κατὰ κακίαν πάθος は訳語表の「情念」。αἰσχρόν は καλόν の反対の語なので「恥ずべき」で通し、αἶσχος・αἰσχρότης は「恥ずべきこと」。
  - 9.5 の ἀναδεικνυμένου は論証の結論の「示される」、ἀλογία は Srawley の注に従い「愚かさ」（5.3 の「ことばのなさ」と違う）。
  - πρέπει・θεοπρεπής・ἀπρεπές・εὐπρεπές は「ふさわしい」で通し、10.3 の τὸ ἀπεμφαῖνον は同じ文の εὐπρεπές と分けて「そぐわない」。
  - 10.1 の τῷ ἀτόμῳ は「ごく小さなもの」。
  - 10.3 の τῆς ὑποκειμένης ὕλης、τοῦ ὑποκειμένου は灯心のことなので「下にある素材」「下にあるもの」。ἐξημμένην は Srawley の注に従い「すがりついて」。挿入句（καί μοι … ἀποποιείσθω）は独立した文にする。τὸ φθαρτικὸν τοῦ πυρός は、形容詞の形から能動に取って「火がものを朽ちさせる性質」とし、Srawley の注（朽ちやすさ）との違いを `// ` メモに書く。
  - 「混ざる」の語（κατακιρνᾶται、ἀνάκρασις、συγκεκραμένη）、「一つになる」の語（ἕνωσις、ἑνοῦται）、συμφυία（「結びつき」。6.14、8.16 と同じ）、προσεγγισμός（「近づき」）を訳し分ける。
  - 10.2 の πολυπραγμοσύνη（探り求める心）と 11.4 の ἀπολυπραγμόνητον（探り求めずにおく）を「探り求める」でつなぐ。
  - 12.2 の τὰς κατὰ τὸν κόσμον οἰκονομίας は 0.5 に揃えて「世界のうちで神が治めておられること」とし、10.3 の θεία οἰκονομία（神の救いのわざ）と分ける。διὰ σαρκός は Srawley の注の第一の取り方（肉によって現れた）。
  - 12.1 には出典（第一テモテ三・一六）と訳注を付ける。グレゴリオスの句は θεός の本文と語が合い、論も「神が」現れたことの証明だが、口語訳は「キリストは」なので、出典を引いた読者が迷う。
  - φθορά は、9〜32 章の初出の 12.3 で「朽ちること」に決める（『神のことばの受肉』も「朽ちる」で訳している）。
- 結果：6 件（必須 2、提案 4。置き換えは 6 組）。すべて採った。底本の読み（9.1 の τὰ ἐφεξῆς と τὸ ἐφεξῆς、10.3 の οὕτω καὶ ἐπὶ τούτου、11.1 の τὸν ἄνθρωπον、12.3 の ἐπιστατεῖν）、12.1 の訳注と出典の位置は、そのままでよいとされた。10.3 の τὸ φθαρτικόν の取り方は、辞書で確かめていないことが論点一覧の「未確認」に残る。
