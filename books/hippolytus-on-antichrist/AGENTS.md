# ヒッポリュトス『キリストと反キリストについて』の決まり

ローマのヒッポリュトスが 200 年ごろ、兄弟テオフィロスの問いに答えて、聖書から反キリストについて解き明かした書。ギリシア語。ダニエル書、イザヤ書、黙示録などの長い引用が続き、その間に短い解き明かしを挟む。同じ 3 世紀のギリシア語の書で、友人に宛てた勧めの書であるオリゲネス『殉教の勧め』（`books/origen-exhortation-to-martyrdom/AGENTS.md`）の文体（敬体、神とキリストへの尊敬語、修辞疑問の終え方）を、同じ語を同じ意味で使うかぎり引き継ぐ。底本を画像から起こす手順は『ペルペトゥアとフェリキタスの殉教録』（`books/perpetua-and-felicitas/AGENTS.md`）と『パピアス断片・クアドラトゥス断片』（`books/papias-quadratus/`）にならう。ダニエル七・二五の期間などダニエル書の語は『トリュフォンとの対話』（`books/dialogue-with-trypho/AGENTS.md`）に合わせる。ここには、この本に固有の決まりだけを書く。食い違うときはこのファイルを優先する。

## 節の形

- 章（1〜67）の番号は底本（Achelis 1897）に従う。英訳（ANF）の章の番号も同じ。
- 底本には節の区分がない。節の番号は、画像から起こした章を `tools/split-units.js` で文の切れ目（. と、その後の閉じ引用符）で分けて、この訳が付けたもの。底本にも英訳にも、この節番号はない。英訳と照らすときは章と文の内容で照らす。ギリシア語の疑問符（;）と上の点（·）では切らないので、問いで終わる文は次の文と同じ節に入る。
- 章が文の途中から始まるところがある（3 章は 2 章の終わりの δεήσει, の後の ὅπως から）。章の切れ目は底本のローマ数字の位置に従い、文がつながっていても章を分ける。訳では、前の章の終わりの訳を読点で終え、次の章の訳がそれを受けるようにする。次の章の訳を言い切りの文で始めない（3.1「…明かしてくださるようにと。」）。
- 底本テキストは `research/achelis-1897.txt`。1 行 1 節で `<章>.<節> <本文>`（`2.5`）。
- 底本の 1 節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `2:5 ` のように章・節の番号で始める。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 1〜5 章　…` の形（章の範囲、中身）。
- 底本の表題（ΙΠΠΟΛΥΤΟΥ ΕΠΙΣΚΟΠΟΥ ΡΩΜΗΣ ΑΠΟΔΕΙΞΙΣ ΕΚ ΤΩΝ ΑΓΙΩΝ ΓΡΑΦΩΝ ΠΕΡΙ ΧΡΙΣΤΟΥ ΚΑΙ ΠΕΡΙ ΤΟΥ ΑΝΤΙΧΡΙΣΤΟΥ。写本によって語が違う）は底本テキストに入れていない。表題は見出しに出さない（書名は README から出る）。
- ページの割り（`research/pages.json`）は、全文を起こす前に、英訳の章ごとの語数（計 13,600 語ほど。ギリシア語は 1〜5 章で英訳の 0.72 倍）を目安に、内容の切れ目で 11 ページに分けた。序（1〜5 章）、ヤコブの祝福（6〜14 章）、ダンの部族とイザヤ・エゼキエル（15〜18 章）、ダニエルの幻（19〜25 章、26〜33 章）、大淫婦バビロン（34〜40 章、41〜46 章）、二人の証人と地から上る獣（47〜50 章）、反キリストの業（51〜57 章、58〜62 章）、終わりの迫害と復活（63〜67 章）。

## 底本の扱い

- 本文は、IIIF で切り出した画像（`research/sources.md`）から起こし、OCR と語ごとに突き合わせる。ページごとに、訳す範囲を起こして `research/achelis-1897.txt` に足す。本を始めたときに起こしたのは 1〜5 章（最初のページ）だけ。次のページを訳すセッションは、page-context を作る前に、そのページの章を起こして足す（起こさないと page-context は空の抜粋を書き出す）。手順：`tools/ocr-lines.js` で pages.json の `print` の行から本文の行だけを拾って下書きにし、画像を見ながら直した章を 1 章 1 行のファイルに書き、`tools/split-units.js` で足す。足したあと、`tools/collate.js <底本テキスト> <範囲> <OCR> <print の行範囲> --ignore-accents` で OCR との違いの候補を出し、一つずつ画像で確かめる（候補の多くは OCR の χ・ϑ の読み違いと読み落とし）。アクセントと気息はこの比べ方では確かめられないので、画像の目視で確かめる。どの画像をどの切り出しで読んだか、OCR との違いが何だったかは `research/sources.md` の IIIF の行に書き足す。
- OCR は κ を χ、θ を ϑ と読み、行頭の語を落とすことがある（1〜5 章では ὡς、δι᾽、καὶ を何度も落とした）。章の番号も多くを読み落とすか崩す（LXVII を「LXVI」、XLVII を「XLVL」と読む）。OCR だけに頼らず、必ず画像で読む。
- 起こすのは本文だけ。ページの柱、余白の行番号と写本の葉の番号（`H 173r`）、本文の中の写本の葉の境の縦線 `|`、聖書の箇所の行、校注は起こさない。行末で分けられた語はつなぐ。
- 文字は通常のギリシア文字で書く（θ、κ。ϑ は使わない）。語中の ς も底本のとおり（9.1 の προςδοκία、9.2 の προςδεχόμεθα）。気息記号の付いた省略は ᾽（U+1FBD。κατ᾽、δι᾽）、上の点は ·（U+00B7）。綴り、アクセント、大文字（底本は章の初めの語を、その章が行の頭から始まるときだけ大文字にする）、句読点は底本のとおり。底本が iota subscriptum を付けないところ（1.4 の παρήνει、3.3 の σώζειν）もそのまま。
- 底本は聖書の言葉の直接の引用を „ “ で囲み、下の欄に箇所を記す。底本テキストでも „ “ を残す。訳では „ “ の部分を聖句の直接の引用として扱い（『』と出典）、下の欄の箇所を出典に使う。„ “ のない言い換えや暗示（1.1 の第一ペテロ四・一一を思わせる句のように、欄に「Vgl.」とあるもの）は『』に入れない。
- 2.5 の点の列（προειρημένα … καλῶς）は、底本が本文の欠けを示す印。底本テキストでは … とし、訳では欠けたままにして `// ` メモに書く。日本語では「…」を使わないので、欠けの位置に訳注「^[ここで本文の一部が欠けている。]」を付ける。角括弧・山括弧など、ほかの記号は初めて出てくるページで校注と序で意味を確かめてからここに書く。
- 校注は写本 H（10 世紀）、E・R（15〜16 世紀）、古スラヴ語訳 S の読みを記す。1〜5 章では、底本は多くのところで H に従う。訳は底本の読みに従い、写本の読みが訳に関わるときだけ `// ` メモに書く。訳注は読者の理解が変わる箇所にだけ付ける。
- 英訳（ANF）は Gallandi の本文から訳したもので、E・R の系統の読みに従うところがある（1 章の τῶν ὄντων など）。英訳と底本の違いは訳の誤りとは限らないので、レビューでは底本の校注と照らしてから指摘させる。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。兄弟テオフィロスに宛てた解き明かしの書で、『殉教の勧め』と揃える。
- 書き手のヒッポリュトスは「わたし」。書き手と読み手を含むキリスト者は「わたしたち」。書き手だけを指す 1 人称複数（1.1 の ὑπὸ σοῦ ἡμῖν、1.2 の παρ᾽ ἡμῶν、2.5 の λέγομεν のような著者の複数）は、文脈から書き手だけと分かるときは「わたし」と訳す。読み手を含むと読めるときは「わたしたち」のままにする。
- テオフィロスは「あなた」。尊敬語は使わない。呼びかけ：1.1 と 67 章の ἀγαπητέ μου ἀδελφὲ Θεόφιλε は「わたしの愛する兄弟テオフィロスよ」、2.7 の ὦ Θεόφιλε は「テオフィロスよ」、ἀγαπητέ だけのとき（29 章など）は「愛する者よ」。呼びかけは文頭か読点で区切って置く。
- 30〜32 章などの預言者への呼びかけ（ὦ μακάριε Ἡσαΐα、μακάριε Δανιήλ）は「幸いなイザヤよ」「幸いなダニエルよ」。預言者への命令は「〜てください」（「来て、はっきり語ってください」）、預言者への 2 人称は「あなた」。預言者・使徒の動作に尊敬語は使わない（『殉教の勧め』と同じ）。
- 神、キリスト、聖霊の動作は尊敬語にする。受け身や可能と紛れる「〜られる」は避ける（「お語りになります」「お着けになりました」）。「来られる」は「おいでになる」（6.3、9.2）、「花開かれる」は「花をお開きになる」（8.3）とする。言（λόγος）がキリストを指すときも同じ。
- 反キリストは尊敬語を使わず、「彼」と呼ぶ。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。

## 文型の訳し方

この本のレビューで決まった型を、ここに統合して書く。

- ὅπως・ἵνα の目的の文は、依頼や命令に変えず「〜ためです」で受ける。3 人称の命令（1.2 の ἤτω）は「〜となりますように」。
- テオフィロスが主語の 2 人称（中動相の ἐγκαταθῇ、1.3 など）は、「あなたが〜する」と主語を出す。
- 神やキリストが動作主の受け身（2.3 の ὑπὸ θεοῦ ἀποκεκαλυμμένα、12.1 の ὑπ᾽ αὐτοῦ τοῦ λόγου … καταρτιζόμενοι）は、意味が変わらないかぎり尊敬語の能動にする（「神が啓示なさった」「言ご自身とその恵みが…整えてくださっていた」）。
- 命令に係る ἵνα μή の目的の文（14.2 の ἵνα μὴ σφαλῇ τις, … ἐπιστησάτω）は、「〜ないように、…べきです」の一文にし、目的の文を独立した義務の文にしない。読者への 3 人称の命令（ἐπιστησάτω）は「〜べきです」。
- ἐπεί・ἐπειδή の文を二つに分けるときは、「ですから」などで理由のつながりを残す（14.4）。
- 書き手の勧めの 1 人称複数の接続法（6.6 の τραπῶμεν、14.4 の ἀτονήσωμεν）は、主語を出さずに「〜ましょう」とする。
- 分詞や関係文の係り先は、日本語でも係り先が分かるように文を分ける（11.1 の κατελθοῦσαν は χάριν に係る：「聖霊の、父からの恵みです。それは、ヨルダン川で…下ったものです」）。

## 引用

- 聖書の引用は口語訳聖書を参考にする（README）。ヒッポリュトスは旧約をギリシア語訳（七十人訳）で引く。ダニエル書がテオドティオン訳の形か古いギリシア語訳の形かは、まだ確かめていない。ダニエル書の長い引用が出る 19〜25 章のページで、引用の形を見て確かめ、ここに書く。口語訳（ヘブル語本文からの訳）と意味が違うところは、底本のギリシア語から訳し、口語訳の言い回しは意味が同じ部分にだけ使う。違いが読者の理解に関わるときは `// ` メモに書く。
- 口語訳の文言をそのまま引く聖句は、口語訳の文の切れ目を保ち、60 字を超えても文を分けない（1.4 の第二テモテ二・一〜二）。verify の 60 字の WARN は、この場合だけ認める（『殉教の勧め』と同じ）。口語訳の中のかぎかっこ（第一テモテ六・二〇 の「知識」）は、『』の中では外す。
- „ “ のない言い換えや暗示（2.7 のローマ一五・三〇）には、出典も付けない。
- サムエル記・列王紀・歴代志の出典は「第一サムエル」「第二列王」の形で書く（2.5 の（第一サムエル九・九））。
- 7〜14 章のヤコブの祝福（創世記四九・八〜一二）は七十人訳の形で引かれ、解き明かしもその形による。7.1〜7.4 の訳を基準の文言にし（意味の同じ句は口語訳と dialogue-with-trypho 52:2・120:3 に揃える）、8〜14 章で一句ずつ引き直すときは同じ文言を使う。引き直しの出典は、章ごとに最初に引き直す句にだけ付ける（8.2 の（創世記四九・九））。イザヤ一・二一、一一・一、創世記四九・一七 なども、解き明かしが七十人訳の語による箇所は七十人訳から訳し、口語訳との違いを `// ` メモに書く。
- 詩篇は、七十人訳の番号と違っても、出典は口語訳の章節で書く（8.5 の（詩篇三・五）。七十人訳では三・六）。
- ダニエル書のギリシア語の付加部分（スザンナ、ベルと竜、三人の若者の歌）や、口語訳にない書から引くときは、底本のギリシア語から訳す。
