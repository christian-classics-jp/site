# フランク・バートルマン『ペンテコステはいかにしてロサンゼルスに来たか』

フランク・バートルマン（1871-1936）著『 How Pentecost Came to Los Angeles: As It Was in the Beginning 』（第二版、Los Angeles: F. Bartleman, 1925）の翻訳。1980 年以降の『 Azusa Street 』の題の版は、編集や付録が加わっているので用いない。

原文は、Deal Pentecostal Church（英国ケント州）が 1925 年版を書き起こして公開していた PDF（2013 年作成）による。元のリンクが切れたため [Wayback Machine の保存版](https://web.archive.org/web/20240218220911/http://www.dealpentecostal.co.uk/How%20Pentecost%20Came%20To%20Los%20Angeles%20F%20Bartleman%201925.pdf) を示す。同じ PDF を `how-pentecost-came-to-los-angeles-1925.pdf` としてこのディレクトリに置き、各節の `both.md` に英文を抜き出した。同じ書き起こしをページ画像にしたものが [CCEL](https://ccel.org/ccel/bartleman/los) にあり（Public Domain と表示）、段落の切れ目はこれと照らし合わせた。

聖書の引用は口語訳聖書を参考にした。
