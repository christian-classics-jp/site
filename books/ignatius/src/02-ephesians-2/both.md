# エペソ人への手紙　11〜21 章　沈黙のうちに行われた奥義

11.1 Ἔσχατοι καιροί. λοιπὸν αἰσχυνθῶμεν, φοβηθῶμεν τὴν μακροθυμίαν τοῦ θεοῦ, ἵνα μὴ ἡμῖν εἰς κρίμα γένηται. ἢ γὰρ τὴν μέλλουσαν ὀργὴν φοβηθῶμεν, ἢ τὴν ἐνεστῶσαν χάριν ἀγαπήσωμεν, ἓν τῶν δύο· μόνον ἐν Χριστῷ Ἰησοῦ εὑρεθῆναι εἰς τὸ ἀληθινὸν ζῆν.
11:1 今は終わりの時です。これからは恥じ入りましょう。神の辛抱強さを恐れましょう。それが、わたしたちへのさばきとならないためです。実際、来るべき怒りを恐れるか、今ある恵みを愛するか、二つのうちどちらかにしましょう。ただ、まことに生きるために、キリスト・イエスにあって見いだされるようにしましょう。
// 「終わりの時」は第一ヨハネ二・一八、第一コリント七・二九を思わせる。ἓν τῶν δύο（二つのうちどちらか）は G・L。g などは「今の生において」と読む。
11.2 χωρὶς τούτου μηδὲν ὑμῖν πρεπέτω, ἐν ᾧ τὰ δεσμὰ περιφέρω, τοὺς πνευματικοὺς μαργαρίτας, ἐν οἷς γένοιτό μοι ἀναστῆναι τῇ προσευχῇ ὑμῶν, ἧς γένοιτό μοι ἀεὶ μέτοχον εἶναι, ἵνα ἐν κλήρῳ Ἐφεσίων εὑρεθῶ τῶν Χριστιανῶν, οἳ καὶ τοῖς ἀποστόλοις πάντοτε συνῄνεσαν ἐν δυνάμει Ἰησοῦ Χριστοῦ.
11:2 この方を離れては、何もあなたがたの飾りとなってはなりません。この方にあって、わたしは鎖を身に帯びています。この鎖は霊の真珠です。あなたがたの祈りによって、わたしがこの鎖をつけたまま、よみがえることができますように。わたしが、いつもその祈りにあずかる者でありますように。エペソのキリスト者たちの分け前のうちに、わたしが見いだされるためです。彼らは、イエス・キリストの力によって、いつも使徒たちとも心を合わせてきました。
// πρεπέτω は「目立って輝く」の意で、続く真珠の比喩につながる。「心を合わせて」は G・L の συνῄνεσαν。g・A は συνῆσαν（共にいた）。

12.1 Οἶδα, τίς εἰμι καὶ τίσιν γράφω. ἐγὼ κατάκριτος, ὑμεῖς ἠλεημένοι· ἐγὼ ὑπὸ κίνδυνον, ὑμεῖς ἐστηριγμένοι·
12:1 わたしは、自分がだれであり、だれに書いているかを知っています。わたしは罪に定められた者、あなたがたはあわれみを受けた者です。わたしは危険のもとにあり、あなたがたは堅く立てられています。
12.2 πάροδός ἐστε τῶν εἰς θεὸν ἀναιρουμένων, Παύλου συμμύσται τοῦ ἡγιασμένου. τοῦ μεμαρτυρημένου, ἀξιομακαρίστου, οὗ γένοιτό μοι ὑπὸ τὰ ἴχνη εὑρεθῆναι, ὅταν θεοῦ ἐπιτύχω, ὃς ἐν πάσῃ ἐπιστολῇ μνημονεύει ὑμῶν ἐν Χριστῷ Ἰησοῦ.
12:2 あなたがたは、神のもとへ行くために殺される者たちの通り道です。聖とされたパウロと共に、奥義にあずかった者たちです。パウロはよいあかしを受け、幸いと呼ばれるにふさわしい人です。わたしが神に達するとき、その足跡のうちに見いだされますように。パウロは、どの手紙でも、キリスト・イエスにあってあなたがたのことを覚えています。
// 底本と Lake は「聖とされた」のあとに句点を打つ。LF・L–H はコンマで、三つの修飾がパウロに続く。底本の句読に従って文を切り、意味はパウロへの修飾として続けて訳した。
// πάροδος（通り道）について、LF は、エペソ人がかつてパウロを、いまイグナティオスを、殉教への道で見送っているとみる。ἐν πάσῃ ἐπιστολῇ を「（エペソ人への）手紙全体で」と解する説もあるが、LF は退ける。

13.1 Σπουδάζετε οὖν πυκνότερον συνέρχεσθαι εἰς εὐχαριστίαν θεοῦ καὶ εἰς δόξαν. ὅταν γὰρ πυκνῶς ἐπὶ τὸ αὐτὸ γίνεσθε, καθαιροῦνται αἱ δυνάμεις τοῦ Σατανᾶ, καὶ λύεται ὁ ὄλεθρος αὐτοῦ ἐν τῇ ὁμονοίᾳ ὑμῶν τῆς πίστεως.
13:1 ですから、神に感謝をささげ、栄光を帰すために、もっと頻繁に集まるよう努めなさい。実際、あなたがたがしばしば一つ所に集まると、サタンの力は打ち倒されます。そして、サタンのもたらす滅びは、あなたがたの信仰の一致のうちに解かれるのです。
// εὐχαριστία は「感謝」の語だが、聖餐をも指す。
13.2 οὐδέν ἐστιν ἄμεινον εἰρήνης, ἐν ᾗ πᾶς πόλεμος καταργεῖται ἐπουρανίων καὶ ἐπιγείων.
13:2 平和にまさるものはありません。平和のうちに、天のものと地のものとのあらゆる戦いが、無にされるのです。
// 天の敵（悪の霊）と地の敵（悪い人々）との戦いのこと（LF）。エペソ六・一二を思わせる。

14.1 Ὧν οὐδὲν λανθάνει ὑμᾶς, ἐὰν τελείως εἰς Ἰησοῦν Χριστὸν ἔχητε τὴν πίστιν καὶ τὴν ἀγάπην, ἥτις ἐστὶν ἀρχὴ ζωῆς καὶ τέλος· ἀρχὴ μὲν πίστις, τέλος δὲ ἀγάπη. τὰ δὲ δύο ἐν ἑνότητι γενόμενα θεός ἐστιν, τὰ δὲ ἄλλα πάντα εἰς καλοκἀγαθίαν ἀκόλουθά ἐστιν.
14:1 あなたがたがイエス・キリストに対して、完全に信仰と愛を持っているなら、これらのことは何一つ、あなたがたの目を逃れません。信仰と愛は、いのちの初めと終わりです。初めは信仰、終わりは愛です。この二つが一つになると、それは神です。ほかのすべては、この二つに続いて、気高い善に至らせるものです。
// 「神です」は L・A など。G は θεοῦ ἐστιν（神のものである）。「初めは信仰、終わりは愛」は第一テモテ一・五を思わせる。
14.2 οὐδεὶς πίστιν ἐπαγγελλόμενος ἁμαρτάνει, οὐδὲ ἀγάπην κεκτημένος μισεῖ. φανερὸν τὸ δένδρον ἀπὸ τοῦ καρποῦ αὐτοῦ. οὕτως οἱ ἐπαγγελλόμενοι Χριστοῦ εἶναι δι’ ὧν πράσσουσιν ὀφθήσονται. οὐ γὰρ νῦν ἐπαγγελίας τὸ ἔργον, ἀλλ’ ἐν δυνάμει πίστεως ἐάν τις εὑρεθῇ εἰς τέλος.
14:2 信仰を公言する者は、だれも罪を犯しません。愛を得た者は、だれも憎みません。木はその実によって明らかになります。同じように、キリストのものだと公言する者たちは、その行いによって見分けられます。実際、今求められているのは、口で約束するわざではありません。最後まで信仰の力のうちに見いだされるかどうかです。
// 「木はその実によって明らかになります」はマタイ一二・三三（口語訳「木はその実でわかる」）、ルカ六・四四の言い回しをなぞる。G・L は「キリストのもの」を「キリスト者」とする。

15.1 Ἄμεινόν ἐστιν σιωπᾶν καὶ εἶναι, ἢ λαλοῦντα μὴ εἶναι. καλὸν τὸ διδάσκειν, ἐὰν ὁ λέγων ποιῇ. εἷς οὖν διδάσκαλος, ὃς εἶπεν, καὶ ἐγένετο· καὶ ἃ σιγῶν δὲ πεποίηκεν ἄξια τοῦ πατρός ἐστιν.
15:1 黙っていて実のあるほうが、語っていて実のないよりもまさっています。教えることは良いことです。言う者が行うのならばです。ですから、教師はただ一人です。その方が仰せられると、そのようになりました。そして、その方が黙って行われたことも、父にふさわしいのです。
// 「仰せられると、そのようになりました」は詩篇三三・九（七十人訳三二・九）、一四八・五の言い回しをなぞる。七十人訳は「それらは成った」と複数。詩篇の神の創造の言葉を、キリストの地上の働きに当てている（LF）。
15.2 ὁ λόγον Ἰησοῦ κεκτημένος ἀληθῶς δύναται καὶ τῆς ἡσυχίας αὐτοῦ ἀκούειν, ἵνα τέλειος ᾖ, ἵνα δι’ ὧν λαλεῖ πράσσῃ καὶ δι’ ὧν σιγᾷ γινώσκηται.
15:2 イエスのことばを本当に自分のものとした者は、その方の沈黙をも聞くことができます。完全な者となるためです。語ることによって行い、黙っていることによって知られるためです。
// γινώσκηται（知られる）を、LF は「人々に理解される」の意にとる。
15.3 οὐδὲν λανθάνει τὸν κύριον, ἀλλὰ καὶ τὰ κρυπτὰ ἡμῶν ἐγγὺς αὐτῷ ἐστιν. πάντα οὖν ποιῶμεν ὡς αὐτοῦ ἐν ἡμῖν κατοικοῦντος, ἵνα ὦμεν αὐτοῦ ναοὶ καὶ αὐτὸς ἐν ἡμῖν θεὸς ἡμῶν· ὅπερ καὶ ἔστιν καὶ φανήσεται πρὸ προσώπου ἡμῶν, ἐξ ὧν δικαίως ἀγαπῶμεν αὐτόν.
15:3 主に隠れているものは何もありません。わたしたちの隠れたことさえ、主の近くにあります。ですから、主がわたしたちのうちに住んでおられると思って、すべてを行いましょう。わたしたちが主の宮となり、主ご自身がわたしたちのうちにいて、わたしたちの神となられるためです。このことは今もそうであり、わたしたちの目の前に現れるでしょう。わたしたちが主を正しく愛することによってです。
// 「宮」は第一コリント三・一六を思わせる。LF は ἡμῶν（わたしたちの）を欠く形を採り、宮の像がその宮の神であるように、内に住む神が霊の宮の神となる、と解する。

16.1 Μὴ πλανᾶσθε, ἀδελφοί μου· οἱ οἰκοφθόροι βασιλείαν θεοῦ οὐ κληρονομήσουσιν.
16:1 わたしの兄弟たちよ、思い違いをしてはなりません。家を汚す者は、神の国をつぐことはありません。
// 第一コリント六・九〜一〇（口語訳「まちがってはいけない。…神の国をつぐことはない」）、ガラテヤ五・二一の言い回しをなぞる。パウロは「正しくない者」などを挙げるが、ここでは主語が οἰκοφθόροι に代わる。
// οἰκοφθόροι は財産を食いつぶす者、また他人の家庭を壊す者、すなわち姦淫する者を言う語。LF は、神の家である心とからだの宮を汚す者と解する。
16.2 εἰ οὖν οἱ κατὰ σάρκα ταῦτα πράσσοντες ἀπέθανον, πόσῳ μᾶλλον, ἐὰν πίστιν θεοῦ ἐν κακῇ διδασκαλίᾳ φθείρῃ, ὑπὲρ ἧς Ἰησοῦς Χριστὸς ἐσταυρώθη; ὁ τοιοῦτος ῥυπαρὸς γενόμενος, εἰς τὸ πῦρ τὸ ἄσβεστον χωρήσει, ὁμοίως καὶ ὁ ἀκούων αὐτοῦ.
16:2 ですから、肉においてこれらのことを行った者たちは死にました。まして、悪い教えによって神の信仰を損なう者は、どれほどでしょうか。その信仰のために、イエス・キリストは十字架につけられたのです。そのような者は汚れた者となり、消えない火の中に行きます。その者に耳を傾ける者も同じです。
// 「神の信仰」は、福音の教えのこと（LF）。LF は「死んだ」を民数記二五・一〜九（第一コリント一〇・八）の出来事とみる。「消えない火」はマルコ九・四三の言い回し。LF・L–H は「悪い教え」を一語の κακοδιδασκαλίᾳ とする。

17.1 Διὰ τοῦτο μύρον ἔλαβεν ἐπὶ τῆς κεφαλῆς αὐτοῦ ὁ κύριος, ἵνα πνέῃ τῇ ἐκκλησίᾳ ἀφθαρσίαν. μὴ ἀλείφεσθε δυσωδίαν τῆς διδασκαλίας τοῦ ἄρχοντος τοῦ αἰῶνος τούτου, μὴ αἰχμαλωτίσῃ ὑμᾶς ἐκ τοῦ προκειμένου ζῆν.
17:1 それゆえ、主はその頭に香油を受けられました。教会に朽ちないことを吹き込むためです。この世の君の教えの悪臭を、身に塗られてはなりません。彼が、あなたがたをとりこにして、前に置かれているいのちから連れ去らないためです。
// マタイ二六・七、マルコ一四・三、ヨハネ一二・三の香油の出来事を指す。ἀφθαρσία は、16:2 の「損なう」（φθείρῃ）と対になる語なので「朽ちないこと」とした。
17.2 διὰ τί δὲ οὐ πάντες φρόνιμοι γινόμεθα λαβόντες θεοῦ γνῶσιν, ὅ ἐστιν Ἰησοῦς Χριστός; τί μωρῶς ἀπολλύμεθα, ἀγνοοῦντες τὸ χάρισμα, ὃ πέπομφεν ἀληθῶς ὁ κύριος;
17:2 なぜ、わたしたちは皆、神の知識を受けて賢い者とならないのでしょうか。神の知識とは、イエス・キリストです。なぜ、主がまことに遣わされた賜物を知らずに、愚かにも滅びていくのでしょうか。
// 神の知識がキリストであることは、コロサイ二・二を思わせる。ツァーンは χάρισμα（賜物）を χρῖσμα（油注ぎ）と推定する。A などは「遣わされた」を「苦しまれた」とする。

18.1 Περίψημα τὸ ἐμὸν πνεῦμα τοῦ σταυροῦ, ὅ ἐστιν σκάνδαλον τοῖς ἀπιστοῦσιν, ἡμῖν δὲ σωτηρία καὶ ζωὴ αἰώνιος. ποῦ σοφός; ποῦ συζητητής; ποῦ καύχησις τῶν λεγομένων συνετῶν;
18:1 わたしの霊は、十字架のためのくずです。十字架は、信じない者にはつまずきですが、わたしたちには救いであり、永遠のいのちです。知者はどこにいるのですか。論者はどこにいるのですか。賢いと言われる者たちの誇りは、どこにあるのですか。
// περίψημα（くず）は 8:1 と同じ語。「つまずき」は第一コリント一・一八、二三、ガラテヤ五・一一を思わせる。
// 「知者は…論者は」は第一コリント一・二〇（口語訳「知者はどこにいるか。学者はどこにいるか。この世の論者はどこにいるか」）の言い回しをなぞる。パウロの言葉はイザヤ三三・一八の言い換え。三つ目の問いはイグナティオスのもので、イザヤ二九・一四、ローマ三・二七を思わせる。
18.2 ὁ γὰρ θεὸς ἡμῶν Ἰησοῦς ὁ Χριστὸς ἐκυοφορήθη ὑπὸ Μαρίας κατ’ οἰκονομίαν θεοῦ ἐκ σπέρματος μὲν Δαυείδ, πνεύματος δὲ ἁγίου· ὃς ἐγεννήθη καὶ ἐβαπτίσθη, ἵνα τῷ πάθει τὸ ὕδωρ καθαρίσῃ.
18:2 実際、わたしたちの神イエス・キリストは、神の計画によって、マリヤの胎に宿られました。ダビデの子孫から出て、また聖霊から出た方です。この方は生まれ、バプテスマを受けられました。受難によって水を清めるためです。
// 「ダビデの子孫から」はローマ一・三（口語訳「肉によればダビデの子孫から生れ」）を思わせる。LF・L–H は「神の計画」の「神の」を省く。τῷ πάθει は、Lake の注によれば「身をゆだねることによって」とも訳せる。

19.1 Καὶ ἔλαθεν τὸν ἄρχοντα τοῦ αἰῶνος τούτου ἡ παρθενία Μαρίας καὶ ὁ τοκετὸς αὐτῆς, ὁμοίως καὶ ὁ θάνατος τοῦ κυρίου· τρία μυστήρια κραυγῆς, ἅτινα ἐν ἡσυχίᾳ θεοῦ ἐπράχθη.
19:1 マリヤの処女であることとその出産、また主の死も、この世の君には隠されていました。これらは、声高く告げられる三つの奥義で、神の沈黙のうちに行われたのです。
// κραυγῆς（叫びの）を、LF は宣べ伝えの叫びとみる。神の沈黙のうちに備えられ、行われ、驚く世に大声で告げられる奥義のこと。第一コリント二・八を思わせる。シリア語の抜粋の一写本は「主の死」を欠くが、LF は写し誤りとみる。
19.2 πῶς οὖν ἐφανερώθη τοῖς αἰῶσιν; ἀστὴρ ἐν οὐρανῷ ἔλαμψεν ὑπὲρ πάντας τοὺς ἀστέρας, καὶ τὸ φῶς αὐτοῦ ἀνεκλάλητον ἦν καὶ ξενισμὸν παρεῖχεν ἡ καινότης αὐτοῦ, τὰ δὲ λοιπὰ πάντα ἄστρα ἅμα ἡλίῳ καὶ σελήνῃ χορὸς ἐγένετο τῷ ἀστέρι, αὐτὸς δὲ ἦν ὑπερβάλλων τὸ φῶς αὐτοῦ ὑπὲρ πάντα· ταραχή τε ἦν, πόθεν ἡ καινότης ἡ ἀνόμοιος αὐτοῖς.
19:2 では、それは、どのようにして代々の世に現されたのでしょうか。天に一つの星が輝きました。すべての星にまさる輝きでした。その光は言い表せないほどで、その新しさは驚きを呼び起こしました。ほかの星々はみな、太陽や月と共に、その星を囲む合唱隊となりました。しかし、その星の光は、すべてにまさっていました。そして、ほかの星々に似ないこの新しさがどこから来たのかと、騒ぎが起こりました。
// 星はマタイ二・二の博士たちの星。ほかの星々が合唱隊となったことは、創世記三七・九（ヨセフの夢）から来た考えかと LF は言う。
19.3 ὅθεν ἐλύετο πᾶσα μαγεία καὶ πᾶς δεσμὸς ἠφανίζετο κακίας· ἄγνοια καθῃρεῖτο, παλαιὰ βασιλεία διεφθείρετο θεοῦ ἀνθρωπίνως φανερουμένου εἰς καινότητα ἀϊδίου ζωῆς· ἀρχὴν δὲ ἐλάμβανεν τὸ παρὰ θεῷ ἀπηρτισμένον. ἔνθεν τὰ πάντα συνεκινεῖτο διὰ τὸ μελετᾶσθαι θανάτου κατάλυσιν.
19:3 そのため、すべての魔術は解かれ、悪のすべての縄目は消え去りました。無知は取り除かれました。神が永遠のいのちという新しさのために人として現れられたとき、古い王国は滅ぼされたのです。神のもとで仕上げられていたことが、始まりました。そこから、すべてのものが揺り動かされました。死を滅ぼすことが、はかられていたからです。
// 底本の句読に従った。LF は「滅ぼされた」（διεφθείρετο）を後の付け足しとみて、「すべての魔術とすべての呪縛は解かれ、悪の無知は消え、古い王国は取り除かれた」と読む。
// 「新しさ」はローマ六・四（新しいいのちに生きる）、「死を滅ぼす」は第一コリント一五・二六を思わせる。エペソの魔術については使徒一九・一九。

20.1 Ἐάν με καταξιώσῃ Ἰησοῦς Χριστὸς ἐν τῇ προσευχῇ ὑμῶν καὶ θέλημα ᾖ, ἐν τῷ δευτέρῳ βιβλιδίῳ, ὃ μέλλω γράφειν ὑμῖν, προσδηλώσω ὑμῖν, ἧς ἠρξάμην οἰκονομίας εἰς τὸν καινὸν ἄνθρωπον Ἰησοῦν Χριστόν, ἐν τῇ αὐτοῦ πίστει καὶ ἐν τῇ αὐτοῦ ἀγάπῃ, ἐν πάθει αὐτοῦ καὶ ἀναστάσει·
20:1 わたしは、これから第二の書をあなたがたに書くつもりです。あなたがたの祈りによって、イエス・キリストがわたしをふさわしい者としてくださるなら、その書でさらに説き明かします。それが御旨であるならばです。わたしが語り始めた、新しい人イエス・キリストについての計画のことです。それは、その方への信仰と愛、その方の受難と復活にかかわる計画です。
// この第二の書が書かれた形跡はない。「新しい人」は、第一コリント一五・四五、四七の「最後のアダム」「第二の人」に当たる（LF）。
20.2 μάλιστα ἐὰν ὁ κύριός μοι ἀποκαλύψῃ, ὅτι οἱ κατ’ ἄνδρα κοινῇ πάντες ἐν χάριτι ἐξ ὀνόματος συνέρχεσθε ἐν μιᾷ πίστει καὶ ἐν Ἰησοῦ Χριστῷ, τῷ κατὰ σάρκα ἐκ γένους Δαυείδ, τῷ υἱῷ ἀνθρώπου καὶ υἱῷ θεοῦ, εἰς τὸ ὑπακούειν ὑμᾶς τῷ ἐπισκόπῳ καὶ τῷ πρεσβυτερίῳ ἀπερισπάστῳ διανοίᾳ, ἕνα ἄρτον κλῶντες, ὅς ἐστιν φάρμακον ἀθανασίας, ἀντίδοτος τοῦ μὴ ἀποθανεῖν, ἀλλὰ ζῆν ἐν Ἰησοῦ Χριστῷ διὰ παντός.
20:2 とくに、主が次のことをわたしに示してくださるなら、そうします^[この一文は本文が崩れているとみられ、『何かを示されたら』と読む説もある。]。それは、あなたがたが一人ひとり皆、御名によって、恵みのうちに共に集まっているということです。一つの信仰のうちに、またイエス・キリストにあって集まっていることです。この方は、肉によればダビデの家系から出た方で、人の子であり、神の子です。あなたがたは、乱れのない思いで監督と長老会に聞き従うために、一つのパンを裂いて集まっています。そのパンは不死の薬であり、死なないための解毒剤です。イエス・キリストにあって、いつまでも生きるためのものです。
// ὅτι を LF は崩れの印で囲み、ツァーンは τι（何か）と直して「主が何かを示されるなら」と読む。そうなら後半は「一人ひとり皆が集まりなさい」という勧めになる。
// ἐξ ὀνόματος を、LF は「名ごとに、一人ひとり」の意にとる。「イエス・キリストにあって」は G・L。テオドレトスは「一人のイエス・キリストのうちに」と引き、LF・L–H はこちらを採る。「肉によればダビデの家系から」はローマ一・三を思わせる。
// 「そのパンは」は G の ὅς。LF・L–H は ὅ（それは）と読み、パンを裂くことを受けるとも取れる。

21.1 Ἀντίψυχον ὑμῶν ἐγὼ καὶ ὧν ἐπέμψατε εἰς θεοῦ τιμὴν εἰς Σμύρναν, ὅθεν καὶ γράφω ὑμῖν, εὐχαριστῶν τῷ κυρίῳ, ἀγαπῶν Πολύκαρπον ὡς καὶ ὑμᾶς· μνημονεύετέ μου, ὡς καὶ ὑμῶν Ἰησοῦς Χριστός.
21:1 わたしは、あなたがたのために、また、あなたがたが神の誉れのためにスミルナへ遣わした人々のために、身をささげる者です。わたしは主に感謝し、あなたがたと同じようにポリュカルポスを愛しつつ、そのスミルナからあなたがたに書いています。わたしのことを覚えていなさい。イエス・キリストがあなたがたを覚えておられるように。
// ἀντίψυχον は「命の代わりの命」が原意で、身をささげる献身と愛情を言う（LF）。「人々」は g の ὧν。G・L・A は ὅν（その人）と単数。
21.2 προσεύχεσθε ὑπὲρ τῆς ἐκκλησίας τῆς ἐν Συρίᾳ, ὅθεν δεδεμένος εἰς Ῥώμην ἀπάγομαι, ἔσχατος ὢν τῶν ἐκεῖ πιστῶν, ὥσπερ ἠξιώθην εἰς τιμὴν θεοῦ εὑρεθῆναι. ἔρρωσθε ἐν θεῷ πατρὶ καὶ ἐν Ἰησοῦ Χριστῷ, τῇ κοινῇ ἐλπίδι ἡμῶν.
21:2 シリヤにある教会のために祈りなさい。わたしは、そこから縛られて、ローマへ引かれていきます。そこの信者たちの中で最も小さい者ですが、そのように神の誉れのために見いだされるにふさわしい者とされたのです。父なる神にあって、また、わたしたちに共通の望みであるイエス・キリストにあって、お元気で。
// ἀπάγομαι（引かれていく）は、処刑に引かれていく罪人に使う語。
