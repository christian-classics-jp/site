# エイレナイオス『異端反駁』の決まり

エイレナイオスは、これまでの弁証家（ユスティノス、タティアノス、アテナゴラス、テオフィロス）とは別の著者で、原文はラテン語訳である。表記と書き方の型（節の形、メモの書き方、引用の括弧）は `books/theophilus-to-autolycus/AGENTS.md` にならう。訳語はこの本で決め、ほかの本の訳語表は、同じ語を同じ意味で使うときだけ引き継ぐ。

## 抜粋の範囲

README の進捗表の 13 ページ。第五巻 33 章 3〜4 節（パピアスの言葉の引用）は `books/papias-quadratus/` で訳したので、ここでは訳さない。範囲は、ページを始めるときに分量を見て直してよい（進捗表と README を合わせる）。

## 節の形

- 巻・章・節の番号は底本（Stieren 1853）に従う。Massuet の章に、Massuet・Stieren・Harvey・ANF が共通して使う節を付けたもの。序は 0 章（`1.0.1`、第三巻と第五巻の序は `3.0.1`、`5.0.1`）。
- 底本の欄外にある「Mass. 2」「Grab. 3」は、Massuet と Grabe の刊本のページで、節ではない。起こさない。
- Harvey 1857 は章の立て方が違う（第三巻などで章番号がずれる）。Harvey の箇所を引くときは、Harvey のページで書く。
- 底本の 1 節ごとに、ラテン語の行、続けて訳の行を置く。訳の行は `1:0:1 ` のように巻・章・節の番号で始める。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 第一巻 序　…` や `# 第三巻 3 章 1〜3 節　…` の形（巻、章節の範囲、中身）。

## 底本の扱い

- 起こすのは、古いラテン語訳（Stieren の紙面で、奇数ページの上の段と、ギリシア語のない箇所の本文）だけ。紙面の下の段にある、ギリシア語を近代の編者がラテン語に訳したもの（第一巻）と、ギリシア語が残らない箇所に Thiersch が付けたギリシア語への訳し戻し（第三巻など）は、底本にも論点の根拠にも使わない。
- 本文は、IIIF で切り出した画像（`research/sources.md`）から起こし、OCR（djvu）と語ごとに突き合わせる。スキャンでは、行頭の 1〜2 字が綴じ目に隠れていることがある。その字は、Stieren の注の見出し語、OCR、Harvey の本文で確かめて補う。
- 注の番号、欄外の記号（`*`、`†`）、イタリック（聖句）は起こさない。行末で分けられた語はつなぐ。綴り（quum、caelum、ae）は底本のとおり。
- 底本の丸括弧は残す。訳では、括弧ごとで一文が 60 字を超えるときは文を分けて括弧を外す。
- ギリシア語が残る箇所（第一巻の序と 1〜21 章の多く、ほかに断片）は、エピファニオスなどの引用の読みを論点一覧で比べる。ラテン語訳とギリシア語が違い、読者の理解が変わるところだけ訳注を付ける。ギリシア語の読みは F1K（`tlg1447`、Harvey の電子化）と Stieren・Harvey の印刷で確かめる。

## 文体

- 友人（dilectissime）に宛てた書なので、地の文は敬体（「〜です」「〜ます」）。書き手のエイレナイオスは「わたし」、キリスト者全体や教会は「わたしたち」。エイレナイオスが自分のことを言う複数（nos、nobis）は「わたし」にするか、主語を出さない（テオフィロスの本と同じ）。
- 読み手（tu）は「あなた」。尊敬語は使わない。呼びかけ dilectissime は「愛する友よ」。
- 神（父、子、霊を含めて）の動作は尊敬語にする。御子・主・キリストの動作も尊敬語。テオフィロスの本の決まり（目的語のない神の動作は「お〜になる」、受け身と紛れる「〜される」を使わない）をここにも当てる。
- 異端の教師たち（ウァレンティノスの弟子など）や、彼らが立てるアイオーン・造物主（Demiurgus、Fabricator を異端の教えとして言うとき）には尊敬語を使わない。エイレナイオスが自分の信じる造り主として Fabricator／Conditor を言うときは神として尊敬語にする。
- 一文を短く切る。ラテン語の長い文は、主文の動詞を先に見つけて、従属節を「〜ので」「〜ために」「〜とき」でつなぎ、切るときも主文とのつながりを残す。
- enim は落とさない。前の文の理由を言うときは「〜からです」、話を進めるときは「実際、」。autem は対比なら「しかし」「一方」、話を移すだけなら訳さなくてよい。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。
- ut＋接続法（目的）は、文を切っても「〜ためです」で目的の意味を残し、依頼の命令に変えない。何の目的かがずれそうなときは「わたしが〜のは、」で受ける（1:0:2）。
- 主文に添う分詞（accipiens など）は「〜て」で主文の中にとどめ、切らない（1:0:3）。
- 聖句の直接の引用は、ラテン語訳の読みで違う語のほかは口語訳の文言（送り仮名も）に揃える（1:0:1 の「引き起させる」）。
- 主文に添う分詞（seminata、vitam donans）と cum＋接続法も切らない。否定の列挙の後の sed は「むしろ、」「そうではなく、」で残す。同格（sol, creatura Dei）は「〜ですが」の譲歩にしない（1:10:1、1:10:2）。
- 神とキリストの尊敬語は、目的節や連体修飾の中でも付ける（「よみがえらせてくださる」「あわれんでくださる」「お造りになった」）（1:10:1、1:10:3）。
- 一般の人を指す 2 人称単数の接続法（adinvenires）は「あなた」にせず、主語を出さない（1:10:3）。
- 底本の注が別の読みを良しとしていても、底本の読みで意味が通るとき（1.10.3 の prophetis Dei）は底本で訳し、別の読みはメモに書く。直して訳すのは、底本のままでは意味が通らないとき（1.10.3 の adesse）だけ。
- 文に組み込んだ聖句は、口語訳の文言のままのものだけ『』に入れる。ラテン語訳の読みに合わせて言い換えたもの（エペソ一・一〇、ピリピ二・一〇〜一一）は『』に入れず、本文に出典を置く（1:10:1）。
- 口語訳の語を借りた暗示（マタイ七・一五の「羊の衣」「警戒」）は本文に出典を置き、語や考えを思わせるだけのもの（第二テモテ三・六）は `// ` メモに書く（1:0:1、1:0:2）。

## 聖書の引用

- 聖書の文言どおりの引用は『』に入れて本文に出典を置く。言い換えで口語訳の語を借りたときも本文に出典を置く。語や考えを思わせるだけの暗示は `// ` メモに書く。
- ラテン語訳は、ギリシア語の聖書（旧約は七十人訳）をラテン語にした形で引く。口語訳と違うときは底本の読みで訳し、口語訳の語を借りられるところだけ借りる。違いが訳に出るときは `// ` メモに書く。
