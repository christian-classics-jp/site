# 異端反駁（抜粋）

リヨンの監督エイレナイオスの『異端反駁』（Adversus haereses、原題は『偽って名づけられた知識の暴露と反駁』）のうち、信仰の基準、使徒の伝承、四つの福音書、まとめ直し（recapitulatio）、神の栄光と人間、聖餐と復活を論じる箇所の抜粋。ラテン語訳の本文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

『異端反駁』はギリシア語で書かれたが、全体が残るのは古いラテン語訳だけで、ギリシア語は後の著作家の引用（とくに第一巻をエピファニオスが引いたもの）にしか残らない。この訳は、全体をラテン語訳から訳す。ギリシア語が残る箇所では、ギリシア語の読みを論点一覧で比べ、読者の理解が変わるところだけ訳注で示す。

底本は A. Stieren 編、*Sancti Irenaei episcopi Lugdunensis quae supersunt omnia* I（Leipzig: T. O. Weigel, 1853）のラテン語本文。パブリックドメイン。archive.org のスキャン（[sanctiirenaeiepi0001adol](https://archive.org/details/sanctiirenaeiepi0001adol)）の画像から本文を起こし、[research/stieren-1853.txt](research/stieren-1853.txt) に置いた。ページごとに、訳す範囲を起こして足していく。Stieren の紙面には、ラテン語訳のほかに、エピファニオスなどが引くギリシア語と、そのギリシア語を近代の編者がラテン語に訳したもの、ギリシア語の残らない箇所を近代の学者がギリシア語に訳し戻したものが載る。起こしたのは、古いラテン語訳だけである。

巻・章・節の番号は底本に従う（Massuet の 1710 年の刊本の章に節を付けたもので、ANF の英訳も同じ）。序には番号がないので 0 章とした（第一巻の序は `1.0.1`〜`1.0.3`）。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
