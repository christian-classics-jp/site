# 第三巻 3 章 4 節〜4 章 3 節　ポリュカルポス、文字を持たない民の信仰

3:3:4 ポリュカルポスもまた、使徒たちから教えを受け、わたしたちの主を見た多くの人々と交わっただけではありません。使徒たちによって、アジヤのスミルナにある教会の監督に立てられもしました。わたしも、若いころに彼を見ています。彼は長く生きながらえ、たいへん年老いてから、この上なく栄光ある、気高い殉教を遂げて、この世を去ったからです。彼は、使徒たちから学んだことを、いつも教えていました。それは、彼が教会にも伝えたことで^[ギリシア語の引用では『教会も伝えていること』。]、それだけが真実です。アジヤにあるすべての教会と、今に至るまでポリュカルポスの後を継いできた人々が、このことを証ししています。ポリュカルポスは、ウァレンティノスやマルキオンよりも、また、ゆがんだ考えを持つほかの者たちよりも、はるかに重みがあります。真理の証人として、いっそう信頼できるのです。実際、この人は、アニケトスのときにローマに来て、先に述べた異端の者たちの多くを、神の教会に立ち返らせました。そのとき彼は、自分が使徒たちから受けたのは、ただ一つ、この真理だけだ、と告げ知らせました。それは、彼が教会にも伝えた真理です。また、彼がこう語るのを聞いた人々もいます。主の弟子ヨハネが、エペソで浴場に行き、中にケリントスがいるのを見ると、湯を浴びずに飛び出した、というのです。そのときヨハネは、真理の敵ケリントスが中にいるので、浴場が崩れ落ちはしないかと恐れる、と言ったそうです。また、ポリュカルポス自身も、あるとき出会ったマルキオンに「わたしたちが分かるか」と言われて、「分かる。おまえはサタンの長子だ」と答えました。使徒たちとその弟子たちは、それほどの恐れを抱いていて、真理を曲げた者たちのだれとも、言葉の上でさえ交わりませんでした。パウロもこう言っているとおりです。『異端者は、一度、訓戒を加えた上で退けなさい。こういう人は、邪道に陥り、自分で自分を罪に定めていることを、知っているからである』（テトス三・一〇〜一一）。また、ポリュカルポスがピリピの人々にあてて書いた、きわめて行き届いた手紙もあります。望む人、自分の救いを心にかける人は、その手紙から、彼の信仰の特徴と、真理の宣教とを学ぶことができます。さらに、エペソにある教会も、使徒たちの伝承の真実な証人です。この教会は、パウロによって基礎を据えられ、ヨハネがトラヤヌスの時代まで、人々のもとにとどまった教会です。

3:4:1 ですから、これほどの証明がある以上、真理を、もうほかの人々のもとで探し求めるべきではありません。真理は、教会から容易に受け取ることができます。使徒たちは、金持ちが倉に預けるように、真理に属するものをすべて、余すところなく教会に納めたからです。望む人がだれでも、教会から、いのちの飲み物を受けるためです。実際、教会こそ、いのちへの入口です。一方、ほかの者たちは、みな盗人であり、強盗です（ヨハネ一〇・八）。ですから、あの者たちを避けなければなりません。そして、教会のものを、この上ない熱心さで愛し、真理の伝承をしっかりとつかまなければなりません。実際、どうでしょうか。たとえ何か小さな問題で論争が起こったとしても、使徒たちが暮らした、きわめて古い教会に立ち返るべきではないでしょうか。そして、その教会から、目の前の問題について、確かで、事実としてはっきりしていることを受け取るべきではないでしょうか。また、もし使徒たちが、わたしたちに聖書を残さなかったとしたら、どうでしょうか。教会をゆだねた人々に使徒たちが伝えた、伝承の秩序に従うべきだったのではないでしょうか。
3:4:2 キリストを信じる異国の多くの民が、この秩序に同意しています。彼らは、紙と墨によらず、霊によって心に書かれた救いを持ち（第二ヨハネ一二、第二コリント三・三）、古い伝承を注意深く守っています。彼らは、唯一の神を信じています。神の子キリスト・イエスによって、天と地と、その中のすべてのものをお造りになったかたです。キリストは、ご自分のお造りになったものへのこの上ない愛のゆえに、処女からの誕生をお受けになりました。ご自身によって人を神と結び合わせてくださいました。そして、ポンテオ・ピラトのもとで苦しみをお受けになり、およみがえりになり、栄光のうちに天に上げられました。そして、救われる人々の救い主として、さばかれる人々のさばき主として、栄光のうちにおいでになります。真理をゆがめる者たちと、ご自分の父とその来臨とを侮る者たちを、永遠の火にお送りになります（マタイ二五・四一）。文字を持たずにこの信仰を信じた人々は、わたしたちの言葉から言えば、異国の者です。しかし、考えと習わしと生き方から言えば、信仰のゆえに、この上なく知恵ある人々です。あらゆる義と純潔と知恵のうちに歩んで、神に喜ばれているのです。だれかが彼らの言葉で語りかけ、異端の者たちが考え出したことを告げたとしましょう。彼らは、その冒瀆の話を聞くことさえ耐えられずに、すぐに耳をふさぎ、はるか遠くへ逃げ去るでしょう。このように、彼らは、使徒たちのあの古い伝承によって、あの者たちの奇怪な話を、何一つ心に思い浮かべることさえしません。彼らのところには、まだ、異端の集まりもなく、異端の教えも立てられていなかったからです。
3:4:3 実際、ウァレンティノスより前に、ウァレンティノスから出た者たちはいませんでした。マルキオンより前に、マルキオンから出た者たちもいませんでした。先にわたしが数え上げた、悪い考えを持つほかの者たちも同じです。彼らのゆがんだ教えを始め、考え出した者たちが現れる前には、まったくいなかったのです。実際、ウァレンティノスは、ヒュギノスのときにローマに来て、ピオスのときに勢いを増し、アニケトスのときまでとどまりました。マルキオンより前のケルドンも、八番目の監督ヒュギノスのときに、たびたび教会に来て、罪の告白をしました。そして、最後までこのようにしていました。あるときはひそかに教え、あるときは罪を告白し、あるときは、悪く教えていたことを何人かの人に暴かれたのです。そして、敬虔な人々の集まりから遠ざけられました^[ギリシア語の引用では『自分から離れていった』。]。ケルドンの後を継いだマルキオンは、十番目に監督の務めについていたアニケトスのときに、力を得ました。一方、グノーシス派と呼ばれるほかの者たちは、わたしが示したように、シモンの弟子メナンドロスから始まりを受けました。彼らはそれぞれ、自分が取り入れた考えの父となり、その長として現れました。これらの者はみな、ずっと後になって、教会の時代がすでに半ばに来てから、自分たちの離反へと立ち上がったのです^[この一文を欠く古い写本があり、後の書き込みとする説がある。]。
