# レビュー：6〜10 章

- 日付：2026-10-31
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、`books/diognetus/AGENTS.md`（引き継ぐ訳語表）、直前のページの `jp.md`、`research/cruxes.md`（6.1〜10.5 の項目 l. 130–275 と「電子化の入力の誤りと、印刷版の誤植」l. 367–407）、Rauschen の印刷版（djvu l. 6230–6620）、ANF 第 1 巻の英訳（`cache/ccel.org/anf01.txt` の Chapter VII l. 16841–16889、VIII l. 16890–16912、III l. 16728–16768、IX l. 16913–16940、X l. 16941–16981。底本 6・7・8・9・10 章との対応も伝えた）、口語訳
- 結果：必須 2（規則違反 1、誤訳 1）、提案 25（直した案は 27 組）。27 組をすべて採り、10:5 の「告げられました」を受け身と紛れない形に直した。

| 節 | 指摘 | 採否 | 理由・直した訳 |
|---|---|---|---|
| 6:2 | διέκρινεν を、底本の編者のラテン語訳は dissolveret と取る | 採る | 6:1 の「解き崩す」（κατάλυσις）と呼応する。「すべてのものを容赦なく解き崩していたはずです」 |
| 6:3 | εὐδαιμονέω は訳語表で「幸福である」 | 採る | 「幸福であるように見える」 |
| 6:6 | ἀπέχομαι＋属格は「〜から離れる」 | 採る | 「あれからは離れよ」 |
| 6:6・7:1 | 7:1 の誤植を 6:6 のメモにまとめている | 採る | 各節のメモに分けた |
| 7:2 | 「ある人々」が πάντας と食い違う | 採る | 「次のような人々がみな憎まれるように仕向けてきました」 |
| 7:2 | 「一部ではなく」を 10:2 の「一部によって」と揃える | 採る | 「種としてのロゴスの一部によってではなく、…生きる人々がいます」 |
| 7:2 | 同じ ἐνεργέω＋μισεῖσθαι の言い方を揃える | 採る | 「その人々がはるかに激しく憎まれるように悪霊たちが仕向けても」 |
| 7:3 | λατρεύω を「仕える」とすると ὑπηρέτης と重なる | 採る | 「悪霊を祭る者たち」。訳語表の λατρεία＝「祭儀」と揃う |
| 7:4 | 「教えられました」が受け身にも読める | 採る | 「そうお教えになりました」 |
| 8:1 | 「たくらまれ」が不自然 | 採る | 「だれかのたくらみにかかり」 |
| 8:1 | ὡς＋分詞で偽りを言う形 | 採る | 「…神を敬わない者であるかのように言うのです」 |
| 8:3 | ὅτι ἀληθῆ λέγω が、申し出とのつながりを失っている | 採る | 「その証しに、あなたがたの前でもう一度問答をする用意もあります」 |
| 9:1 | だれの恐れかが曖昧 | 採る | 底本のラテン語訳も、人々が恐れから徳を行う意味に取る。「わたしたちは、人々が恐れから徳のある生き方をするように求めている」 |
| 9:1 | ἀδίκως は 9:2 の οὐκ ἄδικοι と対になる | 採る | 「不義なことになります」 |
| 9:3 | ὀρθὸς λόγος を尊敬語でキリストに決めている。訳語表と底本のラテン語訳（recta ratio）は「正しい理性」（必須） | 採る | 「正しい理性は現れて、示しています」。キリストと取る読みはメモに残した |
| 10:2 | εὕρεσις は「見いだすこと」で、10:4 の ζήτησις と分ける | 採る | 「見いだし、見つめることを通して」 |
| 10:3 | 人の働かせる λόγῳ を底本のラテン語訳は ratio とする | 採る | 「理性によって物事を見つめ」 |
| 10:3 | メモの「同じ言葉」は語形が違う | 採る | 「同じ系統の言葉」 |
| 10:4 | διὰ λόγου ζητήσεως も同じ | 採る | 「理性によって探し求め」 |
| 10:4 | ἐπίγνωσις は訳語表で「深く知ること」 | 採る | 「深く知るようにと勧めました」 |
| 10:4 | メモに論点一覧の二点（プラトンの原文の違い、使徒一七・二三）がない | 採る | メモに足した |
| 10:5 | ἐν παντί は男性形で「すべての人のうちに」（必須） | 採る | 底本のラテン語訳 in unoquoque と Otto の注に合う |
| 10:5 | 「知られていた方」の受け身が尊敬語と紛れる | 採る | 「ソクラテスも一部は知っていた方」 |
