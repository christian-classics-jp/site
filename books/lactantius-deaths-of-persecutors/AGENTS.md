# ラクタンティウス『迫害者たちの死について』の決まり

ネロからマクシミヌス・ダイアまで、キリスト者を迫害した皇帝たちがどのような最期を遂げたかを、信仰の告白者ドナトゥスに宛てて語るラテン語の書。313〜316 年ごろ、ディオクレティアヌスの大迫害が終わった直後に書かれた。前半は短く歴代の迫害者を挙げ、7 章から後は、ニコメディアで見聞きした大迫害と四帝統治の崩れを詳しく語る。

次の本の決まりを、同じ語を同じ意味で使うかぎり引き継ぐ。ここには、この本で違うところと、この本に固有の決まりだけを書く。食い違うときはこのファイルを優先する。

- 表記と書き方の型（メモの書き方、引用の括弧、底本の記号の扱い）：『オクタウィウス』（`books/octavius/AGENTS.md`）と『護教論』（`books/tertullian-apology/AGENTS.md`）。
- ローマの皇帝・官職・制度の語彙：『護教論』と『オクタウィウス』の訳語表と名前の表。
- 迫害と告白者の語彙（confessor「告白者」、confessio「告白」、stantes・lapsi の「立つ・倒れる」など）、ドナトゥスへの呼びかけ：『キプリアヌス小品集』（`books/cyprian-treatises/AGENTS.md`）。とくに『ドナトゥスへ』と『背教者について』。

## 節の形

- 章（1〜52）と節の番号は底本（Brandt–Laubmann 1897）に従う。節の番号は底本の欄外にある（奇数ページは右、偶数ページは左。反対側の欄外の 5、10、15 … は行番号）。ANF の英訳も章の番号は同じで、節の番号はない。レビューで英訳と照らすときは章と文の内容で照らす。
- 節は底本の番号どおりに切る。`tools/split-units.js` は使わない（『護教論』『キプリアヌス小品集』は節のない版なので split-units で切ったが、この本の底本には節がある）。
- 欄外の節の番号は、その節が始まる行に付いている。行の中のどこから節が始まるかは、文の切れ目から決める（『オクタウィウス』の「節の形」と同じ考え方）。たとえば 1.2 は p. 171 の 4 行目の行末の ecce から始まる。底本は節の始まりの前を、ほかの文の切れ目より広く空けて組むので、番号の付いた行に切れ目が二つあるときは、広く空いたほうから節を始める（19.3 は eo pergitur. の後の contio から）。
- 底本テキストは `research/brandt-1897.txt`。1 行 1 節で `<章>.<節> <本文>`（`1.2`）。
- 底本の 1 節ごとに、ラテン語の行、続けて訳の行を置く。訳の行は `1:2 ` のように章と節の番号で始める。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# 1〜6 章　…` の形（章の範囲、中身）。
- 底本の題（LVCII CAECILII LIBER AD DONATVM CONFESSOREM DE MORTIBVS PERSECVTORVM）は底本テキストに入れない。見出しにも出さない（書名は README から出る）。
- ページの割り（`research/pages.json`）は、全文を起こす前に、英訳の章ごとの語数（脚注を除いて計 18,000 語ほど。ラテン語は 1 章で英訳の 0.65 倍）を目安に、話の切れ目で 13 ページに分けた。序と初期の迫害者（1〜6 章）、四帝の人柄（7〜9 章）、大迫害の始まり（10〜14 章）、迫害の広がりとディオクレティアヌスの病（15〜17 章）、退位（18〜19 章）、ガレリウスの支配（20〜23 章）、コンスタンティヌスの即位とマクセンティウス（24〜26 章）、ガレリウスのイタリア侵入とマクシミアヌスの最期（27〜30 章）、ガレリウスの病と寛容の勅令（31〜35 章）、マクシミヌスの暴政とウァレリア（36〜41 章）、ディオクレティアヌスの死とミルウィウス橋の戦い（42〜44 章）、リキニウスとマクシミヌスの戦い（45〜47 章）、ミラノの勅令と結び（48〜52 章）。

## 底本の扱い

- 本を始めたときに起こしたのは 1 章（1.1〜1.7）だけ。各ページのセッションは、page-context を作る前に、そのページの章を画像（`pages.json` の `images`）から起こし、`<章>.<節> <本文>` の行にして `research/brandt-1897.txt` の末尾に足す。起こさないと page-context は空の抜粋を書き出す。最初のページ（chapter-01-06）では 2〜6 章だけを足す（1 章を二重に足さない）。
- 手順：`node tools/ocr-lines.js` で pages.json の `print` の行から本文の行を拾って下書きにし、画像を見ながら直す。本文を一度に書き出すと出力フィルターに止められることがあるので（『キプリアヌス小品集』の「底本の起こし方」）、直しは `node tools/replace.js` の短い組で当てる。直し終えたら、u と v、j と i をそろえて語の列を OCR と比べ、違いがみな OCR の読み誤りか行番号の混入であることを確かめる。どの画像をどの範囲で読んだか、OCR と違ったところは `research/sources.md` の画像の行に書き足す。
- 画像の番号：IIIF の番号＝印刷ページ−127（0044＝p. 171）。IIIF（`tools/iiif-crop.js`）は応答しないことが多い（本を始めた日は、0045 が HTTP 504、0046 は返るまでに数分かかった）。そのときは archive.org のページ画像 `https://archive.org/download/operaomniaacced01laubgoog/page/nN_w1600.jpg` を `node tools/fetch.js` で取る。N＝IIIF の番号−1（n44＝p. 172）。小さい句読点は `node tools/image.js crop` で拡大して確かめる。
- ページの組み：上が本文、その下に LOCI AVCTORVM EXPILATORVM SIMILES（借用・並行の箇所）、その下に校注。OCR は本文の行に行番号（5、10 … を lo、is などと読む）と節の番号を混ぜ、柱も崩す。
- 起こすのは本文だけ。章の番号、欄外の節の番号と行番号、柱、借用・並行の箇所、校注は起こさない。本文の中の縦線 `|`（2.4 の Mathia | ⟨et⟩、3.4 の non | modo、5.6 の ne | nimium、52.2 の dignatus est | et など）も起こさない。写本の葉の境の印で、欄外に f. 1b、f. 2a などと葉の番号が刷られている（2〜5 章の画像で確かめた）。行末で分けられた語はつなぐ。
- 底本は引用を隔字体（字間を空けた組み）で刷る（2.8 のシビュラの言葉 matricidam profugum a finibus ⟨terrae⟩ esse uenturum）。底本テキストでは字間を詰めて普通に起こし、訳では『』に入れる。
- 綴り、大文字・小文字、句読点は刷られたとおり。底本は u と v を分けずに u と刷り（Audiuit、uiolentos）、大文字は文の初めではなく固有名（Donate、Diocletianus）と章の初めの語に使い、deus、dominus は小文字で刷る。inrogare などの綴りもそのまま起こす。
- 山括弧には、写本の欠けを埋める補い（1.1、1.7、2.8 の ⟨quod n⟩efas など）のほかに、欠けのないところに編者が足した語もある（1.3 の ⟨et⟩、1.4 の ⟨precibus⟩、2.4 の ⟨et⟩、2.8 の ⟨terrae⟩、3.1 の ⟨Domitianus⟩）。どちらも下の補いの決まりで扱う。3.1 の ⟨Domitianus⟩ は、写本が名を出さないところに底本が足した名なので、訳は名を出し、`// ` メモに書く（訳注は付けない）。写本にある語を、底本が本来の場所に移したものもある（22.2 の ⟨poena⟩。写本は 22.3 の in causa の後に pena を持ち、底本はそこを [poena] として除く）。27.1 の susceptis inimicitiis も、写本で後の行に崩れた形である語を底本が直して移したもので、括弧なしで刷られているが同じく扱う。これも補いと同じく訳し、`// ` メモに写本のどこにあった語かを書く。
- 伝わる写本は一つだけ（C。パリ国立図書館 2627 番、11 世紀）で、傷みと欠けが多い。底本はその欠けを山括弧で補う（1.1 の <cotidie fundebas, ceterorumque>、1.7 の p<ostea fu>turi のように語の途中にも入る）。底本テキストでは山括弧を `⟨ ⟩`（U+27E8、U+27E9）にして起こす（『オクタウィウス』の補いの書き方）。訳は補いに従い、補いが訳の意味を決めるところ（1.1、1.7 など、写本が読めない数語をまるごと補うところ）は `// ` メモに補いであることを書く。補いが一語で文意を変えないもの（1.3 の ⟨et⟩）はメモを付けない。一語でも文意に関わるもの（1.4 の ⟨precibus⟩。ほかの刊本は gemitibus、causa などを補う）はメモを書く。
- 底本の角括弧（52.1 の [non]。校注に non del. Columbus）は、編者が取り除くべきとみた語なので、底本テキストに残して訳さず、`// ` メモに書く（『オクタウィウス』と同じ）。ほかの記号は、初めて出てくるページで校注の意味を確かめてからここに書く。
- 底本の短剣符 `†`（40.1 の praesidi † Eratineo）は、直しようのない崩れた読みを、前に十字を付けて本文に残す印（底本の正誤 p. XXXV が 40.5 について、崩れた語を十字を付けて本文に入れるより推定を採ったと言う）。底本テキストに `†` のまま残し、訳は刷られた読みで訳して、読者の理解が変わるところ（40.1 の長官の名）は訳注で本文が崩れていることを示す。`// ` メモに写本の読みとおもな推定を書く。
- 底本の `***`（35.4 の Nicomediae *** mensis eiusdem）は、写本に欠けの跡はないが、伝わるうちに語が抜けたとみて底本が置いた脱落の印（校注は medio、⟨sub finem⟩、⟨Idibus⟩ などの補いを並べる）。底本テキストに `***` のまま残し、訳は欠けた語を補わずに欠けが分かる形にして（「五月の某日」）、訳注で語が欠けていることを示す。
- 底本の句読点が文の切れ目と合わないところ（1.7 の ab re ta⟨men non⟩ est. si a principio … exponam。est の後は句点で刷られているが、si … exponam が ab re non est の条件の文）は、刷られたとおり起こし、訳は文のつながりで訳して `// ` メモに書く。
- 校注の略号：C は写本、Bal は Baluze の初版（1679）。ほかの名前（Heumann、Columbus、Brandt、Buenemann など）は推定を出した刊本の編者や学者。補いや推定の読みは、底本の読みで訳し、写本の読みが訳に関わるときだけ `// ` メモに書く。読者の理解が変わる箇所にだけ訳注を付ける。
- ANF の英訳は底本より古い刊本の本文から訳したもので、1.1 の "all the day long"（Baluze の tota die）のように、底本と違う補いや推定に従うところがある。英訳と底本の違いは訳の誤りとは限らないので、レビューでは底本の校注と照らしてから指摘させる。
- ローマ暦の日付は、『護教論』25.5 と同じく今の暦に直し、ローマ暦の形を `// ` メモに書く。2.1 の post diem decimum Kalendas Apriles は、底本の post に従って「三月二十三日の後」とし、訳注に『後』が書き誤りなら三月二十三日になることを示す（底本の校注は、著者の『神の教え』4.10.18 と比べて ante を勧める。『神の教え』のその箇所は刊本によって decimum と septimum に分かれるので、注には出さない）。執政官の名で言う年（2.1 の duobus Geminis consulibus）は、字のとおり訳し、西暦は補わない（分かるところは `// ` メモに書く）。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。告白者ドナトゥスに宛てた書で（1.1、16.3、35 章、52.5 に Donate の呼びかけがある）、『キプリアヌス小品集』の『ドナトゥスへ』と揃える。7 章から後の長い歴史の語りも敬体で通す。
- 書き手は「わたし」。書き手と読み手を含むキリスト者は「わたしたち」。読み手のドナトゥスは「あなた」で、尊敬語は使わない。呼びかけの Donate carissime は「親愛なるドナトゥスよ」（『ドナトゥスへ』と同じ）。
- 神とキリストの動作は尊敬語にする。受け身と紛れる「〜れる」「〜られる」は避け、「お〜になる」「〜てくださる」にする（「お聞きになりました」「お示しになった」「お降りになる」「起こしてくださいました」）。
- 皇帝たちには、迫害者にもキリスト者を守った皇帝（コンスタンティヌス、リキニウス）にも尊敬語を使わない（『護教論』と同じ）。
- 皇帝や人物の言葉は「」に入れる。間接話法の言葉も、だれの言葉かがはっきりしているところは「」に入れてよい（5.3 のサポルの illud esse uerum）。人物ごとの口調は、最初に出たページで決めてここに書く。
  - ペルシャの王サポル（5.3）：捕らえた皇帝をあざける尊大な常体（「これこそ本物の凱旋だ」）。
  - ディオクレティアヌス（7.10）：言い放って命じる常体（「うまくできていない。別のやり方で造れ」）。自分は「わたし」、ガレリウスは「おまえ」。退位を迫られる 18 章では、折れて嘆く常体（「そうなるがよい。それがよいというのなら」「何か悪いことが起こっても、わたしの落ち度ではない」）。
  - マクシミアヌス（ガレリウス）（9.8、14.7）：荒々しい常体（「いつまで副帝でいろというのか」「生きたまま焼かれないうちに、おれは逃げる」）。自分は「おれ」。ディオクレティアヌスに向けた間接話法の言い分（18.2、18.5〜18.6）は「あなた」で、「〜というのです」で受ける。
  - 地の文をはさまない対話（18 章のディオクレティアヌスとガレリウス）は、底本が話し手の替わりを示す — に従って割り振り、台詞ごとに地の文で話し手を補う（「ディオクレティアヌスは言いました。「…」」「「…」と副帝は言いました」）。話し手が替わるところで補いを省かない。初めに割り振りのことを `// ` メモに書く。
  - 腸卜師の長タギス（10.3）：皇帝に申し上げる敬体（「儀式が答えないのは、汚れた者たちが神事に加わっているからです」）。
  - 勅令を裂いた人（13.2）：あざける常体（「ゴート人とサルマティア人に勝った知らせが掲げられたぞ」）。
  - ウァレリア（39.4）：三つの理由を並べる間接話法の長い言い分なので「」に入れず、常体で並べて「〜というのです」で受ける。マクシミヌスは「あなた」（ガレリウスを「あなたの父」）。
  - 長い言い分や言いがかりの間接話法（11.3 のディオクレティアヌスの言い分、14.2 のキリスト者への言いがかり）と、いくつも重なる間接疑問（29.7 のコンスタンティヌスの問い）は「」に入れず、「〜というのです」で受ける。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。
- 皇帝の勅令をそのまま引く章（34 章のガレリウスの勅令、48 章のミラノの勅令）は、章全体が勅令の文なので『』に入れず、前の地の文で「次のような勅令」と受ける。勅令の文は常体（「〜である」）にし、皇帝の nos は「われわれ」とする（書き手とキリスト者の「わたしたち」と分ける）。勅令の中でキリスト者は「彼ら」「この者たち」。
- 書き手が取り立てを受ける人の声で暴君に呼びかけるところ（31.5 の unde … praestabo）は「」に入れ、`// ` メモに書く。暴君は「おまえ」と呼ぶ（「あなた」はドナトゥスへの呼び方）。
- 勅令の中で、宛先の役人と義務を負う人（キリスト者）が並ぶところは、主語を名詞で言い直す（34.5「それゆえキリスト者たちは」）。
- 地の文に挟む古典の句は、『』の後を地の文で受け、だれのことかと時制が分かる形にする（30.5「〜のようでした」、33.8「そして『…』というありさまでした」）。

## 文型の訳し方

この本のレビューで決まった型を、ここに統合して書く。

- quoque … non は「〜さえ…ない」（7.5 の haec quoque tolerari ⟨non⟩ possunt「兵士を養うための負担さえ、耐えられるものではありません」）。
- 受け身の独立奪格（9.10 の exuto socero）は、本文が言っていない行為者を補わない（「義父が位をはがれ」）。
- ガレリウスを名の代わりに ille などで受け、間にディオクレティアヌスが出るところは「婿」と言い直してよい（9.6〜9.7）。10 章から名の代わりに Caesar と呼ぶところは訳語表どおり「副帝」。ページの中で副帝のガレリウスが Caesar としてしか出ないところは、最初に出たところを「副帝（ガレリウス）」とする（17.7。もう一人の副帝コンスタンティウスと紛れるため）。
- 二組の皇帝を取り違えさせない。ニコメディアの二人（ディオクレティアヌスとガレリウス）を ipsi などで受け、近くに二人の老帝（ディオクレティアヌスとヘルクリウス）が出るところは、名で言い直す（12.3「ディオクレティアヌスと副帝は」）。furor（狂気）はディオクレティアヌスにもガレリウスにも使うので、「その狂気」と受けるときはだれのものかを書く（10.6「副帝のこの狂気」）。
- ページや段落の初めの代名詞（31.1 の ab hoc）は、名を出して始める。同じ節の中で、別々の人を同じ「この人」「彼」で受けない（31.1「ヘルクリウスから…彼の上にも」）。
- 話の筋に戻る igitur（直前の段落の結果ではないもの。32.1）は「さて」、結果を言う ergo・igitur は「こうして」「それゆえ」と訳し分ける。
- 前の内容を受ける qua re・quod cum などは落とさずに訳す（29.3 の qua re「このことで」、27.5 の quod cum timeret「それを恐れたので」）。
- uix ＋動形容詞（17.8 の uix agnoscendus）は「ほとんど〜できない」とし、「〜もできない」と言い切らない。
- multi の属格（11.3 の sanguinem multorum）は「多くの人の」とし、multus sanguis の「多くの血」（7.7）と分ける。
- 原文が同じ語を近くで繰り返して響かせるところは、同じ訳語で受ける（13.1 の propositum est edictum と 13.2 の uictorias … propositas は、どちらも「掲げられた」）。
- non modo A, sed etiam B は「A だけでなく B も」。A が重く B が軽い「〜どころか〜さえ」の形（5.7 の non modo facere, sed etiam cogitare）は「A はもちろん、B さえ」とし、「A どころか」は使わない（「A はしないで、かえって B」と読まれる）。
- 目的や務めを言う関係文（qui ＋接続法。36.4 の qui … facerent … cogerent）は、事実として言い切らず「〜することになっていた」「〜するためである」と訳す。
- nescio an は「〜かもしれない」と肯定に傾けて訳し、「〜かどうか分からない」にしない（37.6「むしろ礼を言うべきだったのかもしれません」）。
- quam ＋最上級（3.1 の quam diutissime）は、文脈が本人の意図を言っていなければ「きわめて〜」。「できるかぎり」にしない。
- 別の人々が間に出たあとで主語や持ち主を代名詞で受けるときは、名詞で言い直す（2.8 の putant の主語 quidam deliri は、間に quidam sanctorum が入るので「正気でない人々は」）。suus も、だれのものかを決めて訳す（5.6 の apud deos suos は蛮族の神々で、主語のローマ人のものではないので「その神々」）。人を「それ」「これ」で受けない（3.1 の non minor は「彼に劣らない」、20.1 の contemnebat は「この人を侮っていました」）。間接話法の中で sibi・suus が話し手と相手の別々の人を指すときは、話し手を「自分」、相手を「あなた」と分ける（39.4「あなたに忠実な妻を離縁する…あなたは同じことを、きっと自分にもする」）。目的の文の中の suus も、主語と紛れるときは名で言う（41.3「ディオクレティアヌスから受けた恩を」）。副文の主語がほかの人のときは、主文の主語を副文の中で「自分」と受けない。「〜のほうが」を使うか、名で言い直す（43.2「リキニウスのほうが…上に立てられたからです」）。
- nuncupare は、叙述の語があれば「呼ぶ」（20.3、25.5 の Augustum nuncuparet「正帝と呼ぶ」）、なければ「立てる」（25.4）。「名指す」は使わない。nuncupare（能動）と appellari iubere（使役）を訳し分ける。
- a quo の関係文（26.10 の eidem a quo acceperat）は、与え手と受け手を取り違えないよう「自分にそれを授けた当人」の形にする。「それを受けた当人」は受け取った人と読まれる。
- 同格の属格（20.4 の secundum Caesarum nomen）は「副帝という第二の名」の形にし、「副帝の第二の名」と持ち主の属格に読ませない。
- audeo（23.5 の facere ausus est）は「あえて〜した」とし、「〜しようとした」にしない。否定の nihil audebat（24.4）も「あえて何もしなかった」とし、「できなかった」にしない。中性の omnia（23.3 の si omnia defecerant）は「すべて（の手立て）」とし、人に取り違えない。
- 主語が文脈で明らかな受け身の本動詞（22.5 の licentia … adsumpta et iudicibus data）は、語の意味（取る、与える）を保ち、主語を補って能動に訳してよい（「彼は…勝手を自分のものとし、裁判官たちにも与えました」）。独立奪格の決まり（9.10）とは別。
- iusti・iustus populus は「正しい人々」「正しい民」、impii は「不敬虔な者」（ガレリウスを皮肉って言う pius は「敬虔な」で、misericors「あわれみ深い」と言い分ける。23.8）、exempla は「見せしめ」、iudex（神）は「審判者」、subiecti は「支配下の人々」。
