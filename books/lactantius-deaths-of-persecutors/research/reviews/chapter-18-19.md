論点一覧の「メインで決めること」の扱い：

- 訳注は付けなかった。18.6 の十五年（写本は XV。十二と直す推定がある）は、底本が写本の数に従い、ガレリウスの言い分の中の数なので、メモだけにした。
- 対話の話し手は、底本が話し手の替わりを示す — に従って割り振り（18.8 はガレリウス→ディオクレティアヌス、18.11 の quid ergo fiet? からはディオクレティアヌスとガレリウスが交互）、台詞ごとに地の文で話し手を補い、割り振りのことをメモに書いた（ANF は 18.11 の quid ergo fiet? と ille dignus non est … を一続きのガレリウスの言葉とする）。
- 18.1 の patri は「義父」とし、字のとおりには「父」で、正帝と副帝を父と子とも言うことをメモに書いた。
- 二人のマクシミアヌス：ヘルクリウスは 18.1 で「老いたマクシミアヌス（ヘルクリウス）」、18.7 で「老いたマクシミアヌス」、18.9 と 18.12〜18.13 は名が近くに並ぶので「マクシミアヌス（ヘルクリウス）」。ガレリウスは 18.1 で「副帝（ガレリウス）」、18.9、19.2、19.4 の Maximianus は「マクシミアヌス（ガレリウス）」、ほかは「副帝」。
- 18.5 の maiores／minores は「上位の者」「下位の者」と字のとおり訳した（18.6 の minor et extremus「下位で最後の者」と響き合う）。18.4 の nomen imperatoris は訳語表どおり「皇帝の名」で、正帝の位を言うことをメモに書いた。
- 18.2 の requiescere post labores と 19.3 の requiem post labores は「苦労の後」「休み」で受けた。
- 18.5 の ⟨non⟩ は一語でも文意を決める補いなので、メモに書いた（spe inuaserat が推定であることも）。18.12 の praefuit（写本は praebuit）、18.13 の ominis（写本は hominis）もメモに書いた。
- 18.4 のネルウァが実際には在位のまま死んだこと（エウトロピウス 8.1）、19.1 の日付（五月一日、305 年）、19.2 の町がニコメディアであること、19.5 のディオクレスが即位前の名であること、19.6 の故郷がダルマティアであることと ueteranus rex の皮肉は、メモに書いた。
- 訳語は、tribunus ordinis primi「第一級の大隊長」、scutarius「盾兵」、protector「親衛兵」、affinis「身内」、adorare「拝礼する」、signum（Iouis）「像」、milia fere tria「三マイルほど」、ueteranus rex「退役した王」、pastor「（群れを）飼う者」とした。本の `AGENTS.md` の訳語表と名前の表に足し、ディオクレティアヌスの退位の場面の口調と、対話に話し手を補う型を「文体」に書いた。
