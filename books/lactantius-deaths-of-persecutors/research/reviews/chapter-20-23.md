論点一覧の「メインで決めること」の扱い：

- 訳注は付けなかった（論点一覧も訳注の案なし）。
- 22.2 の ⟨poena⟩ は、写本の 22.3 にある語を底本が移したものなので、補いと同じく訳し、メモに写本のどこにあった語かを書いた。この種類の山括弧を本の `AGENTS.md` の「底本の扱い」に書き足した。22.3 の [poena] [et] と 20.1 の [esse] は、角括弧の決まりどおり訳さずメモにした。22.4 の ⟨prae⟩、21.7 の id exitii（写本は et exilii）、23.8 の pius（写本は impius）もメモに書いた。
- 21.8 の tamdiu. の句点は刷られたとおり起こし、訳は tamdiu … donec のつながりで訳してメモに書いた。
- 23.5 の ueteres は写本の読みで、初版が uictores と改めたことをメモに書いた（ANF は uictores に従う）。
- 訳語：filium／fratrem は「息子」「兄弟分」（四帝統治の呼び名であることをメモに）、uicennalia は「即位二十年の祝い」のまま、honores「位の特権」、decuriones「町の議員」、egregii ac perfectissimi uiri「高い位の称号を持つ人々」、gynaeceum「機織り場」（後宮と取る説もあることをメモに）、lusorium「遊び」、lancea emendabantur「槍で罰せられました」、malae artes「悪い術」（魔術を言う語であることをメモに）、iudices militares「軍人の裁判官」、adsessores「法の補佐役」、census「課税の調査」、censitores「調査官」、parentes（23.5）「先祖」。Candidianus「カンディディアヌス」とあわせて、本の `AGENTS.md` の訳語表と名前の表に足した。
- 20.2 の a tribus は「三人から」と字のとおり訳し、ガレリウスと新しい二人の副帝を言うとみられることをメモに書いた。
