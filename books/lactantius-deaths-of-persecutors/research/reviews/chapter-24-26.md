## 訳す前に決めたこと（論点一覧の「メインで決めること」）

- ガレリウスは本文で名が出ず（illi、imperator、mala bestia）、24.1 で「マクシミアヌス（ガレリウス）」と名を補い、メモに書いた。24.6〜24.7 の imperator は「皇帝」。25.1 の mala bestia は 2.7 と同じ「悪い獣」とし、メモに書いた。
- 26 章の二人のマクシミアヌスは、26.5 の exercitu Maximiani と 26.9 を「マクシミアヌス（ヘルクリウス）」、26.6 の Maximianus socer を「義父のマクシミアヌス（ガレリウス）」とした。26.7 の patri suo は「自分の父」（26.5〜26.6 で分かる）。26.10 の qui は「セウェルスは」と名で言い直した。
- 25.5 の imperatorem は訳語表の「皇帝」とし、正帝の位を言うことと四人の順をメモに書いた（9.10 の型）。25.4 の alterum は名を補わず、20.3 のリキニウスであることをメモに書いた。
- 24.3 の ⟨frustra repetierat⟩ と 24.5 の ⟨rogatus⟩ は、底本が足した語で筋を決めるので、24.3 のメモにまとめて書いた。26.11 の [ab hoc capite suos persequi.] は訳さず、メモに書いた。
- 26.2 の captiuitas は 23.1 と同じ「捕囚」、26.11 の bonam mortem は 22.3 と同じ「良い死に方」、26.7 の bis は「再び」（底本の索引で iterum）。新しい訳語（sigillum、equi publici など）は本の AGENTS.md の訳語表に足した。
