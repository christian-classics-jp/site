## 訳す前に決めたこと（論点一覧の「メインで決めること」）

- 27.1 の susceptis inimicitiis は、写本で後の行に崩れた形である語を底本が直して移したもので、22.2 の ⟨poena⟩ の型としてメモに書いた（⟨omnibus⟩ もそこにまとめた）。28.2 の ⟨ei⟩ は兵士がだれのものかを決める補いなので、1.4 の型でメモに書いた。
- 二人のマクシミアヌスは、27.1 の Herculius を「ヘルクリウス」、Maximiani を「マクシミアヌス（ガレリウス）」、28.1 の Maximianus alter を「もう一人のマクシミアヌス（ヘルクリウス）」、29.1 の Maximianum を「マクシミアヌス（ガレリウス）」、29.3 の senex Maximianus を「老いたマクシミアヌス（ヘルクリウス）」とした。28 章の senex は「老人」。
- 29.2 の Diocles は、このページで最初に出たところなので「ディオクレス（ディオクレティアヌス）」とし、メモに書いた。utroque は「二人」とし、ディオクレスとヘルクリウスと取ったことと、六人の内訳をメモに書いた。
- 29.3 の tertiam fugam は底本どおり「三度目の逃亡」とし、写本の pugnam をメモに書いた（訳注は付けない）。generi filium（婿の息子）の関係もメモに書いた。
- 29.7 の rogat 以下の三つの間接疑問は「」に入れず、「〜というのです」で受けた（11.3 の型）。
- 27.8 の nomen imperatoris は 9.10 と同じ「皇帝の名」。30.6 の uiginti annorum uota は uicennalia と同じ「即位二十年の祝い」とし、uota の語をメモに書いた。
- 28.4 の Superbus は「傲慢王（タルクイニウス）」、29.7 の Massilia は「マッシリア（マルセイユ）」とした。30.5 のウェルギリウスの二句は『』に入れ、出典をメモに書いた。二句目は「高い梁に、醜い死の輪縄を結んだ」とし、首をつったことが分かるようにした。
- 28.4 の [est] と 29.1 の [et] は訳さず、メモに書いた。名前と訳語の新しい決まりは本の `AGENTS.md` に足した。
