## 訳す前に決めたこと（論点一覧の「メインで決めること」）

- 35.4 の `***` は、このページが初出の底本の脱落の印。底本テキストに残し、訳は「五月の某日」として訳注で日付の語が欠けていることを示した（注は論点一覧の案を短くした）。mensis eiusdem は 35.1 の Kalendas Maias の月なので「五月」とし、メモに書いた。扱いは本の `AGENTS.md` の「底本の扱い」に書いた。
- 34 章の勅令は、章全体が勅令の文なので『』に入れず、33.11 の「次のような勅令」で受けた。勅令の文は常体、皇帝の nos は「われわれ」。エウセビオスの訳にある挨拶と皇帝の名はメモにだけ書いた。34.1 の parentum suorum sectam は、字のとおり「先祖の教え」とし、解釈が分かれることをメモに書いた。
- 31.1 の Maximianum alterum は「もう一人のマクシミアヌス（ガレリウス）」。31.2 の ⟨et ut⟩、31.1 の et⟨iam suae u⟩im、33.3 の m⟨otu u⟩ulneratur は、補いが文意を決めるのでメモに書いた。
- 31.5 の unde … praestabo は、取り立てを受ける人の声として「」に入れ、メモに書いた。31.6 の uotum は即位二十年の祝い。
- 32.2 の主語にガレリウスを補い、メモに書いた。32.5 の in campo Martio は「練兵場」とし、ローマのマルスの野ではないことをメモに書いた。filii Augustorum は「正帝たちの息子」。
- 33.1 の十八年目に「支配の」を補い、メモに書いた。33.4 の cancer は「腐れ」、33.6・33.9 の sedes は「尻」、33.10 の discreuerat は底本の索引に従って「ふくれ上がっていた」。33.5 の Asclepius は底本の形で「アスクレピオス」。33.4 の二人は「ピリュラの子ケイロン」「アミュタオンの子メランプス」。33.4・33.8 のウェルギリウスの句は『』に入れ、出典をメモに書いた。
- 33.11 の deum confiteri は「神を認める」とし、告白者の「告白」と分けた。34.2 の uoluntas は「強情」、34.4 の conuenticula componant は「集会所を建てる」、34.5 の iudices は「裁判官」。uenia は勅令の許しも神の許しも「許し」で受けた。
- 35.3 の妻と息子はメモにウァレリアとカンディディアヌスと書いた。訳語と名前の新しい決まりは本の `AGENTS.md` に足した。
