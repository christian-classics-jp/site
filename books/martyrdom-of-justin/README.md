# ユスティノス殉教録

殉教者ユスティノスと仲間たちがローマで裁かれ、殉教した次第を記す『ユスティノス殉教録』（Μαρτύριον τῶν ἁγίων μαρτύρων Ἰουστίνου …）のギリシア語原文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は R. Knopf 編、*Ausgewählte Märtyrerakten*（第 2 版、Tübingen: J. C. B. Mohr, 1913）の「4. Akten Justins und seiner Genossen」（pp. 16〜18）。パブリックドメイン。archive.org のスキャン（[MN41421ucmf_7](https://archive.org/details/MN41421ucmf_7)）から本文を起こし、[research/knopf-1913.txt](research/knopf-1913.txt) に置いた。この殉教録には長さの違ういくつかの形が伝わっていて、ここに訳すのは底本が載せる形である。

章の番号（1〜6 章）と節の番号は底本に従う。底本は各章の最初の文に番号を付けないので、それを 1 節とした。表題は 0 章とした。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
