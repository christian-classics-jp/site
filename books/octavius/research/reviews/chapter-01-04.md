# レビュー：1〜4 章

- 日付：2026-11-07
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、論点一覧 `research/cruxes.md` の 1.1〜4.6 の項目、ANF 第 4 巻の英訳 `cache/ccel.org/anf04.txt` l. 19954〜20100、底本の OCR `cache/archive.org/mminuciifelicis00halmgoog/mminuciifelicis00halmgoog_djvu.txt` l. 1058〜1300（校注を含む）。前のページはない（本の最初のページ）
- 結果：誤訳の指摘 2 件（2:1、3:3）、規則違反 1 件（4:2）を含む 13 件（必須 3 件）。12 件をそのまま採り、2:1 は構文の読みを採って、訳は別の形に直した。

| 節 | 指摘 | 採否 | 理由・直した訳 |
|---|---|---|---|
| 1:3 | sui desiderium を 1:1 の adfectio と同じ「慕わしさ」にしていて、sui が見えない | 採る | 「あの人を慕う計り知れない思い」 |
| 1:4 | amoribus を「恋心」と言い切っている。solus … conscius と ipse socius の対句が崩れている | 採る | 「愛のことでは、あの人だけがわたしの打ち明け相手であり、迷いの中では、あの人自身も道連れだった」 |
| 1:4 | non respuit comitem の comitem は目的語 | 採る | 「道連れのわたしを拒まなかった」 |
| 2:1 | quod est in liberis amabilius は片言（loquellam … dulciorem）の言い換えで、年ごろに係らない（必須） | 採る（訳は変えた） | 論点一覧の扱いと同じ構文の読みを採った。ただし、レビュアーの案の「片言の話しぶりもあとに残してきた」は、置いてきたものに片言を加える読みで言い過ぎと見て採らず、「それこそ子供のいちばん愛らしいところで、その片言は、つかえる舌がとぎれるからこそ、いっそうかわいらしかった」とした |
| 2:3 | 同格の amoenissimam ciuitatem と quod の理由節が一文に混ざって長い | 採る | 「とても美しい町オスティアへ行くことにした。海で水を浴びることが、…養生になるからだった」 |
| 2:4 | ut … uegetaret … subsideret は浜辺を歩いた目的 | 採る | 「…元気づけてもらうためだった。また、…味わうためでもあった」（60 字を超えたので二文に分けた） |
| 3:2 | liberum litus の「建物のない」は足した言葉 | 採る | 「もう開けた浜辺に出ていた」 |
| 3:3 | cum … tingueremus と quod … resorberet は delectati sumus の時と理由。uestigia retrahens は波が来た跡をたどって退くこと（必須） | 採る | 「足の裏を浸していると、波がかわるがわる寄せては引いたからだ。…引き返しては来た跡をたどり、また自分の中へ吸い込まれていった」 |
| 3:5 | a terrena labe の labes は「傷み、腐れ」。「湿り」は 2:3 の umores と重なる | 採る | 「地面で朽ちないよう、下に敷いた材木の上に浮かせて」 |
| 3:6 | plano situ の「平らにして」は削るようにも読める | 採る | 「平らに寝かせて」 |
| 4:2 | 疑問文が「か」で終わっていない（必須） | 採る | 「これはどうしたことか。…見えないのはなぜだろうか」 |
| 4:4 | de toto et integro mihi cum Octauio res est の「つもり」は足した言葉で、マルクスが外れる含みが落ちている | 採る | 「この件は、もう何から何まで、わたしとオクタウィウスとのあいだのことだ」 |
| 4:4 メモ | 底本の編者は ipsius をそう解釈したのではなく、istius と読みたいと校注で述べている | 採る | メモを「底本の編者は校注で、ipsius より istius（その一派の）と読みたいとし、そう説明している」に直した |

決まった訳し方は本の `AGENTS.md` に足した（疑問文の終わり方、ut・quod・cum の論理を残すこと、itaque／igitur の訳、contubernalis の 4:4 の用例）。
