# オリゲネス『殉教の勧め』の決まり

オリゲネスが、235 年、マクシミヌス帝の迫害の初めに、捕らえられた友人アンブロシオス（執事）とプロトクテトス（カイザリヤの長老）に書き送った、殉教を勧める書。同じ著者・同じ校訂者・同じドイツ語訳者の『祈りについて』（`books/origen-on-prayer/AGENTS.md`）の決まり（底本の扱い、文体、文型の訳し方、訳語表、引用、名前の表）を、同じ語を同じ意味で使うかぎり引き継ぐ。殉教の語彙は『ポリュカルポスの殉教』（`books/martyrdom-of-polycarp/AGENTS.md`）、『リヨンの殉教者たち』（`books/martyrs-of-lyons/AGENTS.md`）、『テルトゥリアヌス小品集』の『殉教者たちへ』（`books/tertullian-treatises/AGENTS.md`）、『キプリアヌス小品集』の『背教者について』（`books/cyprian-treatises/AGENTS.md`）に合わせる（「訳語表」）。ここには、この本で違うところと、この本に固有の決まりだけを書く。食い違うときはこのファイルを優先する。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。捕らえられた二人の友人に宛てた勧めの書で、『祈りについて』と揃える。書き手のオリゲネスは「わたし」、オリゲネスと読み手を含むキリスト者は「わたしたち」。オリゲネス自身も迫害の中にいて、勧めの接続法（ὑπομιμνησκώμεθα など）で自分を含めて言うところは「〜しましょう」とする。
- 読み手（ὑμεῖς。アンブロシオスとプロトクテトス）は「あなたがた」。二人のうち一人（多くはアンブロシオス）に向けた 2 人称単数と、殉教に臨む人一般に向けた 2 人称単数は「あなた」。尊敬語は使わない。
- 呼びかけ：1.1 の Ἀμβρόσιε θεοσεβέστατε καὶ Πρωτόκτητε εὐσεβέστατε は「神を敬うことに篤いアンブロシオスよ、敬虔に篤いプロトクテトスよ」（θεοσεβής は『祈りについて』2.1 と同じ「神を敬うことに篤い」。εὐσεβής は「敬虔な」で、εὐσέβεια・ἀσέβεια・ἀσεβής は「敬虔・不敬虔・不敬虔な者」）。呼びかけだけで一つの文にする。
- 神、キリスト、聖霊の動作の尊敬語、御使い・聖徒・殉教者に尊敬語を使わないこと、指示の「このかた」「そのかた」「あのかた」をひらくこと（29.1、29.5。ページの途中でも漢字に戻さない。「〜する方」の「方」と、34.19 の型の「わたしたちが告白したその方」は漢字）、受け身と紛れる「〜られる」を避けることは、『祈りについて』の「文体」に従う。聖霊（39.1 の「父の霊」）とキリストの地の文の動作も尊敬語にする（「お語りになります」「お祈りになりました」。受け身と紛れる「〜られる」は口語訳の文言の中にだけ残す）。神・キリストを「〜する方」と名詞で言うときも動詞を尊敬語にし（「お教えになった方」「お告げをお語りになる方」「お生まれになった方」「否みなさる方」「お造りになった方」。47.2 の「造られた方」は「造られた者」と読めるので使わない）、連用形でつなぐ前の動詞（「お取りになり、」「歩んでくださり、」）と、』の外で引用を受ける動詞（「知ろう』となさる」）も落とさない（6〜10 章）。太陽やロゴスの想定の言葉は、『祈りについて』15.4 と同じく常体（「〜だ」）。
- 殉教者が迫害者に向かって話す言葉（22〜27 章のエレアザルと七人の兄弟の言葉。七十人訳の第二マカバイから引く）は、『ポリュカルポスの殉教』のポリュカルポスと同じく落ち着いた常体にする（「わたしたちは、父祖の律法を犯すよりは、死ぬ覚悟ができているのだ」）。一人称は「わたし」「わたしたち」、暴君は「おまえ」（24.2 の「呪われた者よ、おまえは」）。神の動作には台詞の中でも尊敬語を使う（「よみがえらせてくださる」）。エレアザルの死の間際の言葉（22.3）と兄弟たちが互いに言う言葉（23.7）も常体。『リヨンの殉教者たち』の敬体の台詞は、手紙全体が敬体であるための決まりなので引き継がない。底本が „ “ を付けない直接の言葉（25.1、25.4、26.3〜26.4）は「」で囲み、中の „ “ は『』にする。王アンティオコスの直接の言葉はこの作品にない（26.1〜26.2 の約束と勧めは間接話法）。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。禁止は「〜てはなりません」。

## 文型の訳し方

『祈りについて』の「文体」にある文法の形の訳し方を引き継ぐ。この本のレビューで決まった型は、ここに統合する。

- ὅταν の節は、主文の出来事が起こる時を言う節として「〜とき、…する」とつなぎ、「〜ときにも…。…ときにも、そうです」と別々の場合に分けない（3.1）。
- 「見る」「知る」の中身（ὡς・ὅτι の節）は「次のことを〜」で受け、中身を地の文の断定にしない（14.1 の「次のことを見て取ることができます」）。βλέπων ὅτι のような知覚・認識の分詞の中身は、未来形の帰結まで含めて「次のことを見ているのです。…なら、…ことになります」と中身の側に入れ、帰結を地の文の断定にしない（3.1）。καταλαμβάνουσιν ὅτι も「次のことを悟っているのです」で受ける（5.5）。
- 名詞に一致する様子の分詞（4.2 の魂に係る θελούσῃ）は「〜からです」の理由にせず、「魂は、…しているのです」と様子にする。
- 読み手への ἐπίστησον μή ποτε は「考えてみてください。…ではないでしょうか」とし、中身（10.3 の、告白する者は告白され、否む者は否まれること）を問いの中に入れて、地の文の断定にしない。引用が続くときは「その言葉とは、『…』です」で受ける（5.4 と同じ）。
- 読み手に当てはめる律法の未来形（6.7 の申命記一三・四 の πορεύσεσθε … προστεθήσεσθε）は命令として「〜べきです」とし、「〜でしょう」と予測にしない。
- ἵνα の節は目的として「〜ためです」で受け、「〜からです」の理由にしない。ἢ などで続く後半も同じ節として受ける（14.5 の「父と呼ばれるためです。…はっきり言うなら、百倍の子供たちの父と呼ばれるためです」）。
- ἄν と希求法・過去形（可能・反実）は「〜ことができるでしょう」「〜ても、…だったでしょう」とし、事実の推量や実際にあったことにしない（17.1 の ἂν λέγοι「語ることができるでしょう」、ἂν εἴρητο「こう言われても、もっともだったでしょう」）。
- ὡς と未来分詞（11.1 の ὡς κοινωνήσοντες）は「〜する者として」「〜しようとして」とし、「〜からです」の理由にしない。
- 条件の節（ἐάν・εἰ）の中の状況分詞（13.2 の φιλομαθοῦντες）は条件の中に入れ（「〜し、…と願うとします」）、「あなたがたは〜しています」と地の文の断定にしない。ἀκολούθως は「当然」（13.4）。
- φανερόν ἐστιν ὅτι など「明らかだ」の中身も、台詞の中で「次のことが明らかである」で受ける（22.3 の第二マカバイ六・三〇）。
- 台詞の中で神が動作の主になる受け身（25.2 の ὑπ᾿ αὐτοῦ ἀναστήσεσθαι）は、尊敬語で「神に〜していただく」とし、「〜らされる」は使わない。
- 読み手への未来形の勧め（29.6 の、μή ποτε … λανθάνῃ に καί で続く ἐπιστήσεις）は「〜してください」とし、μή ποτε の節は「…ではないでしょうか」の問いにする（「わたしたちは何かを見落としているのではないでしょうか。…に、目を留めてください」）。
- 一つの否定が並ぶ二つの不定詞をまとめて否定するところ（29.6 の οὐ … ἔστι … λέγειν … καὶ … φάσκειν）は、「同じ人が、…を言い、…を言い切ることは、できません」と否定を一つにまとめ、後半を地の文の断定にしない。引用が長いときは「一方は、『…』です。もう一方は、『…』です」で並べる。
- ὡς と名詞・形容詞（29.11 の ὡς ὁσίοις）は「〜として」とし、「〜なので」と理由の断定にしない。
- 感嘆の οἷον ἐστι とその主語の不定詞（32.3）は「なんということでしょう。…とは」と、先に感嘆を出して中身を「〜とは」で受ける。中身を「〜のです」と言い切りにしない。
- 前の文の理由を言う γάρ は、文を分けるときも「というのも」などで残す（31.2、42.2 の εἰ γάρ、44.4 の σκοποῦμεν γάρ）。ποῖος οὖν の問いの οὖν も「それなら」で残す（42.2）。ὡς … οὕτως καί は「それと同じように、…も」と並べにし、「そのようにして」と手段にしない（42.3）。列挙の中の καὶ τοῦτο は「これもまた」とし、強調の「これこそ」にしない（33.4 のヨブ三一・二八）。
- 後ろに続く引用を指す ταῦτα（34.8。34.9 の τὰ δὲ ῥητὰ οὕτως ἔχει で受ける）は「次の」とし、「これらの」と前を指すようにしない。
- キリストが受ける本当の受け身（34.19 の ὁ ὁμολογηθείς）は、尊敬語の「〜された方」と紛れるので、「わたしたちが告白したその方」と能動で言い換える。神・キリストが主語の動詞は、受け身と紛れない尊敬語にする（34.18 の「投げ込みなさる」「お勧めになる方」）。
- 書き手がすでに書いたことを言う完了の不定詞（27.2 の παρατεθεῖσθαι）は「〜ておきました」と済んだこととして訳す。
- εἴπερ で聖句を受けるところ（35.4 の第二コリント一〇・一八）は「『…』とあります。そうであれば、」とし、「とします」の仮定にしない（7.1 と同じ）。3 人称の命令（35.2 の ὑπομιμνησκέσθω）は「〜べきです」。命令法に添う分詞（37.6 の πειθόμενοι ὅτι）は「…と信じてください」と二つ目の勧めに分ける。
- εἰ μέν などが出す前提は、聖句が役に立つという当然の内容でも「〜とします」で受け、帰結（οὖν）は「それなら」とする（39.4〜39.5。35.5 と同じ）。μή ποτε の問いの中の ἵνα の節は「〜ためではないでしょうか」と問いのまま分け、「すなわち…ためです」と断定で言い直さない（39.7）。同じ分詞を καί で繰り返すところ（39.6 の βαρούμενον … καὶ βαρούμενον）は、二つとも同じ名詞（良心）にかけ、主語を入れ替えない。
- 問いの直後に来る ἵνα の目的（47.5。47.4 の「なぜためらうのか」の後の、船出することの目的）は、「そのように船出するのは、…ためです」と何の目的かを主語で示し、問いへの答え（理由）に読まれないようにする。ἵνα の節の中の冠詞付き不定詞（48.4 の πρὸς τὸ μὴ πεσεῖν …）は「〜ことによってです」と節の中に入れ、地の文の断定にしない。τάχα の文を分けるときは、後に続く属格独立にも推量（「〜でしょう」）を残す（50.2）。
- 修辞疑問の主語に付く仮定の分詞（2.2 の λογισάμενος）と、比べる文の一方を仮定として出すところ（5.7）は、「〜人がいるとします」「〜ことがあるとします。それよりは…」で受ける（『祈りについて』17.2、31.3 の型）。原文にない「考えてみてください」は足さない。

## 引用

- 聖書の引用、言い換え、暗示の扱いと出典の書き方は『祈りについて』の「引用」に従う。底本の „ “ は『』に入れる。
- 22〜27 章の第二マカバイ六〜七章の引用は、出典を `（第二マカバイ七・九）` の形で書き、章節の番号は Swete に従う。文言の扱いは下の 22〜27 章の項。
- 口語訳にない書の引用は、七十人訳（Swete）から訳す（『祈りについて』と同じ）。
- 1.1 のイザヤ二八・九〜一一 は、1〜2 章の論がすべて七十人訳の語（患難に患難、望みに望み、なお少し、くちびるのあなどり、ほかの舌）に立ち、口語訳（ヘブル語からの訳）にその語がないので、メモだけでなく訳注「イザヤ書のギリシア語訳の句。ヘブル語からの訳では『教訓に教訓』。」を付けた。七十人訳との違いが論の全体にかかるところだけ、このように訳注にする。
- 口語訳の語を七十人訳や論に合わせて一部替えるときは、同じ句の残りの語（動詞など）も七十人訳の意味に合っているかを確かめ、替えたらメモに書く（4.3 のイザヤ五一・七 は「ののしり」を「あなどり」に、「驚いてはならない」を μὴ ἡττᾶσθε に合わせて「屈してはならない」に替えた）。七十人訳に替えた文言には口語訳の表記を持ち込まない（3.2 の『神の御顔の前に現れる』）。語を一つ替えても、文末の敬体・常体など口語訳の文体は保つ（31.4 の詩篇九二・一三『…花を咲かせます』）。
- 5.5 のローマ一〇・一〇 は、オリゲネスが ὁ θεός を主語に入れ「このような人々によって神が信じられ、告白される」と読むので、口語訳の文言（『信じて義とされ』『口で告白して』『救われる』）を下敷きにし、神を目的語に置いて読みを示す（「このような人々こそ、神を『心に』『信じて義とされ、口で告白して』『救われる』のです」）。続く 5.6〜5.7 の引用も同じ文言で引く。
- オリゲネスが同じ聖句の文言を引いて比べるところ（6.3 の民数記二五・二 の「娘たちの偶像を拝した」と、6.4 の「そして、娘たちの偶像に仕えた」とは言われていない、という比べ）は、文字まで揃える。
- 6.7 の申命記一三・四 は、オリゲネスが αὐτῷ προστεθήσεσθε を「ご自分に加える方」と言い換えるので、口語訳の「彼につき従わなければならない」を『彼に加えられる』に替える。9.1 のコロサイ一・一五 は、訳語表の「長子」で『すべての造られたものの長子』とする（口語訳は「すべての造られたものに先だって生れたかた」）。10.4 のルカ六・三八 は、オリゲネスの語順で『ゆすり入れ、おし入れ、あふれ出るまでに』とする。
- 5.1 の創世記一二・一 は、オリゲネスが γῆ を「全地から出よ」に掛けるので、口語訳の「国」を「地」に替える（『あなたの地を出よ』）。神の想定の言葉「全地から出よ」は「」で囲む（『祈りについて』の型）。

- 12 章の福音書の引用は口語訳の文言を下敷きにし、底本の引用が口語訳と違うところは底本に従ってメモに書く（12.2 のマタイ一六・二五 の後半はルカの形で「救う」、12.4 のルカ九・二三 に「日々」がない、12.6 のマルコ八・三五 に「わたしのため」「自分の魂を」がない）。導入の地の文が引用の中にあるところ（ルカ九・二三、マルコ八・三四）は、「」を入れ子にせず、「ルカは、イエスが『みんなの者に言われた』ことを、こう書いています。『…』」の形にする。
- 口語訳の文言をそのまま引く聖句は、口語訳の文の切れ目（14.2 の「〜座につく時には、」、14.3 の「〜を受け、また」）を保ち、60 字を超えても文を分けたり順を入れ替えたりしない（14.2〜14.3 のマタイ一九・二八〜二九、17.1 のヨシュア記二四・一五。16.2 の、14.3 の句に「妻」を足した仮定の句も同じ）。verify の 60 字の WARN は、この場合だけ認める。
- 『』の範囲は底本の „ “ に合わせ、底本が „ “ の外に置く語は、聖句の中の隣の語でも』の外に出す（13.5 の ἐλευθερωθῇ、15.1 の『もろ刃のつるぎよりも』鋭い）。7.8 と 13.5 のローマ八・二一 は『滅びの／敵のなわめから』解放されて、『神の子たちの栄光の自由に』入る。
- 14.2 のマタイ一九・二八 は底本の「神が」（福音書は「人の子が」）で訳し、訳注「福音書の本文では『人の子が』。」を付けた。福音書の地の文（「イエスは彼らに言われた」）は底本の „ “ に合わせて『』の中に置き、オリゲネスの挿入は（ ）で残す。16.1 の「妻は数え入れられていない」には訳注「ルカ福音書では『妻』も挙げられている。」を付けた。16.2 の、底本が „ “ に入れない仮定の句は「」で囲み、14.3 の句と文字まで揃える（「おおよそ、」から）。
- 14.6 の創世記一五・一五、15.1 の箴言二三・五、17 章のヨシュア記二四・一四〜一八 と第一サムエル二・二五 は七十人訳（底本）に合わせ、口語訳の文言は合うところだけ使ってメモに書く。ヨシュア記の民の言葉は口語訳と同じ「われわれ」。
- 18.1〜18.2 の θέατρον は訳語表の「劇場」で通し、第一コリント四・九 は『わたしたちは、全世界に、御使いにも人々にも劇場とされた』とする（口語訳の「見せ物」「天使」を替える。『祈りについて』28.3 と同じ）。
- 18〜21 章の七十人訳の引用のうち、論が七十人訳の語に立ち、口語訳で開くと句が見つからないか意味が逆になるところに、1.1 の型で訳注を付けた：18.6 のイザヤ一四・九〜一〇（18.5〜18.9 のイザヤ一四章の引用全体を受ける。「イザヤ書のギリシア語訳の句。ヘブル語からの訳とは文言が違う。」）、20.1 の詩篇四四・一八（「詩篇のギリシア語訳の句。ヘブル語からの訳では『道を離れませんでした』。」）、21.1 の箴言七・一 の後の句（「箴言のギリシア語訳にだけある句。ヘブル語からの訳にはない。」）。七十人訳と口語訳で意味の筋が同じところ（18.10 の列王紀上一八・二一、19.2〜19.3 の詩篇四四・一七〜一八、20.1 の四四・二〇〜二一）は口語訳の文言で引き、違いはメモに書く。詩篇の章節は口語訳の番号で書き、七十人訳の番号はメモに書く。
- 22〜27 章の第二マカバイの引用は、底本の „ “ の中の文言（オリゲネスの言い換えを含む）で訳し、七十人訳との違いはメモに書く。オリゲネスが言い換えて „ “ を付けない言葉と、物語を言い換えた地の文にも出典を付ける（25.1 の七・一一、26.4 の七・三〇、23.3 の七・三）。Swete の本文は第二マカバイではアレクサンドリア写本で、オリゲネスの文言はヴェネツィア写本と合うところも多い。底本の „ “ が語ごとに細かく分かれるところ（23.5、26.1）は、日本語の語順に合わせて『』をまとめてよい。60 字を超える „ “（22.2 の六・二三）は、『』を分けて文を切る。地の文の暗示（24.1 の知恵の書三・六、23.6 の詩篇三四・一五、27.1 のダニエル書のギリシア語訳三・五〇）は本文に出典を書かず、メモに書く。25.2 のダニエル一二・二 は句がそのまま入るので出典を付けた。
- 27.3 の詩篇一一八・一四 は口語訳の『主はわが力、わが歌』、ピリピ四・一三 は口語訳の文言に第一テモテ一・一二 の「わたしたちの主キリスト・イエス」をつないで『わたしを強くして下さるわたしたちの主キリスト・イエスによって、何事でもすることができる』とする（口語訳の「下さる」は引用なので残す）。
- 28〜29 章の詩篇一一六・一二〜一五（七十人訳一一五・三〜六）は七十人訳（底本）の形で訳す。一二節はオリゲネスが問いと答えとして読むので『わたしは主に何を報いようか』、一三節は 28.5 の ὁ λαβών とつなぐため『救の杯を受けて』（口語訳「あげて」）、一五節は『主のきよい者たちの死は』（口語訳「聖徒」）。地の文の「第百十五篇」は底本どおり。『救の杯』は口語訳の表記で、底本が „ “ に入れるので地の文でも『』の中に置く。詩篇二七・一〜三（七十人訳二六篇）は、一節と三節の前半を口語訳の文言、二節（「わたしの肉を食らおうとして」）と三節の後半（「その中でわたしは望みをいだく」）を七十人訳から訳す。訳注は付けない（口語訳で開けば句が見つかり、意味の筋が逆にならない）。
- 地の文が直前の聖句の語を一つずつ当てはめるところ（29.4〜29.5 の詩篇二七・一〜三）は、引用の訳の語をそのまま使う（「だれをもおじ恐れなさらなかった」「このかたを攻めて陣営を張った」「いくさが起ってこのかたを攻めた」「望みをいだいていた」）。28.4 の συγκαθίσει も、28.3 の「すわりたい」を受けて「共にすわり」とする。同じページで出典を付けた聖句を論の中で引き直すときは、出典を繰り返さない（29.10 の詩篇一一六・一三。『祈りについて』と同じ）。
- 28.3 の杯の問いは、文言の合うマルコ一〇・三八 で引き、出典もマルコにする（底本の欄はマタイ二〇・二二）。ゲツセマネの祈りは、底本の形に合わせて口語訳の三つの福音書の文言を使い分ける。マタイ二六・三九 は底本に μου がないので『父よ、もしできることでしたらどうか、この杯をわたしから過ぎ去らせてください』（29.1、29.6、29.7 で同じ）、28.4 の混ざった形は「父よ、もしできることでしたら」と、マルコの「取りのけてください」「わたしの思いではなく」をつなぐ。29.6〜29.9 の論は三つの福音書の「この杯」に立つので、引用はどれも「この」を保ち、29.8 の丸括弧の想定の言葉だけ「この」を除いて「」で囲む。28.5 のヨエル二・三二 は、詩篇一一六・一三 の「み名を呼ぶ」とつながる口語訳ヨエル書の「呼ぶ」で引き、出典は欄どおり `（ヨエル二・三二、使徒二・二一、ローマ一〇・一三）`。
- 30〜33 章：エステル記のギリシア語訳にだけある部分（33.2 のエステル四・一七、Swete C 七）と、ベルと竜の話（33.3。底本は „ “ を付けないので出典は本文に書かず、メモに節を書く）には、『祈りについて』の型で訳注を付けた（「エステル記のギリシア語訳にだけある部分の言葉。」「ベルと竜の話は、ダニエル書のギリシア語訳にだけある。」）。33.2 の „ “ の外の Ἰσραήλ は θεοῦ にかけて「イスラエルの『神の栄光の上に…』」とする。知恵の書の „ “ の引用（32.3 の一五・一〇）は `（知恵一五・一〇）`。複数の箇所が合わさった引用は出典を並べる（32.3 の `（エレミヤ一六・一九、一四・二二）`）。底本が „ “ に入れない七十人訳の句（32.2 の「異邦人の偶像は悪霊ども」）は本文に出典を書かず、メモに書く。32.3 の χρηστός／Χριστός の言葉遊びは『祈りについて』の型で片仮名の音を添える（「負いやすい（クレーストス）キリスト（クリストス）のくびき」）。31.4 の詩篇九二・一三 は、直前の「花」を受けるので口語訳の「栄えます」を「花を咲かせる」に替える。33.4 のヨブ三一・二七〜二八 は七十人訳から訳し、底本が εἰ を欠いても条件の筋（「〜したなら」）で訳す。
- 34 章の福音書の引用は 12 章の型で口語訳の文言を下敷きにし、底本の形が違うところだけ替えてメモに書く（34.6 のルカ二一・一四 の「前もって」を除く、34.7 の二一・一九 を命令形「かち取りなさい」、34.11 のマタイ一〇・二九〜三〇 を「天にいます父」「頭の毛は」、34.16 のマルコ八・三八 の「この」を除く）。底本が福音書と同じ語のところは口語訳の語を保つ（34.7 の「自分の魂」）。福音書の地の文が „ “ の中にあるマタイ一〇・五 は 14.2 の型で『』の中に置く。34.5 のマタイ一〇・二三 の、福音書の標準の本文にない後半の句は、底本どおり訳してメモに書いた。34.16 の、マタイとルカに共通する句だけを引く『からだを殺す者どもを恐れるな』（34.18 の正誤表の『からだを殺す者ども』も同じ）は、句だけを訳す。ルカ一二・四 の全体などを引き直すところは文字まで揃え、出典は繰り返さない。34.17 の正誤表の „τὴν ψυχὴν“ „ἀποκτεῖναι“ は『魂を殺す』とまとめる。34.18 のイザヤ四三・一〇 は七十人訳から訳し、1.1 の型で訳注「イザヤ書のギリシア語訳の句。ヘブル語からの訳には『わたしも証人』がない。」を付けた。34.19 の οὐ θεῶν は、9.1 の申命記三二・二一 と揃えて「神でもない者たち」。
