# オリゲネス『グレゴリオスへの手紙』の決まり

オリゲネスが弟子のグレゴリオスに、ギリシア人の学問を聖書の解き明かしに役立てるよう勧め、聖書を読むことと祈ることに心を向けるよう励ます短い手紙。同じ著者の『祈りについて』（`books/origen-on-prayer/AGENTS.md`）の文体、尊敬語の型、文型の訳し方、訳語表、引用の扱い、名前の表を引き継ぐ。そこにない決まりと、この本に固有の決まりだけをここに書く。食い違うときはこのファイルを優先する。

## 節の形

- 節（1〜4）は底本（Robinson 1893）の『フィロカリア』13 章の節番号に従う。底本テキスト（`research/robinson-1893.txt`）のラベルは `1.1`〜`4.1`。節の中を分けていないので、小数点の後ろはすべて `.1`（道具の都合で付けたもので、底本にはない）。
- 底本の 1 行ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `1:1 ` のように番号で始める。節と節のあいだに空行を一つ入れる。
- 底本テキストの各行の頭にある「1. 」〜「4. 」は印刷版の節番号で、底本の行の一部として残す。訳の行には付けない（訳の行の番号で示される）。
- 見出しは `# 1〜4 節　…` の形（範囲、中身）。書名は README から出るので、見出しに書名を繰り返さない。
- 13 章の頭の題（Πότε καὶ τίσι τὰ ἀπὸ φιλοσοφίας μαθήματα χρήσιμα εἰς τὴν τῶν ἱερῶν γραφῶν διήγησιν, μετὰ γραφικῆς μαρτυρίας.）は『フィロカリア』の編者が付けたもので、オリゲネスの手紙の一部ではない。電子化では `<head>` に入って文字が崩れており、`tei2labeled.js` も落とすので、底本テキストに入れず、訳さない（『祈りについて』の表題と同じ扱い）。題があることと、その中身は README に書いた。読み比べる ANF もこの題を訳していない。
- 読み比べる ANF の英訳は手紙を 3 節に分ける。ANF の 1 節が底本の 1 節、ANF の 2 節が底本の 2〜3 節（底本の 3 節は「And why should I go on」から）、ANF の 3 節が底本の 4 節に当たる。レビューでは番号で突き合わせず、本文で突き合わせる。
- 全体で約 840 語なので、1 ページ（`01-letter`）にした。

## 底本の扱い

- 電子化（First1KGreek）は OCR から起こしたもので、入力の誤りが多い。いま見えているもの：2.1 の `γῃαμμένον`（γεγραμμένον）・`προσόπου`（προσώπου）、4.1 の `εἶςεν`（εἶπεν）・`ἀναγινόσκοντες`、1.1 の `γρηγόριε`（印刷版は大文字の Γρηγόριε）と `σύνεσιν.`（印刷版はコンマ）、行末の分かち書きの跡（1.1 の `χριστιανι· σμόν`、4.1 の `ἀναγνώ σει`）。底本の行は直さず、照合の表（`research/collation/01-letter.md`）に書き、訳は印刷版の読みで行う。語が変わるものは `// ` メモに書く。句読点は『祈りについて』と同じく画像で一つずつ確かめ、印刷版の句読点で構文を取る。
- 印刷版の画像はトロント大学のスキャン（`philocalia00origuoft`、leaf ＝ ページ＋58、pp. 64〜67 ＝ IIIF 0122〜0125）。その OCR はギリシア文字で読まれているが崩れが多い。リレーの進捗表が挙げた 2024 年のスキャン（`philocaliaoforig0000orig`）は、OCR がギリシア文字をラテン文字に化けさせていて本文の照合に使えず、IIIF の画像も返らなかった。序の略号表と正誤表を読むときだけ使う（`research/sources.md`）。
- 印刷版の欄：欄外に写本の略号（ABC。この手紙の部分は 3 写本）、聖書の箇所、Delarue 版第 1 巻のページ（31、32）と行番号があり、どちらの側に出るかはページによって入れ替わる。下に異読の欄（行番号つき）。異読の欄の略号は序の表による：A ＝ Patm. 270、B ＝ Ven. 47、C ＝ Paris. Suppl. 615、E ＝ Ven. 48。「Ru. I. 30」は Delarue（Ruaeus）版第 1 巻 p. 30、「Tarinus」は J. Tarin の刊本（Paris, 1618。序の OCR l. 148）。電子化は p. 67 の異読の欄（4 節の 2 項）を落としているので、論点一覧は画像で読む。
- 2.1 の αὐλαῖαι は、写本の αὐλαί を Tarin の推定で直した読み（異読の欄）。底本の読みに従って訳し、論点一覧に記録する。
- 正誤表（序の後）に pp. 64〜67 の項はない。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。『祈りについて』と揃える。書き手のオリゲネスは「わたし」、オリゲネスとグレゴリオスを含むキリスト者は「わたしたち」。書き手ひとりを指す 1 人称複数（3.1 の ὡς ἀποδεδώκαμεν）は「わたし」（『祈りについて』と同じ）。
- 読み手のグレゴリオス（σύ）は「あなた」。尊敬語は使わない。父が子に向けるように語る手紙（4.1 の「父としての愛」）なので、命令は「〜なさい」、願いは「〜ように」とし、へりくだりすぎない。
- 呼びかけの κύριε（1.1 の κύριέ μου σπουδαιότατε καὶ αἰδεσιμώτατε υἱὲ Γρηγόριε、4.1 の κύριε υἱέ）は、手紙での丁寧な呼びかけで、「主」と訳さない（神・キリストの「主」と紛れる）。1.1 と 4.1 で同じ「敬愛する」で受ける（「このうえなく熱心で…敬愛するわが子グレゴリオスへ」「敬愛するわが子よ」）。σπουδαιότατε καὶ αἰδεσιμώτατε は二語とも最上級なので、「このうえなく」を両方に付ける。
- 冒頭の挨拶（Χαῖρε ἐν θεῷ … παρὰ Ὠριγένους）は手紙の書き出しの定型。挨拶だけで一つの文にする。
- 神、キリスト（救い主、イエス）、神の霊の動作は尊敬語（『祈りについて』の型）。神の口から出た言葉（2.1 の ἐκ προσώπου τοῦ θεοῦ）も同じ。
- 文型は『祈りについて』の「文体」に従う。とくに、διά＋対格は「〜のゆえに」（3.1 の διὰ τὴν τοῦ θεοῦ σοφίαν「神の知恵のゆえに」）で、διά＋属格の「〜によって」と分ける。添加の καί は掛かる語に「も」「もまた」を付け（1.1 の「哲学そのものについても」、4.1 の「祈りもまた」）、「こそ」に強めない。Καὶ τί で始まる修辞疑問（3.1）は逆接にせず「それにしても」。φιλοσόφων παῖδες（1.1）は慣用で「哲学者たち」。
- οὐ μόνον … ἀλλὰ καί が二つの聖句を一まとめに受けるところ（4.1 の『門をたたけ…』、『捜せ…』）は、聖句を別々の否定に割らず一文に置く。そのため 60 字を超えてもよい。

## 引用

- 『祈りについて』の「引用」に従う。底本の印刷版には引用符がない（電子化にもない）。聖句の文言どおりの引用は『』に入れて出典を置き、言い換えと暗示は出典を置くかメモに書くかを『ギリシア人への勧め』の「引用」で決める。底本の右の欄外の聖書の箇所（Ex xi 2、xii 35 f.、xxvii 16、1 Reg xi 14 ff.、xii 28 f.、Jn x 3、Mt vii 7、Lc xi 9、He iii 14）は、出典を決める手がかりにする。
- 底本の欄の「1 Reg」は口語訳の列王紀上。出典は口語訳の書名と番号で書く（`（列王紀上一一・一四〜二二）`）。
