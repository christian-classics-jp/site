## 訳す前に決めたこと（論点一覧の「メインで決めること」）

| 論点 | 決めたこと | 理由 |
|---|---|---|
| 1.1 ποιητικῶς δέ の句読点 | 底本どおり δέ の後で文を切り、「目的としてはキリスト教のために、また、それを生み出す手段としても、です」。Koetschau 1894 の切り方はメモに書いた | 本の AGENTS.md の「印刷版の句読点で構文を取る」。どちらの切り方でも論の筋は同じ |
| 呼びかけの κύριε | 「敬愛する」（1.1、4.1） | 「主」と紛れない、父から子への丁寧な呼びかけ |
| 2.1 の出典 | 言いつけの場面を（出エジプト三・二二、一一・二）、奪い取った記事を（出エジプト一二・三五〜三六）と分けて置いた | γειτόνων καὶ συσκήνων の文言は三・二二 にいちばん近い。口語訳の一一・二 には「衣服」がなく、一一・二 だけでは読者が引いて「衣服」を見つけられない |
| σκεύη | 「器」（口語訳は「飾り」）。メモに書いた | 後の「聖なる器」（τὰ σκεύη τὰ ἅγια）へ論が続く |
| ἐπίθεμα | 「ふた」 | オリゲネスは贖罪所と別に数える。七十人訳で二語が一つの物であることはメモに書いた |
| καταπέτασμα / αὐλαῖαι | 「垂幕」／「幕」 | 口語訳では両方「幕」になりうるので、出エジプト二六・三一 と二六・一 の語で分けた |
| ῥαφιδευτῶν, συρραπτῶν | 「刺繍した」「縫い合わせた」とし、動詞のない文に「縫い合わせた」を補った | ῥαφιδευτής は七十人訳二七・一六 の語。口語訳の「色とりどりに織った」では七十人訳の語が見えない |
| 金の子牛の台詞の θεοί | 「神々」（口語訳は単数の「神」）。出典は（列王紀上一二・二八、出エジプト三二・四）と並べた | 七十人訳の複数で、二つの子牛と応じる。二つの書の混ざった形 |
| ハダデとヤラベアム | 訳注「金の子牛を造ったのはヤラベアム王。オリゲネスは二人の話を重ねている。」 | 聖書を知る読者が訳の誤りと取りかねない。Swete I の王国の書三 一一・一四（Ἀδὲρ τὸν Ἰδουμαῖον）、一一・一八、一二・二八〜二九 を OCR で確かめ直した |
| τελευταῖα | 「最後の境」 | 「最後の（くじ）」と「いちばん端の」の両方に取れる日本語にした |
| ἀνάπλασμα | 「作りもの」（AGENTS.md の案は「作りごと」） | 金の子牛の像と異端の考えの両方を指す |
| Μέτοχοι τοῦ θεοῦ γεγόναμεν | 「」に入れ、出典を置かない | 聖句ではなく、ヘブル三・一四 をなぞったオリゲネスの言葉。『』だと聖句に見える |

照合で意味の変わる入力の誤りとされた 7 か所（2.1 の ᾗ・ἧς、3.1 の οἷς・ὁ・αἱρετικά、4.1 の ἣν・εὖ）と句読点の 4 か所は、印刷版の読みで訳し、メモに書いた。

## AGENTS.md に統合したこと

- 「文体」：κύριε は「敬愛する」、二つの最上級に「このうえなく」。διά＋対格、添加の καί、Καὶ τί、φιλοσόφων παῖδες の訳し方。οὐ μόνον が二つの聖句を受ける文の長さの例外。
- 「訳語表」：Ἕλληνες／Ἑλληνικός の分け方、幕屋の布（垂幕・幕・ふた・刺繍する者・細工）、ἀνάπλασμα「作りもの」、νοῦς「意味」。
