# オリゲネス『祈りについて』の決まり

オリゲネスが、アンブロシオスとタティアネの問いに答えて、祈りとは何か、何をどう祈るかを論じ、主の祈りを句ごとに説き明かす書。同じアレクサンドリアの神学の語彙は、クレメンスの『ギリシア人への勧め』（`books/clement-protrepticus/AGENTS.md`）と『救われる富者とは誰か』（`books/who-is-the-rich-man/AGENTS.md`）の訳語表と文体の型（γάρ、μὲν οὖν、否定の後の ἀλλά、命令、分詞、一文の短さ）を引き継ぐ。そこにない決まりと、この本に固有の決まりだけをここに書く。食い違うときはこのファイルを優先する。

主の祈りの訳（「主の祈り」の節）は、あとで訳すテルトゥリアヌスの『祈りについて』（tertullian-treatises）とキプリアヌスの『主の祈りについて』（cyprian-treatises）がこの表に揃える。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。アンブロシオスとタティアネに宛てた書で、クレメンスの二つの本とも揃う。書き手のオリゲネスは「わたし」、オリゲネスと読み手を含むキリスト者は「わたしたち」。書き手ひとりを指す 1 人称複数の動詞（εἴπομεν、εὕρομεν、παρετηρήσαμεν）も「わたし」とし（3.2〜3.4）、受け身の動詞に付く書き手の ἡμῖν（14.1 の ἡμῖν ἑρμηνευθέντων、14.5 の ἡμῖν νομίζεται）も「わたし」とする。人一般のならいを言う ἡμῖν・ἡμῶν（「わたしたちのふだんの意味」）は「わたしたち」で分ける。
- 他の人の見方として出す μή ποτε（「もしや…ではないか」）は「〜ではないでしょうか」で受け、その見方の終わりを「〜のだ、と。」で閉じる（4.2）。文を分けても、見方の範囲を先に閉じない。他の人々の論を、その人々の声で何節にもわたって紹介するところ（5.2〜5.5 の祈りを退ける人々の論）も同じで、「〜の論は、次のようなものでしょう」で始め、論の中の「わたしたち」（ἀξιοῦμεν など）はそのまま訳し、論の終わりを「〜、と。」で閉じる。途中に『』や「」を立てない。τις εἴποι ἄν（「こう言う人もいるでしょう」）で出す見方も同じく「〜のだ、と。」で閉じ、その後に続くオリゲネス自身の μή ποτε（18.3 の μή ποτε δὲ βέλτιον ᾖ）は「〜ほうが、よいのではないでしょうか」と「と」で閉じない自分の判断の文にして、境目を見せる。
- ἢ … ἢ で三つ以上並ぶ選択肢は、「または」「あるいは」を落とさない（3.4 の民数三〇・二）。ἤτοι … ἢ … ἢ を文に分けても、各項に「あるいは」を残す（27.9 の乳・野菜・肉）。二つの選択肢の ἤτοι … ἢ は「〜か、あるいは〜かです」と一文で受け、最初の項を言い切りにしない（28.1、28.5）。
- 読み手（ὑμεῖς。アンブロシオスとタティアネ）は「あなたがた」。祈る人一般に向けた 2 人称単数（σύ）と、手紙の書き手ひとり（アンブロシオスとみられる）に向けた 2 人称単数（5.6 の ἔταξας）は「あなた」。尊敬語は使わない。
- 呼びかけ：2.1 の Ἀμβρόσιε θεοσεβέστατε καὶ φιλοπονώτατε καὶ Τατιανὴ κοσμιωτάτη καὶ ἀνδρειοτάτη は「神を敬うことに篤く、労をいとわないアンブロシオスよ、慎み深く、雄々しいタティアネよ」（θεοσεβής 神を敬うことに篤い、φιλόπονος 労をいとわない、κόσμιος 慎み深い、ἀνδρεῖος 雄々しい）。呼びかけだけで一つの文にする。34 章の呼びかけも同じ語で訳す。
- 欠けの訳し方：写本の空白（点の列）は語を補わず、空白の直前に訳注「ここで写本が空白になっている。…」を付ける。空白の後が文の途中から始まるときは、切れた句をそのまま訳し、句の直後に「前の欠けのため、文の途中から始まる。」の訳注を付ける（『救われる富者とは誰か』1:2 の型）。誰の話かが本文から読めないときは、その訳注で言う（2.1「この人はパウロ」）。編者の補いの案は本文に入れず、メモと論点一覧に書く。推定による直しの説を示す訳注は「〜と直す説もある。」に揃え、変わる語だけを示す（4.1、14.4、19.3 の「『不敬虔』を『敬虔』と直す説もある。」、27.17 の「『先に』を『先の書と同じく』と直す説もある。」）。訳注は、崩れた句を含む文の直後に置く。本文と違う構文の取り方を訳注に持ち込まない。「……」は使わない。
- 神、キリスト（主、救い主、子、ロゴス）、聖霊の動作は尊敬語にする。神やキリストを名詞で言う「〜する方」は漢字の「方」で、動詞は尊敬語にする（16.2「お与えになる方」）。指示の「このかた」「そのかた」はひらき、聖句の引用の中でも同じ（1.1、15.1、16.1、22.1 の申命記三二・六『このかたこそ』）。福音書の場面の主の動作も、受け身と紛れる「〜られる」を避ける（2.4「祈りをおやめになった」）。救い主がお着になった『人』（人性。26.4 の「救い主における人」）の動作も尊敬語にし（「おっしゃる」「お受けになる」）、「この人」は解き明かす人（ὁ θέλων、τις）にだけ使って紛れないようにする。尊敬語の型（「お〜になる」「〜てくださる」、受け身と紛れる「〜られる」を避けること、「このかた」）は『ギリシア人への勧め』の「文体」に従う。祈りの中で神に向けた 2 人称は「あなた」、願いは「〜てください」。
- 御使い、聖徒、預言者には尊敬語を使わない。
- 神の言葉をオリゲネスが神の一人称で書くところ（6.4〜6.5 の、神の定めの文言。底本に „ “ はない）は、5.2〜5.5 の人々の論の紹介と違って「」で囲む。オリゲネスの「わたし」と紛れないようにするため。「」の中は常体（「〜しよう」「〜だろう」）で、神が自分の動作と「わたしの子」「わたしのキリスト」の動作を言うところには尊敬語を使わない。途中のオリゲネスの挿入（（ ）、または ( ) を外した独立の文）は「」の外に出し、挿入の前で「」を閉じ、後で開き直す。挿入と枠の地の文の中の神・御子には尊敬語を使う。聖句のキリストの言葉にオリゲネスが „ “ の外の語（ἐγώ）を足したところ（20.2 のヨハネ一四・二三「わたしと『父とは』…」）も、オリゲネスの「わたし」と紛れないよう「」で囲み、足した語を『』の外に置く。「」の中の聖句は『』。オリゲネスがキリストの口に置いた想定の言葉（15.4 の「なぜ、あなたはわたしに祈るのか」から 15.4 の終わりまで。16.1 が受ける）も同じく「」で囲んで常体にし、キリストが自分を言うところ（三人称の「大祭司」「助け主」を含む）は尊敬語にせず、父の動作は尊敬語にする。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。禁止は「〜てはなりません」。
- 哲学の議論（5〜7 章の予知と意志、27 章の οὐσία）は、論の筋を一文ごとに追えるよう、長い期間文を区切り、前提と結論の接続（ἄρα、τοίνυν、ἐπεί、διόπερ）を落とさない。区切るときも、「〜からです」は γάρ にだけ使い（ἐπεί の理由は「〜のですから」、恐れの μή ποτε〈〜することにならないように〉は「〜おそれがあるのです」。22.2、22.3）、理由を言う分詞を切り出した文は「〜のです」で受ける（10.1 の νενοηκότες καὶ κατορθοῦντες、14.5 の ὡς＋属格分詞 ὡς κρείττονος ὄντος）。名詞を修飾する分詞（10.1 の悪い召使いの αἰτιωμένων）は修飾にたたみ、「〜からです」の理由にしない。εἰ μὲν γὰρ … εἰ δέ … は、どちらの帰結も「〜からです」で結ぶ（5.4）。目的の ἵνα は、それが係る動詞の目的として訳し、前の文の後に「〜てもです」「〜を、です」と付け足さない（5.4、5.5）。ὥσπερ … οὕτως の比較を抱える長い ἵνα（27.9）は、比較を先に文にし、係る先を「〜のは、そのためです」と言い直す。独立した「〜ためです」の文にしない。καθ᾿ ὑπόθεσιν と組む ἵνα（8.2）は目的ではなく譲歩で、「仮に〜としましょう。それでも…」とし、それを受ける 10.1 の ὡς καθ᾿ ὑπόθεσιν は「仮定として」。-τέον の動形容詞は「〜べきです」（5.6 の προδιαληπτέον）。祈りの相手を並べる選択肢の文（15.1 の ἤτοι προσευκτέον τῷ υἱῷ … ἢ …）でも「べき」を落とさない。ἵνα が係るのは接続法の動詞だけで、ἵνα の中の分詞（6.5 の νεανιευσάμενος、μεταβαλόμενος、27.16 の ἄξιος γενόμενος「ふさわしい者となるでしょう。そうして、…受けようと」）は状況として別の文にし、目的にしない。理由の διὰ τό＋不定詞（ἤτοι … ἢ と並ぶときも）は「〜ことのゆえに」とつながりを残す（6.4）。ἐπιτρέπω＋不定詞は「〜するのを許す」で、許す中身は不定詞、与格の名詞（6.5 の ζήλῳ）は原因として訳す。
- 神の動作の尊敬語は、連体修飾と従属節の中でも落とさない（5.2「お造りになった」、5.5「定め置いておられた」「お授けになるため」）。キリストである存在を支えるパン（「生きたパン」）が主語の動作も尊敬語にする（27.4、27.9「行き渡ってくださる」「分け与えてくださる」）。ただし、口語訳の文言を借りた言い換えの中の語（27.9 の『天から』下ってきた『パン』）はそのままにする。受け身と紛れる「〜られる」（言われる、語られる、定め置かれる）は神とキリストの動作に使わず、「お語りになる」「定め置いておられる」とする（6.3、6.5、7.1）。完了の不定詞・分詞（κατατεταχέναι、διατεταχέναι）は「〜ておられる」。否定の述語や「〜こともない」、反実仮想の「〜ことはなかったでしょう」、て形・連用形でつなぐ前の動詞（20.2「子らをお離れにならず、…いてくださり、それを見ておられます」）でも落とさない（10.2「祈ってくださらない」「助け主となってくださることもない」、10.1「お望みになること」、10.2「仲立ちをしておられる」、13.1「お求めになるもの」「お受けになることはなかったでしょう」）。神の動作を名詞や「〜こと」にまとめるときも、動詞として残す部分には尊敬語を付ける（24.2「お見捨てになること、受け入れてくださること」、24.5「光を必要となさる」）。神を主語にした皮肉の問い（24.5 の「お祈りになるのでしょうか」）でも落とさない。ほかの人の言葉として『』に入れた神の動作（24.5 のタティアノスの『神は闇の中にいた』）は、その人の言葉なので尊敬語にしない。キリスト・ロゴスの移動（行く・去る・帰る・上る・移る）は「行かれる」の形でなく「おいでになる」「お進みになる」「お帰りになる」「お上りになる」「お移りになる」とする（23.2）。
- 文法の形の訳し方（11〜12 章のレビューで決めた）：数詞の付いた最上級と部分の属格（11.2 の μία κυριωτάτη τῶν ἀρετῶν）は「〜の一つで、しかも最も〜なもの」とし、「最も〜なものの一つ」としない。καὶ ταῦτα＋属格独立句は「しかも」で受け、中身は後に続く内容を「こう」で指す（「そう」は前の引用と紛れる）。冠詞を重ねた同格の句（12.2 の τὴν μέσην … εὐχήν, τὴν πρὸ αὐτοῦ … λεγομένην）は前の名詞の説明として訳し、代名詞の性で指すものを決める。τάχα οὐ μάτην の「おそらく」は「根拠がなくはない」の側に付ける。τάχα は、それが係る主動詞の文に置き、「そういうものがある」の側に移さない（27.8）。ὡσπερεὶ βέλος のように比喩の名詞が主語の文は、原文にない主語を補わず、「いわば矢が」とする。δύναμαι＋アオリスト分詞＋不定詞（13.4 の δυνήσεται … προφητεύσας … γενέσθαι）は、「できる」を不定詞にだけ掛け、分詞は先立つ行為として「〜して」「〜するでしょう。そうして」とする。δυνατόν＋不定詞に属格独立句が付くところ（22.4 の λυθέντων τῶν ἔργων … ἐξαφανισθῆναι … γενέσθαι）も同じで、独立句は先立つ状況として「〜ば、…でしょう。そうして」とし、「できる」は不定詞にだけ掛けて一度だけ訳す。主文の後に続く μή＋分詞（13.4 の μὴ δυσαρεστούμενος μηδὲ ζητῶν）は、条件や様子を言うので禁止「〜てはなりません」にせず、「ただし、それは〜ときです」とする。理由の与格の τῷ＋不定詞は、すぐ前の分詞に係る理由として訳す（22.3 の μὴ ποιῶν ἁμαρτίαν τῷ σπέρματος μετέχειν θεοῦ「神の種にあずかっているので罪を犯さない」）。一人の主語が分詞をいくつも持って一つの命令（εὐχαριστείτω）に至るところは、命令の述語を一度だけ訳す（13.4）。勧めの接続法に係る様子の分詞（27.6 の πειθόμενοι … πιστεύοντες καὶ βιοῦντες … αἰτῶμεν）は「〜ながら、求めるのです」とし、「求めるときには〜する」と主と従を逆にしない。ὀφειλέτης＋属格は、負っているものとして「〜について、負債のある者」とする（28.2、28.3 の「支払われたこれこれの額の金について」）。名詞の前の修飾句（28.3 の τὸ ὑπὲρ πάντα „ποίημα“）は「神の、すべてにまさる『作品』」と係る先がはっきりする語順にする。「AにもまたB」の καί は、掛かる語に「も」を付ける（28.6 の τοὺς καὶ ἡμῖν ὀφλήσαντας「わたしたちにもまた負債を負いながら」）。比べる μᾶλλον … ἤπερ（16.3 の並び）は「…よりも、むしろ…」とし、「まさって」は ὑπερ- に残す。διά＋対格は「〜のゆえに」（16.1 の τῶν δι᾿ αὐτὸν γενομένων υἱῶν「子のゆえに子となった者たち」）で、διά＋属格の「〜を通して」と分ける。事実を挙げる γοῦν は「現に、」（17.1）で、γάρ の「実際、」と分ける。一つの γάρ を「実際、」と「〜からです」の両方で受けない（20.1）。冠詞の付いた比較級と部分の属格（21.1 の ἐν τῇ χείρονι τῶν προειρημένων）は「前に述べたもののうち、より悪いほうの」とし、冠詞のない比較の属格（χαλεπωτέρᾳ τῶν …）の「〜よりも」と分ける。否定の後の ἀλλά は、文を切っても「そうではなく、」で残す（16.1、16.2。『ギリシア人への勧め』の型）。場所を言う ἔνθα・ἐκεῖ は「そこでは」「かしこで」とし、帰結の「そこで、」と分ける（23.2）。ἵν᾿ οὕτως εἴπω は「こう言ってよければ」とし、断っている語の直前に置く（17.1、23.5、28.5 の「すべての人が、こう言ってよければ、自分の手で書きしるした」。27.16 の ἵν᾿ οὕτως ὑπερβολικῶς εἴπω は「誇張して言ってよければ」）とし、οἱονεί・ὡσπερεί の「いわば」と分ける。譲歩の 3 人称命令（23.2 の ἀπιέτω … πορευέσθω「おいでになるがよいでしょう」「お進みになるがよいでしょう」）は「〜がよいでしょう」。修辞疑問の主語に付く仮定の分詞（17.2 の θεωρήσας、ἰδών、κατειληφώς）は「〜たとします」で受け、断定の文にしない。冠詞と名詞の間で比較級と並ぶ指示詞の属格（26.5 の τοῦ κρείττονος „τούτου“ οὐρανίου „κόσμου“）は比較の属格で、「『この』世よりもすぐれた天の『世』」とし、指示の「この」にしない。
- δεῖ の言い方（ὃν δεῖ τρόπον、καθὸ δεῖ）は「祈るべきしかた」「祈るべきように」で揃え、「正しい」と言い換えない（8.2）。συνεχέστερον εὔχεσθαι は、比較級でも「絶えず祈る」（8.2、10.2）。第一テサロニケ五・一七 の ἀδιαλείπτως も口語訳の「絶えず」で引き、12.2 でオリゲネスがこの語を論じるところも「『絶えず』祈る」とする（二つの語は訳で同じになる。10.2 の「絶えず祈ることをしない人々」は 12.1 の論の先取りなので、そのままでよい）。

## 主の祈り

マタイ六・九〜一三とルカ一一・二〜四は、口語訳を下敷きにし、オリゲネスの説き明かしが語の形にかかっているところだけ口語訳と変える。変えたところは、初めて出るところでメモに「口語訳は「…」。オリゲネスは〜と説くので、…とした。」と書く。主の祈りの句を地の文で引くときも、この表の訳を使う。

| 句 | 訳 | 理由と扱い |
|---|---|---|
| Πάτερ ἡμῶν ὁ ἐν τοῖς οὐρανοῖς（マタイ） / Πάτερ（ルカ） | 天にいますわれらの父よ／父よ | 口語訳のまま。23 章の「天に」の論も、この訳で通る。確定 |
| ἁγιασθήτω τὸ ὄνομά σου | 御名が聖とされますように | 口語訳の「あがめられますように」は使わない。24 章でオリゲネスは、御名が聖とされる（ἁγιάζεσθαι）ことを、神についての考えが聖なるもの（ἁγία）となり、神の聖さ（ἁγιότης）を見ることと説く。また 24.4 で、これと詩篇の ὑψόω（口語訳は「あがめる」）を比べる。そのため句そのものを変え、18.2 の初出にメモを書いた。ἁγία は「聖なる」、ἁγιότης は「聖さ」（口語訳ヘブル一二・一〇 の「きよさ」は ἁγν- の「きよめ」と紛れるので使わない）。確定 |

| τὸν ἄρτον ἡμῶν τὸν ἐπιούσιον δὸς ἡμῖν σήμερον（マタイ） / … δίδου ἡμῖν τὸ καθ᾿ ἡμέραν（ルカ） | わたしたちの、存在を支えるパンを、きょうお与えください／…日々お与えください | 口語訳の「日ごとの食物」は使わない。27 章でオリゲネスは、ἐπιούσιος を οὐσία（存在）から説き、命のパン（ヨハネ六章）と結ぶ。そのため ἄρτος は「パン」、ἐπιούσιος は「存在を支える」とし、27 章で語を論じるところでは『存在を支える』（エピウーシオス）と音を添え、語そのものは『エピウーシオス』と音で言う。27.7 の語釈 τὸν εἰς τὴν οὐσίαν συμβαλλόμενον ἄρτον（「存在に寄与するパン」）と、27.9 の、食べた者の存在に入って力を分け与えるという結論に合うので確定。27.13 で紹介される別の語源（ἐπιέναι から）は、語の論なので音で受ける |
| ἄφες ἡμῖν τὰ ὀφειλήματα ἡμῶν, ὡς καὶ ἡμεῖς ἀφήκαμεν τοῖς ὀφειλέταις ἡμῶν（マタイ） / ἄφες ἡμῖν τὰς ἁμαρτίας ἡμῶν, καὶ γὰρ αὐτοὶ ἀφίεμεν παντὶ τῷ ὀφείλοντι ἡμῖν（ルカ、18.2） | わたしたちに負債のある者をゆるしましたように、わたしたちの負債をもおゆるしください／わたしたちに負債のある者を皆ゆるしますから、わたしたちの罪をもおゆるしください | 口語訳のまま。28 章は ὀφείλημα を「負債」として広く論じるので、ὀφείλημα・ὀφειλέτης・ὀφείλω は「負債」「負債のある者」「負う」で通す。底本のルカは、18.2 では現在の ἀφίεμεν、28.1 ではアオリストの ἀφήκαμεν παντὶ ὀφείλοντι。底本の時制に従い、28.1 は「皆ゆるしましたから」として、メモに 18.2 との違いを書く。確定 |
| καὶ μὴ εἰσενέγκῃς ἡμᾶς εἰς πειρασμόν | わたしたちを試みに引き入れないで | 口語訳の「試みに会わせないで」は使わない。29.1 と 29.9 でオリゲネスは、地上の人の一生は試み（πειρατήριον）であって試みられないことはできず、願うのは試みられて負かされないことで、負かされる者が「試みに入る」のだと説く。εἰσφέρω は「引き入れる」、マタイ二六・四一などの εἰσελθεῖν εἰς πειρασμόν は「試みに入る」（口語訳の「誘惑に陥らない」は使わず、メモに書く）。πειρασμός はこの本では「試み」で通す。確定 |
| ἀλλὰ ῥῦσαι ἡμᾶς ἀπὸ τοῦ πονηροῦ | 悪しき者からお救いください | 口語訳のまま。30.1 でオリゲネスは、神が救い出すのは、敵（ὁ ἐχθρός）が戦いを挑んでこないときではなく、わたしたちが勇敢に立って勝つときだと説き、人格の敵と取っている。ルカにはこの句がない（29.1、30.1）。確定 |

## 引用

- 聖書の引用、言い換え、暗示の扱いと出典の書き方は『ギリシア人への勧め』の「引用」に従う。底本の „ “ は『』に入れる。
- 七十人訳の詩篇の番号を地の文で言うところは底本どおり訳し（2.5「第十六篇」）、出典は口語訳の番号で書く（`（詩篇一七篇）`。『トリュフォンとの対話』と同じ）。詩篇の表題は bible-api に入っていないので、七十人訳から訳す。
- 引用の出典に「参照」は付けない。文言どおりの引用と、口語訳の語を借りた言い換えは本文に出典を置き、暗示はメモに書く（『ギリシア人への勧め』の「引用」）。底本に „ “ がなくても、口語訳の語をそのまま借りた句には出典を置く（2.3 の第二コリント一二・四）。
- 底本の „ “ は、言い換えの中の短い句や一語でも『』に入れ、出典を置く（2.1 の『すぐれた啓示』『女のならい』、2.3 の『ちりに伏』す）。同じ聖句を繰り返して引くときは、オリゲネスが „ “ の外に置いた語を『』の外に置く（2.1、2.3、2.4 のローマ八・二六の「祈るべきことを、」）。
- 底本で別々に括った „ “ の句は、日本語の語順のために割れても、一つの『』にまとめない（14.6 の『主よ』、『子を』、17.2 の『震われない』『国』）。ただし、後置の小辞（γάρ、τε）と訳に出ない冠詞だけが聖句の一句を割っているところ（17.2 の „πᾶσα“ γὰρ „σὰρξ ὡς χόρτος“、22.3 の „συγκληρονόμοι“ τε τοῦ „Χριστοῦ“『キリストと共同の相続人』）は、一つの『』にする。それ以外は、間に „ “ の外の語がなく、聖句の語を並べ替えただけのところでも分ける（27.14 の『初めの』『月』、父の『窮めがたい』『さばき』。括りの中の αὐτοῦ が「父の」になるときは『』の外に出す）。„ “ の外の語が訳に出るところ（22.3 の συμμαρτυροῦντος の συμ-「共に」で、『霊』と共に。22.4 の ὥς φησιν … ὁ Ἰωάννης が割る『罪を犯す者は』、『悪魔から出た者である。…』）は分ける。口語訳で一語になる句をオリゲネスの語が割っているところ（19.2 の „ἐν τῇ“ ἑαυτοῦ ἀνθρωπίνῃ „ζωῇ“ ＝口語訳の「生前」）も、一つの『』にし、割っている語は『』の外に置いてメモに書く。
- „ “ の内と外は、動詞の語幹と活用の境でも分ける。オリゲネスが „ “ の外に置いた語（19.2 の φιλῶν）を『』に入れない（『祈る』ことを好む）。
- オリゲネスが預言者の言葉として引くが、文言が七十人訳より新約の引用に近いところ（17.2 のイザヤ四〇・六〜八 は第一ペテロ一・二四〜二五 の形）は、口語訳の新約の文言を下敷きにし、出典を `（イザヤ四〇・六〜八、第一ペテロ一・二四〜二五）` と並べる。オリゲネスの論が語にかかるところ（σάρξ「肉」。口語訳は「人」）は替えてメモに書く。
- 出典と訳注が並ぶときは、出典を先に置く（`（ルカ一一・一）^[…]。`）。
- 底本の ( )（オリゲネスの挿入）は、訳でも（ ）に入れる（2.3、2.6）。ただし、中に聖句と出典を含むもの（1.1 のダビデの句）、呼びかけの中にあって文が長くなるもの（2.1 のタティアネへの祈り）、訳注を伴うもの（2.5 のハンナの祈り）、長くて（ ）のままでは前後の文の係りが見えにくいもの（9.1 の θαυμάζω δὲ …。続く ὡς の句は「女のこのありさまは…とおりです」と係りを補う。20.1 の教会と会堂の挿入は、外した後に「もし、教会と会堂とにこのような違いがあるなら」と条件を受け直す）は、（ ）を外して独立した文にする。挿入の γάρ は「〜からです」で残す（『ギリシア人への勧め』と同じ）。
- 訳者が本文に添える（ ）は、言葉遊びの片仮名の音だけにする（2.2 の『合意』（シュンフォーニア）と不協和（アシュンフォーノン））。本文の（ ）はオリゲネスの挿入に使うので、語の説明は（ ）に入れず、メモに書く。
- 七十人訳による引用で口語訳と意味が違うところは、底本の文言に従い、メモに「口語訳はヘブル語からの訳で、「…」。七十人訳に従って〜とした。」と書く。七十人訳の書名（πρώτη τῶν Βασιλειῶν など）は口語訳の書名で出典を書き（略称は『ギリシア人への勧め』と同じ `（第一サムエル一・一二）` の形）、地の文で書名を言うところは七十人訳の名を訳してメモに書く（2.5「王国の第一の書」）。詩篇の番号は出典では口語訳の番号に直す。
- 詩篇の表題の出典は篇だけで書く（`（詩篇三〇篇）`。2.5 の `（詩篇一七篇）` と同じ）。
- 詩篇のほかにも、七十人訳（底本）と口語訳で章節の番号がずれるところ（民数三〇・二〜五＝口語訳三〇・一〜四、伝道五・四＝口語訳五・五）は、出典を口語訳の番号で書き、メモに七十人訳の番号を書く。
- オリゲネスが聖句の一部だけを引いて主語が文面にないときは、七十人訳の前後の文脈（口語訳）の主語に合わせ、「自分の」などを補って主語を決めない（3.4 の民数六・一一は祭司が主語）。
- 同じページの中で、すでに出典を置いた聖句を論の中で繰り返し引くところ（3.2 の『祈ってください』、4.2 の『主に祈って』『誓願を立てて』）は、『』に入れ、出典は置かない。全文の引用の直前に、その聖句の語を言い換えの中で先に引くところ（9.1 の『きよい手』『髪を編んだり…』、10.2 の『失望せずに常に祈るべき』）は、全文の引用にだけ出典を置く。
- καὶ τὰ ἑξῆς は「『…』と、それに続く言葉です（出典）」（6.5、10.1、10.2）。聖句の中の台詞は、『』の中にもう一度『』を立てる（10.1 の申命記一五・九、10.2 のルカ一一・五。『ギリシア人への勧め』12.123.1 と同じ）。
- オリゲネスが書名を取り違えて挙げるところ（23.4 の「申命記で神が語っておられる」言葉。文言は第二コリント六・一六）は、本文は底本どおり訳し、出典は文言の合う箇所で置き、取り違えはメモに書く。出典で正しい箇所が示されるので、訳注は付けない。
- 複数の書の言葉が合わさった引用は、訳注にせず、出典を並べてメモに書く（9.3 の「エレミヤ」の言葉 `（エレミヤ七・二二〜二三、ゼカリヤ七・一〇）`）。
- ダニエル三・二四〜九〇 の、ギリシア語訳にだけある祈りと歌（13.2、13.4）は、七十人訳（Swete）から訳し、出典は Swete の章節で `（ダニエル三・五〇）` と書く。口語訳の同じ番号の節は別の場面なので、初出に訳注「ダニエル書のギリシア語訳にだけある部分の言葉。」を付け、メモにテオドティオン訳との違いを書く。口語訳にもある節（三・九四＝口語訳三・二七）は口語訳の番号で書く。
- エステル記の、ギリシア語訳にだけある部分（13.2 のモルデカイとエステルの祈り、14.3）は、七十人訳（Swete）から訳し、出典は底本の欄の章節で `（エステル四・一七）` と書く。ページの初出に訳注「エステル記のギリシア語訳にだけある部分の言葉。」を付け、メモに Swete の番号（C 一〜三〇）とウルガタの番号（一三・八〜一四・一九）を書く。
- 口語訳にない書（知恵の書、トビト記、シラ書など）の引用は、七十人訳（Swete）から訳す。出典は `（知恵九・一三〜一六）`、`（トビト一二・一二）` の形（『神のことばの受肉』とポリュカルポスの手紙の本に揃える）。章節の番号は Swete に従う。スザンナ物語は、七十人訳とテオドティオン訳で節が違うので、底本の欄の挙げる七十人訳の節で `（スザンナ三五）` と書き、テオドティオン訳の節をメモに書く（5.2）。
