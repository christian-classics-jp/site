# オリゲネス『祈りについて』の決まり

オリゲネスが、アンブロシオスとタティアネの問いに答えて、祈りとは何か、何をどう祈るかを論じ、主の祈りを句ごとに説き明かす書。同じアレクサンドリアの神学の語彙は、クレメンスの『ギリシア人への勧め』（`books/clement-protrepticus/AGENTS.md`）と『救われる富者とは誰か』（`books/who-is-the-rich-man/AGENTS.md`）の訳語表と文体の型（γάρ、μὲν οὖν、否定の後の ἀλλά、命令、分詞、一文の短さ）を引き継ぐ。そこにない決まりと、この本に固有の決まりだけをここに書く。食い違うときはこのファイルを優先する。

主の祈りの訳（「主の祈り」の節）は、あとで訳すテルトゥリアヌスの『祈りについて』（tertullian-treatises）とキプリアヌスの『主の祈りについて』（cyprian-treatises）がこの表に揃える。

## 節の形

- 章（1〜34）と節の番号は底本（Koetschau 1899）に従う。節は章ごとに 1 から数える（27 章は 1〜17 節、29 章は 1〜19 節）。読み比べに使うドイツ語訳（Koetschau 1926）も同じ番号を持つ。
- 電子化にある二つの番号の印（`altnumbering` の 196〜は印刷版の右の欄の Delarue 版第 1 巻のページ、`manuscriptpage` の 1r〜38v は左の欄の写本 T の紙葉。第 1 巻の略号表 l. 5318〜5323）は、底本テキストに入れていない。
- 底本テキストは `research/koetschau-1899.txt`。1 行 1 節で `<章>.<節> <本文>`（`27.8`）。
- 底本の 1 節ごとに、ギリシア語の行、続けて訳の行を置く。訳の行は `27:8 ` のように章・節の番号で始める。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは、章全体のページなら `# 3〜4 章　…`、章の一部のページなら `# 27 章 1〜7 節　…` の形（範囲、中身）。
- 底本の表題（ΩΡΙΓΕΝΟΥΣ ΠΕΡΙ ΕΥΧΗΣ）は電子化の `<head>` にあり、底本テキストには入れていない。表題は見出しに出さない（書名は README から出る）。
- 底本は、第 1 巻の序の「Inhalt und Gliederung」（l. 4450〜）と BKV のドイツ語訳の部の見出しによれば、1〜2 章が序、3〜17 章が祈りについての総論、18〜30 章が主の祈りの説き明かし、31〜33 章が総論への補い、34 章が結び。ページの割りはこの区切りに合わせ、主の祈りの各句（22〜30 章）がそれぞれページの頭から始まるようにした。1〜2 章（約 1,600 語）は、序を割らないために 1 ページにした。

## 文体

- 地の文は敬体（「〜です」「〜ます」）。アンブロシオスとタティアネに宛てた書で、クレメンスの二つの本とも揃う。書き手のオリゲネスは「わたし」、オリゲネスと読み手を含むキリスト者は「わたしたち」。書き手ひとりを指す 1 人称複数の動詞（εἴπομεν、εὕρομεν、παρετηρήσαμεν）も「わたし」とし（3.2〜3.4）、人一般のならいを言う ἡμῖν・ἡμῶν（「わたしたちのふだんの意味」）は「わたしたち」で分ける。
- 他の人の見方として出す μή ποτε（「もしや…ではないか」）は「〜ではないでしょうか」で受け、その見方の終わりを「〜のだ、と。」で閉じる（4.2）。文を分けても、見方の範囲を先に閉じない。他の人々の論を、その人々の声で何節にもわたって紹介するところ（5.2〜5.5 の祈りを退ける人々の論）も同じで、「〜の論は、次のようなものでしょう」で始め、論の中の「わたしたち」（ἀξιοῦμεν など）はそのまま訳し、論の終わりを「〜、と。」で閉じる。途中に『』や「」を立てない。
- ἢ … ἢ で三つ以上並ぶ選択肢は、「または」「あるいは」を落とさない（3.4 の民数三〇・二）。
- 読み手（ὑμεῖς。アンブロシオスとタティアネ）は「あなたがた」。祈る人一般に向けた 2 人称単数（σύ）と、手紙の書き手ひとり（アンブロシオスとみられる）に向けた 2 人称単数（5.6 の ἔταξας）は「あなた」。尊敬語は使わない。
- 呼びかけ：2.1 の Ἀμβρόσιε θεοσεβέστατε καὶ φιλοπονώτατε καὶ Τατιανὴ κοσμιωτάτη καὶ ἀνδρειοτάτη は「神を敬うことに篤く、労をいとわないアンブロシオスよ、慎み深く、雄々しいタティアネよ」（θεοσεβής 神を敬うことに篤い、φιλόπονος 労をいとわない、κόσμιος 慎み深い、ἀνδρεῖος 雄々しい）。呼びかけだけで一つの文にする。34 章の呼びかけも同じ語で訳す。
- 欠けの訳し方：写本の空白（点の列）は語を補わず、空白の直前に訳注「ここで写本が空白になっている。…」を付ける。空白の後が文の途中から始まるときは、切れた句をそのまま訳し、句の直後に「前の欠けのため、文の途中から始まる。」の訳注を付ける（『救われる富者とは誰か』1:2 の型）。誰の話かが本文から読めないときは、その訳注で言う（2.1「この人はパウロ」）。編者の補いの案は本文に入れず、メモと論点一覧に書く。「……」は使わない。
- 神、キリスト（主、救い主、子、ロゴス）、聖霊の動作は尊敬語にする。神やキリストを名詞で言う「〜する方」は漢字の「方」、指示の「このかた」はひらく（1.1）。福音書の場面の主の動作も、受け身と紛れる「〜られる」を避ける（2.4「祈りをおやめになった」）。尊敬語の型（「お〜になる」「〜てくださる」、受け身と紛れる「〜られる」を避けること、「このかた」）は『ギリシア人への勧め』の「文体」に従う。祈りの中で神に向けた 2 人称は「あなた」、願いは「〜てください」。
- 御使い、聖徒、預言者には尊敬語を使わない。
- 神の言葉をオリゲネスが神の一人称で書くところ（6.4〜6.5 の、神の定めの文言。底本に „ “ はない）は、5.2〜5.5 の人々の論の紹介と違って「」で囲む。オリゲネスの「わたし」と紛れないようにするため。「」の中は常体（「〜しよう」「〜だろう」）で、神が自分の動作と「わたしの子」「わたしのキリスト」の動作を言うところには尊敬語を使わない。途中のオリゲネスの挿入（（ ）、または ( ) を外した独立の文）は「」の外に出し、挿入の前で「」を閉じ、後で開き直す。挿入と枠の地の文の中の神・御子には尊敬語を使う。「」の中の聖句は『』。
- 修辞疑問は「〜でしょうか」「〜ではありませんか」で終え、「？」は使わない。禁止は「〜てはなりません」。
- 哲学の議論（5〜7 章の予知と意志、27 章の οὐσία）は、論の筋を一文ごとに追えるよう、長い期間文を区切り、前提と結論の接続（ἄρα、τοίνυν、ἐπεί、διόπερ）を落とさない。区切るときも、「〜からです」は γάρ にだけ使い、理由を言う分詞を切り出した文は「〜のです」で受ける（10.1 の νενοηκότες καὶ κατορθοῦντες）。名詞を修飾する分詞（10.1 の悪い召使いの αἰτιωμένων）は修飾にたたみ、「〜からです」の理由にしない。εἰ μὲν γὰρ … εἰ δέ … は、どちらの帰結も「〜からです」で結ぶ（5.4）。目的の ἵνα は、それが係る動詞の目的として訳し、前の文の後に「〜てもです」「〜を、です」と付け足さない（5.4、5.5）。καθ᾿ ὑπόθεσιν と組む ἵνα（8.2）は目的ではなく譲歩で、「仮に〜としましょう。それでも…」とし、それを受ける 10.1 の ὡς καθ᾿ ὑπόθεσιν は「仮定として」。-τέον の動形容詞は「〜べきです」（5.6 の προδιαληπτέον）。ἵνα が係るのは接続法の動詞だけで、ἵνα の中の分詞（6.5 の νεανιευσάμενος、μεταβαλόμενος）は状況として別の文にし、目的にしない。理由の διὰ τό＋不定詞（ἤτοι … ἢ と並ぶときも）は「〜ことのゆえに」とつながりを残す（6.4）。ἐπιτρέπω＋不定詞は「〜するのを許す」で、許す中身は不定詞、与格の名詞（6.5 の ζήλῳ）は原因として訳す。
- 神の動作の尊敬語は、連体修飾と従属節の中でも落とさない（5.2「お造りになった」、5.5「定め置いておられた」「お授けになるため」）。受け身と紛れる「〜られる」（言われる、語られる、定め置かれる）は神とキリストの動作に使わず、「お語りになる」「定め置いておられる」とする（6.3、6.5、7.1）。完了の不定詞・分詞（κατατεταχέναι、διατεταχέναι）は「〜ておられる」。否定の述語や「〜こともない」でも落とさない（10.2「祈ってくださらない」「助け主となってくださることもない」、10.1「お望みになること」、10.2「仲立ちをしておられる」）。
- 文法の形の訳し方（11〜12 章のレビューで決めた）：数詞の付いた最上級と部分の属格（11.2 の μία κυριωτάτη τῶν ἀρετῶν）は「〜の一つで、しかも最も〜なもの」とし、「最も〜なものの一つ」としない。καὶ ταῦτα＋属格独立句は「しかも」で受け、中身は後に続く内容を「こう」で指す（「そう」は前の引用と紛れる）。冠詞を重ねた同格の句（12.2 の τὴν μέσην … εὐχήν, τὴν πρὸ αὐτοῦ … λεγομένην）は前の名詞の説明として訳し、代名詞の性で指すものを決める。τάχα οὐ μάτην の「おそらく」は「根拠がなくはない」の側に付ける。ὡσπερεὶ βέλος のように比喩の名詞が主語の文は、原文にない主語を補わず、「いわば矢が」とする。
- δεῖ の言い方（ὃν δεῖ τρόπον、καθὸ δεῖ）は「祈るべきしかた」「祈るべきように」で揃え、「正しい」と言い換えない（8.2）。συνεχέστερον εὔχεσθαι は、比較級でも「絶えず祈る」（8.2、10.2）。第一テサロニケ五・一七 の ἀδιαλείπτως も口語訳の「絶えず」で引き、12.2 でオリゲネスがこの語を論じるところも「『絶えず』祈る」とする（二つの語は訳で同じになる。10.2 の「絶えず祈ることをしない人々」は 12.1 の論の先取りなので、そのままでよい）。

## 主の祈り

マタイ六・九〜一三とルカ一一・二〜四は、口語訳を下敷きにし、オリゲネスの説き明かしが語の形にかかっているところだけ口語訳と変える。変えたところは、初めて出るところでメモに「口語訳は「…」。オリゲネスは〜と説くので、…とした。」と書く。主の祈りの句を地の文で引くときも、この表の訳を使う。

## 引用

- 聖書の引用、言い換え、暗示の扱いと出典の書き方は『ギリシア人への勧め』の「引用」に従う。底本の „ “ は『』に入れる。
- 七十人訳の詩篇の番号を地の文で言うところは底本どおり訳し（2.5「第十六篇」）、出典は口語訳の番号で書く（`（詩篇一七篇）`。『トリュフォンとの対話』と同じ）。詩篇の表題は bible-api に入っていないので、七十人訳から訳す。
- 引用の出典に「参照」は付けない。文言どおりの引用と、口語訳の語を借りた言い換えは本文に出典を置き、暗示はメモに書く（『ギリシア人への勧め』の「引用」）。底本に „ “ がなくても、口語訳の語をそのまま借りた句には出典を置く（2.3 の第二コリント一二・四）。
- 底本の „ “ は、言い換えの中の短い句や一語でも『』に入れ、出典を置く（2.1 の『すぐれた啓示』『女のならい』、2.3 の『ちりに伏』す）。同じ聖句を繰り返して引くときは、オリゲネスが „ “ の外に置いた語を『』の外に置く（2.1、2.3、2.4 のローマ八・二六の「祈るべきことを、」）。
- 出典と訳注が並ぶときは、出典を先に置く（`（ルカ一一・一）^[…]。`）。
- 底本の ( )（オリゲネスの挿入）は、訳でも（ ）に入れる（2.3、2.6）。ただし、中に聖句と出典を含むもの（1.1 のダビデの句）、呼びかけの中にあって文が長くなるもの（2.1 のタティアネへの祈り）、訳注を伴うもの（2.5 のハンナの祈り）、長くて（ ）のままでは前後の文の係りが見えにくいもの（9.1 の θαυμάζω δὲ …。続く ὡς の句は「女のこのありさまは…とおりです」と係りを補う）は、（ ）を外して独立した文にする。挿入の γάρ は「〜からです」で残す（『ギリシア人への勧め』と同じ）。
- 訳者が本文に添える（ ）は、言葉遊びの片仮名の音だけにする（2.2 の『合意』（シュンフォーニア）と不協和（アシュンフォーノン））。本文の（ ）はオリゲネスの挿入に使うので、語の説明は（ ）に入れず、メモに書く。
- 七十人訳による引用で口語訳と意味が違うところは、底本の文言に従い、メモに「口語訳はヘブル語からの訳で、「…」。七十人訳に従って〜とした。」と書く。七十人訳の書名（πρώτη τῶν Βασιλειῶν など）は口語訳の書名で出典を書き（略称は『ギリシア人への勧め』と同じ `（第一サムエル一・一二）` の形）、地の文で書名を言うところは七十人訳の名を訳してメモに書く（2.5「王国の第一の書」）。詩篇の番号は出典では口語訳の番号に直す。
- 詩篇のほかにも、七十人訳（底本）と口語訳で章節の番号がずれるところ（民数三〇・二〜五＝口語訳三〇・一〜四、伝道五・四＝口語訳五・五）は、出典を口語訳の番号で書き、メモに七十人訳の番号を書く。
- オリゲネスが聖句の一部だけを引いて主語が文面にないときは、七十人訳の前後の文脈（口語訳）の主語に合わせ、「自分の」などを補って主語を決めない（3.4 の民数六・一一は祭司が主語）。
- 同じページの中で、すでに出典を置いた聖句を論の中で繰り返し引くところ（3.2 の『祈ってください』、4.2 の『主に祈って』『誓願を立てて』）は、『』に入れ、出典は置かない。全文の引用の直前に、その聖句の語を言い換えの中で先に引くところ（9.1 の『きよい手』『髪を編んだり…』、10.2 の『失望せずに常に祈るべき』）は、全文の引用にだけ出典を置く。
- καὶ τὰ ἑξῆς は「『…』と、それに続く言葉です（出典）」（6.5、10.1、10.2）。聖句の中の台詞は、『』の中にもう一度『』を立てる（10.1 の申命記一五・九、10.2 のルカ一一・五。『ギリシア人への勧め』12.123.1 と同じ）。
- 複数の書の言葉が合わさった引用は、訳注にせず、出典を並べてメモに書く（9.3 の「エレミヤ」の言葉 `（エレミヤ七・二二〜二三、ゼカリヤ七・一〇）`）。
- 口語訳にない書（知恵の書、トビト記、シラ書など）の引用は、七十人訳（Swete）から訳す。出典は `（知恵九・一三〜一六）`、`（トビト一二・一二）` の形（『神のことばの受肉』とポリュカルポスの手紙の本に揃える）。章節の番号は Swete に従う。スザンナ物語は、七十人訳とテオドティオン訳で節が違うので、底本の欄の挙げる七十人訳の節で `（スザンナ三五）` と書き、テオドティオン訳の節をメモに書く（5.2）。
