- 印刷版の ⟨ ⟩ は 2.4 の ψαλῶ ⟨δὲ⟩ の一か所だけで、底本テキストも ⟨δὲ⟩（0313_pct:0,60,100,5.jpg）。底本テキストの ( ) の五か所（1.1 の („πάντα“ … ἐποίησε)、2.1 の (ἀφ᾿ ἧς … εὔχομαι)、2.3 の (ὁρῶν … „καθὸ δεῖ“)、2.5 の (ὅλη γὰρ … γραφῇ)、2.6 の (οὐ γάρ που … προσευχὴν)）は、印刷版でもすべて丸括弧で、補いではない。
- 上の句点のほかに、底本テキストの句点はすべて印刷版でも句点。
