### 28.1〜28.6 負債の系統の語（ὀφειλή・ὄφλημα・ὀφείλω＋不定詞・ἀποδίδωμι・ἀποτιννύω・ἀποστερέω）と、ローマ一三・七〜八、第一コリント七・三、五 の口語訳（メインで決めること）

- 底本：このページは、主の祈りの ὀφειλήματα を受けて、ὀφείλω の系統の語を重ねて論じる。名詞は ὀφειλή（28.1 のローマ一三・七 の τὰς ὀφειλάς、28.2 の πρὸς πολίτας ὀφειλή、πλείων γίνεται ἡ ὀφειλή、28.3 の πρὸς τὸ ἅγιον πνεῦμα ὀφειλή、28.4 の χήρας … ὀφειλή、ἐπισκόπου δὲ ὀφειλὴ βαρυτάτη、ὀφειλήν τινα κοινὴν ὠνόμασεν ἀνδρὸς καὶ γυναικός、28.5 の ἀποστερεῖ τὴν ὀφειλήν、περὶ τῶν προτέρων ὀφειλῶν、κατὰ ταύτας τὰς ὀφειλάς、28.6 の ἰδίων … ὀφειλῶν、μὴ ἀποδεδωκότας τὴν ὀφειλήν）、ὄφλημα（28.2 の βαρύτερον ἡμῖν τὸ ὄφλημα γίνεται）、τὰ ὀφειλόμενα（28.2）。動詞 ὀφείλω は、目的語を取る「負う」（28.3 の κἀκείνῳ ὀφειλέται τινῶν ἐσμεν、28.5 の οὐδενὶ ὀφείλουσιν οὐδέν）と、不定詞を取る「〜すべきだ」（28.1 の διάθεσίν τινα τοιάνδε ὀφείλομεν ἔχειν、28.2 の ὀφείλομεν τῷ μὲν σώματι οὑτωσὶ χρῆσθαι、ὀφείλομεν δὲ καὶ τῇ ψυχῇ … προσάγειν、28.3 の ὀφείλομέν τινα διάθεσιν σῴζειν）の両方で出る。返すことは ἀποδίδωμι（28.1、28.3〜28.6）と ἀποτιννύω（28.5 の τὰ πλεῖστα ἀποτιννύντες）、返さないことは ἀποστερέω（28.4 の第一コリント七・五 の μὴ ἀποστερεῖτε ἀλλήλους、28.5 の ἀποστερεῖ τὴν ὀφειλήν、δυνατὸν δὲ καὶ ἀποστερεῖν、28.6 の οὐκ ἀποδεδώκαμεν ἀλλὰ ἀπεστερήσαμεν）。
- 口語訳（`node tools/bible.js`）：ローマ一三・七「あなたがたは、彼らすべてに対して、義務を果しなさい。すなわち、貢を納むべき者には貢を納め、税を納むべき者には税を納め、恐るべき者は恐れ、敬うべき者は敬いなさい」、一三・八「互に愛し合うことの外は、何人にも借りがあってはならない」、第一コリント七・三「夫は妻にその分を果し、妻も同様に夫にその分を果すべきである」、七・五「互に拒んではいけない」。次の 28.7 が引くマタイ一八・二三〜三五 のたとえは、三〇節 ἕως οὗ ἀποδῷ τὸ ὀφειλόμενον を「借金を返すまで」、三四節 ἕως οὗ ἀποδῷ πᾶν τὸ ὀφειλόμενον αὐτῷ を「負債全部を返してしまうまで」と訳す（MAT.csv l. 614、618）。p. 379 の聖書の箇所の欄 1（l. 26713。画像 0391_pct:0,50,100,20.jpg）は、28.6 の μὴ ἀποδεδωκότας τὴν ὀφειλήν の行に Vgl. Matth. 18, 30. 34 を挙げる。
- 既訳：2.2 は第一コリント七・五 の μὴ ἀποστερεῖτε ἀλλήλους を口語訳のまま「互に拒んではいけない」と訳している（`src/01-chapter-01-02/both.md`）。
- 本の AGENTS.md：主の祈りの表は、28 章が ὀφείλημα を「負債」として広く論じるので、ὀφείλημα・ὀφειλέτης・ὀφείλω は「負債」「負債のある者」「負う」で通す、とする。27.14 の χρέος も「負債」。ὀφειλή・ὄφλημα・ἀποδίδωμι・ἀποστερέω の行はない。τὸ καθῆκον は「務め」（28.1 の τινα καθήκοντα、28.6 の τῶν πρὸς ἡμᾶς καθηκόντων）。
- 1926：ὀφειλή を「Schuld」「Verpflichtung」「Schuldigkeit」と訳し分け、ὀφείλω＋不定詞を「schuldig sein」で受け、ローマ一三・七 を「das Schuldige」、第一コリント七・三 を「was er schuldig ist」、ἀποστερέω を「vorenthalten」と訳す（l. 120〜125）。
- 読者への影響：大。28.4 の「使徒は夫と妻に共通のある負債（ὀφειλή）を名づけて言う」は、引く聖句の中に同じ語があることにかかる。口語訳の「義務」「借り」「その分」「拒む」のままでは、オリゲネスが聖句から「負債」を拾っていることが見えない。28.5 の ἀποστερεῖ τὴν ὀφειλήν も、第一コリント七・五 の ἀποστερεῖτε と同じ語。
- 訳での扱い：訳注なし。メインで決めること（訳語表に足す）。ὀφειλή・ὄφλημα も「負債」で通すか（ὀφείλημα と訳で重なる）。ὀφείλω＋不定詞を「〜することを負っている」「〜する負債がある」のように「負う」で受けて語の重なりを見せるか、「〜すべきです」とし、重なりはメモに書くか。ἀποδίδωμι「返す」、ἀποτιννύω「払う」、ἀποστερέω（「返さずにおく」「出し惜しむ」など）の訳語。引用の中は、ローマ一三・七 の τὰς ὀφειλάς を「負債」、一三・八 の ὀφείλετε を「負う」、第一コリント七・三 の τὴν ὀφειλήν を「負債」、七・五 の ἀποστερεῖτε を 28.5〜28.6 の ἀποστερέω と同じ語に替え、メモに口語訳の文言を書くか（2.2 の既訳「拒んではいけない」との揃えも含めて）。28.6 の ἀποδεδωκότας τὴν ὀφειλήν と 28.7 のたとえの ἀποδῷ … τὸ ὀφειλόμενον は、口語訳マタイ一八・三四 の「負債…を返す」と同じ語になるようにするか。

### 28.1 マタイ六・一二 とルカ一一・四 の ἀφήκαμεν（Angl. はルカについて ἀφίεμεν を推すらしい）

### 28.5 ローマ一四・一〇 と第二コリント五・一〇 の合成

- 聖書の箇所の欄（p. 378 の 11 行、l. 26647）：Vgl. Röm. 14, 10. II Kor. 5, 10。
- 新約：ローマ一四・一〇 は πάντες γὰρ παραστησόμεθα τῷ βήματι τοῦ χριστοῦ（ビザンティン本文。NA は θεοῦ。ROM.csv l. 361）。第二コリント五・一〇 は τοὺς γὰρ πάντας ἡμᾶς φανερωθῆναι δεῖ ἔμπροσθεν τοῦ βήματος τοῦ χριστοῦ, ἵνα κομίσηται ἕκαστος τὰ διὰ τοῦ σώματος, πρὸς ἃ ἔπραξεν, εἴτε ἀγαθόν, εἴτε κακόν（NA は φαῦλον。2CO.csv l. 88）。底本は、ローマ一四・一〇 の前半（πάντες παραστησόμεθα τῷ βήματι）に、第二コリント五・一〇 の τοῦ Χριστοῦ 以下をつなぎ、二つの „ “ に分ける。φαῦλον は NA と同じ。

### 28.5 箴言二二・二六〜二七（七十人訳）の引用：ὁ αἰσχυνόμενος（Oxford・London は ὁ を欠く）、οὐχ ἕξει πόθεν ἀποδώσει（T・Delarue。Oxford・London は οὐκ ἔχῃς πόθεν ἀποδώσῃς）

- 底本：κατὰ ταύτας τὰς ὀφειλὰς καὶ τὸ ἐν ταῖς Παροιμίαις λέγεται· „μὴ δίδου σεαυτὸν εἰς ἐγγύην ὁ αἰσχυνόμενος πρόσωπον· εἰ γὰρ οὐχ ἕξει πόθεν ἀποδώσει, λήψονται τὸ σὸν στρῶμα τὸ ὑπὸ τὰς πλευράς σου.“
- 聖書の箇所の欄（p. 378 の 14 行、l. 26648）：Prov. 22, 26. 27（無印）。異読の欄（p. 378 の欄 15、l. 26656〜26657。画像 0390_pct:0,74,100,26.jpg）：ὁ を Ox. と Lond. は欠く。οὐχ ἕξει πόθεν ἀποδώσει は T と Del.、Ox. と Lond. は οὐκ ἔχῃς πόθεν ἀποδώσῃς。
- 七十人訳（Swete II l. 40028〜40030、異読欄 l. 40079。画像 0477_pct:0,40,100,60.jpg）：μὴ δίδου σεαυτὸν εἰς ἐγγύην, αἰσχυνόμενος πρόσωπον· ἐὰν γὰρ μὴ ἔχῃ πόθεν ἀποτίσῃ, λήμψονται τὸ στρῶμα τὸ ὑπὸ τὰς πλευράς σου。異読欄は、27 節の ἔχῃ を A と C が ἔχῃς、ἀποτίσῃ を ℵc.a が ἀποτείσῃς、A と C が ἀποτίσῃς（C の欄外は -σεις）と読み、λήμψονται を C が ληψονται と綴るとする。底本は、冠詞 ὁ を持ち、εἰ γὰρ οὐχ ἕξει πόθεν ἀποδώσει（未来の直説法、3 人称）、τὸ σὸν στρῶμα（σόν を足す）の形。Oxford・London の 2 人称（ἔχῃς、ἀποδώσῃς）は A・C の 2 人称の側に近い。
- 口語訳（箴言二二・二六〜二七）：「あなたは人と手を打つ者となってはならない、人の負債の保証をしてはならない。あなたが償うものがないとき、あなたの寝ている寝床までも、人が奪い取ってよかろうか」。
- 1926：αἰσχυνόμενος πρόσωπον を「人をはばかって」の意味に、ἕξει の主語を保証された相手と取って訳す（l. 124。注 680）。
- 読者への影響：中。口語訳はヘブル語からの訳で、「人の顔を恥じる者」も、σόν（あなたの）寝床も、3 人称の「（その人が）返すものを持たないなら」もない。底本の 3 人称の ἕξει は、保証してやった相手が返せないときと読める。
- 訳での扱い：訳注なし。七十人訳の底本の形から訳し、メモに「口語訳はヘブル語からの訳で…」と書く。ὁ αἰσχυνόμενος πρόσωπον は「人の顔を恥じる（はばかる）者よ」と呼びかけに取るか、「人の顔をはばかって」とするかをメインで決める。ἕξει の主語は「その人が」と補うか。出典は `（箴言二二・二六〜二七）`。地の文の ἐν ταῖς Παροιμίαις は「箴言に」。ἐγγύη は口語訳の「保証」、ἀποδώσει は上の負債の論点の ἀποδίδωμι の訳語。
- 確かめた資料：l. 26627〜26630、26648、26656〜26657。画像 0390_pct:0,0,100,60.jpg、0390_pct:0,74,100,26.jpg。Swete II l. 40028〜40030、40079。Swete II の画像 0477_pct:0,40,100,60.jpg。1926 l. 124、注 680（l. 850）。`node tools/bible.js Prov.22.26-27`。

### 28.6 φίλοι（Bentley・Delarue に従う。T と三つの刊本は φίλος）と ἀσθενέστερον（Bentley は ἀθενέστερον〈誤植か〉か ἀμελέστερον）

- 底本：καὶ μετὰ τούτους ὡς ἀνδράσι γυναῖκες ἢ ὡς φίλοις φίλοι. ἐπὰν οὖν ἀπὸ τῶν πλείστων ἡμῖν ὀφειλετῶν ἀσθενέστερόν τινες περὶ τὴν ἀπόδοσιν τῶν πρὸς ἡμᾶς καθηκόντων ἀναστραφῶσι, …
- 異読の欄（p. 378 の欄 21〜22、l. 26657〜26659。画像 0390_pct:0,74,100,26.jpg）：φίλοι は Bent. と Del.（I 254 Anm. d）の形で、T と三つの刊本は φίλος。ἀσθενέστερον を Bent.（bei Del. ### 28.6 詩篇七三・八（七十人訳七二・八）の „εἰς τὸ ὕψος“ ἀδικία、τῆς εἰς τὸ ὕψος … λελαλημένης（Bentley は τῶν … λελαλημένων）、τῆς ἀληθείας（Angl.・Delarue に従う。T と三つの刊本は τῆς ἀληθοῦς、Bentley は τοῦ ἀληθοῦς）

- 底本：καὶ μάλιστα ἐὰν μὴ ἐπιλανθανώμεθα τῶν εἰς τὸ θεῖον ἡμῖν παρανενομημένων καὶ τῆς „εἰς τὸ ὕψος“ ἀδικίας ἡμῖν λελαλημένης ἤτοι κατὰ ἄγνοιαν τῆς ἀληθείας ἢ κατὰ δυσαρέστησιν τὴν πρὸς τὰ συμβάντα ἡμῖν περιστατικά.
- 聖書の箇所の欄（p. 379 の 3 行、l. 26715。画像 0391_pct:0,50,100,20.jpg）：Vgl. Psal. 72, 8。異読の欄（p. 379 の欄 3〜4、l. 26719〜26721。画像 0391_pct:0,68,100,32.jpg）：καὶ τῆς … λελαλημένης を Bent.（bei Del. I 254 Anm. f）は καὶ τῶν εἰς τὸ ὕψος ἀδικίας ἡμῖν λελαλημένων と読むが、編者は根拠がないとする。τῆς ἀληθείας は編者が Angl.（bei Del. I 926a）と Del.（I 254 Anm. f）に従って書いた形で、Bent. は τοῦ ἀληθοῦς、T と三つの刊本は τῆς ἀληθοῦς。
- 七十人訳（Swete II l. 27029〜27030）：詩篇七二・八 διενοήθησαν καὶ ἐλάλησαν ἐν πονηρίᾳ, ἀδικίαν εἰς τὸ ὕψος ἐλάλησαν。底本の「高いところに向けて語られた不義」は、この句の ἀδικίαν εἰς τὸ ὕψος ἐλάλησαν を名詞句にしたもの。
- 口語訳（詩篇七三・八）：「彼らはあざけり、悪意をもって語り、高ぶって、しえたげを語る」。
- 1926：„εἰς τὸ ὕψος“ を「神の威光に対して」の意味に取り、句全体を引用符に入れる（l. 125。注 681 は Vgl. Ps. 72,8）。
- 読者への影響：中。口語訳はヘブル語からの訳で、「高ぶって」と語る者の態度にする。七十人訳とオリゲネスの εἰς τὸ ὕψος は、語った不義が向かう先（高いところ、すなわち神）で、前の εἰς τὸ θεῖον（神に対して）と並ぶ。
- 訳での扱い：訳注なし。„εἰς τὸ ὕψος“ は七十人訳に従って『高いところに向けて』などとし、ἀδικίας … λελαλημένης は『』の外。出典は欄が Vgl. なので、メモに七十人訳の番号と、口語訳がヘブル語からの訳で「高ぶって」とすることを書く。ἤτοι … ἢ … は「あるいは」を落とさない。δυσαρέστησις は「不満」、τὰ συμβάντα … περιστατικά は「身に降りかかった境遇」など。
- 確かめた資料：l. 26685〜26688、26715、26719〜26721。画像 0391_pct:0,0,100,35.jpg、0391_pct:0,50,100,20.jpg、0391_pct:0,68,100,32.jpg。Swete II l. 27029〜27030。1926 l. 125、注 681（l. 851）。`node tools/bible.js Ps.73.8`。
