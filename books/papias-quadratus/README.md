# パピアス断片・クアドラトゥス断片

ヒエラポリスの監督パピアスの『主の言葉の解き明かし』の断片と、パピアスについての古い証言、またクアドラトゥスの弁明の断片を、ラテン語とギリシア語の原文から訳したもの。

底本は F. X. Funk, *Patres apostolici* I（第 2 版、Tübingen: H. Laupp, 1901）の「Papiae fragmenta」（I〜XX、pp. 346〜375）と「Quadrati fragmentum」（pp. 376〜377）。パブリックドメイン。archive.org のスキャン（[patresapostolic00piongoog](https://archive.org/details/patresapostolic00piongoog)）から本文を起こし、[research/funk-1901.txt](research/funk-1901.txt) に置いた。断片の番号と、断片の中の節の番号は底本に従う。クアドラトゥスの断片は `Q` の番号で示す。底本が本文の横に添えるラテン語の対訳（Funk の訳）は訳さない。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
