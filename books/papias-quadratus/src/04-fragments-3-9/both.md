# 断片 III〜IX　アポリナリオス、アンドレアス、アナスタシオス、マクシモスより

3.1 Ἀπολιναρίου· Οὐκ ἀπέθανε τῇ ἀγχόνῃ Ἰούδας, ἀλλ’ ἐπεβίω καθαιρεθεὶς πρὸ τοῦ ἀποπνιγῆναι. καὶ τοῦτο δηλοῦσιν αἱ τῶν ἀποστόλων Πράξεις, ὅτι πρηνὴς γενόμενος ἐλάκησε μέσος, καὶ ἐξεχύθη τὰ σπλάγχνα αὐτοῦ. τοῦτο δὲ σαφέστερον ἱστορεῖ Παπίας ὁ Ἰωάννου μαθητὴς λέγων οὕτως ἐν τῷ δʹ τῆς ἐξηγήσεως τῶν κυριακῶν λόγων.
3:1 アポリナリオスの言葉。ユダは首をつって死んだのではない。息が絶える前に下ろされて、生き延びたのである。使徒行伝も、このことを示している。そこには『まっさかさまに落ちて、腹がまん中から引き裂け、はらわたが流れ出た』とある（使徒一・一八）。ヨハネの弟子パピアスは、このことをもっとはっきり伝えている。『主の言葉の解き明かし』の第四巻で、次のように言うのである。
// 断片 III は、聖句ごとに教父の注を集めたカテナに、使徒一・一八の注として伝わる。Funk は、このアポリナリオスをラオディキアのアポリナリオスとみる。マタイ二七章の注にも、形を変えて入っている。
// 「首をつって死んだのではない」は、マタイ二七・五「首をつって死んだ」を受ける。アポリナリオスは、ユダが首をつったが死ぬ前に下ろされたとして、マタイと使徒一・一八をつなぐ。使徒行伝の引用は「みな」を欠く。
// 第四巻は、断片 I でエイレナイオスが挙げる巻と同じ。
// 3:2〜3:3 の「人々の話では」「という」は、伝聞を示す語（φασί）の訳。Funk の注は、この話はパピアスが主の弟子たちからではなく、ほかの人々から聞いたものだとみる。
3.2 „Μέγα δὲ ἀσεβείας ὑπόδειγμα ἐν τούτῳ τῷ κόσμῳ περιεπάτησεν ὁ Ἰούδας πρησθεὶς ἐπὶ τοσοῦτον τὴν σάρκα, ὥστε μηδὲ ὁπόθεν ἅμαξα ῥαδίως διέρχεται ἐκεῖνον δύνασθαι διελθεῖν, ἀλλὰ μηδὲ αὐτὸν μόνον τὸν τῆς κεφαλῆς ὄγκον αὐτοῦ. τὰ μὲν γὰρ βλέφαρα τῶν ὀφθαλμῶν αὐτοῦ φασὶ τοσοῦτον ἐξοιδῆσαι, ὡς αὐτὸν μὲν καθόλου τὸ φῶς μὴ βλέπειν, τοὺς ὀφθαλμοὺς δὲ αὐτοῦ μηδὲ ὑπὸ ἰατροῦ [διὰ] διόπτρας ὀφθῆναι δύνασθαι· τοσοῦτον βάθος εἶχον ἀπὸ τῆς ἔξωθεν ἐπιφανείας· τὸ δὲ αἰδοῖον αὐτοῦ πάσης μὲν ἀσχημοσύνης ἀηδέστερον καὶ μεῖζον φαίνεσθαι, φέρεσθαι δὲ δι’ αὐτοῦ ἐκ παντὸς τοῦ σώματος συρρέοντας ἰχῶράς τε καὶ σκώληκας εἰς ὕβριν δι’ αὐτῶν μόνων τῶν ἀναγκαίων.
3:2 「ユダは、この世で不敬虔の大きな見せしめとなって歩き回った。その肉はひどく膨れ上がり、彼は、車がたやすく通るところさえ、通れなくなった。いや、頭の大きさだけでも、通れなかったのである。人々の話では、まぶたがひどく腫れたのである。そのため、彼自身は光がまったく見えず、医者が器具でのぞいても、その目は見えなかったという。それほど深く、目は外の表面から沈んでいたのである。陰部は、どんな醜いものよりもいとわしく、大きく見えたという。からだじゅうから膿と蛆が流れ集まり、そこを通って出て来た。ただ用を足すだけで、そうして恥をさらしたという。
// マタイ二七章のカテナには、ユダが車にひかれて、はらわたが出たとする短い形の話がある。ここでは、車は膨れ方の大きさを示すたとえである。
// 「陰部は」から後は、使徒行伝のカテナでは一部の写本にしかなく、刊本の一つは別の写本から補った。マタイ二七章のカテナにはある。
3.3 μετὰ πολλὰς δὲ βασάνους καὶ τιμωρίας ἐν ἰδίῳ, φασί, χωρίῳ τελευτήσαντος, ἀπὸ τῆς ὀδμῆς ἔρημον καὶ ἀοίκητον τὸ χωρίον μέχρι τῆς νῦν γενέσθαι, ἀλλ’ οὐδὲ μέχρι τῆς σήμερον δύνασθαί τινα ἐκεῖνον τὸν τόπον παρελθεῖν, ἐὰν μὴ τὰς ῥῖνας ταῖς χερσὶν ἐπιφράξῃ. τοσαύτη διὰ τῆς σαρκὸς αὐτοῦ καὶ ἐπὶ τῆς γῆς ἔκρυσις ἐχώρησεν.“
3:3 人々の話では、彼は多くの苦しみと罰を受けたのち、自分の地所で死んだ。その悪臭のために、地所は今に至るまで荒れ果て、住む人がいなくなったという。いや、今日でも、手で鼻をふさがなければ、だれもそこを通り過ぎることができないという。彼の肉から流れ出たものは、それほど多く、地にまで及んだのである」。
// 「地所」は使徒一・一八〜一九の語に合わせた。

4.1 Παπίας δὲ οὕτως ἐπὶ λέξεως· Ἐνίοις δὲ αὐτῶν, δηλαδὴ τῶν πάλαι θείων ἀγγέλων, καὶ τῆς περὶ τὴν γῆν διακοσμήσεως ἔδωκεν ἄρχειν, καὶ καλῶς ἄρχειν παρηγγύησε. καὶ ἑξῆς φησίν· Εἰς οὐδὲν δὲ συνέβη τελευτῆσαι τὴν τάξιν αὐτῶν.
4:1 パピアスは、言葉どおりに次のように言う。「彼らのうちのある者たち、すなわち、かつては神のものであった御使たちに、地の秩序を治めることもゆだねた。そして、よく治めるように命じた」。そして続けて言う。「ところが、彼らの位は、無に帰することになった」。
// 断片 IV と V は、カイサリアのアンドレアスの黙示録注解から。断片 IV は黙示録一二・七〜八（天の戦いで、龍とその使たちが天に居場所を失う）の注に引かれる。その直前でアンドレアスは、悪魔が高ぶりとねたみのために落とされたと言う。「ゆだね」「命じた」の主語は神である。
// 「位」と訳した語を、アレタスは天の戦いの陣立ての意味に取る。英訳の一部は、続く黙示録一二・九もパピアスの言葉に含める。

5.1 Περὶ μέντοι τοῦ θεοπνεύστου τῆς βίβλου (τῆς Ἀποκαλύψεως Ἰωάννου scil.) περιττὸν μηκύνειν τὸν λόγον ἡγούμεθα, τῶν μακαρίων Γρηγορίου φημὶ τοῦ θεολόγου καὶ Κυρίλλου, προσέτι δὲ καὶ τῶν ἀρχαιοτέρων Παππίου, Εἰρηναίου, Μεθοδίου καὶ Ἱππολύτου ταύτῃ προσμαρτυρούντων τὸ ἀξιόπιστον.
5:1 もっとも、この書（ヨハネの黙示録のこと）が神の霊感によることについては、長々と論じるのは無用であると、私たちは考える。幸いな人々、すなわち神学者グレゴリオスとキュリロスが、この書の信頼に足ることを証言しているからである。さらに、もっと古い人々、パピアス、エイレナイオス、メトディオス、ヒッポリュトスも証言している。
// アンドレアスの黙示録注解の序文から。括弧の中は底本の編者の補いで、アンドレアスの文にはない。「パピアス」は、原文では Παππίου と綴られている。

6.1 Λαβόντες τὰς ἀφορμὰς ἐκ Παπίου τοῦ πάνυ, τοῦ Ἱεραπολίτου, τοῦ τῷ ἐπιστηθίῳ φοιτήσαντος, καὶ Κλήμεντος καὶ Πανταίνου τοῦ τῆς Ἀλεξανδρέων ἱερέως, καὶ Ἀμμωνίου τοῦ σοφωτάτου, τῶν ἀρχαίων καὶ πρὸ τῶν συνόδων ἐξηγητῶν, εἰς Χριστὸν καὶ τὴν ἐκκλησίαν πᾶσαν τὴν ἑξαήμερον νοησάντων.
6:1 あの名高いパピアスから、手がかりを得た。ヒエラポリスの人で、主の胸に寄りかかった弟子に学んだ人である。また、クレメンスと、アレクサンドリア人の祭司パンタイノスと、いとも賢いアンモニオスからも得た。公会議より前の^[古い版では『互いに一致した最初の』となる。]、古い解き明かす者たちである。この人々は、六日間の創造の全体を、キリストと教会にかかわるものと解した。
// 断片 VI と VII は、シナイのアナスタシオスの『六日間の創造についての瞑想』から。六日間の創造を、キリストと教会の型として解く書である。断片 VI はその第一巻の冒頭近く。原文は「得て」という分詞で、文の主語と主な動詞は抜粋に含まれない。
// 「主の胸に寄りかかった弟子」はヨハネのこと（ヨハネ一三・二五、二一・二〇）。古いラテン語訳は、この語を書名と取った。

7.1 Οἱ μὲν οὖν ἀρχαιότεροι τῶν ἐκκλησιῶν ἐξηγητῶν, λέγω δὴ Φίλων ὁ φιλόσοφος καὶ τῶν ἀποστόλων ὁμόχρονος, καὶ Παπίας ὁ πολύς, ὁ Ἰωάννου τοῦ εὐαγγελιστοῦ φοιτητής, ὁ Ἱεραπολίτης ..... καὶ οἱ ἀμφ’ αὐτοὺς πνευματικῶς τὰ περὶ παραδείσου ἐθεώρησαν εἰς τὴν Χριστοῦ ἐκκλησίαν ἀναφερόμενοι.
7:1 さて、教会の解き明かす者たちのうち、より古い人々がいる。哲学者で、使徒たちと同じ時代の人であったフィロンと、偉大なパピアスである。パピアスは、福音書記者ヨハネに学んだ人で、ヒエラポリスの人であった。（中略）この人々とその周りの人々は、楽園のことを霊的に解し、キリストの教会にあてはめたのである。
// 同じ書の第七巻から。「（中略）」は底本の点。省かれているのはエイレナイオス、ユスティノス、パンタイノス、クレメンスの名で、引用のあとには、二人のグレゴリオスの名が続く。

8.1 Τοὺς κατὰ θεὸν ἀκακίαν ἀσκοῦντας παῖδας ἐκάλουν, ὡς καὶ Παπίας δηλοῖ βιβλίῳ πρώτῳ τῶν κυριακῶν ἐξηγήσεων καὶ Κλήμης ὁ Ἀλεξανδρεὺς ἐν τῷ Παιδαγωγῷ.
8:1 神に従って無垢を修める人々を、「子供たち」と呼んでいた。パピアスも『主の言葉の解き明かし』の第一巻で、そのことを示している。アレクサンドリアのクレメンスも『教育者』で示している。
// 断片 VIII と IX は、証聖者マクシモスがディオニュシオス・アレオパギテスの文書に付けた注から。断片 VIII は『天上位階論』二章への注で、ディオニュシオスがテモテを「子よ」と呼ぶ理由の三つ目として言う。Funk は、呼んでいたのを最初のキリスト者たちとみる。
// 『教育者』（パイダゴーゴス）は「子供を導く者」の意。クレメンスはその第一巻で、キリスト者を子供と呼ぶことを論じる。

9.1 Ταῦτά φησιν αἰνιττόμενος οἶμαι Παπίαν τὸν Ἱεραπόλεως τῆς κατ’ Ἀσίαν τότε γενόμενον ἐπίσκοπον καὶ συνακμάσαντα τῷ θείῳ εὐαγγελιστῇ Ἰωάννῃ. οὗτος γὰρ ὁ Παπίας ἐν τῷ τετάρτῳ αὐτοῦ βιβλίῳ τῶν κυριακῶν ἐξηγήσεων τὰς διὰ βρωμάτων εἶπεν ἐν τῇ ἀναστάσει ἀπολαύσεις. . . καὶ Εἰρηναῖος δὲ ὁ Λουγδούνου ἐν τῷ κατὰ αἱρέσεων πέμπτῳ λόγῳ τὸ αὐτό φησι καὶ παράγει μάρτυρα τῶν ὑπ’ αὐτοῦ εἰρημένων τὸν λεχθέντα Παπίαν.
9:1 思うに、彼はこう言うことで、パピアスをほのめかしているのである。パピアスは当時アジヤのヒエラポリスの監督で、神聖な福音書記者ヨハネと同じ時代に盛りを迎えた人である。このパピアスは『主の言葉の解き明かし』の第四巻で、復活のときに食べ物による楽しみがあると言ったからである。（中略）リヨンのエイレナイオスも、『異端反駁』の第五巻で同じことを言っている。そして、自分の言ったことの証人として、いま述べたパピアスを持ち出している。
// 『教会位階論』七章への注から。「彼」はディオニュシオス。「こう言う」は、復活ののちの幸いを地上の食べ物の楽しみと考える人々を退ける彼の文を指す。エイレナイオスの箇所は断片 I（『異端反駁』五・三三・三〜四）。2:12 の千年の時の記述ともつながる。
// 「（中略）」は底本の点。省かれているのは、千年王国の教えをのちにアポリナリオスが信じたこと、ディオニュシオスの文書はアポリナリオスの作ではありえないことを述べる文である。
// 「リヨン」は、原文では古い名のルグドゥヌム。
