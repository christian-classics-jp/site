# 断片 X〜XIV　フォティオス、教会史の要約の抜粋、ゲオルギオスの年代記、エウセビオスより

10.1 .... οὐ μὴν ἀλλ’ οὐδὲ Παπίαν τὸν Ἱεραπόλεως ἐπίσκοπον καὶ μάρτυρα, οὐδὲ Εἰρηναῖον τὸν ὅσιον ἐπίσκοπον Λουγδούνων (scil. ἀποδέχεται Στέφανος), ἐν οἷς λέγουσιν αἰσθητῶν τινῶν βρωμάτων ἀπόλαυσιν εἶναι τὴν τῶν οὐρανῶν βασιλείαν.
10:1 （中略）いや、それどころか、（ステファノスは）ヒエラポリスの監督で殉教者であるパピアスも、リヨンの聖なる監督エイレナイオスも、受け入れない。二人が、天の国とは、感覚でとらえる何かの食べ物を楽しむことだ、と言う点においてである。
// 断片 X は、フォティオス『図書総覧』二三二の一部。ステファノス・ゴバロスの書物の中身を、フォティオスが要約した文である。省かれた直前の文は、ステファノスがニュッサのグレゴリオスの万物の回復の説も受け入れない、と言う。
// 括弧の「ステファノスは」は、底本の補い（scil. ἀποδέχεται Στέφανος）。
// Funk は、パピアスが殉教したことは確かでなく、フォティオスが確かな伝えによって殉教者と呼んだかは、きわめて疑わしいとみる。
// リヨンの古い名はルグドゥヌム。

11.1 Παπίας Ἱεραπόλεως ἐπίσκοπος ἀκουστὴς τοῦ θεολόγου Ἰωάννου γενόμενος, Πολυκάρπου δὲ ἑταῖρος, πέντε λόγους κυριακῶν λογίων ἔγραψεν. ἐν οἷς ἀπαρίθμησιν ἀποστόλων ποιούμενος μετὰ Πέτρον καὶ Ἰωάννην, Φίλιππον καὶ Θωμᾶν καὶ Ματθαῖον εἰς μαθητὰς τοῦ κυρίου ἀνέγραψεν Ἀριστίωνα καὶ Ἰωάννην ἕτερον, ὃν καὶ πρεσβύτερον ἐκάλεσεν. ὥς τινας οἴεσθαι, ὅτι τούτου τοῦ Ἰωάννου εἰσὶν αἱ δύο ἐπιστολαὶ αἱ μικραὶ καὶ καθολικαί, αἱ ἐξ ὀνόματος Ἰωάννου φερόμεναι, διὰ τὸ τοὺς ἀρχαίους τὴν πρώτην μόνην ἐγκρίνειν. τινὲς δὲ καὶ τὴν Ἀποκάλυψιν τούτου πλανηθέντες ἐνόμισαν. καὶ Παπίας δὲ περὶ τὴν χιλιονταετηρίδα σφάλλεται, ἐξ οὗ καὶ ὁ Εἰρηναῖος.
11:1 ヒエラポリスの監督パピアスは、神学者ヨハネに聞いた者であり、ポリュカルポスの仲間であった。彼は、主の言葉についての書を五巻書いた。その中で、彼は使徒たちを数え上げた。そして、ペテロとヨハネ、ピリポとトマスとマタイの後に、アリスティオンと、もう一人のヨハネを、主の弟子のうちに記した。このヨハネを、長老とも呼んだ。そのため、ある人々は、ヨハネの名で伝わっている二つの短い公同の手紙は、このヨハネのものだと考えている。昔の人々は、第一の手紙だけを認めているからである。また、ある人々は思い違いをして、黙示録もこのヨハネのものだと考えた。パピアスは千年王国についても誤っており、エイレナイオスも彼から誤りを受け継いだ。
// 断片 XI は、後の時代に作られた教会史の要約から抜き出した文。もとはシデのピリポの『教会史』だとする説がある。11:1 は『教会史』三・三九（2:4〜2:6、2:12〜2:13）と三・二五をまとめ直したもので、11:2 はエウセビオスにない話である。
// 書名は、2:1 でエウセビオスが挙げる『主の言葉の解き明かし』。ここでは「主の言葉の五巻」とだけ言う。使徒の並びは、2:4 のパピアスの序文と違う。
// 「このヨハネのもの」の「この」は、底本が補った語（τούτου）。
11.2 Παπίας ἐν τῷ δευτέρῳ λόγῳ λέγει, ὅτι Ἰωάννης ὁ θεολόγος καὶ Ἰάκωβος ὁ ἀδελφὸς αὐτοῦ ὑπὸ Ἰουδαίων ἀνῃρέθησαν. Παπίας ὁ εἰρημένος ἱστόρησεν ὡς παραλαβὼν ἀπὸ τῶν θυγατέρων Φιλίππου, ὅτι Βαρσαβᾶς ὁ καὶ Ἰοῦστος δοκιμαζόμενος ὑπὸ τῶν ἀπίστων ἰὸν ἐχίδνης πιὼν ἐν ὀνόματι τοῦ Χριστοῦ ἀπαθὴς διεφυλάχθη. ἱστορεῖ δὲ καὶ ἄλλα θαύματα καὶ μάλιστα τὸ κατὰ τὴν μητέρα Μαναῗμου τὴν ἐκ νεκρῶν ἀναστᾶσαν. περὶ τῶν ὑπὸ τοῦ Χριστοῦ ἐκ νεκρῶν ἀναστάντων, ὅτι ἕως Ἀδριανοῦ ἔζων.
11:2 パピアスは第二巻で、神学者ヨハネとその兄弟ヤコブ^[『神学者』と『その兄弟』は後の人の書き加えとみる説がある。]が、ユダヤ人に殺されたと言っている。先に述べたパピアスは、ピリポの娘たちから受け継いだ話として、次のことを伝えた。ユストとも呼ばれるバルサバが、信じない者たちに試され、まむしの毒を飲んだ。それでも、キリストの名によって、何の害も受けずに守られたのである。パピアスは、ほかの驚くべきことも伝えている。とりわけ、マナイモスの母が死人の中からよみがえった話である。キリストによって死人の中からよみがえった人々についても伝えている。彼らは、ハドリアヌスの時代まで生きていたという。
// Funk は、パピアスが書いたのは「ヨハネとヤコブはユダヤ人に殺された」だけで、このヨハネはバプテスマのヨハネ、ヤコブは使徒ヤコブ（使徒一二・二）だとみる。使徒ヨハネが殺されたとパピアスが伝えた、とみる研究者もいる。12:2 も同じ話である。
// バルサバとピリポの娘たちの話は、2:9 でエウセビオスも伝える。まむしの毒と、信じない者たちに試されたことは、そこにはない。毒を飲んでも害を受けないことは、マルコ一六・一八と重なる。
// マナイモスについて、底本の注は、使徒一三・一の「領主ヘロデの乳兄弟マナエン」と同じ人かと問う。
// 最後の一文は、原文では「〜について、〜ということ」の形で、動詞がない。抜き出した人が要点だけを書き留めたもので、「伝えている」は補った。Funk は、ハドリアヌスの名は要約した人が加えたものとみる。抜粋はこのあと、よみがえった人々もみな死んだ、というクリュソストモスの言葉を続ける。クアドラトゥスの断片（本書の最後）にも、似た話がある。

12.1 Μετὰ δὲ Δομετιανὸν ἐβασίλευσε Νερούας ἔτος ἕν, ὃς ἀνακαλεσάμενος Ἰωάννην ἐκ τῆς νήσου ἀπέλυσεν οἰκεῖν ἐν Ἐφέσῳ. μόνος τότε περιὼν τῷ βίῳ ἐκ τῶν ιβʹ μαθητῶν καὶ συγγραψάμενος τὸ κατ’ αὐτὸν εὐαγγέλιον μαρτυρίου κατηξίωται.
12:1 ドミティアヌスの後、ネルワが一年のあいだ皇帝として治めた。ネルワはヨハネを島から呼び戻し、解き放って、エペソに住まわせた。ヨハネは、そのとき十二弟子のうちで、ただひとり生き残っていた。そして、自分による福音書を書き記したのち、殉教の栄誉を受けた^[ほかの写本では『安らかに眠った』とあり、続く殉教の話はない。]。
// 断片 XII は、ゲオルギオスの年代記の一つの写本に伝わる。「殉教の栄誉を受けた」から、12:3 の「そればかりか」の前までは、この写本だけにある。Funk は、ゲオルギオスより後の人が加えたものとみる。
// 「島」はパトモス島（黙示録一・九）。
12.2 Παπίας γὰρ ὁ Ἱεραπόλεως ἐπίσκοπος, αὐτόπτης τούτου γενόμενος, ἐν τῷ δευτέρῳ λόγῳ τῶν κυριακῶν λογίων φάσκει, ὅτι ὑπὸ Ἰουδαίων ἀνῃρέθη· πληρώσας δηλαδὴ μετὰ τοῦ ἀδελφοῦ τὴν τοῦ Χριστοῦ περὶ αὐτῶν πρόρρησιν καὶ τὴν ἑαυτῶν ὁμολογίαν περὶ τούτου καὶ συγκατάθεσιν. εἰπὼν γὰρ ὁ κύριος πρὸς αὐτούς· Δύνασθε πιεῖν τὸ ποτήριον, ὃ ἐγὼ πίνω; καὶ κατανευσάντων προθύμως καὶ συνθεμένων· Τὸ ποτήριόν μου, φησίν, πίεσθε καὶ τὸ βάπτισμα, ὃ ἐγὼ βαπτίζομαι, βαπτισθήσεσθε. καὶ εἰκότως· ἀδύνατον γὰρ θεὸν ψεύσασθαι.
12:2 ヒエラポリスの監督パピアスは、ヨハネを見た者である。そのパピアスが、『主の言葉』の第二巻で、ヨハネがユダヤ人に殺されたと言っているからである。すなわち、ヨハネは兄弟とともに、自分たちについてのキリストの予告を成し遂げた。また、このことで自分たちが言い表し、承知したことも、果たしたのである。主は彼らに、『わたしが飲む杯を飲むことができるか』と言われた（マルコ一〇・三八）。彼らは進んでうなずき、承知した。すると主は、『あなたがたは、わたしの杯を飲み、わたしが受けるバプテスマを受ける』と言われたのである（マルコ一〇・三九、マタイ二〇・二三）。それも当然である。神が偽ることは、ありえないからである。
// 2:2 でエウセビオスは、パピアスは使徒たちを見た者ではないと言う。11:1 の要約も、パピアスを「聞いた者」と呼ぶ。
// 「すなわち」から後は、パピアスの言葉ではなく、この文を書いた人の説明だと、Funk はみる。
// 問いはマルコ一〇・三八、答えの「わたしの杯」はマタイ二〇・二三の形。
// 「神が偽ることは、ありえない」は、ヘブル六・一八の言い回しに近い。
12.3 οὕτω δὲ καὶ ὁ πολυμαθὴς Ὠριγένης ἐν τῇ κατὰ Ματθαῖον ἑρμηνείᾳ διαβεβαιοῦται, ὡς ὅτι μεμαρτύρηκεν Ἰωάννης, ἐκ τῶν διαδόχων τῶν ἀποστόλων ὑποσημαινάμενος τοῦτο μεμαθηκέναι. καὶ μὲν δὴ καὶ ὁ πολυΐστωρ Εὐσέβειος ἐν τῇ ἐκκλησιαστικῇ ἱστορίᾳ (III, 1) φησί· Θωμᾶς μὲν τὴν Παρθίαν εἴληχεν, Ἰωάννης δὲ τὴν Ἀσίαν, πρὸς οὓς καὶ διατρίψας ἐτελεύτησεν ἐν Ἐφέσῳ.
12:3 博学なオリゲネスも、マタイによる福音書の解き明かしで、同じように断言している。ヨハネは殉教した、というのである。そして、このことを使徒たちの後継者たちから学んだと、ほのめかしている。そればかりか、博識なエウセビオスも、『教会史』（第三巻一章）でこう言っている。「トマスはパルテヤを、ヨハネはアジヤを割り当てられた。ヨハネは、アジヤの人々のもとにとどまり、エペソで生涯を終えた」。
// オリゲネスの注解に実際にあるのは、ローマの皇帝がヨハネを、真理の言葉を証ししたためにパトモス島へ流した、という文である。「証しする」の語を、この文を書いた人は殉教と取り違えたと、Funk はみる。
// エウセビオスの言葉は、『教会史』三・一・一を短くした引用。

13.1 Διέπρεπέ γε μὴν κατὰ τούτους ἐπὶ τῆς Ἀσίας τῶν ἀποστόλων ὁμιλητὴς Πολύκαρπος, τῆς κατὰ Σμύρναν ἐκκλησίας πρὸς τῶν αὐτοπτῶν καὶ ὑπηρετῶν τοῦ κυρίου τὴν ἐπισκοπὴν ἐγκεχειρισμένος. καθ’ ὃν ἐγνωρίζετο Παπίας τῆς ἐν Ἱεραπόλει παροικίας καὶ αὐτὸς ἐπίσκοπος.
13:1 そのころ、アジヤでは、使徒たちと親しく交わったポリュカルポスが、際立っていた。彼は、主を見た人々と主に仕えた人々から、スミルナの教会の監督の職をゆだねられていた。ポリュカルポスと同じ時代に、ヒエラポリスの教区の監督であったパピアスも、名を知られていた。
// 断片 XIII は『教会史』三・三六・一〜二。「そのころ」は、直前でエウセビオスが述べる、トラヤヌスの時代のローマとエルサレムの監督たちのころ。文はこのあと、イグナティオスへ続く。
// 「主を見た人々と主に仕えた人々」は、ルカ一・二の言い回しをなぞる。
// いくつかの写本は、このあとにパピアスをほめる句を加える。2:13 のエウセビオスの評価とは合わない。

14.1 Ἰωάννην [τὸν θεολόγον καὶ] ἀπόστολον Εἰρηναῖος καὶ ἄλλοι ἱστοροῦσι παραμεῖναι τῷ βίῳ ἕως τῶν χρόνων Τραϊανοῦ· μεθ’ ὃν Παπίας Ἱεραπολίτης καὶ Πολύκαρπος Σμύρνης ἐπίσκοπος ἀκουσταὶ αὐτοῦ ἐγνωρίζοντο.
14:1 エイレナイオスとほかの人々は、使徒ヨハネがトラヤヌスの時代まで生き長らえたと伝えている。その後、ヒエラポリスのパピアスと、スミルナの監督ポリュカルポスが、ヨハネに聞いた者として知られていた。
// 断片 XIV は、エウセビオス『年代記』のトラヤヌスの第一年の記事。ギリシア語はシュンケロスの引用で伝わる。
// 底本は「神学者であり」（τὸν θεολόγον καὶ）の語を角括弧に入れ、シュンケロスが加えたものとする。古いラテン語訳とアルメニア語訳にないので、訳さなかった。
