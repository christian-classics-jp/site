# 断片 XV〜XX　ヒエロニュムス、ヨハネによる福音書の序文、カテナ、ヴァルダンより

15.1 Papias, Iohannis auditor, Hierapolitanus in Asia episcopus, quinque tantum scripsit volumina, quae praenotavit: Explanatio sermonum domini. In quibus cum se in praefatione adserat non varias opiniones sequi, sed apostolos habere auctores, ait: „Considerabam, quid Andreas, quid Petrus dixissent, quid Philippus, quid Thomas, quid Iacobus, quid Iohannes, quid Matthaeus vel alius quilibet discipulorum domini; quid etiam Aristion et senior Iohannes, discipuli domini, loquebantur. Non enim tantum mihi libri ad legendum prosunt, quantum viva vox usque hodie in suis auctoribus personans“.
15:1 ヨハネに聞いた者パピアスは、アジヤのヒエラポリスの監督であった。彼は五巻だけを書き、それに『主の言葉の解き明かし』という題を付けた。その序文で彼は、さまざまな意見に従うのではなく、使徒たちを拠りどころとしている、と言い切る。そして、こう言っている。「私は、アンデレが何と言ったか、ペテロが何と言ったかを考えた。ピリポが、トマスが、ヤコブが、ヨハネが、マタイが、あるいは主の弟子のうちのほかのだれかが、何と言ったかを考えた。また、ともに主の弟子であるアリスティオンと長老ヨハネが、何と語っていたかも考えた。書物を読んでも、生きた声ほどには私の益にならないからである。その声は、それを語った人々の中で、今日に至るまで響いている」。
// 断片 XV は、ヒエロニュムス『著名者列伝』一八。Funk は、この章はエウセビオス『教会史』三・三九（本書の断片 II）から取ったものとみる。
// パピアスの言葉は、2:4 をラテン語で要約したもの。「長老たちに付き従っていた人が来ると」と「長老たちの言葉を尋ねた」が落ち、パピアスが使徒たちの言葉をじかに考えたように読める。
// 「語っていたか」は、2:4 では「言っているか」。古い写本のいくつかは、ここも現在の形で読む。
15.2 Ex quo apparet, ex ipso catalogo, nominum alium esse Iohannem, qui inter apostolos ponitur, et alium seniorem Iohannem, quem post Aristionem enumerat. Hoc autem diximus propter superiorem opinionem, qua a plerisque rettulimus traditum, duas posteriores epistulas Iohannis non apostoli esse, sed presbyteri.
15:2 このことから、名の並びそのものから明らかである。使徒たちのうちに置かれているヨハネと、アリスティオンの後に数えられている長老ヨハネとは、別の人なのである。私がこのことを述べたのは、先に挙げた意見のためである。多くの人々がそう伝えていると、私が述べた意見である。ヨハネの後の二つの手紙は、使徒のものではなく、長老のものだ、というのである。
// 「先に挙げた意見」は、同じ書物の九章（使徒ヨハネの項）を指す。そこでヒエロニュムスは、ヨハネの第二・第三の手紙を長老ヨハネのものとする説と、エペソにある二つの墓の話を述べ、パピアスの項で論じると予告していた。
// 底本は「並び」と「名の」のあいだに読点を置くが、ほかの刊本のとおり続けて読んだ。
15.3 Hic dicitur mille annorum iudaicam edidisse δευτέρωσιν. Quem secuti sunt Irenaeus et Apollinarius et ceteri, qui post resurrectionem aiunt in carne cum sanctis dominum regnaturum. Tertullianus quoque in libro de spe fidelium et Victorinus Petavionensis et Lactantius hac opinione ducuntur.
15:3 この人は、千年についての、ユダヤ的な言い伝えを世に出したと言われる。エイレナイオスとアポリナリオスと、ほかの人々が、彼に従った。この人々は、復活の後、主が肉体をもって、聖徒たちとともに治めると言う。テルトゥリアヌスも『信者の望みについて』という書物で、この考えに導かれている。ポエトウィオのウィクトリヌスとラクタンティウスも、そうである。
// 「言い伝え」は、原文ではここだけギリシア語の δευτέρωσις。Funk は、エピファニオス『パナリオン』三三・九を引いて、ユダヤ人が長老たちの言い伝えを呼ぶ語だと説明する。
// 「言われる」について Funk は、ヒエロニュムスはこの書を書いたとき、パピアスを読んでいなかったとみる。
// アポリナリオスは、原文では Apollinarius。どのアポリナリオスかは、底本の注に説明がない。ウィクトリヌスは、同じ書物の七四章に、黙示録の注解を書いた監督として出る。

16.1 Porro Iosephi libros et sanctorum Papiae et Polycarpi volumina falsus ad te rumor pertulit a me esse translata: quia nec otii mei nec virium est, tantas res eadem in alteram linguam exprimere venustate.
16:1 さらに、ヨセフスの書物や、聖なるパピアスとポリュカルポスの書物を、私が訳したという噂が、あなたのもとに届いた。だが、それは偽りの噂である。これほどのものを、同じ美しさのまま別の言葉に移すことは、私の暇にも力にも余るからである。
// 断片 XVI は、ヒエロニュムスの書簡七一・五。スペインのバエティカのルキヌスにあてた手紙で、「あなた」はルキヌスである。直前でヒエロニュムスは、ルキヌスが望んだ自分の小品を、その使いの者たちに写させたと述べる。すぐ後では、オリゲネスとディデュモスのものは少しだけ訳した、と言う。
// ヨセフスは、一世紀のユダヤ人の歴史家。

17.1 Refert Irenaeus ..... Papiae auditoris evangelistae Ioannis discipulus .....
17:1 エイレナイオスは（中略）福音書記者ヨハネに聞いた者パピアスの弟子であり（中略）伝えている。
// 断片 XVII は、ヒエロニュムスの書簡七五・三。書簡七一のルキヌスが死んだとき、その妻テオドラにあてた弔いの手紙である。スペインに広がったバシレイデスの異端が古いことを示すために、エイレナイオスを引く。
// 省かれた語は、初めが「使徒たちの時代の人であり、また」。終わりは「リヨンの教会の監督である」で、エイレナイオスが伝える中身が続く。グノーシス派のバシレイデスの系統から出たマルコスという者が、まずガリアに来た、という話である。
// 「弟子」は、エイレナイオスにかかる。ヒエロニュムスは、エイレナイオスをパピアスの弟子と呼んでいる。

18.1 Incipit argumentum secundum Iohannem. Evangelium Iohannis manifestatum et datum est ecclesiis ab Iohanne adhuc in corpore constituto, sicut Papias nomine Hierapolitanus, discipulus Iohannis carus, in exotericis id est in extremis quinque libris retulit.
18:1 ヨハネによる福音書の序文が、ここから始まる。ヨハネによる福音書は、ヨハネがまだ体のうちにあったときに、ヨハネ自身によって明らかにされ、諸教会に与えられた。ヒエラポリスのパピアスという名の、ヨハネの親しい弟子が、外向けの、すなわち最後の五巻^[本来は『解き明かしの五巻』とあったのが、写し誤られたとみられる。]の中で、そう伝えているとおりである。
// 断片 XVIII は、九世紀のラテン語聖書の写本で、ヨハネによる福音書の前に置かれた序文。十八世紀に刊行された。別の写本には、同じ話を含む別の形の序文がある。
// 「外向けの、すなわち最後の」は写本の読み。Funk は、もとは「解き明かしの」（exegeticis）とあったのを筆写者が exotericis（「外向けの」）と書き誤り、別の人がその語に「すなわち最後の」という説明を足したとみる。書名は 2:1 の『主の言葉の解き明かし』。
// 「まだ体のうちにあったときに」は「まだ生きていたときに」の意。Funk は、ここからこの序文がギリシア語の文の訳だとみる。
18.2 [Descripsit vero Evangelium dictante Iohanne recte. Verum Martion haereticus, cum ab eo fuisset improbatus, eo quod contraria sentiebat, abiectus est a Iohanne. Is vero scripta vel epistolas ad eum pertulerat a fratribus, qui in Ponto fuerunt].
18:2 ［そして、ヨハネが口で述べるとおりに、福音書を正しく書き取った^[［］の部分は、パピアスによらない、後の時代の話とみられる。]。しかし、異端者マルキオンは、反対のことを考えていたので、彼にとがめられ、ヨハネに退けられた。このマルキオンは、ポントスにいた兄弟たちからの書いたもの、あるいは手紙を、彼のもとに届けていたのである］。
// 底本は 2 節全体を角括弧に入れる。Funk は、序文の書き手自身がここをパピアスに帰していないこと、マルキオンの話がもっと後の時代を示すことから、パピアスに帰すべきでないとみる。
// 「書き取った」の主語は書かれていないが、前の文のパピアスを受ける。別の形の序文は、関係詞でパピアスにつなぐ。断片 XIX にも同じ伝えがある。
// マルキオンは、写本の綴りでは Martion。ポントスの兄弟たちの話から、ポントス出身のマルキオンと取れる。マルキオンは二世紀の人で、使徒と同じ時代の人ではない。Funk は、書き手がヨハネの弟子ポリュカルポスをヨハネと取り違えたとみる。ケリントスと読む推測もある。
// 「彼にとがめられ」「彼のもとに」の「彼」が、ヨハネとパピアスのどちらを指すかは、文からは決まらない。

19.1 Ὕστατος γὰρ τούτων Ἰωάννης ὁ τῆς βροντῆς υἱὸς μετακληθείς, πάνυ γηραλέου αὐτοῦ γενομένου, ὡς παρέδοσαν ἡμῖν ὅ τε Εἰρηναῖος καὶ Εὐσέβιος καὶ ἄλλοι πιστοὶ κατὰ διαδοχὴν γεγονότες ἱστορικοί, κατ’ ἐκεῖνο καιροῦ αἱρέσεων ἀναφυεισῶν δεινῶν ὑπηγόρευσε τὸ εὐαγγέλιον τῷ ἑαυτοῦ μαθητῇ Παπίᾳ εὐβιότῳ τῷ Ἱεραπολίτῃ, πρὸς ἀναπλήρωσιν τῶν πρὸ αὐτοῦ κηρυξάντων τὸν λόγον τοῖς ἀνὰ πᾶσαν τὴν οἰκουμένην ἔθνεσιν.
19:1 これらの人々のうち、最後に来るのは、雷の子と呼ばれたヨハネである。彼はたいそう年老いていた。エイレナイオスとエウセビオス、そのほか、代々続いた信頼できる歴史家たちが、私たちに伝えているとおりである。そのころ、恐ろしい異端がいくつも芽生えた。そこでヨハネは、自分の弟子で、行いの正しいヒエラポリスのパピアスに、福音書を口で述べて書き取らせたのである。自分より前に、全世界の異邦人にみことばを宣べ伝えた人々の、欠けを補うためであった。
// 断片 XIX は、ヨハネによる福音書についてのギリシア教父の注釈を集めたもの（カテナ）の、序の一節。十七世紀に、今は失われた写本から刊行された。
// 序では、作者名のない一節が、四つの福音書は互いに補い合い、三人の福音書記者が言わなかったことはヨハネで満たされた、と言う。その続きがこの断片で、「これらの人々」は福音書記者たちを指す。
// 「雷の子」はマルコ三・一七。
// エイレナイオスとエウセビオスは、ヨハネが年老いてから、ほかの福音書の後に書いたことを伝える。パピアスに書き取らせた話は、二人の書物の見た箇所にはない。
// 「行いの正しい」（εὐβιότῳ）を、最初の刊行者は名と取って「エウビオトス」とした。「ともに暮らした」と読み直す推測もある。

20.1 Et cum fores clausae essent, apparuit undecim (discipulis) et aliis, qui cum eis erant. Aloe vero, quam ferebant, mixta erat, ut dicitur, dimidia parte ex oleo, dimidia ex melle. Certum est autem, aloen speciem turis esse, sicut refertur a geographo et Papia, quod (vel: namque) sunt quindecim species aloes in India, et quattuor earum sunt species pretiosae: Nikre, Andrataratz, Ierravor, Dzakotken; unde erat id, quod Iosephus et Nicodemus ad sepulturam dabant; etenim divites erant.
20:1 戸が閉じられていたのに、十一（人の弟子）と、彼らと一緒にいたほかの人々に、姿を現された。彼らが持ってきた沈香は、油と蜜を半分ずつ混ぜたものであったという。沈香が乳香の一種であることは確かである。地理学者とパピアスが伝えるとおりである^[パピアスに由来するのは、沈香が乳香の一種だという言葉だけとされる。]。それによれば、インドには十五種類の沈香があり、そのうち四種類が高価なものである。ニクレ、アンドラタラツ、イェラウォル、ザコトケンである。ヨセフとニコデモが葬りのために用いたのは、そこから来たものであった。二人は金持ちだったからである。
// 断片 XX は、十二世紀のアルメニアの学者ヴァルダンの『四福音書の解答』の一節。アルメニア語の原文を Zahn がドイツ語に訳し、それを Funk がラテン語にした。この訳は、そのラテン語から訳した。
// 戸が閉じていたことはヨハネ二〇・一九、二六、「十一（人の弟子）と、彼らと一緒にいたほかの人々」はルカ二四・三三を思わせる。主語は書かれていない。括弧の「人の弟子」は底本の補い。
// 「沈香」は、口語訳のヨハネ一九・三九に合わせた。原語はアロエ。ヨセフとニコデモはヨハネ一九・三八〜三九、二人が金持ちであったことはマタイ二七・五七に重なる。
// 「それによれば」のところで、底本は「〜ということ」と「なぜなら」の二つの訳し方を示す。前を採った。
// Funk と Zahn は、「地理学者」をモヴセス・ホレナツィの『地理』とみる。四つの種類の話はこの書から来ており、油と蜜の話は世間の説で、パピアスに由来するのは乳香の一種だという言葉だけだという。
// 四つの名は、底本の綴りから音を写した。
