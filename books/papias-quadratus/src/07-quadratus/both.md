# クアドラトゥスの断片　エウセビオス『教会史』四・三より

Q.1 Τραϊανοῦ δὲ ἐφ’ ὅλοις ἔτεσιν εἴκοσι τὴν ἀρχὴν μησὶν ἓξ δέουσι κρατήσαντος, Αἴλιος Ἀδριανὸς διαδέχεται τὴν ἡγεμονίαν. τούτῳ Κοδράτος λόγον προσφωνήσας ἀναδίδωσιν, ἀπολογίαν συντάξας ὑπὲρ τῆς καθ’ ἡμᾶς θεοσεβείας, ὅτι δὴ πονηροί τινες ἄνδρες τοὺς ἡμετέρους ἐνοχλεῖν ἐπειρῶντο. εἰσέτι δὲ φέρεται παρὰ πλείστοις τῶν ἀδελφῶν, ἀτὰρ καὶ παρ’ ἡμῖν τὸ σύγγραμμα, ἐξ οὗ κατιδεῖν ἔστι λαμπρὰ τεκμήρια τῆς τε τοῦ ἀνδρὸς διανοίας, καὶ τῆς ἀποστολικῆς ὀρθοτομίας.
% Q:1 トラヤヌスが満二十年に六か月足りないあいだ帝位を保ったのち、アエリウス・ハドリアヌスが統治を継いだ。クアドラトゥスは、この皇帝にあてて論を書き、差し出した。神をうやまう私たちの道のために、弁明をまとめたのである。ある悪い者たちが、私たちの仲間を悩ませようとしていたからである。その書は、今も兄弟たちの多くのもとに伝わっており、私たちの手もとにもある。そこから、この人の知性と、使徒にならって正しく教えていることとを示す、はっきりした証拠を見て取ることができる。
// 断片の全体は、エウセビオス『教会史』四・三・一〜二。底本はクアドラトゥスの言葉の後で断片を終える。エウセビオスはこのあと、アリスティデスもクアドラトゥスと同じようにハドリアヌスに弁明をささげた、と続ける（四・三・三）。
// エウセビオスはここでクアドラトゥスの肩書を書かない。三・三七・一では、ピリポの娘たちとともに預言の賜物で知られた人としてクアドラトゥスを挙げる。四・二三・三では、コリントのディオニュシオスの手紙が触れるアテネの監督クアドラトゥスを挙げるが、弁明を書いた人とは結びつけない。ヒエロニュムス『著名者列伝』一九章は、二人を同じ人とする。Funk はこれを誤りとみる。
// 「満二十年に六か月足りない」について Funk は、ネルウァが死んだ九八年一月二七日から、トラヤヌスが死んだ一一七年八月七日か八日までを指すとする。
// 「差し出した」について Funk は、エウセビオスは弁明そのものからそう判断したのだろうと言う。そこから正しく言えるのは、クアドラトゥスが弁明を皇帝にあてて書き、ささげようとしたことだけで、実際に手渡されたかどうかはわからない、とする。また、クアドラトゥスはアジヤに住んでいたとみられるので、弁明が書かれたのは、ハドリアヌスがこの地方を訪れた一二五年（一二六年）か一二九年だろうとする。ヒエロニュムスは、ハドリアヌスがアテネで冬を過ごしたときに書物が手渡された、と書く（『著名者列伝』一九章）。Funk は、これを十分な根拠のない推測とみる。
// 「正しく教えている」の原語 ὀρθοτομία は、第二テモテ二・一五の「真理の言葉を正しく教え」と同じ語根の語。
Q.2 ὁ δ’ αὐτὸς τὴν καθ’ ἑαυτὸν ἀρχαιότητα παραφαίνει, δι’ ὧν ἱστορεῖ ταῦτα ἰδίαις φωναῖς· „Τοῦ δὲ σωτῆρος ἡμῶν τὰ ἔργα ἀεὶ παρῆν, ἀληθῆ γὰρ ἦν, οἱ θεραπευθέντες, οἱ ἀναστάντες ἐκ νεκρῶν, οἳ οὐκ ὤφθησαν μόνον θεραπευόμενοι καὶ ἀνιστάμενοι, ἀλλὰ καὶ ἀεὶ παρόντες, οὐδὲ ἐπιδημοῦντος μόνον τοῦ σωτῆρος, ἀλλὰ καὶ ἀπαλλαγέντος ἦσαν ἐπὶ χρόνον ἱκανόν, ὥστε καὶ εἰς τοὺς ἡμετέρους χρόνους τινὲς αὐτῶν ἀφίκοντο“.
% Q:2 この同じ人は、次のことを自分の言葉で伝えており、それによって、自分がどれほど古い時代の人であるかを示している。「私たちの救い主のみわざは、いつもそこにあった。それはまことのものだったからである。そのみわざとは、いやされた人々と、死者の中からよみがえった人々である。彼らは、いやされ、よみがえるところを見られただけではない。その後もいつもそこにいたのである。救い主がこの世におられたあいだだけではない。救い主が去られた後も、かなり長いあいだ、彼らはいた。そのため、彼らのうちのある者は、私たちの時代にまで至ったのである」。
// 引用は、「さて」にあたる小さな接続語で始まる。弁明の途中から取られた言葉である。
// 「まことのものだったからである」について、もとは「まことのものとして、いつもそこにあった」で、「だったからである」は直前の「あった」を写し誤って繰り返したものだ、とみる校訂者がいる。ただし、その語を欠く写本はない。古いラテン語訳（ルフィヌス）も、「まことの」をみわざにかかる語として訳す。
// 「去られた」は、主が死なれたことか天に上られたことか、原文は言わない。
// 断片 XI によれば、パピアスも、キリストによって死者の中からよみがえった人々がハドリアヌスの時代まで生きていた、と伝えた（11:2）。Funk は、ハドリアヌスの名は抜粋を作った人の解釈で、クアドラトゥスの言葉からはそこまで言えないとする。パピアスはこの話をクアドラトゥスから取ったのかもしれない、とみる学者もいる。
// ヒエロニュムス『著名者列伝』一九章は、この言葉を、いやされた人々やよみがえった人々を自分が数多く見た、と言い換える。クアドラトゥス自身は、自分が見たとは言っていない。
// 「私たちの時代」について Funk は、弁明を書いた時ではなく、クアドラトゥスの生きた時代のことだとする。六十歳ほどで弁明を書き上げたのなら、その時代は西暦六〇年から八〇年ごろまでさかのぼる。ヤイロの娘（マタイ九・一八〜二六、マルコ五・二二〜四三、ルカ八・四一〜五六）やナインの町でよみがえらされた若者（ルカ七・一一〜一七）が、そのころまで生きていても不思議ではない、という。
