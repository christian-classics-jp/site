# 『天路歴程』の決まり

共通の規則はリポジトリのルートの `AGENTS.md` にある。ここにはこの本だけの決まりを書く。

## 節

- `src/part1-chapterXX-YY/` は README の進捗表の Section X の Y 番目に対応する。
- 見出しは英題の上に `# （十四） 訳題` を足す。番号は第一部の通し番号を漢数字で、括弧は全角。

## 台詞と名前

- 話者ラベル付きの台詞（`CHR.` など）は `クリスチャン「…」` の形で 1 行に書く。ラベルのない台詞は、地の文から分けて独立した段落の「」にする。
- 寓意的な人名・地名は、節の中の初出（地の文でも台詞でもよい）で〈忠実〉〈滅びの町〉のように山括弧で囲む。2 回目以降と話者名には括弧を付けない。伝道者と解釈者には付けない。訳名は既存の訳語に合わせる（`rg '〈' books/pilgrims-progress/src` で確認できる）。
- 決定済みの訳名：Wicket-gate＝狭い門、Shining Ones＝輝く者、Delectable Mountains＝〈喜びの山々〉、Watchful＝〈用心〉、Carnal Policy＝〈肉の知恵〉、Pagan＝〈異教徒〉、Passion＝〈激情〉。

## 文体

**地の文**
- 常体の過去形「〜た。」で書く。「〜のである」「〜のだった」は区切りの強調にたまに使う程度にする。
- 一文の長さの中央値は 25 字ほど。
- 語り手は「私」。"I saw in my dream" は「私が夢の中で見ていると、」とする。
- 主人公は「クリスチャン」と名前で書き、続く文では「彼」も使う。

**台詞の口調**
- 巡礼者と善良な人物（クリスチャン、忠実、伝道者、好意、敬虔など）：です・ます調。一人称は「私」、相手は「あなた」、名前には「さん」を付ける（「忠実さん」）。
- 敵対的・粗野な人物：常体で、相手は「お前」。強情は一人称が「俺」、アポリュオンは「私」。
- 老人（第一の人アダムなど）：一人称は「わし」、相手は「あんた」。
- 二人連れが声を揃えて話すとき（形式主義と偽善）：一人称は「我々」。
- 地の文の中で台詞をつなぐときは「〜は言った。」「〜は答えた。」「〜と尋ねた。」と短く書く。
