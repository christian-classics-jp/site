# ポリュカルポスのピリピ人への手紙の決まり

## 節の形

- 底本の 1 節ごとに、原文の行、続けて訳の行を置く。訳の行は `1:1 ` のように章と節の番号で始める。あいさつは `0:1`。
- 章の中では空行を入れない。章と章のあいだに空行を一つ入れる。
- 見出しは `# あいさつ、1〜6 章　…` の形（章の範囲、中身）。
- 10〜12 章、13:2 の終わり、14 章は底本がラテン語訳を載せる。そこはラテン語から訳し、ギリシア語の部分と同じ文体・訳語で訳す。13:2 は一つの訳の行にギリシア語の部分とラテン語の部分をまとめて訳す。

## 文体

- スミルナの監督が長老たちとともにピリピの教会に書き送る手紙なので、地の文は敬体（「〜です」「〜ます」）。書き手は「わたし」、読み手は「あなたがた」、両方を含むときは「わたしたち」。
- ἀδελφοί／fratres は「兄弟たちよ」。
- 勧めの接続法（1 人称複数）は「〜しましょう」。命令法（2 人称）は「〜しなさい」。
- 4:2〜6:1 の妻、やもめ、執事、若い者、おとめ、長老たちへの勧めは、動詞のない形や分詞の列でも、前の文の「教えましょう」「〜べきです」を受けた勧めとして訳す。動詞のない文は「〜でなければなりません」とする。
- 3 人称の命令は、禁止なら「〜てはなりません」、肯定なら「〜しなさい」とする。「〜ますように」は神への祈りと、書き手自身の願いを言う希求法にだけ使う。

## 訳語と訳し分け

『イグナティオスの手紙』（`books/ignatius/AGENTS.md`）の訳語・訳し分け・聖書の扱いを引き継ぐ。ラテン語の部分では、同じ語にあたるラテン語に同じ訳語を当てる。この本で足すもの：

| 原語 | 訳 |
|---|---|
| δικαιοσύνη / iustitia | 義 |
| φιλαργυρία / avaritia | 金銭を愛すること（ἀφιλάργυρος は「金銭を愛さない」） |
| πρεσβύτεροι / presbyteri | 長老たち |
| διάκονοι | 執事（キリストについて言う 5:2 の διάκονος πάντων は「すべての人に仕える者」） |
| νεώτεροι | 若い者たち |
| χῆραι / παρθένοι | やもめ／おとめ |
| κρίσις / κρίνω | さばき／さばく（「裁」の字は使わない） |
| ἐντυγχάνω περί＋属格 | 〜のためにとりなす（目的語は人と取る。4:3） |
| ἀνακόπτομαι / ἀπέχομαι | 引き止められる／避ける（「断つ」はどちらにも使わない。5:3） |

## 訳し分け

- 文頭の εἰδότες (οὖν) ὅτι は、前の文を受けて「ですから、〜と知って、…」と一文にまとめる（4:1、5:1）。文末で理由を言うときは「〜と知っているからです」とする（6:1）。
- ὅτι 節が並んで一つの「知る」にかかるときは、二つ目以降も「〜ことを」で受け、独立した断言にしない（4:3）。
- 『クレメンスの第一の手紙』から借りた句は、その本の訳に合わせる（4:2「神を恐れることの教え」）。
- νήφω は「身を慎む」とし、σωφρονέω／sobrietas の「慎み（深い）」と同じ系統の語でも別の語として扱う（7:2）。
- moneo／νουθετέω は「戒める」とし、παρακαλέω の「勧める」と分ける（11:1）。
- εἰς … ἀνήκω は「〜にかかわる」とし、ἐν κυρίῳ の「主にあって」と混ぜない（13:2）。
- 勧め（「〜しましょう」）に添う分詞は文の中にとどめ、「〜ながらです」の形にする（7:2）。
- 願いの動詞が一つだけのときは、並ぶ語の列を分けても、その動詞を繰り返さない（12:2）。
