# ポリュカルポスのピリピ人への手紙

スミルナの監督ポリュカルポスがピリピの教会にあてて書いた手紙（Πολυκάρπου πρὸς Φιλιππησίους ἐπιστολή）の、ギリシア語とラテン語の原文からの翻訳。

底本は [Open Apostolic Fathers](https://jtauber.github.io/apostolic-fathers/)（James Tauber & Seumas Macdonald, Version 1.0, 2019, doi:10.5281/zenodo.2555673）の本文。Kirsopp Lake の Loeb 版（1912）の本文を、印刷版と照らし合わせて校正したもの。各節の `both.md` に置いた原文は CC BY-SA 4.0 で、そのまま引き継ぐ。章・節の番号も底本に従う。

ギリシア語の写本はどれも同じ系統に属し、9 章の終わりの近くで切れて、その後ろにバルナバの手紙の途中が続いている。手紙の全体を伝えるのはラテン語訳で、9 章と 13 章の大部分はエウセビオス『教会史』の引用がギリシア語を伝える。底本は 10〜12 章、13 章の終わり、14 章をラテン語訳で載せ、この訳もそこはラテン語から訳す。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
