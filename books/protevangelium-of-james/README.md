# ヤコブ原福音書

主の兄弟ヤコブの名で伝わる、マリヤの誕生からイエスの誕生までの物語『ヤコブ原福音書』（ギリシア語の表題は Γέννησις Μαρίας など、写本によって違う）のギリシア語原文からの翻訳。新約聖書には入っていない書（新約外典）である。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は C. Tischendorf 編、*Evangelia apocrypha*（第 2 版、Leipzig: H. Mendelssohn, 1876）の巻頭に載る「Protevangelium Iacobi」（pp. 1〜50）。パブリックドメイン。archive.org のスキャン（[evangeliaapocry00tiscgoog](https://archive.org/details/evangeliaapocry00tiscgoog)）の画像から本文を起こし、[research/tischendorf-1876.txt](research/tischendorf-1876.txt) に置いた。ページごとに、訳す範囲を起こして足していく。底本の活字は、語末の σ と語中の σ を同じ字形で組み、π と ν も独特の字形で組む。起こした本文では、ふつうの σ／ς、π、ν に直した。表題は底本の第 1 ページの大文字のまま起こした。

章（1〜25 章）と節の番号は底本に従う。底本の表題は 0 章とした。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes.md](research/cruxes.md) にある。
