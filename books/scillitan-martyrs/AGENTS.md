# 『スキリウムの殉教者行伝』の決まり

文体と人物の口調、殉教の語彙は『ユスティノス殉教録』（`books/martyrdom-of-justin/AGENTS.md`）にならう。そこにない決まりと、この本に固有の決まりだけをここに書く。食い違うときはこのファイルを優先する。

## 節の形

- 底本（Knopf 1913）の節（1〜17）に従う。底本は最初の節に番号を付けないので、それを 1 節とする。表題（PASSIO SANCTORVM SCILITANORVM）は `0.1`。
- 底本テキスト（`research/knopf-1913.txt`）では、節の中を話し手ごとに分け、`7.1`、`7.2` のように番号を付けた。小数点の後ろの番号はこの訳で付けたもので、底本にはない。話し手が一人の節は `.1` だけ。
- 底本の 1 行ごとに、ラテン語の行、続けて訳の行を置く。訳の行は `7:1 ` のように番号で始める。
- 節の中では空行を入れない。節と節のあいだに空行を一つ入れる。
- 見出しは `# 表題、1〜17 節　…` の形（範囲、中身）。
- ANF の英訳は節の番号を持たない。

## 底本の扱い

- 底本の本文は Knopf の印刷のとおりに起こした。行末で分けられた語はつないだ。Knopf には異読の注がないので、異読は Robinson 1891 の校注（写本 A・B・C）で調べる（`research/cruxes.md`）。
- 底本は、Robinson の本文と同じく、u と v を分けず（uos、uidit）、domnus（主）のような口語の形を残す。訳には影響しない。

## 文体

- 地の文は敬体で、過去のことは「〜ました」で語る。
- 「〜dixit:」は、地の文で「〜が言いました。「…」」とする。閉じかぎの前に句点を付けない。
- 地方総督の問いは「〜か」「〜のか」で終える。
- 16 節の名の一覧（十二人）は一文で 60 字を超えるが、名を並べただけの文なので分けない（af-verify の WARN はこの一つだけ認める）。

### 人物の口調

- サトゥルニヌス（地方総督）：常体で、相手を「おまえ」、複数の相手を「おまえたち」と呼ぶ。自分たちローマ人は「われわれ」。判決（14 節）と布告（16 節）は布告の常体。
- スペラトゥス：殉教者たちの代表。落ち着いた常体。一人称は「わたし」、仲間を含めて「わたしたち」、総督には「あなた」。
- ほかの殉教者たち（キッティヌス、ドナタ、ウェスティア、セクンダ、ナルツァルス）：短い常体。一人称は「わたし」「わたしたち」。

## 訳語

| 原語 | 訳 |
|---|---|
| martyr / martyrium | 殉教者／殉教 |
| domnus（皇帝にも神にも使う） | 主（総督の「われらの主である皇帝」とスペラトゥスの「わたしの主」の対比を残す） |
| imperator | 皇帝 |
| genius imperatoris | 皇帝の守護霊 |
| persuasio | 信念 |
| confiteor（14 節 confessos） | 告白する（判決の文でも『ユスティノス殉教録』の ὁμολογία「告白」に揃える） |
| cognosco（6 節。認めない／認めている） | 認める（同じ動詞が対比を作るので訳語を一つにする） |
| Deo gratias | 神に感謝（15.1 の Deo gratias agimus は「わたしたちは神に感謝する」） |
| religio / religiosus | 宗教／信心深い |
| simplex / simplicitas | 素朴な／素朴さ |
