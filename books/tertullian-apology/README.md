# テルトゥリアヌス『護教論』

北アフリカのカルタゴのテルトゥリアヌスが、ローマの属州を治める長官たちに宛てて、キリスト者への迫害の不当を論じた弁明『護教論』（Apologeticum）のラテン語原文からの翻訳。

制作：藤遥。全文を Claude Code（Anthropic の Claude）を使って訳した。

底本は F. Oehler 編、*Q. Septimii Florentis Tertulliani quae supersunt omnia* I（Leipzig: T. O. Weigel, 1853）の本文（pp. 111〜302）。パブリックドメイン。archive.org のスキャン（[quintiseptimiifl0001fanc](https://archive.org/details/quintiseptimiifl0001fanc)）の画像から本文を起こし、[research/oehler-1853.txt](research/oehler-1853.txt) に置いた。

章の番号（1〜50）は底本に従う。底本には節の番号がないので、節の番号はこの訳で付けたもの。章を文の切れ目で 25 語以上のまとまりに分け、`node tools/split-units.js` で番号を付けた。

聖書の引用は口語訳聖書を参考にした。

調査に使った資料は [research/sources.md](research/sources.md)、校訂上の論点と訳での扱いは [research/cruxes/](research/cruxes/) にある。
