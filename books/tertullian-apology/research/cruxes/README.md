# 校訂上の論点

テルトゥリアヌス『護教論』の本文で、写本・刊本の読みが分かれる箇所、編者や注釈者のあいだで構文や意味の取り方が分かれて訳に響く箇所、聖書や古典の引用・暗示の形が訳に影響する箇所の一覧。ページ（`src/<節>/`）ごとに `<節>.md` を置く。訳は底本（Oehler 1853 の本文、`../oehler-1853.txt`）の読みのとおりに行い、ほかの読みは記録にとどめる。訳注は、ほかの読みを知ると一般の読者の理解が変わる箇所にだけ付ける。節の番号はこの訳で付けたもの（本の `AGENTS.md`）で、各項の見出しのラベルは底本テキストの行頭のラベル（章.節）。

略号と資料の所在は次のとおり。資料の URL と取得情報は [../sources.md](../sources.md) にある。「l.」は各資料の OCR テキスト（`_djvu.txt`）の行番号。Oehler の校注と注解は OCR が崩れ、本文・校注・注解を混ぜて並べるので、IIIF のページ画像（`cache/archive.org/<identifier>/pages/` に保存したもの）で読み、OCR の行番号はおよその位置として添える。

- 底本（Oehler）：F. Oehler 編、Tertulliani quae supersunt omnia I（1853）。各ページの上の数行が本文、その下に番号つきの校注（異読）、さらにその下に二段組みで文字記号（a、b、c …）つきの注解（Heraldus、Rigaltius など先行の刊本の注の抜き書きと Oehler 自身の注）を置く。画像の番号は印刷ページ＋30（p. 111＝0141）。各論点では、校注は「校注 5」、注解は「注 g」のように、ページの中の番号・記号で挙げる。
- 校注の略号（p. 110、画像 0140 で確かめた。OCR l. 13852–13900）：
  - A：パリ写本 1623 番（もと Claude Dupuy〔Puteanus〕の蔵）。Aβ は Baluze の照合、Aφ は Hildebrand の照合による読み。
  - B：パリ写本 1656 番。C：パリ写本 1689 番（1〜4 章の異読だけが抜き書きされている）。D：パリ写本 2616 番。E：ゴータ写本。F：エアランゲン写本（もとハイルスブロン）。G：ライデン写本（315 番）。
  - λ：フルダ写本。失われた写本で、Modius が書き留めた異読を Junius が 1597 年の刊本の巻末に載せたものとして伝わる。Oehler の序文によると、異読は 1580 年のパリの刊本（de la Barre）と照らして書き留められたもので、Oehler はこれを一つの写本から取られた、ほかの写本とは別の系統の本文とみる（OCR l. 808–855）。F（エアランゲン写本）と、それと同じ系統のウィーン写本は、ところどころフルダ写本と読みが一致するとされる（l. 416–422）。
  - a：Rhenanus の 1521 年の刊本。b：同じく 1529 年の刊本（Gorze の写本〔Gorz.〕の抜き書きを使う）。c：Gelenius 1550。d：Pamelius 1579（ヴァティカンの写本〔Vatic.〕など）。e：Heraldus 1602（A と Bongars の写本〔Bong.〕を使う）。f：Rigaltius 1634。
  - そのほか校注に名で出る写本：ウィーン写本（Vindob.）、フィレンツェ写本（Florent.）、アンブロジアーナ写本（Ambros.）、ライデン写本 108 番（Leidens.）、オクスフォード（Oxon.。ゲッティンゲンにある Heraldus の刊本の余白の書き込み）、エアフルト写本（Erfurt.）。
  - 校注で略号を丸括弧に入れたもの（「(λ)abcde」「(D)abce」「(AφBC)abd」など）がある。略号表（画像 0140）にも、この作品の範囲で読んだ序文にも、括弧の意味は書かれていない。この一覧では、刷られたとおりに括弧ごと写す（各ページの「未確認」）。
  - 校注の「m. pr.」は写本の最初の手、「m. sec.」は後の手、「om.」は欠くこと。
- Bindley：T. H. Bindley 編、Tertulliani Apologeticus（1889）。序文によると、Migne の『ラテン教父全集』1 巻（1844）の本文をもとに、重要な異読を注で取り上げ、そのいくつかを本文に採った（OCR l. 74–78）。章ごとに本文と英語の注を置く。Oehler と違う本文を刷るところは、各論点で「Bindley の本文」として挙げる。画像（`cache/archive.org/apologeticusadve00tertuoft/pages/`）の番号は印刷ページ＋38（p. 2＝0040、p. 6＝0044）。
- Mayor：J. E. B. Mayor 注、Tertullianus Apologeticus（1917）。本文は Oehler のもの。注（l. 8700〜）は主に並行箇所と用例を挙げる。注の見出しの「p. 2 l. 18」などは Mayor の本文のページと行。注の前（l. 8567〜）に「Mayor が Oehler と違う読みを好んだとみられる箇所」の一覧があるが、OCR ではページと行の番号が崩れて読めない。Souter の英訳は使わない（`../sources.md`）。
- 『諸国民へ』（Ad nationes）：同じ著者が先に書いた、同じ論じ方の書。1 巻 1 章などに『護教論』1 章と同じ文が多く、Oehler・Mayor・Bindley がこれを並行箇所として引く。この一覧ではその引用で読んだ。
- 口語訳：`node tools/bible.js` で引いた 1955 年版の本文。
- ANF：Ante-Nicene Fathers 第 3 巻の Thelwall の英訳（`cache/ccel.org/anf03.txt`）。レビューの読み比べに使う。英訳の文言はこの一覧に使わない。
