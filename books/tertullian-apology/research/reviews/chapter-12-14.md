- 論点一覧で「メインで決めること」とされた点の判断：
  - 13.1 の inquis：二人称単数の決まりどおり「と、あなたは言います」とし、言い分の文言は 10:4 と同じ「しかし、われわれにとっては神々だ」にした。続く vos は「あなたがた」。
  - 14.5 の Sed propterea damnatus est Socrates：Bindley が反論と取るので、8.6 の決まりに従って「」に入れ、「と、人は言うでしょう」で受けた。12.6 の O impiae voces … も、相手の叫びの先取りとして「」に入れ、「と、あなたがたは言うでしょう」で受けた。続く命令形 Infrendite, inspumate が二人称複数で、相手の憤りに向けた言葉であるため。
  - 14.4 の praefentur：底本の注 m（画像 0199 で確かめた）は、praefari を「元となる、張本人である」と取り、神々の悪事や争いが大きな家の災いと迷いの始まりになると説明する。動詞が複数なので dei を複数の主語とし、「神々が、ある家の災いや迷いの元とならない劇はない」と訳した。この本は語義が分かれるところで Oehler の注に従ってきたため（4.11、semel）。`// ` メモに書いた。
  - 13.5 の hastarium：同じ理由で Oehler の注 e の「競売場」を採った（Rigaltius・Bindley は「台帳」）。
  - 14.3 の principis sui：詩人たちの頭ホメロスなので「自分たちの頭（ホメロス）」。訳語表の princeps の行に例外として書いた。
  - 12.6 の reprehendistis：底本どおり「とがめた」で訳し、皮肉が分かるように「同じようにとがめたのでしたね」とした。別の読みでは意味が逆になり、読者の理解が変わるので、論点一覧の案どおり訳注を付けた（校注 29 は本文を起こすときに画像 0193 で読んだ）。
  - 12.7 の merebatur と 14.4 の oportebat：直説法の未完了過去で、当然そうあるべきことを言う。どちらも「〜はずです」で訳し、「文型の訳し方」に書いた。
  - 名前：Larentina は底本の形で「ラレンティナ」（Larentiam は異読なので「アッカ」を補わない）。Simon Magus は「魔術師シモン」、碑文は『聖なる神』。Liber は単独なので「リベル」。Caelestis は「カエレスティス」、Varro は「キュニコス派ウァロ」（『ギリシア人への勧め』の表記）。名前の表に書いた。
  - 訳注は 12.6 の 1 件だけ。14.1 の Volo／Nolo と 13.10 の synodi／cynaedum は筋が変わらないので付けない。13.10 のシモンの碑文は `// ` メモにした。14.6 の auream を aeream に直す推定は、写本の読みでないので扱わない。
  - 繰り返し出る語（contumelia、destruere、addicere、sacrileg-、damnare）は、ページの中で一つの訳に揃え、訳語表に書いた。
- レビューの後に自分で直したところ：14:6 の rescissa damnatio を「罪に定めたことが取り消されて、それがソクラテスへの証しとなった」に（「判決」は同じ文の sententiae と重なり、訳語表の damnatio「罪に定めること」に反していた。testimonium は 10:5 の「証し」）。12:1 の maxime は nobis に係り、関係節がその理由を言うので「とりわけ、そのわたしたちにとって」に。14:1 の domi … pueris は家の奴隷なので「奴隷」に（ANF も slaves）。13:6 の Sed enim は enim を落とさず「しかし実際、」に。
