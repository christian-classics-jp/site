# レビュー：27〜31 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-24-26/jp.md`、論点一覧 `research/cruxes/chapter-27-31.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 27.1〜31.3）、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 3183〜3358。
- 結果：12 組、必須 3 件。11 組をそのまま採り、1 組（27:3）を変えて採った。採らなかった組はない。聖句は 31:3（第一テモテ二・一〜二）を口語訳と照らし、31:2 の言い換え（マタイ五・四四）も確かめた。
- 論点一覧で「メインで決めること」とされた点の判断：
  - 罪名：27.1 laesae divinitatis は 24 章の「宗教を害したという罪」に揃えて「神性を害したという訴え」（intentatio は「訴え」）。maiestas は「威光」とし、28.3 laesae augustioris maiestatis は「もっと尊い威光を害したという罪」、29.1 crimini maiestatis は訳語表の reus maiestatis「大逆の罪人」に揃えて「大逆の罪」、29.4 committimus in maiestatem は「威光に対して罪を犯す」、31.2 de quorum maiestate convenimur in crimen は「皇帝たちの威光のことで罪に訴えられています」（10:2 の convenimur「訴えられます」と同じ）。
  - 28.5 の genius：訳語表どおり 32 章で決める。ここでは『オクタウィウス』29:5 にならい仮に「ゲニウス」とし、`// ` メモに書いた。
  - 30.4 の spiritus と 30.5 の de spiritu sancto：どちらも人間の側の霊と取った。30.4 は「霊」、30.5 は体・魂と並ぶ三つの一つとして「聖い霊」とし、「聖霊」とせず、尊敬語も使わない（21 章の「聖霊と補わない」と同じ考え）。
  - 31.1〜31.2 の二人称：putaveris・inspice は「あなた」、Scitote は「あなたがた」（本の決まり）。31:1 は「あなたが思っているとします。それなら、…調べてください」と、単数の相手を一人立てる形にした。
  - 31.1 の Adolati … vim：inquit がなく、Mayor は皮肉とし、反論と取る注釈者がいないので、「」に入れず、地の文の皮肉（「それなら、…ことになります。なるほど、…ためにです」）とした。Plane proficit は Oehler の注 a の反語（「その偽りは、さぞ役に立つことでしょう」）。
  - 31.3 の Orate, inquit：『』に入れ、口語訳に揃えずに原文どおり訳した。inquit の主語は補わず「こう言っています」。出典は（第一テモテ二・一〜二）とし、テトス三・一との混ざりは `// ` メモに書いた。
  - debellare：キリスト者に向かう 29.5 は 5.6 と同じ「討ち滅ぼそうとしている」、天に挑む 30.3 は 5.9 と同じ「征服する」。
  - 27.6 の ingratis：Oehler の注 l に従い 4:3 と同じ「心ならずも」。
  - 30.7 の Hoc agite, boni praesides：「善良な長官たちよ、さあ、それをしてください」。50 章もこれに揃える。
  - 29.4 の illos … rebus suis：論点一覧は illos を神々とするが、29.3 の cuius et toti sunt（神々はすっかりカイザルのもの）を受けて、illos を皇帝たち、rebus suis を皇帝の持ち物である神々と取り、「皇帝たちを、彼ら自身の持ち物の下に置かない」とした。`// ` メモに書いた。レビューはこの取り方に指摘をしなかった。
