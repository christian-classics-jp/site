# レビュー：32〜35 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-27-31/jp.md`、論点一覧 `research/cruxes/chapter-32-35.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 32.1〜35.13）、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 3359〜3527。
- 結果：12 組、必須 3 件。12 組すべてをそのまま採った。このページに聖句の直接の引用はなく、32.3・33.1 のローマ一三・一を思わせるところは『』を付けずに言い換えた。
- 論点一覧で「メインで決めること」とされた点の判断：
  - genius：「ゲニウス」に決めた。本文が 32.3〜32.4 で genios をダイモンと言い換えるので、『オクタウィウス』29:5 と同じく音を写すほうが論が通る。28:5 は仮の訳のままでよく、直していない。35.10 も揃えた。
  - 32.3 の daemonia：縮小の形だと本文が言うので、ここだけ音を写して「ダイモニア」とし、`// ` メモに書いた（3.8 の Chrestianus と同じ扱い）。
  - 32.4 の adiurare／deierare：「命じて退ける」と「かけて誓う」で対を残した。
  - dominus：神と皇帝を呼ぶ語は「主」、家や奴隷の主人は「主人」（34.3、35.13）。
  - 皇帝に対する pietas／religio／fides：「忠誠／敬虔／誠実」とした。36.1 に三つ並ぶので、その三つ組でも通る語にした。34.2 の父の pietas は「慈しみ」、35.10 の impietas は「不忠」、神に対する 34.4 の religiosus は訳語表どおり「信心深い」。
  - 35.11 の parricidae：皇帝への反逆者の意味なので「反逆者たち」とし、`// ` メモに書いた。
  - 人名の複数形：21.26 にならい「カッシウスやニゲルやアルビヌスのような人々」「シゲリウスやパルテニウスのような人々」。コンモドゥスやペルティナクスの名は補わない。
  - 35.7 の歓呼：民衆の叫びなので「」に入れ、詩の形は `// ` メモに書いた。オウィディウスの行番号は論点一覧で未確認なので、出典としては書いていない。
  - 33.1 の Noster est magis Caesar：コロンの後の著者自身の言い切りなので「」に入れた。
  - Oehler の注で決まる箇所：34.3 の Tanto abest は注 e（magis の省略）、35.2 の focos・toros は注 c の終わり（Focos intellege acerras; toros de lectisterniis。画像 0271 で確かめた。論点一覧の「食卓の寝椅子」は採らない）、35.6 の Tiberis は注 q。ただし訳は字義どおりにとどめ、場所を補っていない。35.11 の quam・nebulabant・ediscerent は注 c・d・e。35.10 の alii foris alii intus は注 a（Rigaltius）、35.6 の vernaculam は注 p（Pignorius）。どちらも Oehler が異論を付けずに引く注なので、25.17 の注 v と同じく Oehler の取り方として扱った。Mayor は 34.3 を、差を表す奪格と取る。Bindley は 35.6 の Tiberis を川辺の民衆と取る。どちらの取り方もここに残すだけにした。
  - 35.5 の ne forte … deprehendantur：35.6〜35.11 がローマ人のほうが悪いと示すので、見込みの形（「ひょっとすると、…のほうではないでしょうか」）で受けた。
- 本文の起こし：このセッションで画像 0266〜0278 から起こし、Oehler の OCR と Mayor 1917 との語の列の差分で突き合わせた（`research/sources.md`）。
