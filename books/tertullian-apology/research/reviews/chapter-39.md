# レビュー：39 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-36-38/jp.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 39.1〜39.22）、論点一覧 `research/cruxes/chapter-39.md`、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 3646〜3775。
- 結果：12 組、必須 2 件。12 組すべてを採り、39:9 と 39:4 の 2 組は文言を変えて当てた。案にしなかった気づき 2 件（39:18 の pudicis、39:4 の conventus）も採り、1 組を足した。聖句の直接の引用はない。39.15 のちりと梁はマタイ七・三の言い換えで、口語訳の「ちり」「梁」を使い、『』と出典は付けない。39.10 の一つの霊を飲むこと（第一コリント一二・一三）、39.8 の互いに愛し合うこと（ヨハネ一三・三五）も言い換えとして扱った。
- 論点一覧で「メインで決めること」とされた点の判断：
  - 集まりの語：coire・coitio は「寄り合う・寄り合い」（注 b のとおり結社の語なので、ふつうの「集まる」と分ける）、coetus は「集い」、congregatio・congregari・convenire は「集まり・集まる」、conventus（39.4）は「会合」。38.2 の coetus「徒党を組む」はそのまま。
  - curia：39.15 の区と組合のあいだの curiae は、38.1 の議会ではないので「市民の組」。39.22 の factio と対になる curia は、38.1 と同じ「議会」。
  - dilectio は「愛」（39.8、39.16）、caritas（39.13）は「親愛」。pietas（39.6、39.16）は、34.2 の父の情愛と同じ「慈しみ」。disciplina は『オクタウィウス』と 37.6 の「教え」で通す（39.20 の「教えを食べた」も）。
  - 39.16 のアガペー：底本にギリシア語の名がなく、名を足すと異読に寄るので、「ギリシア人が愛を言うときの名で呼ばれる」とし、名は `// ` メモに書いた。語を括弧に入れる書き方は、3.8 のクレスティアヌス、32.3 のダイモニアと同じくしない。
  - seniores は口語訳の「長老」。praesident は長官（praeses）と紛れないように「上に立つ」。
  - 39.7 の ingratiis：Oehler の注 o が 4 章の注（ingratis＝心ならずも）を指すので、訳語表の「心ならずも」で副詞に取った。
  - 39.8 の ipsi enim …：異教徒の言葉ではなく著者の皮肉なので、「」の外に置き、enim を「〜からです」で受けた。
  - 39.14 のディオゲネスの言葉は、書かれた文や聖句ではないので「」。
  - 39.10 の expaverint ad unam lucem は、生まれ出る子の像なので、37.8 の「おびえる」ではなく「おののきながら出てきた」。
  - 39.13 の lenones（刊本の読み）とカトーを監察官とする著者の取り違え、39.15 の Saliis（写本の多くは Si aliis）は、訳注は付けず `// ` メモに書いた。39.13 の conviolatur も、注 g に従い訳注は付けない（写本の大勢と Oehler・Mayor が conviolatur）。
