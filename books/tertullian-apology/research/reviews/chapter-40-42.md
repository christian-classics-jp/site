# レビュー：40〜42 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-39/jp.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 40.1〜42.9）、論点一覧 `research/cruxes/chapter-40-42.md`、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 3776〜3952。
- 結果：13 組、必須 3 件。13 組すべてを採った。案にしなかった気づき 2 件（42.8 の Non enim を「〜からです」で結ぶこと、mendicantibus が hominibus にも掛かる読み）は採らない。前者は本の AGENTS.md が enim の「実際、」を認めており、後者は今の取り方も文法的に成り立つため。聖句の直接の引用はない。40.7 のソドムとゴモラ、42.7 のシバびと（ヨブ一・一五）は口語訳の表記。40.14 の荒布と灰、41.3 の選り分け（マタイ一三・三〇）、41.5 の世を去ること（ピリピ一・二三）は言い換えとして扱い、『』と出典は付けない。
- 論点一覧で「メインで決めること」とされた点の判断：
  - 40.2〜40.3：叫び Christianos ad leonem! は 40:2 で「」を閉じ、節の切れ目で 40.3 の頭に来る adclamatur は「そう叫ばれるのです」で始めた（`// ` メモ）。単数は Tantos ad unum? の側で「一頭の獅子に」と見せた。caelum stetit は注 b のとおり「天が止まって雨が降らず」。
  - 40.9 の revincam：注 q（demonstrem）に従い「はっきり示せます」。訳語表の revincere に足した。ab eis は「神々から」と指すものを補った。
  - 40.10 の exactor：nocentiae iudicem et exactorem の並びで、罪の償いを取り立てる方（Bindley の罰する方の意味）とし、「その償いを取り立てる方」。
  - 40.11 の si requisisset … sequebatur：過去完了の事実に反する仮定と同じに、過去の「〜はずでした」で訳した。41.6 の直説法過去完了 debuerant も「〜はずでした」、接続法未完了過去の deberent（41.1、41.6）は「〜べきなのに」。
  - rea（40.12）、rei（41.1）：注 s・注 a に従い「罪ある者」。訴えられた者の「罪人」とは分けた。
  - meritis（41.1、41.5、41.6）：注 41 章 c に従い「罪」。41.1 と 41.6 の同じ句は同じ訳（「キリスト者の罪から切り離すべきなのにです」）。
  - 二つの Denique：40.14 は注 t の「たとえば」、42.8 は注 m の「それなら」。
  - 41.4 の si forte：38:4 と同じ「もしそうなるとすればですが」。
  - 42.6 の coetus：39 章の「集い」に揃えた（38.2 の「徒党を組む」は結社の文脈だけ）。
  - vectigalia：42.7 の templorum vectigalia は「神殿の収入」、42.9 の cetera vectigalia は「ほかの税」。
  - 40.14 の honoratur は「誉れを受ける」（39:5 の honor「誉れ」）。aquilicia は「雨乞いのいけにえ」、nudipedalia は「はだしの行列」と意味で訳し、音は写さない。invidia caelum tundimus は注 zz に従い「嘆き訴えて天をたたき」。
  - 42.5 の ubi は底本のまま「食事をするところでは」。ubiubi（Mayor が好む）は足さない。
  - 42.3 の artes は publicamus の目的語に取った（「技も、わたしたちの働きも、あなたがたの用に差し出します」）。
  - 41.2 の相手の言い分の中の「その神」は、異教徒の言葉なので尊敬語にしない。
  - 名前：ヒエラ、アナフェ、デロス、ロドス、コス、コリントス、ルカニア、シキリア、カンパニア、ポンペイ、ハンニバル、セノネス人、バラモン、インドの裸の賢者たち、サトゥルナリア祭、リベラリア祭、シバびと、ナイル川、ティベリス川を名前の表に足した。
  - 40.8 のポンペイの年代（キリストの来臨の後）には、訳注を付けない（別の読みや後代の挿入ではないため）。
