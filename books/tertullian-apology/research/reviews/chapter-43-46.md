# レビュー：43〜46 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-40-42/jp.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 43.1〜46.19）、論点一覧 `research/cruxes/chapter-43-46.md`、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 3953〜4134。
- 結果：23 組、必須 5 件。23 組すべてを採った。案にしなかった気づき（46.9 の Quam を ANF のように関係代名詞に取る読み）は採らない。底本の文には veritatem があり、関係代名詞として取ると目的語が二重になるので、感嘆の「なんと敵意をもって」とした（下の判断）。聖句の直接の引用は 45.3 の『殺すな』（マタイ五・二一の口語訳）だけ。
- 論点一覧で「メインで決めること」とされた点の判断：
  - 46.6 の Quidni? cum … deputent：本の AGENTS.md が Oehler の注を拠り所にするので、注 i に従い一つの問いと取り、「どうして追い払えないのでしょうか。哲学者たちは、ダイモンを神々の次に数えているのにです」とした（譲歩・対立の cum の「〜のに」）。Mayor の「当然だ」の取り方（22:1・30:2 の既訳と同じ形）は採らない。22.1・30.2 には注 i のような注がないので、訳し分ける。
  - 46.9 の Quam … inimice：感嘆の quam が副詞 inimice に掛かると取り、「なんと敵意をもって真理を装い、装うことで損なっていることでしょう」。inimice は底本のまま（mimice「役者のように」は採らない）。
  - 45.3 の Non occides、Ne irascaris quidem：底本が dicere: と docere: のあとに引用の形で刷るので、二つとも『』に入れ、出典をまとめて「（マタイ五・二一〜二二）」とした。『殺すな』は口語訳の文言。続く情欲（マタイ五・二七〜二八）、悪口、仕返し（マタイ五・三八〜三九）は言い換えとして『』も出典も付けない。
  - iniuria：44.1 は訳語表どおり「町の損」、45.4 は人に加える害なので「害」（注 b の vicem iniuriae は「害への仕返し」）。訳語表に足した。
  - forma：45.4 は注 c の「より古い原型」、46.2 は「同じ仕方」。訳語表の「決まり」に足した。
  - fides・fidelis：46.1 は「神の書物が確かであること」、46.8 は注 o の「本心から」、46.16 は「誠実」「誠実な者」。fidelis の「信者」との掛け言葉は `// ` メモに書いた。
  - dispungere：44.1 は「判決によって罪状の決着をつける」、45.7 は「吟味される」。dispector（45.1）は「見極め手」、speculator（45.7）は「すべてを見張っておられる神」。
  - tori（46.14）は訳語表どおり「寝椅子」。
  - Zenon apud Prienenses（46.15）は「ゼノン」とし、21.10 のゼノンと別人であることは補わない。Lacones は 4.7 の Lacedaemonii と同じ人々なので「ラケダイモン人」。
  - mathematici（43.1）は 35:12 の astrologos と同じ「占星術師」。
  - 46.15 の Thurios、46.17 の Hippias は底本の形で訳し、写本の形は論点一覧に残す（訳に響かないので `// ` メモは付けない）。
  - 46.18 の Sed dicet aliquis：相手の言い分として「」に入れ、「と、ある人は言うでしょう」で受けた。de nostris は言い分の中で「あなたがたの中」。
  - 46.4 の deierare：32 章・35 章のゲニウスにかけての誓いなので、「（ゲニウスに）かけて誓う」と括弧で補った。46.1 の spiritualium potestatum も注 b に従い「霊的な力（ダイモン）」と補った。
  - 名前：エピクロス、スペウシッポス、デモクリトス、ピュタゴラス、トゥリオイ、ゼノン、プリエネ、アナクサゴラス、アリストテレス、ヘルメイアス、ディオニュシオス、アリスティッポス、ヒッピアスを名前の表に足した。
