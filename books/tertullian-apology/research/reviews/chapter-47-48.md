# レビュー：47〜48 章

- 日付：2026-11-15
- レビューした者：新しいサブエージェント（訳者の判断理由は渡していない）
- 渡したもの：`both.md`、リポジトリと本の `AGENTS.md`、前のページ `src/chapter-43-46/jp.md`、底本（both.md の原文の行。`research/oehler-1853.txt` の 47.1〜48.17）、論点一覧 `research/cruxes/chapter-47-48.md`、ANF 第 3 巻の英訳 `cache/ccel.org/anf03.txt` l. 4135〜4338。
- 結果：20 組、必須 1 件。20 組すべてをそのまま採った。聖句の直接の引用はない。聖句に近い言い回し（47.9 の spiritibus erroris、48.9、48.10、48.14、48.15）は、論点一覧のとおり『』も出典も付けない。訳注はない。
- 論点一覧で「メインで決めること」とされた点の判断：
  - 47.3 の ex proprio instituto：立体で刷られた Oehler の推定で、文意を変えないので、36.2・37.8 と同じく `// ` メモだけにした。
  - gehenna（47.10）は口語訳のマタイ五・二二と『第一弁明』19:6〜19:7 に揃えて「地獄」、paradisus（47.11）は口語訳のルカ二三・四三に揃えて「パラダイス」。訳語表に足した。
  - 47.11 の igneae illius zonae：注 u はピュリプレゲトンを指すと取るが、本文は名を挙げないので「あの火の帯」とし、注 u を `// ` メモに書いた。
  - 48.14 の finis et limes, medius qui interhiat：注 p（Rigaltius の千年の期間）は解釈で、本文の語は「境」とだけ言うので、訳に「千年」を補わず、`// ` メモに書いた。
  - 48.3 の λ の長い別の文：論の向きが同じなので、訳注は付けない。
  - 48.2 の At enim：相手の言い分ではなく、哲学者との扱いの違いを示す著者の主張なので、38.2 と同じく「」に入れず「しかし実際、」。本の AGENTS.md の文体の節に足した。
  - 48.2 の coetibus：注 d に従い「話を聞く集いのためにさえ求められず」。訳語表の coetus の行に足した。
  - meritum・merere（48.5、48.14）：善悪の裁きを言うので「値打ち」「値する」とし、41 章の「罪」を当てない。aemulis substantiis（48.13）は「相反する実体」、47.9 の aemulationem は訳語表どおり「敵対」。
  - fides、ratio、conditio・condicio、instrumentum（47.7 は「古い書物」）、praescribere（47.8 は 7:2 と同じ「抗弁」）、expungere（48.14 は「決着をつける」）、erogare（48.16 は「使い尽くす」）、apparere（48.16 は 13:9 と同じ「仕える」）、paratura（47.7 は 22:11 と同じ「備え」）は訳語表に書いた。sacramenta（47.12〜47.13）は訳語表どおり「秘儀」。
  - homines gloriae（47.3）は、直前の 46.9 の既訳に揃えて「名声を追う者」。
  - viri quidam（47.7）は「ある者たち」のままにし、異端者とは補わない。comites ipsius（47.8）は「その方の連れ（使徒たち）」と補った（5:3 と同じく指す人を補う）。
  - 48.12 の Si … destinasset, … experireris：過去完了の条件は「定めておられたなら」、未完了過去の帰結は現在の推量「経験することになるでしょう」。
  - dominus：48.11 の dominus omnium morientium は人なので「主人」、48.12 の rerum dominus は神なので「主」。auctor（48.7）はキリスト者の神なので「造り主」とし、尊敬語にした。
  - 名前：テーバイ人、スパルタ人、アルゴス人、ヘラクレイトス、ピュリプレゲトン、エリュシオンの野、ラベリウス、ソフィスト。48.11 の titulus Pythiae は注 m に従い「デルポイのピュティアの銘」と補い、銘の文言は `// ` メモに書いた。名前の表に足した。
