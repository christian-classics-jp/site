レビューが変えなくてよいとしたもの：2:9・3:2 の『殺してはならない』（口語訳の「あなたは」を省くのは他の本と同じ）、3:3 の詩篇一・一 の句（本の `AGENTS.md` の形）、底本の読み（1.2 の tua、2.5 の datam、2.14 の et、3.4 の necando と consessu、3.9 の de origine spectaculorum）、2:8 の defendunt「罰する」（『護教論』4.11 と同じ）。

論点一覧の「メインで決めること」の扱い：
- 詩篇一・一（3.3）は口語訳を下敷きにし、原文が七十人訳の形で、続く論が concilium を人の集まりとして扱うので、「はかりごと」を「集まり」に、「あざける者」を「疫病のような者」に替えた。3.5・3.9 で詩篇の語を引くところは『悪しき者の集まり』。3.7 の裏返した句は聖句でないので『』に入れない。
- 言い分の範囲：1.2 は Nihil obstrepere から non sit までを「」に入れ、tua は「あなたの」。2.1〜2.3 は言い分として節ごとに「」を閉じて開き直し、2.3 の終わりを「と、人は言います」で受けた（底本の sunt を言い分の続きと取る。2.4 で書き手の反論が始まる）。2.1 の sicut praedicamus は書き手の挿入として「」の外に出した。
- disciplina は、キリスト者の教えなので『護教論』どおり「教え」。conditio は「造られたもの」、institutor／interpolator は「造り主／ゆがめる者」、aemulus は『護教論』どおり「敵対する者」。munus は「剣闘士の試合」（spectaculum の「見世物」と分ける）。
- 2.9 の angeli は訳語表どおり「天使」とし、注 h のダイモンの解は `// ` メモ。
- 3.2 の十戒の言い換えは原文の語のまま『』に入れ、出典は（出エジプト二〇・四〜五、一三〜一五）。仮の禁令も『』に入れた。
- 3.4 の iustum illum は、本文だけでは詩篇をだれに当てはめたかが分からないので、注 c に従い「あの正しい人、アリマタヤのヨセフ」と名を補った（『護教論』の強めの ille の決まり）。necando は推定だが訳注は付けない（論点一覧の勧めどおり。推定と写本の読みは `// ` メモ）。
- 3.8 の欄外の出エジプト一二・一二 はエチオピヤが出ないので、出典を付けなかった。
- 1.3 の supervacuam は刷りでは suvervacuam。刷りの誤りとして正しい形で起こし、`// ` メモに書いた。

決まった訳し方は本の `AGENTS.md` に統合した（文体の『見世物について』の言い分・詩篇一・一・ille の名の補い、訳語表の disciplina・conditio・institutor／interpolator／aemulus（同格の並び）・abdicatio／abstinentia・munus・concilium・angelus・voluptas と periculum・ferrum、名前の表）。
