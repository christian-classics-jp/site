レビューが変えなくてよいとしたもの：13:1 と 13:2 の第一コリントの言い換えと出典（八・四、一〇・一九〜二〇、一〇・二一）、訳注 2 つ（11:3、13:1。論点一覧の案どおりで 40 字以内）。

論点一覧の「メインで決めること」の扱い（本の `AGENTS.md` に統合した）：
- 10.8 の fluxum：本文と校注の fluxum で訳し、注 r が luxum を支持することを `// ` メモに書いた（訳は Oehler の本文に従う決まり）。
- 10.3 の a loci. Initio：Oehler の推定どおり。「場所から始めましょう」と補い、写本の a loci vitio をメモに書いた。訳注は付けない。
- 11.3：注 d の取り方で訳し、訳注を付けた。13.1 の qui bis にも訳注を付けた。
- 12.3 の ferarum：注 d（Rigaltius）のとおり「獣のような見物人」。
- 12.7 の periuria：注 m が採る Rigaltius の解で「偽りの誓いをする者さえ耐えられない場所」。区切りは注 o のとおり、カピトリウムをあらゆるダイモンの神殿とする。
- 12.1 の munus と officium：名の由来の型で「剣闘士の試合（ムヌス）」「務め（オフィキウム）」。
- 12.8 の utriusque ludi：注 p のとおり「両方の遊戯（剣闘と獣狩り）」と補う。6.1・7.1 とは別のもの。
- 第一コリントの引用（13.1〜13.2）：原文が言い換えているので『』に入れず、daemonia は訳語表の「ダイモン」。
- 神々の複数形は「アポロたち」のように残す。Castores は表のとおり「カストルの兄弟」。11.3 の disciplinae は異教の神々の「教え」、10.6 の監察官の disciplina は「規律」。11.2 の sacerdotales praesides は人で「祭司である主宰者たち」。
- parentatio・parentare は 6.3 と同じ「死者を祭る」。13.2 の conditio は『護教論』の「ありさま」。
- 9.3 のウェルギリウスは名を補わず、『』に入れて節の文に続けた。10.5 のポンペイウスの布告は「」。

レビューの後にメインで見直したもの：
