メインで決めたこと（論点一覧の「メインで決めること」）：
- 5.8 の池の名は、原文の Bethsaida ではなく口語訳ヨハネ五・二 の「ベテスダ」にした。本の名前の表の決まり（口語訳にある名前は口語訳の表記）に従い、口語訳の「ベツサイダ」はガリラヤの町の名で紛れるため。原文の名はメモに書いた。天使の節（ヨハネ五・三 後半〜四）が後代の挿入とされることは、口語訳自身が〔 〕で示すので訳注を付けなかった。
- 5.7 の Nympholeptos は Oehler 自身の推定だが、どの読みでも水の害を受けた者の呼び名を並べる要点は変わらないので、訳注を付けず、刊本の読みと CSEL の十字をメモに書いた。
- 5.10 の unum semel anno は原文どおり「一年に一度、一人を」とし、口語訳の「時々」をメモに書いた。
- 5.5〜5.6 の adfectatio・adfectare は、注 h のとおり神のわざを「まねる」意味なので、『殉教者たちへ』の「熱中」と分けて「まねごと」「まねる」とした。
- 5.11 の imago／similitudo は、口語訳の「かたどって」では名詞の対が出ないので、地の文で「かたち」「似る（似ること）」とし、出典（創世記一・二六、二・七）を付けた。
- 6.2 の arbiter は、天使についても三つの御名についても「立会人」、sponsor・sponsio は「保証人」「保証」。angelus baptismi は『祈りについて』16.4 の「祈りの天使」に揃えて「洗礼の天使」。マタイ一八・一六 は原文が「三人」だけを言い、論がその数に立つので、地の文で言い換えた。
- 7.1 の使徒四・二七 は sicut in Actis で直接引くので『』に入れ、口語訳を下敷きにして、論の「父なる神」と結びつく filium を原文どおり「子」にした（3.2〜3.3 の創世記一・二 の型）。
- 8.1 は、水オルガンのたとえと分からないと文が読めないので、Oehler の注 a に従って「水オルガンでは」と補い、spiritus はオルガンの空気を「息」、神の側を「霊」と訳し分けた。
- 8.2 の Christum deformantes は「キリストをかたどって」とし、X の字か十字架かは補わなかった。
- 8.3〜8.4 の simplicitas は、マタイ一〇・一六 の口語訳「素直」とつなぐため「素直さ」。
- 8.4 の ubi ecclesia est arca figurata は、箱舟が教会のひな型だという向きで「このひな型では、教会が、前もって示された箱舟なのです」。
- 8.5 の quo male comparetur は「この点では、洗礼を洪水にたとえるのはふさわしくない」と取った。
