メインで決めたこと（論点一覧の「メインで決めること」）：
- 聖句の中の tinguere（10.8、11.1、11.3）も訳語表の「浸す」で通した。11 章の論は「このかたが浸す」を「このかたによって浸される」と読み替えることに立ち、口語訳の「バプテスマを授ける」にすると筋が消えるため。直接引く 11.1 と 11.3 は 7.1 の型で『』に入れて語を替え、メモに口語訳の文言を書いた。
- 12.1 のヨハネ三・五 と 12.4 のヨハネ一三・一〇 は、直接引き、論が原文の語（「水」「いのち」、「一度」）に立つので、7.1 の型で口語訳を下敷きに原文の語に替えて『』に入れた。12.7 のマタイ一一・一一 と 12.11 のマルコ一〇・五二、ルカ七・四八 は、論が語にかからないので口語訳の文言にした。12.11 のマタイ一〇・三七 は praetulerit に合わせて「重んじる」にした。間接の 10.1（マルコ一一・三〇）、10.7（マルコ一・四）は地の文。
- 12.4 の nolenti は底本どおりにし、Junius の volenti と CSEL の採用はメモだけにした。どちらでも主の答えの論は変わらないため。
- 12.11 の三人の名は補わなかった。本文が行いを物語っていて、出典を付ければ分かるため（『殉教者たちへ』4.7 の型）。「ある者は」で人を分けた。
- 9.4 の aqua in Christo は奪格に取った。9.5 の aqua intervenit は「水が居合わせる」とし、天使の「仲立ち」と分けた（訳語表に書いた）。10.2〜10.3 の potestas はどちらも「力」。
- 底本の起こしで、10.8 の venit の e の上の印、11.1 の venit の上の点、9.5 の vulneratur の前の線は、画像を 3 倍に拡大して汚れと判断し、起こしていない（`research/sources.md` に書いた）。
