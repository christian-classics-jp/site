レビューが変えなくてよいとしたもの：聖句の文言と出典（マタイ二八・一九、ヨハネ三・五、使徒九・六、二二・八、二二・一〇、第一コリント一・一二、一四、一六、一七、エペソ四・四〜六、ルカ一二・五〇、第一ヨハネ五・六、ヨハネ一九・三四、第一コリント六・一二、一〇・二三、一四・三四〜三五）。メモに書いた異読と校訂者の名前。訳注を付けていないこと。17.6 の Quodsi を事実を述べる形で受けたこと。

レビューが挙げた、メインで決めること：17.6 のテクラと「その書」（パウロ行伝）は本文だけでは読者に分からない。本の決まり（本文がその人の行いを物語っていて、名がなくても話が通るところは補わない。『殉教者たちへ』4.7 の型）により、本文は「パウロの名で誤って書かれたもの」「テクラの例」のままにし、書の名は `// ` メモだけに書いた。訳注は、別の読みや後代の挿入を知らせるものに限る決まりで、書の名はそのどちらでもないため付けない。テクラは名前の表に足した。

レビューの照合に入っていない暗示の出典（使徒九・一八、ヨハネ一三・一〇）は、メインが `node tools/bible.js` で確かめた。

レビューの後にメインが直したもの：13.1 の相手の言い分を、11.1 の型に揃えて「」の後で「と、彼らはこうまで言うのです」と受ける形にした（本の AGENTS.md に書いた）。14.3 の tinguere の刷りの欠けをメモに書いた。

メインで決めたこと（論点一覧の「メインで決めること」）：
- 13.3 のマタイ二八・一九 は、inquit で直接引き、論が docete と tinguentes に立つので（14.3、17.7）、7.1 の型で『行って、国民を教え、父と子と聖霊との名によって、彼らを浸しなさい』とした。in nomen は、論が語にかからないので口語訳の「名によって」のままにした。
- 13.3 のヨハネ三・五 は、論が「水」による洗礼の必要に立ち、renatus・regnum caelorum にはかからないので、口語訳の文言（『神の国』）にし、原文の語をメモに書いた（12.1 は論が「いのち」に立つので原文の語にした）。
- 13.4 の使徒九・六 は、九・六 の口語訳の「町」を原文の Damascum に替え、二二・一〇 を並べて出典にした。Damascum と Nazarenum がどちらも二二章の語のため。
- 16.1 のルカ一二・五〇 は、tingui を「浸される」に替え、baptismus は訳語表どおり口語訳の「バプテスマ」のままにした（12.7 と同じ）。
- 15.1 は底本の unus deus で「神は一つ」とし、エペソ四・四〜六 の出典を付けた。ex domini evangelio には Oehler の注 c のとおり（ヨハネ一三・一〇）を付けた。
- 13.2〜13.3 の lex（sua lege、Lex tinguendi、Huic legi）は訳語表の「掟」で揃えた。
- 17 章の教会の職は、このリポジトリの『イグナティオスの手紙』『第一クレメンス』『ディダケー』に揃えて監督・長老・執事。summus sacerdos は、口語訳の「大祭司」がユダヤの大祭司やキリストの呼び名と重なるので「最高の祭司」。laici は「信徒」、discentes は注 b のとおり直前の laici を言うので「弟子である信徒たち」。
- 17.3 の census は注 c のとおり「神の財」とし、『見世物について』の「出どころ」と分けた。
- 17.5 の constantia と 17.7 の constanter は、注 f・注 m のとおり「臆せず」で揃え、『殉教者たちへ』の「不屈」と分けた。
- 17.4 の utaris は「あなた」とし、注 e のとおり「その務め」（監督の務め）を補った。
- 17.5〜17.7 の mulier・femina は、『祈りについて』21〜22 章のような二語の論がないので、どちらも「女」。
- 16.2 の potarent は底本どおり「飲む」とし、初版の portarent はメモだけにした（論点一覧も訳注を勧めない。読みの違いが刊本どうしにとどまり、どちらでも二つの洗礼という論は変わらない）。
- 13.1 のアブラハムは、暗示の箇所が一つに決まらない（創世記一五・六、ローマ四・三、ヘブル一一章）ので出典を付けなかった。16.1 の「召された者、選ばれた者」も、マタイ二二・一四 の暗示と決めきれないので出典を付けなかった。
