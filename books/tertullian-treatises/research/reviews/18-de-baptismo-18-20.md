メインで決めたこと（論点一覧の「メインで決めること」。本の AGENTS.md の『洗礼について』の 18〜20 章の項と訳語表に書いた）：
- 18.1・18.6 の credere は、注 a のとおり「委ねる」で揃えた（18.6 の掛け合いを残すため）。
- 18.2 の impressus は注 c の Oehler の解（聖書が身に深く刻まれた）。ピリポを呼ぶ apostolus は原文どおり「使徒」とし、使徒二一・八 の「伝道者ピリポ」と、口語訳八・二六 で命じるのが「主の使」であることをメモに書いた。
- 18.3 の Simon hospes は底本どおりにし、訳注「『ユダ』と読む古い刊本や、『アナニヤ』と直す案もある。」を付けた。使徒行伝の話（宿はユダの家、告げられたのはアナニヤ）と合わず、読者が使徒行伝と照らすと戸惑うので、別の読みを知ることで理解が変わる箇所とみた。Iudas は Pamelius の刊本、Ananias は Latinius の推定（18 章の校注 6、p. 638。画像 n667 で確かめた）。
- 18.4 の sponsores は訳語表の「保証人」（6.2〜6.3 と同じ語）。
- 18.6 は底本の平叙文に従い、CSEL（Hartel）の疑問符に寄せず、23.7 の型で「…というのでしょう」と皮肉に受けた。
- tentatio は訳語表の「試み」で通し、20.3 のマタイ二六・四一 も 7.1 の型で「試みに陥らないように」とした（論が tentati、intentatum、tentationes の一語でつながるため）。
- 19.1 の Pascha は『祈りについて』18.4 と同じ「過越」。19.2 の Pentecoste は『祈りについて』23.3 と同じ「五旬節の五十日」。utique in Pentecoste は、昇天と天使の言葉が五十日のうちにあったことを言うと取り、別の取り方をメモに書いた。
- 19.3 のエレミヤ三一・八 の『祭りの日に』は七十人訳（三八・八 の ἐν ἑορτῇ φάσεκ。Swete III l. 30105–30107 で確かめた）にだけある句で、論がその句に立つので、口語訳を下敷きに語を足し、『祈りについて』29.2 の型で訳注「『祭りの日に』は、ギリシア語訳にだけある句。」を付けた。
- 20.2 の si nunc publice は Junius の推定で、刊本はみな si non publice と意味が逆（20 章の校注 1、p. 639。画像 n668 で確かめた）。1.3 の Itaque illa と同じく、底本が古い刊本と違い、意味が逆になるので、訳注「古い刊本はみな『公に告白しないなら』と読む。」を付けた。
- 20.3 の neminem intentatum … は、欄外のルカ二二・二八〜二九 と語が隔たるので出典を付けず、メモに書いた。聖書の外の主の言葉とみる説は確かめていないので書いていない。
- 20.5 の in ipsum は「イスラエル自身に」。20.6 の hominem dei は原文の語のまま「神の人」とし、口語訳の文言をメモに書いた。
- 20.7 の primas manus … apud matrem は、注 f のとおり、8.1 の型で「初めて、母である教会のもとで、…祈りの手を広げます」と補った。
- 20.8 の inquit は Petite, et accipietis だけにかかるので、そこだけを口語訳の文言で『』に入れ、完了形の続きは地の文にした。
