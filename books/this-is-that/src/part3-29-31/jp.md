# 小羊の婚宴
**幻（モントウェイトのキャンプ集会にて、神の力のもとで語る）**

わが愛する方を、だれにたとえようか。<br/>麗しい者の中で、最も麗しい方。<br/>まもなく私は、その栄光にあずかる。<br/>空中での出会いのときに。<br/>

『この白い衣を身にまとっている人々は、だれか。また、どこからきたのか』（黙示録七・一三）

『雲のように飛び、はとがその小屋に飛び帰るようにして来る者はだれか』（イザヤ六〇・八）

今、地上では大いなる動きが起こっている。地上だけではない。天においてもである。すみやかに近づいている大いなる出来事のための、大いなる備えである。花嫁とその友人たちは、絶え間ない興奮に打ち震えている。花嫁は、急ぐあまり震える愛の手で、細かい刺繍をほどこした婚礼の衣を身にまとい、嫁入り道具を念入りに調べている。足にはサンダルをはいている。大いなる出来事が近づくにつれて、彼女は最後の支度を急いでいる。その出来事はあまりに大きく、あまりに近い。それが彼女の上にそびえ立ち、間近に迫るその影のために、ほかのものは何も目に入らないほどである。

あかりの大いなる点検が行われている。油の入れものが調べられている。油が漏れ出てしまった人々や、使い果たしてしまった人々は、息を切らして、売る人のところへ急いでいる（マタイ二五章）。空中での出会いに加わろうとしている人々は、商売や、この世の気苦労や、地上の務めを後にしている。急ぎ足で汽車に乗り、車に乗り、いたるところからキャンプ集会や待ち望みの集会へ駆けつけ、自分のあかりのための油を求めている。小羊の血で衣を洗うことが、盛んに行われている。澄んだラッパのような呼び声が夜を貫き、いたるところで眠っているおとめたちに目をさませと命じて、こう言っている。

『さあ、花婿だ』（マタイ二五・六）

花嫁は花婿を慕い求めている。花婿は花嫁を慕い求めている。妻は自分の用意をしている。主のほかには何ものも満たすことのできない大きな慕わしさが、彼女の魂を満たしつつある。彼女の目は、言い尽くせない慕わしさをもって雲に向けられている。彼女の目は幻をとらえた。主の御顔を一目見たのである。彼女はつま先立ちになり、顔を上に向けている。見張り、待ち、その魂の愛する方を見ようと慕い求めている。彼女の耳は天の賛歌の一節をとらえた。主の御声を聞いたのである。まわりには多くの顔と声がある。けれども、それらは彼女の目をほんの一瞬さえ引きつけることができない。長い夜の暗やみと陰鬱の中で、彼女は待ち、見つめ、空を探している。期待に満ち、涙にかすむ目で、両手を差し伸べて。

神は御子、すなわち天のイサクのために花嫁を捜して連れて来させようと、使者を遣わされた。その使者、すなわち聖霊は、「この人といっしょに行きます」と言った人々を集めておられる（創世記二四・五八）。そして彼らを、聖霊のエレベーターに乗せておられる。このエレベーターは、彼らを主のもとへ引き上げるものである。聖霊は、花嫁が愛する方の腕の中に無事に抱かれるまで、決して花嫁を離れられない。

天においても、大いなる備えが進められている。御使の軍勢が集まりつつある。立琴や弦楽器の調律が盛んに行われている。天の楽団は、その晴れの日のために婚礼の歌を練習している。その日は、天でかつて知られた最も偉大な日である。御子がご自分のふところの妻を、その腕に抱かれる日なのである。天のすべての目が花嫁に注がれている。花婿は彼女への愛に圧倒されている（雅歌六・五）。その日が近づくにつれ、空気そのものが期待に張りつめている。

突然、星をちりばめた天の床が二つに裂ける。花嫁の信仰はむなしくなかった。約束された方が、そのみことばを果たされた。主は約束を守られたのである。天が開け、突然、御座からの光の矢が地の暗やみを貫き、照らす。うっとりと上を仰ぐ彼女の顔は、主の輝きを受けて姿を変える。彼女は、刺し通された主の御足が現れ、下って来られるのを見る。続いて、驚くほど輝かしい光の衣をまとった主の全身を見る。天全体が御使の雲、無数の天の軍勢で満たされる。そして、躍り上がり、高鳴る胸をもって、彼女の目はついに主の御顔を見る。

全天の楽団のあらゆる立琴、あらゆる弦楽器、あらゆるラッパが、一つの長く甘い音を打ち鳴らし、響かせ続ける。その音は静けさを震わせ、歓喜の旋律となってはじける。その響きとともに、大きな揺れとおののきが地を揺り動かす。墓が裂けて開く。イエスを死人の中からよみがえらせられた同じ御霊が、死人たちの死ぬべきからだを生かされる（ローマ八・一一）。そして、その歓喜の音楽の呼びかけに応じて、彼らはよみがえる。主の義の白い衣をまとい、顔を上げ、手を差し伸べて、空中を上へと躍り出て行く。天を輝かせ、栄光で満たしておられる、あの栄光の御姿に向かって行くのである。

もう一つの旋律が、ほとばしり出る。その力はあまりに強く、全天がその威厳ある輝きに震えるほどである。その響きとともに、地上で待っていた人々は変えられる。引力の法則は、彼らを支配する力をすっかり失う。両腕を広げて待っておられる方から、彼らを引き止めることができなくなるのである。主は合図の声をもって下って来られ、こう言われる。『わが愛する者よ、わが麗しき者よ、立って、出てきなさい』（雅歌二・一三）。死ぬものは死なないものを着、朽ちるものは朽ちないものを着る（第一コリント一五・五三）。

彼女の目は主を見た。彼女は空中を飛んで主に会いに行き、主も彼女のほうへ来られる。両腕を広げて、二人は出会う。ああ、空中でのその出会い！　ついに主は、彼女をその腕に抱かれる。主がそのために死なれ、これほど長く待ってこられた彼女を。ついに彼女は、その女王のような頭を主の胸にもたせかける。彼女がそのために生き、夢の中で幾度も思い描いてきた方の胸に。主は彼女の涙をぬぐわれる。抱き合うとき、二人の唇が触れ合う。あらゆる立琴と楽器が、婚礼の歌を力強く、威厳ある輝きをもって鳴り響かせると、全天は揺れ、揺らぎ、震える。その歌は高まっては低まり、空中にこだまし、こだまを返す。

全天が、空中での出会いを見るため、また花嫁を迎えるために出て来て、こう言う。『わたしたちは喜び楽しみ、神をあがめまつろう。小羊の婚姻の時がきて、花嫁はその用意をしたからである』（黙示録一九・七）。二人は共に昇って行く。天はふたたび巻かれて閉じる。地にはさらに深い暗やみが降りる。けれども、星をちりばめた天の床のかなたでは、大いなる歓喜がある。御座に至る長い道の両側には、目の届くかぎり、無数の御使の軍勢が幾重にも並んでいる。御座の上には、輝く栄光の雲がとどまっている。あの驚くべき婚礼の行進曲が、言い表しがたい荘厳さで脈打ち、鳴り響く。それに合わせて、主は、ご自分の腕に寄りかかる彼女を御座へと導かれる。そして、しみも傷もなく、輝く清さのうちに、主の義と力をまとった彼女を、父に差し出される。

続いて驚くべき式が行われる。それはあまりにすばらしく、人が語ってはならないほどである。そして小羊の婚宴となる。そこでは、花嫁と花嫁の友人たちが、白い衣をまとった御使の軍勢に給仕され、言葉につくせない喜びにあふれる。二人は共に、御国のぶどう酒を飲む。花嫁の目には、ただひとりの方しか映らない。彼女の主、救い主、王、夫である。

すべての涙は永遠にぬぐわれた（黙示録二一・四）。暗やみは消え去った（黙示録二一・二三）。何ものも、彼女を主から引き離すことはない。彼女は、いつまでも、いつまでも主の御前に住む。

太陽の輝きをまとっているこの方は、だれか。<br/>それはイエス、聖なる方。<br/>平和のにじはその御足の下にあり、<br/>神格の力は、この方のうちに満ちている。<br/>

# あのすばらしい日

神の御子イエスは、まもなくふたたびこの地上に帰って来られる。聖霊は花嫁に、空中で主に会う備えをせよと、最後の呼びかけを送っておられる。今日、地上では大いなる動きが起こっている。罪深い国々の中だけでなく、主が現れてくださる大いなる日のために備えている、義なる聖徒たちの中でもである。

『主ご自身が天使のかしらの声と神のラッパの鳴り響くうちに、合図の声で、天から下ってこられる。その時、キリストにあって死んだ人々が、まず最初によみがえり、それから生き残っているわたしたちが、彼らと共に引き上げられ、空中で主に会い、こうして、いつも主と共にいるであろう』（第一テサロニケ四・一六〜一七）

その日は、なんとすばらしい日になることであろう！　最も雄弁な舌も、最も霊感を受けた筆も、その大いなる勝利の日の栄光の、ほんの一端さえ語ることはできない。

時の初めから、すばらしい日はいくつもあった。けれども、この日はそのすべてにまさって輝く。神がことばによって世界を存在させられた日は、すばらしい日であった。神が天に太陽と月と星を置かれた日も、すばらしい日であった。神がご自分のかたちに人を創造された日は、すばらしい日であった。人が罪に陥り、死ぬべき者と定められたとき、神は、御子イエスを遣わすと約束してくださるほどに、この世を愛された。御子が苦しみを受けて死なれ、人を罪の深みから栄光の最も高い所にまで引き上げてくださるためである。その日も、すばらしい日であった。博士たちが東方で主の星を見、イエスが幼子として飼葉おけの中に生まれられた日は、すばらしい日であった。

イエスの宣教の働きの中には、すばらしい日がたくさんあった。病人をいやし、らい病人をきよめ、死人をよみがえらせ、悪霊を追い出し、奇跡を行い、群衆を養われた日々である。

イエスがピラトの前で裁判を受けられた日は、すばらしい日であった。毛を切る者の前に黙っている小羊のように、イエスは口を開かれなかった。

イエスが十字架に釘づけにされた日、私たちの身代わりとなり、私たちの負債を支払い、私たちの受けるべき罰を、木の上でご自分の身に負われた日は、すばらしい日であった。人々がイエスを墓に納めた日もすばらしい日であったが、イエスがよみがえり、勝利の栄光と力のうちに出て来られた日は、さらにすばらしい日であった。

イエスが、驚き見つめる弟子たちのもとを去って天の父のもとへ昇られ、雲に迎えられて見えなくなられた日は、すばらしい日であった。ああ！　けれども、さらにすばらしい日が来ようとしている。ほかのすべての日の冠となる日である。その日、イエスはふたたび地上に帰って来られる。主は雲を分けて来られ、私たちは、輝かしい衣をまとって天から下って来られる主を見る。今度は、はねつけられ、拒まれ、つばきをかけられ、打たれるために来られるのではない。今度は、勝利の王として帰って来られる。勝利を得る者たち、すなわち最後まで救いを保ち、花嫁への呼びかけに目をさます人々を、目ざめさせてくださるためである。あなたも、その花嫁の行列に加わるように招かれている。償いをしなさい。血におおわれなさい。イエスはまもなく来られるからである。

# 朝に向かって

夜明けの直前が、いつもいちばん暗い。今日、世界は、かつて知られたことのないほど暗い、真夜中の悲しみのとばりに包まれている。死と悲惨、殺戮と絶望、破壊と荒廃がはびこっている。何十万もの家庭で、母や妻たちが泣き、嘆いている。私がこの言葉を書いている今も、慰められることを拒む者のように嘆いている。昔のエジプトの暗やみのときと同じように、今日、災いと疫病が地上に放たれている。そして今、朝の直前に、長子たちが殺され、血は川のように流れている。死に触れられずにすんだ家庭や炉辺は、ほんとうにわずかである。

出エジプト記十二章二十九節にはこうある。『夜中になって主はエジプトの国の、すべてのういご、すなわち位に座するパロのういごから、地下のひとやにおる捕虜のういごにいたるまで撃たれた。エジプトに大いなる叫びがあった。死人のない家がなかったからである』。それから救いが来た。イスラエルの子らは、歌いつつ導き出された。

疲れ、悩み、悲しみに引き裂かれた愛する人よ、目を上げなさい。夜はふけた。長く疲れた道は、ほとんど終わろうとしている。『夜はよもすがら泣きかなしんでも、朝と共に**喜び**が来る』（詩篇三〇・五）。あの太陽が今朝、山々の上にのぼって夜の影を追い払ったのと同じほど確かに、義の太陽であるイエスは、不朽の栄光のうちに山々の上にのぼられる。そして、ご自分の民、ご自分の勝利を得る子供たちを、涙の決して流れることのない国へ連れて行かれる。

今日、暗やみの力が四方から迫っている。悪はますます悪くなっていく。ときどき私たちは、驚くべき事態について読む。最も勇敢で最も優れた者たちが殺されたこと、砲弾に引き裂かれた畑、打ちひしがれた家庭、父のない子供たちの泣き声、焼かれる家々のことである。また、写真家がかなたの戦地から送ってくる写真で、飢えのために黒ずみ、やつれた顔を見る。歩く骸骨のような幼い子供たちが、パンがないために恐ろしい死に方をしていく痛ましい光景を見る。そのようなとき、私たちの頭はそのすさまじい光景の前にくらくらし、すべてが何か恐ろしい悪夢のように思われる。けれども、そうではない。それはあまりにも、あまりにも真実なのである。暗やみが降りた。多くの教会にも降りた。そこでは人々が『神よりも快楽を愛する者』となっている（第二テモテ三・四）。なまぬるい、信仰を言い表している人々が、『信心深い様子をしながらその実を捨てる』所にも、暗やみが降りた（第二テモテ三・五）。けれども、愛するみなさん、目を上げなさい。もうすぐ朝である。ハレルヤ！

『あなたがたは弱った手を強くし、よろめくひざを健やかにせよ。心おののく者に言え、「強くあれ、恐れてはならない。見よ、あなたがたの神は報復をもって臨み、神の報いをもってこられる。神は来て、あなたがたを救われる」と。主にあがなわれた者は帰ってきて、その頭に、とこしえの喜びをいただき、歌うたいつつ、シオンに来る。彼らは楽しみと喜びとを得、悲しみと嘆きとは逃げ去る』（イザヤ三五・三〜四、一〇）

日々の生活の中で、心の痛みや、あなたに加えられる圧力、十字架の重み、道に生えるいばらのために、あなたは途中でほとんど弱り切ってしまいそうになったことがあるだろう。けれども、愛する人よ、もう少しのあいだ堅く立ちなさい。もう少し先へ進みなさい。見なさい！　あのかなたの山々の頂の上に、灰色の夜明けが訪れようとしている。イエスはまもなく来られる。主はすべての人の顔から、すべての涙をぬぐってくださるために来られる。『だから、あなたがたは、これらの言葉をもって互に慰め合いなさい』（第一テサロニケ四・一八）。疲れた旅人にとって、これほど甘い慰めの言葉がかつてあっただろうか。「イエスはまもなく来られる」。この驚くべき言葉は、うなだれた頭を上げさせる。「イエスはまもなく来られる」。その栄光の望みによって、弱った手は新たな力と望みを得て、高く上げられる。「イエスはまもなく来られる」。この言葉は、あまりにも栄光に満ちた幻をもたらす。そのため、この涙の谷にあってさえ、あの栄光の朝のゆえに、目は輝き、歓喜にうるむのである。

『主ご自身が天使のかしらの声と神のラッパの鳴り響くうちに、合図の声で、天から下ってこられる。その時、キリストにあって死んだ人々が、まず最初によみがえり、それから生き残っているわたしたちが、彼らと共に雲に包まれて引き上げられ、空中で主に会い、こうして、いつも主と共にいるであろう』（第一テサロニケ四・一六〜一七）

何ものにも、あなたの歩みを妨げさせてはならない。落胆が、越えられない障壁のように、あなたの道に立ちはだかっても、イエスの名によって進み続けなさい。そうすれば、その障壁は、夏の日差しの前の影のように消えうせる。あなたは夜、さびしい田舎道を歩いていて、「人が木のように歩いている」のが見えるように思ったことはないか。あそこの曲がった切り株が、通りかかるあなたに今にも飛びかかろうとしている巨人のように見えたことを覚えているか。あそこの何でもない柵の杭が、何か恐ろしい、口にできないことをしようと身をかがめて構えている、夜の恐ろしい亡霊のように見えたことを。夜の物音さえ、ふだんとは違って聞こえた。牛が鳴いたり、草をはんだりする音に、あなたの胸は激しく打ち、「あれは何だ！」と叫んだ。朝の光が影を追い払い、物音のもとを明らかにしたとき、あなたは自分の恐れを笑った。愛するみなさん、私たちもそれと同じである。暗やみの中を進み続けるなら、私たちの恐れはみな、ただの愚かさにすぎなかったとわかる。私たちは主のうちに、あらゆる危険から安全に隠されているからである。

ほえたける獅子は、実は鎖につながれている。あなたが主のそば近くを歩いているかぎり、あなたを害することはできない。敵がどれほどあなたをおびえさせようとしても、夜の恐ろしい亡霊を恐れてはならない。進み続けなさい。夜の影がことごとく巻き去られ、私たちが顔と顔とを合わせてイエスを見る時は、もう遠くない。

この古い世で私たちがささげ、苦しんできたものは、すべて忘れられる。そうだ、すぐに来られる私たちの愛する方の目を、ただ一度のぞき込むだけで、それはみな取るに足りないものとなって消えていく。たとえ地上のすべての友を失うことになっても、ひとりで立つことになっても、最後までやり通しなさい。迫害やそしりを受け、自分に死に、日々自分をキリストと共に十字架につけられた者と認めることになってもである。『最後まで耐え忍ぶ者は救われる』からである（マタイ二四・一三）。血におおわれて、へりくだっていなさい。御霊に満たされなさい。衣をしみのないように保ち、足にサンダルをはき、入れものに油を満たしなさい。夜が明けて影が消えうせるまで、そうして備えていなさい。
