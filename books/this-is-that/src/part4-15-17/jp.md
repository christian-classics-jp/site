# 治めよ、沈黙よ、治めよ
**預言（一九一八年十一月二十二日）**

治めよ、沈黙よ、治めよ！<br/>静まれ、黙れ！<br/>海の大波よ、黙れ！<br/>沈黙よ、しばしのあいだ治めよ！<br/>その翼を広げよ。一つは陸の上に、一つは海の上に。<br/>

静かに！　天の四方の風よ、争うのをやめよ。<br/>嵐の雲よ、静まれ！<br/>剣よ、さやに納まれ！<br/>とどろく大砲よ、黙れ！<br/>主はもう一度、地に語ろうとしている。<br/>もう一度、主はあの叫びを送り出そうとしている。<br/>

**見よ、花婿が来る。戸口まで近づいている**。

緑の草の葉よ、野原と丘の上に萌え出よ。まことに、丘と谷よ、花を咲かせよ。ああ、あなたは戦争の巨大な手に固く握りしめられてきた。明るい深紅の血のしずくが、あなたの脇腹から絞り出され、血なまぐさい流れとなって流れ出た。

引き裂かれ、荒らされた森よ、しばしのあいだ傷をいやされよ。主の大いなる輝かしい日が来る前に、主は地に最後の警告の言葉を語ろうとしているからである。その日は近い。**まことに近い**。

御使いたちよ、しばしのあいだ風を引き止めよ。風はやがて、私たちのあがない主キリストを忘れた世に、倍の激しさで吹きつける。その前に引き止めよ。わたしの子らが大いに呼ばわるためである。声をあげて惜しまず、しばしのあいだ「主の来臨」を告げ知らせるためである。

## 目をさませ
目をさませ！　目をさませ！！　いと高き神の子らよ。わたしは自分の手で押しとどめているからである。怒りと憤りを、戦争と疫病を、災いを、地震と苦しみを。神を忘れたすべての者をまもなく包む、激しい火の憤りを。

「**平安だ**」と人々は叫ぶのか。<br/>見よ、平和の君のほかに平安はない。<br/>「**平安だ**」と人々は叫ぶのか。<br/>けれども、平安を叫ぶその声は、彼ら自身の頭上に落ちる。<br/>今日は救いの日である。<br/>

みことばを宣べ伝えよ。<br/>まことに、朝早くから日の沈むまで、それを告げ知らせよ。<br/>まことに、黙っていてはならない。<br/>

## みことばを宣べ伝えよ

夜の見張りの時にも大声で叫べ。<br/>民に警告せよ、民に警告せよ。<br/>このメッセージを地に鳴り響かせよ。<br/>丘々にこだまさせよ。<br/>谷々に響き渡らせよ。<br/>主の日が近いからである。<br/>主の民の救いの時が来た。<br/>

けれども、神を忘れた者たちの頭上には悲しみが降りかかる。<br/>なだれが山腹を流れ下るように。<br/>主の声のとどろきが聞こえるか。<br/>それは主である。主がその軍勢の前で声をあげている。<br/>主は彼らを率いて、勝ち誇って進み出る。<br/>栄光の冠は彼らのもの。<br/>勝利は彼らのもの。<br/>勝利を得た方、<br/>敵を従わせた方、<br/>とこしえに治める方によって。<br/>急げ！　急げ！　わたしの小さい者たちよ。<br/>急げ！　もう時間はない。<br/>見よ、わたしはまもなく来る。<br/>空中であなたがたに会うために。<br/>

わたしの愛する者、わたしの選んだ者よ、声をあげよ。<br/>わたしに賛美をささげよ。<br/>わたしの愛する者よ、喜べ、喜べ。<br/>あなたの王をたたえる賛美のうちに。<br/>

**ああ、このメッセージを送り出せ**。<br/>
屋根の上から叫べ。<br/>尖塔から告げ知らせよ。<br/>幕屋で宣べ伝えよ。<br/>道やかきねのあたりで告げ知らせよ。<br/>通りで、路地で、<br/>町の市場で、寂しい荒野で。<br/>

沈黙よ、治めよ。しばしのあいだ治めよ。わたしの子らが、最後の、最終の呼びかけを送り出すまで。わたしはまもなく来るからである。アーメン。

# 愛の翼と勝利の教会

（一九一九年一月七日、カリフォルニア州ロサンゼルスにて）

緑の野から、それは来て、高く舞い上がった。<br/>豊かで見事な実をたわわにつけた木々の上へと。<br/>乳のように、雪のように白い翼で、それは舞い上がった。<br/>このはと、優しく清らかなはとが。<br/>その翼は広く、その羽は長かった。<br/>高く、さらに高く上り、<br/>ついには雲と、日に照らされた空の中を渡って行った。<br/>主の民、主の民は、はとのようである。<br/>彼らが飛ぶための翼は、愛である。<br/>けれども今、低く落とされた、はとよ。<br/>翼は切られ、風切り羽は抜かれ、<br/>愛は損なわれ、失われた。どうしてあなたは、昔の日のように高く飛べようか。<br/>私は見た。はとが低く落とされ、打たれ、突かれるのを。<br/>はとは、突きつつく棒から逃れられなかった。<br/>誤りと偽りの教えという棒から。<br/>物好きで、試したがりの子供たちが、通りすがりにそれでいじめた棒から。<br/>けれども見よ、羽はふたたび生え始めた。<br/>その翼は、雪のように白く萌え出る。<br/>前よりも強く。<br/>愛と賛美が、あなたを起き上がらせる。<br/>そして大空へと舞い上がらせる、わたしの愛する者よ。<br/>あなたの翼を切り取らせてはならない。<br/>わたしはまもなく、夜明けに来るからである。<br/>どうしてあなたは、空中でわたしに会うために上って行けようか。<br/>もしその翼が損なわれていたら。ああ、こよなく麗しい愛する者よ。<br/>

主はご自分の民のただ中で、新しいわざをしようとしておられる。力と勢いのうちに、ご自身を現そうとしておられる。だから、あなたの愛を満ちあふれさせなさい。心をつくしてあなたの神を愛し、自分を愛するようにあなたの隣り人を愛しなさい。子たちよ、互いに愛し合いなさい。そうすれば、あなたの翼は広く広げられる。あなたは地上のささいなことの上に引き上げられ、主の栄光を見る。そして広大な天を通って、主の御前そのものへと舞い上がる。セラ！

# 花婿と花嫁
**預言**

大いなる、永遠の神の愛よ、<br/>だれがあなたを測り得よう。<br/>神々しく、全能の、栄光ある神の愛よ、<br/>だれがあなたの底を極め得よう。<br/>

私たちは海の深みに下って、尋ねる。「神の愛はここにあるか」深海の生き物たちはみな、大声で叫んで言う。「大いなる、大いなる、大いなる神の愛が、私を見守っている」

見よ、私たちは天に上る。そこでは鳥たちが翼を広げて、青い大空を渡っている。私たちは尋ねる。「あなたの愛はここにありますか」鳥たちは大声で叫ぶ。「しかり、しかり、しかり。主の愛が私を支えている」

私たちはさらに、天の霊妙な大空の高みへと上って行き、叫ぶ。

「まさか、主の愛がこれほどの高みにまで上ってはいないだろう」けれども、星々はその栄光のうちに共に歌い出し、私たちに請け合う。「しかり、しかり。主の大いなる愛が私たちを支え、私たちを輝かせ、主の栄光を映させているのだ」

それから私たちは下って、さらに進み、遠く砂漠の静かな荒れ地へと踏み入る。私たちの心は叫ぶ。

「大いなる神の愛よ、まさかこの不毛の地にまでは届いていないだろう」けれども、砂は大声で叫ぶ。「しかり、しかり。主はここにおられ、その愛を注ぎ出しておられる。主の愛は砂漠をばらのように花咲かせる。荒野には池ができ、かわいた地には川が流れる」

永遠の神よ、あなたの限りない愛は、底知れない永遠の年月を通して語り続けても、なお語り尽くせません。あなたの翼、広げられたつばさは、地の果てにまで届いています。あなたは、めんどりが巣の上にうずくまるように、地を覆っておられます。あなたの愛の金色の流れが、その羽の一枚一枚から私たちの上に流れ下ります。あなたの民は、あなたの翼の陰で、日の暑さからも、荒れ狂う嵐からも守られます。とこしえに、とこしえに。

主は伸ばした御手で、ご自分の民を導き出された。<br/>分かれた水の中を、足をぬらさずに。<br/>主は彼らの目の前で、その敵を滅ぼし尽くされた。<br/>主は天から彼らの上にマナを降らせられた。<br/>毎朝、新しいマナを。<br/>主はご自分の軍勢を、広い地へと導かれた。<br/>乳と蜜の流れる地へ。<br/>ざくろと、ぶどうの木の実りの地へ。<br/>ぶどうと、尊い実りの地へ、<br/>主はご自分の民を導き出された。<br/>

彼らの分は栄光に満ち、<br/>義と平和が彼らの衣であった。<br/>まことに、主の民は主にあって喜び、<br/>とこしえに主の御名をあがめる。<br/>

主は麗しい、朝の夜明けのように。<br/>主は輝かしい、真昼の太陽のように。<br/>主は甘い、蜂の巣の蜜のように。<br/>このイエス、栄光の小羊は。<br/>

主は優しい、幼子を抱く母のように。<br/>主は強い、あなたの国境を守る山々のように。<br/>主は力強い、あなたの岸に大波を打ち寄せる海のように。<br/>主は栄光に満ちている、この王の王、万軍の主は。<br/>

歌声と共にご自分の民を導き出されたのは、この方である。<br/>この方は、王の軍勢の将である。<br/>主の民は主のあとに従い、<br/>その軍隊は主をたたえて叫ぶ。<br/>

## 小川と大海

聞け！　聞け！　主はご自分の民に語っておられる。「あなたは、日の光に輝いているこの細い小川を見るか。目を上げて、力強い大海の、広大な、果てしない広がりを見るか。あなたの今の境は、細い小川のようなものにすぎない。けれども、もしあなたがわたしに従うなら、わたしはあなたの境を広くする。恵みと力と栄光があなたに増し加えられる。大海が小川よりも力強いように、あなたの後の栄光は前の栄光よりも大きくなる」

## 若木と樫

「あそこの樫の若木を見るか。そして、そのはるか上に高く成熟してそびえる、力強い親の樫に心を留めたか。わたしの子らは今、前の雨と、降り始めた後の雨とに養われた若木のようなものにすぎない。けれども、ああ！　もし彼らが頭を上げ、口を大きく開けて、豊かな後の雨を受けるなら、彼らはどこまでも育つ。その枝はあらゆる妨げの上に伸び、あらゆる障害の上に王の権威をもってそびえる。空の鳥はその枝の間に巣を作り、家畜の群れはその陰で大いに喜んで伏す」

## 幼子と巨人

母の手に支えられて、初めて歩き出す幼子を見るか。野を大またに歩いて行く力強い巨人を見たか。その広い肩の上では、最も重い荷も羽一枚の重さにしか見えない。

からだは今日、御霊に治められる領域の力といのちの中へ、初めの一歩を踏み出そうとしている小さな子供のようである。けれども、わたしの民がただわたしを仰ぎ見て、もはや人間の肉という母の腕に寄りかからないとしよう。そのとき、わたしは彼らを巨人のようにそびえ立たせる。彼らは勝利の大またで前進する。異邦人の前から彼らのそしりは取り除かれる。彼らはもはや「あなたの神はどこにいるのか」と問うことはなく、「私たちは遠くから主の光を見た」と言う。そのとき主は、力強く、強く、勝利を得て、栄光に満ちた教会を、自分のもとに迎える。

夜はその影と共に逃げ去ろうとしている。太陽は永遠の丘々の上に輝かしく昇り、夜が明けようとしている。祝福の大波が打ち寄せている。祝福の雨が激流となって降り注ぐ。見よ、日の光と雨の中で、神の栄光が昇り、その民の上に輝き出ているからである。彼らは神の御霊の力によって、力あるしるしと不思議を現す。

花婿の花嫁よ、喜べ。<br/>白い衣を着たおとめたちよ、楽しめ。<br/>喜べ、喜べ、その涙をぬぐえ。<br/>長い、長い夜は終わったからである。<br/>

見よ！　永遠の夜明けの光が差してくる。<br/>義の太陽が、その翼にいやす力を備えて昇る。<br/>まことに、太陽が昇る。決して沈むことのない太陽が。<br/>光が差してくる。決して消えることのない光が。<br/>

聞け！　ラッパが主の聖なる山に鳴り響き、こだましている。<br/>進軍ラッパだ！　大波を越えてやって来る、その澄んだ、速やかな声が聞こえないのか。<br/>それは、涙の流れることのない国からこだまして来る。<br/>

だから、愛と真理と賛美の衣をまとい、足にくつをはいて立て。<br/>分離のベールを顔にかけよ。<br/>主は、その愛する者のためにすぐに来る。<br/>

ベールをかけたあなたの顔は、世にとっては、隠された愚かな謎にすぎない。<br/>けれども、選ばれた者よ、わたしにとって、あなたの顔は麗しく、愛らしい。<br/>わたしもあなたも愛さない者たちは、あなたの名を悪しきものとして捨てた。<br/>けれども、わたしはわたしの新しい名であなたを呼んだ。あなたはわたしのものである。<br/>

わたしはあなたの名を、わたしのたなごころに彫り刻んだ。<br/>わたしはあなたを、わたしの心のひもに編み込んだ。<br/>わが愛する者よ、首の金の鎖と美しい宝石が、あなたを飾っている。<br/>

あなたのルビーは血のしずくのようである。あなたのために流された、わたしの血のしずくのように。<br/>あなたの真珠は、わたしと共に歩み、わたしの苦難にあずかった者が流した涙のしずくのようである。<br/>あなたのダイヤモンドは、あなたがわたしのために獲得した、この上なく尊い魂である。<br/>

あなたの心は義で、あなたの顔は喜びで満たされる。<br/>あなたの目が、夜明けの最初の光をとらえたからである。<br/>子たちよ、わたしは来る。朝に来る。<br/>

ギレアデの乳香よ、あなたはどなたですか。<br/>あなたは大軍の君です。ご自分の民を導き、あらゆる悲しみから彼らをいやされる方です。<br/>

勝利の足取りで来られ、戦いの戦利品を携えておられる力強い勝利者よ、あなたはどなたですか。<br/>あなたは私たちの花婿、義の王です。<br/>

分かれた雲の間から照らし、罪の夜の闇を貫き、悲しみの陰りを払う栄光の光よ、あなたはどなたですか。<br/>あなたは義の太陽です。栄光の主が、あなたの御名です。<br/>

地から天へ至る輝く小道よ、闇から光へ至る栄光の道よ、あなたはどなたですか。<br/>あなたはイエス、道であり、真理であり、いのちである方です。あなたのほかには、だれもいません。<br/>

ちょうつがいで大きく開かれた門よ、その門口から、祝福された、きらめく流れと、かぐわしい牧場が見える方よ、あなたはどなたですか。<br/>あなたは門です。だれでもあなたを通って入る者は、出入りし、牧草にありつくのです。<br/>

谷のゆりよ、シャロンのばらよ、輝く明けの明星よ、あなたの民の魂にとって万人にぬきんでて麗しい方よ。あなたこそ確かに私たちのイエス、王の衣をまとった王、世の初めからほふられた小羊です。<br/>あなたの愛する方の腕に寄りかかって、荒野から上って来る者よ。昇る太陽の最初の光が、姿を変える栄光となって降り注いでいる者よ。あなたはだれですか。<br/>あなたは教会です。小羊の選ばれた花嫁、勝利を得る者たちのからだ、水の中を通り、火の中を歩んだ、試され、ためされた民です。あなたは、あなたの愛する方、生ける神の子と婚約した妻です。<br/>

あなたを包み、義に輝いているこの白い衣は何ですか。<br/>これは主の義の衣です。私たちが裸であった日に、主が着せてくださったものです。<br/>尊い宝石をちりばめ、愛のひもで結ばれて、あなたの足を飾っているこのくつは何ですか。<br/>これは救いのくつです。主が導き出されるご自分の民に、はかせてくださったものです。<br/>

その衣には細やかな刺しゅうが施され、ひと針ひと針が金で縫われている。勝利者の義の冠がその頭に置かれ、彼女は王と共に王の御座で治める。<br/>

ああ、来よ、来よ、わが愛する者よ。時は短い。わたしはあなたを、さらに大いなる力と勝利へと、すぐに導き出したいと切に願っている。<br/>生ける神の教会よ、足を速めよ。<br/>もっとわたしに近く寄れ。わたしの腕にしっかり寄りかかれ。<br/>わたしはあなたを、はるかにまさった栄光へと導き出す。<br/>こうしてわたしたちは、道の終わりまで急いで行く。<br/>ついには、わたしがこの手で永遠の夜明けの燃える幕を押し開き、**わたしたち**が**わたしたちの永遠の勝利の日**の門口を通り抜けるまで。アーメン。<br/>
